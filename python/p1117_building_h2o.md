# 1117. Building H2O · Python

[原题](https://leetcode.com/problems/building-h2o/)。

本题提供H2O接口，每个原子线程只调用一次对应方法，回调实际输出H或O。氢信号量最多允许两个线程、氧信号量最多允许一个线程进入当前分子，每个线程输出后在三人屏障等待，整批三个原子都完成输出后才释放配额。因此下一批的任何字符都只能在上一批三个字符之后出现，连续每组三字符恰为两个H和一个O，不强制组内字符顺序。屏障可复用，适合连续构造多个分子。

每个原子执行常数次同步操作，总工作O(T)，阻塞时间由原子到达与调度决定。同步对象额外状态O(1)，不含运行时等待线程资源；原题保证总体原子比例正确且回调正常返回。
