# 502. IPO · Python

[原题](https://leetcode.com/problems/ipo/)。

初始资本w，最多完成k个不同项目。capital[i]是启动门槛，完成后把profits[i]直接加到当前资本，门槛不会被扣除，求最终资本最大值。原题项目数和k均1..100000，初始资本与门槛0..1000000000，利润0..10000，两数组等长。利润非负是贪心与资本单调增长的前提；输入保持，k=0或空项目列表额外返回初始w。

把(门槛,利润)复制排序，index指向尚未放入候选的第一个项目。每轮先把门槛不超过当前w的所有新项目入堆；Python最小堆中保存负利润，弹出最负值就得到当前可行的最大利润。弹出后从堆移除，该下标项目不会再次加入；相同门槛与利润的不同项目仍各有一个堆条目。

为什么可选最大利润：设最优方案下一项选q，贪心选当前也可行且利润不小的p，改成先做p后资本不会更少，原方案其他中间项目仍可启动。若原方案后面本来要做p，就在那时换做q；q在初始时已可行，而资本不减，换回后累计利润与原方案一致。若没有后续p，保留其余选择只会资本更多。这个交换可反复用于每一轮，所以贪心最优。

没有可行堆项时，全部尚未加入的项目门槛都高于w，又无法再增加资本，可以结束。每个项目至多做一次，因此实际最多迭代min(k,N)轮，不能把需要很高资本但利润大的项目提前选择，也不能把capital当实际成本扣掉。

排序O(N log N)，每项至多入堆一次，至多min(k,N)次出堆；总时间O(N log N+min(k,N) log N)，辅助空间O(N)。只调整局部w和复制后的项目列表，不改profits或capital；非负利润原约束给出最终资本不超过2000000000，Python整数精确表示。

独立参考递归枚举全部可行的不同项目顺序，允许提前停止，直接比较每条路线的最终资本，不排序或用堆。门槛/利润0..2的9种项目类型、长度0..3的820个项目列表，初始资本0..2、k=0..4，共12300次对照；空列表/k0为扩展。另测100000个项目、k上界、资本/门槛10^9、利润10000、逐步解锁、无法启动与零利润，核对整数和输入保持。未向LeetCode提交。
