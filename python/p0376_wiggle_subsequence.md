# 376. Wiggle Subsequence · Python

[原题](https://leetcode.com/problems/wiggle-subsequence/)。

原题nums长1..1000，值0..1000，求最长摆动子序列长度，必须保持原相对顺序；连续差须严格正负交替，0差不合法，单元素长度1。实现保持输入，返回int。

up、down分别表示已处理前缀可得到的末次差为正或为负的最大长度，单元素可作为任一方向的初始状态。相邻值上升时，用此前的down接成up；下降时对称更新down；相等不增加任何状态。连续同向段不应重复增长度，只需把最后选取的端点换成更高峰或更低谷，这不会缩小后续转向的选择余地，因此只看相邻升降即可保留最优。每项一次比较，时间O(n)，额外空间O(1)，满足线性进阶要求。

独立参考枚举每个保序子序列，计算差并检查非0和符号交替，不复用贪心状态。值0/1/2、长度1..7共3279个数组全部核对，另测1000项全相等、单调、最大值交替以及长平台，核对int及输入保持。
