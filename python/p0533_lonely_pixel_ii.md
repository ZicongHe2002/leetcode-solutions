# 533. Lonely Pixel II · Python

[原题](https://leetcode.com/problems/lonely-pixel-ii/)。

给定M行N列黑白图片，M、N在1..200，target在1..min(M,N)。计数满足两个条件的B位置：所在行与列都恰有target个B；该列所有含B的行都必须与该位置所在整行完全相同。输入矩阵及行对象保持，不把第二条件简化成只比较每行B的数量。

把整行转成不可变元组，统计每种完整行模式出现次数，并统计各列B总数。若位置(r,c)满足定义，则列c恰有target个B，这些B所在行全部与第r行相同。反过来，任意与第r行相同的行在c处也必为B，因此该完整行模式必须恰好出现target次。

于是必要条件是：模式的B数恰为target、该模式频率恰为target、位置本身是B、所在列B总数也恰为target。这些条件也充分：模式的target份副本已经贡献该列全部target个B，所以再无其他行模式在该列含B，整行一致条件自动满足。

每个不同模式只遍历一次。模式通过行数和频率检查后，符合列条件的每一列都贡献target个不同黑色像素，因此用target乘列数量，而不是只加1或重复遍历同模式的每份副本。不同模式不会数到同一位置。

哈希表通常时间O(M*N)，因为构造并哈希整行、统计列及扫描所有不同模式的总长度均至多M*N。辅助空间O(M*N)，最坏所有行模式不同，必须保存整行元组；不能把这项存储误写成O(M+N)。返回整数，不改图片。

独立参考对每个黑点直接按题意数同行和同列B，并逐一比较该列所有含B的完整行，不使用行模式频率表。1..3行列的全部682张黑白矩阵，对每个合法target查询，共1850次对照。另测200x200全黑、对角、100份重复行、相同黑点数但行内容不同的反例及原例，核对int、矩阵值和行对象保持。未向LeetCode提交。
