# 120. Triangle · Python

[原题](https://leetcode.com/problems/triangle/)。

原题triangle为1..200行的非空三角形，第i行有i+1项，值在-10000..10000。每次只能到下一行的同列或下一列，求从顶到底的最小路径和。所有行及内容保持，不承诺空三角形。

cost先复制最后一行，表示从该行各位置到底的最小代价。自底向上处理上一行，一个位置只能接下面同列和下一列的较小代价；列号自左向右更新，使当前列与右邻仍是下方行的旧值。处理完当前行后，cost对应前缀恰为该行到底的最小代价，最终cost[0]覆盖所有合法路径，负数不影响最优子结构。n为行数，时间O(n^2)，额外空间O(n)。

独立oracle枚举每一步向下同列或下一列的全部路径，再取实际路径和最小值，不复用DP。值-1/0/1、行数1..4的59808个三角形全部核对。边界覆盖200行、正负10000、左边界最优及单个负值，逐行检查输入保持与int类型。
