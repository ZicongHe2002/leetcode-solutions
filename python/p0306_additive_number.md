# 306. Additive Number · Python

[原题](https://leetcode.com/problems/additive-number/)。

判断一个十进制数字串能否分成至少三个非负整数，使从第三项起每项都等于前两项之和。除单独的0外，操作数不得带前导零；原题长度1..35。输入太短或不存在完整切分时返回False，不改变输入。

枚举前两项的结束位置。第一项以0开头时只允许取一个字符，第二项同理。第二项结束位置必须在串尾之前，所以后续至少要匹配一次完整和才能成功，不能把只有两项的切分当作合法答案。

前两项确定后，后续每个整数及其十进制长度都已唯一确定。用数串逐位相加生成following，检查原串从position开始是否完全匹配；匹配后前移并滚动保存最近两项，直到恰好消耗整串或某处失败。十进制加法从最低位向高位累加进位，0+0仍产生字符0，不经过浮点或固定宽度整数转换。

共有O(n²)种前两项切分。对一种切分，已匹配和的字符长度总计不超过剩余输入长度，另外最多计算一个失败的和；每次加法、反转和startswith成本与该和的长度成正比，所以单切分O(n)，总时间O(n³)，额外空间O(n)用于最近两项及数字缓冲。该界没有把任意长整数加法当作O(1)。

独立oracle枚举全部字符切割掩码，筛掉少于三项和前导零，再用Python精确整数直接核对每组三项，不复用生产前两项驱动的匹配过程或手写加法。三数字域长度1..7共3279个字符串全量核对。另测多次进位、0项、已知序列、35字符大数有效序列、35个0以及35个9的无解边界。
