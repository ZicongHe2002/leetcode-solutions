# 810. Chalkboard XOR Game · Python

[原题](https://leetcode.com/problems/chalkboard-xor-game/)。

当前异或为0时轮到的人立即获胜。异或非0且元素数为偶数时，总能选一个删除后仍非0的元素：若删除每个元素都会得到0，则每个元素都等于总异或，而偶数个相同数的异或应为0，矛盾。合法删除交给对方奇数长度、非0异或局面。奇数长度非0局面每次不立即输掉的删除都会交给对方偶数长度非0局面，因此按剩余长度归纳它是必败态。

计算一次总异或，时间O(n)、额外空间O(1)，不修改输入。
