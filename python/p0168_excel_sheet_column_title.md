# 168. Excel Sheet Column Title · Python

[原题](https://leetcode.com/problems/excel-sheet-column-title/)。

原题列编号1..2^31-1，返回Excel列名，A..Z对应1..26，之后AA、AB等。它使用没有0位的双射二十六进制，不能直接把余数0写成A而忽略进位调整。

当前编号减1后做divmod(...,26)，余数0..25正好映射A..Z，商是尚未处理的高位列编号。减1把原来的1..26一组平移成普通0..25，因此编号26得到Z且商0，编号27得到尾A且商1，再产生高位A。低位先得到，最后逆序连接。

每轮缩小约26倍，时间与额外空间O(log26(columnNumber))，原题最多7个字母。只用整数除法，不访问任何真实电子表格。

独立参考按字母位权直接计算输出对应的十进制数，不复用减1除法；合法字母1..26的表示唯一。1..20000逐一核对字母、长度及位权回读，另用A/Z/AA/AZ/BA/ZZ/AAA和最大FXSHRXW固定边界检查。
