# 450. Delete Node in a BST · Python

[原题](https://leetcode.com/problems/delete-node-in-a-bst/)。

原题为0..10000节点的合法BST，值唯一，节点值与key在-10^5..10^5，删除指定值并返回可能变化的根。未找到时原树保持；找到时原地改变链接，双孩子情况会用后继值覆盖待删节点值，再移除后继节点。TreeNode供本地导入，字段与评测器一致。

按BST比较沿单一路径找到目标，哨兵dummy.left持有原根，使根节点删除与普通子节点删除共用父链接处理。目标至多一个孩子时，父链接直接指向该孩子。若有两个孩子，找到右子树最左节点作为中序后继；后继没有左孩子，复制其值后，把要物理移除的对象改为后继，再执行至多单孩子的链接替换。后继是严格大于原值的最小值，复制后左子树仍小于它，剩余右子树仍大于它，因此BST性质保持。

查找和后继路径合计O(h)时间，固定指针与一个哨兵，额外空间O(1)，没有递归。返回树只由输入中保留的节点构成，哨兵不进入结果。测试对修改后的完整无环树独立计算中序，核对其等于原有序值删除key的结果、节点身份属于原输入，key缺失时结构完全不变。枚举0..7节点全部BST形状及每个已有key和两侧缺失key，共5333次；另测10000节点左右深链、多种删除位置和值域两端。
