# 517. Super Washing Machines · Python

[原题](https://leetcode.com/problems/super-washing-machines/)。

一行机器每轮可任选若干台，各自最多把一件已有衣服送给相邻一台，所有发送同时发生；可以同时接收两侧衣服，收到的衣服下一轮才能再发。求让每台衣服相等的最少轮数，无法均分返回-1。原题1..10000台，每台0..100000件。输入保持；空列表额外返回0。

总数必须能被N整除，目标q=total/N。令s_i=load_i-q，切口i（机器i与i+1之间）净流f_i为s_0..s_i的前缀和，正值必须向右，负值向左；边界f_-1=f_(N-1)=0。每个切口每轮最多沿所需方向送1件，至少需要abs(f_i)轮。某台净多出s_i>0件时，每轮最多发1件，至少需要s_i轮，不能对负的s_i取绝对值，因为缺衣机器可一轮从两侧收2件。

精确答案T=max_i(abs(f_i),s_i)。从单机看，向左要发max(0,-f_(i-1))，向右要发max(0,f_i)。若两边都向外发，两项之和恰为s_i；只有一个出流时，其量已由切口绝对值限制。因此T同时覆盖所有切口和单机出流负载，下面说明这些下界可以同时达到。

q=0时初始必全0，T=0。q>=1时，两边都出流的机器有q+s_i件，足够把两侧发送安排在T轮内互不重叠的时刻。其余有出流的机器只有一个发送方向，设总出流o，把发送放在最后o轮；它最多有一条入流边，总入流i，初始量a=q+o-i。任意合法入流时刻安排在第t轮前至少已到max(0,i-(T-t+1))件，因为剩余T-t+1轮每轮最多再到1件。到第t轮累计要发max(0,t-(T-o))件；需要发送时，将两式代入可得已有量减累计发送至少q-1>=0。因此每次发送都可用此前已有衣服，不借用同轮新收到的衣服。所有计划发送均可逐轮执行，T轮后按固定净流达到q，证明上界也可行。

一次求和、一次前缀扫描，总时间O(N)，辅助空间O(1)。不实际搬运或保存状态图；flow可为负，answer同时检查局部正盈余和切口绝对流，不能只检查其中一种。

独立参考枚举固定总数的全部非负衣服分配，对每个状态枚举每台不发/左发/右发的合法同步动作，再建立逆边，从均衡状态BFS得到各原状态的最短轮数；不用前缀公式，也不误把正向可达当成对称。长度0..4、衣量0..3的全部341数组对照，空列表为扩展。另测双侧接收与双侧发送的差别、10000台、衣量100000、不可整除和输入保持，未向LeetCode提交。
