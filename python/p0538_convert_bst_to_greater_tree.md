# 538. Convert BST to Greater Tree · Python

[原题](https://leetcode.com/problems/convert-bst-to-greater-tree/)。

给定含0..10000个节点、值互不相同的合法BST，原值在-10000..10000。把每个节点改为其原值加所有严格更大原值的和，原地修改值并返回同一个根对象；空树返回None。节点身份及左右引用保持，使用LeetCode提供的TreeNode，不重新定义生产节点类。

反向中序按右子树、当前节点、左子树访问，顺序恰为原BST值严格递减。在访问当前节点之前，total保存所有已访问节点的原值之和，也就是所有比当前原值大的节点之和。先把当前仍未改写的原值加入total，再赋给当前节点，正好满足定义。未访问节点还保留原值；遍历只根据左右引用前进，不依赖已经改写的值作大小判断。

原值可能为负，所以累加和不保证单调增加，不能因为运行和下降就停止或过滤负值。改写后的树也未必仍满足BST大小顺序；要求是保留结构并正确转换各原节点，后续遍历仍使用原结构。total作为本次方法调用的局部变量，每次调用从0开始，不会把上一个树的累加状态带到下一个树。

显式栈保存尚未访问的祖先，先沿右链入栈，弹出节点处理，再转左子树。每个节点进出一次，时间O(N)，辅助空间O(H)，H为树高，退化链最坏O(N)。不递归，避免10000深链触发递归上限，也不临时改写左右链接。

独立参考先快照全部原值，对每个原节点直接枚举所有原值，求大于等于自身的值之和，不使用有序遍历累加。七个含正负与0的合法值，取0..6个并枚举全部BST形状，共2521棵树对照；每棵树从不可变形状新建节点，避免不同测试树共享可变子树。同一Solution对象连续处理，核对返回根身份和每条原边。另测10000节点正值右链和负值左链，用独立等差数列公式核对全部节点，以及正负端点、空树。未向LeetCode提交。
