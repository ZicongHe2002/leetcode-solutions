# 73. Set Matrix Zeroes · Python

[原题](https://leetcode.com/problems/set-matrix-zeroes/)。

输入为1..200行、1..200列的矩形整数矩阵，每项在32位有符号整数范围。若原矩阵某格为0，则它所在的整行与整列都必须原地变为0，其余位置保留原值。接口返回None，本实现保留各行对象；额外支持空矩阵为空操作。

先分别记录原首行、原首列是否有0，再用首行与首列存放内部格子的行/列标记。标记阶段只扫描内部，避免新写入的标记被当成原始0继续传播。第二次只处理内部，依据两类标记置零；最后根据两个旧布尔标志处理首行、首列。首行和首列各自既是数据又是标记，两个独立旧标志防止互相覆盖语义。每个最终被清零的格子恰好属于原始0对应的行或列。时间O(mn)，额外空间O(1)，没有借额外行列数组存储标记。

独立oracle从原图收集所有0的行列集合，再一次性构造期望矩阵，不使用首行/列标记。五种小形状的1569个-1/0/1矩阵及3x3的512个二值矩阵，共2081个，均逐项核对。边界覆盖200x200矩阵的内部单零、原首行/首列0、32位正负端点、单行/列及空扩展；检查返回None、输入原对象实际修改及各行身份保持。
