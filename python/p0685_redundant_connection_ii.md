# 685. Redundant Connection II · Python

[原题](https://leetcode.com/problems/redundant-connection-ii/)。

原题为n节点有向根树再添加一条原来不存在、两端不同的有向边，n等于边数且3..1000，标签1..n。返回删除后恢复有向根树的那条边；多个答案时取输入顺序最后的边。实现依赖这一生成合同，不处理任意有向图；保持输入及各行，返回一份两元素list。

先记录每个节点的首条入边下标。若有双父节点，把先后两条入边记为earlier/later；添加一条边只可能造成一个双父冲突。暂时跳过later，用按大小合并和路径折半的并查集检测其余边的无向环。

若没有双父冲突，则每个节点入度都是1，唯一有向环对应唯一无向环；必须删环上某条边。按输入顺序加边时，最后一条环边恰好是首次发现两端已连通的边，返回它满足最后答案要求。

若有双父冲突，任何修复都必须删除earlier或later。跳过later后若仍有环，删除later无法修复，所以按输入保证只有earlier能同时消除双父与环，返回earlier。若无环，剩余n-1条无向边构成树，且每点入度至多1，因此恰有一根并能沿有向边到达全部节点，删除later有效；即使earlier也可删，later在输入中更后，应优先返回later。

不能对任意有向图直接用无向并查集代替有向环检测；这里正确性来自原图只比一棵根树多一条边、且已先处理双父冲突。无冲突又无环的分支在输入合同下不会出现。时间O(n alpha(n))摊还，额外空间O(n)，没有递归或输入改写。

独立oracle从输入末尾逐条尝试真实删边，按根树定义检查：恰有一个零入度节点，其余节点入度1，沿有向边从根访问恰n个不同节点。完整枚举3/4节点的所有不同非自环边集合及边顺序，仅保留存在合法删边的合同输入；另核对200个固定种子由真实根树加边构造的图，以及1000节点纯环、双父无环、双父与环并存。oracle不用并查集，返回顺序与输入行身份也核对。未向LeetCode提交。
