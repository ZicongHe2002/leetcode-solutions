# 697. Degree of an Array · Python

[原题](https://leetcode.com/problems/degree-of-an-array/)。

原题nums非空，长度1..50000，每项0..49999。数组的度是某个值出现的最大频次，求具有相同度的最短连续子数组长度。并列最高频的多个值均可作为候选，不能只取第一个达到最高频的值。输入保持，返回int。

对每个不同值记录总频次、首次位置、末次位置。设全数组度为D。任何同度子数组必须包含某个值的D次出现；这个值在原数组频次最多D，所以它必为最高频值，且必须包含其所有出现位置。于是子数组至少覆盖该值的首末闭区间，长度下界为last-first+1。

反过来，对任一最高频值，直接取其首末闭区间就包含该值D次，区间内其他值频次不可能超过原数组度D，所以此区间的度恰为D。每个候选区间都能实现自己的下界，取所有最高频值区间长度的最小值即全局答案。全唯一时D=1，自然返回1。

一次扫描更新记录，再扫描不同值记录求度和最短跨度。平均哈希成本下时间O(n)，空间O(U)，U为不同值数，不修改输入，不按值排序。

独立oracle按长度从短到长枚举全部连续切片，对切片每个不同值直接count计算度，首次找到与整数组度相同者即答案，不复用首末位置记录。0/1/2、长度1..7共3279个数组完整核对；50000长度覆盖全唯一、全重复、并列频次、交替极值、最高频值被低频长段隔开，核对int与输入保持。未向LeetCode提交。
