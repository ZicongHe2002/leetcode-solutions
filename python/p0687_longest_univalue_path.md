# 687. Longest Univalue Path · Python

[原题](https://leetcode.com/problems/longest-univalue-path/)。

原题二叉树包含0..10000节点，值在-1000..1000，深度不超过1000。求所有节点值相同的最长简单路径，长度按边数；路径可以不经过根。空树与单节点均返回0。TreeNode由平台提供，实现保持全部节点值与孩子指针。

显式栈用expanded标志模拟后序遍历：第一次遇到节点先安排它在两个孩子之后结算，第二次弹出时孩子的结果已保存。arms[id(node)]表示从该节点向下、节点值始终相同的最长单臂边数。只有孩子值与当前值相等时，孩子单臂才能加上当前这条边；否则这一侧只能贡献0。

经过当前节点的最长同值路径可接左右两条单臂，长度left+right，用它更新全局best。交给父节点的结果却只能是max(left,right)，因为路径不能在向上接父边时再向下分叉三路。每条简单路径在原根方向都有一个最高节点，结算这个节点时会覆盖它，所以全局最优不会遗漏不经过根的路径。

按节点身份id存储而非按值存储，不会把不同但同值的节点混在一起，也不要求TreeNode实现哈希。每节点常数次进出栈，时间O(n)；保存单臂表O(n)，后序栈O(h)，合计额外空间O(n)。使用迭代实现覆盖深度1000边界，不修改Python递归限制。

独立oracle只保留两端值相同的父子边，构建无向森林，从每节点BFS求所有距离并取最大，不复用后序单臂。枚举0..5节点所有有序树形及-1000/0/1000赋值，共11497棵树。边界覆盖10000节点完整层次树、根值不同时最优在子树、1000节点同值/交替链与两条999节点同值臂；大森林用每连通分量两次BFS独立求直径，避免全点对大规模枚举。核对int与全部节点值/孩子身份保持，未向LeetCode提交。
