# 423. Reconstruct Original Digits from English · Python

[原题](https://leetcode.com/problems/reconstruct-original-digits-from-english/)。

输入由若干英文数字单词zero..nine打乱后的字母组成，恢复原数字并按升序输出。原题保证输入能由这些单词构成，长度至多100000；不能用本方法对任意错误拼写作验证。额外支持空串返回空串。

先统计字符频数。z只出现在zero，w只出现在two，u只出现在four，x只出现在six，g只出现在eight，因此可直接确定0、2、4、6、8的份数。接着h属于three或eight，扣除8得到3；f扣除four得到5；s扣除six得到7。

字母o来自zero/one/two/four，扣掉已知0、2、4后得到1。字母i来自five/six/eight/nine，扣掉5、6、8后得到9。每个等式都按前面已经确定的数量消元，原题可构成保证使所有剩余计数非负。最后按0..9输出重复相应份数的字符，天然满足升序，不需要排序整个结果。

设输入长度为n、输出数字数为D，字符统计与输出时间O(n+D)。字母表和十个计数的空间为O(1)，输出及构造片段占O(D)；不能因为计数表固定就省略join前的输出片段存储。这里没有枚举所有数字排列，也不把缺失字母视为错误，因为Counter对缺失键返回0。

独立测试从已知数字数量生成英文单词多重集，再按字符排序、旋转与反转打乱，期望直接来自原始数字数量，不复用特征字母消元。每个数字出现0/1/2次的全部59049个组合核对。另测100000字符的全部zero、全部eight及十种数字混合，覆盖扣除关系、重复数量、规范升序与空串扩展。
