# 412. Fizz Buzz · Python

[原题](https://leetcode.com/problems/fizz-buzz/)。

返回1..n的字符串列表：3的倍数写Fizz，5的倍数写Buzz，同时整除时按顺序合成FizzBuzz，其余写十进制数字。原题n在1..10000内，输出下标0对应数值1，不能把0也加入结果。

分别检查3和5两个条件，以固定顺序追加对应词。两个条件独立而非互斥，所以15的倍数不会被先遇到的单词分支截断；没有命中条件时才回退到数字字符串。循环始终按数值递增输出，不先分组再打乱顺序。

原题单项文本长度最多8，n次固定工作及有界整数转写给出O(n)时间。返回列表和字符串为O(n)空间，不计输出时仅使用常数个局部变量。不使用生产周期查表或根据已经产生的结果递推下一个值。

独立oracle使用预先写明的15项标签周期，每个新块只把普通数字位置加上块起点，不使用生产的两个整除分支生成期望。逐一核对1..1000所有前缀，另测3/5/15边界、10000项上界、完整列表顺序与字符串类型；最大输入中FizzBuzz共666项。
