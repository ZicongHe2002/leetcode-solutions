# 205. Isomorphic Strings · Python

[原题](https://leetcode.com/problems/isomorphic-strings/)。

原题两字符串等长，长度1..50000，可含任意ASCII字符。判断能否建立字符一一映射，把s逐位变成t；不同源字符不能映射为同一个目标，字符也可映射自身。实现额外支持两个空串为True、长度不同为False，不改动输入。

forward记录源字符唯一目标，backward记录目标字符唯一来源。每对字符出现时都检查两个方向已有关系是否一致，然后登记。只检查forward会错放行两个源字符碰撞到同一目标；双向约束保证前缀映射始终是双射，遍历完就满足全部位置。时间O(n)，额外空间O(字符种类数)，在ASCII原题域内最多常数128种。

独立oracle比较所有位置对：s两位置相等当且仅当t对应两位置相等，不使用双向映射表。枚举a/b/c上长度1..4的全部7380对等长串；边界覆盖50000字符、单向映射碰撞、空格和标点ASCII，以及空串/不等长扩展，核对bool。
