# 669. Trim a Binary Search Tree · Python

[原题](https://leetcode.com/problems/trim-a-binary-search-tree/)。

原题输入为1..10000个节点的合法BST，节点值唯一且在0..10000，0<=low<=high<=10000。保留闭区间内所有原节点，并保持它们之间的相对树结构；裁剪后根可能改变或为空。本实现复用节点，原地改写必要的孩子链接，不承诺原树指针保持；节点值不变，TreeNode由平台提供。

若根小于low，整个左子树和该根都不可能保留，答案只能在右子树；大于high时对称地转向左子树。反复选择后，得到第一个区间内根，或确认整树无可保留节点。

此根的左子树所有值都小于根，因此已经满足high上界。只有左边界可能越过low：沿左链检查，若某个左孩子小于low，就移除该孩子及其更小的左子树，用它的右孩子接替；新接入根仍可能越界，所以使用while连续处理。左孩子一旦合法，其右子树的所有值也合法，只需继续检查它的左孩子。右边界用同样理由处理high，越界右孩子由其左孩子接替。

每次改链只跳过已证实越界的节点及整片越界子树，仍在区间内的节点均保留原祖先关系。BST的有序性保证内部子树无需全扫。每个被访问节点至多进入常数次边界路径，时间最坏O(n)，额外工作空间O(1)，不使用递归或新建节点。

独立参考递归生成不可变结构元组，不修改输入，也不复用生产算法的边界链过程。五个候选值0/1/3/5/8生成全部187棵非空BST，每棵对0..9内55个闭区间重新建树，共10285次比较；核对完整结构、返回节点身份恰为原区间内节点、所有原节点的值保持。另测试10000节点左链/右链、单点区间、保留全树和删空。大链仅用迭代检查，不调用递归参考。
