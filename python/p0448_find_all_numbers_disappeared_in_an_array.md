# 448. Find All Numbers Disappeared in an Array · Python

[原题](https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/)。

长度为n的数组每项都在1..n，返回1..n中没有出现的数，重复次数不限。原题n在1..100000。本实现按升序返回缺失值，并在正常返回时恢复nums的原始值和顺序；内部会暂时修改符号。空列表额外返回空列表，不支持原本含0、负数或越界项的输入。

把数值v映射到下标v-1，用该位置的负号表示v已经出现。当前遍历值可能被前面的标记变负，所以必须先取abs恢复数值；只在目标位置仍为正时取负，重复值不会把标记翻回正数。第一遍结束后，且仅当下标i位置为正，数字i+1没有出现。

第二遍先读取符号，把缺失下标加入答案，再将当前值恢复为绝对值。第一遍从未改变任何数的绝对值，因此这一恢复精确重建原值，不需要保存输入副本；已经读取过的标记恢复也不会影响后面尚未检查的位置。调用结束后，调用者仍看到原列表值和顺序。

两次线性扫描，时间O(n)。除返回的缺失列表外，仅使用固定数量变量，辅助空间O(1)。生产不建立集合、计数数组或排序副本，满足题目的线性时间与常数额外空间要求，同时保留输入的最终内容。

独立参考用集合记录实际出现值，再扫描1..n求补集，不使用符号标记。长度1..6全部50069个合法值域数组核对，并验证调用前后输入相同；空数组单列扩展。另测100000项全重复、全部出现的逆序数组、最大下标与经典缺失5/6，重复调用结果一致。未向LeetCode提交。
