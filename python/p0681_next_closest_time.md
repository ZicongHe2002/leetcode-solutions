# 681. Next Closest Time · Python

[原题](https://leetcode.com/problems/next-closest-time/)。

原题输入是合法24小时制五字符HH:MM，小时0..23、分钟0..59，数字可无限复用。求严格晚于当前时刻、循环到次日后仍最近的可表示时间；不能要求四个数字各只用原次数。输出同样保留两位小时和分钟。

先提取四个数字的集合，并把输入转为从午夜开始的分钟数。按过去1分钟、2分钟直到1440分钟的顺序，用模1440处理跨日，divmod分解时与分。候选按两位补零，再核对所有数字均属于原集合，第一条通过的就是正向等待时间最短者。

只枚举合法分钟数，因此不会构造24点或分钟60。起始偏移从1而非0开始，避免错误地把当前时刻当零等待答案；若没有更早候选，1440分钟时原时刻本身一定可表示，循环必然返回。单一数字的00:00、11:11、22:22可等待整天后返回同一文本。

最多检查1440个固定长度文本，时间与额外空间在一天1440分钟的合同内均为O(1)固定上界。没有外部时区或真实日期依赖。

独立oracle枚举允许数字的四重笛卡尔积，过滤合法时分，再按正向循环等待量（同文本记1440）选最小者，不逐分钟模拟。完整核对一天全部1440个合法输入，还覆盖跨午夜、补零、重复数字和整日等待。测试核对str与五字符格式，不声称向LeetCode提交。
