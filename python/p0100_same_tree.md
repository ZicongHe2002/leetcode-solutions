# LeetCode 100 Same Tree

原题：https://leetcode.com/problems/same-tree/ 。输入是两棵有序二叉树，每棵最多100个节点，节点值在[-10000,10000]。左右孩子的位置参与相等判定，不能只比较值的集合或忽略空位置的遍历序列。假设输入无环且没有共享子节点，TreeNode由judge提供；实现也能读取同一棵树两次。

用显式DFS栈保存对应位置的节点对。两个位置都为空时该对子相同；只有一个为空时结构不同；两个非空节点值不同时返回False。值相等则把右孩子对子、左孩子对子依次入栈，因此左侧先处理。实现不写节点或边，不依赖递归深度。

不变量是：已经展开的对应位置值与空缺一致，栈中每个对子都是尚未核对的相同左右路径。弹出时检查空缺和值，再展开两侧孩子，恰好保留这个关系。每个节点及其空孩子位置最多处理一次；有效有限树保证终止。返回False时有具体位置不一致；栈耗尽仍未返回False，所有位置和值均一致，所以返回True。

例如两棵树都是根1、左孩子2：先比较(1,1)，按右空对子再左(2,2)入栈；比较两个2后加入它们的左右空对子，逐一跳过，最后根的右空对子也跳过。结构相同但对象身份不同仍应为True；值相同但左右位置不同应为False。

时间O(n+m)，其中n、m是两棵树的节点数，发现差异可以提前停止。栈的额外空间O(hp+hq+1)，空树用常数空间；链不会消耗Python调用栈。返回值不包含树的拷贝。

测试使用与遍历算法独立的嵌套元组编码，保留值、左右顺序与None。穷举0..3节点、值为-1或1的51棵树，比较全部2601个有序树对；包含同一对象与分别构造的等值对象。另查左/右缺口互换、单空树、100节点链、末端值变化与值域两端；每次逐原节点核对值和左右引用保持。

B补写两棵“忽略空位置后先序均为[1,2]”但不相同的树。p.val=q.val=1，p.left=a、p.right=None；q.left=None、q.right=b，a.val=b.val=2。pending按栈底到顶展示：

| 弹出对子 | 检查结果 | 后续pending |
| --- | --- | --- |
| (p,q) | 都非空，值都为1 | [(None,b),(a,None)] |
| (a,None) | 左孩子对应位置单边缺失 | 返回False，(None,b)不必继续 |

空位置表明不同的左右路径，必须保留；先序去掉None后不能恢复这个信息。不同对象只要位置和值相同仍应判True，节点身份只用于验证输入未被修改。

对两棵树的所有值统一施加单射f，原值x=y当且仅当f(x)=f(y)，左右路径与空位置保持，故每个对应位置的相等条件都不变，整树判定保持。非单射不具备反向推论，例如常数映射会把单节点−1与单节点1变成相同树。

B使用f(v)=−v，在整个官方[-10000,10000]值域内仍合法且为单射，对2601个小树对与4个边界共2605次check加入性质验证。遇到同一棵树同时作为两个参数时，先按节点身份去重，再根据原快照统一取负，避免把同一节点变换两遍。映射后检查求解器保持全部边和值，并在finally中精确恢复；原嵌套编码oracle和缺口反例保留。两个值域端点也合法互换，没有通过缩窄值域跳过边界。
