# 207. Course Schedule · Python

[原题](https://leetcode.com/problems/course-schedule/)。

课程编号0..numCourses-1，课程数1..2000，先修对至多5000个且互不重复；[a,b]表示完成b才能修a。判断能否修完全部课程。自环应为false，无先修关系应为true；保留输入顺序、数值和嵌套列表对象。额外支持0课程与重复边，原合同不依赖这些扩展。

建边b→a，并统计每门课尚未完成的先修边数。所有入度0课程入队；弹出一门即完成它，对依赖它的课程减去对应入度，只在减至0时入队。循环不变量是indegree恰好统计来自未处理课程的入边数，故队列中的课可安全完成。能处理全部课就给出一个合法顺序；若停下时仍有课，每个剩余顶点至少有一条来自剩余集合的入边，在有限集合中反复追溯必遇环，因而无法修完。队列中每门课至多一次，每条边处理一次，时间O(V+E)，额外空间O(V+E)。

独立oracle枚举课程的全部排列，存在使所有先修关系成立的排列才返回true。穷举1..3门课全部允许自环的有向图（530个），再穷举4门课全部无自环图（4096个），共4626个。边界覆盖自环、重复边扩展、孤立点、方向例子、2000门链及闭环，并构造恰5000条边的2000门有向无环图。检查输入与各先修对对象不变。
