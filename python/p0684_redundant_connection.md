# 684. Redundant Connection · Python

[原题](https://leetcode.com/problems/redundant-connection/)。

输入是3..1000个节点的无向树加一条新边，节点标签为1..n，边数也为n，无重边或自环，每条边端点按较小值在前给出。返回一条删除后成为树的边，若有多条则选择输入中最后出现者，保留该边的端点顺序。输入边数组不改变；不承诺不满足树加一边合同的输入。

并查集维护此前各边形成的连通分量。新边两端原本不连通时按分量大小合并；原本已连通时加入它才闭合唯一环，应返回当前边。唯一环上的其他边必须都已在它之前出现，所以当前边正是输入顺序最后的可删除环边，之后的桥边不改变这一选择。查找使用路径折半，结合按大小合并，时间O(n·alpha(n))摊还，额外空间O(n)。

独立oracle从输入末尾尝试删去各边，对剩余n-1条边用图遍历检查全体连通，不复用并查集。枚举3..5节点的全部连通n边简单图及每个边排列，共27006种有序输入。边界覆盖1000节点整环、闭环边提前出现以及环后仍有桥边的反例，检查选择规则与输入保持。
