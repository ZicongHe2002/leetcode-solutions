# 427. Construct Quad Tree · Python

[原题](https://leetcode.com/problems/construct-quad-tree/)。

把0/1正方形网格表示成四叉树：统一区域为叶节点，否则按左上、右上、左下、右下四个等大区域继续分割。原题边长为2的幂，1..64，网格非空。叶值必须表达区域颜色；非叶节点val不影响语义，本实现统一设False。输入不修改，不为非法边长或空网格额外定义结果。

先构建二维前缀和，每个区域的1数量通过四个前缀值相加减得到。区域内全0或全1时创建一个叶节点，不再分割；混合时递归构造四个有序孩子。子区域不重叠且恰好覆盖当前区域，单格必定统一，因此从叶向根归纳，每个节点都准确表示对应输入区域，并在统一区域尽早压缩。

前缀和构建O(n²)，每个四叉树节点的区域求和O(1)，最坏完整树有O(n²)节点，因此总时间O(n²)。前缀数组O(n²)、递归栈O(log n)，除返回树之外的辅助空间O(n²)；返回树另有最坏O(n²)存储。没有对每个递归区域重新扫描全部像素或复制子矩阵。

独立验证把结果叶节点重新涂回实际像素网格，比较原网格；同时检查叶没有孩子、内部恰有四个孩子、四个同色叶没有被不必要地拆开、节点身份无复用，以及输入保持。边长1/2/4全部65554个二进制网格核对。另测64*64统一色、棋盘格完整树5461节点和左右分色的5节点树，核对四个方向顺序。未向LeetCode提交。
