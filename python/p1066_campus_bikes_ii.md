# 1066. Campus Bikes II · Python

[原题](https://leetcode.com/problems/campus-bikes-ii/)。

这题最小化全部工人到分配车的总距离，不是1057规定的逐对距离贪心。mask表示已用车，已分配工人数就是其1位数，固定下一工人，枚举每辆未用车的当前距离加后续最优，取最小。工人顺序固定不漏分配，车的不同选择穷尽所有一对一方案，缓存消除同集合重复子问题。题目工人数不多于车数且车数小，适合指数位掩码。

B辆车，时间O(B*2^B)，缓存空间O(2^B)，输入坐标保持。
