# 977. Squares of a Sorted Array · Python

[原题](https://leetcode.com/problems/squares-of-a-sorted-array/)要求将非递减数组各元素平方后按非递减顺序返回。`Solution.sortedSquares`返回一个新列表，原输入不变；空输入返回新空列表是接口扩展。平方不会保持原顺序，例如[−4,−1,0,3]直接平方得到[16,1,0,9]。

在剩余有序区间[left,right]中，绝对值最大者一定在某个端点：区间内的每个值位于两个端点之间，其绝对值不会同时大于两端。比较两个端点的绝对值，把较大者的平方写到结果最右空位，再收缩该端点。相等时选右端仍正确，另一个相等平方留给后续位置，不会丢重复值。

循环入口时，结果中write之后的后缀已按顺序包含最大的那些平方值，剩余输入恰好覆盖尚待填入的值。选最大剩余平方写入write保持该不变量；每次消耗一个原元素，n次后结果全部确定。最后一次访问前左右端点仍合法，空输入没有循环访问。时间O(n)，返回结果占O(n)空间，除此之外工作空间O(1)，不调用排序。

测试对−3至3、长度0至6的全部1716个非递减数组，以独立平方后排序作为oracle，检查完整输出、重复值数量、输入不变及新对象；另含±10000边界。实际运行情况见PR，没有LeetCode Accepted。A实现，OpenAI Codex辅助整理。

## B补写：相等绝对值与空间核算

输入`[-5,-2,0,2,5]`，结果初始为5个占位0。下表指针为本轮开始状态，后缀为本轮结束后已经确定的部分。

| left | right | write | 端点值 | 选择 | 确定后缀 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 4 | -5 / 5 | 相等取右端5 | `[25]` |
| 0 | 3 | 3 | -5 / 2 | 左端-5 | `[25,25]` |
| 1 | 3 | 2 | -2 / 2 | 相等取右端2 | `[4,25,25]` |
| 1 | 2 | 1 | -2 / 0 | 左端-2 | `[4,4,25,25]` |
| 2 | 2 | 0 | 0 / 0 | 唯一剩余位置 | `[0,4,4,25,25]` |

每轮满足`right-left+1 = write+1`，所以有待写位置时，至少还有一个合法未取元素；最后一轮left=right，仅消耗一次该位置。相等绝对值时也只移动一个端点，另一个值下轮仍存在，因此不会漏掉重复平方。

端点最大性的直接证明：对区间内任意x，有a<=x<=b，其中a、b是端点。若x>=0，则b>=x>=0，所以|x|<=|b|；若x<0，则a<=x<0，所以|x|<=|a|。因此|x|总不超过两个端点绝对值的最大者。这同时覆盖全负、跨零和全非负区间，不需要先找到零的位置。

空间口径需区分：返回的新列表占n个位置，所以把输出计入总分配空间时是O(n)；除此之外只有left、right、write等常数个状态，额外工作空间是O(1)。这个实现并非原地算法，不能只写“空间O(1)”而隐去返回列表。原题数值范围固定时，每个整数的空间可视为常数。
