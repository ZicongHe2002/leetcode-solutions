# 32. Longest Valid Parentheses · Python

[原题](https://leetcode.com/problems/longest-valid-parentheses/)。

原题s长度0..30000，仅含左右圆括号，求最长连续且完整配对的子串长度，不是可跳过字符的子序列。

栈先放边界下标-1，其上保存尚未匹配的左括号下标。遇左括号入栈；遇右括号先弹出一个左括号或旧边界。如果弹出后空了，说明本次右括号没有可匹配的左括号，把当前下标设为新的边界。否则剩余栈顶是当前连续有效后缀之前的最后未匹配位置，index减栈顶就是这个后缀长度。

每个右括号都检查以它结尾的最长合法后缀，取最大值即覆盖所有可能的最长子串。初始边界让从下标0开始的合法段也按同一公式计算；失配边界阻止把两侧不连续的段拼接。时间O(n)，辅助空间O(n)。

独立oracle从每个起点累积括号余额，直接枚举合法子串，余额变负就终止该起点，不用下标栈。长度0..10的全部2047个括号串核对。边界覆盖30000长度、深嵌套、连续配对、首右末左的边界、全左括号，核对int返回。
