# 649. Dota2 Senate · Python

[原题](https://leetcode.com/problems/dota2-senate/)。

原题有1..10000位议员，字符串仅含R与D。每轮按原始循环顺序跳过已被禁言者；轮到一人可永久禁言另一人，只有一方仍有权时该方获胜。双方都为本党采取最优策略，返回Radiant或Dire，而非简单比较初始人数。

当前议员应禁言下一位将行动的敌方议员。相较禁言更晚的敌方者，这避免了较早敌人先行动的机会；同党敌人除行动位置外等价，把较早的敌人换成较晚的幸存者，只会延迟敌方可行动时间，不会让敌方更早伤害己方。禁言自己党的人也不能改善己方行动机会。因此可用这个最早敌人的贪心策略模拟最优结果。

两个deque分别保存R、D所有尚可行动者的下次行动时间，初始为原下标。取两队首比较，较小者先行动、永久移除另一个队首；自己按原周期在time+n再次行动，放回本党队尾。保留的时间序列按行动顺序递增，加入n自然表示进入下一轮，不把某轮起点误当作原字符串重新满员。任一队空时，另一党就是胜者。

每次循环两个出队、一个入队，活跃总数恰少1，最多n-1轮比较；构造与模拟时间O(n)，额外空间O(n)。下标增大只是时间标签，不执行长度达n²的逐时刻扫描。

独立oracle在小局面中枚举当前议员可禁言的每个敌人，递归求随后局面的最优胜者：只要存在能使本党最终胜的选择就选它，所有选择都输时返回对方；用原始席位bitmask和下一起点缓存，不预设禁言最早者。R/D组成的长度1..8共510个局面全部对照。边界覆盖10000位同党、两长块与交替两党，检查首位优势、基本例RD/RDD和精确输出。未向LeetCode提交。
