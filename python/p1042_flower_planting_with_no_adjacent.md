# 1042. Flower Planting With No Adjacent · Python

[原题](https://leetcode.com/problems/flower-planting-with-no-adjacent/)。

原题花园编号1..n，n为1..10000，无向路径最多20000条、无自环，每个花园最多连接3条路径。每点选择1/2/3/4一种花，使每条边两端不同，任一合法list[int]均可，路径输入不变。

先建双向邻接表，再按编号给花园逐个选未被已着色邻居使用的最小花种。总度数最多3，所以已使用的有效花种最多3种，4个选项一定剩至少一个，不需回溯；未着色邻居的0不是合法候选花种，不造成约束。每条边在第二个端点着色时被遵守，最终全部边两端不同。时间O(n+e)，邻接表与结果总空间O(n+e)。这里只在原题度上限内使用这个贪心保证。

输出验证直接检查长度n、每个整数在1..4及全部边两端不同，不要求某一固定配色。穷举1..5节点所有满足度<=3的843个简单图；另测10000花园的孤点、长链、环和2500个互不相交的K4。K4组有15000条边，已达到10000节点且度不超过3时可有的最大边数，不能同时要求20000边和该度上限。核对输入保持并验证所有边。
