# 707. Design Linked List · Python

[原题](https://leetcode.com/problems/design-linked-list/)。

原题MyLinkedList()，get取零起始下标的值，越界返回-1；addAtIndex在该位置前插入，index==size在尾部追加，index>size忽略；deleteAtIndex只删除有效位置。值与下标均在0..1000，每对象最多2000次方法调用，未使用内置LinkedList。本实现按非负下标合同处理，不扩展负下标语义。

自定义节点保存val/next，哨兵_head不算真实元素。_tail在非空时指最后节点，空时指哨兵；_size保存有效节点数。_before(index)从哨兵走index步得到插入或删除点前驱；_insert_after集中完成链接、尾指针与长度更新。头尾插入都走同一链接操作，尾插无需扫描。

删除时先越过被删节点；若删的是尾节点，将_tail移回前驱。删除唯一节点后前驱就是哨兵，因此后续尾插能接回正确位置；遗漏此更新会让新节点接到已经脱链的旧尾。构造O(1)，头尾插入O(1)，按下标取、插、删最坏O(n)，存储O(n)，单次辅助空间O(1)。

普通列表独立模拟语义，九种头尾/按位插入删除操作枚举长度0..4共7381条序列，每次变更后检查有效位置、邻近越界及1000下标。边界分别覆盖空表反复删后追加、删除唯一节点再尾插；一个对象1000次尾插再1000次get恰2000调用，另一个对象检验1001元素时index=1000的读取、删除、原位再插入与值1000。
