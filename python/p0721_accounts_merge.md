# 721. Accounts Merge · Python

[原题](https://leetcode.com/problems/accounts-merge/)。

原题1..1000个账户，每行长度2..10，首项为1..30个英文字母姓名，余下是长度1..30的合法邮箱。同一人各账户姓名一致，共有邮箱证明需要归并，只有同名不能作为归并依据。返回每组姓名与去重、排序邮箱，组顺序任意，输入保持。

按账户下标建并查集，owner保存每个邮箱首次出现的账户。后续同邮箱把所属账户合并，从而将共享关系的传递闭包归到同一组。全部合并后再遍历owner，每个唯一邮箱恰好归入最终根一次，避免在合并尚未结束时错误分桶。根账户的姓名合法代表该组，因为题目保证同一人姓名一致；相同姓名但无共享邮箱的组仍独立。组内邮箱排序，输出不包含重复邮箱。

设A为账户数、T为邮箱出现总次数、E为唯一邮箱数，时间O(A+T*alpha(A)+E log E)，额外空间O(A+E)，每行切片长度受9个邮箱上限约束。独立参考把同一账户邮箱两两连边，用普通图遍历取邮箱连通分量，不按账户做并查集。枚举3个邮箱的7种非空集合，账户数1..4、同名，共2800组输入；另测1000账户/每行9邮箱的长传递链与互不共享同名账户，含30字母姓名、重复邮箱、不同姓名独立账户。核对邮箱排序唯一性、组集合和输入保持。
