# 760. Find Anagram Mappings · Python

[原题](https://leetcode.com/problems/find-anagram-mappings/)。

原题两个长度相同、1..100的整数数组，元素0..10^5，保证互为anagram，即每个值出现次数相同。返回一个下标映射p，使nums1[i]==nums2[p[i]]，且p使用nums2的每个下标一次。重复值允许任意一一匹配，不要求固定输出顺序，两个输入都保持。

先按值收集nums2所有下标，每次读取nums1一个值，就从该值的下标列表末尾消费一个。不同值的下标组互不相交，同值组每个位置只弹出一次，所以不会重复使用下标；两个数组计数相等保证不会缺少可弹出的下标。最终返回n个不同合法下标，恰为0..n-1的排列，并逐项满足值相等。不能只用value->一个index，否则重复值会错误复用同一位置。

哈希表期望时间O(n)，下标分组与返回结果空间O(n)。只消费本地创建的下标列表，不修改nums2或nums1。原题保证多重集相等；不额外定义无效输入的结果。

验证直接检查输出的完整双射合同：长度、每个下标为int、排序后恰为全部合法下标，以及每个映射位置的值相等，不限定某个有效答案。枚举值0/1/2、长度1..6所有同多重集有序数组对，共40572对；另核对官方例、100个重复值、逆序互异值与10^5值域上界，检查两个输入保持。未向LeetCode提交。
