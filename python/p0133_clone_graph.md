# 133. Clone Graph · Python

[原题](https://leetcode.com/problems/clone-graph/)。

输入是0..100节点的连通无向简单图入口，节点值为互异的1..节点数，邻接表没有自环或重边。返回可达图的深拷贝入口；空入口返回None。每个复制节点及邻接列表均独立于原图，保留各原节点的邻接顺序，原值、原邻接列表对象及其节点身份不变。

clones按原节点对象记录唯一副本；发现邻居时先创建并登记副本，再安排处理该原邻居，所以即使沿环回到已发现节点也不会重复创建或无限循环。处理一个原节点时依次把邻居副本追加到当前副本，所有边都指向副本图。每个可达节点处理一次、每个邻接项复制一次，时间O(V+E)，除返回图外额外空间O(V)，显式栈避免递归。

测试独立枚举无向边集合并按标签核对复制图的完整邻接次序、唯一节点、身份不与原节点重叠；修改副本入口的值和邻接表后仍逐项核对原图保持。枚举1..5节点的全部772个连通带标签图，每个入口都测试，共3807次。边界覆盖100节点链与完全图、单节点和空图；不只比较副本的值序列。
