# 501. Find Mode in Binary Search Tree · Python

[原题](https://leetcode.com/problems/find-mode-in-binary-search-tree/)。

给定允许重复键的二叉搜索树，返回出现次数最多的全部值。原题1..10000个节点，值在-100000..100000；左子树值不大于根，右子树值不小于根，所以中序遍历非递减。采用平台提供的TreeNode(val/left/right)接口，不自行替换节点类型。空树额外返回空列表。

相同值在非递减中序序列中必连续，只需previous与run统计当前等值段，不必保存每个值的频率字典。第一遍只求最大频率maximum；第二遍重新统计，某段run第一次达到maximum时追加该值。最大段长度已经确定，合法树中不会继续超过它，所以每个众数只追加一次，不同频次的候选不会占用临时结果空间。

两遍都使用Morris中序遍历。当前节点无左子树就访问；有左子树时找左子树最右节点predecessor，若其right为空则临时指回current并下行左子树；再次沿该线索返回时，先把right恢复为空，再访问current并转右。查找时用对象身份区分回指，不把相同val误当成同一节点。每次遍历完整跑到current为空，没有找到众数就提前返回的分支。

这些临时线索取代递归/栈，正常返回时两遍均已恢复全部原始左右引用；输入树不会留下结构改动。遍历期间会临时写right，因此调用期间不能把同一树交给并发读者或修改者。第二遍只保存最终输出，不采用单遍“旧最大候选列表后重置”的方式来隐去潜在的大量临时候选。

每遍Morris的边访问总量O(N)，两遍仍为O(N)时间；除返回列表外，只有固定数量节点引用与计数，辅助空间O(1)。返回列表最多包含全部N个不同值，另占O(N)，无递归深度限制。

独立参考按普通图遍历收集全部节点，以Counter统计值频率，不依赖BST中序连续性。节点数0..6的全部二叉形状，结合-1/0/1非递减值多重集，共4854棵树逐项对照；空树为扩展。每次调用前后比较节点身份、val和左右孩子身份，重复节点即报环，验证线索全部恢复。另测10000节点右链/左链、全不同众数、全同值、±100000同频和后出现更高频，未向LeetCode提交。
