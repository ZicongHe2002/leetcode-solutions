# 187. Repeated DNA Sequences · Python

[原题](https://leetcode.com/problems/repeated-dna-sequences/)。

输入仅由A/C/G/T组成的DNA字符串，返回所有出现至少两次的长度10子串，每种子串只返回一次，顺序不限。重叠窗口也计为不同出现位置；短于10个字符时没有完整窗口，返回空列表。

四种字符分别用两位二进制表示。每次将已有编码左移两位、放入当前字符，并保留最低20位，因此完成第10个字符后，编码恰好表示最近10个字符。长度固定为10时，该映射是精确编码，不是有概率碰撞的滚动哈希；以A开头的零位也因固定长度而没有歧义。前9个字符不得提前加入seen，否则会将短前缀与完整窗口混淆。

seen保存出现过的完整窗口编码，第二次或以后遇到相同编码时，将当前长度10子串加入repeated集合。集合保证同一子串出现三次或更多次时只输出一次。重叠窗口仍逐字符更新，不能在命中后跳过10个字符。

设输入长度为n。每次编码只操作20位整数，截取子串长度固定为10，期望时间O(n)。设U=min(n,4^10)，两个集合与返回结果的空间为O(U)，不把所有可能的百万个编码预分配成表。生产代码没有对每个位置重新计算整个窗口的通用字符串哈希。

独立oracle直接用Counter统计全部长度10字符串窗口，不复用位编码。穷举A/C二字符域长度0..12的8191个字符串；另以完整四字符域构造交界窗口，核对重叠重复、恰好10字符、三次以上重复、100000个相同字符和四周期长串，验证输出无重复。
