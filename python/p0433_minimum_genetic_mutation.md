# 433. Minimum Genetic Mutation · Python

[原题](https://leetcode.com/problems/minimum-genetic-mutation/)。

原题基因串固定8位，仅含A/C/G/T，bank长度0..10。每次改变一位，变异后的基因必须出现在bank中；起点默认有效，求最少变异次数，无路返回-1。若起终相同，不需要变异，直接返回0，不能先以终点不在bank为由拒绝。

BFS从起点0次开始，每次枚举8个位置的另外3个碱基，只接受仍在剩余bank集合中的候选。入队即从集合删除，首次到达就是最短次数。起终不同且终点不在bank时必无解；其余搜索失败也返回-1。这里计的是变异边数，不像单词序列题把起点算作1个词。

至多处理bank加起点的11个状态，每状态有8*4个固定长度候选。设B为bank长度，固定8字符下时间O((B+1)*8*4*8)，辅助空间O((B+1)*8)，保持输入bank。

独立oracle以两基因汉明距离1显式连边并运行Floyd，不用逐位替换生成邻居。首3位取A/C、其余5位固定A的8个基因，枚举全部256种bank及64组起终点，共16384次合法查询，包含空bank与起终相同。边界覆盖10条bank、需要8步的全位变异、G/T干扰状态和不可达终点，核对int及输入保持。
