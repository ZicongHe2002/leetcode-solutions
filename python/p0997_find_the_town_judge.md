# 997. Find the Town Judge · Python

[原题](https://leetcode.com/problems/find-the-town-judge/)。

原题n为1..1000、人编号1..n，trust含0..10000个互异且无自信任的有向对。法官不信任任何人，除本人外所有人都信任他；存在则返回编号int，否则-1，输入保持。n=1且无关系时本人满足条件。

score等于被信任人数减去主动信任人数。互异无自环保证被信任人数至多n-1，主动信任人数非负，所以score=n-1恰好同时要求入度n-1、出度0。两个不同人不能同时满足，因为他们各自会要求另一个人信任自己而又都不信任任何人。扫描全部分数即可返回唯一候选。时间O(n+e)，额外空间O(n)；不将缺失关系视作已知信任。

独立参考逐人直接检查没有任何出边、每个其他人的信任对都存在，不用净度公式。穷举1..4人的全部4165个无自信任关系集合；另测1000人、10000关系、法官存在但其他人关系密集、候选有一条出边、环图及空关系，核对int与输入保持。
