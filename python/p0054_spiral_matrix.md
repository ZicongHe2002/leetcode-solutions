# 54. Spiral Matrix · Python

[原题](https://leetcode.com/problems/spiral-matrix/)。

矩形matrix的行列长度各为1..10，值在[-100,100]，按从左上出发的顺时针螺旋顺序返回全部元素。本实现保留输入数值和各行对象，额外支持空矩阵返回[]。

top/bottom/left/right围成尚未输出的矩形。每轮依次输出上边、右边、下边和左边，并立即收缩已完成边。输出上边后top已前移，因此右边不重复右上角；输出右边后right已前移，因此下边不重复右下角。下边和左边各自在执行前检查对应剩余维度，避免最后一行或最后一列被反向重复。每轮结束后，未输出元素仍恰好是更小矩形，所有元素最终访问一次。时间O(mn)，不计返回列表的额外空间O(1)。

独立oracle按右/下/左/上的方向向量逐格行走，用已访问坐标决定转弯，不使用收缩边界。1..10全部100种形状分别用唯一位置值核对完整顺序；另枚举六种小形状的666个二值矩阵，验证重复值也不干扰位置跟踪。固定覆盖1x1、单行、单列、-100/100端点及空扩展；每次检查输入和行对象保持。
