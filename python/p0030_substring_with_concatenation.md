# 30. Substring with Concatenation of All Words · Python

[原题](https://leetcode.com/problems/substring-with-concatenation-of-all-words/)。

words中各单词长度相同且非空，可以重复。返回s中由全部单词各用一次拼接成的子串起点，答案顺序不限。原题s长度1..10000，单词数1..5000，单词长度1..30，字符为小写英文字母。本实现不修改words，额外支持空words返回空列表。

设单词长度为k，按起点除以k的余数分别扫描，每次移动一个单词。窗口只含合法单词，且每种单词的数量不超过目标：读到未知单词就清空窗口；某个单词过量时，持续从左侧移走单词直到它不过量。加入前其他单词未过量，移除不会制造新的过量，因此不变量恢复。

当窗口单词数达到m时，各项计数都不超目标且总数相同，故恰好包含全部单词。记录起点后移去最左单词，继续寻找重叠答案。所有起点恰属于一个余数类，因此不会漏掉跨不同对齐位置的答案，也不会重复返回起点。

每个余数类内左右端点均单向前进，所有余数类合计处理O(n)个完整单词片段。Python切片和首次哈希长度k的字符串需要O(k)，构建目标表也需读取m个词，因此按字符成本计时间O((n+m)k)，而不是把切片视作常数后宣称O(n)。计数表最多保存目标中的不同单词及其切片，除输出外空间O(mk)；答案顺序按余数类产生，不额外排序。

独立oracle直接检查每个字符起点的固定长度片段，并对分词后的多重集合作比较。穷举二字符域长度0..7的s以及长度1..2、数量1..3的单词序列，共24990次查询；另测重复词、未知词重置、重叠、多余数类、10000字符、5000单词与30字符单词边界。核对答案唯一和输入保持，不固定答案顺序。
