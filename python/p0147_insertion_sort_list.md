# 147. Insertion Sort List · Python

[原题](https://leetcode.com/problems/insertion-sort-list/)。

原题为1..5000节点的单链，值-5000..5000，要求用插入排序返回升序链头。假设无环，原地重连原节点、不改val；本文件ListNode供本地导入，字段与评测器一致。

dummy之后始终是一条已经处理节点组成的有序链，current是原输入中的第一个未处理节点。先保存following，防止改写current.next后丢失未处理尾链；再从dummy扫描到第一个值大于current的节点前，把current插到这里。扫描条件使用<=，使新遇到的同值节点放在旧同值节点后，实现稳定排序。插入完成后已处理集合多一个节点，仍有序；未处理部分通过保存的following继续，最终所有原节点恰好出现一次。

第i个节点最多扫描前i-1个，最坏时间O(n^2)，额外空间O(1)，不把此插入实现声称为O(n log n)。独立参考按val对原节点稳定排序，然后逐对象比较链表。枚举值-1/0/1、长度1..7共3279条链；另测5000节点正序/倒序、重复值和原题上下限，核对稳定次序、链尾与所有值不变。
