# 313. Super Ugly Number · Python

[原题](https://leetcode.com/problems/super-ugly-number/)。

超级丑数的全部素因子都来自给定primes，1也算第一个。原题n在1..100000，primes包含1..100个互不相同且升序的素数，每项2..1000，保证第n项不超过32位有符号整数上界。本实现不修改primes，不接受空素数表或n=0。

values保存已经按升序生成的不同合法数，初始首项为1。对每个素数p，将p乘以整个合法数序列形成一条有序候选流；positions指向该流尚未输出的第一项，candidates保存对应乘积。每个大于1的合法数都可除去一个允许素因子得到较小合法数，所以一定出现在某条候选流中，最小候选就是下一项。

一个数可能来自多条流，例如2*3与3*2。选中最小值后，所有等于它的流都必须前进，不能只移动第一条，否则下一轮会重复输出同一个数。前进后的乘积严格变大，其他流的当前值也大于刚输出的值，因此values保持严格递增。先写入本轮value再更新指针，确保所访问的values下标已生成。

设k为素数个数，每轮扫描k个候选，时间O(nk)，保存n项输出前缀及k个指针/乘积，额外空间O(n+k)。Python整数允许安全计算超过最终答案的候选，不发生32位中间溢出。

独立小参考逐个检查1..500的整数，反复除去允许素因子，看余数是否为1；对2/3/5/7/11的全部31个非空素数子集，逐项核对该范围内的合法数排名。最大n测试另用独立埃氏筛记录1..1000000每个整数的最大素因子，取仅含前100个素数的第100000项作为期望，验证原题n上界且期望位于32位范围。另测单素数、n=1与多流重合。未向LeetCode提交。
