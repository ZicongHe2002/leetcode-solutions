# 678. Valid Parenthesis String · Python

[原题](https://leetcode.com/problems/valid-parenthesis-string/)。

原题s长1..100，只含左括号、右括号和星号，星号可替换为一个左括号、一个右括号或空串，判断是否存在合法平衡替换，返回bool。任何前缀都不能出现比左括号更多的右括号。

lowest/highest保存当前前缀所有合法替换可达到的未闭合左括号数区间。左括号两端加1，右括号两端减1，星号可减1/不变/加1，使下界减1、上界加1；负余额不可行，下界截到0。若上界也变负，所有方案都在当前前缀失败，后续字符无法修复。可达余额从初始单点出发，经这些平移和星号扩展仍是连续整数区间，因此结尾lowest=0恰好表示存在余额0的合法方案。时间O(n)，额外空间O(1)。

独立参考逐个星号枚举三种实际文本替换，再直接检查生成文本的括号约束，不复用区间状态。长度1..8全部9840个三字符输入；另测100字符、全星号、恰好闭合、前缀失败和星号不足，核对bool。无在线Accepted记录。
