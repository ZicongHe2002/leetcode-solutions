# 724. Find Pivot Index · Python

[原题](https://leetcode.com/problems/find-pivot-index/)。

原题nums长1..10000，每项在-1000..1000，返回最左的中心下标，使左侧严格之前的和等于右侧严格之后的和。中心元素不计入任一侧，越过数组边界的一侧视为和0；无解返回-1。输入保持，实现额外定义空数组返回-1。

先计算total，left在检查位置index时只含之前元素。右侧和由total-left-当前元素得到，因此相等就立即返回当前下标，顺序扫描保证最左；不相等时才把当前元素加进left。使用总和与之前前缀即可，负数不影响恒等式。两次线性遍历，时间O(n)，额外空间O(1)。

独立oracle逐个下标分别切片sum左侧和右侧，不使用total推导。值-2..2、长度0..6共19531个数组全部核对，空数组为扩展。边界覆盖10000长度、全0多个答案取最左、负数交替无解、中心位于末尾或中部，核对int及输入保持。
