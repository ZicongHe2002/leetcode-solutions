# 1036. Escape a Large Maze · Python

[原题](https://leetcode.com/problems/escape-a-large-maze/)。

网格边长10^6而阻挡至多200，不能遍历整个网格。B个障碍借边界所能围住的格数上界为B(B-1)/2，最大围区可视为角落阶梯形三角区。BFS若找到另一端即可成功；若访问数超过该界，起点不可能被这些障碍困在有限小围区。还要从目标反向作同样检查，排除目标独自被围。两端都在围区外时，少量障碍无法横跨百万网格形成隔断，可绕行连接。

时间和额外空间O(B^2+1)，只存实际障碍与有界搜索格，输入保持。
