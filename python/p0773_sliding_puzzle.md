# 773. Sliding Puzzle · Python

[原题](https://leetcode.com/problems/sliding-puzzle/)。

原题固定2*3棋盘，0..5各出现一次，0为空格；每次只能与上下左右相邻数字交换，目标为[[1,2,3],[4,5,0]]，求最少移动次数，无解返回-1。输入保持。

把棋盘按行展开为不可变六元组，邻接表按下标0..5记录合法空格去向，避免把一行末尾与下一行开头当成水平相邻。队列保存状态、空格下标与已经走过的步数；从初态开始，每次复制六个位置、执行一次真实交换，再把未访问的新状态入队，入队时立即加入seen。

每条边恰是一回合法滑动，代价均为1。FIFO队列按距离非递减展开，因此第一次弹出的目标状态距离最短；初态已是目标时直接得到0。若队列耗尽仍无目标，该连通分量全部探索过，确实无解。状态元组和seen去重避免来回交换形成无限循环，复制状态不改写原棋盘。

状态总数最多6!=720，每个状态至多3个邻居，每次复制/哈希六个位置，时间与空间均可用O(6!*6)作明确上界；棋盘尺寸固定，不把这一实现推广为大规模拼图算法。

独立oracle枚举全部720排列，按二维坐标的曼哈顿相邻关系建立真实空格交换边，然后从目标出发以复制层的全图Bellman-Ford松弛到不动点，不使用生产BFS队列或硬编码邻接表。逐个核对全部720合法棋盘，确认360可达、360不可达、最远最短距离21。另核对官方三例与已完成棋盘，检查int及输入保持。未向LeetCode提交。
