# 921. Minimum Add to Make Parentheses Valid · Python

[原题](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/)。

原题s长1..1000，只含左右括号，一次可在任意位置插一个括号，求最少插入数，返回int。只能插入，不能删除或重排原字符。

opened记录还未配对的原左括号。遇到右括号有opened就配一对，否则必须在该前缀补一个左括号，missing加1。扫描后每个剩余左括号还需要一个右括号。前缀不足左括号与最终未配对左括号分别给出必需插入数，当前做法恰好各补一次，达到下界。时间O(n)，额外空间O(1)。

独立参考按合法括号语法生成所有目标串，寻找包含原串作为子序列的最短目标，长度差就是实际插入数，不使用未配对计数公式。长度1..8全部510个输入；每个输入长度为m时，至多m对括号的目标已足够覆盖任意输入，因此枚举界完整。另测1000字符全开/全闭/已平衡和先闭后开，核对int。
