# 524. Longest Word in Dictionary through Deleting · Python

[原题](https://leetcode.com/problems/longest-word-in-dictionary-through-deleting/)。

从字符串s中只删除字符，找字典内能得到的最长单词；同长度时返回字典序最小者，没有匹配返回空串。原题s长1..1000、字典1..1000条、每词长1..1000，均为小写英文字母。输入字符串与字典列表保持，不要求字典有序。

每个候选是否能通过删除得到，等价于它是s的子序列。扫描s并记录下一个待匹配词字符，匹配就尽早前进；更早匹配会给剩余字符留下至少同样多可用位置，因此若存在嵌入，该贪心扫描就能匹配完整词。只统计数量不足，必须保留字符顺序。

best保存目前所有已确认匹配词中的最优者。候选比s长必不可能；比best短不可能改进；同长且字典序不更小也不能改进，均可跳过。其余候选才扫描s，完全匹配时替换best。每次替换都按“长优先、同长字典序小优先”的同一规则，故字典输入顺序不影响最终结果，重复词也不改变答案。

设N为字典条数、S为源串长度，每词至多完整扫描一次s，时间上界O(N*S)，辅助空间O(1)。best只引用输入中的字符串，没有排序字典、构造切片或保存子序列集合；字符串比较最多扫描候选长度，未跳过的候选长度不超过S，已包含在上界内。

独立参考枚举短s的全部实际下标子序列形成集合，直接筛选字典中属于该集合的词，再按(-长度,文本)选择，不调用双指针嵌入。a/b源串长1..6共126种，6种短词的63个非空子字典，共7938次对照。另测1000字符/1000条字典、所有长候选失败、完整源串匹配、词典序后来改进与原例，核对str及输入保持，未向LeetCode提交。
