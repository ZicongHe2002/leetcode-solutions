# 796. Rotate String · Python

[原题](https://leetcode.com/problems/rotate-string/)。

原题s和goal分别长1..100，仅小写英文字母；允许将s最左字符移到最右任意次，包括0次。两串长度不同立即False，否则所有不同旋转起点在0..n-1。

把s循环重复看作虚拟文本，goal是长度n模式。每个合法起点的n字符窗口均在前2n-1个字符内，因此无需实际生成s+s。先构造goal的KMP前缀函数，记录每个前缀的最长真前后缀；匹配失配时回退prefix[matched-1]，保留仍可能延续的模式前缀。匹配满n立即返回True。

前缀构建与文本扫描中，成功增长次数线性、每次回退严格减少matched，合计时间O(n)，额外空间O(n)用于前缀表。虚拟文本用s[index%n]读取。n至少1由原题保证，不将空串作为已验证原题输入。

独立oracle实际逐次左移并收集n个状态，不复用前缀函数或双串查找。ab长度1..6的126个串组成15876有序对，含长度不等情况；另测100字符、重复前后缀的多次回退、全部100个旋转、同字符与不可达同字符计数排列，核对bool。
