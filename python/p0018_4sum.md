# 18. 4Sum · Python

[原题](https://leetcode.com/problems/4sum/)。

原题nums长1..200，每项及target在-10^9..10^9，返回和为target的所有不同四元组，四个下标必须互异，答案顺序任意。重复数值可以来自不同下标，同一个值四元组只返回一次；不足四项自然返回空列表。实现使用排序副本，输入保持。

枚举first和second，余下区间用left/right双指针。偏小时增left，偏大时减right：排序保证移动另一端只会让当前偏差更大，因此被跳过区域没有等于target的候选。命中后输出当前四值，并跨过两端同值段；同一个first下跳过重复second，不同first也跳过同值，因此不会重复输出。跳过重复锚点只省略相同值前缀，最早锚点拥有后续同值元素可用，不会丢掉合法多重数值组合。

排序O(nlogn)，搜索O(n³)，额外空间O(n)，输出另需O(K)，K是结果数。Python整数容纳四个10^9量级数的中间和。

独立oracle按下标枚举所有四元素组合，直接求和后按四值排序去重，不复用双指针。值-1/0/1、长度1..7共3279个数组，各查五个target共16395次，核对结果无重复、每行有序、int类型和输入保持。最大长度200覆盖全零、极端正负10^9、无解与重复元素；另覆盖中间和超过32位有符号范围但真实无解的情形。
