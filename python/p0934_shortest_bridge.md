# 934. Shortest Bridge · Python

[原题](https://leetcode.com/problems/shortest-bridge/)。

原题grid为2..100的方形0/1矩阵，恰有两个四邻接1岛，求最少把多少个0改为1才能连接两岛。函数只返回数量，输入保持；不承诺岛数不为2的输入。

先用显式栈标记第一个岛的全部格，作为距离0的多源BFS起点；再按四邻接扩展，每进入一个水格距离加1。第一次遇到未属于首岛的1必为第二岛，此时返回当前水格距离，不为踏入第二岛再加1。队列按距离递增处理，所以首次连接用水数最少。seen同时去重岛与扩展水格，时间O(n^2)，辅助空间O(n^2)。

独立oracle对小网格用并查集识别两个岛，直接取两岛任意格的最小曼哈顿距离减1，不复用扩展BFS；零格没有额外障碍，这个距离可由翻转中间格实现。完整枚举2*2与3*3的528个二进制格局，筛选其中恰好两岛的全部合法输入核对。边界覆盖100*100对角两角、两条边岛、外圈岛与中心单格，核对int与输入保持。
