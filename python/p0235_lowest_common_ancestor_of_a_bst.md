# 235. Lowest Common Ancestor of a Binary Search Tree · Python

[原题](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/)。

原题2..100000节点的BST，值-10^9..10^9且互异，p和q是树中两个不同节点，返回最近公共祖先节点本身，节点也可以是自己的祖先。TreeNode本地定义用于测试；算法只读取评测器的val/left/right，不创建替代结果节点，不扩展不存在p/q的输入。

把两目标值排成low/high。从root向下：若当前值大于high，两目标都在左子树，LCA只能继续向左；若小于low，两者都在右子树，继续向右。首次当前值落在闭区间[low,high]时，两目标分居两侧，或当前节点本身就是其中一个目标。继续下降会至少丢掉一个目标，因此当前节点正是最近公共祖先。

值唯一且目标确实存在，按值路由不会把不同节点混为一谈；返回已有current对象而非相等值的新节点。时间O(h)，最坏O(n)，额外空间O(1)，完全迭代且不改树，100000节点深链不受递归上限影响。

独立oracle建立父指针，记录p的全部祖先，再从q向上找首次相交，按对象身份核对。2..7节点全部624种BST、11510个无序目标对，两种参数顺序共23020查询，覆盖目标即祖先和不同子树。另在100000节点左/右深链核对近叶祖先、根与深层目标、值域端点，并验证所有输入值与left/right保持。
