# 1552. Magnetic Force Between Two Balls · Python

[原题](https://leetcode.com/problems/magnetic-force-between-two-balls/)。

原题position有2..100000个互不相同的整数坐标，每项1..10^9，2<=m<=len(position)。选m个位置放球，最大化任意两球距离的最小值。坐标可无序；实现排序副本，保持原数组。

给定目标间距，从最左坐标放第一个球，之后总取满足间距的最早坐标。任何可行放法的第j个球都不可能比贪心对应球更靠左，逐球交换说明贪心不会减少可放数量。间距增大只会使放置更困难，所以二分最后一个可行值；不同整数坐标保证下界1可行，总跨度除以m-1给出上界。使用向上中点避免两个候选时停滞。排序O(n log n)，判定O(n)，总时间O(n log n+n log R)，R为间距搜索范围；排序副本及判定切片使额外空间O(n)。

独立oracle枚举所有m个坐标的组合，对组合中所有坐标对计算绝对距离并最大化最小距离，不复用贪心或二分。坐标1..9的所有大小2..7子集共492组，反序交付输入并测全部合法m，共1722次比较。边界覆盖100000个坐标、放满、仅两球、10^9端点与向上中点，核对int及输入保持。
