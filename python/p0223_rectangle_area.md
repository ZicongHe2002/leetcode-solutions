# 223. Rectangle Area · Python

[原题](https://leetcode.com/problems/rectangle-area/)。

两个边平行于坐标轴的非退化矩形，各由左下角与右上角整数坐标给出，满足x1<x2且y1<y2，求它们覆盖区域的总面积。允许负坐标、相交、包含、相离以及只共享边或角。

分别计算两个矩形的面积，相加后将被重复计算的一次交集面积减去。交集在横轴的候选范围是[max(ax1,bx1),min(ax2,bx2)]，纵轴同理；每个方向的长度都单独与0取最大值。不能先将两个可能为负的长度相乘再截断，因为横纵两方向都分离时，两个负数相乘会产生虚假的正交集面积。

边或角接触时至少一个交集长度为0，不会减去正面积。一个矩形包含另一个时，交集就是较小矩形，公式保留外层面积。只做固定次数整数运算，按原题坐标范围的单位成本模型，时间和额外空间均为O(1)。Python整数直接计算，不经过浮点运算或绝对值修正错误方向的坐标。

独立oracle在小整数坐标上枚举两个矩形覆盖的单位网格单元，取集合并的单元数，不使用交集长度公式。坐标-2..2生成100个合法矩形，穷举全部10000个有序矩形对。另测两个方向同时分离、共享边/角、完全包含、重合及坐标±10000，并验证交换矩形顺序不改变结果。
