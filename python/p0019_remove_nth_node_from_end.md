# 19. Remove Nth Node From End of List · Python

[原题](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)。

输入是1..30个节点的无环单链表，节点值在[0,100]，且1<=n<=节点数。删除倒数第n个节点并返回新头。本实现重连原节点，保留剩余节点的身份、原相对顺序与全部节点值，不构造替代结果链；不承诺非法n或空输入。

在链头前放一个固定大小哨兵，fast和slow从哨兵出发，先让fast前进n条边。两者随后同步移动，保持n条边的距离；当fast位于尾节点时，slow恰好位于待删除节点的前驱。把slow.next跨过一个节点即可删除。删除原头时前驱正好是哨兵，仍使用同一条重连语句，无需独立分支。返回哨兵的next。所有节点最多被常数次访问，时间O(L)，额外空间O(1)。

独立oracle在节点数组中删除下标L-n，期待输出必须按数组剩余顺序指向同一批原节点，最后为None；不会只按值比较，也不会无界遍历可能的错误环。枚举0/1/2上长度1..7的全部3279条链，对每个合法n逐一核对，共21324次。边界覆盖30个相同值的全部合法n、单节点、删除原头/尾与经典例子，逐次检查全部节点值保持。
