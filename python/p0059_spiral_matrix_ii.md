# 59. Spiral Matrix II · Python

[原题](https://leetcode.com/problems/spiral-matrix-ii/)。

原题n在1..20，生成n行n列矩阵，将1..n^2按从左上角开始、先向右的顺时针螺旋填入，返回list[list[int]]。

top/bottom/left/right围住尚未填充的矩形。每轮按上边向右、右边向下、下边向左、左边向上填写，每填一边便收缩该边。填写下边和左边前再检查剩余边界，避免只剩单行或单列时重复填已处理位置；所有位置恰处理一次，计数器连续增加。时间O(n^2)，返回矩阵占O(n^2)，除返回值外额外空间O(1)。各行分别创建，独立调用不共享输出缓冲区。

独立参考从左上角用四方向向量逐格行走，下一格越界或已访问就右转，不用四边界收缩。原题全部20个n逐一核对；另检查1/2/3的具体矩阵、行列表不共享，以及同尺寸两次调用的可变存储互不影响。
