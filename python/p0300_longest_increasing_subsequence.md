# 300. Longest Increasing Subsequence · Python

[原题](https://leetcode.com/problems/longest-increasing-subsequence/)。

输入长度1..2500，整数值在[-10000,10000]，返回严格递增子序列的最大长度。子序列保持原相对顺序但不必连续；相等值不能扩展长度。本实现保留输入，额外支持空数组返回0。

tails[k]表示目前前缀中长度k+1的严格递增子序列所能达到的最小末值；它是每种长度的摘要，整个tails不一定对应同一条原数组子序列。对新值value二分首个不小于它的位置position：前面的末值都更小，故可接出长度position+1；替换成更小或相等末值只会使后续扩展更容易。若position在末端，说明原有最长末值更小，可以增长一项。若在内部，新值不能接在长度position+1的旧最小末值后面，因此本步不会凭空产生更长长度。bisect_left在相等时覆盖，保持“严格”而非“非递减”。时间O(n log n)，额外空间O(n)。

独立oracle枚举全部下标位掩码，直接检验选出序列是否严格递增并取最大长度，不使用tails或二分。穷举四值集合[-1,0,1,2]上长度0..6的全部5461个数组。边界覆盖2500项递增、递减、全相等、-10000/10000交替，以及经典例子与空扩展；每次检查输入保持。
