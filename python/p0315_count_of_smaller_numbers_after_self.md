# 315. Count of Smaller Numbers After Self · Python

[原题](https://leetcode.com/problems/count-of-smaller-numbers-after-self/)。

原题nums长1..100000，值在-10000..10000，返回list[int]，第i项是严格小于nums[i]且下标在其右侧的元素数。重复值不能算更小，输入保持原有次序和内容。

对不同值排序压成一基排名，保留大小与相等关系。逆序处理原下标，Fenwick树仅统计已经经过的右侧元素频次；查询排名不超过rank-1的频次前缀恰为严格更小数量，再把当前值加入频次供更左位置使用。查询不含当前排名，因此重复值不会误计。所有右侧元素按下标逐个加入，重复出现仍各有一次频次。时间O(n log n)，结果、排名与树总空间O(n)，只排序值集合，不原地排序输入。

独立参考对每个下标直接枚举后缀并比较值。长度1..8、值-1/0/1的9840个数组全覆盖；另测100000元素的全相等、极值前后两半，以及5个20000长度合法下降块。下降块参考按当前块剩余较小值及未来完整块的较小值数量计算，未使用超出原题值域的十万互异下降数组，核对列表整数与输入保持。
