# 142. Linked List Cycle II · Python

[原题](https://leetcode.com/problems/linked-list-cycle-ii/)。

输入单链表有0..10000个不同节点对象，值在[-100000,100000]；尾节点可能指向任意已有节点。返回环入口的原节点对象，无环返回None。入口由身份决定，值相同不表示有环。本实现只读next，不修改任何原链接或值，不借助pos参数。

快慢指针从头出发，各走两步和一步；快指针能到None则无环。设入口前缀长度为mu、环长lambda，相遇时慢指针走了t步，快指针多走t步且相遇，所以t是lambda的倍数。相遇点在环中的偏移为(t-mu) mod lambda，从相遇点再走mu步正好到入口。从头另放entry并让entry和slow同步一步前进，entry在mu步到入口时slow也到入口；mu=0时相遇点已是头。时间O(L)，额外空间O(1)。

独立oracle从原头用id集合逐步访问，第一个重复对象即入口。枚举0/1/2上长度0..6的1093个值序列，每个尝试无环以及每个合法入口，共7108个图；同值节点不能伪造相遇。边界覆盖10000节点无环、入口为头/中段/尾节点自环，以及单节点有环/无环。每次保存每个原节点的next与值，调用后逐项核对不变，既检查入口身份也检查只读约定。
