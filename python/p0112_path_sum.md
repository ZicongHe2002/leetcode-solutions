# 112. Path Sum · Python

[原题](https://leetcode.com/problems/path-sum/)询问是否存在从根到叶子的路径，其节点值总和等于targetSum。节点数0..5000，节点值与目标范围−1000..1000，judge提供TreeNode；输入为有效树。本实现不修改树，空树返回False，即使目标为0也没有根到叶路径。

显式栈保存节点与包含该节点的根路径总和，初值为(root,root.val)。弹出时仅在左右孩子都为空的叶子比较目标；内部节点即使当前和命中也不能提前成功。有非空孩子时，将孩子连同total+child.val入栈。负数存在时，当前和大于目标不能作为剪枝条件，因为后续负值可能把它降回目标。

每条栈项总和恰好对应其节点的唯一根路径。初始成立，推进到孩子只增加该孩子值，保持不变量；有效树无共享孩子，所以每个节点至多处理一次。所有叶子均有机会被比较，成功给出合法路径，栈空则全部叶子均不满足。时间O(n)，DFS栈额外空间O(h)，最坏O(n)；Python整数不会因长路径累计而产生固定32位溢出，不依赖递归深度。

测试枚举0..5节点树形及每节点−1/0/1的取值共11497棵，对每棵树以独立递归oracle收集全部叶路径和，并核对−3..3共7个目标，共80479次。另有内部节点命中但非叶、负值反向抵消、空根和5000节点全零长链；逐次检查节点值与左右引用保持。递归oracle只用在至多5节点小树，长链用已知答案，避免测试自身递归失败。运行事实见本地记录与后续PR，未提交LeetCode。A编写，OpenAI Codex辅助。

| --- | --- | --- |
