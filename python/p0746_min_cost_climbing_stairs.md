# 746. Min Cost Climbing Stairs · Python

[原题](https://leetcode.com/problems/min-cost-climbing-stairs/)。

原题cost长度2..1000，每项0..999。可从下标0或1开始，每次支付当前台阶费用后向上走1或2步，目标是下标n的楼顶，而非最后一个有费用的台阶。输入保持，返回最小总费用。

令f[i]为到达位置i、尚未支付该位置费用的最小成本。可以直接从0或1开始，因此f[0]=f[1]=0。到达i的最后一步只能从i-1或i-2出发，需要支付出发台阶费用，所以f[i]=min(f[i-1]+cost[i-1],f[i-2]+cost[i-2])。i=n时不读取cost[n]，楼顶没有额外费用。

按i从2递增，two_back和previous在每次转移前分别是f[i-2]、f[i-1]，计算current后同时滚动。两个可能前驱都已是各自最优子问题，所有合法路线的最后一步也只在两者中选择，归纳得到全局最优。长度2时自然返回两起点费用的较小者，零费用不需要特殊分支。

每个台阶处理一次，时间O(n)，除返回整数外工作空间O(1)，没有改写cost或保存完整DP表。

独立oracle从两个实际起点分别枚举每种1/2步跳跃序列，只记录恰好到达楼顶的路线及沿路真实付费总和，取最小值，不按位置合并状态。0/1/4费用、长度2..8全部9837个数组核对；另核对官方例、1000个999费用的499500闭式答案、全部零及两种交替免费台阶、输入保持。未向LeetCode提交。
