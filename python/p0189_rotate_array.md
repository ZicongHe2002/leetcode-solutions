# 189. Rotate Array · Python

[原题](https://leetcode.com/problems/rotate-array/)。

输入数组长度1..100000，值在32位有符号整数范围，k在[0,100000]，要求原地向右旋转k步，接口返回None。本实现只交换传入列表元素，不改变长度；额外支持空数组为空操作。

先令steps=k mod n，把整圈旋转消去；steps=0直接返回。原数组分成前段A和长度steps的后段B，目标是BA。反转整个数组得到reverse(B)reverse(A)，再分别反转前steps项与其余项就得到BA。每次反转只做对称位置交换，不用切片构造副本；三个反转总计O(n)时间、O(1)额外空间。空数组在取模前处理，避免模0。

独立oracle按位置映射new[(i+k)%n]=old[i]生成期望，不使用三次反转。枚举-1/0/1上长度0..6的全部1093个数组，对每个长度测试k=0..2n+2，共15309次，空输入作为扩展。边界覆盖100000长度的k=100000与k=99999、32位正负端点、k远大于数组长度和经典例子；每次检查返回None及传入列表的实际内容与长度。
