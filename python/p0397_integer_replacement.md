# 397. Integer Replacement · Python

[原题](https://leetcode.com/problems/integer-replacement/)。

把正整数n变为1，偶数只能除以2，奇数可以加1或减1，求最少操作次数。原题n在1..2^31-1。n=1已经完成，返回0；0和负数不属于合同。

偶数的下一步唯一，cost(n)=1+cost(n/2)。大于1的奇数无论加1还是减1，下一项都为偶数且接着必须除2，可把这两步合并为2+min(cost(floor(n/2)),cost(floor(n/2)+1))。两种合法选择全部保留，不依赖只看末位的启发式，也不需要对3另设猜测分支。每个递归参数都严格减小，最终到达1。

使用每次调用内新建的记忆化函数，把相同数值状态只求解一次，不在多次Solution调用之间保留缓存。递归深度O(log n)；第d层可能出现的参数仅为n/2^d的向下或向上取整，至多两个，相同状态通过缓存合并，因此总状态数与时间均为O(log n)，缓存及控制栈空间O(log n)。在原题32位范围内深度很小。

奇数状态直接计算两个减半后的参数，不需要在固定32位类型中暂存n+1；Python整数本身也不会在2^31-1处溢出。答案按真实操作计数，合并奇数跳转时的2不能漏掉。

独立oracle在原始整数图上BFS，偶数边为除2，奇数边为加1/减1，每条边费用1，不合并两步、不使用生产记忆化递推。最优路径只需访问1..n+1：奇数加1后必须减半，此后不会产生更大数。1..4096全部输入对照；另测2的幂前后、3、7及2^31-1上界，最大值答案32。未向LeetCode提交。
