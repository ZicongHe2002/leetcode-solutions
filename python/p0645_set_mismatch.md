# 645. Set Mismatch · Python

[原题](https://leetcode.com/problems/set-mismatch/)。

原题数组原本包含1..n各一次，其中一个值被另一个值替代，故恰有一个重复两次的值与一个缺失值；n为2..10000。必须返回[重复值,缺失值]，顺序不能交换。这个原集合与单次替代前提来自题意；任意多重错误不在合同内。实现不排序、不改写输入。

把nums与1..n全部异或，所有正常值各出现两次抵消，重复值d在合并序列中出现三次、缺失值m出现一次，得到difference=d xor m。d与m不同，故difference非0；取最低置位difference & -difference，这一位在d与m上不同。

只异或该位为1的nums值与期望值，正常值仍成对抵消，只留下d或m中的一个first，另一个为difference xor first。异或分组本身没有标记谁重复，所以最后用first是否存在于原数组判别：缺失值不在，重复值在。这样得到题目要求的顺序；不能仅按数值大小排列两个候选。

两轮分组与一次成员查询共O(n)时间，额外空间O(1)，不需要n项计数表。独立oracle使用Counter统计两次项，并直接扫描1..n找缺失，不使用异或。对n=2..6、每个不同的重复/缺失组合及其全部不同排列，共12164个合法输入完整核对；另有100个固定种子乱序样本。10000项边界检查缺1重复10000与缺10000重复1，核对返回顺序、整数和输入保持。未向LeetCode提交。
