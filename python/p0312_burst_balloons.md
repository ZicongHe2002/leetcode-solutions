# 312. Burst Balloons · Python

[原题](https://leetcode.com/problems/burst-balloons/)。

原题nums长1..300，值0..100，每次戳破一个气球获得当前左右最近未破气球与自身数值的乘积，边界外数值视为1，求全部戳破的最大金币。不能用初始相邻关系计算后续收益；输入保持，0值气球按普通节点处理。

两侧补固定1，best[left][right]表示保留这两个边界时，戳完开区间内部的最大收益。选择区间最后戳的last，此时内部其他气球已消失，最后收益确定为values[left]*values[last]*values[right]；此前左右开区间互不干扰，收益加上best[left][last]和best[last][right]。枚举所有last取最大，按区间宽度递增使两个子问题已经完成。

相邻边界间没有气球，初值0。每个完整戳破顺序都有唯一最后节点，拆分覆盖全部顺序，最大值不会遗漏或重用气球。时间O(n³)，额外空间O(n²)，补边界使用新列表，不修改原数组。

独立oracle直接枚举当前第一个要戳的位置，按剩余列表真实相邻值计算即时收益，然后删除该位置继续，用剩余元组缓存；方向与最后戳区间分解不同。值0/1/2、长度1..6的全部1092个数组逐一核对。最大300长度覆盖全100、全0、零与100交替，固定期望来自先戳零及保留两个边界相邻大值的构造；核对int及输入保持。
