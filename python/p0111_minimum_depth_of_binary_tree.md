# 111. Minimum Depth of Binary Tree · Python

[原题](https://leetcode.com/problems/minimum-depth-of-binary-tree/)要求根到最近叶子的节点数。`Solution.minDepth(root)`只读树，空根返回0。judge提供TreeNode；合同是0..100000个节点、节点值−1000..1000的无环且无共享子节点二叉树。

队列保存节点及其根路径节点数，初始为(root,1)。每次取出最早进入队列的节点，只有左右孩子均为空时才返回深度；否则把存在的孩子连同depth+1追加到队尾。缺一个孩子不是叶子，因此单链的答案是整条链长，不能用`1 + min(空孩子深度, 非空孩子深度)`直接求值。

队首取出顺序的深度不下降：深度d的节点只追加深度d+1的孩子，所有已排队的同层节点都先取出。每个入队节点的depth由父路径加1得到，准确对应根路径节点数。第一个取出的叶子之前已处理完全部更浅节点，因此没有更浅叶子，它的深度就是最小值。有限非空树存在叶子，循环必然返回。

每个节点最多入队、出队一次，最坏时间O(n)，最大队列O(w)，其中w为最大层宽；队列可能暂存相邻两层，但数量不超过两倍最大层宽。长链只需常数队列，算法不依赖Python递归上限。不改任何节点值、左右引用或根身份。

测试用独立递归枚举所有根到叶路径长度后取最小值的小树oracle，空树单独返回0；它没有使用队列或空孩子深度取最小值。枚举0..7节点的全部626种有序树形，逐节点核对值和左右引用。边界包含左右100000节点单链、65535节点完整树、深链旁的浅叶与合法值域端点；大树期望值来自构造，不递归遍历长链。实际执行结果见PR验证记录，未向LeetCode提交。
