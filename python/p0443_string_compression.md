# 443. String Compression · Python

[原题](https://leetcode.com/problems/string-compression/)。

原题chars是1..2000个单字符的可变列表，字符可为大小写英文字母、数字或符号。每个连续游程写为字符加十进制长度，长度1时不写计数。必须改写原列表前缀并返回新长度，返回长度以后的内容不作要求，不能另返压缩字符串。

read定位未处理游程，先扫描end取得完整组界，再向write写字符与计数。count大于1时，用最高十进制divisor从高位逐位写出数字，不建str(count)、数字列表或切片缓冲。每组输出长度不超过该组原长度，所以write不会越过已读完的组界；后续未读字符不会被覆盖。列表实际长度不变，只有返回前缀有意义。

每个输入字符扫描一次，各组数字写入总量不超过输入长，时间O(n)，额外空间O(1)，只有固定数量的索引与计数器。输入中的数字不被当作计数解析；组由原字符相等关系划分。

独立oracle使用groupby分组并构造参考字符串，允许测试额外分配。四种合法字符a/A/1/!、长度1..7共21844个列表逐一核对返回int、原长度保持与有效前缀。另测9/10/99/100/999/1000/2000个同字符、2000字符交替及多组正好2000字符；不检查未定义的尾部。
