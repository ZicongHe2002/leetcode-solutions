# 961. N-Repeated Element in Size 2N Array · Python

[原题](https://leetcode.com/problems/n-repeated-element-in-size-2n-array/)。

数组长2N，恰有一个值出现N次，其余值各一次。维护已见集合，第一次重现的值只能是该唯一重复值，直接返回即可；题目保证N>=2且这种值存在，不用再为它计满全部N次，也不需要修改或排序输入。

期望时间O(n)，额外空间O(n)，n为数组长度。
