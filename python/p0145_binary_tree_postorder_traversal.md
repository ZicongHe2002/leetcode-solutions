# 145. Binary Tree Postorder Traversal · Python

[原题](https://leetcode.com/problems/binary-tree-postorder-traversal/)。

输入二叉树有0..100节点，值在[-100,100]，返回左子树、右子树、根顺序的值列表。重复值保留各次出现，空树返回空列表，原树值和左右链接均不变。

先访问根，压栈顺序为左、右，于是后进先出得到根、右子树、左子树。把整个结果原地反序后，每个根移到其两棵子树之后，原来的右先左后也变成左先右后，正好是后序。各节点入栈出栈一次，最终反序也只线性扫描；时间O(L)，除返回结果外额外空间O(h)，不递归、不改树。

独立oracle用左、右、根的直接递归定义，仅用于最多100节点的测试，不复用结果反序。枚举长度0..8的2056种树形，互异前序标签能发现子树顺序错误；每次检查原节点值及左右身份保持。边界覆盖100层左右交替链、100节点完全树、同值节点、值两端和空树。
