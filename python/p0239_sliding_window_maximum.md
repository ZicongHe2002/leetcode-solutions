# 239. Sliding Window Maximum · Python

[原题](https://leetcode.com/problems/sliding-window-maximum/)。

原题nums长度1..100000，值为-10000..10000，1<=k<=长度。返回每个长度k的连续窗口最大值，共n-k+1项，保持输入。

队列保存候选下标，下标递增、对应值严格递减。处理当前值前，删除已经离开窗口的队首；随后从队尾删除不大于当前值的旧候选，因为新值至少一样大且更晚过期，旧候选不会再成为必要的最大值。相同值保留最新下标，也不丢失任何窗口答案。入队后，窗口已形成时队首就是最大值。

每个下标只入队一次，最多从首端或尾端离开一次，故总时间O(n)。队列至多存当前窗口内的k个下标，辅助空间O(k)，另需O(n-k+1)输出空间。

独立oracle对每个窗口切片直接取max，不使用单调队列。3种值、长度1..7的全部3279个数组，查询各自所有合法k，共21324次核对。边界覆盖100000长度、k为1和全长、重复极值、20001值域周期及递减数组，核对输出元素为int与输入保持。
