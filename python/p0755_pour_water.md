# 755. Pour Water · Python

[原题](https://leetcode.com/problems/pour-water/)。

原题1..100列，初始高度0..99，0..2000滴水在合法下标k落下，两侧边界无限高。每滴优先找向左最终能下降的位置，左边不能下降才试右边，两边都不能才在k上升。不是从左右两边选全局最低点，也不会让水流出数组。返回最终高度，本实现复制输入而不改写原高度。

每滴先从k-1向左扫描，只有当前高度不高于右邻时才能继续，遇到上坡就停止。best初始为k，只有发现严格更低高度才更新；相等平台不覆盖best，因此保留离k最近的同高最低位置。若best仍为k，左边没有可下降位置，再用同样规则从k+1向右扫描。最后只把best高度加1，下一滴再基于更新后的全部水位判断。

单向可达范围必须沿途不升高，扫描恰好覆盖该范围。范围中更低的位置会继续吸引该滴下降，最低平台上靠近k的第一格之后没有更低落差，所以在那里停下。严格更新同时实现平台停止规则，先完成左搜索再考虑右搜索实现题目方向优先。只有一次加1确保每滴完整落在一列，不拆分水量。

设列数N、滴数V，复制需O(N)，每滴最多扫描两侧O(N)，总时间O(N+VN)。返回副本空间O(N)，除结果外工作空间O(1)。输出高度可超过初始上限99；单列99再加2000滴应为2099。V=0时返回等值副本。

独立oracle逐个枚举每个潜在落点，再检查从k到该点的完整路径是否每一步非递增，按最低高度和离k距离选择，优先整组左候选；不用实现中的增量扫描指针。0/1/2初始高度、长度1..6全部1092数组，全部k与V=0..5共36090次查询核对。另核对官方三例、零水量、100列2000滴平坦闭式结果、边界k及单列2099，检查水量守恒、原输入保持和返回整数。未向LeetCode提交。
