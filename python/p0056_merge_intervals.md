# 56. Merge Intervals · Python

[原题](https://leetcode.com/problems/merge-intervals/)。

输入有1..10000个闭区间，每项为[start,end]且0<=start<=end<=10000，顺序任意，可以重复、包含或端点相接。返回合并全部重叠区间后的列表。端点相等算重叠，[1,4]与[4,5]合并；相差1的单点区间仍不相交。本实现返回按起点排序的独立区间行，保持输入外层顺序、数值及行对象；额外支持空输入返回[]。

复制排序得到ordered，按起点扫描，result的最后一项是当前尚可能被延长的连通区间。新起点严格大于末项终点才是分离分量，添加新复制行；否则二者相交，延长末项终点。由于后续起点不小于当前起点，已经完成的更早分量不会被后面的区间重新连接，只有末项需要更新。每个区间都被纳入恰当分量，端点相接与传递重叠自然被合并。时间O(n log n)，额外空间O(n)，包含排序引用列表及输出；没有改写原区间行。

独立oracle把每个输入区间看作顶点，两区间相交就连边，用并查集求连通分量，再各取最小起点/最大终点，不使用排序扫描。端点0..3的10种区间上，长度0..4全部11111个有序列表均核对，覆盖重复和任意排列。边界覆盖10000个相接区间串成[0,10000]、10000个不同单点保持分离、包含链、端点相接及空扩展；检查输入保持与结果行无别名。
