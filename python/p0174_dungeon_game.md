# 174. Dungeon Game · Python

[原题](https://leetcode.com/problems/dungeon-game/)。

原题地牢行列各1..200，每格-1000..1000，只能向右或下，从左上走到右下。生命值在进入任何格并结算其增减后都必须至少为1，求出发前最少正整数生命值，保持输入。

反向定义进入当前格之前所需的最低生命值。可以选择右边或下边的较小需求next，结算当前格之后至少达到next，因此进入前需要next-当前格值，同时不能低于1，得到max(1,next-value)。这与最大化总收益不同，路径中间的负前缀不能靠未来回血弥补已经死亡的状态。

从右下向左上滚动一行，needed[column]更新前是下方需求，needed[column+1]是当前行右方需求。额外右边槽设为无穷大以排除越界路径，右下的虚拟出口需求为1。每格两种后继都已定值，选择较小可达需求即最优。时间O(m*n)，辅助空间O(n)。

独立oracle正向枚举全部右下路径，累计每一步前缀和及最低前缀，再由max(1,1-最低前缀)求该条路径起始生命值，最后对路径取最小，不使用逆向需求递推。行列1..3、值取-2/0/3的全部21297个矩阵核对。边界覆盖200*200全损血/全回血/全零、单格和未来回血不能补救早期死亡的路径，核对int与输入保持。
