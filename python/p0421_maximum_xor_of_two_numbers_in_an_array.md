# 421. Maximum XOR of Two Numbers in an Array · Python

[原题](https://leetcode.com/problems/maximum-xor-of-two-numbers-in-an-array/)。

返回数组中两项异或的最大值，允许取同一个下标，所以单元素结果为0。原题长度1..200000，元素0..2^31-1。本实现不修改输入，额外对空数组返回0；负数不属于合同，因此只需处理位30..0。

按高位到低位决定答案。mask保留当前已考虑的全部高位，把输入截成这些位的前缀集合。尝试令当前答案位为1得到candidate；存在两个前缀p与q使p XOR q=candidate，等价于对某个p，集合包含candidate XOR p。该集合查询检验候选高位是否可由真实输入数对实现。

若当前位能取1就保留，否则取0。更低位的任意组合都不可能补偿一个更高位从1降成0的损失，因此在已固定最优高位后选择最大的可行下一位，逐位归纳得到全局最大异或。所有候选当前位都为1，故candidate非0时不可能仅由同一个前缀与自身误通过；结果0则允许同一下标。

每位构造并查询至多n个前缀，哈希操作平均O(1)，时间O(31n)，额外空间O(n)。没有把最大数值当数组长度，也没有用只比较相邻已排序值的错误替代方案。

独立参考枚举全部下标数对，直接计算真实异或再取最大，不使用位前缀集合。0/1/2/7、长度0..7全部21845个数组对照，空输入是扩展。另测200000项、31位最大值、重复数、单元素及跨最高位得到最大低位掩码的构造，核对输入保持。未向LeetCode提交。
