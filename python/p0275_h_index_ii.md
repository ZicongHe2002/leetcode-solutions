# 275. H-Index II · Python

[原题](https://leetcode.com/problems/h-index-ii/)。

原题1..100000篇引用次数已非递减，值0..1000，求h-index，要求对数时间。实现只支持排序前提，保持输入，返回int。

下标i及右侧有n-i篇论文，最小引用是citations[i]，所以该后缀能支持h=n-i当且仅当citations[i]>=n-i。i增大时左式不降、右式下降，因此条件从False单向变True。二分找第一个满足条件的下标，即最长可行后缀；若没有满足项，收敛到哨兵n并返回0。循环只在left<right时访问mid，mid<n，哨兵不被索引。对数次比较，时间O(log n)，额外空间O(1)，不额外排序或遍历计数。

独立参考直接枚举每个h并逐项检查原定义。值0/1/3/8、长度1..8的494种非递减数组全部核对；另测100000篇、1000引用上界、全0/全1、精确阈值和例题，核对int及输入保持。
