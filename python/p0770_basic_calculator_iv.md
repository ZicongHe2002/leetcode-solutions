# 770. Basic Calculator IV · Python

[原题](https://leetcode.com/problems/basic-calculator-iv/)。

原题有效表达式长1..250，包含非负整数字面量、小写字母变量、二元+/-/*、空格和括号，无除法。evalvars与evalints给出部分变量的整数值。返回化简多项式，各单项式变量字典序排列，先按次数降序、同次数按变量序列字典序；系数包括1与-1也要写出，零项省略，常数无变量后缀。不定义非法表达式或一元运算的解析行为。

把单项式表示为有序变量元组，空元组是常数，多项式为元组到非零整数系数的字典。相加/相减合并同键并删零；相乘枚举两个字典项的笛卡尔积，把拼接变量排序后累加系数，末尾删零。已赋值变量立即成为常数，其余变量成为一次项，因此所有后续运算统一在同一种稀疏表示上完成。

递归下降按sum、product、factor三层实现优先级：sum只消费加减，product只消费乘法，factor消费一个字面量、变量或完整括号表达式。括号内sum遇右括号自然结束，factor越过该闭括号。有效输入保证括号与操作数存在。加减逐个从左结合，乘法在返回sum前完成；每个语法子表达式返回的字典都是该子表达式的精确展开，结构归纳得到最终多项式正确。最后按次数与变量元组排序格式化，不留下零系数项。

解析的字符扫描为O(L)，但展开大小可能远大于输入，不能把整个算法写成O(L)。每次加减访问两侧已有项；一次乘法对P、Q项执行P*Q次乘积，令D为合并变量数与1的较大值，每对合并并排序变量的代价上界为O(D log(D+1))，整次乘法为O(P*Q*D log(D+1))，另计整数系数运算。总时间由所有中间多项式操作和最终排序决定；空间为活动中间项、变量元组及O(L)解析栈。原题L<=250，递归深度由括号和语法层数有界。

独立验证先构造算术AST并直接整数求值，表达式文本由AST生成；输出只按单项式合同解释，不实现另一个文本解析器或多项式展开。100个固定种子AST分别做0/1/2变量赋值，共300种化简。对每个剩余变量遍历0..D全部整数的完整网格，核对输出与AST的值，并限制输出次数不超过AST次数上界D。两个次数有界多项式在每变量D+1个值的完整网格相同，逐变量插值保证恒等，而不是仅随便抽点。另核对官方例、多字母变量、零消去、同类项、负赋值和249字符嵌套。未向LeetCode提交。
