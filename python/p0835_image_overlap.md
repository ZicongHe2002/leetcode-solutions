# 835. Image Overlap · Python

[原题](https://leetcode.com/problems/image-overlap/)。

每对1像素确定唯一一个让前图像素对齐后图像素的平移向量。相同向量出现的次数正好是该平移下重叠的1像素数，因为固定平移不会把两个不同源位置映到同一目标位置。统计所有向量，取最大频次；任一图没有1时返回0。无需旋转或构造每次平移后的完整网格。

边长n，两图1像素数分别A和B，时间O(n^2+AB)，额外空间O(n^2)，因为可行位移向量最多(2n-1)^2种，输入不变。
