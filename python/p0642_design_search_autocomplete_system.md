# 642. Design Search Autocomplete System · Python

[原题](https://leetcode.com/problems/design-search-autocomplete-system/)。

原题接口为AutocompleteSystem(sentences,times)和input(c)。历史句子1..100条、各长1..100、次数1..50；输入为小写字母、空格或#，每个完整输入句子非空、长1..200并以#结束，词间单空格；至多5000次input。普通字符返回匹配当前完整前缀的历史前三句，频率降序，同频按ASCII字典序；#把刚输入的整句次数加1、清空前缀并返回[]。没有LeetCode提交记录。

前缀树每个节点只缓存该前缀下最好的三个句子，计数字典保存整句频率。录入一句时先更新它的频率，再沿所有字符节点更新缓存：旧前三加上这一句至多四个候选，按(-频率,句子)排序后保留前三。正确性依赖频率只增加：其他句子的排名关系没变，旧前三之外的其他句子不会突然进入前三；唯一可能进入的是本次增频的句子。构造时逐条录入，重复历史句子也会累加。

普通input沿当前节点走一步，返回缓存列表的副本，避免调用方修改返回值污染树。没有匹配时节点记为None，此后继续收集文字而不搜索；#仍会将整句加入树，再把游标重置到根。未结束的输入不算历史，不提前增加热度。空格也是树边，Python字符串在本题字符集上的顺序等于所需ASCII顺序。

设整句长度L、树节点数U、历史整句总字符数T。普通input期望均摊O(1)，因为只走一个字典边、复制至多3个字符串引用；#需O(L)路径操作，候选间字符串比较最坏O(L)，故严格最坏时间O(L²)，不把字典序比较视为无成本。初始化O(sum(L_i²))，持久空间O(U+T)，当前前缀O(L)，不复制候选字符串本身。

独立oracle保留完整频率字典，每个输入字符重新筛选所有句子并全排序，不使用树或缓存。100个独立系统各输入50个完整句子，对照每个字符的候选与#复位；另查空格同频顺序、重复录入改变热度、无匹配后保存与返回列表隔离。大边界包含100条100字符历史、含结束符#共200字符的输入句子，并在一个实例恰执行5000次input。原构造数组保持。
