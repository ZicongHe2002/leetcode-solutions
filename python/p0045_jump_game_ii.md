# 45. Jump Game II · Python

[原题](https://leetcode.com/problems/jump-game-ii/)。

输入长1..10000，每项在[0,1000]，从下标0起每次最多向右跳当前值的步数，原题保证可以到达末项；返回最少跳跃次数。单项返回0。本实现保留输入，并把不可达和空输入返回-1明确作为扩展。

把显式BFS层压缩成覆盖区间：layer_end是使用当前jumps次能够到达的最右端，farthest累计本层位置所能到达的下一层最右端。扫描到layer_end才提交一次新跳跃，这时整层的所有候选起点已考察，得到完整下一层，而不是提前选定一个局部跳点。由于可选任意较短步长，每层覆盖仍是连续前缀；下一层首次覆盖终点时，BFS分层保证次数最少。若层末farthest仍等于layer_end，扩展检查判不可达；单项在循环前处理，循环不扫描终点，避免多加一次跳跃。时间O(n)，额外空间O(1)。

独立oracle在显式跳跃图上做BFS并记录每个下标的最短距离。穷举0..3上长度1..7的全部21844个数组：BFS可达项按原题合同比较最少次数，不可达项单列为-1扩展检查，两类都实际覆盖。边界覆盖10000个1得到9999步、10000个1000得到10步、单项、经典2步例子，以及不可达/空扩展；检查输入保持。
