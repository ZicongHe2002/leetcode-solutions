# 1514. Path with Maximum Probability · Python

[原题](https://leetcode.com/problems/path-with-maximum-probability/)。

原题n为2..10000，无向边0..20000条，无自环和重复端点对，succProb与边一一对应且每个概率在0..1，起终点不同。路径成功概率是边概率乘积，求最大值float，无路返回0；原题容许绝对误差1e-5，输入保持。

用负概率优先队列每次取当前最高概率的节点，best保存已知最优值，过期的较小标签跳过。每条边概率不大于1，继续走不会提高当前前缀概率，因此最高标签取出时不可能再经更低前缀得到更优路径，目标取出即可返回。只在严格改善时入堆，概率1环不会反复更新；概率0无需取对数，也不会生成非法数值。删掉环不会降低乘积，最优值总有简单路径见证。时间O((n+e)log n)，额外空间O(n+e)。

独立参考在小图枚举所有简单路径，以Fraction精确乘积比较，再转换float核对，未复用堆贪心。2..4节点各潜在边可不存在或概率0/0.5/1，共4164图，全部不同起终点共49544次查询。另测10000节点长链、20000边、断开与零概率；0.9999长链用50位Decimal幂作参考，测试绝对误差1e-10，比原题要求更严，未声称精确实数运算。
