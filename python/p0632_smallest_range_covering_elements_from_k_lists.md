# 632. Smallest Range Covering Elements from K Lists · Python

[原题](https://leetcode.com/problems/smallest-range-covering-elements-from-k-lists/)。

原题有1..3500个非空列表，每个长1..50，值在-100000..100000且各自非递减。求包含每个列表至少一个数的闭区间，先比较宽度，宽度相同时取左端较小者。列表内重复值及不同列表中的相同值都合法。实现保留全部输入，不为缺少列表或空行另定义结果。

堆始终保存每行一个当前候选，right记录这些候选的最大值，堆顶是最小值left，因此[left,right]覆盖所有行。记录该区间后只前进最小值所在行：若保留这个最小值而改动其他候选，左端无法提高，最大值又只会不降，不会缩小区间。若某最优区间[a,b]存在，在指针第一次越过其中某行的最后一个<=b候选之前，所有行当前候选都<=b；当所有<a的值被前进后，必会记录一个包含在[a,b]内的区间，故不会漏掉最优解。

每次弹出最小值后，用该行后继补回，更新right=max(right,successor)。被移出的只是最小值，其他候选的最大值仍保留；若所有值相等，新后继也不会小于旧值，所以right仍是真实最大值。某行用尽时，在弹出该行最后一个候选之前的完整覆盖已经记录；再继续就无法保留每行一个数，可以结束。候选比较显式使用(宽度,左端)，不会忽略题目的同宽取左规则。

令N为总元素数，堆大小k，时间O(N log(k+1))、额外空间O(k)，初始化heapify为O(k)。log(k+1)也涵盖k=1。独立oracle枚举每行各选一个数的全部笛卡尔积，以真实min/max比较，不使用堆或指针。-2/0/3组成的全部长度1..3非递减小行共19种，列举1..3行共7239个输入；另查200个固定种子样本。最大边界是3500行各50项共175000个交错值，答案由3500个不同整数至少跨度3499独立确定；另覆盖单行、零宽、同宽左端和两极值。没有LeetCode提交记录。
