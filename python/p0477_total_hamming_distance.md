# 477. Total Hamming Distance · Python

[原题](https://leetcode.com/problems/total-hamming-distance/)。

求数组所有无序不同下标对的汉明距离总和，即二进制表示不同的位数之和。原题1..10000个数，每项0..1000000000，答案在32位有符号整数内。相同数值的不同下标仍是一对，只是距离为0；输入保持。空数组额外返回0，负数不在合同内。

交换按数对和按二进制位求和的顺序。某一位有ones个下标为1、size-ones个下标为0，恰好选一个1和一个0的无序对共有ones*(size-ones)，每对在这一位贡献1。不乘2，也不除2，因为选择1所在下标和0所在下标已唯一确定无序对。

只需枚举最大数的bit_length范围。所有数均非负，更高位都为0而没有贡献；最大数为0或空输入时位数为0，答案自然为0。逐位右移并取最低位，不把十进制字符串长度当位数，也不依赖固定32位补码处理负数。

令B为最大数的二进制位数，时间O(N*(B+1))包含求最大值的扫描；原范围B<=30，因此为O(30N)，无需二次数对循环。只保存几个整数和生成器的单次迭代状态，辅助空间O(1)，不生成每一对或完整位矩阵。

独立参考枚举全部i<j下标对，直接用异或结果的bit_count求距离，不使用按位的1/0数量公式。值0/1/2/3/7、长度0..6的全部19531个数组对照，空输入为扩展。另测10000个数、全同最大值、两大等值组、29位边界和经典样例，核对int与输入保持。未向LeetCode提交。
