# 1048. Longest String Chain · Python

[原题](https://leetcode.com/problems/longest-string-chain/)。

原题1..1000个小写字母单词，每词长1..16。前驱必须只插入一个字母且保留原字符顺序才能得到后继，返回最长单词链长度；单词本身就是长1的链。相同长度的单词不能接成链，重复词不应增加长度。实现排序副本，不改变输入列表。

按长度从短到长处理，best[word]表示以该词为末尾的最长链。枚举删除word每个位置后形成的前驱串；若它出现在best中，接上word得到best[predecessor]+1，否则当前词至少单独成链。任何合法前驱都恰好能通过一次删除得到，且长度更短、已经处理，所以枚举完整且依赖已就绪。相同前驱因重复字符被枚举多次只重复取max，不改变结果。

N个词、最长长度L，排序O(NlogN)，每词L次删除，每次切片、拼接及哈希O(L)，总时间O(NlogN+N*L²)。best只引用原输入字符串作键，保存O(N)个条目，排序也是O(N)引用，单个临时前驱O(L)，因此额外空间O(N+L)，不把字符串切片当作常数操作。

独立oracle对每对词用双指针检查原字符是否按序保留且长度差1，建立直接关系，再求最长路径，不复用删除字符串查询。二元字母、长度1..3共14词的全部16383个非空子集逐一核对，输入按逆序排列。最大1000词含长度1..16的完整链及16字母填充词，另检查重复词、无前驱和输入保持。
