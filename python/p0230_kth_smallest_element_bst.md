# 230. Kth Smallest Element in a BST · Python

[原题](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)。

输入是含1..10000节点的二叉搜索树，节点值在[0,10000]且互异，1<=k<=节点数，返回第k小的值。本实现只读取树；不承诺空树、重复键或越界k，不要求多次查询下的动态更新。

搜索树中序顺序严格递增。栈保存尚未返回的祖先，current沿左边不断下降，弹栈时该节点的左子树已全部访问、右子树尚未访问，所以该次弹出正是下一个最小值。每弹出一次把k减一，降到0立即返回，不必物化整段中序数组。每节点最多入栈出栈各一次；设树高h，访问到目标为止的时间O(h+k)，最坏O(L)，额外空间O(h)。显式栈可处理10000层链，不依赖递归深度。

测试按全部有序树形构造搜索树，以全局收集节点值再排序为独立oracle，不复用中序逻辑。枚举长度1..6的196种非空树形和每个合法k，共1078次；每次检查所有原节点值及左右链接保持。边界覆盖10000节点纯左/纯右链的首/中/末排名、0与10000值边界和单节点。
