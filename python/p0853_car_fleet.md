# 853. Car Fleet · Python

[原题](https://leetcode.com/problems/car-fleet/)。

按位置从终点附近向后扫描，已处理车队不会被后车超越。当前车的自由到达时间不大于前方最近车队时间时，会在终点前或恰在终点追上并加入该队；否则它形成新的更慢车队，更新比较时间。时间用(终点距离,速度)分数存储，交叉相乘保持精确，等时不能误建新队。

时间O(n log n)，排序副本空间O(n)，扫描额外空间O(1)，输入保持。
