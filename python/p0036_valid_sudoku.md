# 36. Valid Sudoku · Python

[原题](https://leetcode.com/problems/valid-sudoku/)。

输入固定9x9，字符为'.'或'1'..'9'。只检查已填数字在每行、每列及每个3x3宫内是否重复，返回布尔值；不要求已经填满，也不判断是否能补成一个完整解。本实现保留输入数值和行对象。

分别保存每行、列、宫中已经见过的数字，宫编号为3*(row//3)+column//3。空格直接跳过；数字若已存在于当前任一集合就发现重复并false，否则同步加入三类集合。扫描某格前，集合恰好包含此前已处理格子在对应单位内的已填数字，所以每个重复在后出现的一项被发现，没有重复则全部通过。固定81格，扫描时间和集合存储均为常数；按格子数描述，扫描一次并最多保存3×81个成员。

独立oracle对所有已填格子逐对检查：同值且共享行、列或宫就无效，不使用每单位集合。六个选定位置上的'.'/1/2全部729种赋值覆盖同行、同列、同宫与互不相关位置。另校验一个完整合法棋盘，将其81个位置逐一换成其他8个数字，648次均应无效；空棋盘应有效。还构造一个无重复但无法补全的部分棋盘：首行1..8后留空，下一行末列填9；按本题“只查重复”的范围仍返回true。逐次检查输入与行对象保持。
