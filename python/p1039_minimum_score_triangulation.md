# 1039. Minimum Score Triangulation of Polygon · Python

[原题](https://leetcode.com/problems/minimum-score-triangulation-of-polygon/)。

原题按顺时针给出凸多边形3..50个顶点的数值，每项1..100，三角形得分为三个顶点值之积，求完整三角剖分的最小总分。顶点次序不能任意排序，输入保持。

best[left][right]表示从left沿原顺序到right的连续子多边形最小分数。固定边(left,right)，其相邻三角形第三点middle必在两端之间；该三角形把其余区域分为[left,middle]和[middle,right]两块，三者相加，枚举middle取最小。每个完整剖分在固定边上恰有一个相邻三角形，因此所有剖分均被覆盖。

不足三个顶点的区间没有三角形，表中初值0。按两端下标差递增，所有更短子区间先完成。时间O(n³)，额外空间O(n²)；每个剖分共n-2个三角形，正值输入不需要无穷大空解作为合法答案。

独立oracle在当前凸多边形上枚举要剪掉的耳顶点，计算其与前后邻点形成三角形的费用，再删除该顶点继续，按剩余环序缓存，不复用固定边区间分解。值1/2/3、长度3..6全部1080个多边形逐一核对。最大50顶点全1和全100分别为48和48000000，另核对单三角形端点及int、输入顺序保持。
