# 108. Convert Sorted Array to Binary Search Tree · Python

[原题](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/)。

输入为严格递增整数数组，构造一棵高度平衡的二叉搜索树，合法答案不唯一。原题长度1..10000，值为-10000..10000。本实现不修改输入；额外支持空数组返回None。

用闭区间表示当前子问题，中间元素作为根。中点左侧全部更小，右侧全部更大，分别递归构造左右子树，因此整棵树保持二叉搜索树顺序。居中划分使两个子区间规模至多相差1；每个子问题采用相同划分，生成的左右子树高度也至多相差1。空区间返回None。

用下标划分而不创建数组切片。每个元素恰好生成一个节点，总时间O(n)；除返回的n个树节点外，递归栈为O(log n)，空输入为O(1)。

测试不固定中点选择或树形，而是独立检查输出中序序列恰等于输入、每个节点仅出现一次、所有子树高度差不超过1，并检查输入保持。枚举七值域全部127个非空严格递增数组，另覆盖10000元素、值域端点、单双元素及空输入扩展；测试检查树结构使用迭代遍历。
