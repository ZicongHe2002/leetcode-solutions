# 754. Reach a Number · Python

[原题](https://leetcode.com/problems/reach-a-number/)。

原题target在±10^9内且不为0。第i次移动必须走i单位，可选左右方向，返回到达target的最少移动次数。正负目标镜像对称，所以先取绝对值a。

走m次全部向右的最大距离为S=m(m+1)/2。把某些移动改向左，会让总位置减少它们步长总和的两倍，因此达到a必须满足S>=a且S-a为偶数。这也充分：1..m的子集和可以覆盖0..S的每个整数，选子集和(S-a)/2并翻转方向即可。

子集和连续性可归纳证明：已有1..m-1覆盖0..T，加入m后还覆盖m..m+T；从m=2开始m<=T+1，两区间相接或重叠，配合m=1的基例得到全部0..S。因而算法从m=0递增S，第一次同时满足距离与奇偶条件时就存在实际方向安排；此前每个m至少一项必要条件失败，故返回次数最少。

累计和首次超过a只需O(sqrt(a))步；若奇偶不合，再加至多两步就能修正，因为连续两个新增步长中必有一个奇数。总时间O(sqrt(a))，空间O(1)，不枚举指数级方向组合、不使用浮点开方。

独立oracle逐层生成所有真实左右移动后的坐标集合，保留每个坐标首次出现的层数，而非只用三角和公式。核对±1..±200全部400个目标；大范围再对100个固定种子目标逐个验证返回步数可达的算术证书，并直接枚举所有更小步数排除。另核对官方2/3、三角和前后位置、正负10^9答案44723与符号对称。未向LeetCode提交。
