# 818. Race Car · Python

[原题](https://leetcode.com/problems/race-car/)。

从速度+1连续加速k次到达2^k-1。对正距离t，取k=t.bit_length()；恰好到达就直接返回k。否则一种策略先加速k次越过目标，反向后剩余距离为2^k-1-t，平移并镜像后又是速度+1的同类子问题，成本k+1加子问题。

另一种策略先加速k-1次停在目标前，反向加速j次后再反向，j枚举0..k-2。位置变成2^(k-1)-1-(2^j-1)，剩余距离为t减该位置，成本为k-1次前进、两次反向、j次后退再加子问题。两类取最小；每个残余距离均小于t，记忆化避免重复求解。反向重置速度为正负1，使位置平移后的子问题保持相同起始速度条件。

以t为目标值，每个缓存距离最多枚举O(log t)个折返点，时间上界O(t log t)，缓存及递归总额外空间上界O(t)。不声称该上界是最紧的状态数估计。
