# 808. Soup Servings · Python

[原题](https://leetcode.com/problems/soup-servings/)。

所有取汤量都是25ml的倍数，将每种初始汤量向上除以25后得到q。四种等概率操作对应(4,0)、(3,1)、(2,2)、(1,3)。P(a,b)表示A先空概率加同时空的一半；边界P(0,0)=0.5、P(0,b>0)=1、P(a>0,0)=0。按四个后继取平均，每步A至少减少1，所以按a递增填表有效。n=0直接返回0.5。

q>=500时返回1。误差界推导如下：假想停止后继续独立抽取操作，在t=floor(q/2)时A累计取量均值2.5t、B均值1.5t，单步范围长度均为3。若B先空或同时空发生于T<=t，则B在t的累计量至少q；若T>t，则A在t的累计量小于q。两事件偏离均值的距离均至少q/4-1.25。Hoeffding与并集界给出概率上界2*exp(-(q-5)^2/(36q))，在q=500小于2.5e-6且之后递减，因此返回1的绝对误差小于1e-5。这是解析推导，未作实验验证。

q<500时填O(q^2)大小表，时间与额外空间O(q^2)；大输入分支为常数时间与空间。
