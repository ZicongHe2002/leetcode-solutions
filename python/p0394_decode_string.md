# 394. Decode String · Python

[原题](https://leetcode.com/problems/decode-string/)。

原题输入为合法编码字符串：正整数k后接[encoded]表示重复k次，支持嵌套，字母为小写英文；k至多300，解码长度至多100000。不承担非法语法解析，输入字符串保持，返回解码字符串。

parts保存当前层的字母或已解码片段。数字逐位累加，遇左括号把外层parts和重复次数压栈，并创建新的内层parts；遇右括号把内层拼接后重复，作为一个片段加入恢复的外层。每个左括号都保存其尚未完成的前缀，配对右括号恢复同一帧，故嵌套与相邻重复都保持顺序。设e为编码长度、C为各层拼接及重复构造的字符总量，时间O(e+C)，C可达O(e*D)，D为最终解码长度；额外空间O(e+D)，不把嵌套复制忽略为单次输出。

独立oracle先构造语法树，再分别渲染合法编码和直接展开树，避免复制生产解析过程。324组前后缀、内外重复及双字母树核对。边界覆盖100000输出、300次重复、多位数字、9层嵌套1次与相邻重复，核对str；没有把无效语法计作原题测试。
