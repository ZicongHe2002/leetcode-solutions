# 33. Search in Rotated Sorted Array · Python

[原题](https://leetcode.com/problems/search-in-rotated-sorted-array/)。

长度1..5000，元素互异且来自严格递增数组的一次旋转，值与target均在[-10000,10000]；返回唯一命中下标，缺失返回-1。空数组另扩展为-1，不承诺支持重复值。候选闭区间[left,right]中先检查中点，再识别至少一个有序半区；target落在该有序半区的端点范围内才保留它，否则保留另一半。中点已经确认不相等，更新用middle±1排除它。

旋转数组的连续候选区间至多有一处下降。若左半跨过下降，右半就有序；互异性让端点比较能识别这一关系。循环保持尚未返回的目标位置仍在候选区间，有序半区的值域界限允许排除不可能的整半区。每轮至少减半且严格缩小，空区间说明目标缺失。时间O(log n)，额外空间O(1)，输入保持。

独立oracle逐项线性查找。枚举七值集合所有非空子集及每种左旋，共448个旋转数组，对每个查询-4..4，共4032次。固定例子覆盖单项、两项、值域端点与缺失；5000长度旋转数组查询全部5000个值及两端缺失值，其期望来自构造的下标映射。
