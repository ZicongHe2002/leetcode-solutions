# 328. Odd Even Linked List · Python

[原题](https://leetcode.com/problems/odd-even-linked-list/)。

输入无环单链表有0..10000节点，值在[-1000000,1000000]。按原始一基位置，把奇数位置节点放前、偶数位置节点放后，两组各自保持原相对顺序；不是按节点值的奇偶分组。重用全部原节点，每个恰好一次，值保持，非空输入返回原头，空输入返回None。

odd与even分别是已分离奇数组和偶数组的尾，even_head保存最终要接到奇数组后的偶数组头。有下一个奇节点时，先把它接入odd组，再把它后面的偶节点接入even组，两个尾各前进一步。循环结束时奇数组已完整，偶数组也保持顺序且以None结束，把odd.next接回even_head即可。原偶头必须预先保存，否则分离过程中会失去它。时间O(L)，额外空间O(1)。

独立oracle直接使用原节点数组的偶下标切片加奇下标切片，避免复用分链逻辑。枚举-1/0/1上长度0..8的9841条链，按确切身份比较，不让同值节点掩盖错误。边界覆盖10000和9999节点、10000个同值节点、合法值两端以及空/单/双节点；检查原头、全部原值与最终None。
