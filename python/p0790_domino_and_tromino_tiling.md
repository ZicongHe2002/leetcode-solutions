# 790. Domino and Tromino Tiling · Python

[原题](https://leetcode.com/problems/domino-and-tromino-tiling/)。

原题1<=n<=1000，用可旋转的2格多米诺和L形3格tromino完整覆盖2*n棋盘，不重叠、不越界，返回不同铺法数量模10^9+7。每个L可为2*2去掉任一角的四种方向，不是直线三格砖。

设F(n)是完整棋盘铺法，G(n)是缺右上角一格的铺法；缺右下角与之镜像同数。完整棋盘右边界只能以竖多米诺、两块横多米诺，或一个覆盖最后整列的L结束，所以F(n)=F(n-1)+F(n-2)+2G(n-1)。缺角棋盘的最右单格可由横砖延续一个镜像缺口，或由L直接补齐前面的完整部分，因此G(n)=G(n-1)+F(n-2)。

对相邻完整式相减，再代入G(n-1)-G(n-2)=F(n-3)，得到F(n)=2F(n-1)+F(n-3)，n>=3。结构基例为空宽F(0)=1、F(1)=1、F(2)=2；空宽只用于推导，不是原题合法调用。代码保存最近三个完整值，按元组同时更新，避免先覆盖掉仍需使用的F(n-3)。n=1单列，n=2空循环自然返回2。

加法和乘2与取模相容，每步取模保留最终余数且状态数值有界。时间O(n)，额外空间O(1)，不存所有宽度的数组或缺口状态。

独立小域oracle在实际2*n格上生成所有合法多米诺/L位置，选择首个空格并枚举覆盖它且不重叠的砖，计算精确覆盖数，核对1..10。大域oracle另外枚举2*2窗口中首列填充的全部砖组合，建立4种入列/出列占用掩码转移，逐列得到精确大整数计数，最后才取模，核对11..1000所有宽度；不使用生产三阶标量递推。两阶段合计覆盖原题全部1000个合法n，未向LeetCode提交。
