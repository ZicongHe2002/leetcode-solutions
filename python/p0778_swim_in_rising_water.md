# 778. Swim in Rising Water · Python

[原题](https://leetcode.com/problems/swim-in-rising-water/)。

原题n为1..50，n乘n网格恰由0..n^2-1的互异高度组成。水位t允许经过高度<=t的格子，从左上四向游到右下，返回最早时间int，输入不变。路径必须包括起终点高度，单格合法输入仅为[[0]]。

路径需要的水位等于途经格子的最高高度，因此沿边扩展代价为max(旧水位,新格高度)，起点标签必须设为grid[0][0]。这个瓶颈代价单调不降，按最小标签出堆，跳过过期项，在目标出堆时得到最小可行水位。n^2严格高于全部原高度，可作未知标签哨兵。网格总连通，最高水位必能到达目标。若N=n^2，时间O(N log N)，额外空间O(N)。这里比较的是格子高度，未把相邻高度差当作水位。

独立参考二分水位，每次BFS只访问不超过水位的格子，利用可达性随水位单调增加，不复用瓶颈堆。穷举1乘1与2乘2的全部25个合法排列，另对3乘3做300次确定性洗牌；50乘50测试行序、反序、蛇形和确定性洗牌，每个输入都验证互异完整高度排列。比较int、起终点约束与输入保持，不把重复高度网格冒充原题测试。
