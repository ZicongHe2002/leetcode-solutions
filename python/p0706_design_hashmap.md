# 706. Design HashMap · Python

[原题](https://leetcode.com/problems/design-hashmap/)。

原题MyHashMap()，键和值均在0..1000000，put插入或覆盖值，get不存在时返回-1，remove不存在时不改变状态；每对象最多10000次外部调用。生产实现不用内置哈希表库，仅使用列表。

1009个独立列表桶按key%1009定位，桶中保存[key,value]。put逐项比较完整键，找到时只覆盖值并立即返回；未找到再追加，因此每键只有一个记录。remove同样按完整键匹配；get用键是否找到区分缺失，合法值0不会被误判为空。碰撞键共享桶但保留独立记录，覆盖其中一键不会改变邻居。

构造O(1009)。单次操作O(1+桶长度)，分布均衡时O(1+S/1009)，最坏O(S)，S为当前映射数；固定桶数不能保证任意输入常数时间。空间O(1009+S)，列表删除移动也计入桶长度。

独立oracle用普通二元组列表表达键值关系。对键0/1、值0/1的put，加get和remove，共八种操作，枚举长度1..4的4680条序列，每步查询两键及1000000。另用992个同余键和边界键共993键，混合覆盖、删除、重插入与缺失查询，最后逐键查询，单对象恰10000次调用；覆盖值含0和1000000，核对None/int类型。
