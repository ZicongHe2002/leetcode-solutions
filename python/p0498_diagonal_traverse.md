# 498. Diagonal Traverse · Python

[原题](https://leetcode.com/problems/diagonal-traverse/)。

原题mat行列数分别1..10000，总元素不超过10000，元素在-100000..100000，返回从左上开始、逐条交替向右上/左下的对角遍历list[int]。矩阵可以非方形，输入保持。

同一对角线的坐标满足row+column=diagonal，依次处理和从0到rows+columns-2即可覆盖全部格子。偶数对角线从最靠下的有效行开始向右上走，奇数对角线从最靠右的有效列开始向左下走；min限定起点，循环边界使每步坐标有效。每个格子属于唯一坐标和且在本对角线上走一次。时间O(rows*columns)，返回列表占O(rows*columns)，除输出外额外空间O(1)。

独立参考列出所有坐标，按坐标和排序，再按偶数线行号递减/奇数线行号递增作为次关键字，不使用逐线步进。1..3行列的全部682个二值矩阵，以及1..6行列的坐标唯一矩阵逐一核对；另测10000总元素的长单行/长单列/方形和细长矩形、值域端点及原题样例，检查list与输入保持。
