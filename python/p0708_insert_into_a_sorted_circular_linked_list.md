# 708. Insert into a Sorted Circular Linked List · Python

[原题](https://leetcode.com/problems/insert-into-a-sorted-circular-linked-list/)。

原题为0..50000节点的非降序循环单链表，给定head可指向任意节点，并不保证最小值；节点值与insertVal在-10^6..10^6。可插到任意合法位置，空环创建单节点自环，非空必须返回原head对象。Node类由平台提供。本实现新建恰一个节点，按题意改写一个原节点的next，并保持所有原节点、值和循环相对顺序；不承诺原next全部不变。

扫描每条边current→following。若是普通非降边且current.val<=insertVal<=following.val，就能在二者之间插入。若current.val>following.val，这条边是最大值回到最小值的断点；新值大于等于最大端或小于等于最小端时可插这里。比较使用非严格边界以允许重复值。

若绕一圈仍未匹配，所有节点只能同值且新值在其外侧，此时任意边插入均有效。单节点也走这一规则；同值新值可直接命中普通边。找到位置后先连接新节点到原后继，再把current.next指向新节点，保留完整旧环的顺序，不丢失后半段。返回原head，与插入位置无关。

非全同的有序环必有一个下降断点，任意新值要么落在某段普通值区间，要么在全局最小/最大之外，因此上述扫描总能找到合法位置。最多绕原环一次，时间O(n)，除新节点外额外空间O(1)，不用排序或复制原环。

测试直接核对输出合同，不限定唯一插入位置：一个长度n+1的闭合简单环，原head保持，全部旧节点恰一次、旧值保持、仅一个新节点且值正确，删去新节点后旧节点顺序与原环一致，并且全环至多一个严格下降。-1/0/1长度0..6的全部非降序多重集、每种head旋转与插入-2..2共1895次查询，每次重新建环。另覆盖50000节点全同值、任意head、重复插值和±10^6极值；确认恰一个旧next改写。未向LeetCode提交。
