# 644. Maximum Average Subarray II · Python

[原题](https://leetcode.com/problems/maximum-average-subarray-ii/)。

原题1<=k<=n<=10000，元素为-10000..10000整数，求长度至少k的连续区间最大平均值，绝对误差要求小于10^-5。与长度恰k不同，区间可以更长；例如[5,-10,5]、k=2时全段平均值0，优于两个长度2区间的-2.5。实现保留输入。

给定候选平均值t，把每项视为nums[i]-t，存在平均值至少t的区间，等价于存在长度至少k且变换后和非负的区间。设原数组整数前缀和为S[j]，变换前缀为S[j]-j*t；在右端end，只可减去下标0..end-k的前缀。维护这些前缀的最小值，若当前变换前缀不小于它，就找到可行区间。

total保存S[end]，delayed_total在end>k时加入nums[end-k-1]，正好更新到S[end-k]，再让该前缀参与minimum_prefix。end=k时仅下标0合法，初值0正合适；不能提前加入较新的前缀，否则会纳入长度不足k的区间。整数前缀精确累加，每次单独算S[j]-j*t，避免逐项累加变换值所带来的累计误差。

可行性随t增加只会从真变假，答案位于min(nums)..max(nums)。二分60轮，真则提高lower、假则降低upper，返回lower。实数模型下初始区间宽至多20000，60次折半足够；浮点比较另有舍入误差，测试以原题10^-5容差核对，不把二分宽度冒充零数值误差。每轮O(n)，共O(60n)时间，额外空间O(1)，没有保存n项前缀数组。

独立oracle枚举全部起终点，以Fraction精确求长度至少k区间的最大平均值，不二分、不用前缀最小值。-2/0/3组成的长度1..6共1092个数组、全部k共6015次查询，加200个固定种子样本。最大边界覆盖10000长度、k=1/k=n、交替极值下k=9999、接近0的有理数答案及最优长度严格大于k。未向LeetCode提交。
