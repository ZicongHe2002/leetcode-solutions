# 844. Backspace String Compare · Python

[原题](https://leetcode.com/problems/backspace-string-compare/)。

原题两个字符串长度分别为1..200，仅含小写字母和#；#删除当前编辑器末尾一个字符，对空文本退格仍为空。返回两个编辑结果是否相等的bool。

从右向左扫描，skipped记录当前遇到的退格还要跳过多少个普通字符。每个#增加需求，普通字符先消耗需求，需求为0时才是下一个可见字符。分别找到两串最右侧未比较的可见字符，若不同则结果不同；若某侧耗尽，只有另一侧也耗尽才相同。逆向跳过的字母恰被其右侧退格删除，超出开头的需求等价于对空文本退格。所有字符至多扫描一次，时间O(len(s)+len(t))，额外空间O(1)，满足原题进阶要求，不实际构造编辑结果。

独立参考从左到右逐字构造编辑器文本，用字符串切片实际退格。长度1..4、字母a/b及#组成的120个串两两比较，共14400对；另测200字符、连续空退格、删除到底、不同尾字母与大量退格后保留的字符，核对bool。
