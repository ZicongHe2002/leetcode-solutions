# 1351. Count Negative Numbers in a Sorted Matrix · Python

[原题](https://leetcode.com/problems/count-negative-numbers-in-a-sorted-matrix/)。

原题grid为非空矩形，行列各1..100，元素在-100..100，行与列均为非递增顺序，求严格负数个数。0不能计入；实现不定义空矩阵或锯齿输入，返回int，不修改输入。

从左下角看当前尚未处理的行。该值为负时，右侧整段因非递增而全负，一次加上width-column并上移；这一行左侧此前已被排除，整行统计完成。该值非负时，上方同列值更大或相等，当前列在剩余行中均非负，因此右移。已计数行和仍待判定矩形互不重叠，每个负数恰好属于一次加入的后缀。每步上移或右移，时间O(m+n)，额外空间O(1)。

独立参考完整扫描并统计value<0。枚举行列各1..3、值-1/0/1、行列非递增的330个矩阵。另测100×100全负/全0、每项为100-row-column的矩阵，以及单行单列和值域两端；所有期望都由扫描得到，额外核对混合大矩阵恰有4851个负数、int及输入保持。
