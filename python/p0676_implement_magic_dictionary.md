# 676. Implement Magic Dictionary · Python

[原题](https://leetcode.com/problems/implement-magic-dictionary/)。

原题字典包含1..100个不同的小写单词，每词长度1..100；buildDict只在所有search之前调用一次，search最多100次，查询长度1..100。必须恰好替换一个字符后等于某个字典词，不能插入、删除或不修改。类名和接口为MagicDictionary/buildDict/search，不是Solution。

替换不改变长度，因此先按词长分组。查询仅扫描同长组，对齐字符统计不同位置；超过一个即可停止该词比较。恰好一个不同位置时，这一位置的替换能得到该字典词，返回True；零个不同位置不能满足恰改一个，但仍继续看其他词，因为字典中可能存在另一条相差一位的词。全部候选不满足才返回False。

词长分组让不等长词不参与zip，避免只检查公共前缀误判。没有用通配符字符代替真实小写输入，也不依赖字典词顺序。字典列表只读，组内保存不可变字符串引用。

设N为字典词数、L为查询长度、N_L为等长词数。buildDict平均哈希操作下O(N)时间与O(N)额外引用空间，不复制字符串内容；若连同被引用词文本计入存储，上界O(总字符数)。search时间O(N_L*L)，额外工作空间O(1)。原题最多100词、每词100字符，不需要复杂索引也能覆盖合同。

独立oracle枚举查询每个位置的25种实际不同小写字符替换，检查替换结果是否属于原字典集合，不复用差异计数。由a/b构成、长度1..3的14词中选择1..3个，共469个字典；每个对a/b/c、长度1..3的39个查询核对，共18291次查询，每实例39次不超过合同。另核对100个长度100的不同词、100次查询、仅原词相等但不能不改的情形、另一词相差一位和长度不等，并核对输入列表保持。未向LeetCode提交。
