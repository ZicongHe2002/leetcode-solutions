# 101. Symmetric Tree · Python

[原题](https://leetcode.com/problems/symmetric-tree/)要求判断二叉树是否关于根镜像对称；节点值范围−100..100、节点数1..1000，judge提供TreeNode。本实现不改变原节点或边，空根作为扩展返回True。输入是没有环或共享子节点的有效树。

队列每项保存应互为镜像的两个节点。两者都空时该对成立；恰有一个空时结构不对应，立即False；都非空时值必须相等，再把“左的左与右的右”和“左的右与右的左”入队。只比较每层非空节点值的回文不够：忽略空位置会把同值但左右缺口不同的树判成对称。

队列不变量是尚未完成的镜像对应关系。一个非空对子在值相等后拆成两个交叉子对子，恰好覆盖镜像定义的两个必要且充分条件，不会把两个同方向孩子错误配对。所有对子通过才返回True；值不等或单边缺失给出一个确定反例。访问一次后不再重访，时间O(n)，队列空间O(w)，w为最大层宽，最坏O(n)；没有递归深度依赖。

测试使用小树“原结构序列化等于交换左右后的序列化”的独立oracle，序列包含None位置；0..6节点全部树形、每节点−1或1的取值共10067棵树。另构造999节点镜像长臂，验证初始对称及改单侧末端值后不对称；1000节点单链验证单边缺失。每次对照原节点的值和左右引用，核对输入保持。初稿运行结果记录在本地与PR，不声称LeetCode Accepted。A编写，OpenAI Codex辅助。

B补写“同层非空值回文但树不对称”的完整反例。r的左右孩子a、b都为2；a.left=c、b.left=d，c、d都为3；a.right和b.right均为空。第三层非空值是[3,3]，但是两个3都在各自父亲的左侧，不是镜像位置。

| 取出的对子 | 判定 | 剩余/新增队列 |
| --- | --- | --- |
| (a,b) | 都存在且值均为2 | [(c,None),(None,d)] |
| (c,None) | 恰有一侧为空，结构不对称 | 立即返回False，(None,d)无需再处理 |

若把a.left与b.left同向配对，或序列化时删去None位置，就会误判这个反例。节点值相等不代表缺口结构相同。

设M表示交换所有节点左右边，M(M(T))精确恢复T。对称定义为T=M(T)，对等式两侧施加M得到M(T)=T，因此整体镜像不改变对称与否。B在10067棵小树与3个深度/值边界共10070次check中加入此性质：按原引用快照逐节点交换，使用原oracle或固定期望再次判断，并检查镜像后的树没有被求解器改动；finally按原快照恢复全部边和值。镜像变换不递归，可用于1000节点链，且保留所有空位置。原结构序列化oracle和输入保持检查均保留。
