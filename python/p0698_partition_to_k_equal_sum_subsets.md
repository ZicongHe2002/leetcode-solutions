# 698. Partition to K Equal Sum Subsets · Python

[原题](https://leetcode.com/problems/partition-to-k-equal-sum-subsets/)。

原题1<=k<=n<=16，每项1..10000，每个值出现1..4次。要把全部元素按位置划分成k个非空子集，使各组和相等；不是连续子数组划分，重复值的不同下标也都必须使用。返回bool，输入保持。实现依赖正整数合同，不处理目标和为0的推广。

总和若不能整除k则失败；每组目标target为总和/k，若有单项大于target也失败。其他情况target>0。位掩码mask表示已使用的原数组下标，remainders[mask]为一种合法按组顺序装填后当前未满组的和，-1表示不可达，0表示恰在组边界。

从可达状态加入任意未用下标，只有当前组加上该值不超过target才转移；若恰好满组，以模target把余量重置为0，否则保留新部分和。添加一位使新mask严格变大，因此按数值从小到大遍历能处理所有转移。

同一mask不需要保存多种余量：已用元素总和固定，除以target的余数固定，所以不同可行放置路径的余量完全相同。每个转移对应一个真实正数元素加入某组，不会超额；所有元素用完且余量0时，完成组数必为总和/target=k，正目标与正元素保证每组非空。反过来，把任意合法划分的组依次排开，逐个加入组内元素，正数保证中途不超target，本DP必枚举到它，所以判定充分且必要。

最多2**n个状态，每状态检查n个元素，时间O(n*2**n)，额外空间O(2**n)，不递归也不修改或排序输入。k=1与k=n都沿同一合同处理。

独立oracle直接生成元素的规范集合划分：每个元素加入某个已建组或创建新组，末尾检查恰k个非空组且各组实际求和相等；不使用位掩码余量、整除预检或目标容量剪枝。值1/2/3、长度1..6并筛除频次超过4的1050个数组，每个合法k共5766次查询，另核对100个固定种子样本。16元素边界覆盖四种值各四份、10000最大值、可整除但奇目标无法由偶数构成，以及k=1/16，所有测试遵守频次上限。未向LeetCode提交。
