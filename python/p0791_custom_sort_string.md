# 791. Custom Sort String · Python

[原题](https://leetcode.com/problems/custom-sort-string/)。

原题order长度1..26、字符互异，s长度1..200，都只含小写英文字母。返回s的任意排列，使order中较前的字符的所有出现都排在较后字符之前；不在order里的字符没有额外相对顺序要求，不需要强行按字母表排序。

先统计s每个字符出现次数，按order依次输出该字符的完整重复块，并从计数表弹出这一项。order中没出现于s的字符贡献空串，不凭空添加。最后输出计数表剩下的未列出字符块，再连接成字符串；弹出已输出项避免重复输出。

每个原字符的次数恰好在被列出的阶段或剩余阶段消耗一次，所以输出与s的多重集完全相同。列出字符的整块按order顺序放置，保证任意一对被规定先后的字符都满足全部出现的先后关系。未列出字符放在末尾是题目允许的一种选择，其他合法位置也同样应被测试接受。

设N=len(s)、M=len(order)，期望时间O(N+M)，计数O(U)，分块字符串与最终输出合计O(N+M)空间，U<=26。没有对s执行比较排序，不依赖未列出字符的特殊排名。

独立验证直接检查完整结果合同：排序后的全部字符相等以证明是排列，再对order的每对先后字符检查所有出现位置的最大/最小边界，不构造另一个计数排序结果。a/b/c的全部15个非空互异order，a/b/c/d上长度1..5全部1364个s，共20460查询；d专门覆盖不在order中的字符。另核对官方例、26字符order、200字符s、缺失字符与重复字符。不要求一个固定的无关字符顺序，未向LeetCode提交。
