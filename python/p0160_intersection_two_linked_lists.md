# 160. Intersection of Two Linked Lists · Python

[原题](https://leetcode.com/problems/intersection-of-two-linked-lists/)。

两条无环单链表各有1..30000个节点，值在[1,100000]，可能共享一段真实节点后缀；返回第一个共享节点对象，无共享返回None。同值但不同对象不是交点，且调用后两条链的结构和值必须保持。本实现额外支持一个或两个输入头为None。

两个指针分别从A、B头前进，到None后改走另一条链，使用is比较对象身份。若前缀长度不同，换头让两者在走过相同总长度后消除差值；有公共后缀时在其首节点相遇，若一开始同头则立即返回。无交时，两者各遍历两条链后同时来到None。全程只读取next，没有接环、改链或额外节点集合。时间O(m+n)，额外空间O(1)。

独立oracle把A路径节点的id放入集合，再从B的节点数组找第一个成员，不使用双指针换头。穷举两条独立前缀和共享后缀长度各0..3、所有唯一节点值取1/2的3375个图；其中空路径作为接口扩展单列，同值不相交是重点反例。边界覆盖A长30000/B长25000且共享15000尾、两条各30000节点同值但完全独立、A长30000/B仅1节点且该节点就是共享尾，以及空扩展。每次逐条核对两条原路径的确切节点序列、尾部None与全部节点值，验证只读结构约定。
