# 606. Construct String from Binary Tree · Python

[原题](https://leetcode.com/problems/construct-string-from-binary-tree/)。

原题有1..10000个二叉树节点，值在-1000..1000。以先序值和括号表示整树，省略无用空孩子括号，但仅有右孩子时必须先保留空左组()，以区分左右位置。叶子只输出数值，只有左孩子输出value(left)，两个孩子输出value(left)(right)。输入TreeNode与左右引用保持；额外约定空根返回空串。

pending保存待访问节点和待输出的括号字符串事件。弹出节点先输出本节点值，再把右孩子组以逆执行次序压为右括号、右节点、左括号；接着同样压左孩子组。因此后进先出会先完整输出左组，再输出右组，括号闭合位置也与子树完成对应。

若没有左孩子但有右孩子，右组已经等待，最后再压一个()事件，保证它在右组之前输出。若只有左孩子，根本不建立空右组；若叶子，两组都不建。不用后期字符串替换删除()，否则会把右孩子所需的占位也误删。

Node对象与字符串括号事件类型明确分开，节点值转换为文本后只进入pieces，不会再当作节点遍历。显式栈可处理10000层单链，无Python递归深度依赖。所有片段最后一次join，不反复复制增长中的完整前缀字符串。

设最终字符串长S、节点数N、高度H。每节点常数事件，加上数值转换与join，总时间O(N+S)，本题值长有界且S>=N，也可写O(S)。pending辅助栈O(H)，输出片段与最终字符串占O(S)；没有把必需输出空间算成常数。

独立参考按四种孩子情形递归构造小树的规范字符串；另用独立递归语法把输出重新解析为(值,左,右)结构，核对结构不能因省略括号改变。0..5节点全部树形和-1/0/12标号共11497棵；空树为扩展。另测10000层左链/右链的直接闭式字符串、负1000、0及样例，核对原节点值与左右引用保持。大链不调用递归参考或解析器。未向LeetCode提交。
