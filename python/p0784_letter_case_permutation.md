# 784. Letter Case Permutation · Python

[原题](https://leetcode.com/problems/letter-case-permutation/)。

原题s长1..12，只含大小写英文字母与数字。每个字母可独立改大小写，数字保持，返回全部不同结果，顺序不限。原字符串保持，不把数字转为整数，前导零也保留。

用可变字符数组记录当前路径。递归访问每个位置：英文字母分别设置小写和大写并进入下一位置，数字只沿原值前进；到末尾时join成一个新字符串加入结果。字符数组只在本次调用内共享，不把同一个可变数组当作多个输出。

原题英文字母的大小写是两个不同字符，每个字母位置恰选一次，所以每条路径产生一个合法结果，不同路径至少在一个字母位置不同；任意合法结果的各位置选择也对应唯一递归路径，因此无漏项也无重复。后续位置在每条分支进入时都会按当前选择写入，无需保留上个分支的后缀状态。

设字母数为L、总长n，输出有2^L个长n的字符串。扫描路径和叶子连接时间O(n*2^L)，辅助字符数组与递归栈O(n)，输出空间O(n*2^L)。原题递归深度最多12，不使用不断拼接前缀导致额外的长尾复制。

独立oracle枚举字母域a/A/b/B/0/1上全部候选文本，按整个字符串的小写签名分组，一组就是该小域内全部合法输出，不按生产回溯逐位置生成。长度1..5全部9330输入逐个比较完整输出集合与重复情况。另核对官方例、12个字母的4096种输出、全数字与前导零，检查返回字符串与合法大小写合同。未向LeetCode提交。
