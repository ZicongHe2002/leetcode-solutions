# 1391. Check if There is a Valid Path in a Grid · Python

[原题](https://leetcode.com/problems/check-if-there-is-a-valid-path-in-a-grid/)。

原题m、n均1..300，每格街道类型1..6，分别连接左右、上下、左下、右下、左上、右上。从左上到右下只能沿现有街道，禁止旋转或改格子；返回bool。单格起终点相同，不需要走边即可到达。

用每类两个方向向量表达出口。从当前格能沿(dr,dc)出发还不够，邻格也必须具有(-dr,-dc)端口，才构成真正连接。BFS只将边界内、双向端口匹配且未访问的格子入队，入队时即标记，避免街道环上反复行走。队列弹出终点即可成功，耗尽则没有连通路径。

每格至多入队一次、仅检查两个出口，时间O(mn)，额外空间O(mn)，完整输入保持，未用修改街道作为visited标记。

独立oracle用L/R/U/D位掩码扫描每对横/纵相邻格，双方端口匹配才在并查集中连接，不复用方向向量队列。1x1、1x2、2x1、1x3、3x1和2x2的全部1806张街道网格逐一核对。300x300蛇形通路覆盖长连通路径，再断开终点回接端口核对False；1x300及300x1最大细长形也测试，核对bool及输入保持。
