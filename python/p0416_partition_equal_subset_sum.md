# 416. Partition Equal Subset Sum · Python

[原题](https://leetcode.com/problems/partition-equal-subset-sum/)。

输入为1..200个正整数，值在[1,100]，判断能否把全部元素分成和相等的两组，每个位置只用一次。本实现保留输入，额外支持空数组返回true。负值不属于合同。

总和为奇数直接失败；否则只需找到和为target=total/2的一个下标子集，剩余元素自然具有同样总和。整数reachable的第s位表示已处理前缀能否选出和s，初始只有第0位。加入value时，旧reachable左移value表示选该元素，和旧值按位或表示不选或选；右侧表达式整体先求值，再赋回，故每个位置恰好处理一次，不会变成可重复取的背包。mask保留0..target位，因为正数使已超过target的和永远不能再减回目标。最终检查目标位。

设S=target，按照位操作的保守上界，时间O(n·S)，额外存储O(S)位；Python大整数运算会批量处理机器字，但不能把任意宽整数的移位/按位或当成O(1)。总和最多20000，目标最多10000。奇数分支仅需O(n)求和时间。

独立oracle枚举全部下标子集，直接求子集和并与总和比较，不复用位集递推。枚举1..4上长度0..6的全部5461个数组，包含空扩展。边界覆盖200个100可等分、199个100加98的偶数总和仍无解、奇数总和、单个100及[1,2,5]防止重复取同一元素；逐次检查输入保持。
