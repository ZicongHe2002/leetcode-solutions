# 299. Bulls and Cows · Python

[原题](https://leetcode.com/problems/bulls-and-cows/)。

secret与guess是等长十进制数字字符串，可以有重复数字和前导零。位置和值都相同的匹配为bull，剩余数字中值相同但位置不同的匹配为cow；每次出现只能参与一次匹配。返回格式为xAyB，不修改输入。原题长度1..1000；实现额外支持两个空串返回0A0B，不支持长度不等或非数字输入。

先逐位匹配bull，并仅将不相同位置的数字加入两个长度10的频数表。这排除了同一个位置已计作bull后再次参加cow匹配。对每个数字，两个未匹配集合最多能配成min(secret_count,guess_count)对，且不同数字之间不会争用同一个出现位置，因此各数字的最小计数可以直接相加。

不能只检查guess中的数字是否出现在secret中，因为重复数字会被重复使用；也不能先统计全部共同数字却忘记扣除bull。两个表仅覆盖固定十个数字，总时间O(n)，额外空间O(1)，整数计数不会改写输入字符串。

独立oracle先固定所有bull位置，再对其余位置执行一对一匹配搜索：每个secret位置可以跳过，或与一个尚未使用且同值的guess位置配对，取最大匹配数。它不使用频数最小值公式。三数字域长度1..4的全部7380个有序字符串对核对，另测1000项、全同、全错、整体互换与重复数字被bull占用的情况；空串扩展有单独检查。
