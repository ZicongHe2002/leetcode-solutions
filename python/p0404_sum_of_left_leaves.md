# 404. Sum of Left Leaves · Python

[原题](https://leetcode.com/problems/sum-of-left-leaves/)。

原题非空树1..1000节点，值-1000..1000，求所有左叶子之和。左叶既须是某个父节点的left，也须自身没有孩子；根即使是唯一叶子，也不是左叶。实现保持树，返回int，不定义空树输入。

显式栈项携带当前节点是否由父节点左边进入。只有当前节点两孩子都空且is_left为True才累加；内部左孩子不能提前计入，右叶也不能计入。根的方向标志初始化False，左右入栈各带真实方向。每个节点恰处理一次，时间O(n)，深度优先栈额外空间O(h)，不使用递归。

独立参考在每个父节点检查其left是否为叶，并递归检查所有孩子，不传递is_left标记。枚举1..5节点全部树形及值-1/0/2，共11496棵；另测1000节点左右深链和完全层序树，深链与大树期望由单叶方向或层序下标直接计算，避免参考递归超深。覆盖单根、负叶和值域两端，核对int及原树保持。
