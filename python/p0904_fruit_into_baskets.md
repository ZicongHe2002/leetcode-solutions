# 904. Fruit Into Baskets · Python

[原题](https://leetcode.com/problems/fruit-into-baskets/)。

原题fruits长1..100000，每项在0..len(fruits)-1，表示一种水果；从某个起点连续取水果，最多使用两种类型的篮子，求最大可取长度。实现额外支持空数组返回0，保持输入，返回int。

counts只保存当前窗口内的非零频次。加入右端后若出现第三种类型，就移出左端并删除归零项，直到只剩至多两种。对于同一右端，更靠左且被排除的起点都包含第三种类型，不可能合法；留下的最长合法窗口即可更新best。左右各至多前进n次，平均哈希操作下时间O(n)；加入第三种类型后立即收缩，字典最多3项，额外空间O(1)。

独立oracle枚举每个连续切片，用set计算类型数，不复用频次维护。长度0..8且值在range(min(3,长度))内的9834个数组逐一核对，非空样本均满足原题值域，空数组为扩展。边界覆盖100000同类型、交替两类型、循环三类型及末尾引入第三种，核对输入保持。
