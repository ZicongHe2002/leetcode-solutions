# 486. Predict the Winner · Python

[原题](https://leetcode.com/problems/predict-the-winner/)。

原题nums长1..20，值0..10^7，两人最优地轮流取数组最左或最右元素并得分，先手总分不低于后手即胜，平局也返回True。只能取端点，输入保持。

advantage[left]表示当前区间轮到的一方，相对另一方能保证的最大分差。取左端后轮到对手，其最佳分差需从所得分中扣除，因此候选为nums[left]-右侧子区间分差；取右端同理。选较大者。单元素区间分差就是该值，外层逐步增加区间长度。

原地滚动表按left递增更新：读取advantage[left]时仍是旧长度的[left,right-1]，读取advantage[left+1]时也尚未被本轮改写，表示[left+1,right]；顺序反过来会混用长度。返回最终分差>=0保留平局语义。时间O(n²)，额外空间O(n)，状态数组由输入副本初始化。

独立oracle显式区分先后手轮次，先手回合最大化其最终绝对得分，后手回合最小化先手最终得分，再用两倍先手分数与总分比较，不复用分差状态。值0/1/2、长度1..8全部9840数组核对。最大20项全0平局、全10^7、单元素及明确后手获胜反例检查，核对bool和输入保持。
