# 694. Number of Distinct Islands · Python

[原题](https://leetcode.com/problems/number-of-distinct-islands/)。

原题grid为1..50行、1..50列的0/1矩阵，陆地按四邻接连通。只允许平移后重合的两座岛算同形，不额外做旋转或镜像归一化；对称形状若本来就能平移重合仍属同形。全水返回0，输入各行和值保持，返回int。

按行优先扫描找到未访问陆地，它必是这座岛按(row,column)字典序最小的格。以它为锚，用显式栈遍历完整四邻接连通分量，格子入栈即标记，保存每格相对锚的行列偏移。将偏移集合冻结为frozenset加入全局形状集合，使结果与DFS访问顺序无关。

若两座岛可以平移重合，平移保持行列字典序，所以各自最小锚也按同一向量平移，所有相对偏移完全相同。反过来，若偏移集合相同，用两个锚之间的向量平移就能把每格对应重合。因此签名相等恰好表示题目允许的平移等价。较低行可能在锚左侧，负列偏移是合法信息，不能取绝对值或丢弃方向。

每格扫描一次，每个陆地格只进出栈一次，冻结和散列的总元素量不超过陆地数，平均哈希成本下时间O(RC)，额外空间O(RC)。不排序每座岛，不递归，也不把陆地写成水。

独立oracle用并查集连接右/下相邻陆地，再对不同分量逐一尝试实际平移向量并比较绝对格集合，不生成锚偏移签名。完整核对行列各1..3的全部682个二元矩阵，另核对200个固定种子矩阵。50x50覆盖全水、整岛、1250个孤立格；具体形状核对四种不相互平移的L方向及重复副本、同边界的空心环和实心方块，保存并核对所有行身份和值。未向LeetCode提交。
