# 62. Unique Paths · Python

[原题](https://leetcode.com/problems/unique-paths/)。

网格行列长度m、n均在[1,100]，从左上走到右下，每步只能向右或向下，返回路径数。原题另保证答案不超过2×10^9；实现使用Python整数，测试中将100x100等超过该保证的大计数明确作为扩展，不冒充题目合同内样例。

对称交换行列只改变局部循环方向，让滚动数组长度取min(m,n)。第一行每个格子只有一种走法，故初始全为1。之后从左到右，paths[column]尚是上方格子的路径数，paths[column-1]已是当前行左方格子的路径数；最后一步只能从上或从左，两类互斥且完备，相加就是当前格子的路径数。第一列始终为1。完成所有行后末项就是右下格子。时间O(mn)，额外空间O(min(m,n))，单行/列自然返回1。

独立oracle使用组合公式C(m+n-2,m-1)，因为任一路径唯一对应全部步数中向下步的位置集合，不使用DP。检查1..12行列的全部144个网格，另有100x1、1x100、100x7和7x100，后两者实际检查结果仍在2×10^9范围内。100x100与组合公式的大整数相等属于扩展检查。
