# 402. Remove K Digits · Python

[原题](https://leetcode.com/problems/remove-k-digits/)。

原题num为长度1..100000的非负十进制字符串，无多余前导0，1<=k<=len(num)。必须恰好删除k个位置，返回最小数的规范十进制字符串，不保留前导0，空结果为'0'。实现额外支持k=0，输入保持。

新数字更小时，若仍有删除额度，应先删除保留串末尾更大的数字，让最早发生变化的位置尽可能小；剩余前缀决定字典序，后面数字无法弥补该差异。扫描后若额度仍在，保留串已非降，应从末尾删掉最大的后缀。最后统一移除前导0，不把去0计入删除额度；remaining为0时必须跳过尾部切片删除。每位至多进出一次，时间O(n)，额外空间O(n)，不把整个大数字转成整数。

独立oracle枚举保留位置组合，用小输入的整数值直接选最小，不复用贪心。数字0..3组成、无多余前导0且长度1..6的4096个原题格式数字，各测k=0..n共27308次查询，k=0为扩展。边界覆盖100000位、长0后缀、同数字、剩余额度及全部删除，核对str。
