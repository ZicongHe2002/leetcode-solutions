# 367. Valid Perfect Square · Python

[原题](https://leetcode.com/problems/valid-perfect-square/)。

原题num是1..2^31-1的正整数，判断是否为整数平方，返回bool；禁止调用sqrt等内置开方函数。实现与参考测试均不使用浮点开方。

正平方根若存在必在1..num内，正整数平方随根严格递增。二分比较middle^2与num，相等立即返回，小于则答案只能在右侧，大于则只能在左侧；闭区间每轮至少去掉middle并缩短，区间耗尽即不存在整数根。Python整数乘法不会产生固定宽度溢出，没有浮点舍入问题。时间O(log num)，额外空间O(1)，按原题32位整数运算规模说明。

独立参考显式枚举1..46340的整数平方形成集合，覆盖32位正数范围内全部平方数，不用二分或开方作为参考。逐一检查1..10000；再对全部46340个平方及其前后相邻合法正整数核对，共139019次边界检查，另测2^31-1。邻值判断仍以集合成员为准，不手写根相近时的猜测结果。
