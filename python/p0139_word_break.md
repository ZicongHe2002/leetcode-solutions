# 139. Word Break · Python

[原题](https://leetcode.com/problems/word-break/)。

字符串s长1..300，词典含1..1000个不同的非空小写单词，每词长1..20，s也仅含小写字母。判断能否把s分成词典中的单词，允许重复使用词典项。本实现保留词典列表，额外支持空字符串为true，空词典匹配非空字符串为false。

reachable[end]表示前end个字符能否完成分割，空前缀为true。按end递增，只检查最长词长L以内的起点start：前缀reachable[start]已经确定，且s[start:end]是词典项时，拼接得到一个合法方案。反过来，任何合法分割的最后一个词必有这样的start，因此枚举完整。非空词保证start<end，递推不循环；一旦找到见证即可break。

设n为字符串长、W为不同词数量、L为最大词长。每个end至多考察L个切片，切片构造和哈希最多O(L)，在集合平均查找假设下，DP时间O(n·L²)，另有词典建集合的字符哈希开销。额外空间O(n+W+L)，包含布尔表、词典引用集合与临时切片；没有把Python切片和字符串哈希误当O(1)。

独立oracle枚举全部切割位掩码，完整分割后逐词查词典，不使用可达前缀DP。六个词a/b/aa/ab/ba/bb的全部64个词典子集，配合长度0..6的全部127个二字母字符串，共8128次；空词典/字符串作为扩展单列。边界覆盖300字符、20长度词、1000个不同的5字母词、末尾无法匹配、重复用词和经典样例，检查词典输入保持。
