# 688. Knight Probability in Chessboard · Python

[原题](https://leetcode.com/problems/knight-probability-in-chessboard/)。

原题n为1..25，k为0..100，起点row/column在合法棋盘内。每一步都从骑士八种移动等概率选择，包括会离开棋盘的移动；离开后失败并停止。求走完k步仍未出界的概率，不能把概率重新均分给合法落点。返回float。

ways[r][c]表示从(r,c)出发，还需完成当前步数且全程留在棋盘内的移动序列数量。零步时每格恰有一种空序列，初始全为1。再增加一步时，按八种首步分类，合法落点后接原ways对应的剩余序列，非法落点贡献0。因此新值是所有合法邻格原计数之和；逐层替换两个棋盘，不在同一层读写混用。

最终ways[row][column]是成功序列数。把每次移动补齐到八选一、共k次的选择空间有8**k个等概率序列，即使某些选择早已出界也不能减少分母。所有计数用整数，仅最后一次除法转float，避免每步累计浮点误差。k=0自然返回1.0；1x1或2x2在正步数时无合法路径，返回0.0。

初始化与转移共O((k+1)*n²)次有界整数运算，额外空间O(n²)；其中+1包含k=0时构建初始棋盘的成本。本题k<=100使计数至多8**100，位数至多301位；若把k推广为任意大数，不能把大整数算术成本仍当作无条件常数。没有随机模拟或概率采样声明。

独立oracle直接枚举八种移动的长度k选择序列，逐步移动并在首次出界时拒绝，核对n=1..5所有起点、k=0..4共275次查询。大边界用从指定起点向前传播的独立整数分布，与生产从所有起点反向计数的初始化和方向不同，再以Fraction转换概率；覆盖25x25/100步、棋盘镜像、概率随步数不增加及零步。未向LeetCode提交。
