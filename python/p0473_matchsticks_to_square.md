# 473. Matchsticks to Square · Python

[原题](https://leetcode.com/problems/matchsticks-to-square/)。

用全部火柴各一次、不折断不丢弃，判断能否拼成四边等长的正方形。原题1..15根，每根长度1..100000000；输入保持，不排序或改写火柴。长度全为正，少于4根不能形成四条非空边；空列表作为扩展返回False。

总长必须被4整除，目标边长side=total/4，最长一根不能超过side。这些必要条件先排除明显失败；正长度保证通过后side>0，取模安全。仍需检查全局分组，不能仅凭总长和最长值返回True。

mask记录已使用的火柴下标，remainder[mask]为按顺序填完若干整边后、当前未填满边的长度，-1代表该集合不可按此过程排列。空集余长0；选择一个尚未使用的下标，只有加上它不超过side才可转移，恰好填满就取模回0，再开始下一边。加入下标使新mask严格增大，按整数mask顺序遍历可读到前面更新的状态。

同一mask的总长度固定，所以任意合法排列的当前余长都等于集合长度和模side；已达状态可以直接覆盖为同一值，无需保存不同填边历史。合法四边分组把各组顺次排列就是一条DP路径；反过来，每条路径从不超边、仅在整边处重置，全集总长恰为4*side，若可达就恰好完成四边。正长度同时排除零边伪解。

2^n个子集各尝试n根，时间O(n*2^n)，辅助空间O(2^n)。相同长度的火柴仍以不同下标代表各自一次使用，原列表保持。Python整数可精确处理最大总长1500000000。

独立参考用递归把每根火柴实际分配到4个边容器，检查边容量，跳过同一层等负载的对称选择；不使用子集mask或余长状态。长度1/2/3、根数0..8共9841个数组对照，空列表为扩展。另测15根、单根100000000、总长可整除但无解、过长火柴及经典样例，核对bool和输入保持。未向LeetCode提交。
