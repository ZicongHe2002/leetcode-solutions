# 1541. Minimum Insertions to Balance a Parentheses String · Python

[原题](https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/)。

原题s长1..100000，仅含左右括号；合法语法为左括号+A+两个连续右括号，合法串还可拼接，空串合法。一次插入任意一个括号，返回最少插入数int；这里不能把普通单右括号平衡规则套用。

needed表示还欠多少右括号。读入左括号前若needed为奇数，说明上一对右括号只读到一半，必须先插一个右括号把它补齐，再给新左括号增加两个需求。读入右括号就减少需求；若变负，表示没有左括号供这一个右括号归属，必须补一个左括号，而这一对还欠一个右括号，故needed改为1。末尾补足needed个右括号。每次即时插入都由当前半对或无左可配的前缀强制，剩余需求也必须满足，算法恰按这些下界补齐。时间O(n)，额外空间O(1)。

独立参考直接按空串、拼接、左+A+双右的语法枚举合法目标，取包含输入为子序列的最短目标，长度差给最少插入。长度1..7的254个原串全部核对；长度m时m个左括号对的目标足以覆盖任意原串，枚举上界完整。另测100000字符、全开/全闭、奇数闭括号长度和重复单对，核对int。无在线Accepted记录。
