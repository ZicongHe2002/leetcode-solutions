# 126. Word Ladder II · Python

[原题](https://leetcode.com/problems/word-ladder-ii/)。

给定等长小写单词beginWord、endWord及词典，每一步只能改一个字符，变换后的词必须在词典中，返回全部最短变换路径。原题起终点不同、单词长至多5、词典至多500词，答案顺序不限。输入词典不修改；另外定义起终点相等时返回单词本身组成的零步路径。

BFS按层维护frontier，并在扩展整层前从remaining移除该层词。某个新词可以被本层多个词同时发现，因此不能在第一次发现时立即从remaining删除。parents用集合保存本层所有指向新词的父边，following去重下一层节点。父边只从前一层连向后一层，不会回到旧层或在同层形成环。

第一次发现endWord后仍需完成本层的所有扩展，下一次循环条件才停止。这样保留所有最短路径的最后一层父边，同时不再扩展更长路径。若词典不含终点或BFS耗尽仍未到达，返回空列表。沿父边从终点回溯到起点，每次输出反转后的路径；集合父边与唯一逐层路径保证结果不重复。

设N为词典大小、L为单词长度、E为记录的父边数、R为全部输出路径中的单词引用总数。每个被扩展词生成26L个候选，Python切片和字符串构造为O(L)，因此时间上界O(26NL²+R)。额外空间O(NL+E+R)，包含候选词、父边、回溯路径和输出；回溯深度不超过词典词数加起点。不能仅用BFS节点数声称全部路径输出也为线性。

独立oracle先按逐对Hamming距离显式建图，再用保存完整路径的队列枚举至首个成功深度，不复用生产父边DAG或逐字符造邻居。三字符二字母域8词的全部256个词典子集、56个不同起终点有序对，共14336次查询。另测完整三维字母立方体的6条最短路径、终点缺失、500词边界与零步扩展，并检查词典保持。
