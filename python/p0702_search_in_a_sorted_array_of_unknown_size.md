# 702. Search in a Sorted Array of Unknown Size · Python

[原题](https://leetcode.com/problems/search-in-a-sorted-array-of-unknown-size/)。

原题只能调用ArrayReader.get(i)读取未知长度、严格递增且值唯一的数组。合法下标返回数组值，越界返回2^31-1；长度1..10000，数组值与target均在-10000..10000。返回目标零基下标或-1，算法只使用get，不读取内部数组或长度。ArrayReader由平台提供。

先取闭区间[0,1]。若get(high)<target，有序性保证high及更左位置都不是答案，令low=high+1并把high翻倍。倍增直到右端值至少为target；越界哨兵大于所有合法target，保证即使目标大于最大真实值也能停下。若目标存在，它必在当前闭区间中。

随后按普通闭区间二分：相等时返回下标，小于目标排除左半含中点，大于目标排除右半含中点。越界哨兵按大值处理，因此不会被误报为目标，也无需把越界当异常捕获。low超过high时不存在目标，返回-1。严格递增保证命中下标唯一，负值不影响比较。

倍增最多把右端扩到包住数组末端的下一倍增位置，随后二分相同数量级区间，时间与get调用数为O(log(n+1))，额外空间O(1)。使用n+1包括单元素数组的常数工作；不借助已知10000上限固定搜索区间。

独立oracle直接用测试端已知列表查找目标，而生产只能看到无长度接口的Reader。七个稀疏正负值的全部127个非空有序子集，对-5..9的15个目标共1905次查询；另核对10000元素、首中尾、缺失奇数、目标在末尾之外、单元素正负边界。Reader记录并拒绝负/非整数下标，每次查询核对调用数不超过2*bit_length(n+1)+4，能发现退化成线性读取；同时核对原数组保持。未向LeetCode提交。
