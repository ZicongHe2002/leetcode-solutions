# 674. Longest Continuous Increasing Subsequence · Python

[原题](https://leetcode.com/problems/longest-continuous-increasing-subsequence/)。

原题nums长度1..10000，每项在-10^9..10^9，求最长连续且严格递增片段的长度。这里必须是连续下标，不能跳过下降点；相等也会中断。输入保持，返回int。实现额外支持空数组返回0。

ending表示以当前下标结束的最长严格递增连续段长度。若当前值大于前一个值，原末尾段恰能延长一位；否则任何跨过这条相邻边的连续段都不严格递增，所以重置为1。首项同样从1开始。best是所有已处理末尾的最大值，每个合法片段都有某个末尾，扫描完成即覆盖最优解。

每个元素处理一次，时间O(n)，额外空间O(1)。只读访问输入，不切片或维护整个递增段。

独立oracle枚举全部非空区间，检查区间内任意较早位置的值都严格小于较晚位置，再取最大长度，不复用相邻计数状态。对-1/0/1、长度0..8的9841个数组逐一核对，其中空输入为扩展；另检查10000长度的递增、递减、重复、两个长段及正负极值交替，保存并核对原数组。没有LeetCode提交记录。
