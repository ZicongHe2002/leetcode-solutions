# 658. Find K Closest Elements · Python

[原题](https://leetcode.com/problems/find-k-closest-elements/)。

arr为长度1..10000的非递减数组，值与x在[-10000,10000]，1<=k<=n。返回离x最近的k个元素，距离相同时较小值优先，结果按数值升序且保留重复元素。本实现保留输入，并返回新的列表，包括k=n时也不返回原列表对象。

最优选择可由一个长度k的连续窗口表示：若选择了两端却跳过中间值，中间值到x的距离不会同时比两端更差，可交换成连续选择。相邻窗口只差左端arr[mid]和新增右端arr[mid+k]；比较带符号间距x-arr[mid]与arr[mid+k]-x决定应否右移，等号时保留较小左端。这个条件等价于2x>arr[mid]+arr[mid+k]，右侧随mid非递减，因此可二分第一个不应继续右移的窗口。x在两端同侧时符号自然指向更近方向；不能随意替换为绝对值比较，重复端点会破坏对应单调判断。k=n时搜索范围只有0，不会读取arr[n]。

时间O(log(n-k+1)+k)，包含最终复制k项；不计返回列表的额外空间O(1)，结果空间O(k)。独立oracle按(abs(value-x),value)给全部元素排序，取前k项后再按数值排序，不使用连续窗口二分。五值集合[-2,-1,0,1,2]上长度1..7全部791个非递减数组，对全部k与x=-3..3共32340次查询。边界覆盖10000长度、k=1/n、x在值域外侧、数值端点和重复值陷阱[1,1,1,10]、k=1、x=9；逐次检查输入保持与新返回对象。
