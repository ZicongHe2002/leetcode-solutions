# 123. Best Time to Buy and Sell Stock III · Python

[原题](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iii/)。

原题prices长度1..100000，价格0..100000，同时至多持有一股，至多完成两次买卖，求最大利润，保持输入。可以只交易一次或完全不交易。

buy1/sell1分别记录第一层持股/不持股的最佳现金，buy2/sell2对应至多第二层交易。未持股的初始收益为0，尚未买入的持股状态为负无穷。每天可以保持旧状态，也可以由上一层卖出收益买入，或由持股状态卖出。四个右侧表达式先计算再赋值，所以只读取前一天的状态，不会把同一天的新收益跨多层传递。

sell1初始为0，使第二层也能表示只做一次交易的策略；sell2同样以0表示不交易。逐日枚举了每个状态的全部合法最后动作，归纳得到最优值，最终未持股的sell2就是至多两次交易答案。时间O(n)，辅助空间O(1)。

独立oracle递归枚举每天休息/买入/卖出，卖出后减少剩余完整交易次数，终点禁止未平仓，不复用四变量递推。3种价格、长度1..7的3279个数组核对。边界覆盖100000天、两次极值收益、长上涨与长下降、单日，核对int与输入保持。
