# 240. Search a 2D Matrix II · Python

[原题](https://leetcode.com/problems/search-a-2d-matrix-ii/)。

原题矩阵为m×n非空矩形，m,n各1..300，每行自左向右、每列自上向下非递减，元素与target都在-10^9..10^9。这里不要求上一行末项小于下一行首项，因此不能把整个矩阵直接当有序一维数组。实现不定义空矩阵或锯齿输入，返回bool，保持矩阵。

从右上角开始，尚未排除的区域是当前行及以下、当前列及以左的矩形。若当前值大于target，同一列的下方值也都过大，整列可删；若小于target，同一行左侧也都过小，整行可删。相等立即返回True。每步恰好排除一行或一列，离开矩阵时所有候选已排除，返回False。最多m+n-1次取值，时间O(m+n)，额外空间O(1)。

独立参考逐项扫描相等关系。枚举行列各1..3、值-1/0/1且满足双向有序的330个矩阵，各查-2..2，共1650次查询。另测300×300矩阵、合法值域两端、重复值、单行单列、行间交叠与间隔中的缺失目标，并核对bool及输入保持。
