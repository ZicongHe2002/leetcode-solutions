# 670. Maximum Swap · Python

[原题](https://leetcode.com/problems/maximum-swap/)。

原题0<=num<=10^8，允许至多交换一对十进制数字，返回可得到的最大整数。允许不交换；0也有一位数字。返回int，未引入浮点或额外交换。

先记录每种数字最右出现位置。再从最高位向最低位扫描：在当前位置，按9向当前数字的严格更大值递减寻找，只选确实出现在右侧的数字。找到后与其最右出现位置交换，立即返回。若所有位置都无法提升，原数已最大，直接返回。

等长非负十进制数的大小由第一个不同位置决定，因此必须优先提升最靠左的可提升位，并为它选最大的可用数字。若最大数字在右侧重复，交换它最右的出现位置更好：提升后的前缀相同，而较小的原数字会被放到更低位，左侧仍保留较大数字。至多一次交换保证首次提升后即可结束。只向首位换入更大数字，所以不会产生前导零。

设d为十进制位数，构造位置表O(d)，逐位最多检查9种数字，时间O(10d)=O(d)，数字数组与拼接文本占O(d)额外空间，位置表固定10项。原题d最多9。

独立oracle枚举每一对下标实际交换，再与不交换的原数一起取最大值，不使用贪心选择或最右位置表。完整核对0..100000的100001个输入，并以固定种子检查1000个大范围输入；覆盖2736、9973、1993重复最大数字、98368与10^8。实际验证仅为本地测试，没有LeetCode提交记录。
