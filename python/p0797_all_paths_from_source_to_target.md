# 797. All Paths From Source to Target · Python

[原题](https://leetcode.com/problems/all-paths-from-source-to-target/)。

原题graph为2..15个节点的DAG，节点0到n-1，邻接表无自环、无重复边；列出从0到n-1的全部路径，返回list[list[int]]，顺序任选。编号不保证是拓扑顺序，输入不变。

current保存从0到当前节点的路径，依次尝试每条后继边，递归返回时弹出刚加入的节点。到目标便复制当前路径，不能保存同一个可变列表引用。DAG保证递归不会回到当前路径上的节点，最长深度不超过15；不使用全局visited，因为汇合节点应允许从不同前缀分别进入。每条源目标路径对应唯一分支选择，故完整且不重复。可能有指数多个前缀或输出，最坏时间O(n*2^n)，返回存储最多O(n*2^n)，除返回值外路径和调用栈O(n)；不把输出为空时的前缀探索声称为线性。

独立小图参考枚举中间顶点的所有选取长度与排列，再检查候选路径每条边是否存在，不用图搜索。穷举2..5节点、仅小编号指向大编号的全部1098个DAG，再检查内部节点重编号后的非数字拓扑图。最大15节点的有序完全DAG用全部中间顶点子集参考，核对8192条路径；另测长链、目标不可达和邻接表乱序，按集合比较而不固定路径次序，并核对路径列表独立及输入保持。
