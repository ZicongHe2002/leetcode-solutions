# 127. Word Ladder · Python

[原题](https://leetcode.com/problems/word-ladder/)。

原题起终单词不同、长度1..10，字典有1..5000个互不相同的等长小写单词。每次只能改一个字符，转换后的词必须在字典中，起点本身不要求在字典里；求最短序列的单词个数，无路返回0。

把起点及字典词当作状态，单字符合法修改是等权边。BFS从起点长度1开始，枚举每个位置的另外25个小写字母。候选词在remaining中才可进入，入队时就删除，保证首次到达即为最短长度，并避免后续重复入队。终点不在字典时直接无解；否则首次弹出终点的长度包含起点和终点，不是仅计修改次数。

设W为字典大小、L为词长，每个候选字符串构造和哈希最多需要O(L)，至多处理W+1个状态并检查26L个修改，时间O(W*26*L*L)，辅助空间O(W*L)，包含字典集合及队列候选字符串。输入列表保持。

独立oracle逐对比较单词的汉明距离，显式建图并用Floyd求距离，不用字母替换生成邻居。二元字母、词长2和3的所有非空字典子集，查询所有不同起终点，共14460次合法查询。边界覆盖5000词、10字符、起点在字典中、终点缺失及同前缀大连通块与隔离终点，核对int与输入保持。
