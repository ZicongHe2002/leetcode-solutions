# 803. Bricks Falling When Hit · Python

[原题](https://leetcode.com/problems/bricks-falling-when-hit/)。

原题二值网格行列各1..200，hits长1..40000且所有坐标互异。顶行砖及经四邻砖连接到顶行的砖稳定；每次擦除会使原本稳定而失去支撑的其他砖立即消失，答案不含被直接擦除的砖。擦空位置不会掉砖。原网格与hits保持，不要求初始所有砖都稳定，不把互异坐标扩展为重复命中合同。

正序删边很难维护连通块，改为先在副本擦除全部命中位置，再逆序恢复。并查集加一个虚拟屋顶，顶行砖连到它，当前所有四邻砖相连。未被命中的虚拟砖即使在真实正序中已经掉落，仍可留在离屋顶断开的块；它们不计入屋顶大小，但恢复支撑时会整体重新计入。

恢复原来为1的命中位置前后，比较屋顶连通块大小。若该位置接上屋顶，增量包括它自身和因本次恢复重新连上的砖，减去自身1就是正序因擦除它失去支撑的砖数；未接上屋顶时差为0，用max(0,差-1)得到0。原来为0的位置跳过，互异命中保证不会多次恢复同一原砖。若某命中砖在更早正序步骤已经掉落，对应逆序恢复时尚无屋顶连接，贡献也为0。

初始浮空块在完整原网格都不连屋顶，删砖不会让它新接上屋顶，因此不应在第一个命中时凭空计入掉落。算法只统计屋顶连接的增减，包含该情况。并查集迭代路径压缩、按大小合并，避免深网格递归。

设N=行数*列数、H=命中数，时间O((N+H)*alpha(N))，额外工作空间O(N)，答案另占O(H)。副本网格和并查集只各为线性大小。

独立oracle按正序实际擦除，每次用屋顶四邻搜索求前后稳定集合，只删除从稳定变为不稳定的砖，空命中直接返回0。全部1*1、1*2、2*2、2*3二值网格及长度至3的全部互异命中排列共10642查询，包含初始浮空与先掉落后命中。另测官方例、200*200满网格逐个擦除顶行、40000空位命中与200高单列，核对输入保持。未向LeetCode提交。
