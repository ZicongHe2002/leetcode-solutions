# 434. Number of Segments in a String · Python

[原题](https://leetcode.com/problems/number-of-segments-in-a-string/)。

词段是由连续非空格字符组成的最大非空片段。原题以普通空格字符分隔，允许字母、数字和标点，字符串长度0..300；逗号或感叹号本身不会分隔词段。只返回词段数量，不输出切分结果，也不改写输入。

一个词段恰有一个起点：当前字符不是空格，且它位于字符串开头，或前一字符是空格。扫描每个位置，只对这种起点计数。连续多个空格不会增加计数，前后空格也不会制造空段；全部空格与空串自然返回0。

该判定与“最大连续片段”定义一一对应，不需要维护当前单词文本或分配所有切片。每个字符检查一次，时间O(n)，额外空间O(1)。按原题的普通空格合同判断，不把非空格标点或数字替换成分隔符。

独立oracle按普通空格使用标准库split，再过滤空片段计数，不复用生产起点判断。三字符域a/空格/感叹号、长度0..7全部3280个字符串核对。另测重复/前后空格、相邻标点、数字、300字符边界与返回类型。
