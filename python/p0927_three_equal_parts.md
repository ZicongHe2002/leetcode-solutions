# 927. Three Equal Parts · Python

[原题](https://leetcode.com/problems/three-equal-parts/)。

前导0不影响值，但三个非零相等二进制数的1数量必须相同。总1数不是3倍数直接失败；全0可任取三段非空。否则定位第1、第k+1、第2k+1个1作为三段有效起点，第三段从起点到数组尾的长度决定每段必须包含的有效位与末尾0。前两段需要有足够空隙放同长度文本，逐位相同后其余间隙只作为下一段前导0，返回对应两处分界。

时间O(n)，额外空间O(1)，不转换可能很长的二进制整数，不修改输入。
