# 860. Lemonade Change · Python

[原题](https://leetcode.com/problems/lemonade-change/)。

原题bills长1..100000，每项只可能5、10、20，按给定顺序每人买一杯5元饮料，初始无零钱，必须当场找零，判断能否服务全部顾客。返回bool，输入顺序及内容保持。

收到10元必须找一张5；收到20元优先用10+5找15，否则尝试三张5。优先用10保留更通用的5：未来10元支付只能用5找零，而10元钞票只在20元支付的找零中有用；把10+5替换为三张5会多消耗两张5，却只多留一张用途更窄的10，不会改善后续可行性。收到20元钞票本身不保存，因为任何一次找零最多15，永远不能用它找零。缺零钱立即False，未来顾客付款不能补救之前的失败。

固定两个计数，时间O(n)，额外空间O(1)。独立参考保留全部可达的5/10/20钞票数量状态，对每位顾客枚举所有精确找零组合，再加入收到的钱，不按贪心偏好选组合。枚举长度1..8的9840个支付序列；另测100000顾客、可重复服务模式和前缀已失败情形，核对bool及输入保持。
