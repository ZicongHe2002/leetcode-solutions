# 289. Game of Life · Python

[原题](https://leetcode.com/problems/game-of-life/)。

当前原题board行列数分别1..25，格子为0/1，按八邻居的生命游戏规则同时推进一代。原地修改给定二维列表，函数不返回值；矩阵外不计活邻居，既不循环边界，也不在此接口扩展尺寸。

第一遍让每格最低位始终保存旧状态，第1位保存新状态。统计邻居时只取&1，所以较早写入的新位不会污染旧邻居数；活格恰有2或3邻居存活，死格恰有3邻居出生，符合时置第1位。全部新状态写好后第二遍右移1，将新位变成唯一状态，恢复所有值为0/1。只替换整数，不替换外层或行列表，时间O(rows*columns)，额外空间O(1)，满足原地同步更新。无限平面的进阶讨论可改用活细胞坐标集合，对每个活格的八邻居累计候选再生成下一代；当前有限矩阵实现不声称提供无限棋盘API。

独立参考从初始活格坐标集合向八方向散发邻居计数，最后只在原尺寸内生成结果，不使用就地双位编码。穷举1..3行列的全部682个二值棋盘；另测25乘25、全死/全活、单行单列、边界及滑翔机连续四代。核对返回None、精确下一代、纯0/1整数，以及外层和每个行对象身份保持。
