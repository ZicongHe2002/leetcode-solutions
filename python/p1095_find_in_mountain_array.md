# 1095. Find in Mountain Array · Python

[原题](https://leetcode.com/problems/find-in-mountain-array/)。

原题是交互接口题，MountainArray仅提供get(index)和length()；长度3..10000、值与target均在0..10^9，数组为两侧严格单调且峰在内部的山峰。返回目标的最小下标，不存在返回-1；get调用超过100次判错。提交代码使用评测器提供的对象，不自行读取数组或依赖测试桩内部数据。

先按相邻斜率二分唯一峰：上升就排除mid及左侧，否则保留mid及左侧。再在[0,peak]上升区间二分，找到立即返回；只有左侧不存在才搜索[peak+1,n-1]下降区间，比较方向相反。每侧严格单调保证各自最多一个匹配；先左后右保证两坡都有目标时返回较小下标。下降搜索不重复包含峰，所有get下标都在0..n-1内。

read缓存已读下标的值，每个下标至多真正get一次。时间与额外缓存空间均为O(log n)。n<=10000时峰定位最多14轮、每轮最多2次get；两段搜索各最多14轮、每轮最多1次get，因此即使忽略缓存也不超过56次，低于100。缓存不改变接口调用合同。

本地测试桩只暴露get/length给被测实现，拒绝非法下标并在超过100次get时报错。独立参考在测试侧完整扫描原始数据，取第一个匹配下标。枚举1245个小严格山峰，对每个峰值p查0..p+1，共8361次；覆盖两坡重复目标、峰本身和缺失目标。另测10000长度的三个峰位置与目标值域边界，每次核对调用数<=56以及同一下标只get一次。这是本地接口模拟通过，没有在线评测Accepted记录。
