# 598. Range Addition II · Python

[原题](https://leetcode.com/problems/range-addition-ii/)。

初始m×n矩阵全0，m,n在1..40000。每个操作[a,b]给左上角a×b区域全部加1，1<=a<=m、1<=b<=n，最多10000次操作。返回最终达到最大值的格子数量，不返回最大值本身。输入操作列表保持，不需要实际建立矩阵。

每个操作都包含左上角格子，因此若有K次操作，最大格值恰为K。一个格子达到K，当且仅当它在每个操作矩形内。所有矩形从同一左上角开始，交集仍为矩形，行数是全部a的最小值，列数是全部b的最小值，数量为两者乘积。

rows/columns从m/n开始，逐操作取小后，始终等于当前所有已处理矩形与整个网格的交集尺寸。没有操作时所有格子仍为0，也都是最大值，初始尺寸直接给出m*n，不能返回0。合法a/b至少1，交集至少含左上角，无需另设空交集分支。

K次操作各处理一次，时间O(K)，额外空间O(1)，即使40000×40000也不分配面积大小的存储。返回整数，重复操作可以增加最大格值，但不会改变已确定的交集范围；原ops不排序或改写。

独立oracle真正建立小矩阵并逐格执行每一次加1，再找最大格值并数格子，不使用交集公式。对1..3行、1..3列，枚举0..3次合法操作的全部1537个序列。另测40000×40000、空操作、10000次重复操作和互相限制行/列的操作，检查整数返回及操作列表保持。未向LeetCode提交。
