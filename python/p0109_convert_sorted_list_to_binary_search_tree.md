# 109. Convert Sorted List to Binary Search Tree · Python

[原题](https://leetcode.com/problems/convert-sorted-list-to-binary-search-tree/)。

原题输入为非递减单链，0..20000节点，值在-10^5..10^5，返回高度平衡的二叉搜索树。相同值可以重复，因此检查中序非递减及每个节点左右高度差<=1，不额外要求严格不等。假设链无环；空链返回None，输入next和值保持。TreeNode/ListNode供本地导入，字段与评测器对应。

先数链长，再按树的中序访问顺序消费链表。build(size)先递归建立size//2个节点的左子树，然后把当前cursor值作为根并前进一项，最后建立剩余右子树。函数恰好消费size个连续链节点，中序输出就是输入序列；左右规模至多相差1，递归使用相同平衡划分，每个输出节点的子树高度差至多1。只推进共享的局部cursor，不切断原链，不反复扫描中点。

计数与建树各读链一次，时间O(n)；除返回树外仅有平衡递归栈O(log(n+1))，不是常数栈。测试不绑定一种合法树形，而是独立检查全部中序值、节点数、每个节点平衡和无共享/环。枚举值-1/0/2、长度0..8的165种有序链；另测20000节点含值域两端和20000个重复值，同时核对输入next和值不变。
