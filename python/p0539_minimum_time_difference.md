# 539. Minimum Time Difference · Python

[原题](https://leetcode.com/problems/minimum-time-difference/)。

给定2..20000个合法24小时HH:MM时间点，求任意两点之间最短的分钟差，允许跨午夜。时间点是一天内的位置，不带不同日期或时区；相同文本可重复，重复时间的答案为0。输入列表保持。

一天只有1440个整数分钟。先把每个时间转换为0..1439，在布尔表标记。若同一分钟再次出现，立刻返回0，因为分钟差不可能更小。没有重复时，按布尔表下标升序扫描，就得到时间排序，既不排序原列表，也不复制全部时间字符串。

记录首个分钟first和最近分钟previous，检查每对相邻分钟的普通差。最后还必须比较从最后一分钟跨午夜到first的圆周间隔1440-previous+first；例如23:59与00:00的普通差为1439，跨午夜差却为1。任意两点之间的圆周弧都由若干相邻间隔组成，弧长不会小于其中最小间隔，所以全局最短差一定出现在这些普通相邻间隔或最后的跨午夜间隔中。

None只表示尚无前驱，不能用previous的真假判断，因为00:00对应合法整数0。原题至少两点，且重复情况已经返回，收尾first与previous都必有值。

设输入数量为N，解析时间点及扫描分钟表的时间上界O(N+1440)，辅助空间O(1440)，对固定一天分钟域是常量。提前发现重复可以缩短实际扫描，不改变上界；不声称对任意精度时间仍是常量空间。

独立参考枚举全部下标对，对每对直接取abs差与1440-abs差的较小者，不用位图或相邻扫描。六种覆盖午夜、小时边界及半天的时间、列表长2..5，共9324个列表逐个对照；另遍历1440种相邻分钟对，含跨午夜，测试全部1440个不同分钟与20000项重复。核对int及输入保持，未向LeetCode提交。
