# 49. Group Anagrams · Python

[原题](https://leetcode.com/problems/group-anagrams/)。

输入1..10000个单词，每词长度0..100，只含小写英文字母；空词列表另支持为空输出。对每词生成26字符重数元组，以其作字典键。两个词属于同一异位词组当且仅当每个字符的出现次数相同，因此键相同恰好等价于应分在同组。每次追加当前出现的词，重复词与空词的出现次数保留，不修改输入列表。

输出组及组内顺序不作承诺。设总字符数L、词数n、不同键数u，平均时间O(L+26n)，含输出引用的空间O(26u+n)；固定长度键的构造不是与单词长度无关的整个算法。输入字符串由结果引用，没有为每次出现复制全部字符串。

独立oracle按单词排序后的字符序列分组，和生产频数键不同。七词集合[空词,a,b,aa,ab,ba,bb]上长度0..4全部2801个词列表；另查10000个长度100的单词、全重复空词和分组重复项。归一化仅排序，不去重，错误丢失重复项仍会失败。
