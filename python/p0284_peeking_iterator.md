# 284. Peeking Iterator · Python

[原题](https://leetcode.com/problems/peeking-iterator/)。

包装原题提供的整数Iterator，支持peek查看下一项但不消费、next消费并返回下一项、hasNext判断是否仍有数据。原题保证只有存在下一项时才调用peek或next；耗尽后的这两个调用不在合同内。本实现额外支持初始化时底层为空，hasNext直接为False。

初始化时最多预读一个值。_has_value为True时，_value是包装器下一次应返回的值，底层指针位于它之后；为False时没有待返回项。peek仅返回缓存，不调用底层next，所以重复peek不会丢失元素。next先保存当前缓存作为返回值，再查询底层是否有下一项并补充缓存。hasNext直接返回缓存有效标志。

有效标志与数值分开，不用缓存的真值判断是否耗尽，因此0或负整数也不会被误判。底层next仅在其hasNext为True时调用，每个底层元素恰好读取一次。依赖底层两个操作为O(1)，包装器每个方法时间O(1)，额外空间为一个缓存值和几个引用，即O(1)，不把全部迭代器转换为列表。

测试用列表和单独的逻辑游标作为可观察接口参考，底层测试迭代器在耗尽后读取会直接失败，并计数next调用。三值域长度0..3的40种底层序列，配合长度0..5的364种peek/next/hasNext程序，共14560组；仅执行每个程序的合法前缀，再排空剩余值检查没有丢失或重复。另测1000项、重复peek、0值、负值及空底层扩展。
