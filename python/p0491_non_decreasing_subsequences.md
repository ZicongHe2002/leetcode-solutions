# 491. Non-decreasing Subsequences · Python

[原题](https://leetcode.com/problems/non-decreasing-subsequences/)。

列出数组内所有长度至少2、数值非递减的不同子序列，允许相等值，必须保留原下标顺序，结果顺序不限。原题数组长1..15，值在-100..100。相同数值序列只输出一次，不按下标方案重复计数；输入保持，空数组额外返回空列表。

path保存已选择的非递减前缀，search(start)只考虑更靠右的下标。只要新值不小于path末项就可加入，递归后弹出；长度至少2时复制path到结果，不能保存同一可变列表引用。不能先排序nums，因为排序会改变合法子序列的顺序条件。

used是本次search调用内独立的集合，同一层同值只选最早可用下标。若改选后面相同值，能继续使用的后缀下标是前者后缀的子集，值前缀相同，所以不会产生新的值序列；保留最早选择覆盖所有可能。used不跨递归层共享，同一个值仍可在更深层再次选择，从而保留[7,7]等合法非递减序列。

最多2^n种下标子集，分支扫描与复制输出给出O(n*2^n)时间上界。结果本身最坏占O(n*2^n)。除结果外，递归深度和path为O(n)；活跃层的used集合合计也是O(n)：某层只扫描到当前所选下标，下一层从更右下标开始，各活跃层已扫描区间互不重叠，重复值只会减少集合项。因此辅助空间为O(n)，没有为每个输出保留额外全局去重集合。

独立参考枚举全部下标子集，按原序取值，直接检查每一对相邻值是否非递减，再用元组集合去重，不使用逐层回溯选择。-1/0/1、长度0..7全部3280个数组对照，空数组为扩展。另测15个严格递增值的32752个结果、全相等值、严格下降、-100/100边界，检查无重复、列表接口与输入保持。未向LeetCode提交。
