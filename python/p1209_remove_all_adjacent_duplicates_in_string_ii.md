# 1209. Remove All Adjacent Duplicates in String II · Python

[原题](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string-ii/)。

原题s长1..100000，仅小写英文字母；k为2..10000。每次删除k个相邻相同字母，两侧重新连接；原题保证反复删除后的终态唯一，返回str。k大于文本长度时也属于合法输入。

runs是已读前缀的终态连续段栈，每段计数在1..k-1。新字符只可能延长栈顶同字母段，否则新增一段；一旦段长达到k就整体删除。删掉栈顶后露出的前缀本身已不可删除，后续字符又能继续与其合并，因此跨删除段的级联同样被覆盖。所有操作都是合法k删除，最终没有满k段，结合唯一性得到答案。每字符只处理一次，拼接输出长度不超过n，时间O(n)，额外空间O(n)。

独立参考枚举小文本所有长度k且全相同的删除位置，递归收集全部终止文本。长度1..8的a/b文本共510个，分别k=2/3/4/9，共2040次核对；另测10万长度、k=10000、不到整组的余数、级联删除、完全不可删交替及原题样例，核对str。
