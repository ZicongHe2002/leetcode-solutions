# 219. Contains Duplicate II · Python

[原题](https://leetcode.com/problems/contains-duplicate-ii/)。

输入整数列表nums和非负整数k，判断是否存在两个不同下标i、j，使nums[i]=nums[j]且abs(i-j)<=k。不修改输入，空列表或k=0返回False；负k不在本方法的约定内。

扫描右端right之前，集合保存下标max(0,right-k)..right-1的值。这些位置与right的距离都不超过k，因此当前值已在集合中就构成合法不同下标对。没有找到重复时才加入当前值；若right>=k，再移除right-k的值，为下一轮保留最近k个位置。

移除放在比较之后，保证距离恰好等于k的旧值仍参与本轮判断。未提前返回的窗口中没有重复值，所以集合与这些位置一一对应，remove不会误删另一个相同值的代表；若此前存在这样的重复，算法早已返回True。k=0提前返回避免将自身当成不同下标。

哈希集合操作按期望O(1)计，总时间O(n)，额外空间O(min(n,k+1))，其中加一覆盖插入后移除前的瞬时窗口。k=0时使用常数空间。这里没有要求输入有序，也不按数值差判断重复。

独立oracle枚举全部i<j的下标对，直接检查距离与相等性。穷举三值域长度0..7的3280个数组，对每个数组测试k=0..n+1。另测距离恰好等于k及刚超出k、100000项互异或重复序列、负数和大k，并核对输入保持。
