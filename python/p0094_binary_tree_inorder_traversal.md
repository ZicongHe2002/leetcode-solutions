# 94. Binary Tree Inorder Traversal · Python

[原题](https://leetcode.com/problems/binary-tree-inorder-traversal/)返回二叉树的左子树、根、右子树顺序值列表。输入为judge提供的TreeNode或None，原题0..100个节点；假设是无环、不共享子节点的有效树。`Solution.inorderTraversal`只借用节点，不改变边和值。类型注解延后求值，TreeNode定义由judge或测试环境提供。

沿current的左边向下走，把尚未输出的祖先逐个入栈。左边到底后，栈顶就是接下来应输出的节点：其左子树已完成，根应先于右子树。弹出并输出后转到它的右孩子，再重复左降。栈顶弹出发生在左降之后，此时外层条件保证current或栈原本非空；若current原本非空，它已经入栈，若原本为空，栈本来就非空，所以pop安全。

栈中的每个节点代表仍在等待“处理根及右子树”的一层递归调用。按此对应关系，输出与递归中序一致。每个节点只入栈、出栈和输出一次，时间O(n)；栈最长为树高h，工作空间O(h)，返回列表另外占O(n)。空树直接返回[]；不能以值作已访问标记，因为不同节点可以同值。

B补写节点身份账本：R(0).left=L(1)，L.left=P(1)，R.right=Q(0)，Q.right=S(-1)，其他边为空。栈左侧是底、右侧是顶；同值节点仍使用不同字母标识：

| 进入current | 左降完成后的栈 | 本轮pop | 下个current | 已输出 |
| --- | --- | --- | --- | --- |
| R | [R,L,P] | P | None | [1] |
| None | [R,L] | L | None | [1,1] |
| None | [R] | R | Q | [1,1,0] |
| Q | [Q] | Q | S | [1,1,0,0] |
| S | [S] | S | None | [1,1,0,0,-1] |

P之后current=None但栈仍有L和R，所以不能只按current判断退出。pop之前若此前current非空，左降至少压入一个节点；若此前current为空，外层成立只能因为栈非空。两种情况都保证本轮pop有元素。两个值1和两个值0分别输出，值相同不等于同一个节点。

算法只按边决定访问顺序，不依赖值的大小。对所有节点应用f(x)=-x，边不变，所以映射后遍历结果恰为原中序列表逐项取负；这是位置不变的映射性质，不是把结果逆序，也不要求f递增。B在197种小树与两条100节点链的199次check中实际加入此核验，期望来自原独立oracle或长链固定期望逐项取负。小树值−1..1、长链0..99取负后均在合法范围；先构造映射输入、再拍快照核对求解器保持边和值，finally恢复原值后再次核对原快照。
