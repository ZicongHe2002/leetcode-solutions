# 16. 3Sum Closest · Python

[原题](https://leetcode.com/problems/3sum-closest/)。

原题nums长3..500，每项-1000..1000，target在-10000..10000，选三个不同下标，使和最接近target并返回这个和。原题保证最近答案唯一，测试不对两个不同和等距的输入额外规定输出。实现排序副本，调用者列表保持原顺序。

固定排序后的first，在其右边用left/right搜索剩余两数。先用当前和更新best，再按与target的大小移动指针：若和偏小，固定left并把right左移只会得到更小的和，其距离不会优于刚检查的值，因此可以淘汰当前left；偏大时同理淘汰当前right。每次移动先保留被淘汰区域的最佳候选，遍历全部first后best即全局最近和，碰到精确target可立即返回。排序不会改变三个下标必须不同的条件，因为first<left<right。

排序O(nlogn)，双指针总计O(n²)，额外空间O(n)用于排序副本。Python整数直接计算绝对距离，target可远在三数和范围以外。

独立oracle枚举不同下标的所有三元组，直接求所有和与target的距离。五种值、长度3..6共19500个数组，各测五个target，其中94120次具有唯一最近和；3380个等距查询不在原题唯一保证内，明确跳过。最大长度500覆盖两端极值、target正负10000与精确最近值，核对int及输入保持。
