# 763. Partition Labels · Python

[原题](https://leetcode.com/problems/partition-labels/)。

输入为1..500个小写英文字母，把字符串按原顺序分成尽可能多的非空连续部分，使每种字母只出现在其中一部分，返回各部分长度。本实现额外支持空字符串返回[]。

先记录每种字母的最后位置last。从当前部分起点start开始扫描，end是本部分已见字母的最晚末次出现位置。若index<end，切开会让至少一种已见字母跨越边界，不能结束；若index=end，已见字母的全部出现都已经包含，当前位置是当前部分最早合法切点。选择最早切点不会与后面的字母产生关联，留下的后缀可以独立继续分割；任何更晚的首次切点只会合并若干原本可以分开的部分，因此贪心达到最多部分。新部分从index+1开始。时间O(n)，不计输出的额外空间O(σ)，σ最多26；结果存储上界O(n)。

独立oracle枚举全部切割位掩码，对完整分割建立字母所属部分表，排除同字母跨部分的方案，再取部分数最多的一项，不使用last末次出现或最早切点。枚举a/b/c上长度0..7的全部3280个字符串。边界覆盖500个相同字母、26个互异字母、500字符且恰有26部分的输入、经典[9,7,8]样例及空扩展。
