# 573. Squirrel Simulation · Python

[原题](https://leetcode.com/problems/squirrel-simulation/)。

height和width在1..100，坚果数1..5000，坐标位于花园中。松鼠从squirrel出发，每次最多携带一个坚果，四方向走到相邻格，必须将全部坚果逐个送到tree，求最少移动数。无障碍，两个格之间的最短路是行列差绝对值之和；这种路径能留在矩形花园内，所以无需分配网格或使用面积做状态。height/width只描述合法坐标范围，不改变距离公式。输入坐标与列表保持，不定义空nuts。

先假想每个坚果都从树出发取回，其总成本为sum(2*树到坚果的距离)。真实行程只有第一次取坚果的出发位置不同：首个坚果i的成本是松鼠到i再到树，其余坚果都已从树出发。首趟节省为d(tree,i)-d(squirrel,i)，从总成本中减去这个完整差值。选择节省最大的i即可，之后的取回顺序不影响总距离。

节省可以为负，仍然必须选一个坚果作为第一趟，不能把最大节省与0取大。例如一行三个格，树在1、松鼠在0、唯一坚果在2，树往返成本2而节省-1，答案3。假想松鼠已经在树下并不是免费动作。即使最短路经过其他坚果，也不要求立即拾取；容量1保证每次交付后的下一趟总是重新从树出发。

两个生成器分别累加总成本和求最大节省，各扫描N个坚果，时间O(N)，额外空间O(1)。非空合同保证max有候选，所有结果均为整数，无递归或输入修改。

独立oracle在小花园用BFS求格间最短距离，枚举全部坚果取回顺序，按松鼠→坚果→树、树→坚果→树逐段加和，不用节省公式。对1×3、2×3、3×3花园，枚举不同树/松鼠位置及剩余格中1..3个坚果的所有组合，共4962组。另测5000个不同坚果的100×100边界、负节省例、松鼠在树下及样例，核对所有输入保持。未向LeetCode提交。
