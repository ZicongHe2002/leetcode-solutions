# 909. Snakes and Ladders · Python

[原题](https://leetcode.com/problems/snakes-and-ladders/)。

原题n*n棋盘，2<=n<=20，从左下1号格起按每行交替方向编号到n*n。一次掷骰可前进1..6格且不超过终点；落格若有蛇或梯，立即跳到指定编号，但本回合只执行一次跳转，不连续追随跳转目的格的蛇梯。1号和终点格保证没有蛇梯起点。求最少掷骰次数，无路返回-1，输入保持。

BFS状态是回合结束后所在编号。枚举每个骰子落格，用divmod转换成从底部起的行与行内偏移，偶数行左向右、奇数行右向左。只读取这一个落格的跳转，再把跳后的编号当作一步边的终点；不会递归读取目的格。所有边代价均为一次掷骰，首次到终点即最短。seen记录跳转后的状态，允许蛇倒退但不重复探索循环。

共有n*n个状态，每个最多6条边，时间O(n*n*6)，辅助空间O(n*n)。

独立oracle按底部行与交替列顺序显式展开格子，再构造全部骰子加单次跳转边，用复制层的Bellman-Ford求最短路，不使用divmod映射或BFS。2*2内部格全部5种目标、3*3内部格取无跳转/回1/到9的全部组合，共2212个合法棋盘。边界覆盖20*20、一步梯子、回1死循环和必须遵守单次跳转才能到达的2步路径，核对int与输入保持。
