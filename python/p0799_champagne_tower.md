# 799. Champagne Tower · Python

[原题](https://leetcode.com/problems/champagne-tower/)。

原题0<=poured<=10^9为整数，每杯容量1，超出部分平均流向下一行左右相邻两杯。0<=query_glass<=query_row<100，行列从0开始，求该杯最终装满比例，范围0..1。只能传出超过容量的流量，未满不能凭空向下流。

row记录当前行每杯累计收到的量，允许超过1；对每杯传给两个孩子的量为max(0,(amount-1)/2)。新建全0的下一行累加两侧父杯贡献，整行完成才替换row，避免同层新流量被再次向下使用。第0行仅接收poured，逐层守恒地传出剩余流量，归纳可知到查询行即得到正确到达量；最终用min(1,amount)截取杯内保留量。若过早把row截为1再算溢出，会丢失继续向下的流量。

设r=query_row，处理1+...+r个杯，时间O((r+1)^2)，同时只保存相邻两行，额外空间O(r+1)。使用float返回，不将每杯整数截断。验证使用精确Fraction参考量和1e-10绝对容差，不声称浮点计算没有舍入误差。

小域oracle逐杯倒入1单位，队列传播真实溢流事件，每杯用精确Fraction保留容量内的量，完全独立于按行总量滚动。poured=0..30、行0..7所有杯共1116查询。大域另用记忆化逐杯追溯父杯的精确有理数到达量，核对0/1/2/3/4/100000009/10^9在第99行全部100杯及官方例，覆盖塔底、边杯和饱和。未向LeetCode提交。
