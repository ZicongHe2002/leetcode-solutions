# 519. Random Flip Matrix · Python

[原题](https://leetcode.com/problems/random-flip-matrix/)。

初始m*n矩阵全0，flip均匀随机选择一个当前为0的格子，将它置1并返回[row,column]；reset恢复全0。原题行列1..10000，flip/reset合计最多1000次，保证每次flip前至少一个空格。不构造可能含10^8格的完整矩阵。

把格子编号为row*n+column。虚拟数组的前remaining个位置始终与全部空格编号一一对应，初始位置等于编号；remap只保存偏离初始映射的槽位。每次在0..remaining-1均匀抽一个槽，先读出其编号，再把末尾有效槽的编号移到该槽，缩短有效范围。这是只保存改动槽位的Fisher-Yates交换删除。

remaining先减1后就等于原末尾槽下标。读取chosen时尚未改写index，末尾取值也在写入前读取；最后删除末尾槽映射，避免保存已失效槽。抽中末尾自身时，写入后同一键又被删除，也保持正确。返回编号再按列数整除/取模，不让二维坐标影响抽样权重。

因为有效槽与空格是双射，均匀抽槽就均匀抽空格；删除一个槽后该不变量继续成立，不会重复返回已翻格。reset清除映射并恢复remaining，就重新得到全部初始编号，不保留上一轮翻转状态。

若K是自上次reset以来翻转次数，flip平均O(1)时间，映射O(K)空间；reset清理字典需O(K)时间，不能把Python clear写成严格O(1)。整段调用中清理项可归到此前插入的翻转，故不分配或扫描整个矩阵。随机源使用标准库randrange的均匀离散抽样。

验证不靠频率近似。对至多6格的小矩阵，枚举每一步全部合法槽选择，共1481条完整抽样分支；每条分支概率均为1/(格数!)，所得完整输出排列恰好覆盖所有排列各一次，所以也核验了条件均匀性。另用固定种子验证重复reset后再次覆盖全部格子，以及10000*10000矩阵恰好1000次API调用内的唯一性、坐标和稀疏映射规模。没有声称统计测量随机源质量，也未向LeetCode提交。
