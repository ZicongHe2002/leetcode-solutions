# 693. Binary Number with Alternating Bits · Python

[原题](https://leetcode.com/problems/binary-number-with-alternating-bits/)。

原题n在1..2^31-1，检查无前导零二进制表示中相邻位是否都不同，返回bool；只有一位的1自然符合，0不在输入范围。

n XOR (n>>1)的最高位一定为1，其余每位表示原整数对应相邻位是否不同。因此原数交替当且仅当这个差异值从最高位到最低位全部为1。正全1值x加1会变为更高一位1、低位全0，故x & (x+1)==0；反过来若x中有0截断了末尾连续1，进位停止后的更高1仍在两数中保留，AND不会为0。原题保证n正数，所以差异值也为正。实现无循环；固定31位输入下时间和额外空间O(1)。

独立参考格式化无前导零二进制文本，直接检查每对相邻字符是否不同。穷举1..65535；另构造1..31位交替串、翻转其中每一位后的合法正值、全1和最高单1，参考以翻转后实际有效位为准，核对bool。
