# 452. Minimum Number of Arrows to Burst Balloons · Python

[原题](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)。

原题有1..100000个闭区间气球，-2**31<=start<end<=2**31-1，一支竖直箭在start<=x<=end时击穿气球。求击穿全部气球的最少箭数。端点相接可以共用一箭；实现保持输入，额外支持空列表返回0。

按右端点升序，把第一支箭放在最早结束气球的右端点。所有能覆盖这个气球的可行箭，都可右移到此处：已经处理的区间不用考虑，未处理区间的右端点不更小，原来覆盖它们的箭右移后若仍在它们起点右侧就继续覆盖。对于本来覆盖最早结束气球的那支箭，其覆盖的每个未处理区间起点不大于原箭位置，因此右移不丢覆盖。固定这支箭、删除被覆盖气球后重复交换即可得到最优解。扫描时若start>上次箭位置，当前气球尚未覆盖，必须增加一箭；相等时继续共用。时间O(n log n)，辅助空间O(n)，包括sorted副本。

独立oracle从全部端点枚举射击位置子集，直接检查每个闭区间是否至少被一个位置覆盖。任意可行解的箭可移动到它所覆盖区间交集的端点，故有限枚举足够。6种小区间、长度1..4全部1554个序列核对。边界覆盖100000个分离区间、全部重复、接触端点和32位端点极值，核对int与逐行输入保持；空列表为扩展。
