# 487. Max Consecutive Ones II · Python

[原题](https://leetcode.com/problems/max-consecutive-ones-ii/)。

二进制数组最多把一个0翻成1，求可得到的最长连续1长度。原题数组长1..100000，每项0或1；允许不翻转，全1数组返回原长度。输入保持；空数组额外返回0。

任一可用一次翻转变成全1的连续区间，恰好是其中0的数量不超过1。用left/right维护这样的窗口，zeros记录真实0数；新右端若让0数超过1，就逐个移出左端，直到再次合法。不能遇到第二个0只缩一步，也不能把题目误解为必须删除一项。

对于固定右端，收缩结束时left是能保留的最早起点，所以该窗口是当前右端下的最长合法候选。被丢弃的更早起点已包含至少两个0；右端继续向右不能让它重新合法。因此扫描所有右端并取最大长度覆盖全部最优候选，不需要实际改写任何元素。

每个元素最多从右端进入一次、从左端移出一次，时间O(n)，辅助空间O(1)，仅保存三个计数与迭代位置。两个布尔表达式直接作为0/1更新计数，返回值仍为整数。

独立参考枚举不翻转或实际翻转某个0的位置，对每种选择重新从头扫描连续1段，不维护窗口或0预算。长度0..12全部8191个二进制数组对照，空数组为扩展。另测100000长度全0/全1、单0连接、两个相邻0与交替数组，核对int及输入保持。未向LeetCode提交。
