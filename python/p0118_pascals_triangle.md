# 118. Pascal's Triangle · Python

[原题](https://leetcode.com/problems/pascals-triangle/)。

原题1<=numRows<=30，返回杨辉三角最前面的numRows行。第0行为[1]，第r行有r+1项，两端为1，每个内部元素是上一行相邻两项之和。

逐行创建长度level+1且初值为1的新列表，只更新内部位置。生成当前行时上一行已完整确定，因此每个内部项可直接相加，边界保持1。把新行加入结果后重复，归纳得到每行都满足定义。每行单独创建，不把同一可变行反复追加。

返回r行需要r*(r+1)/2个整数，时间O(r*r)，总空间O(r*r)，主要就是结果三角，没有构造额外二维工作表。

独立oracle使用math.comb(r,c)的组合数定义，不递推上一行。原题全部30种行数分开核对：1..29在枚举测试中检查，30在上限测试中完整检查。最大结果还验证各行左右对称、行和为2**r、两端为1及返回元素均为int。
