# 13. Roman to Integer · Python

[原题](https://leetcode.com/problems/roman-to-integer/)。

原题输入长度1..15，仅含I/V/X/L/C/D/M，保证是1..3999内的有效标准罗马数字。任务是解码已有有效表示，非法顺序或任意拼接符号不属于输入合同。

从左到右读取字符。如果当前值小于下一个字符，它就是合法减法对的前半部分，先减去；否则直接加上。下一个较大的字符在其自己的轮次会被加上，因此IV得到-1+5，CM得到-100+1000。有效表示保证升序相邻处只属于规定减法对，不必另外猜测或修复非法形式。

每个符号恰贡献一次，局部加减与标准罗马数字的分段含义相同，累计和就是原整数。时间O(s长度)，辅助空间O(1)，固定7符号查表。

测试用独立的十进制位标准编码表生成1..3999的全部有效输入，再要求解码回各自整数，不依赖另一题实现。额外覆盖6种减法对、最大值和最长15字符的纯加法组合。返回必须为int；没有把非法罗马数字的未定义表现写成已支持验证功能。
