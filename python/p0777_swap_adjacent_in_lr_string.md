# 777. Swap Adjacent in LR String · Python

[原题](https://leetcode.com/problems/swap-adjacent-in-lr-string/)。

原题两个等长字符串，长度1..10000，仅含L/R/X。只允许把相邻XL改为LX，或把RX改为XR，即L只能穿过空位向左、R只能穿过空位向右。判断start能否变为end，不是任意相邻交换。

双指针分别跳过两个串中的X，逐个匹配非空字符。匹配字符必须相同，保证L/R的相对次序不变；匹配L的起始下标必须>=目标下标，匹配R的起始下标必须<=目标下标。如果一边先耗尽非X字符，另一边仍有字符就返回False；两边同时到末尾才成功。

这些条件必要，因为每次操作只与X交换，L与R不能互相越过，而且各自移动方向固定。它们也充分：先从左到右把每个L移到目标位置，之前的L已定位在它前面，原先在它前面的R起点不超过其目标，而R目标仍在该L目标之前，不会挡住L所需路径；之后从右到左把R移到目标位置，后面的字符已在合法目标一侧，路径中的空位允许逐个右移。因此满足次序和方向限制就能通过合法操作完成，不必实际模拟指数级路径。

每个指针只前进，时间O(n)，除输入外空间O(1)。不构造去X副本，不对字符串排序，保持大小与字符合同。

独立oracle对每个短start用显式XL->LX/RX->XR替换搜索整个有向可达状态图，再查每个end是否可达，不使用非X顺序或方向不等式作为oracle。三字符长度1..6全部597870个有序字符串对均核对。边界覆盖官方例、10000字符单L或单R跨空位的正反方向、全X、L/R试图交叉及相同字符串，检查bool。未向LeetCode提交。
