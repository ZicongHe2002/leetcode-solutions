# 959. Regions Cut By Slashes · Python

[原题](https://leetcode.com/problems/regions-cut-by-slashes/)。

原题grid为1..30的n×n字符方阵，每格只含正斜杠、反斜杠或一个空格，求正方形内部被分开的连通区域数。字符串内的空格是实际格子，不能strip。输入保持，返回int。

每格分成上、右、下、左4个三角形。空格把四片全连；正斜杠把上左连、右下连；反斜杠把上右连、下左连。相邻格共边的两片必须连通，代码只接上邻和左邻，恰好覆盖每个格边一次。斜线只在角点接触不能穿越，三角片模型不会把仅角点相遇的区域误并。所有允许相通的片归并后，并查集分量数就是内部区域数，不添加方阵外部区域。

共有4n^2片，时间O(n^2*alpha(n^2))，额外空间O(n^2)。独立参考把每格扩成3×3像素，用三像素斜线作障碍，对剩余像素做四邻域洪水填充，不复用三角并查集。枚举n=1..3的全部19767个合法网格，另测30×30全空、全正斜杠、全反斜杠和交替斜线，核对int和输入字符串保持。
