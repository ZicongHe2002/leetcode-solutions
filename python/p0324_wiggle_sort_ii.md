# 324. Wiggle Sort II · Python

[原题](https://leetcode.com/problems/wiggle-sort-ii/)。

原题nums长1..50000，值0..5000，保证存在严格摆动重排，使nums[0]<nums[1]>nums[2]<…；函数原地修改并返回None，保留全部元素及重复次数。不可构造的数组不在原题范围，不能把所有相等且长度大于1的输入当合法样本。

先用随机枢轴三路快速选择找到下标n//2的中位数，重复值归在等值段，目标落在段内即可停止，不必完整排序。之后按虚拟下标(1+2*i)%(n|1)访问数组，其顺序是所有奇数位再所有偶数位。三路划分把大于中位数的值放在虚拟前部，即实际奇数峰；小于中位数的值从虚拟末端放入实际偶数谷；中位数留在两者之间。大值从左侧峰填起，小值从右侧谷填起，让重复中位数分布在剩余两端而不相邻。原题可构造保证排除重复值数量和位置使严格不等式不可能成立的情况。

每次交换后，大值分支可推进扫描，小值从末端换来尚未知元素，必须重查当前位。虚拟划分O(n)，随机选择期望O(n)、最坏O(n^2)；总期望O(n)，额外空间O(1)，没有排序副本、递归或按输入长度保存辅助数组。这里明确采用期望线性时间，并不宣称最坏保证线性。

测试独立用多重集合回溯枚举判断小数组是否可构造，再只核对合法输入的元素频次、逐相邻严格摆动和None返回。值0/1/2、长度1..7共2093个可构造输入，分别在首端枢轴、末端枢轴、固定随机枢轴3种策略下测试，共6279次。另测50000/49999长度重复值、5001个不同值及值域两端，固定随机种子使测试可复现。无在线Accepted记录。
