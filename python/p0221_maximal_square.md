# 221. Maximal Square · Python

[原题](https://leetcode.com/problems/maximal-square/)。

输入为1..300行、1..300列的矩形字符矩阵，每项是'0'或'1'，返回全1正方形的最大面积。目标是面积，不能返回边长或最大矩形面积。本实现保留输入，额外支持空矩阵返回0；整数1不作为合同内字符'1'处理。

滚动数组lengths[column]记录以对应格子为右下角的最大正方形边长。当前为0就必须重置0；为1时，当前边长是上方、左方、左上方三个旧/新边长的最小值加1。这三个正方形连同当前格子覆盖了所需的新正方形；反过来，若能形成边长k，三个邻居必须各至少能形成k-1，故这个最小值同时是可达界与必要界。保存above再更新，最后把diagonal设为旧above，保证左上值来自上一行。第0列哨兵始终为0。largest保存全局边长，最终平方成面积。时间O(mn)，额外空间O(n)。

独立oracle枚举每个左上角与所有合法边长，直接检查候选正方形的全部字符，不使用局部三邻居递推。穷举六种小形状的666个二值矩阵，再检查全部65536个4x4矩阵，共66202个。边界覆盖300x300全1面积90000、全0、棋盘格面积1、单行300项、经典面积4例子及空扩展；逐次检查输入和行对象保持。
