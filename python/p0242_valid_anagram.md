# 242. Valid Anagram · Python

[原题](https://leetcode.com/problems/valid-anagram/)。

两串长度1..50000，字符仅小写英文字母；双空串作为扩展返回True。长度不等先返回False；否则26项计数记录当前已读s前缀的字符重数减t前缀的重数。每轮分别加一、减一保持该不变量；全部处理后每项为零当且仅当两串各字符重数完全相同，即互为字母异位词。

重复字符按出现次数计，不能只比较字符集合。时间O(n+m)，固定26项额外空间O(1)，输入字符串保持。Unicode不属于当前合同，不能把ord索引方式泛化为任意字符支持。

独立oracle对两串分别排序后比较；穷举a/b/c上长度0..4全部121个字符串，核对全部14641个有序对。边界包含50000长度、重数只差一项、值为a或z、相同集合而次数不同。
