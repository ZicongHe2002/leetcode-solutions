# 93. Restore IP Addresses · Python

[原题](https://leetcode.com/problems/restore-ip-addresses/)。

parts保存已经验证的段，递归只枚举下一段长度1..3。剩余slots段必须消耗slots..3*slots位，不满足就剪枝。多位段首0时更长也非法，数值超过255时更长也不可能，均可停止当前长度循环；到四段时只在刚好耗尽输入时保存。每种切分只有一条路径，不重复地址。最多3^4种段长分支，辅助回溯空间O(4)，不计输出；长度不在4..12时立即排除。

独立oracle枚举三个切点的全部组合，再逐段直接检查长度、前导0和数值，不复用递归剪枝。数字0/1/2、长度0..8共9841个串核对，空串为扩展。边界覆盖20位、255与256、全0、长度4和经典多个结果，核对字符串列表及无重复。
