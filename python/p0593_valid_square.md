# 593. Valid Square · Python

[原题](https://leetcode.com/problems/valid-square/)。

输入四个二维点，坐标均在-10000..10000，顺序任意。判断是否恰为四个不同的正方形顶点：边长必须正、四边等长且角均为90度。允许旋转后的正方形，不只识别与坐标轴对齐者，四个输入坐标列表保持。

固定p1，把其余三个点变为相对向量，并按长度平方排序。若四点是正方形，最近的两个向量u、v就是两条邻边，第三个w为对角线。必要条件是u长度正、v与u等长、点积u·v为0、w=u+v。相等邻边的排序先后不影响这些条件。

这些条件也充分：非零、等长且垂直的u和v从同一个起点出发，构成两条正方形邻边；u+v正好是唯一的对角顶点。此时它的长度平方为2*边长平方，自然比两个邻边大，符合排序角色。四点也必不重合。仅检查四边相等会误收非直角菱形，仅检查垂直会误收长方形，本实现同时检查全部条件。

全部使用整数的平方、乘积和加法，无平方根或浮点容差，重复点、共线点不会构成合法四顶点。只有三个向量，排序及判定的时间和额外空间均为O(1)，返回bool，不修改原点列表。

独立参考枚举四点的全部顶点环绕排列，要求四点互异、四条环边长度相同且为正、相邻边成直角，不固定输入p1的邻边或向量和。穷举3×3格点中允许重复的全部6561个有序四元组。另核对轴对齐/旋转方形、非直角等边菱形、长方形、共线与重复顶点的全部输入排列，以及正负10000坐标边界，检查bool及输入保持。未向LeetCode提交。
