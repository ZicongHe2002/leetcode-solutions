# 241. Different Ways to Add Parentheses · Python

[原题](https://leetcode.com/problems/different-ways-to-add-parentheses/)。

输入合法表达式，仅含非负整数及二元+、-、*，没有括号、空格、除法或一元符号，返回全部合法完整括号化的计算结果。相同数值来自不同括号树时必须重复保留，答案顺序不限；原题表达式长1..20，不能将输出当作数值集合去重。

以半开字符区间[start,end)为状态。枚举区间中每个运算符作为最后执行的根，将左右区间的所有结果两两组合。若没有运算符，该区间就是完整的多位整数，直接解析。每棵完整括号树有唯一根运算符及左右子树，所以枚举不漏不重；结果数值相同仍可来自不同树。

缓存放在方法内部，键是当前表达式的两个端点，缓存结果为元组，不会被外部列表修改或跨调用泄漏。区间缓存消除了重复求同一子表达式，但不能消除返回全部树结果所需的输出规模。

设n是字符数，R是全部缓存区间结果元组的元素总数，包含重复数值。扫描O(n²)个可能区间的字符上界为O(n³)；各根的笛卡尔积每次组合都生成一个结果，累计O(R)。按原题有界整数运算计，时间上界O(n³+R)，空间O(n²+R)，包括缓存、结果及递归栈。不能把缓存状态数当成总输出数而称多项式输出规模。

独立oracle从最底层开始，尝试依次合并每一对相邻子表达式，并用带原叶位置的完整括号树文本去重合并顺序；同一棵树可由多个合并顺序产生，但不同树的相同数值仍保留。穷举1..4个操作数、三种数值及三种运算符的2460个表达式。另测多位数、非交换减法、重复结果、同一实例重复调用及20字符表达式的4862棵括号树。
