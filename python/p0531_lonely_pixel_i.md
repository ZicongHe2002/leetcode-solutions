# 531. Lonely Pixel I · Python

[原题](https://leetcode.com/problems/lonely-pixel-i/)。

给定M行N列黑白图片，M、N均在1..500，每格是B或W。求所在行和列都没有其他黑点的黑色像素数量。只计黑点，输入矩阵及各行保持，不把空矩阵当作原题输入。

第一次扫描分别累计每行和每列的黑点数。一个位置恰好满足定义，当且仅当它本身为B、行黑点数为1且列黑点数为1。第二次扫描把这三个条件同时成立的位置各加1，每个位置只访问一次，不会因同时满足行条件和列条件而计两次。不能省略位置本身是B的检查，因为某行和某列各有一个黑点，并不保证它们交点就是黑色。

两次扫描时间O(M*N)，行列计数表辅助空间O(M+N)。没有逐黑点重扫整行整列，不对图片作标记或覆盖字符。

独立参考对每个B直接检查同一行其他列、同一列其他行是否还有B，不预存行列计数。1..3行、1..3列的全部682张黑白矩阵逐张对照。另测500x500对角黑点、全黑、全白、单行/单列及最小1格，核对int、矩阵值和行对象保持。未向LeetCode提交。
