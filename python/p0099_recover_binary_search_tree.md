# 99. Recover Binary Search Tree · Python

[原题](https://leetcode.com/problems/recover-binary-search-tree/)。

原题2..1000节点的BST恰有两个节点值被交换，值在32位有符号范围，须恢复值且不改变结构，原地返回None。TreeNode本地定义供测试，算法使用评测器相同的val/left/right属性。

正确BST中序严格递增。若交换的两个值在中序相邻，只出现一次逆序，交换这对即可；若不相邻，会出现两次逆序，真正错误节点为第一次逆序的前项及最后一次逆序的后项。遍历维护previous，第一次下降时固定first，之后每次下降更新second，最后只交换这两个节点的val。

Morris遍历把左子树最右节点原本为空的right暂接回当前节点，先进入左子树，第二次通过这条线回到当前节点时立刻把right恢复None，再执行一次中序访问。无左子树时直接访问。不能在找到第二次逆序后提前返回，因为还需继续撤销所有临时线；实现完整遍历后才交换值。所有原节点及left/right最终保持原样。

每条边被常数次访问，时间O(n)，额外只保存固定数量节点引用，空间O(1)，满足常数空间follow-up；没有递归栈或中序列表。

测试枚举2..7节点全部624种BST树形，在每棵树上穷举所有值交换位置，共11510次恢复。参考是交换前逐节点记录的原值及left/right身份，恢复后完全相等，不仅检查排序值。另在1000节点左/右深链测试相邻与非相邻交换、32位端点和None返回，发现残留线或共享/环时直接失败。
