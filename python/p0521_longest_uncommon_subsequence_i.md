# 521. Longest Uncommon Subsequence I · Python

[原题](https://leetcode.com/problems/longest-uncommon-subsequence-i/)。

给出两个字符串，找只属于其中一个字符串、不是另一个字符串子序列的最长子序列长度；不存在返回-1。原题两串长1..100，只含小写英文字母。这里求uncommon，而不是最长公共子序列，不需要构造动态规划表。

两串完全相同时，它们拥有完全相同的子序列集合，没有任何非常见子序列，返回-1。不能把“没有不同字符”误解释为空子序列长度0，因为空子序列同样属于双方。

两串不同时，若长度不同，较长串自身不可能成为较短串的子序列，已经给出长度max(len(a),len(b))的合法候选。若长度相同但内容不同，一个长度等于原串长度的子序列只能是不删任何字符的原串本身；因此a自身就不是b的子序列，同样达到这个长度。任何子序列都不会超过所属原串长度，这个候选同时达到上界，所以恰为答案。

Python字符串相等判断最坏线性扫描，len与取较大长度为常数操作，总时间上界O(|a|+|b|)，辅助空间O(1)，不构造任何子序列，不改输入。

独立参考枚举每个字符串的全部下标子集形成真实子序列集合，再求两个集合的对称差，取其中最长长度，空差为-1，不使用长度/相等两分法。a/b字母表、两串长度1..5共62种字符串，全部3844对核对。另测100字符相同、同长不同、长短前缀、重复字母与原例，检查int。未向LeetCode提交。
