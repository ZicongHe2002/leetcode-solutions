# 435. Non-overlapping Intervals · Python

[原题](https://leetcode.com/problems/non-overlapping-intervals/)。

原题有1..100000个区间，端点满足-50000<=start<end<=50000，要求删除最少区间使剩余区间互不重叠。端点刚好相接允许同时保留，例如[1,2]和[2,3]。实现保持输入，额外支持空列表返回0。

按结束位置从小到大扫描，保留第一个区间，再保留起点不小于上次结束位置的区间。交换论证：任意最优选择的第一个区间可替换为结束最早的区间，后面的所有可选区间仍可接上；固定该区间后对后缀重复，所以保留数量最大，删除数就是总数减保留数。相同结束位置不影响论证。Python的sorted创建新列表，时间O(n log n)，辅助空间O(n)，不原地排序。

独立oracle枚举保留子集，逐对按max(start)<min(end)判断真正相交，不按结束位置贪心。4个小端点构成6种合法区间，长度1..4的全部1554个有序区间序列核对。边界覆盖100000个相接区间、全部重复、嵌套、负端点、极端端点与输入保持；空列表为扩展。
