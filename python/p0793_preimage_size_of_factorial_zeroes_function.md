# 793. Preimage Size of Factorial Zeroes Function · Python

[原题](https://leetcode.com/problems/preimage-size-of-factorial-zeroes-function/)。

原题0<=k<=10^9，求非负整数x中x!恰有k个十进制末尾零的个数，0!=1所以k=0包含x=0。返回个数，不是返回某个x或取模结果。

阶乘中因子2比5充足，末尾零数f(x)=floor(x/5)+floor(x/25)+...。循环反复整除5累加，使用整数避免浮点精度。f单调不减，但在25等位置可能跳过某个k，因此不能假定每个k都有原像。

定义L(t)为第一个使f(x)>=t的非负x，区间[0,5t]包含它，因为f(5t)>=t；t=0时直接得到0。二分始终保留第一个可行位置，命中>=时缩右端，不能在相等时提前返回平台中点。所有恰等于k的位置正好是半开区间[L(k),L(k+1))，两次下界之差自动处理跳过值与k=0。

每次零数计算O(log(k+2))，二分有O(log(k+2))步，总时间O(log^2(k+2))、额外空间O(1)，按整数算术操作计。Python整数能表示5*(10^9+1)，不使用32位有符号中间量。

小域oracle实际累乘得到0!..500!，转十进制剥尾零，核对k=0..100；500!零数已超过100，单调性保证更大x不影响这些计数。大域用独立恒等式f(x)=(x-s5(x))/4，其中s5是五进制数位和，不做二分或逐幂商求和。任何根x<=5k+4，若该上界有d位，则4k<=x<=4k+4d；只枚举这个短区间并按数位和检验。覆盖1000种子k、5的幂附近跳跃及10^9边界。未向LeetCode提交。
