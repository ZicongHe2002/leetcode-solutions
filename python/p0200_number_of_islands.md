# 200. Number of Islands · Python

[原题](https://leetcode.com/problems/number-of-islands/)。

输入为1..300行、1..300列的矩形字符网格，每项是字符串'0'或'1'，四方向相连的陆地组成岛屿。返回岛屿数；本实现保留原网格并额外支持空网格返回0。字符与整数不同，不把整数1作为合同内陆地。

扫描到未访问陆地时计一个新岛屿，然后以显式栈穷尽该连通分量。入栈前标记visited，每个陆地至多入栈一次。路径归纳保证同一分量没有遗漏；沿四方向且只通过陆地的发现规则保证不会越过水域或把对角线当连接。完成的分量全部已标记，后续外层扫描只会在另一个分量启动，因此计数正好等于岛屿数。时间O(mn)，visited和栈最坏O(mn)，没有递归深度依赖，保留输入。

独立oracle以并查集合并陆地右邻和下邻，根的个数就是岛屿数。穷举六种小形状的666个网格及全部65536个4x4网格，共66202个。固定测试覆盖空图、单行/列、对角分离、300x300全水/全陆地、45000个岛屿的棋盘格；检查输入和行对象身份保持。
