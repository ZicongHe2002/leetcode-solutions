# 655. Print Binary Tree · Python

[原题](https://leetcode.com/problems/print-binary-tree/)。

原题树节点1..1024，值-99..99、深度受题目10的限制，返回字符串矩阵。若树有R层（根在第0层、边高度为R-1），矩阵R行、2^R-1列。根在首行正中；下一层左右孩子分别落在左右半区中心，空单元格必须是空字符串，不是0或空格。负数和多位数作为一个完整字符串存入单个格，不按字符拆列。节点由平台提供，输入保持；空树返回[]是额外扩展。

先用显式栈求真实层数，再分配各行独立的空串数组。放置节点时带上它负责的闭列区间[left,right]，节点放在中点middle，左右孩子分别负责[left,middle-1]与[middle+1,right]。初始区间长2^R-1，每次半区仍为完整二叉布局的奇数长度，其中点间距正好是题目规定的2^(height-row-1)。即使某边缺节点，它的半区也保留空白，不能因稀疏树而压缩列。

设节点数n，时间O(n+R*2^R)，矩阵本身占O(R*2^R)，除矩阵外遍历工作栈O(R)。两个显式深度优先遍历都不递归，不把填满空字符串矩阵的代价误写成O(n)。

独立oracle记录每个节点的根到节点左右路径编号p及深度d，用闭式列坐标(2*p+1)*2^(R-d-1)-1放置，不使用生产的区间二分。0..6节点所有树形与-99/99标签共10067种输入（含空树扩展）完整比较矩阵。边界检查10层左/右链、1023节点完全树、0与负数、空单元格、独立行对象以及全部原值/边保持；没有LeetCode提交记录。
