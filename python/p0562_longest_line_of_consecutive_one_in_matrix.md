# 562. Longest Line of Consecutive One in Matrix · Python

[原题](https://leetcode.com/problems/longest-line-of-consecutive-one-in-matrix/)。

输入为m×n二进制矩阵，1<=m,n<=10000且m*n<=10000。求连续1构成的最长直线，方向包括水平、垂直、主对角线和反对角线，不能转弯。返回长度，保持输入。实现额外将空矩阵和零列矩阵定义为0；不支持不等长行。

从上到下、从左到右处理。horizontal表示本行以当前格结束的连续1长度，vertical[column]表示该列以当前格结束的长度。遇到0，两者归零。遇到1，分别在左边和上边的长度基础上加1。

对角线必须读取上一行。diagonal[j]对应上一行第j-1列结束的主对角线，因此当前第j列写入next_diagonal[j+1]；anti_diagonal[j+1]对应上一行第j+1列结束的反对角线，因此当前结果写入next_anti_diagonal[j]。两端的额外0作为越界前驱，每一行新建结果数组，0格自然截断，不会把本行刚写入的数据当成上一行。取四个方向的最大值，每条非空连续直线都以某个1格结束，故覆盖全部答案。

每格常数次操作，时间O(m*n)；各方向仅保留一行，额外空间O(n)。方向数组在换行后替换，不修改mat。反对角线虽然向左下延伸，前驱仍在上一行右边，不能误用左边前驱。

独立oracle从每格出发向四个方向逐格行走，不保存动态规划状态。穷举1..3行、1..3列及2×4/4×2的全部1194个二进制矩阵；另测10000格长行/长列、100×100全1、两种对角线和中间0断开，检查输入保持和整数返回。未向LeetCode提交。
