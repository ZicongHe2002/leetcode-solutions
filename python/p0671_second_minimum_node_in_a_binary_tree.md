# 671. Second Minimum Node In a Binary Tree · Python

[原题](https://leetcode.com/problems/second-minimum-node-in-a-binary-tree/)。

原题为非空特殊二叉树，1..25个节点，每个节点恰有0或2个孩子，值在1..2^31-1，内部节点值等于两个孩子值的较小者。求全树不同值中的第二小值，只有一种值时返回-1。TreeNode由平台提供，节点、值和孩子指针均保持。这里依赖特殊树合同，不是任意二叉树求第二小值的通用剪枝。

每条父子边上值都不下降，所以根值minimum是全树最小值。用栈访问节点：若值等于minimum，仍可能在下面找到更大值，需要继续访问它的两个孩子；若已经大于minimum，就把它作为第二小候选并停止深入该子树。它的所有后代都不小于它，因此不可能改善这一候选，也不会漏掉更小的第二值。

second保存所有已遇到的大于根值的候选最小值，用None表示尚未找到，避免与合法最大值2^31-1冲突。栈清空后有候选就返回，否则所有可达分支都没有更大值，返回-1。每个节点最多入栈一次，时间最坏O(n)，DFS栈空间O(h)，最坏O(n)。不递归，不修改树，也无需收集并排序全部值。

独立oracle遍历全部节点后对不同值集合排序，不做候选剪枝。枚举1..5个叶子的所有有序满二叉树形状，并给叶子赋1/2/5，内部值按合同生成，共3873棵合法树；另核对200棵固定种子、最多13叶/25节点的树，25节点梳状树、全同值及最大整数候选。每次保存并核对所有节点值与左右孩子身份。
