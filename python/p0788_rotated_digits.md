# 788. Rotated Digits · Python

[原题](https://leetcode.com/problems/rotated-digits/)。

原题1<=n<=10000，统计1..n中每一位都能独立旋转、且旋转后整数与原数不同的好数。0/1/8保持，2与5互换、6与9互换，3/4/7非法。各数字位置保持，不是把整个数字的顺序反转。

逐个整数按十进制取末位。遇3/4/7立即退出该数的扫描，不计入结果；看到2/5/6/9就标记changed。只有全部位都检查完时才累加changed，所以合法但完全没变化的1、8、18等不计数，先看到变化位后又发现非法位的32等也不误计。Python的while-else仅在没有break时执行，明确对应所有位均合法。

每位合法且至少一位改变是好数的充要条件：合法映射逐位置产生等长数字，首位的非零合法数字仍映成非零，不存在前导零造成等值问题；任一位置改变即得到不同数字。循环从1开始，因此0不需要作为独立候选处理。

每个数最多检查O(log(n+1))位，总时间O(n log(n+1))，原题有界整数下额外空间O(1)。不保存所有前缀状态或全部好数，也不修改外部状态。

独立oracle实际对十进制文本逐字符查旋转映射，拼出旋转后的完整文本，再与原文本比较；非法字符直接拒绝，不用生产中的算术取位和changed判据。为1..10000所有整数建立真实旋转计数表，再核对全部1..500上界、100个固定种子上界、最大上界与官方例。另以7^d-3^d闭式核对9/99/999/9999边界；10000本身不改变所以仍为2320。未向LeetCode提交。
