# 990. Satisfiability of Equality Equations · Python

[原题](https://leetcode.com/problems/satisfiability-of-equality-equations/)。

原题1..500条长度4的关系，形式为小写变量x==y或x!=y，变量可相同，判断是否有整数赋值同时满足。返回bool，输入保持，不定义非法关系字符串。

先合并所有等式，计算等价关系的传递闭包，再检查每条不等式。若不等式两端属于同组，该组必须同值，矛盾；若所有不等式都跨组，给每组分配一个不同整数即可满足全部关系，因此检查充分且必要。必须先处理完整等式集合，不能在读取顺序里提前把尚未合并的变量当作永不相等。自等式恒可满足，自不等式自然判False。

并查集只有26项，按大小合并、路径减半，时间O(26+m*alpha(26))，固定字母表下额外空间O(1)。独立参考对a/b/c穷举0/1/2赋值；至多3个变量的任意整数相等分组都可由这3个值代表。8种基本关系组成长度1..4的4680个序列逐个核对，另测500条关系、26字母传递矛盾/可满足链、自等式和自不等式。没有在线Accepted记录。
