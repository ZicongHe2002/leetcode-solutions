# 1047. Remove All Adjacent Duplicates In String · Python

[原题](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/)。

原题字符串长度1..100000，仅含小写英文字母。一次删除两个相邻且相同的字母，直到无法删除，原题保证最终字符串唯一，返回str，可为空。

remaining保存已读前缀消除后的无相邻重复结果。新字符若等于末尾，就能删除这两个字符；否则只需追加，因为原前缀已经没有可消除对，新产生的对只能跨越末尾边界。弹出后留下的前缀原先也无相邻重复，故不变量保持。扫描所得结果由合法删除得到且不可继续删除，利用题目给出的唯一性可知就是答案。每字符至多压入弹出一次，时间O(n)，额外空间O(n)，包含结果构造。

独立参考对小文本枚举每个合法删除位置，并递归收集所有终止文本，核对结果集合恰为实现返回的单一字符串；不使用栈消除作为参考。长度1..7的a/b/c文本共3279个；另测100000字符不变交替、全相同、跨整段级联和原题样例，核对str。
