# 787. Cheapest Flights Within K Stops · Python

[原题](https://leetcode.com/problems/cheapest-flights-within-k-stops/)。

原题2<=n<=100，节点编号0..n-1，航班数0..n*(n-1)/2，票价1..10000，同一有向边不重复，src与dst不同，0<=k<n。最多k次中转表示最多k+1条边，求最小费用，不可达为-1。输入航班数组保持。

第r轮之后cost表示使用至多r条边的最小费用。每轮先复制旧cost保留更短路线，然后每条边只从旧cost读、向updated写，保证同一轮不会把多条新边连锁使用。执行k+1轮即覆盖允许的全部路线；原地更新会受到航班排列顺序影响并越过停靠限制。含每轮n项复制的时间O((k+1)*(n+E))，辅助空间O(n)，E为航班数。

独立oracle枚举允许边数内的全部行走路径并直接累加票价，不使用DP。3节点的233个小有向图满足原题边数上界，正票价1或4，全部起终点和k共4194次查询核对。边界覆盖100节点、最大4950条航班、99边链、0次中转与更便宜却超停靠数的路线，核对int及航班输入保持。
