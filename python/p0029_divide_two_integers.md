# 29. Divide Two Integers · Python

[原题](https://leetcode.com/problems/divide-two-integers/)。

原题dividend、divisor为有符号32位整数，divisor非0；不用乘、除、模运算，商向0截断，超出32位则截断到边界。实现只支持此合同，返回int。唯一可能溢出的合法商是-2147483648除以-1，直接返回2147483647。

取绝对值可能产生32位有符号范围之外的2147483648，因此把被除数和除数统一留在非正域。block表示除数的负倍增块，weight为对应的负商位，二者从除数本身和-1开始。只有block不小于最小整数的一半时才尝试翻倍，先验边界检查保证block+block仍可表示；若余量足以容纳翻倍块就一起翻倍。

之后从最大块向小块遍历。remaining<=block表示余量的绝对值至少为块的绝对值，可以减去该块并把负weight累入quotient。剩余块与weight每次右移一位，撤销一次确切倍增；到weight=-1处理完后退出，避免负数右移-1永不变的陷阱。已选择块加上remaining始终等于原负被除数，遍历完除数单位块后余量绝对值小于除数，所以所得绝对商向0截断。quotient保持非正，最后按符号返回；除已提前处理的溢出例外，所有中间算术值及结果均在32位有符号范围内。

倍增和还原各最多32轮，按一般数值规模为O(log(|dividend|+1))时间、O(1)额外空间；没有乘除模运算。独立参考用非负整除求绝对商，再加符号并截断，避免Python负数整除向下取整差异。枚举257个被除数-128..128与64个非0除数-32..32，共16448次比较；另测32位上下限、半下限附近和符号组合。AST检查实现没有乘、除、整除、模运算符；没有LeetCode在线记录。
