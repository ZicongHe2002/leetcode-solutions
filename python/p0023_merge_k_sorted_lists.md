# 23. Merge k Sorted Lists · Python

[原题](https://leetcode.com/problems/merge-k-sorted-lists/)。

原题k在0..10000，每表长0..500、各自非递减，节点值-10000..10000，总节点N<=10000。按独立链表输入理解，各表无环且不共享节点；实现重连原节点形成一条有序链，不改节点值，也不替换lists数组里的头引用，原各表next会被重接。本文件ListNode用于本地导入，对接评测器相同val/next接口。

堆中只保留每条未耗尽链的当前头。全局最小剩余节点必是某条链的头，因此弹出堆顶就是下一个输出节点；随后保存并放入该节点原后继，保持不变量。元组按val再按链下标比较，同一链最多有一个堆项，避免值相同时比较不可排序的ListNode；相同值按原链编号稳定输出。所有节点弹出一次，最后显式把tail.next设为None，空输入也自然返回None。

设非空链数为h，含初始扫描的时间O(k+N log(h+1))，堆额外空间O(h)，除哨兵外不新建输出节点。测试参考把所有原节点按val稳定排序，而非复制多路堆算法。枚举20种长度0..3、值-1/0/1的有序链，组合k=0..3共8421组；另测10000条单节点链、20条各500节点链和10000条空链。核对确切节点顺序、链尾、值以及lists头引用保持。
