# 767. Reorganize String · Python

[原题](https://leetcode.com/problems/reorganize-string/)。

原题s长1..500，仅含小写英文字母，要求重排后相邻字符不同，可返回任意合法排列；无解返回空串。若最大频数超过ceil(n/2)，其他字符不足以填入其相邻副本之间，必然无解，先直接返回空串。

堆按负频数取剩余最多的可选字符。上次使用的字符及剩余负频数先保存在堆外，取出本次字符后才把上次字符放回，保证不会连续取同一字符。当前频数加1表示消费一份，再作为下一轮的隔离字符；频数为0就不重新入堆。输出顺序不要求字典序最小。

可行性用剩余容量不变量说明。剩余t个字符、上一字符为p时，需要p的剩余数不超过floor(t/2)，其他字符各不超过ceil(t/2)。初始没有p，最大频数预检满足条件。选剩余最多的非p字符q后，q减一，满足新隔离容量floor((t-1)/2)。其他字符在t为偶数时容量不变；t为奇数时容量下降一，但若另一个非p字符仍有ceil(t/2)份，q至少同样多，两者总数会超过t，矛盾；原p本来就满足较小容量。因此不变量保持，非空余量不会只剩被隔离字符，最终堆循环能消费所有字符。

设不同字符数K<=26，时间O(n log(K+1))，额外空间O(n+K)含输出列表与堆。原题保证非空，不额外定义空输入的max行为。

独立验证先枚举三字符字母表所有候选输出，把相邻不等的字符串按完整排序签名记录为可行多重集；再对长度1..8的全部9840个输入查这一穷尽集合。非空结果逐项核对原字符计数、长度与相邻不等，不限定某个有效答案，也不用最大频数条件作小域oracle。另核对500字符、奇偶临界频数、26字母和官方例。未向LeetCode提交。
