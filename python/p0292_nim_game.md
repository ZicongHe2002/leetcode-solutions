# 292. Nim Game · Python

[原题](https://leetcode.com/problems/nim-game/)。

单堆n颗石子，两人轮流取走1..3颗，取到最后一颗者获胜，双方都采取最优策略。原题n为1..2^31-1的整数，求先手是否必胜，不扩展到多堆、不同可取数量或拿最后一颗输的变体。

1、2、3可直接取完而获胜，4无论取多少都会给对方留下1..3。归纳地，4k是必败态：任何合法一步都到达非4倍数，而对方可以取互补数量让这一轮两人合计取4。非4倍数则能先取n%4颗，交给对方4的倍数。之后持续互补取法，最终由自己取到最后一颗。

因此判断n%4是否非0即可。原题整数宽度有界，时间和额外空间均为O(1)。不能因为总石子数很大就枚举每次取法，也不能把“存在一个取法获胜”误换成“所有取法都获胜”。

独立oracle从0颗的无合法行动败态出发，枚举每个石子数的全部合法取法，按是否能到达败态进行逆向动态规划；不使用模4公式生成期望。核对1..1024全部石子数，并覆盖最大32位正整数附近的完整四余数组及bool返回类型。
