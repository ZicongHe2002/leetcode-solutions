# 730. Count Different Palindromic Subsequences · Python

[原题](https://leetcode.com/problems/count-different-palindromic-subsequences/)。

原题s长度1..1000，只含a/b/c/d。统计不同的非空回文子序列字符串，按10^9+7取模。同一个字符串由不同下标组合产生仍只算一次；不是回文子串数，也不是按下标计数。

counts[left][right]表示闭区间中的不同非空回文串数，单字符为1，空区间为0。端点字符不同时，答案是去掉左端与去掉右端的集合并集，内部区间被重复计数一次，因此相加后减去inner。端点相同时记该字符为c：每个内部回文p既可原样保留，也可包成cpc，再考虑新字符串c、cc，先得2*inner+2，随后需要去重。

预先记录每个位置前一次和后一次相同字符的位置。对于相同端点，first为左端之后首个c，final为右端之前末个c。若first>final，内部没有c，上述新增字符串与内部集合不重合，保留+2；若相等，内部只有一个c，只有单字符c重复，改为+1；若first<final，内部已有c和cc，并且所有在first与final之间的回文q都已生成cqc，这部分与外层包裹重复，最终为2*inner-counts[first+1][final-1]。

左端从右往左，右端从左往右填表，转移需要的短区间都已完成。二维表对角线下保持0，表示长度2转移或相邻内部同字符之间的空区间。每次写入取模，包含减法的分支也落在合法模范围，模运算与这些加减转移一致。

预处理相同字符邻居O(n)，填表O(n²)，空间O(n²)。邻居已预计算，每个区间不再线性寻找首末同字符；没有递归深度问题。输入字符串保持，返回int。

独立oracle枚举所有非空下标子集，真正构造对应字符串，按与反串相等判断回文，最后放入字符串集合去重，不使用区间递推。a/b/c长度1..7全部3279个字符串核对；另核对官方多重重复与取模样例、内部同字符0/1/多个分支，以及长度1000的单色、两色分块、两侧a夹b闭式答案。未向LeetCode提交。
