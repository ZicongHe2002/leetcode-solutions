# 717. 1-bit and 2-bit Characters · Python

[原题](https://leetcode.com/problems/1-bit-and-2-bit-characters/)。

原题bits长1..1000，仅0/1且末位保证为0。单比特字符编码为0，双比特字符编码为10或11，判断最后字符是否必须是单比特字符，返回bool，输入列表不变。

index总是指向下一个完整字符的开头。开头0只能取单比特、前进1，开头1只能取双比特、前进2，所以整个解析唯一，位值加1恰是本字符长度。扫描到最后一位附近即停；若恰停在最后的0，它是单比特开头，返回真；若跳到数组末尾，则最后0属于前一个10，返回假。末尾0保证前面的1有可用后继，不会留下无字符可解的单1。时间O(n)，额外空间O(1)。

独立参考从三个完整码字0、10、11生成长度不超过12的全部编码串，并记录最后码字长度；相同串出现时必须记录一致，不使用位值跳步求参考。对长度1..12且末位0的全部4095个二进制数组逐一核对。另测1000位、全0、长串1的奇偶尾段和重复双比特模式，检查bool与输入保持。
