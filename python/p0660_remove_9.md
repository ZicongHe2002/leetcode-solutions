# 660. Remove 9 · Python

[原题](https://leetcode.com/problems/remove-9/)。

原题把正整数中十进制含9的数全部删除，返回剩余递增序列中第n个数，1<=n<=800000000，排名从1开始。返回整数，不是某个九进制字符串，也不是把n自己的十进制9字符删掉。

不含9的十进制数恰好使用0..8这九个数字。把正整数n写成九进制，再把同一串数字按十进制读出，就得到所求数：九进制正整数与这些十进制数一一对应，位数较短的先出现，同位数按数字字典序比较，故这个对应保持递增顺序。n=1对应1，因此不应先减1；n=9的九进制是10，对应删除序列第9项10。

实现不断取n%9获得从低到高的九进制数字，但乘十进制位权place=1,10,100,...来拼接结果。n整除9推进下一位，整个过程只用整数。时间O(log_9(n))，在原题固定整数范围下额外空间O(1)，不逐个枚举到第n项，也不分配字符数组。

独立小输入oracle从十进制1开始直接过滤字符串含9的数，完整比较前100000项。大输入oracle按十进制上界逐位枚举允许数字的tight状态，统计不含9的正整数排名，不使用九进制转换；检查输出本身不含9、其排名恰为n、前一整数排名为n-1。覆盖1000个固定种子大n、9的幂及相邻值、800000000上界。未向LeetCode提交。
