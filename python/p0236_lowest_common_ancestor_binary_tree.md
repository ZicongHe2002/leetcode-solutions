# 236. Lowest Common Ancestor of a Binary Tree · Python

[原题](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)。

输入是含2..100000节点的普通二叉树，值互异且在[-10^9,10^9]；p、q是树内两个不同的节点对象。返回它们最低公共祖先的原对象，允许其中一方就是祖先；不承诺节点缺失、相同查询节点或空树。原树值和链接保持，不把普通二叉树当作搜索树。

显式遍历建立子节点到父节点的映射，直到两查询节点都已发现；发现节点时其全部祖先映射都已经存在。沿p父链收集祖先对象，再从q向根走，第一个属于该集合的节点就是离q最近的公共祖先；它也位于p祖先链上，因此满足最低条件。映射和集合按默认TreeNode对象身份工作，返回真实原对象。最坏时间O(L)，额外空间O(L)，不递归，可处理100000层链。

独立oracle在小树中分别构造根到每个节点的完整路径，取两路径的最长共同前缀末节点，不复用父指针集合。枚举长度2..6的195种树形、全部2501个无序节点对并交换查询顺序，共5002次；每次检查所有原值和左右身份保持。边界覆盖100000节点链的祖先/后代与根查询、左右分叉以及合法值两端，返回值用is核对。
