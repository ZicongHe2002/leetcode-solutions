# 1143. Longest Common Subsequence · Python

[原题](https://leetcode.com/problems/longest-common-subsequence/)。

两个字符串各长1..1000，仅含小写英文字母，返回最长公共子序列长度；子序列不要求连续。本实现也支持任一字符串为空时返回0。

交换局部引用使列方向使用较短字符串。lengths[column]处理前是上一行同列的长度，lengths[column-1]已是当前行左列，diagonal保存被覆盖前的左上值。字符相同就接到左上最优公共子序列末尾，长度加1；字符不同则至少舍弃一个末字符，取上方与左方较大值。每次先保存above，更新后再把diagonal设为旧above，避免把当前行值当作上一行。每行列0固定为0。该过程逐行实现前缀LCS递推，最终最后一格就是答案。时间O(mn)，额外空间O(min(m,n))，不构造公共子序列本身。

独立oracle用下标位掩码分别生成两个字符串的全部子序列集合，取交集中最长字符串长度，不复用二维或滚动DP。枚举二字母字符串长度0..5的全部63个字符串，完整检查3969对。边界覆盖1000对1000的全同/全异字符串、1000对1的非方形状态、重复字符与经典非连续公共子序列例子。
