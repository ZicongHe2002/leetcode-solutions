# 164. Maximum Gap · Python

[原题](https://leetcode.com/problems/maximum-gap/)。

原题nums长1..100000，值0..10^9，求排序后相邻元素最大差，少于2项返回0，要求线性时间和线性额外空间。实现不排序、不改输入，返回int；所有值相同时直接返回0。

设跨度R=max-min，n>=2且R>0，最大相邻差至少是ceil(R/(n-1))，取它为桶宽width。每桶是宽度width的整数区间，桶内任意两项差至多width-1，因此全局最大差一定发生在不同非空桶之间。每桶只存最小、最大值，按桶顺序用当前桶最小值减去上一个非空桶最大值，跳过空桶，恰好覆盖所有跨桶相邻差。桶数floor(R/width)+1<=n，因此初始化、填桶、扫描均O(n)，额外空间O(n)，满足原题线性要求。

独立参考直接排序后扫描相邻差，不复用桶。枚举值0/1/3/7、长度1..6共5460个数组；另测100000项、全相等、均匀间隔和值域两端，全部核对int和输入保持。
