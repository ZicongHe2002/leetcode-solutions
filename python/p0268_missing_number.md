# 268. Missing Number · Python

[原题](https://leetcode.com/problems/missing-number/)。

原题输入包含1..10000个互异整数，长度为n，每个值在[0,n]，恰有一个值未出现。返回缺失值，不改变输入顺序或内容。本实现额外支持空数组返回0，不承诺重复值或越界输入。

从n开始，把全部下标0..n-1和全部输入值逐项异或。完整值域0..n中的每个已出现值都恰出现两次，依据x^x=0及异或交换、结合律消去；唯一未配对的缺失值保留下来。初始化为n使最大合法值也在抵消域内，缺失0或n无需特殊分支。时间O(n)，额外空间O(1)，不排序、不构造集合或总和数组。

独立oracle用完整值域集合减去输入集合。枚举n=1..7的每个缺失值和所有合法输入排列，共46232个，逐次检查输入保持。边界覆盖n=10000缺失0/5000/10000，数组反序以避免依赖输入排序，以及空数组扩展。
