# 1544. Make The String Great · Python

[原题](https://leetcode.com/problems/make-the-string-great/)。

原题s长1..100，仅含大小写英文字母。相邻的同一字母若大小写相反就一起删除，直到没有这样的相邻对，原题保证终态唯一；返回str，空串也合法。同大小写的重复字母不删除。

在题目限定的英文字母内，同字母相反大小写的字符码差绝对值恰为32；这里没有把该判断推广到任意Unicode或标点。remaining保存已读前缀的good结果，新字符仅可能与其末尾形成坏对，成立则弹出末尾，否则追加。原前缀内部没有坏对，弹出后剩余部分仍good，故每步不变量保持。所得结果来自合法消除且不可再消除，唯一性保证它为题目答案。时间O(n)，额外空间O(n)，包括输出。

独立参考通过swapcase判断每个可删位置，枚举全部删除顺序及终止文本，未使用字符码32判断或栈算法。a/A/b/B、长度1..6的5460个文本全部核对；另测长度100、全同大小写、连锁配对、不可删交替、z/Z与原题样例，核对str。
