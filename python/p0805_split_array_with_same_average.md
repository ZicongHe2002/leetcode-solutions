# 805. Split Array With Same Average · Python

[原题](https://leetcode.com/problems/split-array-with-same-average/)。

原题nums长1..30，每项0..10000。要求把全部元素分到两个非空数组，使平均值相等；重复值仍是不同位置，输入保持，返回bool。只有一个元素不能分。

设总和T、长度n。非空真子集S与补集同平均等价sum(S)*n=T*|S|。把每个值变成n*value-T后，条件变成该子集和为0，全部变换值之和也为0。全程整数避免平均值浮点误差。

将位置分为两个非空半区，各用从[0]出发的倍增表枚举全部子集和：每加入一个值，旧表对应不取、新表副本加该值对应取。表下标就是取值掩码，最后一项恰为取整个半区。先保存左半非空子集和，若包含0直接成功；它肯定不是整个数组。遍历右半非空子集，若和为0也直接成功，否则在左集合查相反和。

必须排除仅由全数组零和造成的假成功。右半不是全取时，任何左右组合都为真子集，可以接受；右半全取时不做跨区匹配。这样不会漏解：若合法解取完整右半和一部分左半，它的非空补集完全位于左半，也为零和，已经由前面的左半零和检查找到。无须为每个和额外保存所有基数，也不能直接把左右全部非空和互补而不排除全取。

最多枚举2^floor(n/2)与2^ceil(n/2)个和，期望时间和额外空间O(2^ceil(n/2))，变换数组O(n)被该界包含。切片、集合和掩码只涉及折半大小，不枚举2^30全数组组合。

独立oracle枚举原始下标子集，直接用整数交叉乘法比较子集与补集平均，不复用变换或折半。值0..3、长度1..6全部5460数组及200种子长度至12样本核对。另测官方例、零、全相等、30元素且只有全取零和的无解、10000值边界与输入保持。未向LeetCode提交。
