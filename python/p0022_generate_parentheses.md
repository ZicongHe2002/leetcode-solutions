# 22. Generate Parentheses · Python

[原题](https://leetcode.com/problems/generate-parentheses/)。

合同为1..8对括号，返回全部合法括号字符串，顺序任意且不重复；本实现额外支持n=0返回['']。负数不在合同内。每个字符串长2n，任意前缀右括号不能多于左括号，最终两者相等。

状态opened、closed记录已选左右括号数，path记录对应前缀。只有opened<n时追加左括号，只有closed<opened时追加右括号，始终保持0<=closed<=opened<=n。closed=n时不变量迫使opened=n，此时保存字符串。合法答案的任意前缀都满足这两个追加条件，因此不会被剪去；每个字符序列只对应一条递归路径，故既完整又没有重复。回溯逐步pop恢复父状态，保存字符串而不是可变path引用。

设第n个Catalan数C_n为答案数量。每个合法前缀都能补成完整答案，递归节点可映射到其某个后代答案及前缀长度，节点数O(n·C_n)；叶子字符串构造也需O(n)，因此时间O(n·C_n)，递归和path额外空间O(n)，输出空间O(n·C_n)。没有先生成全部2^(2n)字符串再过滤。

测试oracle独立生成全部长度2n的括号字符串，扫描前缀余额并检查最终为0，不复用合法前缀生成法。n=0..7逐一比较全部结果列表，最大n=8再与全部65536个候选字符串的过滤结果比较，保留列表重复项以检测重复输出；核对数量1430，并验证每个字符串的长度、前缀和括号计数。另有n=1、n=2的明确结果。
