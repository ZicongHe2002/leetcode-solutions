# 190. Reverse Bits · Python

[原题](https://leetcode.com/problems/reverse-bits/)。

反转固定32位中的位顺序，不能只反转最短二进制文本。当前[题目镜像约束](https://github.com/doocs/leetcode/blob/main/solution/0100-0199/0190.Reverse%20Bits/README_EN.md)为偶数n且0<=n<=2^31-2。本实现额外支持0..2^32-1所有无符号值，扩展结果也按无符号整数解释；不承诺负数或超出32位。

每轮把result左移，再并入n当前最低位，然后让n右移。经过t轮，result恰是原数最低t位的反序；固定做32轮，原数的高位0也被纳入，保证原低位移到其完整32位位置。Python整数不可变，局部右移不会修改调用者变量。时间固定32步，额外空间O(1)，原题域及扩展域内都返回0..2^32-1的整数。

独立oracle用format(n,'032b')得到恰好32位的文本并反序解析，不复用移位循环。穷举低16位全部65536值，其中32768个偶数在原题域，奇数属于扩展；检查int返回和32位输出范围。边界覆盖单个1在全部32位置、各长度全1掩码、原题最大偶数、完整32位掩码和交替掩码，避免把扩展用例冒充原约束。
