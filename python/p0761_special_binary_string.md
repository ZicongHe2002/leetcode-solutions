# 761. Special Binary String · Python

[原题](https://leetcode.com/problems/special-binary-string/)。

原题s长1..50，保证为special二进制串：1和0数量相等，每个前缀中1不少于0。一次可交换两个相邻、非空、各自special的子串，求任意次操作后的字典序最大字符串。合法非空输入必为偶数长度，空串只作为递归基例。

把1看作左括号、0看作右括号。balance从0出发，每次首次回到0就切出一个不可再拆的原始平衡段，它必形如1+inner+0，inner仍为special。递归把每个inner最大化，重新包上1和0，再把所有原始段按字典序降序连接。空串没有段，自然返回空串。

括号串是一片有序森林。合法special子串恰好由某个深度的一串完整相邻子树构成；交换相邻special子串只重排兄弟子树，不改变每棵子树的内部父子关系。任何兄弟排列都能用相邻单棵子树交换实现，因此可以先独立最大化每棵子树内部，再选择兄弟顺序。

不同原始平衡段不可能互为真前缀，因为短段结束时balance已为0，而长原始段在末尾前不能回到0。因此比较两段时会在共同长度内分出大小，降序放置恰使它们的连接字典序最大，不需要一般字符串拼接问题中的a+b比较器。递归同理，在所有可达森林排列中得到全局最大串。

每层扫描、切片和连接处理当前串；降序排序的字符比较最坏也与段长有关。一个保守上界为O(n^2 log(n+1))时间，递归深度最多n/2，保守辅助空间O(n^2)计入活动切片与重建文本。n<=50，不声明线性时间或常数空间。

独立oracle对短串枚举所有切分i<j<k，直接检查两段是否各为非空special，再执行真实相邻交换；BFS穷尽整个可达字符串图，取最大字符串。不递归排序括号树。1..6对括号的全部196个合法串均核对最优值与special合同；另核对官方例、50字符深嵌套和25个平段。未向LeetCode提交。
