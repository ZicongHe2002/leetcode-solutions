# 522. Longest Uncommon Subsequence II · Python

[原题](https://leetcode.com/problems/longest-uncommon-subsequence-ii/)。

给定字符串列表，求只作为其中恰好一个条目子序列的最长子序列长度；不存在返回-1。相同内容的两个输入条目仍算两个归属，不能先去重再判断。原题2..50条，每条长1..10，只含小写字母，输入列表保持。

只需把输入整串当候选。若某个子序列u只属于s_i，而s_i本身能成为另一条s_j的子序列，则子序列关系的传递性使u也属于s_j，矛盾。因此只要存在非常见子序列，它所属的整串也非常见且不会更短；不需要枚举指数数量的子序列。

复制后按长度降序检查每个候选，对全部其他下标核验它是否为子序列。更短的字符串不可能容纳候选，直接跳过；同一下标跳过，但同内容的另一下标必须检查并会淘汰该候选。首个没有被任何其他条目包含的整串即为最长；全部被包含就返回-1。

子序列检测按other从左到右扫描，每次遇到候选下一字符立即匹配。尽早匹配给后面字符保留至少同样多的位置，所以有合法嵌入时贪心不会错过。matched只前进，不重排字符；同长不同内容不会互为子序列。

N条、最大长度L，排序O(N log N)，两两检测O(N^2*L)，合计O(N log N+N^2*L)，辅助空间O(N)用于排序引用，不改strs，也不构造全部子序列集合。

独立参考逐条枚举实际下标子序列集合，每条的集合各给Counter加1，再从归属计数恰1的子序列取最大长度，不只枚举整串。14种a/b短词、列表长2..4全部41356个列表对照，含重复条目。另测50条/10字符、全部重复、较长重复而较短独有与子序列方向，核对int及输入保持。未向LeetCode提交。
