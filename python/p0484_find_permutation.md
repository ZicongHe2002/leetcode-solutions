# 484. Find Permutation · Python

[原题](https://leetcode.com/problems/find-permutation/)。

给出由I/D组成的长度n字符串，要求用1..n+1各一次构造字典序最小排列；I对应相邻递增，D对应相邻递减。原题1..100000个字符，只含I或D。空模式额外返回[1]，输入字符串保持。

从升序1..n+1开始。对于一段连续D，设它占模式下标[start,end)，它连接的排列位置是闭区间[start,end]，长度比D的个数多1；翻转这一段升序整数后就满足全部下降。连续I不动，D段相邻的I边界也仍上升，因为前后段使用的是整体更小/更大的连续值区间。翻转右端不能错用end-1。

字典序最小性可逐段证明。在尚未处理的位置开始，如果后面有k个连续D，当前值之后必须留出k个更小且互异的数；可用数中的第k+1小就是当前位可能取到的最小值。接着为了字典序最小且仍可完成该下降段，依次取这k个更小数的降序。若没有D，就是先放最小可用数。算法翻转最小的一组k+1个连续可用值，正好执行这一最优选择，后缀继续归纳。

扫描每个模式字符一次，每个排列位置至多参与一个D段的翻转（相邻D本就属于同一段），总时间O(n)。结果列表O(n)是必需输出，除此只保存固定数量下标，辅助空间O(1)。手动双指针交换，避免用切片翻转额外分配与下降段同长的临时列表。

独立参考从小到大枚举1..n+1的全部排列，取第一个符合所有I/D约束的排列，不使用分段翻转。长度0..6的全部127个模式对照，空模式为扩展。另测100000个I、100000个D及交替ID，检查完整1..n+1排列、全部比较关系及明确边界期望。未向LeetCode提交。
