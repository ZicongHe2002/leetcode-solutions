# 737. Sentence Similarity II · Python

[原题](https://leetcode.com/problems/sentence-similarity-ii/)。

原题句长1..1000、词长1..20、相似词对0..2000，词含大小写英文字母。此题相似性具有传递性：给定无向词对构成图，连通的词互相相似；相同词即使未在图里出现，也与自身相似。长度不同直接不相似，大小写不自动归一。

使用并查集表示图的连通分量。find首次遇到词时创建单元素集合，之后迭代把父指针缩短到祖父，直到根。读入每个相似词对时，先求两根；若不同，把较小集合根挂到较大集合根，并更新大根大小。重复词对、自环或已经间接连通的词对不会重复合并。

每次合并只加入题目给定的一条无向联系，所以同根一定通过原始边连通；任意图路径的每条边都已合并，所以连通词最后也必同根。逐位置比较根正好对应传递相似性。句中未出现过的词会创建各自单元素集合：同词两次find得到同根，不同孤立词得到不同根。长度检查先于zip，避免截断漏词。

设N为句长、P为词对数、L为最长词长、V为涉及的不同词数，V<=2N+2P。在哈希表平均访问模型下，按大小合并和路径压缩的均摊时间上界O((N+P)*L*alpha(V+1))，空间O(V)个词引用和整数；若连同引用的词文本计入，则O(VL)上界。find迭代实现，不因长链增加Python递归深度。输入全部保持。

独立oracle建立原始无向邻接图，每个对应词对用显式栈重新搜索能否到达，不使用根或合并。核对3词8种关系、39个短句两两组合的12168次判断；另核对官方多跳链、大小写、未见词自身/不同词、重复边及2000词对的2001节点长链、1000词句和20字符边界。未向LeetCode提交。
