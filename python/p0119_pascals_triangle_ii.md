# 119. Pascal's Triangle II · Python

[原题](https://leetcode.com/problems/pascals-triangle-ii/)。

原题0<=rowIndex<=33，返回从0开始编号的杨辉三角指定一行，不需要返回之前各行。第0行结果是[1]。

只保存一行。每次先在末尾补1，再从右向左更新内部项：row[column]和row[column-1]在读取时都仍是上一行的值，因为更小下标尚未修改。若从左向右相加，左邻会混入当前行的新值，破坏相邻两项来自同一旧行的定义。两端维持1，完成一轮后数组就是下一行。

时间O(r*r)，空间O(r+1)，其中r为rowIndex；存储量随返回行长度增长，不保存整个三角，满足原题单行空间要求。

独立oracle使用math.comb(r,c)逐项生成期待值，不做逆序相邻更新。原题全部34种下标分开核对：0..32枚举，33单独检查最大行；最大行同时验证对称、行和2**33、两端为1和中间值1166803110，所有返回项均为int。
