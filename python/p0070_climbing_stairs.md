# 70. Climbing Stairs · Python

[原题](https://leetcode.com/problems/climbing-stairs/)允许每次走1或2级，输入n在1..45，求到达第n级的不同步长序列数。`Solution.climbStairs`返回整数；走法按顺序区分，例如到3级的[1,2]和[2,1]是不同走法。n=0返回1，表示唯一空路径，是接口扩展。

记W(k)为到k级的路径数。最后一步若为1，其前缀恰到k−1；若为2，其前缀恰到k−2。两类互斥且覆盖全部路径，所以W(k)=W(k−1)+W(k−2)，并以W(0)=W(1)=1初始化。

循环进行k轮后，previous=W(k)、current=W(k+1)。初始k=0满足这两个值都为1；Python先计算赋值右侧两个表达式，再更新两个变量，所以一轮后状态为W(k+1)、W(k)+W(k+1)=W(k+2)，不误用刚更新的值。执行n轮后previous就是W(n)。时间O(n)，只保存两个路径数，按题目有限范围计额外空间O(1)；不声称任意大n下Python大整数运算都是常数时间。

B补写n=5的滚动状态。表中k是已经完成的循环次数；两项必须一起使用上一轮值计算：

| k | previous=W(k) | current=W(k+1) |
| --- | --- | --- |
| 0 | 1 | 1 |
| 1 | 1 | 2 |
| 2 | 2 | 3 |
| 3 | 3 | 5 |
| 4 | 5 | 8 |
| 5 | 8 | 13 |

最后返回previous=8，current=13已经属于到第6级的走法，不能误返回它。若写成previous=current后再current=previous+current，第二行会把旧previous丢掉，重复使用旧current；Python并行赋值避免此错误。

8条路径可以完整分组：没有2步时为[1,1,1,1,1]；一个2步时为[2,1,1,1]、[1,2,1,1]、[1,1,2,1]、[1,1,1,2]；两个2步时为[2,2,1]、[2,1,2]、[1,2,2]。这给出1+4+3=8，而不是把步长的多重集合当一种路径。

组合数oracle存在明确双射：固定t后，步数只能为n−t，从这些有序位置中选t个放2，其他放1，得到和为n的唯一合法步长序列；反过来，从任一路径取出2步的位置，唯一恢复该位置子集。不同t的路径不相交，所以对t求和既不漏也不重复。n=0时只有t=0，C(0,0)=1对应空序列；它是递推和测试的基线扩展，不表示原题要求输入0。

测试用另一种计数：若有t个2步，则1步有n−2t个，总步数n−t；选择其中t个位置放2步，得到组合数C(n−t,t)，对t求和。它不复用生产递推，核对0..45全部46个输入，另有1、2、3、5及45的固定期望。实际运行结果见PR；未提交LeetCode，不声称Accepted。A实现与测试，B补写完整状态、8条路径和组合数双射；双方使用OpenAI Codex辅助。
