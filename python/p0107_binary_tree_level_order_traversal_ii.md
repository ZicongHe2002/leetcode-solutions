# 107. Binary Tree Level Order Traversal II · Python

[原题](https://leetcode.com/problems/binary-tree-level-order-traversal-ii/)。

返回二叉树自底向上的分层节点值；每层内部仍按从左到右排列。原题允许空树，节点数0..2000，值为-1000..1000。本实现只读原树，每层结果使用独立列表。

队列先按从上到下处理。每轮固定当前队列长度，只消费这一层，按左孩子、右孩子的顺序追加下一层节点；新增孩子不会在同一轮被消费。因此每层内部顺序正确。收集全部层之后仅反转外层列表，不反转任何层内部的节点值，就得到自底向上的结果。

每个节点入队、出队一次，最终反转不超过树高次交换，总时间O(n)。除返回结果外，队列最多同时容纳相邻两层的部分节点，额外空间O(w)，w为最大层宽；反转原地完成。

独立oracle以左优先深度遍历按深度分桶，再按深度逆序读取。穷举0..8节点共2056种树形，另覆盖2000节点交替深链、2000节点完全树、缺口及值域端点，核对层列表独立和原节点值、链接保持。
