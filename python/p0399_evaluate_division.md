# 399. Evaluate Division · Python

[原题](https://leetcode.com/problems/evaluate-division/)。

原题1..20个方程与1..20个查询，变量名长1..5、由小写字母和数字组成，方程值0<value<=20。输入无矛盾且不会除零。查询无法确定时返回-1.0；未出现在方程中的变量未定义，因此未知x/x也为-1.0，已知a/a才为1.0。

方程a/b=r建两条有向边：a到b权r，b到a权1/r。沿路径相乘会约掉中间变量，得到起点/终点。每次查询独立用栈搜索，保存起点到当前节点的乘积，发现新变量时标记seen避免环上反复访问。无矛盾前提保证同一连通分量中的任意路径给出相同比例，所以无需枚举所有路径；未知变量先返回，已知同名变量由初始乘积1.0处理。

E个方程、V个出现过的变量、Q个查询，建图O(E)，查询总时间O(Q*(V+E))，额外空间O(V+E)，输出另O(Q)。浮点数按评测容差比较，未声称任意长乘积精确无误差，也不处理相互矛盾的扩展输入。所有入参保持。

独立参考先为变量指定隐藏真值，只用真值比值生成一致方程，另用无权并查集判定能否求值；期望直接取隐藏真值之比，不复用权重搜索。2..4变量的71个非空简单图共1696个含未知/自除查询，按每次不超过20项分批。另用20方程的21变量链、20查询验证长乘积与倒数，覆盖断连分量、未知自除和全部输入保持。
