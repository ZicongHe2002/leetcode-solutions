# 605. Can Place Flowers · Python

[原题](https://leetcode.com/problems/can-place-flowers/)。

原题flowerbed长1..20000，只含0/1且原本没有相邻1，n在0..花坛长度，判断能否再种n朵且保持不相邻。只返回bool，不实际改写花坛；不支持原本已有相邻花的非法输入。

从左到右，在当前格、已处理左邻状态、原始右邻都为0时虚拟种一朵。previous在新种后置1，阻止下一格紧挨着种；不能种时置为原格值，准确维护前一格处理后的状态。两端之外按0视为空。每段空位总可以先选最左可种位置：若某最优方案先种得更右，把其第一朵左移不会伤害右侧可用位置，因此最左贪心不减少可种总数。完整扫描后planted是最大数量，n=0自然为True。

每格一次，时间O(m)，额外空间O(1)，花坛始终保持。独立参考枚举所有原空格新增子集，按完整候选花坛检查相邻约束，求最大可新增数。长度1..9共有230个合法二进制花坛，遍历每个合法n共1955次查询；另测20000长度、容量恰够/多一朵、已有花交替及单格边界，核对bool与输入保持。
