# 611. Valid Triangle Number · Python

[原题](https://leetcode.com/problems/valid-triangle-number/)。

nums长1..1000，每项0..1000，统计从数组不同下标选三个数构成非退化三角形的组合数。相同数值但下标不同是不同选法，不能把值去重。输入保持，额外定义空数组返回0。

复制排序为sides后固定最大边下标k。由于非负且a<=b<=c，三条严格三角形不等式等价于a+b>c；等号是退化线段，0边也不会通过这个条件。只需在k以前找下标对，不需要检查所有三条式子。

left/right初始指向区间两端。如果最小候选sides[left]+sides[right]已经大于最大边，那么把left换成left..right-1中的任意下标都有效，一次加入right-left种，再把right减1，下一轮处理不同右端。若当前和不足或等于最大边，则同一个left配任何更小右端也无效，可直接把left加1。每次删除的候选已全部计入或证明无效，因此不会漏计、重复计数。

每个三元组按排序后最大的下标唯一归属一个k，相等边长也仍保留不同下标，所以累计得到正确组合总数。每个k最多线性移动指针，整体时间O(N²)，排序O(N log N)被其覆盖。排序副本和排序工作区额外空间O(N)，不能因双指针本身只用常数变量就把保持输入的复制成本漏掉。

独立oracle枚举全部下标三元组，直接检查原顺序的三条严格不等式，不排序、不用双指针或成批计数。值0/1/2/3、长度0..8的全部87381个数组对照，空数组为扩展。另测1000个相等正边的C(1000,3)、全0、零与1000混合、仅一组三边、严格等号拒绝及样例，核对整数和输入保持。未向LeetCode提交。
