# 66. Plus One · Python

[原题](https://leetcode.com/problems/plus-one/)。

digits是非空的十进制高位在前表示，各位0..9，除[0]外没有前导零。返回加一后的数字列表；本实现返回新列表并保持输入。原题输入长度1..100，不先转换整个数字来完成算法。

复制输入后从最低位处理进位。每次到达的位置都接收一个进位；若该位小于9，增加一即可结束，左侧未处理前缀不变。若该位等于9，写为0并继续向左。循环耗尽说明原数组全为9，添加首位1即可，例如所有低位0都是同一次进位产生的结果。复制和最坏进位扫描均为O(n)，额外空间O(n)；全9时构造扩展后的结果也计入该界。

独立oracle使用Python整数加一，再重新拆成十进制位，与手工进位实现分开。穷举0..9999，共10000次比较，另覆盖100位全9、百位普通进位和长尾连续9，并核对结果类型、输入保持及输出列表独立。
