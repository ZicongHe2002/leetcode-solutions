# 191. Number of 1 Bits · Python

[原题](https://leetcode.com/problems/number-of-1-bits/)。

按当前[题目镜像的约束](https://github.com/doocs/leetcode/blob/main/solution/0100-0199/0191.Number%20of%201%20Bits/README_EN.md)，原题输入为1..2^31-1，返回二进制中1的数量。本实现额外支持0..2^32-1的全部无符号值，0返回0；不承诺负数。原题范围与扩展范围的测试分别说明。

对非零n，n-1会把最低的1变成0并把其更低的0变成1；n与n-1按位与恰好删除最低的一个1，其余更高位不变。因此每轮计数加一，直到n变0就是原1的数量。Python整数是不可变值，局部重绑定不改变调用者输入。若原来有k个1，时间O(k)，在本合同内最多32轮，额外空间O(1)。

独立oracle用二进制字符串统计字符1，不复用最低1删除。穷举0..65535共65536个值，其中0属于扩展，其余均在原题范围；核对int返回。边界覆盖单个1的全部32位置、各长度全1掩码、31位最大正值及两个交替掩码，最高位31和完整32位掩码明确按扩展检查。
