# 51. N-Queens · Python

[原题](https://leetcode.com/problems/n-queens/)。

原题1<=n<=9，返回n*n棋盘上放n个皇后且任意两皇后不同列、不同对角线的全部棋盘，使用Q和.，输出顺序任意。每行只放一枚，结果包含独立生成的棋盘字符串。

逐行选择列，用columns、row-column、row+column三种集合分别检测列与两类对角线冲突。合法候选加入三集合与placement，递归完成下一行；返回时逐一恢复。完整路径转为n行棋盘，所有列选择序列唯一，故没有重复棋盘。搜索最坏时间O(n*n!)，S个结果的棋盘构造另需O(S*n^2)，辅助回溯空间O(n)，不计输出。

独立oracle枚举全部列排列，用对角线集合直接筛选，不复用逐行剪枝。n=1..9共409113个列排列全部核对，比较完整解集合，并检查每行单Q、列与对角线唯一及结果不重复。另核对n=2/3无解和同一Solution实例重复调用、外部修改旧结果后的隔离。
