# 476. Number Complement · Python

[原题](https://leetcode.com/problems/number-complement/)。

原题num在1..2^31-1，翻转其无前导零二进制表示中的全部位，返回对应非负int。最高有效位以外的位不参与翻转，所以1的结果是0，不是无限位取反后的负数；0不在原题范围。

从1左移到严格大于num的第一个2次幂next_power。若num有b个有效位，这个值就是2^b，减1得到恰有b个1的掩码。与num XOR仅翻转该有效宽度内的位，高位保持0，正好实现题意。循环至多31次，时间O(b)，额外空间O(1)，本题b<=31；全部使用整数操作。

独立参考将无前导零的二进制文本逐字符0/1交换，再按二进制解析，不构造全1掩码。核对1..10000；另对有效宽度1..31的最高单1、全1和交替模式检查，覆盖最高31位输入，核对int。
