# 499. The Maze III · Python

[原题](https://leetcode.com/problems/the-maze-iii/)。

矩形0/1迷宫内小球选上下左右方向后持续滚动，撞墙或边界才停；经过洞hole时立即落入，不能继续越过。返回移动格数最少的方向串，同距离取字典序最小的串，方向字符为d/l/r/u；无法入洞返回impossible。原题行列1..100，至少两格空地，ball和hole是不同的合法空地；输入全部保持。同点额外返回空串。

图状态是停点与洞，一条边代表一次有实际位移的滚动，权重为经过格数。逐方向步进时同时检查洞，遇到立即停止；与The Maze里只在撞墙处停的规则不同。完全被墙挡住的方向steps=0，必须跳过，不能为原地动作增加字符并制造零权循环。

best[cell]保存当前最优的(距离,方向串)，堆也按这两个量依次排序。更短距离优先，距离相等才比较完整方向串；同距离字典序改善也要重新入堆，不能只检查距离。出堆若与best不符就是旧项，直接跳过；有效洞项首次出堆即可返回，不能在首次看到洞边时提前结束。

所有实际边权为正，Dijkstra的距离定型成立。同一停点同距离的两个路径若一个是另一个的真前缀，后者必须多走一个回到该停点的正权环，矛盾；因此同距离较小方向串接相同后缀仍较小，可以只保留最优二元组。有效目标项前所有可能更优的前驱都有更短距离，已经处理，故目标返回同时满足距离和字典序。

令V=mn。忽略字符串成本时，四方向滚动扫描总上界O(V*(m+n))，堆操作O(V log V)。Python每个路径串最坏长O(V)，复制和堆内字典序比较不能当常数；给出包含它们的保守时间上界O(V*(m+n)+V^2 log V)，best与堆保存路径的保守空间上界O(V^2)。不把这些实际字符串隐写成O(V)总空间。

独立参考按行列最大空段直接建立带距离/字母的端点边，洞在段内时把相应端点截到洞；再用至多V-1轮的快照松弛求最佳二元组，不用堆或逐格滚动。3x3全部512墙布局的合法不同球/洞共9216次对照。另测100x100全空、同距lu/ul、走廊中途落洞、不可达洞和原地动作，检查三输入保持。未向LeetCode提交。
