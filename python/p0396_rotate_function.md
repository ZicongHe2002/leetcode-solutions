# 396. Rotate Function · Python

[原题](https://leetcode.com/problems/rotate-function/)。

长度为n的数组每次向右旋转一位，定义F(k)=各位置下标乘该位置元素后的总和，求k=0..n-1中的最大值。原题长度1..100000，元素-100..100。输入不修改，额外为空数组返回0；负数必须正常参加加权，不能把初始最大值写成0。

F(0)直接计算，S为所有元素之和。向右旋转时，除原末尾元素外每个元素的下标增加1，贡献总增量S；原末尾从n-1移动到0，需额外减去n倍该值。因此F(k+1)=F(k)+S-n*本次移到首位的元素。被移动的原始下标依次为n-1、n-2直到1，不需要实际构造旋转数组。

weighted始终等于当前完整旋转的权重，best保存已扫描旋转中的最大值。初始旋转已经计入，再更新n-1次恰好覆盖所有不同旋转。n=1时没有更新，唯一权重为0；全负数组的最优权重也可能为负，初值仍正确。

时间O(n)，额外空间O(1)，没有保存所有旋转或权重列表。Python整数可安全计算中间算式，测试中的原题内输入和期望均明确给出。
