# 738. Monotone Increasing Digits · Python

[原题](https://leetcode.com/problems/monotone-increasing-digits/)。

原题0<=n<=10^9，返回不超过n且十进制各位非递减的最大整数，相等数字允许。0自身合法。不能只改掉第一个下降位置，因为减一后可能继续破坏左侧，如332需要连锁借位成299。

把数字写成数组，从右向左检查相邻位。若左位大于右位，保持此前前缀不变就不可能找到合法且不超过原值的数字，因此把左位减1，并记录从右位开始应当改成9的后缀起点。继续向左可以发现这次减1引发的更早下降。所有检查结束后，把最早记录起点以后的数字统一置9，得到在已减小前缀下最大的后缀。

从右向左处理保证需要的连锁减一不会遗漏；每次减一只发生在正位上，不会产生负数字。若没有下降，原数已经合法，不改动。发生下降时，首次真正变小的前缀决定结果小于原n，后缀全部9仍不超过n，并在这个合法前缀下最大。需要更早减小的情况已由反向扫描传播，因此得到全局最大可行数。开头可能变0，最终int转换自然移除前导0，如1000得到999。

设D为数字位数，时间O(D)，额外空间O(D)。原题最多10位，不按n的数值大小枚举候选。

独立oracle用1..9数字的可重复组合生成全部1..9位非递减正整数，再加入0，得到原题整个值域内全部48620个合法数。正数非递减时不可能含0，10位最小合法正数1111111111已超过10^9，所以生成没有遗漏。核对每个合法数本身及它前一整数的答案，共97239个完整阈值边界，再核对1000个固定种子输入和典型连锁借位；期待值从完整有序合法集合选不超过n的最大数，不用借位贪心。未向LeetCode提交。
