# 47. Permutations II · Python

[原题](https://leetcode.com/problems/permutations-ii/)。

原题nums长1..8，每项在-10..10，可重复；返回所有不同排列，外部顺序任意。实现按字典序生成，保持输入，额外定义空数组有一个空排列[[]]。

先排序副本，把相等项放在一起。used表示源位置是否在当前路径中；某项与前项相等且前项尚未使用时，跳过它，让同一层只由最靠前的可用副本代表该值。若前项已在当前路径中，当前项仍可使用，因此不会丢失重复值的合法位置。每次返回前恢复path和used，完整路径复制进结果。最坏时间O(n*n!)，辅助空间O(n)，输出另占O(n*u)，u为唯一排列数。

独立oracle用itertools.permutations枚举按位置的排列后取集合，不复用去重回溯。值-1/0/1、长度0..6共1093个数组核对，空数组为扩展。边界覆盖8个互异值的40320个排列、8个相同值、正负10重复和输出唯一性，核对两层列表及输入保持。
