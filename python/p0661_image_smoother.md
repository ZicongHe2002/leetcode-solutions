# 661. Image Smoother · Python

[原题](https://leetcode.com/problems/image-smoother/)。

原题img行列数分别1..200，每个灰度值为0..255。每格取自身及最多八个周围格子的平均值向下取整，缺失邻格不参与总和或分母；返回同形状list[list[int]]，输入不变。

对每格将行列范围各裁剪到矩阵内，枚举这个至多3乘3的小矩形。它恰为存在的邻格加自身，count至少为1，所以total//count精确给出非负平均值的floor。全部读取来自img，写入独立output，不会用已经平滑后的值污染后续结果。每格最多读取9值，时间O(rows*columns)，输出空间O(rows*columns)、除输出外额外空间O(1)。单格、单行、单列也以实际邻域计分母。

独立参考先建立二维积分图，再用四个前缀和相减求每个裁剪矩形的总和，不逐邻格累积作为参考。1..3行列、灰度0/1/255的全部21297个矩阵逐一核对；另测200乘200全0/全255/棋盘、200长单行单列和原题非整平均样例，核对整数取整、list行及输入保持。
