# 27. Remove Element · Python

[原题](https://leetcode.com/problems/remove-element/)。

在nums中原地保留所有不等于val的元素，返回保留长度k；只需前k项有效，后缀无约定。原题允许改变顺序，本实现选择稳定保留且不改变列表长度。合法输入长度0..100，元素0..50，val为0..100。

write记录已经保留的元素数。扫描到当前位置时，nums[:write]恰为已读原前缀中应保留的元素，顺序保持；write不超过读取位置，所以写入只覆盖已读位置，不会改变之后要读取的元素。不等于val时追加到有效前缀，等于时不写；扫描结束即可返回write。时间O(n)，额外空间O(1)，不通过创建过滤后的新列表实现原地要求。

测试以新建过滤列表为独立oracle，比较返回长度、有效前缀和原列表长度，不约束无效后缀。长度0..7、值0/1/50的3280个数组分别对照val为0/1/2/50/100，共16400次查询；另覆盖空数组、100元素、全部删除、全部保留和交替删除。
