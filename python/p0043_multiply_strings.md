# 43. Multiply Strings · Python

[原题](https://leetcode.com/problems/multiply-strings/)。

原题num1/num2均为长度1..200的非负十进制整数字符串，只有0本身允许前导0。返回它们乘积的标准十进制字符串；实现不把整串转换成整数，不依赖大整数乘法。

把最低位看作下标0，任意两位的乘积贡献到下标之和对应的位，先把全部贡献累加到digits。两个长度m/n的数的乘积小于10**(m+n)，所以预留m+n位足够。之后从低位向高位执行divmod(...,10)，当前位保留余数、商加入下一位；处理完的低位不再改变。最高预留位最终不超过9，因为整个乘积小于10**(m+n)。最后去掉高位0并反向拼接，零乘积提前返回0。

时间O(m*n+m+n)，辅助空间O(m+n)，包括数位缓冲和输出。没有浮点运算，逐位乘积和进位均为整数。

独立oracle仅在测试中使用Python整串int转换及乘法。0..100两两相乘的10201对输入核对；边界覆盖两串均为200位、全9连锁进位、10的高次幂、不同数字模式和零。输出必须为非空ASCII数字串，除0外没有前导0。
