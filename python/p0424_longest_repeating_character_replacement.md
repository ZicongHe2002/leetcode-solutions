# 424. Longest Repeating Character Replacement · Python

[原题](https://leetcode.com/problems/longest-repeating-character-replacement/)。

原题s长1..100000，仅含大写英文字母，0<=k<=len(s)。最多替换k个位置，使某个连续子串全部相同，返回可达到的最长长度；不需要真的改写s。本实现额外支持空串且k=0时返回0。

一个窗口最少需要替换的数量是窗口长度减当前最高字符频次，保留最高频字符即可达到这个下界。右端加入字符后，只要该差值大于k就移出左端，直到窗口重新合法，再更新最长长度。这里每次用26项计数计算实际最大值，不保留过期的历史最大频次，因此当前窗口一直满足真实替换预算。左右各最多移动n次，时间O(26n)，固定字母表下为O(n)，额外空间O(26)。

独立oracle枚举全部子串，逐个用Counter计算最少替换数，不复用双边界维护。枚举A/B/C上长度0..7的3280个串及每个合法k，共24604次，空串为扩展。边界覆盖100000同字符、100000交替字符且预算0/50000，以及经典AABABBA、k=1，核对int。
