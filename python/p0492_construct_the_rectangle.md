# 492. Construct the Rectangle · Python

[原题](https://leetcode.com/problems/construct-the-rectangle/)。

面积为正整数area，求整数长度L和宽度W，使L*W=area、L>=W且L-W最小，返回[L,W]。原题1<=area<=10000000；0或负面积不在合同内。

L>=W和乘积固定给出W<=sqrt(area)。宽度确定后L=area/W，且在正数范围W越大，area/W-W越小，所以应找不超过平方根的最大整数因子。用isqrt得到精确的平方根下取整，从它向下找第一个整除area的宽度；1必定整除正面积，循环能结束。

整数除法只在找到因子后计算，保证乘积精确，完全平方数直接得到L=W。没有浮点开根或四舍五入，不会在完全平方数附近从错误的整数起点开始。area=1时宽度就是1，返回[1,1]。

最多检查floor(sqrt(area))个宽度，最坏时间O(sqrt(area))，只保存固定数量整数，辅助空间O(1)，输出固定两项。

独立参考枚举全部正长度1..area，保留整除且L>=W的矩形，再直接按L-W选最小，不使用平方根起点或降序宽度搜索。area=1..2000全部对照。另测10000000、接近上界的完全平方数、2^23；大10幂的最佳宽度额外按2/5素因子组合回读。核对列表接口、乘积、大小关系及整数，未向LeetCode提交。
