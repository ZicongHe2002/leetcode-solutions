# 148. Sort List · Python

[原题](https://leetcode.com/problems/sort-list/)。

原题链长0..50000，节点值-10^5..10^5，返回升序链头，进阶要求O(n log n)时间和常数额外空间。假设无环；空链返回None，重连原节点，不改val。本文件ListNode供本地独立导入，与评测器val/next一致。

使用自底向上归并，先数长度，初始每个单节点就是宽度1的有序段。split把至多width个节点切成独立链，返回剩余头；每轮取左右两段并先保存下一对起点，防止重连时失去后续输入。比较两段头，较小者接到tail后，平值优先左段保证稳定；某段耗尽时接上另一段，并把tail推进到这对合并段尾。当前宽度一轮结束后，所有至多2*width的段有序，下一轮把width倍增，直到覆盖全长。

每轮切分、归并和推进尾指针的总访问量均O(n)，轮数O(log n)，总时间O(n log n)；没有递归或节点数组，仅固定指针、计数、一个哨兵及非递归split调用，额外空间O(1)。尾段不足width或缺少右段都由split(None)和剩余链分支处理。

独立参考对全部原节点按val稳定排序。枚举值-1/0/1、长度0..7共3280条链；另测50000节点正序、倒序、重复值及极值混合，逐节点比较身份、最后None和值保持。大链测试也覆盖不依赖递归栈这一行为，没有在线Accepted记录。
