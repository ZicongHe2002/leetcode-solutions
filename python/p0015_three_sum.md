# 15. 3Sum · Python

[原题](https://leetcode.com/problems/3sum/)。

长度3..3000，值[-100000,100000]；输出来自三个不同下标且和为零的不同值三元组，顺序不作承诺。少于3项扩展为空输出。复制排序，依次固定首项，在其右侧用两个指针找其余两项；首项重复就跳过，首项已为正则其后也都为正，可以结束。输入保持。

固定首项后，和太小意味着保留left并把right变小仍不会命中，故排除left；和太大时对称排除right。命中后左右同时内移，再分别跳过刚用过的相同值；固定首值与左值时，满足和为零的右值唯一，因此这种跳重不会遗漏新的值三元组。first<left<right始终保证三个下标不同，重复的零仍可来自不同位置。

时间O(n²)，排序O(n log n)包含在内；排序副本与排序临时空间合计O(n)，结果含k组三元组另占O(k)。Python求和没有32位溢出，但测试仍遵守题目值域。独立oracle枚举所有三下标组合，再按值去重形成期望；生产结果仅排序比较，不对实际输出去重，重复错误仍会失败。五值集合长度3..6全部19500个数组、值域端点、重复解及3000长度全零/全正边界均核对。
