# 391. Perfect Rectangle · Python

[原题](https://leetcode.com/problems/perfect-rectangle/)。

判断给定轴对齐矩形能否无重叠、无空缺地恰好覆盖一个大矩形。原题1..20000个矩形，每项为[x1,y1,x2,y2]，坐标-100000..100000且x1<x2、y1<y2。本实现不修改输入，额外对空列表或退化/反向矩形返回False。

累计每个矩形面积，并记录全部矩形外接框。同时让每个角点在集合中奇数次出现时保留、偶数次出现时移除。完美铺接的内部接点与直边接点都出现偶数次，只有外框四角出现奇数次，所以最终角点集合必须恰好是外框四角；矩形面积总和还必须等于外框面积。

两项约束合起来也充分。用全部横纵边界把外框切成小格，格内覆盖次数固定。角点奇偶状态沿两个方向作前缀异或，得到每格覆盖次数的奇偶；只有外框四角为奇数，使框内每格都覆盖奇数次，因此至少覆盖一次。面积总和等于外框面积又排除任何格被覆盖3次或更多，故每格恰好覆盖一次，不可能有空缺或正面积重叠。单独面积相等不能排除一处重叠补偿另一处缺口。

每矩形处理4角和固定数量算术，哈希集合平均O(1)操作，总时间O(n)，角点最坏O(n)额外空间。Python整数安全处理横纵跨度200000所产生的面积，不能按32位有符号整数累计。

独立小参考枚举矩形覆盖的整数单位格，用计数器检查外框每格恰好出现一次，不使用面积或角点奇偶。0..3坐标内全部36种非退化矩形，取1..3个的可重复无序组合共9138项，加空输入共9139项核对。另测重复重叠与空缺恰好面积抵消、负坐标、退化拒绝及20000条带完整覆盖最大坐标框。未向LeetCode提交。
