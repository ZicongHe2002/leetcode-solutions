# 776. Split BST · Python

[原题](https://leetcode.com/problems/split-bst/)。

原题BST有1..50个节点，节点值与target在0..1000。原地拆为两个BST，第一棵值<=target，第二棵值>target；同一输出树中的原父子必须仍直接相连，而不只是保持中序值集合。返回两个根，不新建节点、不修改值。TreeNode由LeetCode提供；实现额外支持空树返回[None,None]，单列为扩展。

沿原BST查找target的分界路径行走。若当前node.val<=target，它的整个左子树也<=target，保留该左边；把node接到small树的右侧链尾，保存原右孩子作为下一步，再断开当前右边。若node.val>target，它的整个右子树都>target，保留该右边；把node接到large树的左侧链尾，保存原左孩子后断开当前左边。

两棵树的链尾是尚未确定边界孩子的唯一位置。小侧新节点来自已走路径的右子树，值大于小侧先前链尾；大侧新节点来自已走路径的左子树，值小于大侧先前链尾，所以连接保持BST序。每次只有分界方向的孩子尚需分类，另一侧整棵子树已可确定，最终所有原节点恰归一侧，没有丢失或重复。

若原父子落在同一输出侧，非分界方向边从不修改；分界方向边若孩子同侧，下一轮立即把该孩子接回原父亲，原边仍在。只有原父子跨侧时才删除边，并把更深的同侧节点接到链尾，满足题目正式保边合同。下一步先保存再清空旧边，避免丢掉尚未处理的子树，也避免临时跨树引用保留到返回。

只访问高度为h的分界路径，时间O(h)，最坏O(n)；两个头尾和一个游标额外空间O(1)。不递归、不遍历所有已整侧分类的子树。

独立oracle先记录原树前序与所有边，分别过滤两侧值，再按过滤前序重新插入构造期望BST；不复用分界路径拆边。枚举1..7节点全部625种BST形状，以奇数作中序值，遍历合法阈值共9412次查询。核对完整输出结构、原节点身份/值、每节点恰出现一次、两侧互斥，以及所有原同侧父子边保持。另核对官方例、50节点左右链、值0及target=1000，空树只算扩展。未向LeetCode提交。
