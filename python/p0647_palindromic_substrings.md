# 647. Palindromic Substrings · Python

[原题](https://leetcode.com/problems/palindromic-substrings/)。

输入为1..1000个小写英文字母，返回回文连续子串的出现次数；相同内容出现在不同下标区间时分别计数，例如aaa应为6。本实现额外支持空字符串返回0。

用0..2n-2的虚拟中心统一奇偶情况：偶数中心落在字符上，奇数中心落在字符间。每成功向外扩展一次，就恰好产生一个回文区间，因此加1；字符不等或越界时停止。任意非空回文区间由唯一中心及扩展半径决定，故全部出现都会计到且不会重复计同一区间。这里按区间计数，不对字符串值做集合去重。最坏全相同输入成功扩展n(n+1)/2次，时间O(n²)，额外空间O(1)。

独立oracle枚举全部连续区间，直接与反转比较并累计布尔值，不使用中心扩展。枚举a/b/c上长度0..8的全部9841个字符串。边界覆盖1000个a得到500500、500个a接500个b得到250500、长度1000的abc周期串仅有1000个单字符回文、aaa的重复出现、空扩展与经典abc样例。
