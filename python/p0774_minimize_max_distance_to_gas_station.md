# 774. Minimize Max Distance to Gas Station · Python

[原题](https://leetcode.com/problems/minimize-max-distance-to-gas-station/)。

原题stations长度10..2000，坐标为0..10^8内严格递增整数，新增1..10^6座加油站，可放在任意实数坐标。最小化最终相邻站点最大距离，允许绝对误差10^-6。测试的小规模合同也保留至少10个原站点，不把两站点简化问题当作原题合法边界。输入保持。

在一段长度g的原间隙中放t个新站，最优是均匀分成t+1段，最大距离为g/(t+1)；要不超过正数d，至少需ceil(g/d)-1个新站。各原间隙独立，所需数量相加不超过k就可行，剩余新站继续放入间隙只会缩小局部段长，因此至多k的可行性也满足恰好新增k的要求。

为避开浮点除法在整倍数处的ceil误差，把候选距离固定为q/S，S=10^7，q为正整数。所需数量为ceil(g*S/q)-1，因分子分母都是正整数，严格等于(g*S-1)//q。整个二分可行性计算只用整数，不需要减epsilon或转浮点后判断整除。q越大所需站越少，二分寻找最小可行q；上界max(gaps)*S无需新增站就已可行。

设连续问题的精确最优距离为d*，取q=ceil(S*d*)所得网格距离可行，最小可行网格值位于[d*,d*+1/S)。最后仅返回时作一次除法转float。值不超过10^8，Python binary64在这个范围的一次舍入误差至多2^-27，合计小于1.08*10^-7，严格小于题目10^-6容差。这里的正确性依赖原坐标为整数与固定坐标范围，未声称网格结果是精确有理最优值。

设原站数N、最大原间隙G，整数二分时间O(N log(G*S))，间隙副本空间O(N)。原题乘积不超过10^15，Python整数不会溢出，不按k逐个插站。

独立oracle枚举把k个新站分配到所有9个原间隙的全部非负整数分配，逐项用Fraction(g,t+1)计算各分配的真实最优最大段长，取最小值；不使用二分或向上取整。10站、七个单位间隙及两个1..5间隙的25组坐标，各k=1..4并作高坐标平移，共200查询。另核对官方两例、2000站/10^6新增、10^8坐标及超大单间隙，精确比较返回值误差与输入保持。未向LeetCode提交。
