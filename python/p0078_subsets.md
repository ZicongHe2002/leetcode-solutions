# 78. Subsets · Python

[原题](https://leetcode.com/problems/subsets/)。

输入为1..10个互不相同的整数，值在[-10,10]，返回全部子集且不能重复，子集与答案顺序均任意。本实现保留输入，子集内按输入原有顺序排列，各结果行互不共享；额外支持空输入返回[[]]。重复值是另一题的合同，此处不声明去重。

visit(start)先保存当前path的一份副本，再枚举所有可追加的下标index>=start，递归时从index+1继续，返回后撤销追加。path的下标始终严格递增，因此同一输入元素不会重复选择，任意子集唯一对应一组递增下标并恰好到达一个递归节点。保存每个节点包含空集、单元素和完整集合，保证完整；复制path避免回溯清空旧结果。恰有2^n个节点，所有结果共保存n·2^(n-1)个元素（n>0），时间O(n·2^n)，不计结果的path和递归空间O(n)，输出空间O(n·2^n)。

独立oracle遍历0..2^n-1的全部位掩码，按位选择输入位置；比较完整元组列表而不使用集合消除重复。枚举五值集合上长度0..5的全部326种互异有序输入，检查数值、原顺序、输入保持及结果行身份。边界长度10核对全部1024个子集，覆盖-10/10端点；修改某个非空结果验证其余结果与输入保持。
