# 711. Number of Distinct Islands II · Python

[原题](https://leetcode.com/problems/number-of-distinct-islands-ii/)。

原题grid为1..50行、1..50列的二元矩阵，按四邻接收集岛屿。两岛允许平移、90/180/270度旋转与镜像后重合时视为同形；只允许平移的694题判定不能直接用于本题。接口为Solution.numDistinctIslands2，输入行和值保持，全水返回0。

显式栈遍历每个未访问陆地分量，保存完整坐标集合。方格轴向的全部八种等距方向变换由坐标交换与各轴符号翻转构成：(x,y)、(x,-y)、(-x,y)、(-x,-y)、(y,x)、(y,-x)、(-y,x)、(-y,-x)。它们恰覆盖四次旋转及其镜像，不引入缩放或斜向旋转。

每个变换分别减去最小行与最小列，移到自身包围盒左上原点，再将所有坐标排序成不可变元组。独立减两个最小值不要求原点本身是陆地，只是去除平移。八个元组取字典序最小者作规范形，放入集合计不同形状；排序去掉DFS访问顺序影响。

允许的旋转/镜像组成闭合的八元变换集合，因此等价岛屿会产生相同的八个平移规范候选，最小者必相同。反过来，最小元组相同意味着存在两个允许变换使两岛只差平移，复合一个逆变换仍是允许变换，所以不会把不等价岛误合并。形状的洞、方向分支与格子数量都保留在完整坐标中。

设总格数RC、单岛面积A，遍历O(RC)，每岛八次排序O(A log(A+1))，总体O(RC log(RC+1))上界；额外空间O(RC)。不递归、不修改陆地，不用短摘要代替完整形状相等。

独立oracle用并查集收集分量，对每对分量实际做逐次90度旋转、可选镜像，再尝试平移向量检查绝对坐标集合是否相等，不计算最小排序规范形。完整核对全部682个小二元矩阵与200个固定种子矩阵；50x50边界覆盖全水、整岛、1250孤岛，把非对称F形的八个方向分开放置核对合并为1，另比较空心环与实心方块。所有输入行身份和值保持，未向LeetCode提交。
