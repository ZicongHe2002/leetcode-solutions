# 789. Escape The Ghosts · Python

[原题](https://leetcode.com/problems/escape-the-ghosts/)。

原题玩家从(0,0)出发，1..100个ghost与目标坐标各分量在-10000..10000。每轮所有人同时上下左右移动一格或停留，玩家须在被任何ghost碰到之前到达目标；同轮相遇包括目标点也失败。ghost可重叠，目标也可为原点，输入保持。

玩家到目标的最短时间D为两坐标绝对值之和，ghost到目标的最短时间为其坐标差绝对值之和。只要一个ghost的时间<=D，它就能先到目标并停留，玩家至少需要D轮才能到达，绕路只会更迟，因此无法先于该ghost到达；同时到达也失败。

反之若每个ghost到目标都需>D轮，玩家任取一条长D的最短路即可。假设某ghost在第t轮沿这条路截到玩家，它已有长t的路径到截点，再沿玩家剩余D-t步就能在总计D轮内到目标，与其最短时间>D矛盾。因此目标距离比较也排除了所有中途截击，不需要把每个ghost的追逐策略放进搜索。严格大于才成功，不能写成大于等于。

逐个ghost比较一次，时间O(g)，额外空间O(1)，不在无限平面上BFS。目标为原点时D=0，只有ghost已在原点才会立即失败，公式自然覆盖。

独立oracle用实际四向加停留操作逐轮扩展ghost全部可能位置，再扩展玩家所有尚能避开这些位置的路径；一旦ghost可到目标，因能停留，之后再无逃出机会。oracle不计算曼哈顿距离。-2..2小坐标全部单ghost配置与允许重复的双ghost配置、全部目标共8750查询核对。另核对官方例、同时到达、原点、100个ghost与正负10000边界，检查bool和两个输入保持。未向LeetCode提交。
