# 515. Find Largest Value in Each Tree Row · Python

[原题](https://leetcode.com/problems/find-largest-value-in-each-tree-row/)。

返回二叉树每一深度所有节点值的最大值，从根所在第0层依次输出。原题0..10000个节点，值为-2^31..2^31-1；空树合法并返回空列表。采用平台TreeNode的val/left/right接口，不要求BST，输入保持。

队列在每轮开始只含当前层节点。先固定len(queue)作为本轮弹出次数，期间把孩子追加到尾部；新增的下一层节点不会被这一轮处理。循环结束后队列正好包含下一层，因而每层输出恰好一项，没有把动态队列长度当循环边界。

maximum从本层真实首节点值开始，再与每个弹出值取max，不能每层初始化为0，因为整层可能全负；也不需要用浮点无穷大作哨兵，输出始终是实际整数节点值。空树在读取queue[0]之前单独处理。

每个节点入队、出队各一次，时间O(N)。若树最大层宽为W，处理相邻两层时队列长度至多两层节点数量之和，辅助空间O(W)；结果另占O(H)，H为层数。没有递归，深10000的链不会触发递归深度限制，不改写节点或左右引用。

独立参考按显式DFS收集每个深度的全部值，结束后按深度取max，不用队列层长度控制。节点数0..5的全部二叉形状与每节点-1/0/1标签，共11497棵树对照，前后核对节点身份/值/左右引用。另测10000深链、8191节点全负完全树及32位值两端，核对整数列表，未向LeetCode提交。
