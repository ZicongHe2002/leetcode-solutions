# 7. Reverse Integer · Python

[原题](https://leetcode.com/problems/reverse-integer/)。

原题输入32位有符号整数，按十进制反转数字，超出[-2^31,2^31-1]返回0，并要求不能依赖64位中间值。末尾0反转后自然成为无效前导0。生产实现不先取最小负数的绝对值，也不先构造超范围反转数再判断。

把正输入取负，负输入保持，使待处理x和result始终非正。Python中x%-10得到-9..0的余数digit；x-digit是可被10整除的非正数，所以(x-digit)//10得到去掉末位后的数，不受负数向下取整影响。x-digit向0方向移动或保持不变，仍在32位范围。

乘加前要求result不少于-214748364；相等时，若最终要转为正数，最后负位不得小于-7，否则不得小于-8。通过后result*10+digit一定在允许负域内，乘法本身也不会越界。最终正输出取负前已受-2147483647界约束，原负输出可保留-2147483648。因此所有生产算术中间值均可放入有符号32位。

至多10轮，固定32位下时间和额外空间O(1)，没有字符串或浮点转换。

独立oracle在测试中允许Python宽整数，直接反转十进制文本再检查输出范围，不复用负域算术。-10000..10000全部20001整数核对，另含32位端点、反转接近上界而合法/溢出的输入、负数对称、0和末尾0，检查int及返回范围。仅测试参考使用宽整数，生产不依赖它。
