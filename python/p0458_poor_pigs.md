# 458. Poor Pigs · Python

[原题](https://leetcode.com/problems/poor-pigs/)。

恰有一桶有毒，可在有限时间内让若干只猪按计划混合饮用并观察死亡轮次，求必定辨别毒桶所需最少猪数。原题桶数1..1000，1<=minutesToDie<=minutesToTest<=100，保证至少完整一轮。单桶不需要实验，返回0。

完整轮数R=floor(minutesToTest/minutesToDie)。每只猪可在第1..R轮死亡，或始终存活，共R+1种可区分结果；p只猪最多产生(R+1)^p个联合观察，至少要覆盖全部桶，因此得到必要下界。

这一下界可以构造达到。把每桶分配一个不同的R+1进制p位标签，某位0表示对应猪不饮该桶，某位d>0表示第d轮饮该桶；每轮允许混合饮用。恰有一个毒桶，所以各猪死亡轮次或存活状态恰好恢复其各位标签。某猪在毒性生效前的其他轮只饮安全混合物，不会提前破坏观察；最后完整一轮结束不超过总时间。

从容量1和0只猪开始，用整数反复乘R+1直到容量不小于桶数，返回最小p。避免浮点对数在完全幂附近产生向上取整误差，且不把不完整轮次算成额外状态。时间O(1+log_(R+1)(buckets))，辅助空间O(1)。

独立验证通过枚举标签、建立每只猪每轮实际喂饮桶集合，再逐个模拟毒桶并检查所有观察签名唯一；少一只猪的标签枚举不足则证明该范围下界。R=1..4、桶数1..64共256个小计划核对，含多出的不完整时间。另测1000桶、最慢单轮、15/60分钟、完全幂前后和单桶。实际验证为离散计划模拟，未向LeetCode提交。
