# 237. Delete Node in a Linked List · Python

[原题](https://leetcode.com/problems/delete-node-in-a-linked-list/)。

调用者给出单链表中需要删除的非尾节点node，只提供该节点而不提供头指针。原题保证至少两个节点、值互异且node不是尾节点。接口就地修改链表并返回None；不处理尾节点或None指针。

将后继的值复制到node，再让node.next跳过原后继。前面的所有节点仍然指向同一个node对象，但从头遍历时，该位置的值已变成原后继值，其后接原后继之后的序列。因此得到的值序列正好删除了原node值，长度减一，其他值的顺序不变。

这里满足的是原题对可观察值序列的删除定义，不能解释成让调用者持有的node对象消失。被复制值的原后继从主链断开；外部若另持有对象引用，该对象生命周期属于语言运行时，不属于本题返回合同。两次字段赋值只做固定数量操作，时间和额外空间均为O(1)。非尾保证访问node.next合法。

独立验证以原值列表删除指定位置形成期望，从原头遍历实际修改后的链表，检查值序列、长度、无环及None返回，不要求某个特定对象身份必须被移除。五种互异值的长度2..5全部排列及其每个非尾删除位置共980例，另测1000节点的头部、中部和倒数第二位置。
