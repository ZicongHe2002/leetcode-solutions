# 733. Flood Fill · Python

[原题](https://leetcode.com/problems/flood-fill/)。

矩形图像的行列长度均为1..50，颜色在[0,65535]，起点位于图像中。只修改原图中与起点同色且四连通的像素；原地修改并返回同一个image对象，保留各行对象。

先记录原色。新旧颜色相同时立即返回；否则在像素入栈时改色，使颜色同时充当已访问标记。每个待处理点已变为新色，并有一条原色路径连接起点。其四邻域中仍为原色的点就是尚未发现的可达点，入栈前改色保证每点至多入栈一次。按路径长度归纳，所有原色可达点最终都会发现；未连通像素不可能入栈。设被填充区域大小为k，时间O(k)，栈额外空间O(k)，最坏O(mn)，没有递归深度限制。

独立oracle不遍历栈或队列，而在原图上反复扫描，通过集合不动点求出原色连通区域，再统一生成期望图。枚举1x1、1x3、2x2、2x3、3x2、3x3的全部666个二色图，对每个起点和新色0、1、2检查，共16398次；断言返回/行对象身份。另有65535颜色端点、同色无操作、对角断开，以及最大50x50同色图。
