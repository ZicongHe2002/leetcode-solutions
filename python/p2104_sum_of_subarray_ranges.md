# 2104. Sum of Subarray Ranges · Python

[原题](https://leetcode.com/problems/sum-of-subarray-ranges/)。

原题nums长1..1000，每项在-10^9..10^9，求所有非空连续子数组的最大值减最小值之和，直接返回整数，不取模。输入保持，额外定义空数组返回0。

极差总和等于全部最大值贡献减去全部最小值贡献。两次单调栈分别求每项作指定极值时的左右区间选择数；最小值用左严格小、右小于等于，最大值用左严格大、右大于等于，把重复极值交给最右者。贡献为nums[index]*(index-left)*(right-index)。末尾按下标到达size触发清栈，不使用数值0哨兵，因此负数也能完整结算。每次每个下标至多入出一次，时间O(n)，额外空间O(n)，Python整数保留原题的大结果。

独立oracle逐个枚举连续切片，直接算max-min后相加，不复用两种边界贡献。值-2..2、长度0..6共19531个数组核对，空数组为扩展。边界覆盖1000长度、正负10^9交替、相等值、单调升降闭式期望及大于32位的结果，核对int和非负性、输入保持。
