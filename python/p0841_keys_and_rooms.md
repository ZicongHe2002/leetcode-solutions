# 841. Keys and Rooms · Python

[原题](https://leetcode.com/problems/keys-and-rooms/)。

原题2..1000个房间，只有0号初始可进入；房间中的钥匙是0..n-1房号，每房钥匙互不相同，总钥匙数1..3000。能通过已进入房间找到钥匙继续开门，判断是否能访问全部房间，保持嵌套输入列表。

把房间作为有向图节点，房间内钥匙作为出边。从0开始用栈遍历，首次发现房间就记入seen并入栈。每个已发现房间都有一条来自0的实际钥匙路径，访问它之后能拿到全部出边钥匙；栈耗尽时不存在尚可通过已拿钥匙进入的新房间，因此seen恰为从0可达的节点集合。比较数量即可，不要求图无环，也不要求钥匙不指向本房。

每个房间最多入栈一次，每把可达房间的钥匙最多检查一次，时间O(n+E)，辅助空间O(n)，E为总钥匙数。

独立oracle用Floyd布尔传递闭包计算可达性，不用栈或队列。2..4个节点的全部非空有向边子集共66061个合法图核对，保留自环并满足总钥匙数至少1。边界覆盖1000房间、链、环、不可达分量和恰好3000把钥匙，核对bool与输入保持。
