# 575. Distribute Candies · Python

[原题](https://leetcode.com/problems/distribute-candies/)。

candyType长n，2<=n<=10000且n为偶数，每个类型编号在-100000..100000。必须选择恰好n/2颗糖，求其中不同类型的最大数量。编号只表示类别，负数与0均正常计入，不按编号大小赋权，保持输入。

设全部糖果中有D种类型，能吃K=n/2颗。答案至多D，也至多K。如果D>=K，任取K种，每种取一颗即可达到K；如果D<K，先每种取一颗得到D种，再从剩余n-D颗中补足K-D颗。由于n>=K，补足总是可行，且不会减少已经获得的种类。因此上界min(D,K)可达，不能因为某类型数量多就额外算作新种类。

set只计算互异类型数，平均哈希模型下时间O(n)，额外空间O(D)，最坏O(n)。返回整数，不排序或改写原数组。仅处理题目保证的偶数长度；没有把奇数长度的向下取整当作额外合同。

独立oracle枚举所有恰含n/2个下标的组合，再逐个数所选糖的类型数，不用上界公式。长度2/4/6/8、每项取-1/0/2的全部7380个数组逐项比较。另测10000颗全同类型、全不同、每种两颗，以及类型编号的正负上下界，检查整数返回和输入保持。未向LeetCode提交。
