# 624. Maximum Distance in Arrays · Python

[原题](https://leetcode.com/problems/maximum-distance-in-arrays/)。

给定2..100000个非空升序数组，每个长1..500，总元素最多100000，值在-10000..10000。必须从两个不同数组各取一个数，最大化绝对差，返回距离。相同数组的最大值和最小值即使差更大也不能直接配对，所有输入数组及其元素保持。

处理第i个数组前，smallest/largest只来自前面i个数组，answer是此前所有跨数组元素对的最大距离。当前数组的最远候选只需它的末端值与旧smallest、它的首端值与旧largest，因为绝对差对两个有序范围的最大值必在相反极端取得。两项都来自当前数组和某个旧数组，所以满足不同数组要求。

先计算并更新answer，再把当前首尾加入运行极值，顺序不能反过来。例如[[0],[-10000,10000]]正确答案10000；若先更新极值，就会把当前数组自身两端配成20000。即使旧smallest和largest来自同一旧数组也无妨，因为本轮只把其中一个与当前数组配对。

对已处理数组数量归纳，新最优对要么已经全在旧数组中，要么一端在当前数组中，分别由旧answer与本轮两项覆盖，故扫描完整后得到最优解。不需要给所有元素排序或扫描数组内部，因为升序是输入合同。

设数组数为M，读取各首尾都是O(1)，总时间O(M)，额外空间O(1)，不把遍历所有内部元素当成必须步骤。通过下标访问后续数组而不复制arrays[1:]，也不修改任何数组。

独立oracle枚举所有不同数组下标对，再枚举两数组内部全部元素对直接求abs，不只看端点或维护运行极值。值-2/0/3的全部非空长度1/2升序行，共9种，取2..4行的全部7371组对照。另测100000个单元素数组、200个500长数组、同数组两端不能配对、正负10000、同值及样例，核对整数与输入保持。未向LeetCode提交。
