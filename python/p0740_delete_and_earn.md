# 740. Delete and Earn · Python

[原题](https://leetcode.com/problems/delete-and-earn/)。

原题nums长度1..20000，值为1..10000。选择一个值v可获得v分，并删除该元素及全部值为v-1或v+1的元素；可重复选择，求最大总分，保持输入。

若决定选择某个值v，所有相同值的元素都可以随后选完，因为它们彼此不冲突，也不会再额外删除其他值。因此先汇总points[v]=v出现次数乘v，问题变为选择不相邻的值，取得最大权重和。相邻是数值差1，而不是原数组下标相邻。

扫描值域时，previous1为处理到前一个值的最优收益，previous2为再前一个值的收益。当前值可以不选，保留previous1；或选择，取得previous2+points[v]，两者取大。两个右侧先求值再更新，保留所需前缀。设U=max(nums)，时间O(n+U)，辅助空间O(U)，原题U最多10000。

独立oracle直接枚举原题删除操作：挑一个仍存在的元素赚分，删除该下标以及所有相邻值，再递归尝试每一种后续操作，不先汇总成按值动态规划。3种正值、长度1..7的3279个数组核对。边界覆盖20000元素、全是10000、完整值域重复两次、相邻值冲突与稀疏取值，核对int与输入保持。
