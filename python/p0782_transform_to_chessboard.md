# 782. Transform to Chessboard · Python

[原题](https://leetcode.com/problems/transform-to-chessboard/)。

原题2..30阶二值方阵，一步可交换任意两整行或任意两整列，求变成横竖相邻都不同的棋盘的最少步数，无解返回-1。不是只交换相邻行列，也不允许单独翻转或改格值。输入保持。

合法棋盘的任意矩形四角异或必须为0，而整行/列置换不改变这一全体矩形性质。以首行首列作参照，检查b00 xor bi0 xor b0j xor bij==0；通过后每行只可能是首行或其逐位互补，每列也同理。此时首列代表行类型、首行代表列类型，要能交替排列，其1的数量都必须为floor(n/2)或ceil(n/2)，否则不可能。

把首列与0,1,0,1,...比较，得到行类型错位数m；换成反相目标时错位数为n-m。偶数阶两种目标含相同数量的1，均可选，取较小错位数。奇数阶两种目标的1数量相差1，只有与现有数量相同的目标可选；该目标错位数为偶数，另一目标为奇数，所以若m为奇数就改为n-m。首行的列类型完全同样计算。

同数量的二值序列中，错误0位置和错误1位置成对，每次交换一对恰修复两处；一次交换最多修复两处，因此最少交换数正是错位数/2。行列类型可以独立选交替顺序：四角异或条件给出每格等于行类型 xor 列类型 xor 固定角值，两种类型都交替后必为两个合法棋盘相位之一，所以两种最小代价直接相加，没有遗漏角值耦合。

检查全部格需O(n^2)时间，类型计数O(n)，额外空间O(1)，不枚举行列排列，不真实交换输入。

独立oracle从两个目标棋盘相位出发，枚举所有行置换和列置换。任意置换的最少任意两项交换数为n减循环个数，记录每种得到的棋盘的最小行列交换总数；不使用生产四角异或、平衡计数或错位公式。2/3/4阶全部66064二值棋盘逐个核对。另核对官方例、30阶两相位、奇偶阶成块类型需14次、单格破坏及类型失衡，检查int和输入保持。未向LeetCode提交。
