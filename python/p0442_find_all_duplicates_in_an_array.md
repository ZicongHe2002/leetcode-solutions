# 442. Find All Duplicates in an Array · Python

[原题](https://leetcode.com/problems/find-all-duplicates-in-an-array/)。

输入长度n的整数列表，初始每项在1..n内，每个值只出现一次或两次，返回出现两次的全部值，顺序不限。要求线性时间和不计输出的常数额外空间。实现会修改nums的符号，不承诺保持原始数组；若调用方之后需要原值，应自行保留副本或按该实现的符号规则恢复。

将值v映射到下标v-1，借用该位置的符号作为是否见过v的标记。第一次见到时将该位置改为负数；再次见到时标记已经为负，将v加入输出。原始值都严格为正，没有0无法变负的问题，也保证映射下标始终合法。

由于数组中的位置可能在迭代器读到之前已经被其他值标记，每次必须先取abs(value)恢复该位置的原始正值。标记只改变符号，绝对值序列不变。原题每个值至多出现两次，因此第二次命中只会输出一次，不需要额外集合去重；不能把同一方法直接推广到任意重复次数还声称输出不重复。

每个位置扫描一次，时间O(n)，除返回列表外只用几个整数，额外空间O(1)。输出最多n/2项。没有使用生产Counter、排序副本或访问范围外的标记数组。

独立oracle在修改前用Counter统计真实频率，核对输出集合、去重、正整数值，以及修改后逐位置绝对值仍等于原输入。枚举长度1..6且取值在1..n的全部组合，筛选每值最多两次的合法输入后全量核对。另测100000项全不同、全部成对出现和最大下标重复，覆盖未来位置先被标负的情况。
