# 673. Number of Longest Increasing Subsequence · Python

[原题](https://leetcode.com/problems/number-of-longest-increasing-subsequence/)。

原题nums长1..2000，值在-1000000..1000000，返回严格递增的最长子序列有多少个，答案保证在32位整数范围。按下标选择区分序列，所有元素相等时最长长度为1、数量为n；返回int，输入保持。

lengths[i]与counts[i]分别保存末下标为i的最长严格递增长度及达到该长度的数量，初始单元素长度1、数量1。只从值严格更小的left扩展；得到更长长度时替换长度并重置数量，得到相同长度时累加数量，较短候选丢弃。不同前驱下标给出不同倒数第二下标，不会重复统计；最终只汇总全局最长长度的末尾数量。枚举所有前驱，时间O(n^2)，额外空间O(n)。

独立参考枚举全部非空下标子集，直接检查严格递增，再按选出长度取最大及计数，不使用长度/数量DP。长度1..7、值-1/0/1共3279个数组。另测2000长度递增/递减/全同和两遍递增块，30层各重复两次的计数2^30仍在题目保证范围内，并覆盖值域端点，核对int与输入保持。
