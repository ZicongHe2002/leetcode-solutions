# 38. Count and Say · Python

[原题](https://leetcode.com/problems/count-and-say/)。

原题1<=n<=30，第1项为1，后一项按前一项连续相同数字的个数、该数字顺序描述。例如1211分为1、2、11三段，得到111221。只合并连续段，不把分散出现的同一数字一起计数。

迭代维护当前term，start标记当前连续段起点，end从下一位置扫描到字符串尾后。遇到不同字符或尾后位置时，追加段长度和段首字符，再从end开启下一段。判断尾后位置在读取term[end]之前，避免越界；每段恰处理一次，连接成下一项。n=1不做转换，直接返回1，满足迭代follow-up。

总时间与各轮扫描字符数之和成正比，峰值额外空间与最长一轮字符串长度成正比；不把n轮生成成本写成只扫描最终字符串一次。原题最大第30项长度4462。

独立参考用标准库groupby划分连续相同组，核对全部n=1..30输出。另用固定前六项，并把第30项按计数/数字对解码回第29项；相邻描述组数字必须不同，计数为正，以核对最大项的游程结构和4462长度。
