# 630. Course Schedule III · Python

[原题](https://leetcode.com/problems/course-schedule-iii/)。

原题有1..10000门不同课程，每项为[duration,lastDay]，两个数均为1..10000。从第1天起连续上课，不可同时上两门，允许完成日等于lastDay；求最多可完成的课程数。即使两项数值相同，也代表不同课程，不能用集合去重。实现保留输入及内部行，额外支持空课程列表返回0。

先按截止日递增处理。若某个可行日程中相邻两门课的截止日逆序，交换它们：更早截止的课完成更早，另一门交换后的完成时间等于原来两门结束时间，也不会超过更晚截止日。因此每个可行选课集合都可按截止日安排。

selected用负时长实现最大堆，elapsed为被选课程总时长。先暂收当前课程，若总时长超过当前截止日，就撤去已选课程中最长的一门。前一轮elapsed不超过前一截止日，也不超过当前截止日；撤去的最长时长至少等于本轮加入的时长，故一次撤去就能恢复可行。去掉旧课程只会使更早课程完成得更早；当前课程如保留则放在最后，所有截止日继续满足。

最优数量可用更强的不变量说明：堆中最短的j门时长之和，是已处理前缀中任意可行j门集合的最小总时长，对0<=j<=堆大小都成立。初始显然。加入新课后，一个j门集合要么全在旧前缀，要么由新课加旧前缀的j-1门组成；两者最小总时长的较小者，正是旧堆加新时长后最短j项的和。若全选超期，大小为旧堆大小+1的集合即使采用最小总时长也超期，无法扩充数量；删除最大项保留了所有更小j的最小和。若未超期则数量增加1。因此堆大小就是此前缀的最大可行选课数，最后为全局答案。

排序和堆操作共O(n log n)时间，排序副本与堆共O(n)额外空间。独立oracle把课程当作不同下标，用子集DP尝试每个可能的最后一门课，直接核对累计用时与其截止日，不排序、不使用最大堆。五种时长/截止日组合、长度0..6共19531个序列完整对照，空输入单列扩展；另有固定种子的200个7..10门课程样本。边界覆盖10000门同值课程、恰好到截止日、所有课程不可能、撤去旧长课与原输入完整保持。未向LeetCode提交。
