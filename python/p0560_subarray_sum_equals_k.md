# 560. Subarray Sum Equals K · Python

[原题](https://leetcode.com/problems/subarray-sum-equals-k/)。

原题nums长1..20000，每项在-1000..1000，k在-10^7..10^7，统计和恰为k的非空连续子数组。负数与0都合法，不能依赖只适用于非负数的滑动窗口。输入保持，实现额外定义空数组返回0。

设当前位置前缀和为prefix，一个以当前位置结束的区间和为k，当且仅当其起点前的前缀和为prefix-k。counts保存此前每个前缀和出现的次数，初始0出现一次代表数组前的空前缀。必须先查询再登记当前前缀，才能排除k=0时把空区间算入；相同前缀的多次出现分别对应不同起点。平均哈希操作下时间O(n)，额外空间O(n)。

独立oracle枚举全部非空连续切片并直接sum，不复用前缀计数。值-1/0/1、长度0..7共3280个数组，k遍历-长度-1..长度+1，共52488次比较；空数组单列扩展。边界覆盖20000长度、全0计数200010000、正负1000与k的原题极值、正负交替，核对int及输入保持。
