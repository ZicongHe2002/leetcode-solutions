# 559. Maximum Depth of N-ary Tree · Python

[原题](https://leetcode.com/problems/maximum-depth-of-n-ary-tree/)。

给定0..10000个节点的N叉树，最大深度不超过1000，返回从根到最远叶子路径上的节点数。空树深度0，单根深度1，不把边数当深度。使用LeetCode提供的Node(val,children)接口，children的次序不影响深度；输入值和孩子列表保持。

frontier初始只含根，对应深度1的全部节点。每轮先给depth加1，再把当前层所有节点的孩子按列表展开为下一层。树中每个非根节点恰有一个父节点，所以新frontier正好是下一层，不漏节点也不会把同一节点重复加入。直到下一层为空，已经处理的层数就是最深叶子的深度。

叶子的空孩子列表不会贡献下一层；Node构造中孩子为None时也按空处理，不把它当额外层。空根在循环前直接返回0。按层推进无需递归，1000层输入不会碰到Python递归深度限制。

每个节点和每条父子边只处理一次，时间O(N)。若W为最大层宽，同时保留当前和下一层最多占O(W)引用。N叉根可能一次拥有很多孩子，所以不能把此实现空间按树高H误写成O(H)；最坏W可为O(N)。返回整数，不修改任何孩子列表或节点值。

独立参考在小树上直接按定义递归取1+最大孩子深度，不使用分层列表。1..8节点的全部626种有序N叉树形状对照，均从不可变形状新建节点。另测10000节点宽星形、1000层单链、空树、单根及None叶孩子，核对int、所有原节点值、孩子列表对象与顺序保持。未向LeetCode提交。
