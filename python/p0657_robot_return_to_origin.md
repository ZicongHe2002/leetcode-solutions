# 657. Robot Return to Origin · Python

[原题](https://leetcode.com/problems/robot-return-to-origin/)。

原题moves为1..20000个L/R/U/D字符，机器人从(0,0)出发，每次沿绝对方向走同样长度，判断全部动作完成后是否回到原点。R/L始终是向右/向左，不随面向改变；中途经过原点后又离开也应返回False。

水平净位移等于R次数减L次数，竖直净位移等于U次数减D次数。回到原点当且仅当两个差都为0，因此只需比较两对计数，不需保留路线或模拟面向。实现最多对字符串扫描4次，时间O(n)、额外空间O(1)，直接返回bool；没有构造长度n的方向列表。

独立oracle逐步更新(x,y)位置，不先统计方向次数。L/R/U/D组成的全部长度1..8共87380条路线逐一核对；另覆盖20000动作的两长段、交替返回、只一个轴不平衡及中途返回后最终离开。没有LeetCode提交记录。
