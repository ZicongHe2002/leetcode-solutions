# 344. Reverse String · Python

[原题](https://leetcode.com/problems/reverse-string/)。

原地反转字符数组，修改调用者传入的同一个列表，接口不返回反转结果。原题长度1..100000，字符为可打印ASCII。本实现额外支持空列表。字符作为整体交换，不对ASCII内容进行解释。

left与right指向尚未处理区间的两端。在每次循环之前，区间之外的字符都已经位于最终反转位置；交换两端后，该不变量扩展到这两个新位置。两指针各向中间一步，偶数长度最终相遇或交错，奇数长度保留中间字符，因此每个位置都正确。每对位置只交换一次。

时间O(n)，额外空间O(1)，同时赋值仅保存固定数量的字符引用。没有切片副本，也没有用局部变量重新绑定列表来代替修改调用者对象；函数隐式返回None。

参考结果用输入字符串的反向切片建立，检查实际列表内容与返回None。a/b/c、长度0..8全部9841个输入对照；另测100000字符、完整可打印ASCII集合、单字符、重复字符与奇偶长度。空输入单列为扩展，不声称线上Accepted。
