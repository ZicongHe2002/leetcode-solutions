# 329. Longest Increasing Path in a Matrix · Python

[原题](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)。

原题矩阵1..200行列，值0..2^31-1，求上下左右严格递增路径的最大节点数；相等值不能接边，不走对角或回绕。实现不修改矩阵，不使用可能在40000长路径上溢出的递归。

把每格指向所有严格较大邻格，严格递增保证图无环。degree保存每格剩余较大后继数，先把degree=0的局部最大值入队。按层删除这些终点，每删除一格，就给所有严格较小邻格的degree减1；只有它的全部较大后继被删除后才入下一层。

某格被删除的层数为1加其所有较大后继层数的最大值，正好是从该格出发的最长递增路径长度。最后层数就是全局答案。不能对相等邻格减degree，否则会制造不存在的边。每格和至多4条邻边各处理常数次，时间O(mn)，额外空间O(mn)。

独立oracle从每个起点直接枚举严格递增路径，不用入度/出度或拓扑分层。值0/1/2的1560个小矩阵逐一核对。最大200x200蛇形递增编号存在经过全部40000格的合法路径，验证答案40000；同样大小全2^31-1矩阵答案1，另有细长递减矩阵，核对int及输入保持。
