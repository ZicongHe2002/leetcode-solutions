# 785. Is Graph Bipartite? · Python

[原题](https://leetcode.com/problems/is-graph-bipartite/)。

输入无向简单图有1..100节点，邻接表对称，无自环或重复邻居，可能不连通。判断能否把节点分成两组，使每条边的两端分属两组；孤立节点不会造成失败。返回bool，原邻接表对象与内容不变；额外支持空图返回True。

遍历每个未着色节点以覆盖所有连通分量。为起点选颜色0，沿边让未着色邻居取反色；若已着色邻居与当前同色，则当前约束不可能满足，返回False。每个分量的起点颜色任选，所有已检查边都必须异色；无冲突时这些颜色就是一份合法划分。每节点入栈一次、每邻接项检查一次，时间O(V+E)，额外空间O(V)，不递归。

独立oracle枚举完整的两色赋值，逐边检查是否存在合法划分，不复用图遍历着色。枚举0..5节点所有无向简单图，共1100个，空图为扩展；逐次核对bool及输入邻接列表身份和内容保持。边界覆盖100节点偶环、99节点奇环加孤点、50×50完全二分图、三角形加孤点及100节点链，防止只检查第一个分量。
