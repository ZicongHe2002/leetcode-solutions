# 886. Possible Bipartition · Python

[原题](https://leetcode.com/problems/possible-bipartition/)。

原题1<=n<=2000，人员编号1..n，0..10000个不喜欢关系，关系两端满足a<b且所有对互异。要求把人分成两组，使每条关系两端不同组。孤立点可放任意组，图可能断开；返回bool，输入关系保持。

把不喜欢关系建为无向图，颜色0表示未分组，±1代表两组。从每个尚未染色的点启动BFS，发现邻居时立即赋相反颜色并入队。如果已染邻居与当前同色，这条关系无法满足，返回False。每个新点的颜色由一条生成树边确定，冲突等价于已有路径与新边要求相矛盾；无冲突时每条边两端都异色，即给出了合法分组。

外层遍历全部编号保证不漏掉断开的奇环，孤立点只处理一次。n个人、m条关系，时间O(n+m)，额外空间O(n+m)，采用迭代队列而非递归。

独立oracle枚举全部2^n种二组分配，直接检查每条关系两端的位是否不同，不复用染色搜索。n=1..5全部1099个无向简单图逐一核对。最大n=2000覆盖深链、添加三角形、只在末尾断开分量出现奇环；恰10000条边的完全二部关系验证边数上限和孤立人处理，核对bool及输入保持。
