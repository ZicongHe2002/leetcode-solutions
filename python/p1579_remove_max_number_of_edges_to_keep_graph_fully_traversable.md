# 1579. Remove Max Number of Edges to Keep Graph Fully Traversable · Python

[原题](https://leetcode.com/problems/remove-max-number-of-edges-to-keep-graph-fully-traversable/)。

原题n在1..100000，节点编号1..n；m在1..min(100000,3n(n-1)/2)，边三元组(type,u,v)互异且u<v。类型1只供Alice、2只供Bob、3两人共用。求删除尽可能多边后双方都能遍历全部节点，无法做到返回-1。输入边不排序、不改写，返回int。

先只处理类型3，为两人建立相同的共享生成森林；一条有效共享边只记为一条保留边，但两个并查集都必须实际合并，不能用短路表达式跳过Bob。若共享图有c个分量，共享森林保留n-c条边；再分别用类型1和2补足各自连通，成功时每人需c-1条有效私有边。优先取满共享森林最大化一条边同时服务两人的数量；共享环边对两人均冗余，私有环边对所属一方也冗余。任何可行解都须使每个共享分量连接到全图，两类私有边分别补足，当前森林策略达到所需保留边的下界。若任一人最终仍有多个分量，即使用尽其可用边也不能连通，返回-1。

下界可以直接计数。设一个最优保留集合用了s条共享边、a条Alice私有边和b条Bob私有边。共享边形成的环可删去一边而不影响任一人的连通性，所以最优集合中的共享边必为森林，且s<=n-c。两人各自连通分别要求s+a>=n-1和s+b>=n-1，因此总保留数满足 `s+a+b>=2(n-1)-s>=n+c-2`。算法成功时恰保留 `(n-c)+2(c-1)=n+c-2` 条，达到这个下界，所以删除数最大。

例如n=2，输入含 `[1,1,2]、[2,1,2]、[3,1,2]` 三条不同类型的边。先保留两条私有边会让后来的共享边看似冗余，只删掉1条；先保留共享边则两人都已连通，能删掉2条。原穷举测试覆盖这组合法输入，说明两轮处理顺序是最优性所需的决策。

按大小合并、路径减半，时间O(n+m*alpha(n))，两份并查集额外空间O(n)。独立参考枚举输入边的全部保留子集，分别用普通图遍历检查Alice和Bob可达性，取可行子集最少边数，不复用共享优先策略。枚举n=2..3全部518个非空合法带类型图；另测100000节点/100000边、全共享多一冗余边、只有Alice边无法服务Bob，以及99999节点共享链加两类冗余私边。核对int及输入保持。
