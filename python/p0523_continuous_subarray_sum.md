# 523. Continuous Subarray Sum · Python

[原题](https://leetcode.com/problems/continuous-subarray-sum/)。

原题nums为长度1..100000的非负整数数组，k为正整数；要求是否存在长度至少2、元素和为k整数倍的连续子数组。和为0也可以是k的0倍，单个元素无论是否整除都不合格。输入保持；额外定义空数组返回False，不支持k=0。

两个前缀和模k相等，等价于中间区间的和模k为0。earliest保存每个余数最早出现的下标，余数0初始在-1，覆盖从数组首项开始的区间。重复余数只有距离至少2才返回True；距离不足时仍保留原最早位置，因为它给未来区间留下最大长度。只维护余数即可，无需累积完整和。平均哈希操作下时间O(n)，额外空间O(min(n+1,k))。

独立oracle枚举长度至少2的全部切片，直接sum后模k；不用前缀余数表。值0..3、长度0..6共5461个数组，各测k=1..8，共43688次比较，空数组为扩展。边界覆盖100000长度、k=2^31-1、总和恰为2^31-1、两个0、单元素整除及距离不足，核对bool与输入保持。
