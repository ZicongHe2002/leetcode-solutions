# 389. Find the Difference · Python

[原题](https://leetcode.com/problems/find-the-difference/)。

原题s长0..1000，t比s长1，两串只含小写英文；t由s重排并新增一个字母得到，该字母可以已在s中出现。返回新增的单个字符，不承诺不满足频次差合同的输入，字符串保持不变。

把两个串所有字符的编码异或。原s中每次出现都能在t中找到配对，同编码异或抵消，重排不影响交换和结合律；只剩新增字符的编码，再用chr转回字符。即使新增字符已有多次出现，成对抵消后仍恰剩一次。时间O(len(s)+len(t))，额外空间O(1)，不排序、不创建频次表。

独立oracle用Counter(t)-Counter(s)取唯一正频次字符，不复用编码异或。枚举二字母s长度0..6、加入a/b/c中一个字母及t的全部不同排列，共13139例。边界覆盖1000字符、原已存在字符的再加入、单一种类重复、完整重排与原题空s，返回单字符被检查。
