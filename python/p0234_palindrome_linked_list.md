# 234. Palindrome Linked List · Python

[原题](https://leetcode.com/problems/palindrome-linked-list/)。

原题无环单链表含1..100000节点，值在[0,9]，判断值序列是否回文。本实现还把空链定义为回文。返回bool，调用结束后恢复每个原节点的next和值，调用者仍可沿原头完整遍历原链。

快指针每次两步、慢指针每次一步，定位左半末尾；偶数时是中间两节点的左边，奇数时是中间节点。反转其后的右半，便可从两端向内顺序比较，比较次数由右半长度控制，奇数中间值无需单独比较。即使发现不相等也不提前返回，最后把右半再次反转并接回左半末尾。反转保存following后才改next，故不丢失后缀；两次反转恢复所有链接。时间O(L)，额外空间O(1)，不使用递归或节点数组。

测试的oracle使用原值数组与其反序比较，另按原节点数组逐条检查调用后身份顺序、尾部None与原值保持。枚举0/1/2上长度0..8的9841条链，空链属于扩展。边界覆盖100000节点回文及仅末位破坏的非回文、99999节点奇数回文及中心相邻位置破坏的非回文、单节点和两节点；布尔返回类型也被检查。
