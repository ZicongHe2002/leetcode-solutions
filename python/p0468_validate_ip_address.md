# 468. Validate IP Address · Python

[原题](https://leetcode.com/problems/validate-ip-address/)。

按原题给定语法把queryIP分类为IPv4、IPv6或Neither。IPv4恰有4个十进制段，每段0..255且除单个0外不允许前导0；IPv6恰有8个十六进制段，每段1..4位，大小写均可，允许段内前导0。原输入只含英文字母、数字、点与冒号。本题不允许IPv6的::压缩、嵌入IPv4、前缀长度或区域标识，不能直接把通用网络库接受的全部形式视为有效。

出现点时只尝试IPv4；混入冒号的段会被十进制字符检查拒绝。split保留首尾或相邻分隔符产生的空段，段数与非空检查都不能省略。先验证1..3位ASCII数字和前导0，再安全地转为整数检查上界；不使用会接受其他Unicode数字的isdigit，也不靠异常处理正常语法分支。

没有点时按冒号分割，必须恰好8段。逐段限制长度和ASCII十六进制字符，空段导致压缩写法被拒绝；十六进制4位本身已限制在0..ffff，无需转整数。没有足够分隔符的普通字符串也不能通过段数检查。

最坏扫描输入长度L若干遍，时间O(L)。分割得到的新字符串与段列表共O(L)额外空间；没有把split隐写成常数空间。分类不修改字符串，也不进行网络访问。空串、空白、符号和Unicode数字作为额外非法输入返回Neither。

独立参考用完整匹配的正则表达式刻画语法，IPv4把0..255分成明确数字范围，IPv6固定重复8组，不调用生产的分段或数值判断。13种合法/非法候选段的全部28561个四段组合对照；另逐位置替换IPv6段、改变段数，并测大小写、压缩、混合格式、空串、空白与Unicode扩展。实际是本地字符串验证，未向LeetCode提交。
