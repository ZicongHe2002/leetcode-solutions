# 666. Path Sum IV · Python

[原题](https://leetcode.com/problems/path-sum-iv/)。

原题nums是升序的1..15个三位整数，代表有效连通二叉树。百位深度d为1..4、十位是该层完整二叉树位置p为1..8、个位为0..9的值；位置不能因同层缺少节点而压缩。返回所有根到叶路径的值之和，公共祖先的值要为每条叶路径分别计入，输入保留。

用number//10得到键10*d+p、number%10得到值。父位置是ceil(p/2)=(p+1)//2，父键为10*(d-1)+(p+1)//2。原数组升序使更浅层先处理，合法连通合同保证非根父前缀已经存在；根的虚拟父键不在表中，前缀取0。每个节点前缀等于父前缀加当前值。

完整层位坐标下，左右孩子键分别为10*(d+1)+2*p-1与其加1。两者都不在整树值表中才是叶，不能把值0当作不存在，也不能只按输入数组的相邻元素判定孩子。仅把叶前缀加进total，这等价于逐条完整根叶路径求和，不会漏算祖先的多次贡献。

n为编码数，时间期望O(n)、额外空间O(n)，没有重新分配TreeNode或递归；原题最多15节点，结果用整数。独立oracle先按有效树形创建真实节点对象，直接沿左右引用求根叶和，再把同一棵树编码为输入。深度至多4的全部676个非空树形，各用全0、全9和按层位变化三套值，共2028个输入完整对照；另查15节点全9的288、最右位置8、稀疏只有右孩子、单根0及原题例。未向LeetCode提交。
