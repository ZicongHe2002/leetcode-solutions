# 881. Boats to Save People · Python

[原题](https://leetcode.com/problems/boats-to-save-people/)。

原题1..50000人，1<=体重<=limit<=30000，每船至多2人且总重不超过limit，求最少船数，返回int。每人本身都能单独乘船；实现保持原体重数组，排序副本。

剩余最重者必须登一条船。若最轻者也不能与他同船，则其他人更重，最重者只能独自占船；若能同船，把二者配对不会增加最少船数。设二者原伙伴分别是x、y，最重者与x原本同船，而y不超过最重者，所以x+y也不超载，可放在另一条船；若原本有独乘者，余下伙伴改为独乘腾出的原船即可。于是每轮固定消耗最重者，并在可行时消耗最轻者，直到无人。只剩一人时不尝试把同一个人配两次。

排序O(n log n)，双指针O(n)，排序副本额外空间O(n)。独立参考用位集枚举把人划为单人或合法双人组，动态规划最少组数，不按轻重贪心。limit=1..4、长度1..6、各体重在1..limit的6684个合法查询；另测50000人、30000载重上界、可配/全须独乘及一轻一重，核对int及输入保持。
