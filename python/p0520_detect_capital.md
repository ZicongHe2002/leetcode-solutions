# 520. Detect Capital · Python

[原题](https://leetcode.com/problems/detect-capital/)。

判断英文单词的大写使用是否符合三种合法模式之一：全部大写、全部小写、仅首字母大写。原题word长1..100，且只含英文字母。返回bool，输入不变，不把任意混合大小写都视为合法。

一次统计ASCII大写字母数量uppercase。为0就全小写，为词长就全大写；其余只有“恰好1个大写且它位于首字符”才合法。原输入全为字母，所以首位之外没有其他大写时，其余必全小写，不需要再构造小写副本。

单字母无论大小写都合法，三种模式可以在这种边界重合，布尔或不会重复计数。FlaG之类首字母大写但后面还有大写的词必须拒绝；不能只检查word[0]或仅检查最后一位。

统计扫描O(L)时间，生成器只保留当前字符，辅助空间O(1)。直接用A..Z范围匹配原题ASCII合同，不涉及区域设置或非英文字母规则。

独立参考用完整正则匹配三种整词语法，不使用大写计数条件。a/A/b/B、长度1..7的全部21844个词对照，覆盖每种大小写分布。另测100字符全大写/全小写/首大写、末位错大写、只有末位小写及单字母，核对bool。未向LeetCode提交。
