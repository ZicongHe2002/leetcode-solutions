# 764. Largest Plus Sign · Python

[原题](https://leetcode.com/problems/largest-plus-sign/)。

原题n在1..500，n*n网格除mines指定的互异格为0外全部为1；mines长度0..min(n*n,5000)。k阶轴对齐加号包括一个中心和四个方向各k-1个连续1，求最大阶数，无1返回0。臂长计入中心，单个1的阶数为1，输入保持。

对每行先从左到右，再从右到左扫描，run遇矿归零、遇1加一。order先存左向连续长度，再取右向长度的较小值。每列再做向下扫描得到向上连续长度，最后从下到上得到向下连续长度并取最小值；在第四向完成后更新全局最大值。

某中心支持k阶加号，当且仅当四向含中心连续长度都至少为k。因此四个长度的最小值正是该中心的最大阶数，遍历所有中心取最大即全局答案。各方向run只依赖扫描路径中遇到的最近矿或边界，不会把被矿切断的1连接起来；矿格四向长度均为0。

建矿集合O(M)，四次扫描O(n^2)，哈希查询按期望常数计算，总期望时间O(n^2+M)，空间O(n^2+M)，原题M<=n^2因此可写O(n^2)。不为每个中心重复扩展整条臂。

独立oracle枚举每个中心及可能阶数，直接构造该加号需要的全部格坐标并检查边界与是否为矿，不使用四向连续长度。n=1..3所有530种矿集合全部核对，再核对100个固定种子小网格。边界包含官方例、500*500空网格阶250、合法5000矿占满前10行后阶245、70*70全4900矿为0；不使用超过5000矿的非法大边界。未向LeetCode提交。
