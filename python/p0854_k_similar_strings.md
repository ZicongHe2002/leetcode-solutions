# 854. K-Similar Strings · Python

[原题](https://leetcode.com/problems/k-similar-strings/)。

输入互为字母重排。对当前状态找最左错位i，从后方仍错位且字符等于目标第i位的位置j交换过来。已有正确前缀不必破坏，缺少的字符必能从未完成部分取得；交换把至少一个错位修正。按交换次数做BFS，首次得到目标即是最少交换数，相同字符串状态只入队一次。已正确的同字符位置不作为供给者，以免制造额外错位。

设实际搜索到S个状态、串长N，每状态至多N种交换且构造字符串O(N)，时间上界O(SN^2)，状态存储O(SN)。没有声称状态数为多项式。输入字符串保持。
