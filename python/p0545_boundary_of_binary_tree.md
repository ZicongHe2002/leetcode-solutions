# 545. Boundary of Binary Tree · Python

[原题](https://leetcode.com/problems/boundary-of-binary-tree/)。

给定1..10000个节点的二叉树，节点值在-1000..1000，返回逆时针边界值：根、非叶左边界、从左到右的叶子、反向的非叶右边界。根单独处理，只有一个根时返回其值一次。相同值可以属于不同节点，不能按值去重。使用LeetCode的TreeNode，树值和左右引用保持。

左边界只从根的左孩子开始，优先向左，缺左时才向右；根没有左孩子时左边界为空，不能擅自改从根的右子树寻找。沿途只加入非叶节点，让路径末端叶子统一由叶子阶段处理。右边界对称，从根的右孩子开始，优先向右，缺右时才向左，同样排除叶子，最后把收集的路径反向追加。

中间的叶子阶段用显式DFS栈，先压右再压左，使左子树先弹出，最终所有叶子按从左到右加入。根非叶时不会在这个阶段再次加入；单根的情况已提前返回。左右边界分别位于根的不同子树，不会互相重叠；它们排除叶子，所以和叶子列表也不重复。计数依据节点位置而非值，保留不同节点的重复值。

叶子扫描访问全部节点，左右路径各不超过树高H，时间O(N)，除返回列表外辅助空间O(H)，包含DFS栈和右边界路径；最坏退化链为O(N)。没有递归或临时改指针，能处理10000深链。

独立参考枚举所有根到叶的完整路径，左边界取左子树首条叶路径的内部节点，右边界取右子树末条叶路径的内部节点，叶子取每条路径的末端；不复用生产的两条优先边走法。所有1..8节点的2055种二叉树形状逐一对照，标签不同以核对次序。另测10000节点左右退化链、重复值、单根及缺左子树原例，核对list、所有原节点身份/值/边保持。未向LeetCode提交。
