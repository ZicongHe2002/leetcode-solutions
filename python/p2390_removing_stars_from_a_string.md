# 2390. Removing Stars From a String · Python

[原题](https://leetcode.com/problems/removing-stars-from-a-string/)。

原题s长1..100000，仅含小写字母及*，每次选一个*，同时删除它和左侧最近的非星号字符。原题保证操作可完成且结果唯一，返回str，可为空。不同于空编辑器退格题，这里不需要定义没有可删字母时的扩展行为。

从左到右处理，remaining是已读前缀删完星号后留下的字母序列。普通字母追加，星号删除当前末尾，因此删掉的恰是最近仍存在的左侧非星号字符。原题的可完成保证使每个前缀中字母不少于星号：后面的字母不能给前面的星号使用，故这里pop时不会为空。扫描给出一种合法完整删除顺序，结合唯一性得到答案。每字符至多入栈出栈一次，时间O(n)，额外空间O(n)，含输出。

独立参考对小文本尝试选择每一个星号，再在原文本中向左寻找最近非星号，直接删除两个下标并递归枚举终态。长度1..8、a/b/*的输入只保留满足可完成前缀条件者，共5352个；检查全部操作顺序的终态集合只含返回结果。另测10万字符、无星号、完全删除、交错删除后留尾字母及原题样例，核对str。
