# 17. Letter Combinations of a Phone Number · Python

[原题](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)。

输入digits长度0..4，每个字符是2..9，按电话键盘返回全部字母组合，顺序任意；空输入返回[]。不承诺支持0、1或其他字符，7和9各有四个字母，其余各三个。

从唯一空前缀开始，依次处理每个数字，生成当前全部前缀与该键全部字母的笛卡尔积。处理k个数字后，列表恰好是每个位置从其键中选一个字母的所有长度k前缀。追加位置只影响新末尾，任意完整组合可唯一拆成旧前缀和末字母，所以既完整又无重复。对空字符串单独返回[]，不把笛卡尔积的空元['']当作题目答案。

设k为数字个数、P为各键字母数量的乘积，结果需要P个长度k字符串。各层前缀数至少按3倍增长，累计字符串构造时间O(k·P)，空间O(k·P)，包含结果及构造中新旧两层同时存在的列表；最坏P=4^k。

独立oracle使用标准库itertools.product展开另一份键表，比较完整排序列表，不用集合掩盖重复。枚举2..9上长度0..4的全部4681个输入，核对每个输出的位置字母约束与长度。固定检查'23'的9个明确结果、'79'的16个结果、'7777'与'9999'各256个结果以及空输入。
