# 454. 4Sum II · Python

[原题](https://leetcode.com/problems/4sum-ii/)。

四个等长数组中各选一个下标，统计四项之和为0的下标四元组数量。原题各数组长度1..200，元素-2^28..2^28。相同数值在不同下标出现仍是不同选择，不能去重成数值集合。四个输入保持；四个数组都为空的扩展返回0。

先对前两个数组的所有下标组合计算和，用Counter保存每种和出现的次数。后两个数组每选一对值c/d，就需要前两项的和为-(c+d)，将对应频数加入答案。每个四元组被唯一拆成前后两个下标对，因此恰好计入一次；频数保留前半重复，后半重复又在遍历中分别计入，乘积数量不会丢失。

每半只有n²个下标组合，时间O(n²)，和的不同取值最坏O(n²)，辅助空间O(n²)。没有生成全部n^4四元组或按大值域分配数组。Python整数精确保留有符号和与计数；全0且n=200时答案为200^4=1600000000。

独立参考用四重下标笛卡尔积直接相加，不使用两两和频数。-1/0/1、共同长度0/1/2全部6643组四数组对照，0长度为扩展。另测200项全0的乘法重数、原题整数上下界配平、无解和经典例子，检查各数组内容保持。未向LeetCode提交。
