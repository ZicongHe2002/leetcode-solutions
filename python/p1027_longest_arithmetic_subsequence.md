# 1027. Longest Arithmetic Subsequence · Python

[原题](https://leetcode.com/problems/longest-arithmetic-subsequence/)。

当前原题nums长2..1500，元素在0..500，求保持下标顺序的最长等差子序列长度int，可以跳过元素；长度2总是可行，负差、零差也允许，输入保持不变。

ending[i][d]保存以i结尾、公差d的最长长度。对于每个left<right，将ending[left][d]接上nums[right]；若此前没有该公差，单元素nums[left]按长度1作基底，扩展成长度2。多个前驱可能得到同一末下标和公差，保留最大长度；汇总全部扩展的最大值即答案，因为任意长度至少2的最优序列必有唯一最后两下标可枚举。平均字典操作下时间O(n^2)，每个末下标至多有1001种公差，所以额外空间O(n*min(n,1001))。

独立参考枚举保留的下标子集，对长度至少2的选出序列直接扫描相邻差并取最大，不使用公差DP。长度2..8、值0/1/2共9837个数组全覆盖；另测1500长度全同/0与500交替/每值重复三次，完整0..500升降序与原题有正负差样例，核对int与输入保持。最大长度按本次原题回读的1500取值。
