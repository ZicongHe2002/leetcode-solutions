# 229. Majority Element II · Python

[原题](https://leetcode.com/problems/majority-element-ii/)。

找出整数列表中出现次数严格大于floor(n/3)的全部值，答案顺序不限，不修改输入。至多有两个答案，否则三个值各自超过三分之一会使总次数超过n。原题输入非空；这里额外支持空列表返回空列表。

维护两个不同候选和各自剩余计数。当前值匹配已有候选就增加对应计数；否则先占用空候选槽；两个槽都非空且当前值不同于两者时，各减一个计数，相当于从尚未消去的序列删除三个互异值。每次删除对任意一个真实高频值最多删除一份，而总共最多删除floor(n/3)组三元组，所以出现次数超过n/3的值不能被全部消掉，必然留在候选之中。

候选计数只是消去后的剩余数量，不是实际频率，最后必须重新统计两个候选在原列表中的真实次数，并用严格大于n//3筛选。输入是整数，None仅作为尚未设置候选的内部标记，不会与合法输入值混淆。两个候选的赋值仅在当前值不同于二者时发生，因此最终不会重复输出同一个候选。

第一次扫描O(n)，最多两次count各为O(n)，总时间O(n)；两个槽和计数使用O(1)额外空间，返回列表最多两个元素。没有构建生产频数字典或排序副本。

独立oracle直接用Counter统计全部值的实际频率。穷举四值域长度0..7的21845个数组，并核对返回值去重、整数类型与输入保持。另测严格阈值等号、单/双答案、候选需要二次过滤、极端整数，以及50000项恰好过阈值和未过阈值的数据。
