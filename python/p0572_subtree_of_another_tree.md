# 572. Subtree of Another Tree · Python

[原题](https://leetcode.com/problems/subtree-of-another-tree/)。

原题root有1..2000节点，subRoot有1..1000节点，值在-10000..10000。判断root中是否存在某节点，其自身及全部后代与subRoot的值和左右结构完全一致。不能只包含目标的一部分，也不能忽略多出的孩子。使用平台TreeNode接口，保持两棵树。额外约定空subRoot为真，空root配非空subRoot为假。

先序序列记录整数值，同时为每个空孩子输出None标记。空标记使先序能唯一还原有序二叉树，区分只有左孩子和只有右孩子，也阻止较大树只匹配到目标非空节点后就误判。使用整数token而非拼接数字字符，值12不会被当作包含值2，负号也没有歧义。显式栈先压右再压左，不受树深度或递归限制。

某节点的完整子树序列在整树先序中连续出现。反过来，非空目标模式首token为整数，匹配起点一定是某实际节点；带空标记的完整树编码恰好消耗这个节点的全部后代，不能提前结束或跨过其子树边界。因此问题化为token序列的精确连续匹配。

将subRoot序列存成pattern，构建KMP前缀表，表示每个模式前缀的最长相等真前后缀长度。流式读取root的token，失配时沿前缀表退到仍可能接续的长度，匹配则加1，达到整个模式长度就返回真。重复节点值会造成长公共前缀，回退表保证不会从每个节点重新逐棵比较，也无需概率哈希。

N/M节点各输出2N+1/2M+1个token，前缀表构建和扫描均线性，时间O(N+M)。目标序列和表占O(M)，整树生成器栈占O(H_root)，额外空间O(M+H_root)，最坏O(N+M)；无需保存整个root序列。输入不改写。

独立oracle枚举root的每个节点，以递归逐节点比较左右结构和值，不序列化也不做字符串搜索。0..3节点、每节点值取-1/1/11的157棵树，两两组合24649组；空树属于明确扩展。另测2000深链与1000节点目标、重复值长前缀末端失配、左右结构反转、12与2数字边界、额外后代和全树自身匹配，检查原节点值与引用保持。未向LeetCode提交。
