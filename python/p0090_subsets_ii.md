# 90. Subsets II · Python

[原题](https://leetcode.com/problems/subsets-ii/)。

输入有1..10个整数，值在[-10,10]且允许重复，返回所有不同子集，不能输出重复子集。答案和子集顺序任意；本实现复制排序并保留输入，子集内非递减，各结果行独立，额外支持空输入返回[[]]。

每次进入visit(start)先保存path副本。枚举index>=start时，若index>start且值等于前一个值，就跳过同层的重复首选；选中后从index+1递归。每个位置至多使用一次，同层相等分支只保留最早位置，而下一层仍允许继续选相同值。因此一个出现k次的值允许选择0..k次，并且每种次数只有一条规范路径。对每个不同值的次数选择唯一决定一个子集，故完整且无重复。保存副本和回溯pop防止结果被后续修改。

排序O(n log n)，递增下标路径至多2^n，每节点扫描与复制至多n项，保守时间O(n log n+n·2^n)；不计输出的副本、递归和path空间O(n)，输出空间O(n·2^n)。重复值会减少实际答案数，但不把最坏情况误写为多项式。

独立oracle枚举全部下标位掩码，将每个选中多重集排序后对期望结果去重；实际结果按完整列表比较，重复输出仍会失败。枚举-1/0/1上长度0..7的全部3280个有序数组。最大长度10分别验证全互异的1024个子集、全相同的11个子集以及-10/10各5次的36个子集；检查输入和结果行身份。
