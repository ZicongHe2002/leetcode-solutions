# 639. Decode Ways II · Python

[原题](https://leetcode.com/problems/decode-ways-ii/)。

原题字符串长1..100000，字符为十进制数字或*；*只代表1..9，不含0。把数字分成1..26的编码，前导0不合法，求全部展开与分组的解码数，模1000000007。实现面向原题非空输入，没有LeetCode提交记录。

令D[i]为前i个字符的解码数，D[0]=1。最后一个字母要么使用单个字符，贡献D[i-1]*single；要么使用最后两个字符，贡献D[i-2]*pair。两类按最后一组长度互斥且覆盖所有解码。single在*时为9、0时为0、其他数字时为1。

两字符中**可取11..19与21..26，第二位不能为0，故pair=9+6=15；1*为9，2*为6，其他数字接*为0。若左边是*而右边是具体数字0..6，可选十位1或2，pair=2；右边7..9仅十位1合法，pair=1。这也使*0只有10与20两种。两个普通数字直接检查10..26，左边0不会成为合法十位。首字符不计算双字符项。earlier、previous滚动保留前两状态，每轮并行赋值并取模，时间O(len(s))、额外空间O(1)。

独立小输入oracle先枚举所有*的1..9替换，再递归尝试所有合法1位/2位分组，不使用生产的pair计数表或滚动DP。全部11种字符、长度1..3，加上0/1/2/6/*组成的长度4..5，共5213个不同字符串完整对照。长度100000的全*另用按双字符组数量p分类的组合公式sum(C(n-p,p)*15^p*9^(n-2p))，以模阶乘与逆阶乘求系数，不使用逐字符DP。另覆盖100000个0、重复10、重复*0和非法前缀后长后缀，核对模范围与整数结果。
