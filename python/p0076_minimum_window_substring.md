# 76. Minimum Window Substring · Python

[原题](https://leetcode.com/problems/minimum-window-substring/)。

原题s、t长度各1..100000，含大小写英文字母且区分大小写。返回s中覆盖t全部字符及重复次数的最短连续子串，无解为空串。本实现若有多个最短解保留最早起点，并额外定义空s或空t返回空串；字符串保持。

needed记录目标频次减窗口频次，missing只数尚未满足的正缺口。右端加入字符，旧缺口为正才让missing减一，再扣减该频次。全部覆盖后持续缩左端，每个仍合法的窗口都可更新最优；移出一个字符使频次转正时才产生缺口。左右边界都只前进，保留最短结果的位置直到最后才切片。时间O(len(s)+len(t))，英文大小写固定字母表下除返回切片外额外空间O(52)。

独立oracle枚举小s的全部子串，按长度再起点顺序，用Counter检查覆盖，不复用窗口收缩。二字母s长0..6与t长0..3共1905对核对，空输入与非唯一最短解作为扩展。边界覆盖100000长度、重复需求、大小写区分、无解和ADOBECODEBANC/ABC；大输入使用明示的闭式期望。
