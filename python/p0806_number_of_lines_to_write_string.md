# 806. Number of Lines To Write String · Python

[原题](https://leetcode.com/problems/number-of-lines-to-write-string/)。

原题widths恰有26项且每项2..10，按a..z给出字符像素宽度；非空小写s长1..1000。每行上限100，从左到右尽可能写满再换行，返回[行数,最后一行实际像素宽度]。最后一行宽度不是字符数，也不固定为100。

以一行、已用0像素开始，每个字符查对应宽度。若加入后超过100，就先增行并清空已用量，再加入该字符；恰好等于100仍留在本行，不能用>=提前换行。每字符最多10像素，换行后一定可写入，不需再次拆分字符或循环换行。输入非空保证初始一行确实被使用。

处理完每个前缀后，lines是按题目贪心排版已开的行数，used是当前行真实宽度；仅在下一个字符无法容纳时换行，恰好实现尽可能长的连续行前缀。时间O(len(s))，额外工作空间O(1)，返回固定2项列表，不修改widths。

独立oracle枚举全部字符间切分掩码，直接求各段宽度并排除超过100的方案，再选行结束下标列表字典序最大的方案；这正好依次最大化每行可写前缀，而不复用逐字符used状态。9种a/b宽度组合与10个a加长度0..3二元后缀共135查询，包含精确100与刚超过100。另测官方例、单字符、26字母分别1000重复字符的闭式满行数/余量、宽度最小最大，检查列表/int和输入保持。未向LeetCode提交。
