# 561. Array Partition · Python

[原题](https://leetcode.com/problems/array-partition/)。

给定2N个整数，N在1..10000，每项-10000..10000，划成N对使每对较小值之和最大。所有元素按下标各用一次，重复值仍是不同元素，不去重。输入nums保持，返回可能为负的精确整数。

排序后记x0<=x1<=...。最小元素x0不论与谁配对都贡献x0。如果某方案将x0与xj配对、x1与xk配对，且j不等于1，则j、k都至少为2。把这两对替换为(x0,x1)、(xj,xk)，原贡献为x0+x1，新贡献为x0+min(xj,xk)，因两项都不小于x1而不会下降。即使有负数或相等值，这个不等式也成立。

因此总存在最优方案让最小的两个元素配对，移除它们后对剩余有序元素重复同一交换论证，得到相邻两两配对。每对贡献其偶下标元素，答案就是排序后的0、2、4等下标之和。无需在原数组顺序上成对，也不把每对最大值加入答案。

M=2N个输入元素，排序时间O(M log M)，求和再用O(M)。sorted构造独立列表，步长切片也分配引用，辅助空间O(M)；没有原地排序或修改原数组。累加用整数，不能把全负输入的最佳值错误地截成0。

独立参考固定剩余序列第一个下标，枚举它与每个其他下标的配对，再递归枚举剩余所有完美匹配，直接取贡献和最大值，不排序或使用相邻贪心。值-1/0/1、长度2/4/6/8，共7380个数组对照。另测20000元素、全负/全正端点、交替极值、有序连续值、原例和重复值，核对int与输入保持。未向LeetCode提交。
