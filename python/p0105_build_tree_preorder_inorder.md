# 105. Construct Binary Tree from Preorder and Inorder Traversal · Python

[原题](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)。

原题两数组等长，含1..3000个互异值，值在[-3000,3000]，且确实是同一棵二叉树的前序与中序遍历。返回重建根，不改动两个输入数组。本实现额外支持两个空数组返回None；不承诺重复值、不匹配数组或非法遍历。

前序依次提供根、左子树、右子树；中序的下一项指出当前哪一个祖先的左侧处理已经完成。栈保存尚可能接孩子的当前祖先路径。栈顶值与下一个中序值不同，说明它的左侧还未完成，下一个前序节点就是左孩子；相同时，逐个弹出已走到中序位置的祖先，再把新节点接为最后弹出节点的右孩子。唯一值让两遍历的对应节点不含歧义，每个新值只创建一个节点。各节点最多入栈/出栈一次，时间O(L)，除返回树外额外空间O(h)，不切片、不建值下标字典、不递归。

测试先由枚举树形构造已知原树，再独立取两种遍历，重建后逐个比较含None标记的结构序列与原树。结果遍历检测重复对象，防止错误共享或成环；输入数组回读检查保持。枚举长度0..7的626种树形，空树为扩展。边界覆盖3000节点纯左/纯右链、[-3000,3000]合法极值、单节点和两边均非空的例子，避免只核对遍历集合而漏掉结构错误。
