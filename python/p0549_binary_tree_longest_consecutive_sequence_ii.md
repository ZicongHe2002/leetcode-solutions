# 549. Binary Tree Longest Consecutive Sequence II · Python

[原题](https://leetcode.com/problems/binary-tree-longest-consecutive-sequence-ii/)。

给定1..30000个节点的普通二叉树，节点值在-30000..30000，求沿边连接、值每步固定加1或固定减1的最长路径长度。路径可以从孩子经父节点到另一孩子，不要求从根向下；但0→1→0这种方向中途改变的路径不合格。值可以重复，输入节点值和左右引用保持，使用LeetCode提供的TreeNode。

每个节点保存两种向下臂长：increasing从当前值开始每步加1，decreasing从当前值开始每步减1。初始都为1。孩子值恰等于当前值+1时，只能延长该孩子的increasing臂；恰等于当前值-1时，只能延长decreasing臂；差不是1则不能连接。对左右孩子各取相应方向的最长候选。

以当前节点作为路径最高点，把一条递减向下臂反向走到当前，再走递增向下臂，就形成整体递增的合法路径，长度increasing+decreasing-1，减1避免把当前节点数两次。一个孩子的首条边不可能同时是+1和-1，所以两个长度大于1的方向不会来自同一个孩子而重叠。只有一个方向时，另一个臂长1自然退化为向下路径。

任意简单路径都有一个最高节点，最多分成它左右两个方向的臂；若路径全程连续单调，它必由这里的一个递增臂和一个递减臂组成。因此遍历所有节点并取这些组合的最大值覆盖全部合法路径，不必枚举全部节点对。

显式栈用ready标记区分展开和计算，保证孩子的状态先于父节点。状态表按节点身份保存两项长度，不按值合并，因为重复值可能处于不同子树。每个节点最多展开和计算各一次，时间O(N)，状态表辅助空间O(N)，DFS栈再用O(H)。这里确实保存全部节点状态，不把总空间误写成只有O(H)；无递归，可处理30000深链。

独立参考把树转成无向邻接关系，从每个起点枚举到所有节点的唯一路径，直接检查整条路径的每个差是否全为+1或全为-1，不使用双臂递推。1..5节点的全部树形、每个节点取-1/0/1，共11496棵有值树对照。另测30000节点递增深链、交替0/1非单调深链、穿过根的30000节点连续长路、值域端点与原例；核对int及所有原值/引用保持。未向LeetCode提交。
