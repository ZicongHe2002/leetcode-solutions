# 42. Trapping Rain Water · Python

[原题](https://leetcode.com/problems/trapping-rain-water/)。

长度1..20000，高度0..100000；统计各宽1柱上方的总积水，不是选一对线的容器面积。空输入另扩展为0。left/right围住尚未结算区间，每轮先将当前端点纳入各自已知最高墙。左最高不高于右最高时结算左端，否则结算右端；最后同一位置只结算一次，原输入保持。

纳入端点后，left_max是[0,left]真实最大值，right_max是[right,n)真实最大值。若left_max较小，从left开始的完整后缀最高墙至少达到已知right_max，因此两侧最高墙的较小值已经确定为left_max，左端积水就是left_max-height[left]。另一分支对称。最大墙包含当前高度，增加量非负；已正确结算的位置不再访问，最终每个位置恰好处理一次。

时间O(n)，只存两个下标、两个最大值和总量，额外空间O(1)。最大总积水(20000-2)*100000=1999800000，Python整数精确处理。独立oracle对每个位置分别取完整左右区间最大值，不用滚动墙或双指针。四种高度长度1..7全部21844个数组核对；另查空扩展、固定盆地、20000长度最大水量、单调及全等边界。
