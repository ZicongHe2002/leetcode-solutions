# 222. Count Complete Tree Nodes · Python

[原题](https://leetcode.com/problems/count-complete-tree-nodes/)。

原题树保证完全：除最后一层外全满，最后一层从左向右连续；节点0..50000，值0..50000。要求低于O(n)时间。只支持此完全树合同，不把任意稀疏树作为合法测试；空树返回0，返回int，树保持。

比较左右子树各自沿左边走到空的高度。完全树中，若两高相等，左子树一定是满的，根加左子树共2^left个节点，只需继续计右子树；若左高大一，右子树一定是满的，根加右子树共2^right个，只需继续计左子树。已经加入的满子树与之后继续的子树不重叠，count累加后保持尚未计数区域恰为current子树。每次下降一层，每层求两次高度，总时间O(log^2(n+1))，只用计数与固定指针，额外空间O(1)。

独立参考按left/right逐节点扫描，不使用满树高度公式。枚举完全树所有规模0..1023共1024棵，另测50000节点最大规模、各层满前/刚满/多一个节点的边界、重复值和值域两端；核对int及原树保持。
