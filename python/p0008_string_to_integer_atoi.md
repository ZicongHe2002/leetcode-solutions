# 8. String to Integer (atoi) · Python

[原题](https://leetcode.com/problems/string-to-integer-atoi/)。

原题字符串长度0..200，字符仅为英文字母、ASCII数字0..9、空格、加减号和句点。先跳过开头空格，读至多一个符号，再读取连续数字前缀；没有数字返回0，后续非数字不再解析。结果截断到[-2**31,2**31-1]。

index依次经过前导空格、可选符号和数字阶段，阶段不会倒退。value累计已经读取的数字前缀大小，遇非数字即停止；符号后再遇空格或第二个符号不会重新开始读取。负数允许的幅值为2**31，比正数多1，因此按符号选择limit。数字幅值一旦超过limit，继续追加数字只会不减，且后续字符不会改变已读符号，可以立即返回对应边界。

只做单次扫描，时间O(s长度)，辅助空间O(1)，没有把整个输入交给整数解析器，也不把小数点后的内容当成浮点数。

独立oracle使用正则表达式识别开头的有符号数字前缀，再用Python int解析并执行上下界截断，不复用逐字符累积过程。8种字符、长度0..5的全部37449个字符串核对。边界覆盖200字符、纯空格/只有符号/前导零、32位正负端点及溢出、句点和中途空格，核对int返回。
