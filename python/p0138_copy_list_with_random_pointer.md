# 138. Copy List with Random Pointer · Python

[原题](https://leetcode.com/problems/copy-list-with-random-pointer/)。

next构成有限单链表，random指向链内任意节点或None。返回保持节点值及两类链接拓扑的深拷贝，所有返回节点都与原链分离。本实现保持原节点值及链接。原题节点数0..1000，值为-10000..10000。

第一遍按原节点对象身份登记唯一副本，不能按val登记，因为不同节点允许同值。第二遍再给副本接next和random，此时前向、后向、自身或循环random指向的副本都已经存在；None通过字典默认值保持为None。每条原链接都被替换为同一映射下的副本链接，因此节点对应关系一致，空链返回None。

两遍均只沿有限next链前进，时间O(n)，额外空间O(n)。使用映射避免了把副本临时插入原链，也无需为random环递归遍历。

测试从预先给定的节点值与random索引布局构造原链，不复用实现中的副本映射作oracle。枚举长度0..5的全部8477种random索引布局，使用包含重复值的合法值模式；另覆盖1000节点、全空random、指向同一节点、反向及自指。逐项核对新节点身份分离、链长、两类链接、修改副本后的原链保持。
