# 390. Elimination Game · Python

[原题](https://leetcode.com/problems/elimination-game/)。

从1..n的递增序列开始，先从左到右删除第一个、第三个等隔项，再从右到左同样删除，交替直到只剩一个数。原题n在1..10^9，返回最后保留的原始数值，不构建整个列表。

每轮的存活值总是一个等差序列，只需保存首项head、公差step、长度remaining及本轮方向。从左删除时首项必被删除，head增加step；从右删除时，长度为奇数才会同时删到左侧首项，偶数长度时首项保留。无论哪种方向，存活长度减为floor(remaining/2)，公差加倍，下一轮翻转方向。

这四个量完整描述下一轮的序列，既不需要保存每个数，也不能仅根据方向就决定head是否前移。长度变为1时，head就是唯一存活的原始值；n=1不进入循环直接返回1。

每轮长度至少减半，时间O(log n)，额外空间O(1)，按原题有界整数模型计算。数值仍在原序列1..n中，Python整数精确保存head与公差，不用浮点对数确定轮数。

独立oracle直接创建列表，左轮保留切片[1::2]，右轮反转后保留相同切片再反转，核对1..2000所有输入。大输入另用秩镜像递推f(n)=2*(1+floor(n/2)-f(floor(n/2)))，不复用生产head/step状态。检查二进制幂前后、奇偶长度、10^9上界及返回类型。
