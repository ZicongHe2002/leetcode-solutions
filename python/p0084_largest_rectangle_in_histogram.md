# 84. Largest Rectangle in Histogram · Python

[原题](https://leetcode.com/problems/largest-rectangle-in-histogram/)。

原题heights长1..100000，每项0..10000，各柱宽度为1，求被直方图完全覆盖的最大矩形面积。输入保持，实现额外定义空数组面积0。

pending保存严格递增高度及其最早可延伸起点。遇到更低柱时，弹出高度对应的矩形右界已确定为当前位置，以right-left计算面积，并把其最早起点传给当前高度；等高不重复压入，保留已有更早起点。0不入栈，并在末尾虚拟一个0，确保所有正高度候选结算。每个高度候选最多入出一次，时间O(n)，额外空间O(n)。

独立oracle枚举每个非空连续区间，用区间min高度乘宽度，不复用栈或边界传播。高度0..3、长度0..7共21845个数组全部核对，空数组为扩展。边界覆盖100000柱与10000高、全0、交替0、递增及递减形状，核对int和输入保持。
