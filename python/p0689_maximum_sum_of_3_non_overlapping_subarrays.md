# 689. Maximum Sum of 3 Non-Overlapping Subarrays · Python

[原题](https://leetcode.com/problems/maximum-sum-of-3-non-overlapping-subarrays/)。

原题nums长度最多20000，每项1..65535，1<=k<=floor(n/3)。必须选三个互不重叠、各长度k的连续区间，使总和最大，返回三个零基起点；多解取起点列表字典序最小者。合法k保证至少3k个元素，不能用不足三个区间或重叠窗口替代。输入保持，返回三个int组成的list。

先用滑动和得到每个长度k窗口的和windows。left[i]保存起点0..i中和最大的窗口起点；自左向右仅在严格增大时替换，所以相等取更早起点。right[i]保存i..末尾的最佳起点；自右向左扫描时在大于或等于旧和时替换，所以相等仍取更早起点。两个方向的比较符号不同，目的都是取最小下标。

枚举中间窗口起点middle。左窗口起点至多middle-k，右窗口起点至少middle+k，分别查left[middle-k]与right[middle+k]即可得到这个中间位置下的最大总和及最早左右起点。三个区域互相独立，局部各取最大不会冲突。遍历全部合法middle，就覆盖任意三窗口解的中间区间。

候选总和更大时更新答案；总和相等时显式比较完整三元组，保证全局字典序要求，而不是只比较末尾或依赖不明确的遍历顺序。正整数合同使初始best_sum=-1低于所有候选，且至少存在一个候选，最终answer一定非空。

每个滑动和、前后最佳表和中间起点扫描都为线性，时间O(n)，额外空间O(n)。没有对输入排序或修改。

独立oracle枚举所有三个起点组合，直接检查区间间隔，再对原数组切片求和，并以总和及三元组字典序排序，不使用前后最佳表。1/2数组长度3..10共2040个、全部合法k共5560次查询，另核对200个固定种子数组。20000长度覆盖65535最大值、k=1/6666的密集并列和三个稀疏峰，核对完整起点而非仅总和。未向LeetCode提交。
