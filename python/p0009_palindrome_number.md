# 9. Palindrome Number · Python

[原题](https://leetcode.com/problems/palindrome-number/)。

原题输入为有符号32位整数，判断十进制表示是否回文，返回bool，实现不把整数转换成字符串。负数因前面的负号不是回文；非零且以0结尾的正数也不是回文，因为它没有对应的前导0。0本身是回文。

每轮从x末尾取一位，接到reversed_half末尾，同时从x删去该位。直到剩余前半部分不再大于已逆转后半部分，位数已经走到中点或两半数值足以判定不相等。偶数位回文满足x==reversed_half，奇数位的中间一位不需要配对，满足x==reversed_half//10。非回文即使因为两半大小关系多处理一位，也不能满足这两种等式。

时间O(log(abs(x)+2))，辅助空间O(1)。对d位正整数，逆转过程在中点附近停止，最多读取floor(d/2)+1位；输入变量局部缩短不影响调用者的整数。

独立oracle直接比较非负整数的字符串与反向字符串。-10000..10000全部20001个值核对；边界覆盖32位正负端点、接近上限的回文2147447412、2000000002、10的幂与0，核对bool返回。
