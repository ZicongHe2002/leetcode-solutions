# 667. Beautiful Arrangement II · Python

[原题](https://leetcode.com/problems/beautiful-arrangement-ii/)。

原题1<=k<n<=10000，返回1..n的一个排列，使相邻绝对差恰有k种。答案不唯一，不能把某个固定排列当作唯一正确输出；每个数必须出现一次，差值按种类数而不是总和或出现次数计算。

先交替取区间[1,k+1]的最小、最大剩余值，得到1,k+1,2,k,...。每次取走一个端点，下一对间距恰比上一对小1，因此这k+1项已经产生差k,k-1,...,1，各一次。两端逐步收缩且不重复取中点，所以完整使用1..k+1。

再按升序追加k+2..n，尾段内部差均为1。若尾段非空，与交替段连接的差也在1..k内：交替段最后一项在2..k+1中，连接到k+2的正差最多k、至少1。因此不会增加新差种类。两个值域不相交且并集为1..n，最终既是排列又恰有k种差。k=1和k=n-1都自然包含，不需要额外返回未经核对的特殊构造。

时间O(n)，返回数组O(n)，除返回值外工作空间O(1)。测试直接核对题目输出合同：长度n、每项为int、集合和重复次数、相邻绝对差集合大小，不复述交替构造或要求某一排列。完整覆盖2<=n<=100的全部4950个合法(n,k)，再检查n=10000时k=1/2/5000/9999。没有LeetCode提交记录。
