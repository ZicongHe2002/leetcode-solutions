# 654. Maximum Binary Tree · Python

[原题](https://leetcode.com/problems/maximum-binary-tree/)。

原题数组长1..1000、值0..1000且互不相同，最大值为根，左右区间分别按同样规则建树，返回新树根。TreeNode构造器由LeetCode提供，与本仓库其他需要新建树节点的题一致；测试注入相同val/left/right接口。实现保留输入，并额外支持空数组返回None。

维护值严格递减的节点栈，它正好是已建前缀树的右侧路径。新值v比栈顶大时，新节点必须在这些较小节点的上方；逐个弹出，并把最后弹出的子树根作为新节点左孩子。最后弹出的节点包含此前弹出者构成的完整右链，不能只保留最先弹出的最小节点。若栈还非空，其栈顶是新节点的较大父节点，将它的右孩子改为新节点；原右侧较小部分已接到新节点左边，未丢失。

每次修改保持两个性质：中序恰等于已读数组，父值严格大于子值。对于互异数组，这两点唯一确定最大树：根只能是最大值，中序位置确定左右区间，再递归唯一。因此最后栈底就是所求根。每节点入栈和出栈各至多一次，时间O(n)、工作栈O(n)，另新建O(n)输出节点，不反复复制子数组或递归到1000层。
