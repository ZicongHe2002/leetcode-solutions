# 583. Delete Operation for Two Strings · Python

[原题](https://leetcode.com/problems/delete-operation-for-two-strings/)。

原题输入为长度1..500的小写英文串，只允许从任意一串删除字符，返回使两串相同的最少总删除次数；不允许替换或插入。本实现额外支持空串，空串与另一串的距离为另一串长度。字符串不可变，局部变量交换不改变输入。

删除后保留的串必须同时是两原串的子序列。若最长公共子序列长度为L，至少要删去m-L与n-L个字符，且保留该子序列就达到这个下界，所以答案m+n-2L。用滚动行计算L：末字符相同则左上角加1，不同则上方与左方取较大者。两行足够，交换输入让第二维更短。含空串扩展的时间上界为O((m+1)(n+1))，额外空间O(min(m,n)+1)，不会把替换一次错算成删除一次。

独立oracle显式枚举两个小串的全部子序列，取交集中最长长度，不复用LCS递推。二字母长度0..4的31个串全部961对均核对，含空串扩展。边界覆盖500长度全不同需要1000次删除、相同串、少一个字符、交替串移位、sea/eat及空串扩展；返回int被检查。
