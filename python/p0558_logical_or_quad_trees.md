# 558. Logical OR of Two Binary Grids Represented as Quad-Trees · Python

[原题](https://leetcode.com/problems/logical-or-of-two-binary-grids-represented-as-quad-trees/)。

两个合法四叉树表示相同N*N范围的0/1网格，N=2^x、x在0..9，即1..512。返回逐格逻辑OR对应的四叉树。使用LeetCode提供的Node(val,isLeaf,topLeft,topRight,bottomLeft,bottomRight)接口，不在生产文件重定义Node。非叶val可任意，不代表区域恒为该值；只有isLeaf为真时才能据val短路。

某输入为1叶时，该整块区域与任何另一输入OR后都为1，直接返回新1叶。某输入为0叶时，0 OR另一块等于另一块，可直接复用另一输入子树。本方法不改任何输入字段，但结果可能与输入共享节点，不承诺深拷贝；调用过程中两个原树的值和引用保持。

两边都是非叶时，分别递归合并同一位置的左上、右上、左下、右下象限，不能交错象限。每个象限得到正确OR后，若四个结果全是叶且值相同，整个区域一致，应合并成一个叶。若含非叶或叶值不同，则保留四个孩子的非叶；该非叶val取False只作占位，不参与后续区域逻辑。

按区域边长归纳，叶子规则符合布尔OR，四个象限又互不重叠并完整覆盖父区域，因此结果逐格正确。规范输入子树在0叶分支复用仍规范；新合并的四叶同值情况被压缩，所以输出也满足一致区域为叶的构造规则。叶子四个孩子为None，非叶有完整四个孩子。

设两输入节点数为T1、T2，最坏时间O(T1+T2)，短路会跳过不必访问的区域。除结果节点外，递归辅助空间O(H)，H为树高，不超过原题9次细分加根。新建结果节点最坏O(T1+T2)；复用分支少分配节点，不展开稠密网格计算生产结果。

独立验证从稠密输入网格构造规范四叉树，调用后把输出按象限解码，逐格比较直接布尔OR，并检查叶/非叶结构与一致区域压缩。全部1x1、2x2网格的260组输入树对逐一核对；另测固定种子80组4/8/16/32网格和512结构化网格。输入所有非叶故意使用True占位，验证不能误当1叶；快照核对两个原树所有值/引用保持。实际运行通过，未向LeetCode提交。
