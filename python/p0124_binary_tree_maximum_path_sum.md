# 124. Binary Tree Maximum Path Sum · Python

[原题](https://leetcode.com/problems/binary-tree-maximum-path-sum/)。

原题为1..30000节点的非空二叉树，值-1000..1000，求任意非空简单路径的最大节点和，路径可不经过根。只支持合法非空、无环树，返回int，保持val/left/right；TreeNode供本地导入，字段与评测器一致。

向父节点传递的gain只能是一条从当前节点向下的单链，否则父节点再连接会产生分叉。节点处理时左右子树已处理，负gain可舍弃为0；经过当前节点作为最高点的完整路径可同时接左右非负gain，用于更新best，而向上只传node.val+max(left,right)。任意简单路径都有唯一最高节点，故每条候选都会在该处计入；best从负无穷开始且每次包含node.val，保证全负树返回最大单节点而不是空路径0。

显式栈用ready标记实现后序，不依赖递归。每个节点入栈处理两阶段，时间O(n)，栈和按节点保存的gain字典总额外空间O(n)，不冒称常数或仅树高空间。非空输入至少更新一次best，返回实际整数。

独立参考把小树变成无向邻接表，从每个起点枚举所有不重复经过节点的简单路径，不复用左右gain递推。枚举1..5节点全部树形，值-1/0/2，共11496棵；另测30000节点全正和全负深链、最优路径不经根的例子。核对int及原结构和值保持，无在线Accepted记录。
