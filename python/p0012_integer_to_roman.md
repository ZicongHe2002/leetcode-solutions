# 12. Integer to Roman · Python

[原题](https://leetcode.com/problems/integer-to-roman/)。

原题1<=num<=3999，输出标准罗马数字。千位使用M，百/十/个位分别使用对应的1、5、10符号，4和9必须使用减法形式，例如IV、IX、XL、XC、CD、CM。

按数值降序枚举全部普通与减法符号，用divmod取出当前符号出现次数并保留余数。各十进制位的1..3重复单位符号，4使用减法对，5..8使用五倍符号加单位符号，9使用下一位单位的减法对；降序表正好逐位实现这些标准规则，而不是对任意面额套用一般贪心猜测。千位最多3个M，因此不会产生超出原题范围的高位表示。

输出按高位到低位拼接，不需要再整理符号。原题固定范围内符号表13项、最长输出15字符，所以时间和辅助空间为O(1)；若把输出长度作为参数，构造与存储均随输出长度增长。

独立oracle分别查千/百/十/个位的固定标准表示再拼接，不使用降序金额表和余数循环。原题全部3999个输入逐个核对，并检查编码互不相同。边界覆盖全部6种减法对、最大3999和最长15字符的3888。
