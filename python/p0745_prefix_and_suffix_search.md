# 745. Prefix and Suffix Search · Python

[原题](https://leetcode.com/problems/prefix-and-suffix-search/)。

原题有1..10000个小写词，每词长1..7，最多10000次f查询，查询前后缀均为1..7个小写字母。返回同时匹配前缀和后缀的最大原始下标，无匹配返回-1。前后缀可以互相重叠，重复词仍保留各自原下标，不能先去重后重新编号。

构造时按原始下标递增处理每个词。分别生成该词全部非空前缀和非空后缀，对所有组合保存latest[(prefix,suffix)]=index。每个前缀/后缀片段只生成一次，再由多个二元键引用，不为每个组合复制整段字符。

对任意查询，某个词匹配当且仅当这个前缀和这个后缀都分别出现在它的片段表中，所以组合键被写入的下标集合恰是全部有效下标。写入顺序递增且覆盖旧值，最后保留最大者。查询直接取键，缺失时返回-1。独立枚举片段没有不重叠限制，因此同一个完整词作为前缀和后缀也会被记录。f不修改输入或内部索引。

设N为词数、L为最长词长，最多枚举O(NL²)个组合键；若把切片、散列及相等比较的字符成本全部计入，构造时间上界O(NL³)。存储O(NL²)，包含复用片段的字符总量及二元键引用，实际重复组合会覆盖。查询前后缀长为P、S时，哈希表平均访问模型下时间O(P+S)，临时键只保存两个引用。原题L<=7，查询不扫描全部历史词。

独立oracle从原词表最后一个下标开始反向扫描，逐词直接调用startswith/endswith，不建立组合索引。6种长度1..2二元词组成长度1..4的全部1554个词表，对14种前缀和14种后缀全部304584次查询核对，覆盖重复词、重叠片段及长于词的查询。另核对官方例、最大下标与缺失、10000个七字符词和同一对象恰10000次查询及输入保持。未向LeetCode提交。
