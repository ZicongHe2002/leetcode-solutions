# 683. K Empty Slots · Python

[原题](https://leetcode.com/problems/k-empty-slots/)。

原题bulbs是1..n的排列，1<=n<=20000，第i个元素表示第i+1天点亮的位置，位置从1编号。0<=k<=20000，求最早一天存在两个已亮端点、之间恰k盏灯全部未亮，无解返回-1。只要求某一时刻成立，之后中间灯亮不影响已找到的最早日；输入排列保持。

把排列反转为days数组：days[p]表示零基位置p的开灯日期，日期仍从1开始。固定左端left，右端必须是left+k+1，两端都亮的第一天为D=max(days[left],days[right])。这一对能产生合法时刻，当且仅当所有内部位置的开灯日都严格大于D。若某内部日不大于D，那么两端亮齐时它已亮，而更早时两端又未齐，永远不合法；满足时最早合法日恰为D。取全部合法端点对的最小D。

内部窗口为left+1..right-1。用按days递增的单调队列保存下标，队首就是内部最早开灯日。初始化第一个内部窗口；每次判定后移除离开窗口的left+1，再把旧right作为下一窗口新内部右端加入。入队时淘汰日期不小于新项的队尾，因为它们更早过期且不会比新项更早开灯。队列存下标，过期按位置处理。

k=0时内部为空，队列始终为空，任何相邻端点对在较晚端点点亮日成立；不把端点错误加入内部。若k+1>=n则放不下两个端点，直接返回-1，包括n=1。每个位置最多进出队列一次，时间O(n)，days数组O(n)、队列O(k)，总额外空间O(n)。

独立oracle按输入顺序逐日点亮布尔数组，再枚举距离恰k+1的端点，直接检查内部灯全灭，不使用日期窗口或单调队列。枚举n=1..7的全部5913个排列，每个检查k=0..n，共46232次查询；另覆盖20000长度、相邻灯、先亮两端形成19998空槽、升序永无非空槽、k=20000不可放置，并核对int与原排列保持。未向LeetCode提交。
