# 58. Length of Last Word · Python

[原题](https://leetcode.com/problems/length-of-last-word/)。

原题字符串长1..10000，仅含英文字母和空格，保证至少一个单词，返回最后一个单词的字母数。本实现额外定义空串或全空格串返回0；空格指ASCII空格，不把其他分隔符纳入合同。

从末尾先跳过所有空格，end记录最后一个字母的下标；继续向左直到空格或下标-1，最后一个单词正好是(index,end]，长度为end-index。两阶段各向左单调推进，总计时间O(n)，额外空间O(1)，不创建单词数组。全空格扩展中end与index同为-1，因此返回0。

独立oracle使用split获得单词，再取最后项长度。枚举字母a/b及空格上长度1..8的全部9832个有单词输入；另检查长度0..8全空格扩展。边界覆盖10000字母单词、大量前导或尾随空格，以及大小写英文字母，返回int被检查。
