# 948. Bag of Tokens · Python

[原题](https://leetcode.com/problems/bag-of-tokens/)。

每次换得1分时买最便宜未用令牌，不比买贵的消耗更多能量；需要牺牲1分补能量时卖最贵未用令牌，得到最大补给。排序后用两端游标执行，令牌只用一次。最后一枚若买不起，无需卖掉它，因为卖出只减分且无后续令牌可买。卖出可能降低当前分数，所以单独保存全程最高分。

时间O(n log n)，排序副本空间O(n)，扫描额外空间O(1)，输入保持。
