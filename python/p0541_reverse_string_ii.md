# 541. Reverse String II · Python

[原题](https://leetcode.com/problems/reverse-string-ii/)。

给定长度1..10000的小写字符串s和1..10000的k，从开头起每2k字符反转前k个。最后不足k个时全部反转；剩余在k到2k之间时，只反转前k个，后面保持。返回新字符串，输入s保持。

把字符串转成字符列表，块起点依次为0、2k、4k等。只反转每块的[start,start+k)切片，第二半块从未被写入。Python切片会自动截到列表结尾，所以尾块不足k时实际取到全部剩余字符；尾块长至少k时则正好只取前k个。

右侧先从切片生成独立临时列表并反向迭代，再赋回同长切片，不会改变总长度。因此后续块起点仍对应原位置，不需要因上一轮反转调整下标。每个应反转的位置只属于一个前半块，其余位置保持，最后拼接为字符串。

字符总数为N，构造、各不相交前半块反转与最终拼接合计时间O(N)。字符列表和返回字符串均需O(N)空间，临时反转切片最多min(k,N)个字符，整体辅助空间上界O(N)，不把Python字符串实现误说成原地O(1)。

独立参考逐个输出位置计算它属于哪个2k块，再按块内偏移直接映射回原字符串下标，不使用反转、切片赋值或块拼接。a/b/c字符串长1..7共3279种，每个测k=1..9，共29511次对照。另测10000字符与k在1、2、4999、5000、5001、9999、10000的尾块边界，核对str、输出长度及原例。未向LeetCode提交。
