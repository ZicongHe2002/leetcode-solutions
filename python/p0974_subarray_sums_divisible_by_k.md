# 974. Subarray Sums Divisible by K · Python

[原题](https://leetcode.com/problems/subarray-sums-divisible-by-k/)。

原题nums长1..30000，每项在-10000..10000，k在2..10000，统计和能被k整除的非空连续子数组数量。负数与0均合法，输入保持，额外定义空数组返回0。

区间和能被k整除，当且仅当区间两端前缀和的余数相同。counts按0..k-1记录此前前缀余数出现次数，0先记一次代表数组前的空前缀。每项先查询当前余数已有次数，再加一次当前前缀；顺序排除空区间并保留重复起点。Python对正k取模自然落在0..k-1，负值无需额外修正。初始化数组需O(k)，扫描O(n)，总时间O(n+k)，额外空间O(k)。

独立oracle枚举全部非空切片，直接sum再检查余数，不维护前缀。值-2..2、长度0..6共19531个数组，各测k=2..8，共136717次比较；空输入单列扩展。边界覆盖30000长度、全0计数450015000、负10000、k=10000及交替正负数，核对int和输入保持。
