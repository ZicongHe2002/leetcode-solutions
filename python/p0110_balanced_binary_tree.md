# 110. Balanced Binary Tree · Python

[原题](https://leetcode.com/problems/balanced-binary-tree/)要求每个节点两侧子树高度差不超过1。`Solution.isBalanced(root)`返回布尔值，空树为True。judge提供TreeNode，按节点身份区分字典键；合同为0..5000节点、值−10000..10000、无环且无共享子节点的二叉树。算法不修改节点。

用显式栈模拟后序。未展开的节点先压回标记为已展开的自身，再压右、左孩子；LIFO使左右子树先于父节点完成。已展开时读取两个孩子的高度，差超过1就返回False，否则保存`1 + max(left,right)`。None的高度预置为0，节点值不参与平衡判断，也不作缓存键。

每次处理已展开节点时，其非空孩子已得到准确高度，而且此前已检查过的子树内部全部平衡。如果遇到局部高度差超过1，整树定义立即失败；若没有提前失败，子树都准确归纳，根节点完成后每个节点的局部约束都已验证，因此返回True。只比较根两侧高度会漏掉内部不平衡；“所有叶子同深”又比题目要求更强。

每个节点最多压栈两次，时间O(n)。显式栈O(h)，高度字典保留已完成节点共O(n)，因此额外空间总计O(n)，不写成O(h)。即使5000节点链也不触发Python递归深度限制。输入的节点值、左右引用和根身份均保持。

独立小树oracle对每个节点重新递归计算两侧高度，并递归检查两棵子树，直接对应定义，未复用实现的缓存或栈。0..7节点全部626种有序树形均核对；大树包括左右5000节点链、4095节点完整树和根处高度相同但内部失衡的构造。测试逐原节点核对值与左右引用；长链期望值由构造给定，不递归求oracle。运行事实见PR，不声称LeetCode Accepted。
