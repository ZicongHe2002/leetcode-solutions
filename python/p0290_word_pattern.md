# 290. Word Pattern · Python

[原题](https://leetcode.com/problems/word-pattern/)。

原题pattern由1..300个小写字母组成，s长1..3000，只含小写英文单词及单个分隔空格，没有首尾空格。判断模式字符与单词之间是否存在双射，位置数也必须一致。实现额外按split规范化首尾或重复空格，并允许空模式与空文本匹配；原字符串不变。

先分词并检查数量，避免zip截短后误判。forward固定每个模式字符对应的单词，backward固定每个单词对应的模式字符；逐位置双向核对并登记，任何已有关系冲突都失败。处理完后，每个模式位置都满足同一个双射。设文本长度为L、模式长度为P，时间O(L+P)，分词及映射额外空间O(L+P)。

独立oracle按位置对比较模式字符的相等关系与单词相等关系，不复用映射字典。枚举a/b/c模式与x/y/xy单词序列，位置数1..4，共7380例。边界覆盖300模式字符、3000字符单词、双向碰撞、单词数量不符及空输入/重复空格扩展，核对bool。
