# 338. Counting Bits · Python

[原题](https://leetcode.com/problems/counting-bits/)。

输入整数n在[0,100000]，返回长度n+1的整数列表，第i项是i的二进制表示中1的数量。包含0的一项，countBits(0)返回[0]；不承诺负数或超过合同范围的输入。

把i右移一位去掉最低位，剩余的1数量已在更小下标i>>1算出，再加最低位i&1。正整数右移后严格变小，所以按数值递增处理即可；0的计数用初始化0作为基例。每个输出只做常数次操作，时间O(n)，返回数组占O(n)，除返回数组外额外空间O(1)。

独立oracle把每个整数格式化为二进制字符串后统计字符1，不复用递推。逐一核对n=0..1024的1025个完整输出，共525825个条目，并检查列表长度与条目int类型。边界覆盖100000、65535/65536及若干二次幂两侧，区分输出完整前缀与只返回n的计数。
