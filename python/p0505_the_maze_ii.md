# 505. The Maze II · Python

[原题](https://leetcode.com/problems/the-maze-ii/)。

0为空地、1为墙的矩形迷宫内，小球每次选方向后必须滚到撞墙或边界才停。求能停在destination时经过格数的最小总和，不可达返回-1；经过目标但无法在那里停不算到达。原题行列1..100、至少两格空地，起终点为不同的合法空地。maze/start/destination保持；同点额外返回0。

图节点是可选择下一方向的停点，边是一次完整滚动，权重为这次移动的格数。四方向扫描到墙前或边界上的最后空格，途中不因遇到destination而截断；这与洞会中途吸收小球的The Maze III不同。零位移方向不形成有效边，直接跳过。

不同滚动的长度不同，普通FIFO BFS只能保证滚动次数最少，不能保证经过格数最少。用Dijkstra距离最小堆，每次取当前距离最小停点，对四个新端点做松弛。第一次发现一个停点还不能把距离永久标定，后续更短路线需更新并再次入堆；弹出旧距离项时跳过，避免无效重复展开。

所有有效边权为正，某停点以当前最优距离出堆时，不可能还有经由更远未处理前驱的更短路线。因而目标只有在有效出堆时才返回距离；堆耗尽则没有停点路径。输入保持，不把墙或节点值改成访问标记。

令V=mn，最多V个停点，每个有效展开至多4条边。滚动扫描上界O(V*(m+n))，总堆操作O(V log V)，时间O(V*(m+n)+V log V)，辅助空间O(V)；距离为整数，没有路径字符串的复制成本。

独立参考按行列最大空段给每个格点直接连接两端，边长为坐标差，不逐格模拟滚动；再用至多V-1轮快照松弛求最短距离，不使用堆。3x3全部512墙布局的合法不同空地起终点共9216次对照。另测100x100、单行端点/中点、最短距离12的分支迷宫、不可停目标与同点扩展，核对int和三输入保持。未向LeetCode提交。
