# 144. Binary Tree Preorder Traversal · Python

[原题](https://leetcode.com/problems/binary-tree-preorder-traversal/)。

输入二叉树有0..100节点，值在[-100,100]，返回根、左子树、右子树顺序的值列表；空树返回空列表。原节点值及左右链接保持，重复值照常保留，不把结果当作节点集合。

栈保存尚未访问的子树根。弹出时先记录根，再先压右、后压左，使后进先出的栈先完整处理左子树，然后才处理右子树。每个非空节点只入栈出栈一次，时间O(L)，除返回结果外额外空间O(h)，h为树高；无需递归或修改指针。

测试独立按枚举树形递归构造节点，并依次消耗已知前序值；期望输出直接来自构造时的值序列，而非再次实现栈遍历。枚举长度0..8的全部2056种树形，用互异前序标签发现左右颠倒，并逐次检查全部原链接和值保持。边界覆盖100层左右交替链、100节点完全树、全部同值节点、值两端及空树，原题规模内不依赖递归实现。
