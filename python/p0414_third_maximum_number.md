# 414. Third Maximum Number · Python

[原题](https://leetcode.com/problems/third-maximum-number/)。

输入非空整数列表，返回第三大的不同数值；若不同值少于三个，返回最大值。重复出现不会占据第二或第三名，输入不修改。原题至多10000项，允许32位最小负整数，不能用该值冒充“尚无候选”的哨兵。

best始终保存已扫描前缀最大的至多三个不同值，并按降序排列。当前值已经在候选中时不变；否则先加入、对至多四个值排序，超过三个就删除最小者。已经被淘汰的较小值即使再次出现，排序后仍会被淘汰，无需保存全部历史去重集合。

这一更新保持每个前缀的前三不同值不变量。全部扫描完成时，有三个候选就返回下标2，否则返回下标0。局部列表最大长度仅4，因此成员检查和排序均有固定上界，总时间O(n)、额外空间O(1)，没有对整个输入做排序或构建全量集合。

独立oracle先取全部不同值，再以“严格大于该值的不同值恰有两个”的秩定义找第三名，少于三个时直接取最大，不复用生产的固定候选更新。五值域长度1..7全部97655个数组全量核对；另测全重复、少于三种值、32位端点和10000项边界，验证int类型及输入保持。
