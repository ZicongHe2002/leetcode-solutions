# 179. Largest Number · Python

[原题](https://leetcode.com/problems/largest-number/)。

原题nums长1..100，每项0..10^9，重排后拼成最大数，以字符串返回，避免整数容量限制。输入保持，全部为0时结果为单个0。

把各项看成十进制文本，相邻两段a、b应按a+b与b+a较大者在前排列；其余前后文本相同时，这个局部比较决定整体哪一种更大。该关系可等价于比较各段反复连接的无限文本，具有传递性，能作为比较排序的依据；拼接相等时次序任意。compare在a+b较大时返回负值，使a排前。最终连接并把全0情形规范为单个0；只要有非0段，比较规则会把它放到0之前。

设单段最大位数为d（原题至多10），时间O(n*d*log n)，保存数字文本、排序与结果的空间O(n*d)。独立参考枚举所有输入排列并取最大拼接文本，不复用比较器。值0/1/10/12/121、长度1..5共3905个数组，另测100项、1000位输出、全部0及公共前缀，核对str和输入保持。
