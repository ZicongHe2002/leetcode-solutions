# 705. Design HashSet · Python

[原题](https://leetcode.com/problems/design-hashset/)。

原题MyHashSet()，键0..1000000，add插入、remove删除、contains返回是否存在；重复插入不增加副本，删除不存在键保持状态。每对象最多10000次外部调用，不使用内置哈希表库。

建立1009个各自独立的列表桶，以key%1009选桶，桶内保存完整键。add仅在桶中没有该键时追加；remove找到后删除并立即返回；contains只检查对应桶。相同键必定落在同一桶，因此能正确检测重复；不同键即使碰撞也会按完整键区分。生产实现只用列表，没有dict或set。

每次操作时间为O(1+该桶长度)，键分布均衡时为O(1+S/1009)，最坏O(S)，S为当前键数；固定取模不保证任意输入的常数时间。构造O(1009)，存储O(1009+S)。删除列表项的移动成本也包含在桶长度中。

独立模型使用普通键列表。枚举键0/1的add/remove/contains六种操作、长度1..5共9330条序列，每步另查0、1及1000000。碰撞测试使用0、1009、2018直到999919共992键，加1000000边界键，共993键；混合插入、重复、删除及查询后用993次contains收尾，单对象恰10000次外部调用，核对None/bool返回类型。
