# 218. The Skyline Problem · Python

[原题](https://leetcode.com/problems/the-skyline-problem/)。

每栋建筑为[left,right,height]，满足left<right、height>0。求从左到右可见轮廓的关键点[x,height]，相邻点高度不得相同，最终回到0。建筑在横轴上覆盖半开区间[left,right)，共享边界的建筑必须在同一坐标一起处理。原题按left排序；本实现另外排序独立的起点元组，因此不修改输入，也支持未排序输入和空列表。

所有高度变化只可能发生在建筑左右端点。按所有不同端点递增扫描，在当前坐标先加入全部起始建筑，再从最大高度堆顶部移除right<=当前坐标的过期建筑，最后只观察一次当前最大高度。先集中处理同坐标事件再输出，避免建筑交接处产生不存在的零宽高度变化。

堆保存负高度和结束位置。过期但不在堆顶的建筑可以暂留，因为它们不可能影响当前最大值；若以后升到堆顶，会在读高度之前被清理。每栋建筑最多入堆一次、出堆一次，且只在当前高度与上一关键点不同时输出，因此无连续同高点，最右端点清空全部有效建筑后输出0。

排序、堆操作总时间O(n log n)，端点集合、排序副本、堆和输出均为O(n)空间。n=0直接得到空结果。没有把坐标展开成原题可能非常长的横轴网格，生产实现也没有逐点扫描全部建筑。

独立oracle对小整数横轴的每个单位区间，直接检查全部建筑取覆盖高度，再压缩实际高度变化，不使用事件堆。18种小建筑的长度0..3多重集共1330组，覆盖重复、嵌套和同坐标事件。另测同高无缝接续、未排序扩展、32位最大坐标/高度，以及10000栋重合或间隔建筑，并核对输入保持。
