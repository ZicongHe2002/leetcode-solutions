# 227. Basic Calculator II · Python

[原题](https://leetcode.com/problems/basic-calculator-ii/)。

输入合法的非负十进制整数与二元+、-、*、/组成的表达式，允许空格，没有括号。按通常优先级、同级左结合计算，整数除法向0截断，除数非0。原题中间与最终结果在32位整数范围内；合法数字可按十进制读取前导零，不把它解释为八进制。不使用eval、exec或生产AST解析。

number累积当前数字，term保存当前尚未并入总和的带符号乘除项，total保存已经结束的加减项。遇到下一个运算符或最后一个字符时，执行previous：加减先把旧term结算进total，再开始新term；乘除直接更新term，因此不会破坏乘除优先级。最后返回total+term。

减号产生的term可能为负，Python的负数//会向负无穷取整，不符合题目要求。实现先对abs(term)整除正除数，再恢复符号，避免浮点中转。最后一个字符即使是空格也会触发一次结算；数字字符则先累积再结算，不会丢失最后一位。

每个字符访问一次，时间O(n)，只保存几个整数和标记，额外空间O(1)。依赖输入合法，不在这里引入通用表达式语法校验或支持括号、一元运算的解析器。

独立oracle使用标准库AST获得优先级与左结合结构，除法用Fraction的精确有理数再int向0截断，不复用单项累积解析。穷举1..4个操作数、值0..3和四种运算符，排除除0后共14464个表达式，带空格测试。另测负中间项除法、前导零、32位边界和199999字符的长加法链。
