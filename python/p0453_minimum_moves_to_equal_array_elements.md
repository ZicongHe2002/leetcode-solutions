# 453. Minimum Moves to Equal Array Elements · Python

[原题](https://leetcode.com/problems/minimum-moves-to-equal-array-elements/)。

每次选n-1个元素各加1，求让全部元素相等的最少次数。原题数组非空，长度1..100000，元素-10^9..10^9，保证最终答案在32位有符号整数范围。输入保持；n=1本来就相等，公式自然返回0。

把一次操作后的所有数统一减1，不会改变相等关系；相对效果就是只让被省略的那个元素减1，其他不变。因此原问题与每次单独减少一个元素、最后使所有数相等具有相同操作次数。相对目标值t不能超过原最小值m，总次数为sum(nums)-n*t，在t=m时最少；逐个把每个元素降到m又给出可实现方案，故最优答案是sum(nums)-n*m。

负数不影响论证，因为只使用大小差和整体平移。不能把目标选为平均数或中位数，那对应另一种允许增减单个元素的问题。即使最终答案有32位保证，n个负大值的中间总和仍可能很大，Python整数可以精确计算并抵消。

sum与min各扫描一次，时间O(n)，辅助空间O(1)，不排序或修改输入，也不实际模拟可能有数十亿步的过程。
