# 162. Find Peak Element · Python

[原题](https://leetcode.com/problems/find-peak-element/)。

长度1..1000，32位有符号整数，相邻元素不相等，数组外侧在数学上视为负无穷。返回任意一个严格局部峰的下标，不要求全局最大值或唯一答案。非空与相邻互异是合同，不承诺为平台区间返回严格峰。

候选[left,right]两端若有外侧相邻元素，候选端点都比各自外侧邻居高；初始用负无穷边界成立，因此区间内至少存在一个峰。若nums[middle]<nums[middle+1]，保留右半并建立新的左边界上升条件；否则相邻互异保证是下降，保留左半并建立新的右边界下降条件。区间最大值必比其相邻元素高，故至少一个峰一直被保留。left<right时middle<right，访问middle+1安全。终止的单点满足两侧边界条件，即合法峰。

时间O(log n)、额外空间O(1)，仅作比较，不对极值作减法，输入保持。独立oracle逐位置检查两侧严格大小条件，验证返回值属于全部合法峰集合；不会把某个固定下标强加给有多个答案的输入。五值长度1..7中相邻互异的全部27305个数组核对，另查1000长度升序/降序/交替峰与INT_MIN/INT_MAX边界。
