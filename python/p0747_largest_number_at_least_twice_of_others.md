# 747. Largest Number At Least Twice of Others · Python

[原题](https://leetcode.com/problems/largest-number-at-least-twice-of-others/)。

原题数组长度2..50，值0..100，最大值保证唯一。若这个最大值至少为每个其他元素的两倍，返回其原下标，否则返回-1。等于两倍也合格，零元素照常参与条件，输入保持。

先用原下标作为候选求唯一最大值位置。随后检查每个不同位置的元素是否满足max>=2*value，只要一项失败就返回-1，全部通过才返回原下标。必须排除最大值自己的位置，否则正数无法满足max>=2*max。不排序，所以不会丢失原始下标。

最大值由第一遍完整扫描找到；题目条件正是第二遍逐项检查的合取，因此两阶段直接对应定义。唯一最大值保证没有并列选择歧义；例如[50,...,50,100]仍只有100是最大值，且允许低位重复。值非负，最大值100时乘2最多200，不需要浮点除法或容差。

时间O(n)，额外空间O(1)，返回int；没有用排序的O(n log n)代价，也不改写数组。

独立oracle逐个下标尝试是否能达到所有其他元素的两倍，再选择合格下标，不先求最大值。0..4、长度2..7全部满足唯一最大值合同的44310个数组核对；另核对官方例、0与100、50元素最大值在首尾、恰好两倍与只差1的失败边界及输入保持。未向LeetCode提交。
