# 63. Unique Paths II · Python

[原题](https://leetcode.com/problems/unique-paths-ii/)。

原题障碍矩阵行列各1..100，0可走、1不可走，只能向右或向下，从左上走到右下。原题生成数据保证最终答案不超过2*10**9；起点或终点也可能被阻挡。函数保持输入。

ways[column]在处理当前格前保存从上方到达的路线数，左侧ways[column-1]已经更新为当前行的路线数。当前格可走时把两者相加，障碍格直接清零，阻断任何穿越它的路线。初始ways[0]=1代表进入起点之前的一种起始方式，若起点有障碍也会立即归零。每条合法路径最后一步只可能来自上或左，两个集合互不重叠，所以相加既不漏计也不重复。

时间O(m*n)，辅助空间O(n)，不原地覆盖障碍。Python整数能保存中间计数；最终答案的范围保证不等于每个中间格的计数也受同一上界约束。

独立oracle递归枚举每一条右/下路线，遇障碍或出界停止，不缓存格子计数。行列各1..3的全部682个二元矩阵核对。边界覆盖100*100、唯一通边走廊、全部阻挡、终点障碍前的大量中间路线，以及17*17开放区加唯一出口的601080390条路线。所有测试最终答案均在原题上界内，核对int与逐行输入保持。
