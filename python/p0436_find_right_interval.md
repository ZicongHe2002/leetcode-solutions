# 436. Find Right Interval · Python

[原题](https://leetcode.com/problems/find-right-interval/)。

对每个区间找起点不小于其终点且起点最小的区间，返回该区间在原输入中的下标，没有则-1。原题1..20000个区间，-1000000<=start<=end<=1000000，各起点互不相同；允许零长度区间，这种区间可能选中自己。输入保持，空列表额外返回空列表。

把每个起点与其原始下标配对，按起点排序；二分数组只保存有序起点。对终点end，bisect_left定位第一个>=end的起点，正好满足合法性且最小；位置超出数组即无解。不能使用bisect_right，否则起点恰好等于end时会漏掉合法候选。

结果按原区间顺序生成，并从排序配对中取原始下标，不把排序位置作为答案。起点唯一使选择没有并列歧义，终点与起点相等时也无需排除当前区间。

排序及n次二分合计O(n log n)时间，配对、起点及结果各O(n)存储，额外空间O(n)。没有在原列表上排序或为每个区间重复扫描全部输入。

独立参考逐个扫描所有原区间，直接比较合法起点并选最小，不使用有序数组或二分。起点-2..2分别不选或选一个合法终点到3，共2520个布局，连同每个布局的反向输入共5040次核对，空列表是扩展。另测20000项相邻连接、零长度自选、百万坐标边界及原列表/子列表保持。未向LeetCode提交。
