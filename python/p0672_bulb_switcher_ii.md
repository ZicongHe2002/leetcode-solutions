# 672. Bulb Switcher II · Python

[原题](https://leetcode.com/problems/bulb-switcher-ii/)。

原题1<=n<=1000，灯从1编号且初始全亮，必须恰按presses次按钮，0<=presses<=1000。四按钮分别翻转全部、偶数编号、奇数编号、编号模3为1的灯。统计最终不同状态，不统计按键顺序；恰好次数不能误写为至多次数。

同一按钮按两次抵消，不同按钮的翻转可交换，所以结果只取决于四个按钮各自次数的奇偶。枚举16个奇偶向量，设其中1的数量为count。它可实现当且仅当count<=presses且差为偶数：先把要求奇数的按钮各按一次，再在任意按钮追加成对按压即可补足；必要性来自每个按钮剩余次数都是非负偶数。该条件在presses=0时只允许零向量。

每盏灯对四按钮的成员关系由编号模2和模3决定，周期为6。n>=6时前六盏覆盖所有编号余数类，后续状态完全由它们决定，因此截取min(n,6)盏不会把两个不同完整状态错误合并；n<6则保留全部。用位掩码记录四按钮，按奇偶向量异或全亮初态，放入集合去重。不同可行向量可以产生同一状态，必须去重后计数。

最多构建6个灯位、枚举16个向量且每个处理4按钮，时间和额外空间均为O(1)，与n和presses上界无关。没有借助只适用于n>=3的计数表。

独立oracle保留全部n个灯位，从全亮状态逐次执行四种实际按钮转移，记录每一精确步数的可达状态数量，不枚举按钮奇偶。n=1..20、次数0..20共420次比较；再对n=1/2/3/6/7/1000逐步模拟次数0..1000，共6006次比较，核对截断周期、次数奇偶、小n状态合并及presses=0边界。没有LeetCode提交记录。
