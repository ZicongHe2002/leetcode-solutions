# 529. Minesweeper · Python

[原题](https://leetcode.com/problems/minesweeper/)。

原题棋盘1..50行列，输入为M、E、B或1..8，点击位置保证是尚未揭示的M或E。M变X后结束；E若八邻雷数非零只揭示数字，若为0揭示B并递归揭示邻近尚未揭示格。本实现选择原地更新并返回同一board对象，click保持，已有B和数字不会重新扩展；X只作为本次踩雷的输出。

踩雷分支立即返回。其余用队列保存待揭示E，入队时加入seen，避免同一格被多个零雷格重复加入。出队时统计八个相邻位置的M；有雷写数字后停止扩张，无雷写B并加入尚未揭示E邻格。零雷格周围没有M，所以扩展不会意外揭示地雷；数字边界不会继续向外泄漏。

每个空格最多入队一次，每次检查常数个邻格，时间O(mn)，额外空间O(mn)。全程迭代，可一次展开2500格。

独立oracle先从静态棋盘计算所有E格的邻雷数，用并查集连接相邻的零雷E格，再一次性揭示被点击零区及其相邻E边界，不复用逐格出队规则。小M/E棋盘的全部5458个有效单击逐一核对完整输出，另覆盖已有B/数字后的继续点击、八雷中心、50x50全空及全雷。验证返回对象身份、click保持与M/X/数字的完整位置。
