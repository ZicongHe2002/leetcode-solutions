# 722. Remove Comments · Python

[原题](https://leetcode.com/problems/remove-comments/)。

原题输入1..100行，每行0..80个可打印ASCII字符，没有单双引号；每个有效块注释最终闭合。//删去当前行余下部分，/*删到下一个不重叠的*/，注释内部的其他开头无效。块注释能删掉换行，从而连接开始行前缀和结束行后缀。只删空串行，保留只有空格的行；不会把删除后新相邻的字符重新识别为注释。

按原始行与字符位置扫描，inside_block只表示当前位置是否处于块注释中。块内只有*/能结束状态；块外先识别//并停止该行，再识别/*并进入块，其他字符加入pending。识别两个字符的分隔符后一次前进2，因此/*/的最后一个/不能与已用过的*重叠闭合。

pending保存尚未遇到有效换行的输出前缀。行尾仍在块内时保留pending，继续下一行；块外行尾才输出非空pending并清空。空pending不输出，含空格的pending照常输出。原题保证全部块闭合，所以末尾不会遗留被块注释隔开的未完成行。

每个原始字符至多访问常数次，输出拼接总长度不超过输入字符总数。设S为字符总数、R为输入行数，时间O(S+R)，额外工作空间O(S)，包含pending及输出。R项不能省略，因为全是空行时仍需逐行处理。输入列表与字符串保持。

独立oracle对带真实换行的完整输入用正则按出现顺序匹配整段行/块注释，并一次删除，再拆换行与过滤空串；未闭合的有效块作为非法测试输入剔除，不对结果重新分词。枚举a、/、*、换行组成的长度0..8全部字符串中合法的源程序，另核对官方样例、空行/空格、重叠分隔符、行注释内块标记及100行每行80字符的跨行边界。未向LeetCode提交。
