# 392. Is Subsequence · Python

[原题](https://leetcode.com/problems/is-subsequence/)。

原题s长0..100，t长0..10000，只含小写英文，判断能否从t删除若干字符、保持剩余顺序后得到s。空s是任意t的子序列，空t只能匹配空s；字符串保持不变。本实现处理单次判定，不建立多查询索引。

matched表示已找到的s前缀长度。自左向右扫描t，遇到当前所需字符就匹配它；选择最早可用位置不会比选择更晚位置减少后缀余地，所以贪心仍保留所有可能的完成方式。matched达到s长度后不再索引s，只继续完成扫描，最终用完整长度判定。时间O(len(t)+1)，额外空间O(1)，不切片、不生成子序列。

独立oracle显式枚举小t的全部子序列，再查询s是否在集合中，不复用贪心指针。二字母t长度0..7与s长度0..4共7905对全部核对。边界覆盖100字符s、10000字符t、顺序颠倒、重复字符与两种空串，核对bool。
