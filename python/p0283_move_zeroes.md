# 283. Move Zeroes · Python

[原题](https://leetcode.com/problems/move-zeroes/)要求把所有零移到数组末尾，同时保持非零值的相对顺序。`Solution.moveZeroes`原地修改同一nums对象，长度不变并返回None，不使用临时结果数组。

read顺序访问原数组，write表示已写入的非零值数量。读到非零值就写到nums[write]并推进write；读到零则跳过。始终有write不大于read，因此只覆盖当前或已经读过的位置，未来待读的值不会被破坏。完成第一轮后，nums[:write]按原顺序恰好包含所有非零值。

第一轮的其余位置仍可能留有旧值，必须再把从write开始的后缀填零。这样每个非零值出现次数及顺序均不变，末尾零的数量恰好为原零数量。两个线性扫描合计O(n)时间，额外空间O(1)。空数组返回None且不修改是自然扩展。

例如`[0,1,0,3,12]`最终得到`[1,3,12,0,0]`；只做第一轮会留下旧尾部，不能省略清零。测试对字母表−1、0、2及长度0至7的全部3280个数组，用独立过滤与零计数生成期望，检查完整结果、稳定顺序、对象身份、长度与返回None。实际运行结果写入PR；没有LeetCode Accepted记录。A实现，OpenAI Codex辅助整理。

## B补写：两个阶段的完整账本

输入`[0,2,0,-1,2,0]`，write初始为0。表中read与write为本轮开始值，数组为本轮结束状态。

| read | 读取值 | write（前） | write（后） | 数组 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | `[0,2,0,-1,2,0]` |
| 1 | 2 | 0 | 1 | `[2,2,0,-1,2,0]` |
| 2 | 0 | 1 | 1 | `[2,2,0,-1,2,0]` |
| 3 | -1 | 1 | 2 | `[2,-1,0,-1,2,0]` |
| 4 | 2 | 2 | 3 | `[2,-1,2,-1,2,0]` |
| 5 | 0 | 3 | 3 | `[2,-1,2,-1,2,0]` |

第一阶段仅承诺前3项。若此时返回，尾部旧的-1和2会让非零值重复出现。第二阶段依次将索引3、4、5改为0，数组依次为`[2,-1,2,0,2,0]`、`[2,-1,2,0,0,0]`、`[2,-1,2,0,0,0]`；最终结果才满足完整合同。

归纳地，在处理read前，write等于原数组前read个位置中的非零数量，已写前缀恰为这些非零值的原顺序。由于数量不超过read，赋值不会触及未来位置。每个非零原位置只遇到一次，并且只使write增加一次，所以包括重复的2在内，其原有出现次数和相对顺序都保留。最终write是非零总数，后缀长度`len(nums)-write`等于原零数量；填零消除残留值，不改动已经完成的非零前缀。全零时第一阶段write始终为0，全非零时第二阶段为空，两个边界同样满足证明。
