# 345. Reverse Vowels of a String · Python

[原题](https://leetcode.com/problems/reverse-vowels-of-a-string/)。

只反转字符串中元音出现的顺序，所有非元音字符保留原位置；大小写元音a/e/i/o/u及对应大写都参与，大小写跟随字符一起移动。原题字符串长1..300000，字符为可打印ASCII。本实现额外支持空串，返回新字符串，原字符串不可变。

两端指针跳过非元音；跳过的位置不写入，因此辅音、数字与标点始终原位。找到两端元音后交换，再缩小待处理区间。区间外已经放好逆序后的元音，区间内还未处理，交换保持不变量；剩一个元音时它应留在中间，无需交换。输入没有元音或只有一个时自然保持。

每个指针只向内移动，固定10字符的成员检查是常数时间，总时间O(n)。Python字符串不能原地写入，字符列表与join结果均需线性存储，所以额外空间O(n)，不把该实现误写成常数空间。

独立参考先收集全部元音，反向后按原元音位置重新填入，不使用双指针。a/E/b/x、长度0..7全部21845个输入对照，覆盖大小写混合与无元音。另测全部元音、标点位置、300000字符长输入及全部大写元音；空串为额外扩展。
