# 461. Hamming Distance · Python

[原题](https://leetcode.com/problems/hamming-distance/)。

原题x、y均在0..2^31-1，求对应二进制位不同的位置数量，返回int；比较时短表示的高位视为0，两数相等时结果0。

x XOR y恰在不同位置置1。对正difference执行difference & (difference-1)会清掉最低一个1：减1把该位变0、其右侧0变1，更高位不变，AND后只少了这一个1。每轮计数一次直到差异掩码归0，所以返回的就是不同位数量。时间O(h)，h为差异位数且h<=31，额外空间O(1)，按原题固定宽度计。

独立参考把两个整数分别格式化成31位二进制文本，逐字符比较并计数，不用XOR或清位算法。核对0..127内全部16384个有序数对；另组合全部31个单位置1、对应补掩码、全0/全1及两种交替掩码，覆盖高位和相等输入，核对int。
