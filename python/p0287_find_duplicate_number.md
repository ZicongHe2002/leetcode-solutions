# 287. Find the Duplicate Number · Python

[原题](https://leetcode.com/problems/find-the-duplicate-number/)。

输入长度n+1，1<=n<=100000，每个值在[1,n]，只有一个不同的值重复两次或更多次，其余值至多一次，允许部分值缺失。返回重复值，不修改数组，额外空间O(1)；不承诺多种重复值或越界值输入。

把下标i视为节点，nums[i]视为唯一后继。从人工入口0开始，因为所有后继都在1..n，路径最终进入环且0不可能在环内。环入口有来自尾部和来自环内的两个不同前驱，因此它的值至少出现两次；唯一重复值保证该入口就是答案。快慢指针先在环内相遇，再让一个指针从0出发、另一个从相遇点出发同步一步，消除前缀与环的距离差后在入口相遇。时间O(n)，额外空间O(1)，不借助排序、标记、集合或改写输入。

独立oracle用完整频次表找唯一频次大于1的值，不复用函数图。枚举n=1..5的全部5841个合法数组，含同一个值重复超过两次而其他值缺失的情况。边界覆盖n=100000且重复值为首/中/末值、100001个相同值以及最小输入，逐次检查原数组保持。
