# 907. Sum of Subarray Minimums · Python

[原题](https://leetcode.com/problems/sum-of-subarray-minimums/)。

原题arr长1..30000，每项1..30000，求每个非空连续子数组最小值之和，对10^9+7取模。输入保持，额外定义空数组返回0；正数合同使末尾虚拟0能弹空栈，不承诺负值输入。

栈保存严格递增值的下标，当前值不大于栈顶时弹出。被弹下标的左界是最近严格更小值，右界是最近小于等于它的值，因此能作为指定最小值的区间数为(index-left)*(right-index)。相等值采用左严格、右非严格的非对称边界，把含多个相等最小值的区间交给最右者，避免重计或漏计。乘上该值后累加取模；每个下标至多进出一次，时间O(n)，额外空间O(n)。

独立oracle枚举每个非空切片直接min，再求和取模，不复用边界贡献或栈。值1/2/3、长度0..8共9841个数组核对，空数组为扩展。边界覆盖30000长度、30000最大值、全相同、单调升降的闭式期望以及重复最小值，核对int和模数范围、输入保持。
