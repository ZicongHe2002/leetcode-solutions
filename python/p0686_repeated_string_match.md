# 686. Repeated String Match · Python

[原题](https://leetcode.com/problems/repeated-string-match/)。

原题a、b为非空小写字符串，长度均1..10000。求至少重复a几次，能把整个b作为连续子串包含；无论重复多少次都不能包含则返回-1。这里是子串，不是子序列，不能跳过不匹配字符；非空b也不可能由0次重复获得。

把无限重复a视为虚拟文本，第i个字符为a[i mod len(a)]。任何匹配的起点都可按周期平移到0..len(a)-1，所以只需检查前len(a)+len(b)-1个字符：最晚起点len(a)-1的匹配结束下标为len(a)+len(b)-2。这个界恰好覆盖完整匹配，不需要真的构造无限文本。

对b先构造KMP前缀表，prefix[i]为b[:i+1]的最长真前后缀长度。扫描虚拟文本时matched保持已匹配的b前缀长度；失配就沿前缀表跳到仍可能接续的真后缀，避免重复比较。匹配完成时，若结束下标为index，所需重复次数为ceil((index+1)/len(a))，用整数表达式(index+len(a))//len(a)。按结束位置递增扫描，首次完成的匹配需要的重复次数最少。

若有限扫描界内没有匹配，则所有周期起点都失败，返回-1。原题保证b非空，因此前缀下标访问有定义。时间O(len(a)+len(b))，额外空间O(len(b))；不构造重复文本，输出为int。

独立oracle依次真实构造a重复1..len(b)+1次的字符串并调用子串包含检查；该次数上界足以覆盖任何合法周期起点，不使用KMP。二元字母a长度1..4、b长度1..7共7620对输入全部核对；边界包含双方长度10000、单字符重复10000次、偏移一位需额外一次、长共同前缀后不可能、以及跨多个周期的目标。未向LeetCode提交。
