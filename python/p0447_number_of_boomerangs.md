# 447. Number of Boomerangs · Python

[原题](https://leetcode.com/problems/number-of-boomerangs/)。

统计互不相同下标的有序三元组(i,j,k)，使i到j与i到k的欧氏距离相等；j与k交换顺序算另一个结果。原题1..500个坐标互不相同的点，每个坐标-10000..10000。输入不修改，空点集额外返回0。

逐个固定中心i，使用整数平方距离作为分组键，不开平方、不比较浮点结果。若某个距离已经出现t个其他点，新来一个同距离点会与已有每点形成两种顺序(j,k)和(k,j)，故立即增加2t，再将数量加1。一个距离组最终累计0+2+...+2(c-1)=c(c-1)，正是该组全部有序不同点对。中心自己跳过，避免混淆三个不同下标的要求。

任一合法三元组有唯一中心和唯一平方距离，必定在该中心、该距离组中计入且只计一次；不合法的不同距离点不会组成同一组。点坐标唯一是原题保证，不为重复坐标额外改变语义。

每个中心扫描全部点，哈希操作平均O(1)，总时间O(n²)，每次仅保存当前中心的距离计数，额外空间O(n)。整数算术保留精确等距关系，负坐标自然支持。

独立参考枚举所有有序不同下标三元组，直接比较两个平方距离，不使用距离分组。3*3小坐标网格的全部512个点子集对照，空集为扩展。另测500点直线的闭式计数124500、坐标值界正方形、单点/两点、经典三点直线与中心四臂图形，并检查输入保持。未向LeetCode提交。
