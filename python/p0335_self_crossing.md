# 335. Self Crossing · Python

[原题](https://leetcode.com/problems/self-crossing/)。

从原点依次向北、西、南、东循环行走，distance给出每段严格正的长度。判断路径是否与自身相交，非相邻线段的端点接触和共线重叠都算相交；相邻段天然共有的连接端点不算。原题至多100000段、每段至多100000，本实现不修改输入。

在首次相交前，正长、持续左转的轴对齐路径只能一直向外扩，或在某次转折后向内收。内收路径若再次无约束地外扩，就必须先穿过最近围成的边界。因此首次交点只需检查当前段与3、4、5步前线段的三种局部情形；更早线段位于该边界另一侧，到达前已会触发较近边界相交。

与3步前段相交：当前长度至少为两步前长度，且上一步长度不超过三步前长度。与4步前段共线重叠：上一步与三步前长度相同，使支撑直线对齐；当前长度加四步前长度至少达到两步前长度。

与5步前段相交覆盖外扩转内收的夹层：两步前长度至少为四步前长度；上一步不超过三步前长度，但加上五步前长度后能够覆盖三步前跨度；当前长度加四步前长度也能覆盖两步前跨度。代码四个不等式对应这两个轴向覆盖条件，使用包含等号的比较以保留接触情形。

每一步只读最近六个距离，时间O(n)，额外空间O(1)，无需保存所有坐标或线段。严格正长度是该局部判定的前提，不能把允许0步或任意转向的路径直接套入此结论。

独立oracle显式构造平面坐标，使用一般整数叉积与点在线段上的判定，逐一比较当前段和所有非相邻旧段，不复用局部距离公式。长度1..9、每段1/2/3共29523个数组全量核对。另测三种相交情形、端点接触、100000段严格外扩/内收和重复单位长度，检查bool类型及输入保持。
