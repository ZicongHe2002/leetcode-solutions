# 213. House Robber II · Python

[原题](https://leetcode.com/problems/house-robber-ii/)。

输入为1..100间环形排列房屋，金额在[0,1000]，不能同时取相邻房屋，第一间与最后一间也相邻，返回可取最大金额。本实现保留输入，额外支持空数组返回0。

单间必须直接返回其金额，不能把它同时当作一条自环而排除。至少两间时，任意合法方案必定不取第一间或不取最后一间，因此分别求区间[0,n-1)和[1,n)的线性最优解再取较大值。两类方案可以重叠，但最大值运算不要求互斥。线性子问题只保留前一项和前两项的最优金额：当前不取继承前一项，当前取则接前两项；同时更新恢复滚动含义。通过起止下标处理两个区间，不切片复制输入。时间O(n)，额外空间O(1)。

独立oracle枚举全部房屋下标子集，直接检查环上的每条邻接边，再对合法子集求和，不使用线性递推或排除首尾的分解。穷举0..3上长度0..6的全部5461个数组；长度0和1按接口扩展及原题单间规则处理。边界覆盖100间全1000得到50000、99间全1000得到49000、交替金额、两间互斥、经典样例及输入保持。
