# 792. Number of Matching Subsequences · Python

[原题](https://leetcode.com/problems/number-of-matching-subsequences/)。

原题s长1..50000，words有1..5000项，每项长1..50，全部为小写英文。统计words中是s子序列的项数；重复单词是不同数组项，必须重复计数。输入保持，不要求连续子串。

waiting按下一需要的字符保存(word,index)，index之前的前缀已匹配。初始化每项等待首字符；扫描s的当前字符时，先把相应整个桶从字典弹出，再推进桶中每项一个位置。单词完成即计数，否则放进新的等待桶。弹出使新建立的同字符桶与正在遍历的列表分离，例如s='a'不能让'aa'一次推进两位，也不会在遍历时无限追加。

每个状态总使用可用的最早源位置匹配下一个字符。把任何可行匹配的第一个位置换成更早位置都不会压缩后续空间，逐位归纳可知贪心推进不会漏掉子序列；扫描结束完成项恰好是答案。重复字符串分别建立状态，不会被去重。

设S为源长度，W为单词项数，L为全部单词长度之和。每个源字符处理一次，每个单词位置最多推进一次，期望时间O(S+L)。状态仅持有原字符串引用和下标，不切片复制后缀；每项至多一个活动状态，额外空间O(W)，字母表常数项另计。

独立oracle枚举源的实际下标组合，构造全部子序列字符串集合。a/b上长度1..9共1022个源，分别核对62个长度1..5的单词及含重复项的批量查询；另测官方例、单字符不能复用、50000源长度、5000单词与50单词长度边界，检查int及输入保持。未向LeetCode提交。
