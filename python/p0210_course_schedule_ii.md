# 210. Course Schedule II · Python

[原题](https://leetcode.com/problems/course-schedule-ii/)。

课程数为1..2000，编号0..numCourses-1，先修对[course,prerequisite]互异，表示后者必须先完成。返回任意一个包含全部课程的合法顺序；有有向环则返回空列表。实现还支持0课程返回空列表，不改动先修数组及其各对内容；不承诺唯一或字典序最小顺序。

把先修边定向为prerequisite到course，记录每门课尚未满足的入度。初始零入度课程全部入队；取出一门课就删除它到后继的边，后继入度恰降到0时入队。队中课程的全部先修都已输出，故每步追加合法。若最后不足全部课程，剩余子图的每个节点都有未删除入边，有限图中必含环；反之无环图一定可继续找到零入度节点。时间O(V+E)，额外空间O(V+E)，无需递归。

独立oracle枚举全部课程排列，逐一检查先修位置关系，判断是否存在合法顺序；对实现输出仅检查完整排列和全部边，不强行指定一种答案。枚举1..4课程的全部无自边有向图，共4165个。边界覆盖2000课程长链、闭合该链形成环、全孤立课程、自先修和0课程扩展，逐次核对输入保持。
