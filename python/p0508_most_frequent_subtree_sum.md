# 508. Most Frequent Subtree Sum · Python

[原题](https://leetcode.com/problems/most-frequent-subtree-sum/)。

对二叉树每个节点，取以该节点为根的全部子树节点值之和，返回出现次数最多的全部不同子树和，结果顺序不限。原题1..10000个节点，值在-100000..100000；使用平台TreeNode的val/left/right接口，不要求BST。输入保持，空树额外返回空列表。

子树和必须在两个孩子都求完后计算。pending中的expanded=False表示首次看到节点，把该节点以True压回，再压右孩子和左孩子；栈先处理左边，再右边，最后才弹出父节点True项。此时孩子的和已存入subtotals，缺失孩子贡献0。

subtotals按节点身份id保存，每个真实节点恰好计算一次；节点全程被输入树引用，身份不会被回收复用。相同val的节点仍分别计算，不能把节点值当子树缓存键。frequencies按算出的整数和计数，0与负数均是正常键；最后找最大频次并返回所有并列项，不返回重复整数。

每个节点各有一次首次展开和一次合并，均为常数次字典操作，总平均时间O(N)。栈、每节点子树和及不同和频次最坏都O(N)，辅助空间O(N)，返回值另占O(N)。不用递归，10000节点链不会依赖Python递归深度；最大绝对子树和不超过1000000000，Python整数精确保存。

独立参考逐个把每个节点当根，重新遍历其整棵子树并求和，再做Counter统计，不复用孩子缓存或后序状态。节点数0..5的全部二叉形状及每节点-1/0/1标签，共11497棵树对照；空树为扩展。每次前后检查身份/值/左右引用不变。另测10000节点零链、正/负链、值上界导致的10^9子树和及并列众数，未向LeetCode提交。
