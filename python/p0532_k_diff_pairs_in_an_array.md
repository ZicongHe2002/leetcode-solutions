# 532. K-diff Pairs in an Array · Python

[原题](https://leetcode.com/problems/k-diff-pairs-in-an-array/)。

给定长1..10000的整数数组nums，每项在-10^7..10^7，k在0..10^7，求绝对差为k的不同数值对数量。两个下标必须不同，同一数值对出现多次仍只计1。输入保持；依赖原题k非负，不把负差参数当成原题输入。

先统计每种值的出现次数。k>0时，每对都能唯一写成较小值x与较大值x+k；遍历不同的x，检查x+k是否存在，恰好计每个合法无序数值对一次。两值不同，自然来自不同下标；出现次数不影响该对是否存在，不乘频率，也不再同时检查x-k而重复计数。

k=0时，合法数值对是(x,x)，需要至少两个不同下标，所以只数频率至少为2的值。此时不能只检查x是否在表中，否则每个只出现一次的值也会被误计；也不能按组合数计算，因为题目要不同数值对而非下标对。

设N为数组长度、U为不同值数量，建立频率表并遍历不同值，哈希表通常时间O(N+U)，辅助空间O(U)。不排序或修改nums，返回整数。

独立参考枚举所有不同下标i<j，检查绝对差，把每个通过的二元值排序成元组放入集合去重。值-1/0/1、长1..7的全部3279个数组，每个测k=0..4，共16395次对照。另测10000元素、全重复/全不同、最大k和正负值域端点，核对int与输入保持。未向LeetCode提交。
