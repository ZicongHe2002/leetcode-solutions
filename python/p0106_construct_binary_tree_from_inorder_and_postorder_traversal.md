# 106. Construct Binary Tree from Inorder and Postorder Traversal · Python

[原题](https://leetcode.com/problems/construct-binary-tree-from-inorder-and-postorder-traversal/)。

原题两数组为同一棵树的合法中序和后序遍历，长度相同且1..3000，所有值唯一、在-3000..3000。只支持该合法非空合同，不定义重复值或不一致遍历；新建树，不改两个输入数组。本文件TreeNode供本地独立导入，字段与评测器一致。

反向后序是根→右→左，反向中序是右→根→左。先由后序末项建立根，栈保留等待处理左子树的祖先路径。若栈顶不等于当前反向中序值，其右侧尚未走完，下一个反向后序节点接为它的右孩子。若相等，就沿反向中序连续弹出已经完成右侧的祖先，最后弹出的节点正是下一个节点应挂左孩子的父节点；接好新节点再入栈。值唯一及两遍历合法保证每次弹出匹配都能定位对应祖先，不需递归分段或查找表。

每个节点创建、入栈、出栈各至多一次，时间O(n)，除返回树外额外空间O(n)，最坏栈深随树高增长但不使用Python调用栈。测试独立由原树计算遍历，再比较重建树完整前序含空标记的结构。枚举1..7节点的625种二叉树形，另测3000节点左深链、右深链、平衡树以及值域两端；核对结果无环/无共享节点、结构和值、输入数组保持。
