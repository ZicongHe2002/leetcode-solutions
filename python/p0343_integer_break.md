# 343. Integer Break · Python

[原题](https://leetcode.com/problems/integer-break/)。

原题n在2..58，要拆成至少两个正整数之和，返回最大乘积int。因此n=2不能直接返回2，n=3也不能直接返回3。

先处理2和3，其结果分别为1、2。n>=4的最优拆分不需1：若只有两项1+(n-1)，改为2+(n-2)会增大乘积；若还有其他项，把1并入另一项后仍至少两项，乘积也增大。大于等于5的项x拆成3+(x-3)会增大乘积，因为3(x-3)>x。剩下只需2、3、4，4可视作2+2；三个2的乘积8又小于两个3的9，所以优先使用3。为避免余下1，将最后的3+1改成2+2，乘积从3提高到4。代码只在剩余n>4时取3，保留最终2/3/4；最终4表示两项2，保证n=4也确实拆分。时间O(n)，额外空间O(1)，在本题范围内精确整数计算。

独立小规模参考枚举n个1之间的全部非空分隔掩码，直接得到每一种至少两项的有序拆分并算乘积；n=2..12共4083种拆分。另用不依赖取3规则的动态规划逐个枚举第一项与后缀最优，在全部57个合法n上核对，并检查58的结果1549681956。没有浮点优化或连续数近似。
