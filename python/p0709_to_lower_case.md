# 709. To Lower Case · Python

[原题](https://leetcode.com/problems/to-lower-case/)。

原题s长度1..100，仅包含可打印ASCII字符（编码32..126）。把大写字母换成对应小写，其他字符保持原样，包括空格、数字和标点，返回str。这里依照ASCII合同，不把实现描述成任意Unicode语言的大小写规则。

ASCII的A..Z与a..z在各自区间内按同样顺序连续排列，编码差恰32。因此逐字符先检查是否在闭区间A..Z，只有命中才把编码加32再转回字符；其余字符原样放入结果。不能不经范围检查就对所有编码加32或置位，否则会改变数字、方括号等标点。

每个输入字符恰生成一个输出字符，顺序和长度保持。扫描与拼接时间O(n)，返回文本与join收集字符的额外空间O(n)，不声称Python不可变字符串拼接原地完成。

独立oracle用固定英文字母大写表与小写表的对应映射逐字符查找，不使用编码加法。全部95个可打印单字符与95²个双字符，共9120个输入完整核对；另核对1000个固定种子混合串和100字符边界，特别检查@/[/反斜线/下划线/反引号、数字空格不变，以及转换幂等性、长度与str类型。未向LeetCode提交。
