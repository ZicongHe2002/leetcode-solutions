# 258. Add Digits · Python

[原题](https://leetcode.com/problems/add-digits/)。

原题0<=num<=2**31-1，重复对十进制数位求和直到只剩一位，返回该数字。实现不使用循环或递归。

10在模9意义下等于1，所以每次对数位求和都保持原数模9的余数。正整数的数位和仍为正，因此最终一位数位于1..9，恰是1+(num-1)%9；9的正倍数对应9而不是0。原输入为0时必须单独返回0，这也是公式唯一需要分支的地方。超过一位的正整数每次求和都严格变小，因此重复过程确实能结束。

在原题32位整数范围内，时间和辅助空间均O(1)。

独立oracle通过字符串提取数位并逐轮求和，不使用模9公式。0..10000全部10001个值核对；边界覆盖32位最大值、最大值减1的9倍数、10的幂、9和99等正倍数，核对int返回和0的特殊语义。
