# 759. Employee Free Time · Python

[原题](https://leetcode.com/problems/employee-free-time/)。

原题1..50名员工，每人1..50个已排序、不重叠的忙碌区间，0<=start<end<=10^8。返回所有人同时空闲、长度为正且端点有限的区间；最早工作前和最后工作后的无限空闲段不返回。Interval类由LeetCode提供，结果为新Interval对象，不改写任何员工列表或原区间。

所有人同时空闲等价于该处不属于任何员工忙碌区间的并集。把所有区间仅复制为端点元组并按起点排序，end保存已处理忙碌并集最右一段的右端。后续区间若start>end，中间[end,start]无人工作且长度为正，记录为结果；否则它与当前并集段相交或恰好接触。无论是否有间隙，都令end=max(end,following_end)。

按起点排序后，未处理区间的起点都不早于当前start，所以发现的空隙不会再被未来区间覆盖；此前所有区间都已结束于end或更早，空隙也不会被过去区间覆盖。反过来任意有限公共空隙必位于忙碌并集相邻两段之间，扫描会恰好报告一次。接触端点不形成正长度空隙，嵌套区间不能把end缩回去。初始化从首个忙段右端开始、结束后不补尾段，排除了两个无限区间。

设总忙碌区间数M<=2500，排序时间O(M log M)，扫描O(M)，排序副本和结果空间O(M)。原题保证所有员工都有区间，busy非空；实现不额外定义空schedule的行为。

独立oracle在小整数端点域0..4逐个检查每个单位段中点：只要任一员工区间覆盖该半整数，该段就忙碌；把连续无人覆盖的单位段组成答案，不排序合并忙段。枚举该端点域全部33种合法非空单员工日程，1..3名员工的全部37059个有序组合。另核对官方例、接触/嵌套、50员工各50区间、0与10^8边界；检查返回类型、端点顺序、正长度、原对象身份及端点保持。未向LeetCode提交。
