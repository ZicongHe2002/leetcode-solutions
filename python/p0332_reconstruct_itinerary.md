# 332. Reconstruct Itinerary · Python

[原题](https://leetcode.com/problems/reconstruct-itinerary/)。

原题1..300张机票，每个机场是3个大写字母，一张票的起终点不同；从JFK出发，所有票恰用一次，返回字典序最小完整行程。题目保证至少有一种合法行程。相同起终点的多张票仍是不同可用次数，不能把邻接表改成集合。输入机票及行顺序保持。

每个起点保存目的地列表，逆序排序后从尾部弹出最小目的地。显式栈沿尚未使用的票前进；当栈顶无剩余出边时，将它弹到逆序结果。最终反转即有序Hierholzer欧拉行程：每次弹票只发生一次，不能再延续的尾部先归位，其他可续行部分在回溯中接到它之前。

这不是直接把最小出边当成最终答案前缀。最小出边若通向只能作为终点的机场，会先在逆序结果中归位，保留其他票先行的完整路线；在有多个可用欧拉分支时按最小出边顺序展开，得到最小完整行程。JFK->KUL、JFK->NRT、NRT->JFK必须先去NRT，是专门覆盖的反例。

共E张票，排序时间O(ElogE)，栈行走O(E)，额外空间O(E)。实现迭代，不依赖递归深度；每个机场字符串本来就是固定长度。

独立oracle按票索引回溯所有可行使用顺序，取完整路线字典序最小者。三个机场、1..6张票的全部126条无自环合法起始行程生成票组，再分别按原顺序和逆序查询，共252次；重复票按索引分别使用。另测300张重复往返票、两目的地的300票字典序选择和提前死路反例，核对路线边多重集、长度、类型与输入保持。
