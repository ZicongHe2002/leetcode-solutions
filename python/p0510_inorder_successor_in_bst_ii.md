# 510. Inorder Successor in BST II · Python

[原题](https://leetcode.com/problems/inorder-successor-in-bst-ii/)。

只给BST中的一个节点node，每个节点具有val/left/right/parent，返回其中序后继的原节点对象，没有后继返回None。原题1..10000节点，值在-100000..100000且互异，parent与孩子链接正确；函数没有根节点参数。使用平台Node接口，不创建替代节点。输入全部链接和值保持，空node额外返回None。

若存在右子树，当前节点之后中序首先访问右子树最左节点，因此先到right，再沿left到底。不能直接返回右孩子，因为右孩子可能还有更小的左后代；在这个分支不需要向祖先搜索。

没有右子树时，当前节点自己的子树已遍历完成。若它是父亲的右孩子，父亲也已访问，继续上行；首次遇到“当前节点是父亲左孩子”时，父亲就是下一次中序访问，返回它。若一路越过根，parent为None，说明原节点是全树最大值，没有后继。判断孩子归属用对象身份is，返回的必须是树中已有对象，不能只返回同值或新构造节点。

这两个分支沿一条下行或上行链，最多O(h)时间，h为树高，最坏O(N)。只重绑定局部node引用，不写left/right/parent，辅助空间O(1)，无递归深度问题，也不需要从未知根重新搜值。

独立参考对完整树用普通显式栈建立中序节点序列，再按给定节点身份找到其下一项，不使用父指针后继规则。1..7节点全部625种二叉形状按中序填入互异值，逐节点共4081次对照；前后快照同时核对val、左右孩子和parent身份。另测10000节点右链的最高节点长回溯、长右子树左链下降、±100000和空node扩展，验证返回对象身份及全部输入保持。未向LeetCode提交。
