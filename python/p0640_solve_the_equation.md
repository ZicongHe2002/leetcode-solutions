# 640. Solve the Equation · Python

[原题](https://leetcode.com/problems/solve-the-equation/)。

原题方程长3..1000，恰有一个等号，两侧仅含带加减号的整数项与x项。每个显式整数绝对值0..100、无多余前导0，唯一解时保证是整数。输出格式严格为x=<整数>、No solution或Infinite solutions。实现不调用eval，不处理题外括号、乘除或分数解。

扫描原字符串，把右边全部移到左边，累计coefficient*x+constant=0。side在等号前为1、后为-1；每项自己的负号再翻转符号。逐位读取数字，并单独保存has_digits：裸x系数为1，但0x的系数必须为0，不能把数值0当作没有数字。读到x就更新系数，否则更新常数；等号单独处理，不截取两侧副本。

coefficient=0且constant=0时等式恒成立；coefficient=0而constant非0时矛盾。其他情况唯一解为-constant/coefficient，题目保证整除，所以直接整数//，不经过浮点舍入或把不整除输入截断冒充原题结果。每个字符只读常数次，时间O(L)，除返回字符串外额外空间O(1)，累计整数大小在长度和每项数值约束内有界。

独立oracle在生成项时保留每项的符号系数与常数，组合两侧的已知代数值后判定结果，不重新扫描生成的文本。完整列举10种项组成的1..2项左右两侧，仅保留原题保证的整数解或无解/无穷解方程；另生成1000个已知整数根的带正负系数方程，常数拆成绝对值不超过100的项。边界覆盖裸-x、0x、左右抵消、负根和恰1000字符输入。未向LeetCode提交。
