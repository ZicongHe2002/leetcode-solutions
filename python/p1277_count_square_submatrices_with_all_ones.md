# 1277. Count Square Submatrices with All Ones · Python

[原题](https://leetcode.com/problems/count-square-submatrices-with-all-ones/)。

原题二元矩阵行列各1..300，统计所有元素均为1的正方形子矩阵个数，大小不同或位置不同都分别计数，保持输入。

若当前格为1，以它为右下角的最大全1方块边长等于上方、左方、左上方三个最大边长的最小值加1。更大方块必须同时拥有这三个足够大的邻块；反过来三块的并集加当前格也恰好覆盖所需方块。若当前格为0则边长为0。最大边长为k意味着以此格为右下角恰有边长1..k共k个方块，所以累加所有格的边长即可得到总数，不是只保留最大面积。

一行数组更新前保存上方，已更新左邻保存当前行左方，单独diagonal保存覆盖前的左上方；每格完成后把旧上方移给下一格的diagonal。时间O(m*n)，辅助空间O(n)，不覆盖输入矩阵。

独立oracle逐个枚举方块大小和左上角，直接检查方块内全部格，不使用邻居递推。行列各1..3的全部682个矩阵核对。边界覆盖300*300全1的9045050个方块、全0、棋盘格45000个单格方块、单行和单列，核对int与输入保持。
