# 209. Minimum Size Subarray Sum · Python

[原题](https://leetcode.com/problems/minimum-size-subarray-sum/)。

原题target为1..10^9，nums长1..100000且每项为1..10000，求和至少为target的非空连续子数组最短长度，无解返回0。实现额外支持空数组返回0；不支持非正target或含负数的数组，输入保持。

total是当前闭区间的和。正数保证扩展右端不会减小和、移出左端不会增加和；每次达到target，就记录当前长度并继续缩左端，直到再次不足。被移出的起点已有当前右端下的最短候选，更晚的右端只会让该起点的区间更长，因此不会丢失更优解。左右各最多移动n次，时间O(n)，额外空间O(1)。

独立oracle枚举全部起终点并对切片求和，不复用双指针。值1/2/3、长度0..6共1093个数组，target遍历1..总和+1，共13123次比较；空数组单列为扩展。边界覆盖100000元素、target=10^9、每项10000、恰好达到与始终不足，并核对int及输入保持。
