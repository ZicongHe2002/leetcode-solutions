# 1462. Course Schedule IV · Python

[原题](https://leetcode.com/problems/course-schedule-iv/)。

原题2..100门课，先修关系互不重复、没有自边且整图无环，最多n*(n-1)/2条；查询1..10000组不同课程的有序对，判断第一门是否为第二门的直接或间接先修课。查询可以重复，返回顺序对应原查询，保持两个输入列表。

reach先保存直接边。依次允许middle作为内部节点：如果first已经能到middle，就把middle能到的所有second并入first的可达集合。处理某个middle后，矩阵恰表示只使用已处理内部节点的路径；归纳到全部课程，就得到完整先修关系。没有把课程序号当成拓扑顺序，反向编号的先修链也适用。无环保证不会由真实先修路径回到自己，查询本来也不含同课程对。

闭包时间O(n*n*n)，每条查询O(1)，总时间O(n*n*n+q)，辅助空间O(n*n)，另需O(q)输出。

独立oracle对每条查询沿原始邻接表搜索，不使用传递闭包。2..5门课中按编号递增的所有1098个DAG构造，查询全部不同有序对，共21300条原题合法查询。边界覆盖100课反向编号长链、4950条先修的完整DAG和10000查询，包括重复查询，核对bool列表与嵌套输入保持。
