# 506. Relative Ranks · Python

[原题](https://leetcode.com/problems/relative-ranks/)。

互异得分越高排名越靠前，前三名分别输出Gold Medal、Silver Medal、Bronze Medal，其余输出排名的十进制字符串；答案位置必须对应原得分下标。原题1..10000个得分，每项0..1000000且互异。输入保持，空数组额外返回空列表，不定义并列名次。

只对下标按对应得分降序排序，不排序原数组。遍历得到的第rank个下标就是该运动员的名次，再把奖牌或数字字符串写回result[index]。排名从1开始，只有rank<=3使用rank-1访问奖牌表；n=1或2时不会访问不存在的运动员。输出按原顺序，不是按排名顺序。

所有得分互异使降序次序唯一，每个原下标在order中恰好一次，所以每个结果槽都被准确赋值。排名4及以后必须转成字符串，不能混入整数；0得分仍是合法数值，不能当作空槽或缺失。

下标排序O(N log N)，回填O(N)，总时间O(N log N)；排序下标和结果列表均O(N)，辅助空间O(N)，其中结果是必需输出。没有修改score的顺序或数值。

独立参考对每个原得分直接统计严格更高的得分数量，再加1生成名次，不排序。0..5互异得分、长度0..6的全部1957个有序列表对照，空列表为扩展。另测10000个得分、1000000与0边界、前三名在任意下标和原例，核对字符串列表与输入保持，未向LeetCode提交。
