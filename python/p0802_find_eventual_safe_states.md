# 802. Find Eventual Safe States · Python

[原题](https://leetcode.com/problems/find-eventual-safe-states/)。

原题graph有1..10000个节点、1..40000条有向边，邻接表严格递增，可以有自环。安全节点要求从它出发的每一条路径最终终止，返回全部安全节点的升序list[int]，输入保持。

remaining记录还未确认安全的后继数量，反向邻接表保存每个节点的前驱。从出度0的终点开始消除：它的所有前驱各减少一个尚未处理后继，减到0的前驱也能确认安全。被消除节点的全部后继已安全，按归纳它的每条路径都会终止；消除结束还留下的节点至少有一条通向剩余图的边，沿此选择最终进入环，故不安全。按原编号扫描remaining==0直接得到升序，无需按队列次序排序。时间O(n+e)，额外空间O(n+e)，迭代处理10000长链。

独立参考用传递闭包找出可达自身的环节点，再拒绝能到达任一环的起点；闭包不预置对角为真，以区分真正环和零长度路径。穷举1..3节点且至少一边的527个有向图，包含自环。另测10000节点长链/有向环/安全不安全两分区，并在40000边的DAG与环图上核对，不构造违反原题边数下界的全空图，检查升序与输入保持。
