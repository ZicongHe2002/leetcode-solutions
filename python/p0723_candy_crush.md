# 723. Candy Crush · Python

[原题](https://leetcode.com/problems/candy-crush/)。

原题棋盘3..50行、3..50列，初始糖果值1..2000。每轮把所有横向或纵向连续至少3个同色糖果同时消除，再令每列幸存糖果保持顺序落底；不补新糖果，重复直到稳定。0表示后续产生的空格。本实现按原题允许的方式修改并返回传入棋盘。

每轮先完成标记，再做重力。横向和纵向分别检查每个长度3的窗口，非零且三个绝对值相同就改成负值。任何长度至少3的最大同色段都是这些窗口的并集，因此不会漏掉长段。负号仅表示本轮应消除，绝对值保留原始颜色，所以横向标记不会阻止纵向发现交叉，也不会让已经标记的一段失去颜色。0不能被当作糖果继续消除。

全部标记结束后，逐列从下往上读取，只把正数写到从底部递减的write处，最后把剩余上部置零。写指针不会跑到尚未读取位置之上，原地写入不会覆盖未来要读的糖果；负数和0被跳过，幸存者上下顺序保持。下一轮才检查新相邻关系，确保同步消除语义。

若一轮没有标记则已经稳定，直接返回。每个有消除的轮次至少永久删去3个糖果，总糖果数有限，所以最多mn/3轮有消除。每轮标记和重力O(mn)，总时间上界O((mn)^2)，额外工作空间O(1)，返回棋盘复用输入；不声称实际达到最坏轮数或有计时结论。

独立oracle在未改动的快照上枚举横纵最大等值段，用坐标集合收集所有应消除格子，再另外分配新棋盘完成重力；不使用负号或三元窗口标记。核对全部19683个3x3三色棋盘和200个固定种子棋盘，覆盖官方多轮样例、同步十字、50x50全消除/稳定格局及2000颜色边界；同时检查终态再次调用不变。未向LeetCode提交。
