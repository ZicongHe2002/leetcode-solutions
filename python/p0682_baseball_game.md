# 682. Baseball Game · Python

[原题](https://leetcode.com/problems/baseball-game/)。

原题operations长度1..1000，操作为-30000..30000的整数字符串、C、D或+。整数追加新得分，C撤销上一条仍有效得分，D追加其两倍，+追加最后两条有效得分之和。输入保证操作所需有效记录存在，所有中间计算和最终和均在32位整数内；实现依赖该合同，不自行处理非法C/D/+。输入列表保持，结果为int。

scores按时间顺序保存当前有效得分。整数、D和+只向尾部追加一项，C移除末尾一项，因而每步结束后scores恰等于题意中的有效记录。被C删除的得分不再参与后续D/+；D与+引用的是有效记录末尾，而非原输入相邻token。扫描结束对全部仍有效项求和，空记录的和自然为0。

每个操作产生常数次栈访问，Python列表追加为摊还O(1)，最终求和O(n)，总时间O(n)、额外空间O(n)。合法数值可为负数或0，不能用字符串是否全为数字来误拒绝负号。

独立oracle保存按原token下标标识的全部历史得分与有效下标集合，撤销时删除最大有效下标，新计算通过排序有效下标取最近记录，不复用尾部栈。枚举长度1..6、数字-2/0/3及合法C/D/+的全部程序，并核对输入保持。边界覆盖1000项正负最大数字、零值连倍、反复清空、15次倍增仍满足32位上界，以及两种典型混合程序。未向LeetCode提交。
