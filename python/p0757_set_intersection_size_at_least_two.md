# 757. Set Intersection Size At Least Two · Python

[原题](https://leetcode.com/problems/set-intersection-size-at-least-two/)。

原题1..3000个闭整数区间，0<=start<end<=10^8。找最小整数集合，使每个区间至少包含其中两个不同整数，返回集合大小。端点可以相同、区间可以重复，输入保持。

按右端递增、同右端时左端递减排序。first、second保存已经选中整数中最大的两个，初值-1位于原题所有区间左侧。处理当前[start,end]时，先前选中点都不超过end；若start>second，一个也没有，加入end-1、end。若first<start<=second，只有second在内，再加入end。否则最大的两点都在内，无须添加。无需保存更早的小点，因为它们若能落入当前区间，最大的两点也必在内。

右端优先使贪心选择尽可能靠右而不影响当前区间。相对于任意与已有选择一致的最优完成集，当前缺两个时，可把它为当前区间补的两点改成end-1、end；缺一个时可把该点改成end。这些替换只向右移动，不超过当前end，后续区间右端不小于当前end，因此某个旧点能覆盖的后续区间仍被替换点覆盖。每步都保留某个最优完成集，所以最终数量最少。

同右端时先处理更窄区间：如果second已等于当前end，则当初选出它的同右端区间左端至少为当前start，first也已在当前区间，故不会进入缺一个分支重复加入同一个end。start<end保证缺两个时end-1与end是合法不同整数。

排序时间O(m log m)，扫描O(m)，排序副本空间O(m)，扫描状态O(1)。不枚举10^8范围内的整数。

独立oracle枚举0..4上全部32个整数子集，直接检查每个区间覆盖了几个不同点，从所有可行子集中取最小大小。10个可能区间的全部1023个非空家族均与贪心核对，并反转输入和重复区间核对不变。另核对官方例、同右端嵌套、3000个不相交双点区间需要6000点、3000重复区间仅需2点以及10^8端点。未向LeetCode提交。
