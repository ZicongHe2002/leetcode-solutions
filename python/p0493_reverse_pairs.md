# 493. Reverse Pairs · Python

[原题](https://leetcode.com/problems/reverse-pairs/)。

原题nums长1..50000，值在-2^31..2^31-1，统计i<j且nums[i]>2*nums[j]的下标对数量int。严格大于、不要求两个值本身逆序；例如相同负数也可能成对，输入保持。

在数组副本上按原下标递归分半，先计各半内部，再利用已按值排序的两半统计跨半对。对每个左值，让右指针前进到第一个不满足左值>2*右值的位置，之前所有右元素均成对；左值递增时符合条件的右前缀只会扩大，所以右指针不回退。跨半仍保证原下标左小于右，每对按其分治分裂层恰计一次。之后线性归并供上层使用。时间O(n log n)，副本、缓冲和切片临时量总额外空间O(n)，递归深度O(log n)。直接整数乘2，避免负数除法取整或固定宽度溢出改变比较。

独立参考枚举全部i<j并直接检查双倍不等式，不用归并统计。长度1..6、值-2/-1/0/1/2共19530个数组全覆盖；另测50000个负1的全部下标对、50000正数升降序和正负32位端点分段，核对大计数、等号排除及输入保持。没有把一般逆序对判据替代本题双倍条件。
