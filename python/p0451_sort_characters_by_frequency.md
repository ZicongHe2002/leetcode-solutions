# 451. Sort Characters By Frequency · Python

[原题](https://leetcode.com/problems/sort-characters-by-frequency/)。

原题s长1..500000，只含大小写英文字母和数字，区分大小写，按字符出现频次降序输出，相同字符必须连续成块；同频字符之间顺序任意。返回str，保留每个字符原有次数。

先统计各字符频次，再按频次降序排列不同字符，每个字符输出一次完整重复块，保证次数准确、块连续且频次不增。本实现用字符本身作为同频次的次关键字，使输出确定；这是任选合法同频顺序的一种，不是题目额外要求。设不同字符数为k，时间O(n+k log k)，计数、排序及输出构造总空间O(n+k)，其中原题k<=62。

独立测试直接核对输出字符多重集合、每字符仅一块及各块长度非递增，不强制同频字符的某个顺序。这些约束共同刻画合法输出，能拒绝频次相同却穿插字符的文本。字母a/A/0、长度1..8共9840个字符串全部核对；另测500000长度、62种字符、大小写与数字和同频样本，核对str。
