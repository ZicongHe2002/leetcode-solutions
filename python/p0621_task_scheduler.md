# 621. Task Scheduler · Python

[原题](https://leetcode.com/problems/task-scheduler/)。

原题tasks有1..10000个大写英文字母，每个任务耗时1，相同字母两次执行之间至少间隔n个时间单位，0<=n<=100。任务顺序可重排，允许空闲，求总完成时间。输入保持，额外定义空任务列表结果为0。

设最大出现次数为f，共有c种字母达到f次。总时间至少为任务总数，也至少为(f-1)*(n+1)+c：每种最高频字母的最后一次出现都不早于第(f-1)*(n+1)+1个时隙，而这c次最后出现必须占不同位置，所以最晚一次至少在第(f-1)*(n+1)+c个时隙。

该下界可以达到。把频次最高的字母轮流安排，先形成f-1个至少n+1长的轮次，再放各最高频字母的最后一次出现。其他字母的次数不超过f-1，可分散插入不同轮次；每轮优先放剩余次数多且尚未在本轮出现的字母。如果任务不足，补空闲使轮次长n+1；如果足以填满这些位置，继续用不同字母扩展轮次，空闲可全部消除。若最高频字母自身多于n+1种，它们互相提供冷却间隔，也不需要空闲。因此答案为两下界的最大值。Counter只覆盖至多26种字母，时间O(tasks长度+26)，辅助空间O(26)。

独立oracle保存每种任务剩余个数及还需等待的时隙，递归枚举当前所有可执行任务；没有可执行任务时跳到最近解冻时刻，不使用频次公式。A/B/C各0..3次、排除空任务的63个多重集合，冷却0..3共252次查询核对。边界覆盖10000任务、单字母冷却100、26种字母和并列最大频次，核对int与输入保持；空列表为扩展。
