# 741. Cherry Pickup · Python

[原题](https://leetcode.com/problems/cherry-pickup/)。

原题n为1..50，方阵格子为-1障碍、0空地或1樱桃，起终点不是障碍。先从左上只向右/下到右下，再只向左/上返回；每个樱桃只能取一次，无通路返回0。本实现保持输入矩阵不变。

把返程反向，就得到两条同时从左上向右/下走到右下的路径。原往返可采樱桃恰是两条路径格子并集中的1数量，反向与原路径一一对应，所以最优值不变。两人都走step步时，位置行列和必为step，只需记录两行first/second，列分别为step-first与step-second。

current[first][second]保存上一层这对位置的最大已采数量，-1表示不可达。每个人上一格可能来自左边（行不变）或上边（行减1），因此当前对恰有四种前驱组合；取可达最大值，再加当前两个格子的樱桃。当前两行相同就代表同一个格子，只加一次。任何给定格子只可能在其行列和对应的一步被访问，因此跨路径重复也一定在同一步发生，不需要另存整个已采集合。

step范围限制每个行列合法，任一当前位置是障碍则跳过，四个前驱都为-1也不能生成状态。每层独立新表避免同一步互相转移。最终两人都到右下，返回其最大值；不可达时转为0。n=1没有转移，正确只取一次起点樱桃。

步数O(n)，每步O(n²)对位置、每对常数前驱，时间O(n³)。只保留前后两层，工作空间O(n²)，不修改grid，也不把来回过程当作两次各自独立贪心。

独立oracle枚举每条实际合法右/下路径的坐标集合，再枚举路径对并集，直接数并集樱桃，不使用同步状态DP。穷举所有端点非障碍的1x1、2x2、3x3棋盘，共8786个；另核对官方可达/不可达、50x50全1最优196、全0、完整障碍墙与唯一边界走廊99樱桃及输入保持。未向LeetCode提交。
