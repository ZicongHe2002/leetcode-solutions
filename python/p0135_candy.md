# 135. Candy · Python

[原题](https://leetcode.com/problems/candy/)。

原题有1..50000个孩子，ratings[i]为0..50000；每人至少一颗糖，比相邻孩子评分高时糖果也必须更多，评分相等没有大小要求。求最少总糖数，保持输入。实现额外支持空列表返回0。

先给每人一颗，从左往右：若当前评分严格更高，就至少比左边多一颗，得到只满足左侧约束的逐点最小数量。再从右往左：若当前评分比右边高，当前糖数取已有值与右边糖数加一的最大值。对一条向右上升的边，第二遍不会提高左端，因为它不比右端评分高；右端只可能保持或提高，原来的严格大小关系仍成立。向右下降的边则由第二遍直接满足，评分相等的边没有约束。

也可分别记满足左侧、右侧约束的最小值L[i]和R[i]；任意合法分配都必须至少是max(L[i],R[i])，两遍得到的正是这一值，并同时满足每条邻边约束，故总和最小。时间O(n)，辅助空间O(n)。

独立oracle枚举1..n颗糖的全部分配，按总数升序寻找首个同时满足每对相邻评分约束的分配，不做两遍扫描。最优解不会需要超过n颗糖，因为严格递增路径至多n个孩子。评分取0/1/2、长度1..5的全部363个序列核对。边界覆盖50000孩子的严格升序、降序、全相等、交替谷峰和平台，核对int与输入保持；空列表为扩展。
