# 1319. Number of Operations to Make Network Connected · Python

[原题](https://leetcode.com/problems/number-of-operations-to-make-network-connected/)。

原题n在1..100000，计算机编号0..n-1；连接数m在1..min(n(n-1)/2,100000)，端点不同，无重复无向连接。一次可拆一条已有线并接到一对原本无直接连接的计算机，求使网络连通的最少次数，无解返回-1。输入保持，返回int。

连通n个点至少需要n-1条线，线数不足立即无解。并查集合并已有边，得到c个连通分量；每个分量保留生成树一共需n-c条线，剩余m-(n-c)条可用于跨分量连接。m>=n-1恰保证剩余至少c-1条，每次连接可把分量数减少1，故c-1既是下界也可达到。按大小合并和路径减半让合并摊销接近常数，总时间O(n+m*alpha(n))，额外空间O(n)。

独立参考把每种简单图编码为边位集，从所有连通状态出发，对一次删一条现有边、加一条缺失边的重接状态图作多源BFS；距离就是最小重接次数，同边数不能到达任何连通状态则-1，不复用并查集或分量公式。枚举n=2..5的全部1094个非空合法简单图。另测100000点/100000线、线不足、仅一个孤立点可用环上冗余线接回，核对输入保持。n=1与空边不计入上述原题非空边枚举。
