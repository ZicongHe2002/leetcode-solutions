# 466. Count The Repetitions · Python

[原题](https://leetcode.com/problems/count-the-repetitions/)。

令S1为s1重复n1次，S2为s2重复n2次，求最大的M使S2重复M次可作为S1的子序列，字符可以删除但不能重排。原题两个串长1..100，小写字母，n1/n2在1..1000000；不实际构造大串。n1=0额外返回0；n2必须为正，两个模式非空。

扫描s1时，index记录s2下一个待匹配位置，matched记录已经完成的s2个数。能匹配当前字符就尽早匹配，给后面字符保留至少同样多空间，因此贪心扫描得到最多完成次数。index必须跨s1块保留，不能逐块独立计数；最后才除以n2向下取整，未完成的s2前缀不算整组。

每读完一个s1块，未来行为只取决于index，不取决于已完成个数的绝对大小。相同index再次出现时，两次记录之间的块数与完成数就是一个可重复周期；把剩余块数除以周期块数，直接累加完整周期的收益，再真实扫描不足一周期的余块。seen从未读任何块的index=0开始记录，周期块数始终为正，不会除0。

块边界最多有len(s2)种index状态，发现重复之前最多扫描该数量级的块，跳跃后剩余不足一个原周期。时间O(len(s1)*len(s2))，辅助空间O(len(s2))；字母集合检查在固定26字符表内有界。s2含s1没有的字母时直接返回0，没有为百万次重复分配字符串。

独立小参考只构造短S1和S2，对每个候选重复数用通用LCS动态规划判断完整目标是否为子序列，不使用贪心匹配或周期状态。a/b非空串长1..3、n1=0..6、n2=1..4共5488项对照，n1=0为扩展。另测百万源重复、模式长100、跨块前缀、缺字母、末尾余数与最大n2；大边界期望由明确重复关系给出。未向LeetCode提交。
