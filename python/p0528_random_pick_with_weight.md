# 528. Random Pick with Weight · Python

[原题](https://leetcode.com/problems/random-pick-with-weight/)。

给定长度1..10000的正整数权重w，每项1..100000，pickIndex最多调用10000次，返回下标i的概率必须为w[i]/sum(w)。构造时复制累计和而不修改输入；不展开最多10^9个权重槽位，也不把概率转成浮点小数。

prefix[i]是下标0..i的权重和。令prefix[-1]意义上的总和为T，把整数区间[0,T)分成连续半开段：下标i对应[前一个累计和,prefix[i])，首段左端为0。段内恰好有w[i]个整数槽位。randrange(T)在这T个槽位上均匀取整，落入第i段的概率就恰为w[i]/T；这一证明以标准库均匀取整接口为前提，不把确定性边界测试当作随机源质量测试。

给定slot，要找第一个严格大于slot的累计和，用bisect_right。slot恰等于某段右端时必须进入下一段；用bisect_left会把这种边界错误地留在前段。正权重保证累计和严格递增；0<=slot<T保证返回值始终落在合法下标范围。pickIndex只读取累计和，各次调用不删除或重排权重，因此允许重复抽到同一下标。

构造时间O(N)、存储O(N)，每次pickIndex二分O(log N)、额外空间O(1)。原题T最多10^9，整数运算范围有限。输入列表在构造和调用后均保持。

独立参考把每个下标重复w[i]次，直接形成短输入的槽位所有者序列，不使用累计和或二分。权重1..3、长度1..5的363个数组，把每个可取整数槽位逐个注入，共3282次调用，核对逐槽输出与每个下标的精确槽数。另测10000项/权重100000/总和10^9，注入10000个段尾槽位，覆盖每个下标；另测首尾与累计和相等边界。测试替换随机取整接口，验证映射，不做统计均匀性或随机质量宣称。未向LeetCode提交。
