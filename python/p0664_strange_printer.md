# 664. Strange Printer · Python

[原题](https://leetcode.com/problems/strange-printer/)。

原题s为1..100个小写英文字母，打印机每次可在任意连续区间写同一个字符，并覆盖此前内容，求从空屏得到s的最少轮次。覆盖是允许的，所以aba只需先aaa再在中间写b，共2次，不能仅按相邻不同字符段数计数。

先把每个相邻同字符段压成一个字符，最优轮次不变。一方面，压缩串的每个打印区间可扩展到原串对应完整字符段，轮次不增加；另一方面，在每个原字符段选一个代表位置，把任意原串打印计划投影到这些位置，仍是连续区间操作，空投影可略去，得到压缩串计划也不增加轮次。两方向合起来证明最优值相同。

令best[l][r]为压缩串闭区间的最少轮次。基线单独打印l，花1+best[l+1][r]。若后面某位置k与l同字符，则可与k共用一次打印，候选为best[l+1][k-1]+best[k][r]，空中间区间费用为0。构造上，先执行[k,r]的计划，把最终写k的那次向左延到l，再修复中间(l,k)区间；不会额外多花写l的一轮。按最左位置的打印轮次分类，最优区间计划也可整理为单独打印或与某相同位置共用这两类，枚举全部k取最小。左端从右向左、右端递增，所有依赖先算完。

原长n、压缩后长m，时间O(n+m³)、额外空间O(m²+m)。不能因合并相邻重复后通常变短，就把最坏复杂度写成线性；非空合同保证m>=1。

独立小输入oracle从全空屏幕BFS，真正枚举每个连续区间及a/b/c的覆盖操作，获得最短轮次，不使用区间DP或相邻压缩；完整比较a/b/c组成的长度1..6共1092个目标。无需引入目标字母表之外的字符：没有任何最终格使用那种字符的操作可直接删去。另用不同的端点相等/切分递推核对50个固定种子字符串，最大100字符边界含全同、交替、26种字母块和嵌套回文，独立已知答案及整数类型均核对。未向LeetCode提交。
