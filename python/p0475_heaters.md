# 475. Heaters · Python

[原题](https://leetcode.com/problems/heaters/)。

直线上所有供暖器采用同一非负半径，求覆盖全部房屋所需最小半径。原题房屋数H和供暖器数R均1..30000，位置为1..1000000000，可有重复位置。输入不变，不要求预先有序。供暖器仍要求非空；空房屋列表额外返回0。

对每栋房屋，任何可行半径至少等于它与最近供暖器的距离；反过来，把所有最近距离的最大值作为半径，每栋都能由最近的一台覆盖。因此答案是max_house min_heater距离，不是相邻房屋距离，也不要求每栋分配不同的供暖器。

复制排序供暖器。bisect_left找到首个不小于房屋的位置，左侧候选是紧邻的前一台，右侧候选是该位置；更远的供暖器不会更近。如果位置已到尾部，以最后一台初始化距离；如果位置是0，没有左候选。恰好同址时右距离为0，重复供暖器和重复房屋不改变含义。

不排序房屋，逐栋二分后更新最大距离。排序O(R log R)，H次查询O(H log R)，合计O(R log R+H log R)，R=1时也需O(H+R)基本扫描。复制排序列表及排序临时状态共O(R)辅助空间。全程整数运算，避免用无穷大哨兵导致返回类型偏离整数。

独立参考逐栋枚举全部供暖器并直接求最小绝对距离，不排序或二分。位置1..4、房屋多重集大小0..4共70种，供暖器多重集大小1..3共34种，共2380组对照，交替逆序检验输入顺序独立；空房屋为扩展。另测两类数目30000、同址、重复、两端之外、空隙中点及1/1000000000位置边界，检查输入保持。未向LeetCode提交。
