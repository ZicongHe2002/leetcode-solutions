# 817. Linked List Components · Python

[原题](https://leetcode.com/problems/linked-list-components/)。

给定值集合在链表中形成若干连续段，每段是一个连通分量。当前值属于集合且下一节点不存在或不属于集合时，当前节点恰是一个段的末尾，计数一次。每段有且只有一个末尾，因此不重复也不遗漏；集合中值的排列不影响链表上的邻接。使用LeetCode提供的ListNode，不修改节点或nums。

链表长度n、集合项数k，期望时间O(n+k)，额外空间O(k)。
