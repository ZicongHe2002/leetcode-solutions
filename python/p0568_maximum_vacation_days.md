# 568. Maximum Vacation Days · Python

[原题](https://leetcode.com/problems/maximum-vacation-days/)。

n个城市、k周，1<=n,k<=100。flights为n×n有向0/1航班矩阵，对角线为0；days为n×k矩阵，每项0..7。最初在城市0，每周一早最多乘一次直达航班，也可以不飞，随后获得所在目的城市该周的休假天数。可在第一周开始前飞出，不要求最后回城0，求总休假最大值。只处理题目保证的非空尺寸，输入矩阵均保持。

scores[c]记录已完成前若干周、当时位于城市c的最大休假数，-1表示不可达。初始尚未度过任何一周，只有城市0为0；若把所有城市初始化为0，就会凭空允许从不可达城市出发。每周新建next_scores，遍历旧状态里可达的source，再枚举destination，仅在原地停留或存在source到destination航班时转移，加上目的城市本周的days。

新旧层分离保证同一周不串接两趟航班，也不会重复领取休假。对已完成周数归纳，所有合法行程都有最后一周的来源城市，必被相应转移考虑；取最大值保留所有未来只依赖所在城市的最佳前缀。完成k周后对任意终点取最大值。停留即使flights[c][c]=0也始终合法，不能要求自环航班。

每周最多枚举n²个城市对，时间O(k*n²)，额外空间O(n)。合法收益非负，因此-1不会与真实分数混淆；返回整数，最大700。该实现不求航班传递闭包，因为一周只允许一段飞行。

独立oracle枚举每周所在城市组成的全部行程，逐段检查从城市0出发的有向直达边，再直接求days和，不保存最优状态。对n=1/2、k=1..3及n=3、k=1..2，穷举所有无自环有向图和0/1休假矩阵，共4958组。另测有向链禁止第一周两段飞行、不可达高收益、第一周飞出、样例及100城市×100周边界，核对两个输入保持。未向LeetCode提交。
