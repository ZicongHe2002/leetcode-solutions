# 913. Cat and Mouse · Python

[原题](https://leetcode.com/problems/cat-and-mouse/)。

状态包含鼠位置、猫位置与轮到谁；鼠进0胜，猫鼠重合猫胜，猫不能进入0。先把这些终局及无合法动作的必败态入队，再沿前驱逆推。如果前驱行动者能选择一个自己获胜的后继，就把前驱定为该方胜；否则只扣除一个已证实输给对手的可选动作，全部合法后继都输才定为对手胜。未被任何有限胜负证明覆盖的循环状态保持0，即双方最优时和局，不能把首次递归遇环直接当最终和局。

合法度数在猫回合排除0，逆向猫边也排除0，保证传播规则与真实可选动作一致。N个点E条无向边，时间O(N^2+NE)，空间O(N^2)，输入保持，返回初始鼠1猫2且鼠先手的状态。
