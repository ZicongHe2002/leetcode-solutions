# 794. Valid Tic-Tac-Toe State · Python

[原题](https://leetcode.com/problems/valid-tic-tac-toe-state/)。

原题board恰有3行、每行3字符，仅含X、O和空格。X先走，双方交替往空格放一个标记；任何人连成行、列或对角三格，或棋盘已满，立即结束，之后不能落子。判断是否存在某段合法对局达到输入，不模拟固定的一套落子顺序，输入保持。

X数必须等于O数或多1，否则违反轮流。分别检测两人是否获胜：双方同时赢不合法；X赢要求X比O多1，O赢要求两人数相等，确保赢家是最后落子者。不能把同一个人两条相交胜线误当非法，例如X最后在中心一落形成两条对角线是可行的。

这些条件也足够。若没人赢，按任意顺序交替放入最终各方的格子即可，任何前缀都是最终局面的子集，不会凭空出现胜线。若X赢，它最多有5子；不同胜线若不相交就至少要6子，三条不同胜线的并集也至少6格，所以最多两条且有共同格。移走该共同格（单线可移任一格）消除全部X胜线，O本来没有胜线，得到人数相等的无赢家前缀，最后补回X即可。O赢时最多4子，无法有两条不同胜线，移走一颗胜线子也得到无赢家合法前缀，再补回O。无需额外搜索历史。

棋盘固定9格，时间与额外空间均O(1)。只针对题目规定的3*3输入，不用额外分支处理非法字符或其他棋盘尺寸。

独立oracle从空盘交替枚举所有落子，采用位掩码胜线检测，在首次胜利或满盘处停止。把全部合法前缀存入集合，再核对三种字符全部3^9=19683个棋盘；可达集合有5478个。另单列官方例、双赢家、胜后继续落子与最后一手形成双线的案例，核对bool及输入保持。未向LeetCode提交。
