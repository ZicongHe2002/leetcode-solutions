# 936. Stamping The Sequence · Python

[原题](https://leetcode.com/problems/stamping-the-sequence/)。

反过来看最后一次印章，其窗口所有尚未擦除字符必须等于印章对应字符，已擦位置可匹配任意字符。找到这样的窗口就擦为?，要求至少新擦一位才记录操作。擦除只放宽其他窗口的匹配条件，不会阻止原本可用的逆序步骤，所以可贪心反复扫描。某整轮无进展而仍有字符就无解；全部擦空后倒序返回操作，恰是从空白盖成原目标的顺序。

每条记录至少擦掉一个新字符，所以操作数至多目标长n，满足10n限制。重复扫描时间上界O(n^2*m)，m为印章长，额外空间O(n)。原字符串保持。
