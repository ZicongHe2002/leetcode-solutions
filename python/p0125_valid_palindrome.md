# 125. Valid Palindrome · Python

[原题](https://leetcode.com/problems/valid-palindrome/)。

字符串长度1..200000，仅可打印ASCII；保留英文字母与数字、忽略字母大小写后判断回文。空串另扩展为True。双指针跳过非有效字符，对两个有效端点作ASCII大小写归一化后比较；不同则立即False，相同则同时内移。数字必须参与比较，不能把0P当作回文。

已经越过的有效字符都按镜像配对且相等。跳过无效字符不改变题目定义的序列，匹配两个最外层有效字符后剩余区间仍是同一问题；指针相遇时剩余至多一个字符，必为回文。每轮至少移动一个端点，时间O(n)、额外空间O(1)，没有创建完整归一化副本。Unicode不在本合同内。

独立oracle调用ASCII字符分类并物化过滤/转小写后的字符串，再与其反序比较。8字符集合上长度0..5全部37449个字符串，以及95个可打印ASCII字符的全部9025对均核对；固定例子包括大小写、数字、标点与空有效序列。另查200000长度全标点、全A与末端不匹配边界。
