# 662. Maximum Width of Binary Tree · Python

[原题](https://leetcode.com/problems/maximum-width-of-binary-tree/)。

原题非空二叉树1..3000节点，值-100..100，层宽计算最左和最右非空节点之间的完整位置数，包含两端之间本应存在的空槽；答案保证在32位有符号范围内。TreeNode本地定义对接val/left/right，节点值不参与宽度运算。

按完整二叉树位置编号，左孩子2*i，右孩子2*i+1，则某层宽为末位置减首位置加1。队列始终保持本层从左到右的真实节点，空槽只由位置差表达，不创建None占位。每层先记录首位置offset，所有本层位置减去同一offset，末项的归一化位置加1就是该层宽。

下一层从归一化位置计算子位置，相当于从所有下一层位置统一减去2*offset，差值保持，因此不影响后续宽度。每层消除不影响答案的公共偏移，深而窄的右链不会积累随深度翻倍的大编号。节点各处理一次，时间O(n)，额外空间O(w)，w为真实节点最大层宽；队列不按包含空槽的答案宽度分配空间。树保持不变。

独立小树oracle直接展开含None的完整层，并量首尾非空下标差，不复用稀疏位置队列。1..7节点全部625种树形逐一核对。最大3000节点左/右深链均宽1，2047节点满树宽1024，另构造63节点稀疏树，最深层两端间宽度恰2147483647，遵守原题32位保证并覆盖巨大空隙。
