# 152. Maximum Product Subarray · Python

[原题](https://leetcode.com/problems/maximum-product-subarray/)。

输入有1..20000个整数，值在[-10,10]，求非空连续子数组的最大乘积。原题保证任意子数组乘积在32位有符号整数内。本实现保留输入，额外支持空数组返回0。

smallest、largest分别表示以前一位置结尾的非空子数组最小/最大乘积，best记录所有已经完成位置的全局最大值。加入value时，新的子数组只能单独从value开始，或把旧子数组延长。value为负会翻转乘积顺序，因此必须同时保留旧最小和旧最大。先分别计算两个旧端点与value的乘积，再更新新端点，避免某一端使用已经覆盖的新值。0自然把本轮两个端点归零，下一项仍可选择重新开始。时间O(n)，额外空间O(1)，循环按下标访问，没有复制nums[1:]。

独立oracle枚举所有非空连续区间并用math.prod直接求积，再取最大，不复用两个端点的动态规划。穷举五值集合[-2,-1,0,1,2]上长度1..6的全部19530个数组。边界覆盖20000个1、0或-1、长度9且乘积10^9的10序列、零分隔正负段、[-2,3,-4]的符号翻转与空扩展；所有固定输入均满足原题32位乘积保证，并检查输入保持。
