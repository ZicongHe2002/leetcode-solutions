# 646. Maximum Length of Pair Chain · Python

[原题](https://leetcode.com/problems/maximum-length-of-pair-chain/)。

原题有1..1000个二元组，每对-1000<=left<right<=1000。可以任意重排、选取部分对组成链，但前一对的right必须严格小于后一对的left；接触端点不能相连。返回最长长度int，保持输入列表及内层对不变。

按右端点升序遍历，每次取左端点严格超过已选末尾的对。对任意剩余可选集合，最早结束的对能替换某最优链的首对，结束位置不会更晚，后续原有所有可接对仍可接；反复应用交换论证得到最长链。初始previous_end=-1001低于全部合法左端点，使首个可选对正常进入。sorted只创建排序副本，未修改原列表。排序时间O(n log n)、扫描O(n)，额外空间O(n)。

独立参考对小输入用已选下标集合递归枚举全部可行选取次序，最大化长度，不按结束点贪心。6种短区间组成长度1..5的全部9330个数组，含重复、嵌套和接触；另测1000对完整可连、全部相同、连续接触、相同右端点与反序输入，核对int及两层输入保持。
