# 89. Gray Code · Python

[原题](https://leetcode.com/problems/gray-code/)。

原题1<=n<=16，返回任意合法n位格雷码序列：长度2^n、首项0、每个0..2^n-1恰出现一次，任意相邻项以及首尾之间的二进制都恰差一位。输出不要求唯一排列，本实现选择二进制反射顺序。

从[0]开始，每轮把已有序列逆序复制到尾部，并给这些新项统一加上当前最高位。前半仍是旧序列，后半保留旧的相邻一位差；两半连接处是旧末项与同值加新位，恰差新位。旧首项为0，新末项为只有新最高位的数，因此首尾也恰差一位。两半由新位区分且内部无重复，覆盖值域随每轮翻倍。

内层range在循环开始时固定旧列表下标，从旧末项走到0；追加不会让这次遍历读到新项，所以每轮准确翻倍。总追加2^n-1项，时间O(2^n)，输出空间O(2^n)，除结果列表外辅助空间O(1)。

测试对n=1..16全部位宽，共检查131070个输出项；分别核对长度、首项、完整值域、唯一性、每条相邻边及回卷边的一位差。另用独立闭式i^(i>>1)对照选定的反射顺序；闭式仅在测试中使用。边界样例和多次调用/修改旧结果再调用，检查不共享结果状态。
