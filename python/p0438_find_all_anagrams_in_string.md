# 438. Find All Anagrams in a String · Python

[原题](https://leetcode.com/problems/find-all-anagrams-in-a-string/)。

原题s与非空p长1..30000，仅含小写英文字母，返回s中所有与p字符频次相同的连续窗口起点，包含重叠匹配。本实现按起点递增返回，额外支持空s且p非空时返回空列表；不承诺空p，字符串保持。

needed记录p的26个频次，window记录当前最多len(p)个字符。加入右端后，若窗口超长就移出恰好一个左端旧字符；达到完整长度时比较全部26项，相等即为异位词。窗口固定长度让频次相同足以判定，无需排序每个切片。时间O(len(p)+26·len(s))，固定字母表下为线性；除返回结果外额外空间O(26)。

独立oracle对每个候选切片构造Counter并与p比较，不复用滚动更新。二字母s长0..7与p长1..4的7650对全部核对，空s为扩展。边界覆盖30000字符、30000模式、模式更长及交替字符重叠窗口；大段均匀或交替字符串用已说明的全部合法起点作期望，不运行大切片穷举。
