# 901. Online Stock Span · Python

[原题](https://leetcode.com/problems/online-stock-span/)。

原题接口为StockSpanner类及next(price)：每次收到1..100000的价格，返回以今天结束、价格都不高于今天的最长连续天数；next调用至多10000次。状态按实例保存，等价价格应计入跨度。

栈中每对(price,span)概括一段已处理连续日，价格从底到顶严格递减。当前价格不低于栈顶时，栈顶整段都可并入当前跨度，弹出并累计；遇到更高价后停止，留下最近的阻挡日。再把当前价与总跨度压入，供未来使用。每个价格对只进出一次，q次调用总时间O(q)，单次摊还O(1)、最坏O(q)，额外空间O(q)。

独立oracle保存原始价格历史，收到新价就直接向前逐日扫描，不使用压缩栈。价格1/2/3、长度0..8的9841个调用序列共73812次next核对，空序列只验证构造无调用。边界覆盖10000次递增、递减和同价调用，并交错使用两个实例核对状态隔离；返回int。
