# 1134. Armstrong Number · Python

[原题](https://leetcode.com/problems/armstrong-number/)。

输入为正整数，设它有k位，Armstrong条件为各位数字的k次幂之和等于自身。位数必须在扫描之前固定，不能随着逐位取数而变化。比如153满足1^3+5^3+3^3=153，123不满足。字符串仅用于取得十进制数字，不使用浮点次幂。

题目有界整数模型下，时间O(k)，额外空间O(k)，输入不修改。
