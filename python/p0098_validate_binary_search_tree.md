# 98. Validate Binary Search Tree · Python

[原题](https://leetcode.com/problems/validate-binary-search-tree/)。

原题有1..10000个节点，值在32位有符号整数范围。判断每个节点的整个左子树是否严格更小、整个右子树是否严格更大；重复值不合法，不能只比较父子。本实现额外把空树定义为合法，返回bool，所有原值及左右链接不变。

栈内每项为节点及从全部祖先继承的开区间(lower,upper)。当前值必须严格落在区间内；左孩子继承旧下界并把上界收紧到当前值，右孩子把下界提高到当前值并继承旧上界。这样祖先约束不会在下一层丢失，也不会误放行重复值。无界端用None而非32位边界加减，能正确接受最小/最大合法键。时间O(L)，额外空间O(h)，显式栈避免深链递归失败。

独立oracle收集中序值并检查相邻项严格递增，不复用祖先区间。枚举长度0..5的全部树形与值-1/0/1赋值，共11497棵树，包含空树扩展；每次检查bool和输入结构保持。边界覆盖10000节点合法链、仅最深节点越过祖先界限、父子关系正常但跨层违例、重复键及32位值两端。
