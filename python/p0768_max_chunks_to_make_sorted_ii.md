# 768. Max Chunks To Make Sorted II · Python

[原题](https://leetcode.com/problems/max-chunks-to-make-sorted-ii/)。

原题数组长1..2000，元素0..10^8，可重复。把数组分为若干非空连续块，每块独立排序后按原块顺序连接，要求等于整个数组排序结果，求最多块数。原输入保持；不能套用只适用于0..n-1排列的前缀最大值等于下标条件。

维护每个当前块的最大值栈，顺序非递减。新value若不小于最后块最大值，可独立成为新块；否则它必须与最后块合并，暂存被弹块的最大值maximum。继续弹掉最大值大于value的更早块，再把maximum放回，代表被迫合并后的整块最大值。相等时可以保留边界，因此比较使用严格大于。

合法块边界要求左侧任意元素都不大于右侧任意元素。若先前某块最大值大于当前value，该块与当前元素之间的边界绝不可能在最终划分中保留，合并是必要动作；更早块若同样大于value也必须一起合并。原栈从底到顶的最大值非递减，首次弹出的最后块最大值就是全部合并元素的最大值，暂存它不会丢失后续比较信息。

算法只删除被跨边界逆序强制删除的边界，其他候选边界全部保留；扫描结束后，保留边界两侧不存在逆序，逐块排序拼接即为全局有序。因此它得到可行划分，并保留了所有可能边界，块数最大。每轮最多入栈一个新栈项，每个栈项最多弹出一次，时间O(n)，额外空间O(n)。

独立oracle枚举全部连续切分掩码，对每块真实排序后拼接，与全局排序结果逐项比较，从全部合法切分中取最大块数，不用栈或极值条件。值0/1/2、长度1..7的全部3279个数组核对。边界包含官方例、2000递增/递减/同值、重复块最大值与10^8，检查int和输入保持。未向LeetCode提交。
