# 1202. Smallest String With Swaps · Python

[原题](https://leetcode.com/problems/smallest-string-with-swaps/)。

原题s为1..100000个小写字母，pairs长0..100000，下标均合法，可按任意给定对交换任意多次，返回可达的字典序最小字符串。允许自配对或重复对，输入pairs保持，返回str。

把可交换下标作为无向边，并查集合并连通分量。沿连接路径的相邻交换可实现同分量任意排列，不同分量之间不能移动字符，所以每个分量可独立最小化。按下标从小到大收集位置，给这些位置依次放入分量内排序后的字符，最早可变下标总取最小剩余字符，得到全局字典序最小结果。索引顺序由range遍历自然递增，无需再排位置。重复边或自边不改变分量。

时间O((n+m)*alpha(n)+n log n)，额外空间O(n)。独立参考用字符串状态BFS，实际执行所有允许交换，取全部可达文本最小值，不复用连通分量排序。枚举长度1..4、字母a/b/c全部字符串及全部简单交换图，共5421次；另测100000字符和100000对、无边、自边/重复边，核对输入保持。大样本全连接时参考为全部字符排序，无边时保持原串。
