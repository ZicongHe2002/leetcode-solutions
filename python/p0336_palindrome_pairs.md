# 336. Palindrome Pairs · Python

[原题](https://leetcode.com/problems/palindrome-pairs/)。

输入互不相同的小写单词，返回所有不同下标i、j，使words[i]+words[j]是回文。顺序是配对的一部分，不能用同一单词下标和自身配对；允许词典中有空字符串。原题至多5000词，每词至多300字符。本实现不修改输入，额外支持空词典返回空列表；不扩展到重复单词的多下标映射。

将当前词切成prefix与suffix。若prefix自身回文，且reverse(suffix)在词典中，把它放在当前词前就得到回文。若suffix自身回文，且reverse(prefix)在词典中，把它放在当前词后就得到回文。字典值可以是下标0，所以是否找到必须检查is not None，不能按整数真值判断。

任意合法拼接A+B中，较短词必须与较长词的一端反向匹配，剩余中段必须回文，因此会落入上述至少一种切分。等长情况对应空中段；第二分支跳过末尾空suffix的重复方向，结果集合仍统一去重。空字符串可以与任意非空回文词按两个方向配对，但不能与自身下标配对。

设N为词数、L为最大长度、R为答案对数。每词L+1个切分，切片、反转、比较与字符串哈希成本均计O(L)，期望时间O(NL²+R)。词典键直接引用输入字符串，额外空间O(N+L+R)，包含索引表、临时切片与答案集合/返回列表；不把整个输入字符串存储算作新复制空间。

独立oracle枚举全部不同下标有序对，直接检查完整拼接的对称字符，不复用切分查反串。七个含空词的小单词池，长度0..4的全部无重复有序词典共1100组，覆盖空词位于下标0及其他位置。另测混合长短词、300字符边界，以及5000个三字符词；后者以数字索引的三位26进制反转独立生成等长配对期望。
