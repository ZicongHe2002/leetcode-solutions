# 336. Palindrome Pairs · Python

[原题](https://leetcode.com/problems/palindrome-pairs/)。

输入互不相同的小写单词，返回所有不同下标i、j，使words[i]+words[j]是回文。顺序是配对的一部分，不能用同一单词下标和自身配对；允许词典中有空字符串。原题至多5000词，每词至多300字符。本实现不修改输入，额外支持空词典返回空列表；不扩展到重复单词的多下标映射。

原题要求时间随总字符数线性增长。逐个切分再复制、反转、检查子串，会在长度L的词上重复处理Θ(L²)个字符，不能满足这一合同。本实现先线性标记回文边界，再建立反向字典树，不在各个切分重新扫描或复制子串。

每词用Manacher的奇数和偶数回文半径标记prefixes[k]（前k字符是否回文）和suffixes[k]（从k到末尾是否回文）。每个触及词首或词尾的回文，已经被边界挡住，必为其中心的最大半径，因此只需检查各中心的最大回文是否触及边界。空前缀和空后缀均标记为真。半径计算复用当前最右回文的镜像结果，成功扩展只推进右边界，两个扫描各为O(L)。

将每词从右向左插入字典树，terminal保存完整单词下标；节点的回文候选链保存“尚未插入的原词前缀是回文”的词下标，包括插完后的空前缀。正向查询当前词时有两类配对：还没读完整个词就遇到terminal，只有当前未读后缀为回文才输出；整个词读完后，输出该节点回文候选链中的其他下标。前者对应更短的伙伴，后者对应等长或更长的伙伴。任意合法拼接都必须先让较短词与较长词的一端反向匹配，剩余中段回文，所以两类情况完整覆盖答案。

同一有序下标对只属于上述一类，且每个词在每个经过节点最多登记一次，因此无需答案集合去重。terminal以-1表示不存在，下标0合法；查询空词时直接读取根候选链，普通回文词也能通过根的空词terminal生成相反方向，但始终跳过自身下标。输入单词互异这一合同不可去掉。

设词数N、总字符数S、输出对数R。边界预处理O(S+N)，建树经过S条字符边并登记至多S+N个回文候选。查询也只走S条边；由于输入单词互异，一个树节点最多被一个完整查询词走到终点，因此所有终点候选链的总访问量不超过S+N。较短伙伴检查至多S次，故R<=2S+N，含输出的总时间为O(S+N+R)=O(S+N)。唯一单词使N<=S+1（最多一个空词），所以满足O(S+1)的总字符数线性合同，也覆盖S=0的空输入边界。树边用紧凑数组保存首孩子和兄弟链接，每次查找最多比较固定小写字母表的26个孩子，不依赖子串哈希；不为每个节点分配26格数组或Python字典。树、回文候选链接、边界标记及结果共用O(S+N+R)额外空间。

保留的独立oracle枚举全部不同下标有序对，直接检查完整拼接的对称字符，不复用字典树或回文半径。测试代码保留1100组含空词的小词典、空词下标0、双方向、不同长度、300字符及5000词上界覆盖。新增长回文前后缀边界，以及2000个长度300的长公共前缀/后缀词；长词按互为反串分成两组，等长词仅能与唯一反串配对，独立构造2000个有序答案，不使用耗时阈值充当正确性证明。
