# 748. Shortest Completing Word · Python

[原题](https://leetcode.com/problems/shortest-completing-word/)。

原题车牌长1..7，含英文字母、数字或空格；词表1..1000个小写词，每词长1..15，保证有解。忽略车牌数字与空格、字母不区分大小写，但重复字母必须出现足够次数。返回最短合格词，并列选择原词表中最早出现者。

把车牌字母转为小写后用Counter记录每字母所需重数。按原词表顺序遍历候选，只有每个所需字母的可用重数都不少于要求，才是完成词。用集合会错误接受只有一个s却需要两个s的词，逐字母计数能排除这种情况。输入合同只含英文字母，所以isalpha的过滤对应所需字母类别。

best始终是已处理词中最短且最早的完成词。有best后，长度大于或等于它的词不能改进答案，直接跳过；只有更短且合格的词会更新。这样等长不会覆盖先出现者，且不必排序。车牌没有任何字母时，needed为空，所有候选都满足条件，仍按长度与原顺序选出正确答案。保证有解使最终best必为字符串。

设车牌长度P、词总字符数W、词数N、不同所需字母数D，时间上界O(P+W+ND)，被长度剪枝跳过的词可更少；D<=7。字母表固定26个，两个计数器及其余工作空间O(1)，返回原字符串引用，不改写任何输入。

独立oracle把候选词拆成字符列表，按车牌所需字母逐个寻找并移除，最后在合格词中按长度和原下标选择，不用频次表。a/A/b/B/0/空格组成长度1..3的258种车牌、14种短二元词组成的210个一词/两词列表，遍历全部54180组合中的所有有解实例。另核对官方例、无字母、重复大小写、并列原顺序、1000词/15字符词及7字符车牌边界、输入保持。未向LeetCode提交。
