# 131. Palindrome Partitioning · Python

[原题](https://leetcode.com/problems/palindrome-partitioning/)。

输入s为1..16个小写英文字母，返回所有分割方案，使每个片段都为非空回文，拼接恰好为s，答案顺序任意。本实现额外支持空字符串返回[[]]，各结果行独立。

先用区间动态规划记录palindrome[start][end]。首尾字符相同且内部是回文即可；长度1或2只需比较首尾，短路条件避免访问无效内部区间。start递减计算，保证start+1对应的内部区间已经确定。随后在当前start枚举所有回文片段，追加s[start:end+1]后从end+1递归；到达字符串末尾保存path副本，再回溯。任何合法分割具有唯一的切割位置序列，逐一枚举全部可行end既不会漏掉，也不会重复。

预计算时间/空间O(n²)。递归节点可由一个前缀及其切割位置集合唯一标识，最坏节点数O(2^n)。每节点扫描至多n个end，切片复制长度至多n，采用保守时间上界O(n²·2^n)，不计结果的额外空间O(n²+n)，包括表、递归和当前分割的总长度。全部结果的列表引用与字符串存储上界O(n·2^n)。

独立oracle枚举字符间所有切割位掩码，形成完整分割后逐片与反转比较，不使用回文DP或合法片段递归。核对全部510个长度1..8的二字母字符串。最大16个相同字母产生32768个方案，逐项与位掩码oracle比较；16个互异字母只允许单字符方案。另检查aab、空字符串扩展、每个方案拼接与回文性质及结果行身份。
