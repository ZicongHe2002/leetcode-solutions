# 316. Remove Duplicate Letters · Python

[原题](https://leetcode.com/problems/remove-duplicate-letters/)。

原题s长1..10000，仅含小写英文，返回包含每种出现过字母恰好一次的字典序最小子序列。必须保持原相对顺序，不能直接排序字符。输入保持，额外定义空串返回空串。

last给出每种字符最后可选位置，included跟踪已保留字符。新字符尚未入选时，若栈顶更大且未来还会出现，就可把它延后选取，让当前更小字符提前；没有未来出现时必须保留该顶，保证所有种类都能出现。已入选字符跳过，出栈同步从included删除，最终每种恰好一次。每个源位置至多入出一次，时间O(n)，小写字母表下额外空间O(26)。

独立oracle枚举全部位置掩码，只保留字符种类完整且无重复的候选，再直接取字典序最小，不复用贪心。三字母长度0..7共3280个串核对，空串为扩展。边界覆盖10000字符、单一字母、正反字母周期、无法把末次字符延后与经典cbacdcbc，核对str。
