# 405. Convert a Number to Hexadecimal · Python

[原题](https://leetcode.com/problems/convert-a-number-to-hexadecimal/)。

原题num为32位有符号整数，返回小写十六进制，无0x前缀且除0本身外无前导零。负数按32位二进制补码表示，而不是在正数十六进制前加负号；生产实现不能直接调用库的十六进制转换。

先单独处理0。value=num&0xffffffff取低32位，正数不变，负数得到其32位补码对应的非负值，从而避免Python负数右移一直保留符号位。每次value&15取最低4位映射到0..f，再右移4位，最后反转得到从高到低的数字。循环只在非零值上继续，所以不会产生多余高位0。

固定32位最多8轮，时间及额外空间O(1)。生产只使用位运算、字符表及反转连接，没有hex/format或字节转换调用。

独立oracle把原数按signed=True打包为4个大端字节，再由测试标准库输出字节十六进制并去掉无意义前导零，不复用生产的掩码移位。-10000..10000全部20001整数逐一核对，结果再按32位补码解释回原数；最大/最小32位、相邻端点和4位进位边界也检查，核对小写、字符集、长度与规范0。
