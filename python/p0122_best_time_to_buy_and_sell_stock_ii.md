# 122. Best Time to Buy and Sell Stock II · Python

[原题](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)。

原题prices长度1..30000，价格0..10000，可以多次交易但同时至多持有一股，求最大利润。不要求必须交易，输入保持。

一段买入到卖出的利润等于沿途相邻价格差的总和，因此任何交易策略的利润都不超过全部正差之和。把每个连续上涨段的起点买入、终点卖出，就能取得该段所有正差；不同上涨段互不占用持仓，相等价格可并入任意一侧。因此这个上界能够达到，累加正的相邻差就是答案。

使用生成器逐项求和，不复制价格后缀，时间O(n)，辅助空间O(1)。全下降、平价或只有一天时结果自然为0。

独立oracle递归枚举每天休息、买入、卖出的合法选择，持有状态只能卖出或等待，结束时仍持有不计为合法完成策略，不使用相邻差公式。同日零收益往返不影响最优值，所以每个交易动作使用不同日期即可。3种价格、长度1..7的3279个数组核对。边界覆盖30000天、极值交替、平价、下降和单日，核对int及输入保持。
