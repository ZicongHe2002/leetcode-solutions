# 172. Factorial Trailing Zeroes · Python

[原题](https://leetcode.com/problems/factorial-trailing-zeroes/)。

原题0<=n<=10000，求n!十进制末尾连续0的个数，0!=1所以结果为0。

每个尾0需要一对因子2和5，阶乘中的2不少于5，因此只数5的总重数。每个5的倍数至少贡献一个5，每个25的倍数再贡献一个，每个125的倍数再贡献一个，依次相加得到floor(n/5)+floor(n/25)+...。循环反复将n整除5，正好逐项得到这些商，直到变成0；例如25额外贡献第二个5，不能只数5的倍数。

不实际构造n!，时间O(log(n+2))，辅助空间O(1)。

独立oracle调用math.factorial真实构造阶乘，再反复检查末位是否为0并除以10，不使用5因子公式。0..300全部301个输入核对；边界覆盖5/25/125/625/3125的重因子、9999与原题上限10000，核对int返回及0!语义。
