# 226. Invert Binary Tree · Python

[原题](https://leetcode.com/problems/invert-binary-tree/)对每个节点交换左右子树，返回镜像树的根。原题至多100个节点，judge提供TreeNode。`Solution.invertTree`返回原根身份，直接修改原节点的左右边，不创建替代节点或改变节点值；空根返回None。输入必须是无环、无共享子节点的有效树，类型注解延后求值。

栈初始包含根。每次弹出一个节点，用Python并行赋值交换其左右引用，然后把非空孩子压栈。赋值右侧在写入前求值，因此两个原孩子都保留；不能用连续的left=right、right=left替代，否则原左孩子会丢失。

一次交换不改变孩子集合，只改变左右位置。有效树中每个非根只有一个父节点，所以每个原节点被入栈、弹出并交换恰好一次，所有节点的边都满足镜像合同。第二次调用时每个节点再次交换，精确恢复原结构。这一证明依赖节点身份，不能仅因输出值相同就断言结构正确。

时间O(n)。显式DFS栈最多积累当前路径的待访问兄弟，额外空间O(h)，最坏O(n)；单链栈最多一个条目，但不能把所有树都算成常数空间。测试构造0..6节点的197种树形，并补充左右各100节点链；第一次调用逐个原节点核对左右引用恰好互换、值保持、根身份保持，第二次核对所有原边精确恢复。实际运行结果见PR；没有LeetCode Accepted记录。A实现与测试，OpenAI Codex辅助。

B补写有重复值的不对称树账本，用身份r、a、b、c区别相同数值：r.val=1，r.left=a、r.right=b；a.val=b.val=2，a.left=c、a.right=None；c.val=3，其他边为空。pending下表按栈底到栈顶展示：

| 弹出身份 | 原left/right | 交换后left/right | 推入后pending |
| --- | --- | --- | --- |
| r | a / b | b / a | [b,a] |
| a | c / None | None / c | [b,c] |
| c | None / None | None / None | [b] |
| b | None / None | None / None | [] |

若对r顺序执行`r.left=r.right`再执行`r.right=r.left`，两个字段都会指向b，a及其孩子c从根不可达；重复值2可能掩盖这种身份错误。并行赋值先保存旧右、旧左这两个引用，再更新字段，因此不会丢失a。

令I(T)为独立中序序列，T的左右子树为L、R。镜像后中序为I(mirror(R)) + [root.val] + I(mirror(L))；对子树归纳即reverse(I(R)) + [root.val] + reverse(I(L))，等于reverse(I(T))。B在原197种小树及两条100节点链共199次check中加入递归中序oracle：第一次翻转与原中序反序比较，第二次还原后与原中序比较。递归只存在于这个最多100节点的测试辅助函数，不改变生产实现的迭代DFS；重复值保留其出现次数。值序列性质不能证明节点身份，因此原逐节点引用检查及二次精确边恢复均保留。
