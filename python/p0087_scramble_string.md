# 87. Scramble String · Python

[原题](https://leetcode.com/problems/scramble-string/)。

字符串可在任意非空切分处递归拆成左右两部分，并在每个内部节点选择保持或交换两部分的次序。判断s2是否能由s1这样得到。原题两串等长，长度1..30，仅含小写英文字母。额外支持两个空串返回True、长度不同返回False。

子问题由s1起点、s2起点和长度确定。两个片段完全相同就无需变换；字符多重集合不相同则不可能成立。否则枚举s1的切分长度k，分别尝试两种对应：前k个字符对应s2前k个字符，或者对应s2最后k个字符。剩余片段的起点和长度随之确定，只有两个子问题都成立才接受。

每棵合法变换树的根都有某个切分和保持/交换选择，因此枚举不漏解；反过来，两个成功的子树接到所选根上就是一棵合法变换树。字符计数只用于排除不可能状态，相同计数并不直接证明可变换，例如abcde和caebd。缓存完整的三个下标参数，避免重复求解同一片段对，也不把不同调用的输入混在一起。

所有长度的片段对合计O(n³)个状态。每个状态至多枚举O(n)个切分；片段切片、比较和计数也是O(n)工作，故宽松最坏时间界O(n⁴)。缓存O(n³)，递归深度O(n)；小写字母计数表最多26项，活动栈上的片段临时对象最多O(n²)，总额外空间由O(n³)缓存支配。短路和计数剪枝有助于实际运行，但不改变最坏界。

独立oracle从源字符串出发，构造每种切分下所有左右结果的拼接及交换拼接，收集完整可达字符串集合；它不调用生产实现的片段匹配或计数剪枝。穷举三字符域长度0..5的全部等长字符串对，共66430次查询，并核对定义中的可达集合。另覆盖计数相同但不可变换、长度30、整串反转和根节点交换、字符计数失配及长度不同扩展。
