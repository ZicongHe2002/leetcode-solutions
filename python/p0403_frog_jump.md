# 403. Frog Jump · Python

[原题](https://leetcode.com/problems/frog-jump/)。

石头坐标互不相同并严格升序，第一块位于0。青蛙第一次跳1，此后若上次跳k，本次可向前跳k-1/k/k+1，判断能否到最后一块。原题2..2000块，坐标0..2^31-1。本实现不修改输入，额外支持单块[0]返回True、空列表返回False。

arrivals[p]保存能落到石头p的上一跳长度。起点放入0作为虚拟上一跳，要求step>0，使第一次只能选择1，之后也不会原地跳或后退。对于每个已可达状态，枚举三个合法步长，仅当目标正好是某块石头时才传播下一状态；无石头的水面不能落脚。

正步长使所有状态都向更大坐标传播，因此按石头升序处理就是有向无环图的拓扑顺序。处理当前石头时，所有可能从前面石头到达的跳长已经加入，传播覆盖全部合法后继；不同跳长必须分别保存，因为它们允许的下一跳不同，不能只记录一个可达布尔值。传播不会写入正在遍历的当前集合。

每次跳长最多比上一跳增加1，至多经过n-1次跳跃，所以每块石头最多O(n)种跳长，状态与转移总计O(n²)。坐标字典平均O(1)查询，时间和额外空间最坏O(n²)，空间按石头/状态数量而不是最大坐标分配；生产无递归，2000块长链不依赖递归深度。

独立小参考递归枚举下一个实际落石下标，直接比较坐标差是否满足上次跳长，不使用生产到达集合或记忆化。0为起点、1..12任意子集共4096组输入对照，[0]为扩展。另测2000块连续石头、逐次增大跳长的三角坐标链、最大坐标不可达和经典有解/无解例子，核对布尔类型与输入保持。未向LeetCode提交。
