# 594. Longest Harmonious Subsequence · Python

[原题](https://leetcode.com/problems/longest-harmonious-subsequence/)。

nums长1..20000，值在-10^9..10^9。和谐子序列要求最大值减最小值恰好为1，求最大长度；子序列可跳过元素，但保持原有相对顺序，不要求连续。全部同值的非空子序列差为0，因此没有两种相邻值时返回0。输入保持，额外定义空数组返回0。

任意合法子序列的最小值若为x，最大值只能是x+1，整数之间没有其他值，所以它只含x和x+1且两者都至少一次。固定x时，把原数组中所有x与x+1按原顺序全部选入，仍是合法子序列，而且达到这个值对可取的最多数量counts[x]+counts[x+1]。枚举所有确实存在的相邻值对并取最大即可覆盖全部候选。

必须检查x+1实际存在，不能把缺失频次当0后仍用counts[x]更新，否则全同值数组会误得正长度。只从较小值x枚举，每对一次，不排序或改写原数组；正负值和0都只是计数键，输入次序不影响可选的总频次。

设互异值数为U，Counter建立与枚举在平均哈希模型下时间O(N)，额外空间O(U)，最坏O(N)。返回整数，Python对边界x+1的查找无溢出风险，也不会向Counter插入缺失键。

独立oracle枚举全部下标子集，直接检查所选值的max-min是否等于1，不使用频次或相邻键。值-1/0/1、长度0..8的全部9841个数组逐项对照，空数组为扩展。边界覆盖20000个同值、相邻两长段、稀疏远值、全部互异连续值及正负10^9端点，检查整数返回、恰好差1和输入保持。未向LeetCode提交。
