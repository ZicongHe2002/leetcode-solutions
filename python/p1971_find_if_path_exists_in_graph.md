# 1971. Find if Path Exists in Graph · Python

[原题](https://leetcode.com/problems/find-if-path-exists-in-graph/)。

原题n为1..200000，无向边0..200000条，无重复边、无自环；节点编号0..n-1，给定合法source、destination，判断两者是否连通，返回bool。允许零长度路径，所以源终点相同为真，输入不变。

建立双向邻接表，用显式栈遍历source的连通分量。节点入栈时就标记seen，避免不同邻边把同一节点重复推入；弹出目的节点即成功，栈耗尽则源分量内已无未访问节点，目的不可达。每个被访问节点均由源已有路径沿一条边发现，反过来源分量的任一节点都能沿路径逐步被发现，故判断充分且必要。时间O(n+e)，额外空间O(n+e)，不用递归处理20万节点长链。

独立参考在小图使用含对角真值的传递闭包，穷举1..5节点全部1099个简单无向图，并检查每个源终点组合，共26705次查询。另测200000节点连通长链、断开长链、200000边的环、空边与单点，核对bool及输入保持。大图预期由具体连通结构给出，不对大图运行立方闭包。
