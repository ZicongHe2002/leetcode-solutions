# 140. Word Break II · Python

[原题](https://leetcode.com/problems/word-break-ii/)。

用词典单词完整拆分s，返回所有以单个空格分隔的句子。一个词可以重复使用，词典条目互不重复；答案顺序不限。原题s长度1..20，词典大小1..1000，单词长度1..10，仅含小写英文字母，并限制返回文本总长度。本实现不修改输入，额外支持空s或空词典返回空列表。

以起点下标为状态，缓存从该位置开始的全部后缀句子。枚举不超过词典最长单词长度的非空前缀；若前缀在词典内，就把它接到每个合法后缀句子前。到达字符串末尾时返回包含空字符串的单元素元组，表示一个完整拆分已经结束，拼接时不加尾随空格。它与空元组不同，后者表示当前后缀没有合法拆分。

每个有效句子的第一个词确定一个唯一切分位置，剩余部分属于对应后缀状态，因此递归枚举完整且不会重复。状态只依赖同一次调用的s及词典，缓存建立在方法内部；多个调用互不共享旧结果。缓存元组不被拼接过程修改，最外层将结果转为列表。

结果可能呈指数增长，不能仅凭O(n)个起点状态就声称线性时间或空间。设W为词典最大词长，D为词典总字符数，V为全部缓存句子的总字符数。建词典与读取词长需O(D)；各起点枚举至多W个片段，Python切片和哈希的字符成本合计O(nW²)；构造缓存文本需O(V)。因此时间上界O(D+nW²+V)，缓存与递归栈、词典集合的额外空间为O(V+n+m)，其中m是词典大小，集合引用原词而不复制所有单词内容。

独立oracle枚举相邻字符之间的全部切割位掩码，直接检查每段是否在词典中，不调用后缀递归。穷举二字符域长度0..6的s与长度1..2单词的全部词典子集，共8128次查询。另核对多答案、无答案、20字符、1000词条、10字符单词、927个重复字符拆分及输入保持；空输入为空列表是明确扩展。
