# 679. 24 Game · Python

[原题](https://leetcode.com/problems/24-game/)。

原题恰有4张牌，每张值1..9，每张必须用一次，可重排并使用二元加、减、乘、除和括号，除法为实数除法，不能拼接数字或用一元负号。返回能否得到24，输入列表保持。中间结果允许负数、0与分数；实现用Fraction精确有理数，按准确相等判断，无浮点容差。

状态列表中的每项代表由互不相交的一部分牌构成的一个合法子表达式。每次选择两个下标，保留其他项，对这一对枚举加、乘、两个方向的减法，以及分母非零时两个方向的除法，再用运算结果替换这对值。交换律运算不重复列方向，同值结果用集合去重；重复牌仍保留为不同列表项，不会遗漏牌的重数。剩下一项时检查是否恰为24。

每次运算合并两个不相交表达式，因此构造结果始终合法且不重复用牌。反过来，任意合法表达式都有二叉运算树，至少存在一个由两叶或已合并子表达式组成的运算；反复合并即可由本搜索枚举，所以运算顺序覆盖所有括号与牌序。两种非交换方向不可省略，除数0必须排除，非整数中间值不能按整数截断。

四牌合同固定，状态深度至多4，递归边数上界为每层组合对数乘最多6种运算：最多(6*6)*(3*6)*(1*6)条完整合并分支。时间与工作空间在原题范围内均为O(1)固定上界；这不是对任意牌数的多项式算法。Fraction的分子分母也受固定四张1..9牌约束，不声称无限精度运算任意规模恒定。

独立oracle枚举牌的不同排列，并按连续区间的每个分割点生成全部括号表达式结果，用精确Fraction集合归并，不复用任意两项合并搜索。1..9可重复选四张的全部495种多重集核对；再检查3/3/8/8的所有牌序、两个典型可行/不可行输入、必须保留分数的解8/(3-8/3)=24、重复1/2不能拼接，以及1/1/1/1无解。核对bool与原输入保持。未向LeetCode提交。
