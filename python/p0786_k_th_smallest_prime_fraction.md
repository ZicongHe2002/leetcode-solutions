# 786. K-th Smallest Prime Fraction · Python

[原题](https://leetcode.com/problems/k-th-smallest-prime-fraction/)。

原题arr长2..1000，严格递增且互异，首项为1，其余为质数，每项<=30000；合法分数为arr[i]/arr[j]、i<j，返回第k小分数的整数分子分母，1<=k<=n(n-1)/2。需要精确的原数组项，不返回浮点近似。输入保持。

对阈值q/S，S=2^40，用整数乘法判断arr[i]*S<=q*arr[j]。固定分子i时，满足条件的分母是从某个j开始的完整后缀，贡献n-j个；分子增大时最小合格分母只能向右，所以一个不回退的分母游标就能在线性时间计数。每个分子的最小合格分母也给出该分子下的最大合格分数，用交叉乘法维护所有合格分数中的最大者。

二分整数q寻找使合格数量至少k的最小正网格阈值。上界S对应1，包含所有合法真分数。计数单调，全过程不用浮点除法、epsilon或比较近似分数。

为什么固定网格仍能返回精确答案：两个不同有理数a/b、c/d的差的绝对值至少1/(b*d)，而原题b,d<=30000，故不同分数值间隔至少1/(30000^2)，严格大于1/S。一个网格单元只能跨过一个不同的分数值。最小合格阈值的前一网格点计数不足k，当前点计数至少k，故第k个分数就在最后跨入的唯一分数值上；当前最大合格分数恰好是它。返回计数时保存的原分子分母就是精确答案，而非网格距离本身。

每轮分母最多移动n次，计数O(n)；二分O(log S)=40量级轮次，总时间O(n log S)，额外空间O(1)含固定大小输出。整数乘积不超过30000*2^40，原合同内有界，优于枚举排序O(n^2)个分数；此精度证明依赖分母上界，未推广到任意无界数值。

独立oracle枚举全部i<j，使用标准库Fraction精确排序，不使用阈值计数或网格。六个小质数的全部63非空子集连同首项1，对每个合法k全量核对，共432查询；再核对100个固定种子合法数组。最大1000元素用精确枚举检查最后一名，第一名直接核对1/最大项，并覆盖接近30000的最大可用质数。检查返回两个int、输入保持，未向LeetCode提交。
