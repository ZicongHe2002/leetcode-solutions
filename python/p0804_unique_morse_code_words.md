# 804. Unique Morse Code Words · Python

[原题](https://leetcode.com/problems/unique-morse-code-words/)。

原题words有1..100项，每项长1..12且只含小写英文字母。按标准26字母摩斯表连接点划，不插入字母分隔符，返回不同转换结果数。相同单词会去重，不同单词也可能得到同一结果，例如gin与zen；不能只对原单词去重。

代码固定a..z的标准表，用ord偏移取得每字母编码，逐词join后放入set。每个词生成的完整点划序列是题目转换的定义；集合只保留不同序列，因此长度恰为所求。字母边界不加入输出，所以不能把字母代码元组当作集合键，那会错误地区分如a与et（都为.-）。

设全部词总长度为L，每字符最多4个点划，构造与期望哈希处理总时间O(L)，所存不同完整编码总大小至多O(L)，额外空间O(L)。常量26表另计，不声称对任意输入规模为O(1)。不修改词数组。

独立oracle不复制26项查表，而从标准摩斯二叉树的各层字母位置推导根到字母的左右路径，左为点、右为划，用无分隔的布尔路径元组比较。核对26字母及全部两字母共702个词的246753对组合，覆盖重复词与不同词碰撞。另测官方例、全部字母、100词/12字符边界及100种子批量，检查int与输入保持。未向LeetCode提交。
