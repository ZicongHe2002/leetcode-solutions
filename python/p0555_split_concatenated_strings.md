# 555. Split Concatenated Strings · Python

[原题](https://leetcode.com/problems/split-concatenated-strings/)。

给定1..1000个非空小写字符串，总长度L在1..1000。原块顺序固定，每块可独立反向或保持，然后连接成环，在任一字符前切开，求字典序最大的长度L字符串。不能任意重排原块，也不是仅对原始拼接串寻找最大旋转；输入列表保持。

固定切口落在哪个块、该块方向及块内位置后，输出形式是“切块后半段+其后所有整块绕环排列+切块前半段”。中间每个完整块都可以独立选其原串与反串中较大者：块长不变，某块的更大方向在首次不同字符处就改进整体，中间其他块与两端片段不受影响。因此先保存每块较大方向，并拼接一次。

切口所在块则不能只保留较大方向，因为该块被拆成输出的开头和结尾，原本整块较大的比较顺序可能被切口改变。对每个原块明确枚举两个方向及全部字符前切口；offset按原块长度定位，在已优化拼接中排除整个当前块，取“其后部分+其前部分”作为中间整块序列，再夹上当前方向的两个片段。

每个环上的字符切口都属于某个块的某个字符前，块边界也由下一个块的cut=0覆盖。对该切口的两种方向均已检查，其他完整块又已各自最优，所以任意合法方案都不优于某个枚举候选；每个候选本身也可按题意构造，取最大就得到最优答案。

两个方向共枚举2L个候选，每次切片、连接与字典序比较最多O(L)。每块构造中间串再用O(L)，非空块数不超过L，因此总时间O(L^2)，辅助空间O(L)，包括优化方向、拼接串和当前候选。没有枚举所有块的2^N方向组合，不修改strs。

独立参考对小列表枚举全部2^N方向选择，完整拼成环后枚举所有全局旋转，不预选任何整块方向。a/b单词长1..3共14种，列表长1..3的全部2954个列表对照，包含重复块。另测1000个单字符块、1000字符单块、原例、回文块和块内切口，核对str、结果长度与输入保持。未向LeetCode提交。
