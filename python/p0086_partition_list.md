# 86. Partition List · Python

[原题](https://leetcode.com/problems/partition-list/)。

输入无环单链表有0..200节点，值在[-100,100]，分界x在[-200,200]。把值小于x的节点放到其余节点之前，两组内部各保留原相对顺序。等于x属于后一组，不排序组内节点。输出重用全部原节点、以None结束，值不变，空输入返回None。

两个固定大小哨兵分别保存小于组和其余组的头，两个尾只向后追加。读取current.next保存未处理后缀，再把current.next断开，按值将当前原节点追加到对应尾。每轮之后，两组都保持已处理节点的原相对顺序且没有交叉链接；保存的following保证原遍历继续。最后小于组尾接到其余组头，哨兵也自然覆盖任意一组为空。时间O(L)，额外空间O(1)，不分配结果节点。

独立oracle从原节点数组分别过滤两个谓词后相加。枚举-1/0/1上长度0..7的3280条链，每条对x=-2..2核对，共16400次。边界覆盖200节点正负极值与交替分组、所有节点同组、x=-200/200、等值分界、经典例子和空输入。精确身份序列与尾部None既验证稳定性，也能发现漏断原链接造成的环或跨组残留。
