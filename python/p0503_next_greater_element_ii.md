# 503. Next Greater Element II · Python

[原题](https://leetcode.com/problems/next-greater-element-ii/)。

原题nums长1..10000，值在-10^9..10^9，可重复；从每个位置向右循环寻找第一个严格更大值，没有为-1。数组保持，额外定义空数组返回空列表。答案值本身也可能为-1，按原题返回值合同处理。

pending保存尚未找到答案的下标。按取模访问两遍数组，遇到严格更大值就确定栈顶答案；只有第一遍把每个下标压入一次，第二遍只完成跨尾部的查找。等值不弹栈，避免把相等项当更大值；未能弹出的最大项保持-1。每个下标入栈出栈至多各一次，两遍扫描时间O(n)，额外空间O(n)。空数组的range长度为0，不执行取模。

独立oracle对每个下标枚举向右1..n-1步并直接比较，不复用栈或双遍扫描。值-1/0/1、长度0..7共3280个数组全部核对，空数组为扩展。边界覆盖10000项、相同值、递增/递减循环、负数与10^9端点，核对列表及输入保持。
