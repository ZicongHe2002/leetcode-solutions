# 648. Replace Words · Python

[原题](https://leetcode.com/problems/replace-words/)。

原题词根字典1..1000项，每项1..100个小写字母；句子长1..1000000，含1..1000个词，每词1..1000字母，词间恰一个空格且没有首尾空格。将每个词替换为其最短匹配词根，无匹配则保留原词，返回新句子；输入字典保留。

把词根逐字插入嵌套字典组成的前缀树，用空字符串键保存结束词根。这个键不与任何小写字母边冲突，词根本身都非空。处理句子中的一个词时，从首字母沿树走，第一次遇到结束标记就返回该词根；因为访问深度递增，第一次结束的匹配一定最短，而不是最长匹配或字典录入顺序中的第一个。若某边不存在，任何更长词根都不能再匹配，返回原词。

每个词独立处理后按单空格连接，恰好遵守输入空格合同。设字典总字符D、句子字符S，构建和扫描期望时间O(D+S)，前缀树最多O(D)节点；split与返回文本需要O(S)空间，故整体额外空间O(D+S)，不把分词副本隐去。返回的词根是原不可变字符串，不在输入列表上原地替换。

独立oracle逐词检查字典里所有词根的startswith，直接选最短长度，不使用树。六个短词根的63种非空子集，对照62个短词组成的句子；另查500个固定种子字典/句子样本。边界覆盖词根嵌套、词本身等于词根、无匹配、字典顺序与重复词根；最大结构为1000词根（含100字符词根）、1000个句子词、最长词1000，句子恰1000000字符，答案独立为1000个z。未向LeetCode提交。
