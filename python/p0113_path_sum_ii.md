# 113. Path Sum II · Python

[原题](https://leetcode.com/problems/path-sum-ii/)。

原题0..5000节点，值及targetSum在-1000..1000，返回所有和为targetSum的根到叶路径，路径用节点值列表表示。必须到叶节点，不能把中间前缀当答案；不同叶路径即使值序列相同也都要保留。TreeNode本地定义对接val/left/right。

显式栈保存进入/退出事件、节点及本分支的剩余和。进入时把值加到当前path并从剩余和扣除，先压入本节点的退出事件，再压右、左进入事件，使左子树先完整处理。退出事件只弹出path末项，恢复父路径；兄弟分支使用各自事件中的剩余和，不共享可变累计值。

仅在叶节点且剩余和为0时复制path保存答案，之后回溯不影响已存结果。值可为负或0，因此不根据剩余和符号提前剪枝。时间O(n+S)，S为全部输出路径长度之和；栈和当前路径额外空间O(h)，输出另需O(S)。使用迭代事件栈，5000深链不依赖Python递归深度；树所有值和链接保持。

独立oracle先建立父指针并收集叶，再从各叶向根重建路径、直接求和，不复用进入/退出事件。0..5节点所有树形和值-1/0/1组合共11497棵树，各查五个目标共57485次，保留相同值路径的多重性。另覆盖5000节点零/正负交替深链、原题数值端点及重复值叶路径，核对输出类型与树身份保持。
