# 151. Reverse Words in a String · Python

[原题](https://leetcode.com/problems/reverse-words-in-a-string/)。

原题s长1..10000，包含大小写英文字母、数字及空格，至少有一个单词。只反转词的顺序，词内字符不变，输出没有首尾空格，词间恰一个空格；输入可能有多重分隔空格。

不指定分隔符的split把连续空格视为一个分隔区，并丢弃首尾空段，得到原词序列。reversed提供反序词迭代，join用一个空格连接，直接满足词序和规范间隔。与按单个空格保留空段的拆分语义不同。

时间O(|s|)，额外空间O(|s|)保存词和输出。Python字符串不可变，本实现返回新字符串；原题对可变字符串语言的O(1)原地follow-up不作为这里已实现的性质。测试仅使用原题空格合同，不添加其他空白字符语义要求。

独立参考逐字符扫描非空格区间得到词边界，核对输出词序恰为其逆序及词内文本保持，再检查没有首尾或双空格。四种合法字符、长度1..6共5460串中5454个至少含一词，全部核对；6个全空格串不在原题合同内，明确跳过。最大10000字符覆盖长单词、首尾空格包围的词、5000个词和固定样例，核对str与输出规范。
