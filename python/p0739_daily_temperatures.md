# 739. Daily Temperatures · Python

[原题](https://leetcode.com/problems/daily-temperatures/)。

长度1..100000，温度30..100；返回每个位置距离最近未来严格更暖日的天数，不存在则为0。空输入另扩展为空结果。栈保存尚未得到答案的日期下标，下标递增、对应温度非递增；相同温度不能互相解答。当天温度严格高于栈顶时，弹出旧日期并记录下标差，最后压入今天。

栈内每个旧日期在之前所有日期中都未遇到更暖日。当前温度如果高于一个待处理日期，该日期上面的温度都不高于它，会先被弹出，因此不会被较冷栈顶遮挡。首次弹出时当前日期就是最近更暖日。未被弹出的日期保留0，符合没有后继的定义。

每个下标只入栈一次、出栈至多一次，所有while循环总弹出次数O(n)，总时间O(n)，输出与辅助栈各O(n)。输入列表保持。独立oracle对每个位置向后扫描第一个更大值，不使用单调栈。四种温度上长度0..7全部21845个数组核对；固定例子含等温、最近日期与100上界。100000长度边界覆盖全相等、最后一天单次升温和循环递减温度，期望由构造给出，不运行平方oracle。
