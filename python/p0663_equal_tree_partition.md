# 663. Equal Tree Partition · Python

[原题](https://leetcode.com/problems/equal-tree-partition/)。

原题二叉树有1..10000节点，节点值-100000..100000，必须恰好删掉一条真实原边，把树分成两个非空连通部分且值之和相等，返回bool。节点接口由平台提供，不修改树；空树返回False为额外扩展。

每条可删边都唯一对应它的非根孩子子树。若这个子树和为s、整树和为T，删边后两部分和分别为s与T-s，相等当且仅当2*s=T。后序计算每个子树和，只把非根节点的和放入proper_sums，最后检查T为偶数且T/2存在即可。负数、0都适用这个整数等式；不能因子树和超过某个正数阈值提前剪枝。

根本身不是可切下的子树，空孩子也没有真实边，均不进入proper_sums。尤其整树和0时，必须有一个非根的零和子树才成功；只有一个值0的根应返回False，不能把整树自身当成一次合法切分。

显式展开标记栈保证先计算左右子树，身份字典按id(node)记录整数和，避免10000层链的递归深度问题，也不依赖TreeNode可哈希。总时间期望O(n)、额外空间O(n)，包括栈、身份和表和非根和集合；总和绝对值最多10^9，整数取半不经过浮点。

独立oracle把原树变成无向邻接图，对每条实际边都虚拟屏蔽一次，从一端BFS得到连通分量并独立求两个部分的和，不使用子树后序和。0..5节点所有树形与-1/0/1标签共11497种输入（含1个空树扩展）完整比较。另查10000层链、正负最大值与大总和、零和根但无合法零子树、单根与确实可切零边，并回读全部值/边保持。未向LeetCode提交。
