# 46. Permutations · Python

[原题](https://leetcode.com/problems/permutations/)。

输入为1..6个互不相同的整数，范围[-10,10]，返回全部排列，输出排列顺序任意。本实现保持输入顺序和内容，每个输出排列独立保存；额外支持空输入返回[[]]。重复值不属于本题合同，不声明去重扩展。

path保存已经选择的前缀，used[index]恰好表示该输入位置是否在path内。每层依次选择所有未使用位置，入递归前标记并追加，返回后弹出并解除标记，恢复父层状态。长度达到n时复制path保存，避免后续回溯修改已交付结果。任意排列有唯一的输入下标序列，该序列对应唯一递归路径；枚举所有未使用位置保证完整，互异性保证没有重复结果。枚举代价包含每层扫描全部n个位置及叶子复制，时间O(n·n!)，不计结果的递归、path和used额外空间O(n)，输出空间O(n·n!)。

独立oracle使用标准库itertools.permutations，比较排序后的全部元组列表，保留重复项以暴露重复输出。枚举五值集合上长度1..5的全部325种互异有序输入；另核对空输入扩展、包含-10/10的6元素全部720个排列。每次检查输入保持、每个结果长度和值域以及所有结果行无别名；修改一项结果后不影响另一项或输入。
