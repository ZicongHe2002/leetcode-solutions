# 752. Open the Lock · Python

[原题](https://leetcode.com/problems/open-the-lock/)。

原题锁为4位十进制轮，初始0000，每步选一位加1或减1并在0/9之间循环。禁用表有1..500个4位数字串，目标保证不在禁用表。求到目标的最少转动数；若初态已禁用或不可达返回-1，输入禁用列表保持。

每个可用状态有最多8条等权转动边，BFS按转动次数从小到大处理。seen先放禁用状态，随后加入初态，候选首次入队立即标记，统一避免进入禁用状态或重复状态。弹出目标即可返回最短距离，目标为0000且初态可用时得到0。每位用模10处理回绕，0000向下转一位得到9而不是负数。

状态空间固定至多10000个，每状态最多8个固定长度候选，时间O(10000*8)，辅助空间O(10000)。不修改调用方的deadends。

第一种独立参照用无阻碍的轮距公式，验证目标00xy的100种组合；禁用状态固定9999，所有公式最短路线都可只转末两轮而避开它，所以这些是原题合法数据。第二种参照用整数状态及十进制位权生成邻居、用Dijkstra最小堆求路，不复用字符串BFS。边界覆盖500个禁用状态、20步最远目标、目标被邻居围住、初态禁用与0/9回绕；全部目标均未禁用。
