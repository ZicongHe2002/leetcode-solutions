# 931. Minimum Falling Path Sum · Python

[原题](https://leetcode.com/problems/minimum-falling-path-sum/)。

原题为n*n矩阵，1<=n<=100，值-100..100。从第一行任意列出发，每次到下一行同列或相邻列，求到底行的最小路径和，保持输入。

previous[column]记录到上一行该列的最小完整前缀和。到当前格只能由上方三列中的合法列进入，选择其中最小前缀和，再加当前格值即可。当前行单独构造，避免较小列的新状态被本行其他格误当成上一行；第一行每列本身就是相应起点代价，最后对底行全部终点取最小。

路径沿行号严格前进，因此负数不会导致循环或需要特殊贪心处理。时间O(n*n)，辅助空间O(n)，没有原地修改矩阵；n=1按相同初始化直接返回单格。

独立oracle枚举整条路径的列下标序列，检查相邻列差至多1，对每条完整序列直接求各行元素和，不保存最优前缀状态。尺寸1..3、值取-1/0/2的全部19767个矩阵核对。边界覆盖100*100全负/全正、斜线最优、边列最优及单格，核对int与逐行输入保持。
