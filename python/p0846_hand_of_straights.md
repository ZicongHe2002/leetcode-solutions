# 846. Hand of Straights · Python

[原题](https://leetcode.com/problems/hand-of-straights/)。

原题hand长度1..10000，牌值0..10**9，1<=groupSize<=hand长度。必须用完全部牌，将每组排成groupSize个连续整数，返回是否可行，输入保持。

总牌数不能整除组长时直接失败。按牌值升序查看剩余计数，最小仍存在的牌start不能放在一组中间，否则需要更小的剩余牌。因此它的每个副本都必须作为新组的开头，同时从start到start+groupSize-1各消耗groups张。任何一个计数不足就不可能分完；成功消耗后再处理下一最小牌。这是被最小值强制的选择，归纳到没有剩余牌即证明充要。Counter的缺键读取为0，不为值域分配数组。

设n为牌数、u为不同牌值数。排序O(u log u)，每次成功内层访问至少消耗一张牌，所以成功访问总数不超过n；失败前最多再访问groupSize<=n次。时间O(n+u log u)，辅助空间O(u)，输入列表不变。

独立oracle枚举任意groupSize个下标的组合，检查牌值能否组成一组，递归尝试所有分割，不把最小牌固定成组头。4种牌值、长度1..8的全部494个多重集合，枚举各自所有合法组长，共3168次查询。边界覆盖10000张单长组、重复完整长组、计数不匹配、缺号、最大牌值，检查bool及输入保持。
