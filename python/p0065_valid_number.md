# 65. Valid Number · Python

[原题](https://leetcode.com/problems/valid-number/)。

判断字符串是否符合十进制数字语法：可选正负号，随后为整数或含小数点的尾数，再可选e/E及有符号整数指数。小数点两侧至少一侧有数字；指数部分必须含数字且不能含小数点。原题长度1..20，字符为英文字母、数字、正负号和点；空串额外返回False，不自动去除空白。

从左到右记录是否出现过点、是否进入指数，以及当前部分是否已有数字。数字令当前部分有效；符号只允许在首位或紧跟e/E；点只允许在指数前且至多一个。遇到e/E时，要求尾数已有数字且此前未进入指数，然后清除数字标记，强制指数随后出现数字。其他字符立即失败。扫描结束时，数字标记必须为真。

数字标记在指数前表示尾数含数字，在指数后表示指数含数字，所以'.'、'e1'、'1e+'都被拒绝，'.1'、'1.'和'1.e2'则有效。符号的位置条件不会接受连续符号，因为前一个符号并非e/E。使用ASCII数字比较，避免把其他Unicode数字误当成原题十进制字符。时间O(n)，额外空间O(1)。

独立oracle按语法使用完整匹配正则表达式，不使用实现的三个标记。穷举字母表01.eE+-x上长度0..5的37449个字符串，再覆盖题目示例、20字符边界、指数正负号、仅一侧有数字的小数、重复点/指数及非数字字母。空串是明确扩展；不声称对空白作容错解析。
