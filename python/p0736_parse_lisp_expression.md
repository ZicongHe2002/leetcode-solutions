# 736. Parse Lisp Expression · Python

[原题](https://leetcode.com/problems/parse-lisp-expression/)。

原题表达式长度1..2000，语法保证合法，支持有符号整数、变量、add、mult和let，全部中间结果在32位整数范围。变量以小写字母开头，后接小写字母或数字；关键字受保护。let的绑定按顺序生效，右侧表达式能读取先前绑定或外层值，最终表达式在最内层可见绑定下求值。

把括号单独分词，用一个共享position递归消费表达式。普通token若以小写字母开头就读取变量当前值，否则转为整数。add/mult各解析两个子表达式，再消费本层右括号。输入合法，所以不需要设计额外错误恢复或执行任意Python代码。

values为每个变量保存绑定值栈。进入let后记录本层实际新增的名字，逐对读取变量和右侧表达式；先求右侧再push，确保同名再赋值的右侧仍能读到旧值。下一个token若是括号、数字、负号开头，或者是紧接右括号的变量，就是最终表达式；否则它是下一个绑定名。let有至少一对绑定，且最后只有一个表达式，所以这种判定完整且无歧义。

最终表达式求值后，按新增绑定的相反顺序pop。即使同一个let反复绑定同名变量，也会逐层恢复原值；若原来未定义，则删掉空栈。嵌套let的临时绑定不会泄漏到相邻表达式。解析变量只读栈顶，无须复制整张环境或逐层搜索作用域。

设n为表达式长度，分词与每个token的处理合计O(n)，存储token、活跃绑定与递归栈O(n)；整数运算按32位合同作常数计算。最短的二元表达式嵌套每层也要增加8个字符，2000字符合同内最多249层这种包裹；不声称支持超出原题合同的任意深度。

独立oracle直接解释构造好的表达式树，对let复制环境并顺序写入，不解析token，也不用同名绑定值栈。核对50个二元算术树、125个外层恢复/同层重复绑定树及1000个固定种子合法树，全部中间结果限制32位。另核对官方样例、带数字变量名、边界整数、249层算术、190层同名let及150次连续增量赋值。未向LeetCode提交。
