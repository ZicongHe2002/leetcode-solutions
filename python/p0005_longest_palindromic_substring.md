# 5. Longest Palindromic Substring · Python

[原题](https://leetcode.com/problems/longest-palindromic-substring/)。

输入为1..1000个英文字母或数字，返回最长连续回文子串；比较区分大小写。原题允许返回任一最长答案，本实现固定返回最靠左的一项，额外支持空字符串返回空字符串。

每个非空回文都有唯一中心：奇数长度中心落在字符上，偶数长度中心落在相邻字符之间。逐中心同时覆盖这两种情况，从内向外检查一对字符；在越界或不等处停止，因为更大的同中心回文必然包含这对字符。每次成功扩展可得到一个完整连续回文，严格变长才更新最佳起点和长度。任意最长回文都会在自己的中心被发现；同长度回文中心的先后次序等于起点次序，故严格更新保留最左项。最后才构造一次返回切片。时间O(n²)，不计返回字符串的额外空间O(1)，返回切片最多O(n)字符。

独立oracle枚举全部非空连续区间，与自身反转比较，并按长度最大、起点最左选答案，不使用中心扩展。穷举a/b/0上长度0..8的全部9841个字符串。边界覆盖1000个相同字符、两个各500字符的相同长度候选、奇/偶中心、babad的左侧平局、大小写与数字混合，以及空扩展。
