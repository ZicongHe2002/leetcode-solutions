# 75. Sort Colors · Python

[原题](https://leetcode.com/problems/sort-colors/)。

输入长度1..300，每项为0、1或2，要求原地按0/1/2次序排序，不调用排序库。接口返回None；本实现只交换原列表元素，不扩容或替换列表，额外支持空数组为空操作。

维护[0,low)全0、[low,current)全1、[current,high]未知、(high,n)全2。当前位置是0时，与low交换并同时推进两者；被换回当前位置的值来自已知1区，或交换自己，所以无需重查。当前位置是1只推进current。当前位置是2时与high交换并缩小右端，新换来的值仍未知，必须保留current继续检查。每次迭代未知区长度至少减1，结束时三类全排好且交换保持元素出现次数。时间O(n)，额外空间O(1)。

独立oracle使用标准库sorted获得排序目标，不复用三指针划分。枚举0/1/2上长度0..8的全部9841个数组，包含空扩展。边界覆盖300个相同值、100个2接100个1再接100个0、经典混合顺序；每次检查返回None、原列表数值和长度。
