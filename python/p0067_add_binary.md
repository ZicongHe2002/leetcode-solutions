# 67. Add Binary · Python

[原题](https://leetcode.com/problems/add-binary/)。

原题a/b为长度1..10000的二进制字符串，只有0本身允许前导0。返回和的标准二进制字符串，实现不把整串转换成整数。

两个下标从末位向前，某一串已经用完时该位视为0。把两位与旧carry相加，通过divmod(...,2)得到当前输出位和新进位；总和最多3，所以carry始终是0或1。已经输出的低位正是两个低位前缀相加的结果，高位未处理信息只剩两个下标和carry。即使两串用完，最后的carry仍需要输出，循环条件因此同时检查三者。

低位先放入列表，结束后反转拼接。合法输入保证至少执行一轮，0+0得到0；非零结果的最后处理位非零，不会产生前导0。时间O(max(len(a),len(b)))，辅助空间与输出空间均O(max(len(a),len(b)))。

独立oracle仅在测试中以int(...,2)解析两串，再用原生整数相加并格式化成二进制。0..63两两组合的4096对输入核对；边界覆盖10000位全1加1的整段进位、不同长度、交替位型和零。核对非空0/1输出及无多余前导0。
