# 766. Toeplitz Matrix · Python

[原题](https://leetcode.com/problems/toeplitz-matrix/)。

原题矩阵行列均为1..20，每个元素0..99。若每条从左上到右下的对角线上元素都相同则返回true，输入保持。

每个非首行、非首列元素与其左上邻居比较。对角线上的所有相邻元素相等，通过传递性整条线相等；反过来整条对角线相等当然满足每个相邻检查，因此条件充要。首行或首列是各对角线的起点，不需要再找越界前驱。单行或单列时所有对角线都只有一项，all对空生成器返回True，恰好满足合同。

最坏比较(m-1)*(n-1)对，时间O(mn)，额外空间O(1)，短路在发现首个不等时返回False。不用复制矩阵或存全部对角线。

独立oracle按column-row把所有格值分组为集合，检查每组是否至多一个不同值，不做左上相邻比较。1..3行列的全部682个二值矩阵均核对；另构造100个20*20合法随机对角线矩阵，每个再改一个长对角线内部值，核对真变假。边界包含官方例、单行/单列、0与99，检查返回bool和输入保持。未向LeetCode提交。
