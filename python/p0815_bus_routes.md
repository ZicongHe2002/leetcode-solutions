# 815. Bus Routes · Python

[原题](https://leetcode.com/problems/bus-routes/)。

一条循环公交路线可到达该路线所有车站，成本为上车一次，与车站数量无关。先索引每站有哪些路线，再从source做BFS，队列保存车站及已乘公交数。首次展开一条路线时，把沿线所有未见车站放入下一层；路线全局标记一次，避免每到一个同线车站又扫描整条路线。

BFS按乘车数量递增，第一次遇到target即为最少公交数。起终站相同无需上车，返回0；队列耗尽仍未达到则返回-1。不修改routes。

设路线表中车站出现总数为L，每个车站与每条路线最多展开一次，各站索引总遍历量为L，时间与额外空间O(L)。
