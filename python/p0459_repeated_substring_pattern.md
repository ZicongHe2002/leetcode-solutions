# 459. Repeated Substring Pattern · Python

[原题](https://leetcode.com/problems/repeated-substring-pattern/)。

原题s为1..10000个小写字母，判断能否由一个更短的非空子串重复至少两次构成，返回bool。单字符不能满足。

KMP前缀函数给出每个前缀的最长相等真前后缀长度，最后一个值border对应整个串。设n为长度，p=n-border，前后缀相等意味着从下标p开始每个字符都与前p位的对应位置相同，所以p是最短候选周期。只有border>0且p整除n，才能把串完整铺成至少两份该长度的块；只存在边界但最后一块不完整时不能算重复。

若原串能由某个完整短块重复，最短周期也会整除全长，因此检查最长边界给出的最短周期足够，不必枚举所有块长。前缀函数的失配回退复用已有边界，每个字符的匹配增长和总回退均为线性，时间O(n)、辅助空间O(n)。

独立oracle枚举所有不超过n//2的候选块长，只有整除n时直接构造重复串并比较，不使用前缀函数。长度1..12的全部8190个二元串核对。边界覆盖10000长度、单字符、完整重复、接近重复但末位错误和abc周期最后不完整的情况，核对bool返回。
