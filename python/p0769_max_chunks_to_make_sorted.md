# 769. Max Chunks To Make Sorted · Python

[原题](https://leetcode.com/problems/max-chunks-to-make-sorted/)。

原题arr长1..10，保证为0..n-1的排列。切成非空连续块，每块各自排序并原序拼接后须得到全局排序结果，求最大块数。这里依赖无重复的完整排列合同；有重复值的通用问题是768，不能把本题判定直接用于该合同。

从左到右维护前缀最大值largest。前缀下标0..i共有i+1个不同的非负整数，若largest==i，这些数必恰为0..i；剩余位置只含更大的数，当前位置就是可以独立切块的边界。每遇到这样的前缀就令chunks加1，无需重置largest。

这个条件也必要：如果某个最终块在i结束，前面所有块排序后的拼接就是全局排序的前i+1项，即0..i，因此原前缀的最大值必须为i。算法恰好选择全部满足充要条件的边界，任意有效划分都不能用更多边界，所以得到最大块数。只重排块内部不会改变各边界的前缀集合。

时间O(n)，额外空间O(1)，输入保持。不会因为当前元素等于下标就误切块；必须比较整个前缀最大值。

独立oracle枚举每个连续切分掩码，实际排序每块后拼接，再与全局排序结果比较，取最大块数，不使用前缀最大值。长度1..7的全部5913个排列核对。另核对官方例、最大长度10的递增/递减排列、跨多个位置的逆序与单元素，检查int和输入保持。未向LeetCode提交。
