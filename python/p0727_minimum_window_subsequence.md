# 727. Minimum Window Subsequence · Python

[原题](https://leetcode.com/problems/minimum-window-subsequence/)。

原题s1长度1..20000、s2长度1..100，均为小写字母。要找s1最短连续窗口，使s2按顺序成为它的子序列；不是字符多重集覆盖。并列最短时选开始位置最左的窗口，不存在返回空串。

扫描s1右端。starts[j]表示已读前缀里，能按顺序匹配s2[0..j]的方案中最靠右的开始位置，-1表示不存在。当前字符等于s2[j]时，可以从此前starts[j-1]延伸；j=0则直接以当前位置开头。保留最靠右的开始位置，因为同一个未来右端下它形成的窗口最短，不会比更早开头差。

j必须从后往前更新，使starts[j-1]仍来自处理当前字符之前，防止一个字符同时匹配目标中多个重复位置。原有starts[j]可以保留；新延伸的starts[j-1]不会比旧starts[j]更早，因为旧完整前缀的匹配本身包含一个可选的较短前缀。因而直接赋值仍保持最靠右不变量，无须完整二维表。

只有读到s2末字符时才考虑完整窗口，开始位置取starts[-1]。对每个右端这就是最短可行窗口；比较所有右端便覆盖全局最优。仅在长度严格减小时更新答案，相同长度对应更早处理的右端和更左的起点，自动保留左侧并列答案。

设n=len(s1)、m=len(s2)，扫描时间O(nm)，状态空间O(m)，返回子串额外占O(答案长度)。不递归、不枚举全部窗口；输入字符串保持。原题目标非空，不把空目标语义混入合同。

独立oracle按窗口长度、再按左端顺序枚举全部实际连续子串，用字符串迭代器直接判断顺序包含，找到第一个可行窗口即返回，不使用前缀DP。核对254个短二元源串与30个短二元目标的全部7620组合，另覆盖官方左侧并列样例、目标长于源串、重复字符不能重用、20000源字符和100目标字符的边界及不存在情况。未向LeetCode提交。
