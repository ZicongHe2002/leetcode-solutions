# 64. Minimum Path Sum · Python

[原题](https://leetcode.com/problems/minimum-path-sum/)。

输入是1..200行、1..200列的矩形网格，每项在[0,200]，只能从左上向右或向下走到右下，返回包含起终点的最小路径和。本实现保留原网格数值和行对象，额外支持空网格返回0。

先把第一行前缀和写入costs，因为第一行只能从左走来。后续每行先累加第一列，因为它只能从上走来，再从左到右处理内部：旧costs[column]是上方最优值，新costs[column-1]是左方最优值，二者较小者加当前权值。每条路径最后一步必属于这两类之一，且最优前缀可接到当前格子，所以递推同时给出可达到的上界和所有路径的下界。滚动覆盖时先左后右，保留尚未使用的上方值。时间O(mn)，额外空间O(n)，不切片复制外层网格，也不借输入作为DP存储。

独立oracle枚举所有向下步在固定步数中的位置集合，逐条实际走完整条路径并累加权值，最后取最小，不使用最优前缀递推。枚举五种小形状的1569个三值网格与3x3的512个二值网格，共2081个。边界覆盖200x200全200得到79800、200x1/1x200各40000、全0、经典7路径和及空扩展；每次检查输入数值和行对象身份。
