# 462. Minimum Moves to Equal Array Elements II · Python

[原题](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/)。

每次只给一个元素加1或减1，求让全部元素相等的最少次数。原题数组非空，长度1..100000，元素-10^9..10^9。输入保持；这里允许单点双向调整，与453每次n-1项加1的合同不同，不能使用同一最小值公式。

选最终整数目标t时，总次数必为sum(abs(value-t))，且逐点移动到t就能达到。排序后将最小与最大、次小与次大依次配对。对一对a<=b，abs(a-t)+abs(b-t)至少为b-a，并在t位于[a,b]时取等。全部配对区间都包含中位位置；奇数长度剩下的中间值还要求t与它相同。因此整数中位数使每对同时最优，得到全局最小总距离。

偶数长度在两个中间值之间任选整数都最优，本实现选上中位数而非浮点平均值。负数和重复值不影响配对论证。sorted创建副本，原数组顺序不写入；Python整数精确累计距离。

时间O(n log n)，排序副本O(n)辅助空间，求和只需固定数量累加变量。没有按整个数值范围扫描，也不把平均数误当作绝对距离的最优点。

独立小参考枚举从最小输入到最大输入的全部整数目标，直接计算每个目标的总距离，不使用中位数或排序配对。-2/0/3、长度1..7全部3279个数组对照。另测100000项、正负值界、偶数最优区间、单元素与大负值重复，核对输入保持。未向LeetCode提交。
