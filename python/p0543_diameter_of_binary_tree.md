# 543. Diameter of Binary Tree · Python

[原题](https://leetcode.com/problems/diameter-of-binary-tree/)要求树中任意两个节点之间最长简单路径的边数。`Solution.diameterOfBinaryTree(root)`只读树，judge提供按身份作键的TreeNode。官方合同为1..10000节点、值−100..100、无环且无共享子节点的二叉树；另明确支持空树返回0，不把扩展混作官方非空案例。

显式后序栈使用未展开/已展开两种状态。先压父的完成状态，再压右、左孩子，保证读取父时两个孩子高度已知。高度按节点数计，None高度0；经过当前节点且连接其两侧最深后代的路径边数恰好为left+right，不再加1。保存当前高度1+max(left,right)，同时更新全局最长边数。

任意简单路径在以给定根定向后都有唯一最高节点。若最高节点为u，它在左右两侧分别使用不超过相应子树高度的边数，因此路径长度不超过leftHeight+rightHeight；取两侧最深后代又能达到此界，缺一侧时退化为从u到单侧最深后代。遍历所有节点并取最大值，覆盖不经过根的最优路径。不能只返回根处的两个高度之和，也不能混用节点数与边数。

每节点两次栈事件，时间O(n)。显式栈O(h)，全部已完成高度字典O(n)，总额外空间O(n)。10000节点链通过显式栈处理，不依赖递归栈；不改变节点值或任何边。

测试先把小树独立转为无向邻接表，从每个节点广度优先计算所有距离，以最远距离作为oracle；不用后序高度公式。1..7节点全部625种有序树形核对，空树扩展单列。边界包括左右10000节点链（9999边）、8191节点完整树（24边）、根位于长路径端点且最长路径在内部相交的结构；每次检查原节点值与左右引用。大树用已知构造期望值，不运行平方复杂度oracle。运行事实见PR，未向LeetCode提交。
