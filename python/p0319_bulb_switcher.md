# 319. Bulb Switcher · Python

[原题](https://leetcode.com/problems/bulb-switcher/)。

初始有n个关闭的灯泡，第k轮翻转每个编号为k倍数的灯泡，执行1..n轮，求最后亮着的数量。原题n在0..10^9，n=0自然返回0，不需要真的分配n个开关。

编号v恰好在其每个正因子对应的轮次被翻转一次。不同因子成对出现为d与v/d，因此通常是偶数次翻转；只有v为完全平方数时，中间因子sqrt(v)与自身配对，因子总数才为奇数，最终状态为亮。答案就是1..n中完全平方数的个数，即floor(sqrt(n))。

使用math.isqrt直接得到精确整数平方根，不通过浮点sqrt再取整，避免平方数附近的舍入边界。在原题有界整数运算模型下，仅一次平方根调用，时间与额外空间均为O(1)；没有把构造灯泡列表或逐轮扫描隐藏在辅助函数中。

独立oracle实际保存灯泡状态，对每一轮及其全部倍数执行翻转，核对0..500所有n，不复用平方数计数公式。另测多个完全平方数前后、原题最大n=10^9、0及返回类型；31622²不超过10^9，而31623²超过它。
