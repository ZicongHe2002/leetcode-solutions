# 696. Count Binary Substrings · Python

[原题](https://leetcode.com/problems/count-binary-substrings/)。

原题s为长度1..100000的二元字符串。统计非空连续子串，要求0与1数量相等，且各自集中成一段；相同文本在不同位置出现要分别计数。不能只检查0/1数量相等，因为0101虽然平衡却有三次字符切换。

把字符串视为最大同字符游程。一个合法子串恰好跨过一条相邻游程边界，两侧取相同的正长度。相邻段长为a/b时，可选长度为1..min(a,b)，恰有min(a,b)个不同位置子串；不同边界的子串不会重复，因为每个合法子串只有一次切换。

扫描只保留前一段previous与当前段current。遇到同字符就延长current；遇到切换时，给已经结束的这一对游程结算min(previous,current)，再向前推进两个段长。循环结束还要结算最后一对，否则会漏掉末尾边界。首段previous=0，不会产生伪造的单段候选。

每字符处理一次，时间O(n)，额外空间O(1)，不构造全部游程数组或实际子串。返回int，输入字符串不可变。

独立oracle枚举全部非空切片，直接检查0/1计数相等且相邻字符切换恰一次，不使用游程公式。核对长度1..12全部8190个二元串；100000长度覆盖全同、完全交替、等长两段、悬殊两段和三段，另核对00110011位置重复计数。未向LeetCode提交。
