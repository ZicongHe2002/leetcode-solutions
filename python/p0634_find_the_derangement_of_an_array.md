# 634. Find the Derangement of An Array · Python

[原题](https://leetcode.com/problems/find-the-derangement-of-an-array/)。

原题1<=n<=1000000，统计1..n的排列中没有任何元素留在原位置的排列数，结果模1000000007。这里元素不同，不能把数值重复或任意交换序列当作独立排列。n=1答案为0。

令D[m]为m个元素的错排数，空排列D[0]=1，D[1]=0。看排列映射中元素n所在的循环，n的后继j可在其余n-1个元素中选。若该循环恰为(n,j)的二循环，剩余元素有D[n-2]种错排。若循环长度至少3，删除n并连接它的前驱与后继j，得到其余n-1个元素的错排；反过来，在任意该错排中j前插入n，唯一恢复这个长循环。因此对每个j有D[n-2]+D[n-1]种，D[n]=(n-1)(D[n-1]+D[n-2])。

previous和current在每步开始分别保存D[size-2]与D[size-1]的模值，Python并行赋值同时读取旧值，避免覆盖后错误使用同一状态。每步取模，时间O(n)、额外空间O(1)，不构造阶乘大整数或n项数组。

独立小输入oracle枚举n=1..9的全部409113个排列，逐个判断所有位置都不等于原下标。大输入oracle使用容斥D[n]=sum((-1)^k*n!/k!,k=0..n)：从k=n向下，以q=1开始并在每轮之后乘k，得到下一项n!/(k-1)!，全程取模，不使用生产的两项递推。核对10、25、100、999、100000、999999和1000000，覆盖模数与最大循环次数。未向LeetCode提交。
