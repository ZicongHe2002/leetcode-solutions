# 1254. Number of Closed Islands · Python

[原题](https://leetcode.com/problems/number-of-closed-islands/)。

原题grid为1..100行、1..100列的0/1矩阵，0是陆地、1是水，按四邻接计数完全不接触矩阵边界的0连通块。函数保持输入，额外定义空矩阵或0列为0。

扫描到未访问的0时，队列完整遍历该连通块，并记录是否有任意格位于四条边。接触边界说明外侧没有水包围，不计为封闭岛；否则整个0块只与内部水相邻，应计一次。入队即标记seen，连通块后续不会重计；即使已经碰边仍要走完整块，避免残余格误计。时间和辅助空间均O(行数*列数)。

独立oracle用并查集把0四邻接合并，边界0接到虚拟外界，再数不属于外界的0根，不复用BFS的closed标志。行列各1..3全部682个矩阵核对。边界覆盖100*100全0/全1、内部大岛、棋盘格的4802个封闭单格和单行边界，核对int及逐行输入保持；空维度为扩展。
