# 413. Arithmetic Slices · Python

[原题](https://leetcode.com/problems/arithmetic-slices/)。

原题nums长1..5000，元素在-1000..1000，统计长度至少3且相邻差相等的连续子数组，返回int。不能跨过中间元素；正差、负差、零差都合法，输入保持。

ending记录恰在当前位置结束的合法片段数量。最近两个相邻差相等时，上一位置的每个合法片段都可向右扩展，另新增最近三个元素构成的片段，因此ending加1；差变动时，没有长度至少3的合法片段能以当前位置结束，ending清0。对所有右端点的ending求和，每个连续片段按唯一右端点计一次。时间O(n)，额外空间O(1)。

独立参考枚举每个连续区间，再直接扫描其全部相邻差判断，不复用ending递推。长度1..8、值-1/0/1共9840个数组；另测5000长度全同、两段常量、极值交替，以及值域两端的2001长等差段，按合法起止区间数核对int与输入保持。
