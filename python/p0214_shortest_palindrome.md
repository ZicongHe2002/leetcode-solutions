# 214. Shortest Palindrome · Python

[原题](https://leetcode.com/problems/shortest-palindrome/)。

原题s由0..50000个小写字母组成，只允许在开头添加字符，返回能得到的最短回文串。原有s必须完整保留为输出后缀。

空串无需补字符。对非空串，总能通过添加至多n-1个字符完成回文，所以寻找最优解只需考虑0<=k<n。添加k个字符时，回文的中间部分就是原串长度n-k的前缀，它必须已经回文；新增前缀则必须是原串最后k个字符的反向。因此应保留最长回文前缀P，把余下后缀T反转放到前面，得到reverse(T)+P+T，新增字符数n-len(P)最少。

对s+'#'+reverse(s)计算KMP前缀函数，最后的最长相等前后缀长度正是s的最长回文前缀长度。分隔符不属于原题小写字母集合，保证相等边界不能跨过分隔符；末尾匹配意味着s前缀等于它自己的反向。KMP失配时沿已有前缀长度回退，每次前进与回退总数线性，时间O(n)，辅助空间O(n)，包含拼接串、前缀表及输出。

独立oracle从长到短直接反转检查每个前缀，找到最长回文前缀后构造预期串，不使用KMP。长度0..10的全部2047个二元串核对，并确认输出回文、以原串结尾。边界覆盖50000长度、原本回文、只在首字符形成回文前缀、长同字符前缀和交替串，核对str返回及最短结果。
