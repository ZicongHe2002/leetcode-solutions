# 875. Koko Eating Bananas · Python

[原题](https://leetcode.com/problems/koko-eating-bananas/)。

1..10000堆，每堆1..10^9根，堆数<=h<=10^9；每小时只吃一堆、最多speed根，剩余时间不能用于另一堆。返回能在h小时内完成的最小正整数速度。候选[1,max(piles)]，上界每堆至多一小时，因h至少是堆数而一定可行。

某速度的耗时为各堆ceil(pile/speed)之和，用(pile+speed-1)//speed作精确整数计算，不依赖浮点。速度增大时每项耗时不增加，故可行性单调。中点可行时最优值在左半且可能等于中点，保留right=middle；不可行时所有更小速度也不可行，left=middle+1。每次严格缩小包含最小可行速度的区间，终止即答案。累计耗时已超过h时可提前返回False。

设最大堆为M，时间O(n log(M+1))，额外空间O(1)，输入保持；Python整数能容纳最多10^13的总香蕉数。独立oracle逐堆逐小时减去速度模拟耗时，再线性尝试所有小速度，不用取整公式或二分。四种正堆大小上长度1..5全部1364个数组，遍历从堆数到总香蕉数的全部10922个期限。大边界检查10000个10^9堆、h最小与最大、单堆及典型例子，使用构造可验证的固定答案。
