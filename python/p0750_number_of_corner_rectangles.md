# 750. Number Of Corner Rectangles · Python

[原题](https://leetcode.com/problems/number-of-corner-rectangles/)。

原题为1..200行列的二值矩阵，总1数量在1..6000。矩形只要求四个不同角为1，边上和内部可以为0。必须选择两条不同的行和两条不同的列，不能把单行或单列当作矩形；返回总数，输入保持。

逐行列出本行值为1的列下标，再枚举其中两个不同列。previous[(left,right)]记录之前有多少行也同时在这两列为1。当前行与其中任一历史行恰好组成一个新矩形，因此先把该计数加到答案，再把这对列的历史行数加1。

任何合法矩形都有唯一的下边所在行和唯一列对，所以会在处理下边时计数一次；反过来每次增加都来自两条不同的行和两个不同的列，四角确实全为1。组合按递增列对生成，不会把左右反向重复计算。先加后更新避免与当前行自己配对。中间格从未参与条件，符合只看四角的定义。

设m为行数、n为列数、第r行有k_r个1，时间O(mn+sum(k_r²))，上界O(mn²)，空间O(n²)存放至多n(n-1)/2个列对及当前列列表。总1上限6000也限制实际组合数量，不把200x200全1当作合法测试。

独立oracle枚举两行两列的全部四角，直接判断四个矩阵位置，不累计历史列对。1..3行、1..4列的所有非空1矩阵共5038个，另核对100个固定种子矩阵。边界覆盖200x200且恰6000个1的30条满行，闭式答案C(30,2)*C(200,2)=8656500；单行/单列、空心四角及官方样例、输入保持。未向LeetCode提交。
