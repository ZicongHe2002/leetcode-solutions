# 57. Insert Interval · Python

[原题](https://leetcode.com/problems/insert-interval/)。

intervals含0..10000个已经按起点递增且互不重叠的闭区间，每个端点在[0,100000]、起点不大于终点；插入一个同范围的新闭区间，合并产生的全部重叠后仍按起点排序。端点相接算重叠。本实现保持原外层顺序、各区间对象和newInterval数值；返回的全部行均独立复制，不与输入行或新区间共享。

顺序处理三段。先复制终点严格小于新起点的左侧区间；此时它们与新区间分离，后面不会再合并回来。接着只要当前起点不大于不断扩展的新终点，就把它并入[start,end]并继续，覆盖传递桥接。循环停止后，剩余区间的起点严格大于合并终点，直接复制右段。原输入已排序且不重叠，三个部分完整、互不遗漏，输出仍有序且不重叠。时间O(n)，返回数据占O(n)空间；不计返回结果的额外空间O(1)，没有重新排序输入。

独立oracle把原区间加新区间后的交叠图做并查集连通分量合并，不使用三段扫描。在端点0..4的全部89个合法不交叠区间列表上，分别插入全部15种新区间，共1335次。边界覆盖空原列表、单点、端点相接、跨多个旧区间、10000个旧单点被[0,100000]合并，以及在其后插入[100000,100000]得到10001个输出；检查两个输入保持及全部输出行无别名。
