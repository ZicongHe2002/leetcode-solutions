# 55. Jump Game · Python

[原题](https://leetcode.com/problems/jump-game/)。

输入长1..10000，每项在[0,100000]，从下标0出发，在i处最多向右跳nums[i]步，判断能否到最后一项；允许选择小于最大值的步数。单项数组已经在终点，答案true。本实现保留输入，额外支持空数组返回false。

farthest表示已经考察过的可达位置所能覆盖的最右端。由于每次允许任意不超过上限的步长，从0到farthest的整个下标区间都可达，不只是最右点。顺序扫描中index>farthest时，之前所有可达位置都无法越过这个缺口，可以立即false；否则当前位置可达，扩展farthest=max(farthest,index+nums[index])。一旦覆盖末下标即可true，无需实际落在每个中间点或构造路径。时间O(n)，额外空间O(1)。

独立oracle用BFS显式枚举每个位置能够跳到的全部后继，标记已到达下标，不使用最右覆盖摘要。穷举0..3上长度1..7的全部21844个数组。边界覆盖10000项全1、终点前的0缺口、首项100000直接跨越、单项0、经典成功/失败及空扩展；逐次检查输入保持。
