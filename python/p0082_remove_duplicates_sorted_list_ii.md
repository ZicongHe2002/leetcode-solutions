# 82. Remove Duplicates from Sorted List II · Python

[原题](https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii/)。

输入为0..300节点的已排序无环单链表，值在[-100,100]。凡某个值出现不止一次，该值对应的全部节点都删除，只保留原来恰好出现一次的值。返回链按原顺序重用这些唯一值节点，尾部为None，全部节点值不改写；空链返回None。

排序使同值节点连续。previous指向最后一个保留节点，或头前哨兵；current指向尚未决定的段首。若current与下一节点同值，则整段都应删除，先跨过所有该值，再把previous.next接到新current，previous不移动。若当前值只出现一次，保留它并让previous前移。每步删除一整段或保留一个节点，完成前缀始终只含唯一值，未处理后缀未丢失。哨兵统一处理重复头段和全部删除。时间O(L)，额外空间O(1)。

独立oracle用完整原值的Counter判断频次，只让频次1的原节点进入期望身份序列，不使用链上重复段扫描。五值集合[-2,-1,0,1,2]上长度0..8的全部1287条非递减链均核对。边界覆盖300节点全重复、两端唯一且中间298个重复、201个合法互异值、首/尾/中重复段及经典例子；核对确切原节点、尾部None与全部值保持，区别于另一题“重复值保留一个”。
