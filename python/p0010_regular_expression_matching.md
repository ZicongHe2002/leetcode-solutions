# 10. Regular Expression Matching · Python

[原题](https://leetcode.com/problems/regular-expression-matching/)。

原题s/p长度均为1..20，s只含小写字母，p还可含点号和星号，并保证每个星号前有合法可重复字符。点号匹配一个任意字符，星号让紧邻前字符重复0次或更多次；要求整个字符串匹配，不是寻找子串。实现额外支持空s或空p的同一匹配语义。

previous[j]表示已经处理的s前缀与p前j个字符是否全匹配。普通字符或点号消耗一个s字符、一个模式字符，因此读取previous[j-1]。星号有两种情况：不用前面的字符和星号，读取当前行current[j-2]；或当前字符与星号前字符相符，再消耗一个s字符但保留同一模式，读取previous[j]。这枚举了星号零次和正次数的全部可能，没有把星号当成可独立匹配任意串的通配符。

空s初始化只能跨过完整的字符加星号组合。每行只依赖前一行和当前行左边的值，时间O((m+1)*(n+1))、辅助空间O(n+1)，m/n为s/p长度。

独立oracle使用标准库re.fullmatch。由a/b/点号及其可选星号形成0..3个token，共259个合法模式，配对0..5长的63个二元字符串，共16317次查询，其中321次空输入属于扩展。边界覆盖原题20字符长度、连续重复token、多种字符与不匹配尾部；大重复模式使用已知预期值，不依赖回溯引擎耗时。
