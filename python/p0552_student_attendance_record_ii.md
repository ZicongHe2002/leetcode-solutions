# 552. Student Attendance Record II · Python

[原题](https://leetcode.com/problems/student-attendance-record-ii/)。

给定1..100000的天数N，计算只含A/L/P、总A少于2次且没有连续3次L的长度N记录数量，结果对10^9+7取模。本题返回计数，不是对某条记录作资格判断；不用生成指数数量的记录。

按总缺勤次数0或1分成两个三元组，每组下标0/1/2表示末尾连续L的数量。两种条件需要同时记住：同样的末尾L段长度，若已用过一次A，后面就不能再追加A。初始空前缀只有zero_absence[0]=1，其余为0；空前缀只是递推起点，原题N仍至少为1。

追加P会把同组所有合法状态汇入末尾L为0的状态。追加L只把旧末尾0移到新1、旧1移到新2，旧2不允许再追加L。追加A只允许从零缺勤组来，并汇入一次缺勤组的末尾0；因此新one_absence[0]等于旧一次缺勤总数的P转移加旧零缺勤总数的A转移。两者末尾字符不同，不会重计。

同时赋值保证新一轮只读取上一轮状态，不把刚生成的记录再次延长。每个合法记录有唯一最后字符，移去最后一天后也有唯一合法前缀，所以这些转移既覆盖全部合法记录又互不重复。按天归纳，最后把六个互斥状态相加就是所求数量。

每轮只处理固定六项，时间O(N)，辅助空间O(1)。各总数和新项及时取模，旧移位项已经是模内值；输出也是0..10^9+6的整数，计数没有浮点近似。

独立小参考枚举全部A/L/P字符串，用总A计数及LLL子串直接过滤，N=1..9分别核对。独立大参考先用三项递推计算只含P/L且无LLL的数量f，再按唯一A所在位置分解：f(N)+sum(f(i)*f(N-1-i))，不使用六状态递推。核对10、50、1000、10101、99999、100000，含原例10101=183236316，检查int和模范围。实际运行通过，未向LeetCode提交。
