# 204. Count Primes · Python

[原题](https://leetcode.com/problems/count-primes/)。

原题0<=n<=5000000，求严格小于n的素数个数。0和1不是素数，n本身不参与计数。

用长度n的bytearray表示0..n-1是否尚可为素数。遇到未被划去的value，从value*value开始划去它的倍数：更小倍数已有更小因子处理，而每个合数都有不大于自身平方根的素因子，所以处理到isqrt(n-1)后留下的恰是素数。切片长度用(n-1-start)//value+1计算，精确覆盖小于n的倍数；小n提前返回避免访问不存在的0/1槽。

时间O(n log log n)，辅助空间O(n)，包括字节标记和当前批量清零的bytes；使用紧凑字节存储，没有为每个数创建Python布尔对象列表。

第一种独立oracle逐个数试除到平方根，对n=0..500全部501个输入核对。第二种oracle采用Euler线性筛：每个数与不大于其最小素因子的素数相乘，每个合数只生成一次，控制流程不同于逐素数批量清除倍数。最大5000000输入及1000000输入由线性筛实际交叉验证，同时核对348513/78498两个计数。边界覆盖严格小于n、素数/合数两侧，核对int返回。
