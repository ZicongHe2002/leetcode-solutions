# 490. The Maze · Python

[原题](https://leetcode.com/problems/the-maze/)。

0为空地、1为墙的矩形迷宫中，小球每次选一个上下左右方向，必须滚到撞墙或边界才停，再选择下一方向。判断能否停在destination，经过但不停不算到达。原题行列1..100，至少两格空地，起终点是不同的空地。输入maze/start/destination均保持；起终点相同额外返回True。

状态只记录小球可以停止的位置，起点本身也允许选择初始方向。从队首停点向四个方向模拟，只有下一步仍在矩形内且为空才继续；循环结束的当前位置就是这一方向唯一可停端点。途中看到目标不能直接返回，目标判断只在弹出停点时进行。

seen在入队时标记，避免相同停点被不同滚动路径反复入队；方向紧邻墙时端点就是自身，已经在seen内，不产生无效循环。所有合法路线都由这样的停点边连接，所以BFS覆盖全部可行路线；队列耗尽仍未弹出目标，就没有可到达的停点路径。这里只问存在性，不把一次滚动当一步来计算实际移动距离。

最多mn个停点各向四方向扫描，单次滚动至多m或n格，最坏时间O(mn*(m+n))，队列和seen辅助空间O(mn)。没有把墙布局改成访问标记，重复调用也不会受上次搜索影响。

独立参考先按行和列找全部最大连续空地段，直接把段内每个格点连到该段两个端点，再搜索这个显式端点图，不逐方向步进滚动。3x3全部512种墙布局的合法不同空地起终点共9216次对照。另测100x100全空、单行走廊的端点/中点、孤立空地、分支样例和同点扩展，检查全部输入保持。未向LeetCode提交。
