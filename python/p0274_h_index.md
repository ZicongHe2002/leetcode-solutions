# 274. H-Index · Python

[原题](https://leetcode.com/problems/h-index/)。

原题citations为1..5000篇论文的引用次数，值0..1000，求最大的h，使至少h篇论文各有至少h次引用。数组不保证排序；实现保持输入，返回int。

h不可能超过论文总数n，所以大于n的引用数都可截到n而不改变任何合法h的判定。counts[v]保存截断后引用恰为v的篇数，从n向0扫描时，papers累计所有引用至少为当前h的论文数。第一次papers>=h就是最大可行h；h=0总可行，因此函数必返回。建桶和扫描均O(n)，额外空间O(n)，不排序。

独立参考直接枚举h=0..n，并逐项按原定义计数。值0/1/3/5、长度1..7共21844个数组全部核对；另测5000篇、1000引用上界、全0/全1及恰有1000篇达阈值，核对int及输入保持。
