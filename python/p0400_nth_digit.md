# 400. Nth Digit · Python

[原题](https://leetcode.com/problems/nth-digit/)。

将正整数按1,2,3,...依次连接成十进制数字流，返回第n个字符对应的整数数字，n从1开始，原题n在1..2^31-1。不能把n当作目标整数本身或使用从0开始的位次。

一位数有9个、两位数有90个、每增加一位数量乘10。width记录位宽，first是该位宽的第一个整数，count是整数数量；整个块占width*count个字符。只有n严格大于整块长度时才跳过，等号仍属于当前块的最后一位。

跳过所有完整块后，将剩余位次减1，整除width得到当前块内的整数偏移，取模得到目标整数中从左起的数字偏移。再用10的整数幂把目标位移到个位，取模10，无需构建目标整数的字符串或整个数字流。所有计算都是整数；即使n不超过32位，块长度width*count仍可能超过32位，Python精确整数不会回绕。

块数随n对数增长，按原题有界整数模型，时间O(log n)，额外空间O(1)；最多定位到九位整数的块。不用浮点对数猜测目标位宽，避免10的幂边界误差。

独立小域oracle直接连接1..9999的十进制文本，对其38889个位置逐一核对。大位置另用累计数字秩函数配合二分搜索，找出第一个累计长度达到n的整数，再从其字符串取位；不复用生产逐块减n或算术取位。检查9/189/2889等块末尾、下一块开头以及32位最大n。
