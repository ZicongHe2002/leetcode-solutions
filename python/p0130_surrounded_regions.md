# 130. Surrounded Regions · Python

[原题](https://leetcode.com/problems/surrounded-regions/)。

原题board为1..200行、1..200列的矩形，元素是字符X或O，四邻接。需要把完全被X包围的O区域原地改为X，边界连通的O保留；solve返回None，调用方查看board。实现额外支持空矩阵或0列直接返回。

从四条边的O同时出发，BFS标记所有与边界连通的O为safe，角落重复种子由集合去重。一个O能沿O到达边界就不被包围，反之它所在连通块与边界隔离，应全部翻转。搜索期间保留原board，最后只改不在safe中的O，避免自身修改影响后续可达性。时间O(行数*列数)，辅助空间O(行数*列数)，使用队列而非深递归。

独立oracle把O与虚拟外界组成并查集，按四邻接合并后判断每格是否连到外界，不复用BFS。行列各1..3的全部682个X/O矩阵核对。边界覆盖200*200全O/全X、内部大区域、通边细走廊及只沿对角接触的O，核对原地结果和None返回；空维度为扩展。
