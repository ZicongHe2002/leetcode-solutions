# 980. Unique Paths III · Python

[原题](https://leetcode.com/problems/unique-paths-iii/)。

先统计所有非障碍格，包括起终点。四向回溯时将当前格临时标障碍，避免同一路径重复访问，返回前恢复；遇终点立即结束，仅当已访问数等于全部可走格数才计1。提前到终点不能继续穿过再回来，因而不计。每次分支对应下一步不同的路径选择，完整枚举所有合法路线。标记只作用于副本，原网格保持。

可走格K在题目小规模范围内，首次最多4分支、之后不能原路返回，时间保守上界O(3^K+RC)，副本与递归空间O(RC+K)。
