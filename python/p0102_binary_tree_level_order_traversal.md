# 102. Binary Tree Level Order Traversal · Python

[原题](https://leetcode.com/problems/binary-tree-level-order-traversal/)。

输入二叉树有0..2000节点，值在[-1000,1000]。返回按深度分组、同层从左到右的值列表；空树返回空列表，每层是独立列表。只读原树，不改值或左右链接。

队列开始仅含根。每轮先固定当前队列长度，该批正好是当前层；逐个弹出并按左、右顺序追加孩子，所以下一层仍然从左到右。固定批次长度使新入队的孩子不会被混入当前层。每节点入队出队各一次，时间O(L)，除返回结果外额外空间O(w)，w是最大层宽，使用deque避免列表头删的搬移开销。

独立oracle使用显式深度优先栈，将值追加到对应深度的桶；先压右后压左保证同深度相对顺序，不复用按队列长度分层。枚举长度0..6的所有树形与二值赋值，共10067棵，检查输入身份/链接/值保持与各层列表互不相同。边界覆盖2000层链、2000节点完全树、左右缺口、重复值、合法值两端和空树。
