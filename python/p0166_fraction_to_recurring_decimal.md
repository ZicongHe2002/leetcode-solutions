# 166. Fraction to Recurring Decimal · Python

[原题](https://leetcode.com/problems/fraction-to-recurring-decimal/)。

原题分子分母均在32位有符号范围，分母非0，输出十进制字符串，循环部分加括号，答案长度保证小于10000。有限小数必须有限表示；循环部分原题允许多种合法写法，本实现选择首次余数重复所对应的最早循环起点与最短循环节。

先单独处理0，避免-0；符号由分子分母符号是否不同决定，再对绝对值做整数除法。整数部分直接输出，非零余数开始长除法。每一步把余数乘10，商产生一个0..9数字，新余数决定下一步。

positions记录一个余数第一次出现时的小数位下标。相同余数意味着后续整个商/余数序列重复，因此在对应数字区间加括号；余数归零则精确终止，不添加括号。记录位置发生在生成该位之前，避免循环起点偏一位。全程整数运算，Python的abs能表示最小32位整数的绝对值。

L为实际输出长度，时间和额外空间O(L)，只保存数字及出现过的余数。没有浮点舍入参与。

独立验证把输出非循环段与循环段按几何级数精确还原为Fraction，必须等于原分数；对约分后的分母提取2和5的次数来确定所选最早前缀长度，再用10的乘法阶确定最短周期，避免仅凭近似小数相等。小分子-20..20、非零小分母-20..20共1640例，另有32位端点、零、有限小数及1/9967的9966位周期，输出9970字符且小于10000。参考按200位块读取长数字，不改Python全局整数转换限制。
