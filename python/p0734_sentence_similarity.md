# 734. Sentence Similarity · Python

[原题](https://leetcode.com/problems/sentence-similarity/)。

原题两个句子各1..1000词，每词1..20个英文字母，给出0..1000个不同相似词对。句子相似要求长度相等且每个对应位置的词相同，或直接出现在给定的相似词对中。关系对称且自身相似，但不具有传递性；大小写不会自动归一。

先检查长度，防止zip截断后漏掉多余词。把每个给定词对变成frozenset后放入集合，同一无序对不受输入方向影响。逐位置检查：相同词直接通过，即使它从未出现在任何词对中；不同词则必须查询对应的无序词对。全部位置通过才返回True。

集合只存直接给出的词对，没有构造传递闭包，因此a~b、b~c不会自动使a~c通过。不同词构成的frozenset有两项，与同词词对的一项集合不同；重复方向也不会改变判断。实现不修改句子数组、词对数组或任何字符串。

设N为句长、P为词对数、L为最长词长，在哈希表平均常数访问模型下时间O((N+P)*L)，集合占O(P)个词引用，若把所引用词文本也计入则O(P*L)上界；词对查询只临时构造两个引用。提前长度不等时O(1)返回。没有把此题当作可传递的句子相似II。

独立oracle逐位置扫描原始词对列表的两个方向，不使用无序集合或图连通性。3词全集的8种无向关系、长度1..3的39个句子两两组合，共12168次判断，包含不同长度和非传递链。另核对官方样例、大小写、自身相似、1000词/1000对/20字符边界及输入保持。未向LeetCode提交。
