# 202. Happy Number · Python

[原题](https://leetcode.com/problems/happy-number/)。

原题1<=n<=2**31-1，反复把整数替换为各十进制数字平方的和，能到达1则为快乐数，否则最终落入其他循环。返回bool。

替换过程是确定的后继函数。用divmod逐位计算后继，slow每轮走一步，fast每轮走两步；快指针到1就成功，非1环中两者必会相遇，相遇后可判失败。初始fast先走一步，避免把起点相等直接当成环。1的后继仍为1，所以任何路径到1都能由快指针检测到。

原题最多10位，第一次替换后不超过810，之后不超过243，因此最终处在有限状态空间中，必然到1或进入循环。初始按位处理需要O(log n)时间，后续环检测在原题固定范围内为常数规模；辅助空间O(1)，不用记录全部访问值。

独立oracle用字符串提取数字并以集合记录访问，出现重复或到1时停止，不使用快慢指针，也不复用divmod后继。1..10000全部10000个输入核对；边界覆盖32位最大值、含多个9的大数、10的幂、已知快乐数19及非快乐循环入口2/4，核对bool返回。
