# 72. Edit Distance · Python

[原题](https://leetcode.com/problems/edit-distance/)。

输入是长度0..500的两个小写英文字母串，返回把word1变成word2所需的最少插入、删除或替换次数，每种操作代价为1。空串属于原题合同，字符相同不需要操作。字符串不可变，实现仅局部交换变量以缩短存储行，不改变调用者输入。

一格表示两个前缀的编辑距离。末字符相等时沿左上角继承；不等时，删除对应上方、插入对应左方、替换对应左上方，三者取最小再加1。首行和首列分别是从空串插入或删至空串的长度。当前行只依赖上一行与本行左格，因此保留两行即可。插入和删除互为逆操作、替换也对称，允许交换两输入使第二维更短。含空串边界的时间上界为O((m+1)(n+1))，额外空间O(min(m,n)+1)。

独立oracle把小字符串当作编辑图节点，用单位边的广度优先搜索找目标，不复用前缀递推。枚举二字母长度0..4的31个串全部961对；测试图候选长度不超过两输入较长者，枚举插入/删除/替换。边界覆盖500长度全替换、相同串、空串、交替串移位的两步期望和horse到ros的3步例子，返回int被检查。
