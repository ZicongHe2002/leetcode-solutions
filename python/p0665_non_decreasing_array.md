# 665. Non-decreasing Array · Python

[原题](https://leetcode.com/problems/non-decreasing-array/)。

原题nums长1..10000，值-10^5..10^5，判断最多修改一项能否变成非递减数组。相等允许，已经有序无需修改。只返回bool，本实现虚拟修改，不改变原数组。

previous是已处理前缀经过至多一次虚拟修改后的末值。第一次遇到value<previous时，若没有左左邻或左左邻<=value，可以把前一项降到value，较小末值更利于后续；否则降低前一项会破坏左边，只能把当前项抬到previous，此时continue让previous保持。若随后再遇到下降，一次修改已用尽，直接False。第一次修改之前前缀原本有序，所以判断左左邻时读取原nums[index-2]有效；修改之后再下降会先拒绝，不会继续依赖已过时的原值。

每项一次，时间O(n)，额外空间O(1)，没有输入拷贝或写入。独立参考逐下标尝试实际替换，再检查全部相邻关系。小样本值-1/0/1，替换枚举-2..2，完整包含所有必要邻值或端点选择；长度1..8共9840个数组全部核对。另测10000项、一次可修/两处不可修、原题值域两端，核对bool与输入保持。
