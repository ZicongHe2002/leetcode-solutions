# 592. Fraction Addition and Subtraction · Python

[原题](https://leetcode.com/problems/fraction-addition-and-subtraction/)。

expression含1..10个合法最简分数，以加减连接，没有空格、乘除或括号。各项分子和正分母在1..10，首项为正时不写+，最终分子分母在32位范围内。返回最简的有符号分子/正分母字符串；整数也写成分母1，零必须规范为0/1。只处理合法表达式，不使用eval，也不以浮点近似判断约分。

index逐项读取可选符号，定位/得到完整分子，再消费分母的全部数字，因而正确处理10而非只取一位。后续的+或-留给下一轮作为该项的符号。当前numerator/denominator始终等于已经读完前缀的精确和，且已最简、分母为正。

加入a/b时先按(numerator*b+a*denominator)/(denominator*b)通分，再用gcd(abs(新分子),新分母)同时约分。正分母乘积保持正，Python整数保持中间运算准确。分子变为0时gcd(0,d)=d，立即归为0/1；结果为正不额外加+，为负保留负号。对已读项数归纳，最后得到整式的最简精确和。

设输入长L、项数K、中间整数绝对值上界为B。在单次整数运算模型下，扫描O(L)，欧几里得算法每项O(log B)，总O(L+K log B)。本题分母约分后整除lcm(1..10)=2520，项数和分子也有界，因此保存常数个有界整数，额外空间O(1)，不将其推广为任意长度大整数的位复杂度。输出另计其字符串长度。

独立参考用正则识别有符号分数，然后使用标准库Fraction求和，不复用手写扫描或gcd归约。分子/分母取1..3的合法互质项，带正负号共14种，穷举1..4项全部41370个表达式；另测300组固定种子的10项合法表达式。边界覆盖10分子/10分母、相消为0、负分数、正负整数和样例，检查输出分母为正、互质、格式规范。未向LeetCode提交。
