# 304. Range Sum Query 2D - Immutable · Python

[原题](https://leetcode.com/problems/range-sum-query-2d-immutable/)。

原题矩阵行列数1..200、元素在-10000..10000，使用NumMatrix(matrix)和sumRegion(row1,col1,row2,col2)。矩形两个角均包含在查询中、下标合法；每对象最多10000次调用，要求查询O(1)，返回int，输入矩阵保持。

补一圈0建立二维前缀，_prefix[r][c]是前r行前c列总和。构造时逐行累加running，再加正上方的前缀，覆盖目标前缀矩形。查询取右下大矩形，减掉上方条带和左方条带，再加回重复减去的左上角，四项容斥给出闭矩形和，顶行/首列自然用0边界。构造O(m*n)、空间O(m*n)，每次查询固定四次读取，为O(1)。

独立参考对每个查询矩形直接逐格求和。1..3行列、值-1/0/1的全部21297个矩阵逐一查询其全部合法矩形；另对200乘200极值棋盘连续执行恰10000次查询，按高宽奇偶给出独立参考，并新建对象核对全正/全负矩阵的大和。每对象符合调用上限，检查int与原矩阵不变。
