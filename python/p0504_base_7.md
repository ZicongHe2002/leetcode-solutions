# 504. Base 7 · Python

[原题](https://leetcode.com/problems/base-7/)。

原题num在-10000000..10000000，返回带符号的七进制字符串。数字仅0..6，0单独表示为0，负数前加一个负号，不采用固定宽度补码。

对非零输入先保存符号，再用绝对值反复divmod(value,7)。余数是当前最低位，商为尚未处理的高位，直到商归零；将逆序数字反转连接后加符号。0提前返回，避免空字符串或-0。

非零输入有D个七进制数字，时间和额外空间O(D)，D=1+floor(log7(abs(num)))，原题最多9位；0为常数时间。使用整数除法，不经过浮点对数计算位数。

独立验证使用标准库int(text,7)回读，结合无前导零、正确单一符号和0..6字符集，唯一确定规范七进制表示，不复用生产余数循环。-10000..10000全部20001整数核对，另测正负10000000及7^0..7^8附近的进位，固定100->202、-7->-10与0样例检查。
