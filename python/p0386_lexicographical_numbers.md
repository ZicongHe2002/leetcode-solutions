# 386. Lexicographical Numbers · Python

[原题](https://leetcode.com/problems/lexicographical-numbers/)。

按十进制字符串的字典序返回1..n，不能用数值升序代替，例如n=13时先1、10、11、12、13，再2。原题n在1..50000，要求O(n)时间，除输出外O(1)空间。本实现额外对n=0返回空列表。

把每个正整数看作十叉前缀树中的节点，子节点为末尾追加0..9后仍不超过n的整数，根为1..9。先序遍历恰好是字典序：一个前缀先于其扩展，同层下一位更小的子树先输出。

current*10不超过n时进入第一个孩子。否则当前子树没有尚未访问的孩子：若末位为9，已经没有下一兄弟；若current+1超过n，下一兄弟不在范围。遇到这两种情况就除10回到父前缀，直到可转入下一个兄弟。排除末位9再加1，避免把19错误地当作下一兄弟20而跳过父前缀2。整个过程用整数算术，不创建字符串、递归帧或排序副本。

共输出n次。虽然某次可能连续回升多层，但每次下降进入的前缀边至多回升一次，因此总回升次数O(n)，总时间O(n)。结果列表O(n)是必需输出；除此只有current与固定数量的循环变量，辅助空间O(1)。最后一项之后的后继值不再输出，不需要赋予范围外状态额外含义。

独立oracle显式构造1..n并按str排序，不使用数字前缀游走。0..500全部n对照；另核对9/10、99/100、999/1000等回升边界和原题上界50000，检查输出无缺失、无重复以及1..n范围；n=0属于扩展。
