# 215. Kth Largest Element in an Array · Python

[原题](https://leetcode.com/problems/kth-largest-element-in-an-array/)。

原题1<=k<=nums长度<=100000，元素为-10000..10000。求排序后第k大的元素，重复值按出现次数参与排名，不是第k个不同值。实现保持输入。

最小堆selected始终保存已经读取元素中最大的k个值。先读k个值建堆，后续值若不大于堆顶，就不可能改善这k个位置；更大时替换最小的堆顶，仍保留最大的k个。读取全部元素后，堆内最小值就是第k大。相等值无需替换，堆本身仍保留正确的重复次数。

使用迭代器继续扫描，避免nums[k:]额外复制整个后缀。时间O(n log(k+1))，辅助空间O(k)，没有原地排序或修改nums。

独立oracle直接降序排序后取下标k-1，不使用堆。元素取-1/0/1、长度1..7的全部3279个数组，枚举所有合法k，共21324次查询。边界覆盖100000元素、k为1及n、重复极值、正负混合，核对int与输入保持。
