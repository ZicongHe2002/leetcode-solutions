# 800. Similar RGB Color · Python

[原题](https://leetcode.com/problems/similar-rgb-color/)。

原题输入为7字符#加6位小写十六进制数。可简写颜色要求每个通道的两位相同，因此单通道只能取0x00、0x11、...、0xff，即17的倍数。输出仍是完整#rrggbb，不是三位简写。

相似度为三个通道平方距离之和的相反数；三个选择相互独立，逐通道最小化平方差就最小化总差。平方距离随绝对差增大，故对v选择最近的17倍数即可。相邻倍数间距17为奇数，整数v不可能恰好处在8.5的中点；余数0..8向下，9..16向上，整数公式(v+8)//17恰好表达该规则。v<=255时结果在0..15，无需额外截断。

format(...,'02x')保持两位小写和前导0，再按原顺序拼接三个通道。固定三个通道，每次最多枚举两字符，时间与额外空间O(1)。不采用浮点round，也不把整个24位颜色作为单个距离轴。

独立oracle枚举16个候选，以实际平方差选最小，核对三个通道各自0..255全部768查询。另对32个固定种子颜色逐个枚举全部4096个可简写颜色，直接比较总平方差并核对最优值；包含官方例、全0、全f、前导0与临界余数8/9。未向LeetCode提交。
