# 530. Minimum Absolute Difference in BST · Python

[原题](https://leetcode.com/problems/minimum-absolute-difference-in-bst/)。

给定含2..10000个节点的二叉搜索树，节点值在0..100000，返回两个不同节点值的最小绝对差。使用LeetCode提供的TreeNode接口，不重新定义生产节点类；树的值和左右引用保持。依赖原题BST顺序和至少两个节点，不把一般无序树或空树当作本题输入。

BST的中序遍历按值非降序访问节点。排好序的任意两个非相邻值之差，是它们之间相邻差的和；这些差非负，所以不会小于其中最小的相邻差。全体节点对的最小绝对差必能在某对中序相邻节点中找到，不必保存所有节点再枚举二次方数量的节点对。

stack保存尚未访问的祖先，每次先沿左链入栈，弹出最小的未访问节点，再转入其右子树。previous保存刚访问节点的值，None只表示尚无前驱，不能用真假判断，因为合法值0必须参与下一次比较。best累计相邻差的最小值，初始化100000是原题值域允许的最大差；至少两个节点保证真正比较过节点对。结果保持整数。

每个节点入栈出栈各一次，时间O(N)，辅助空间O(H)，H为树高；退化链最坏O(N)。使用显式栈避免10000深链超出Python递归上限，既不临时改左右指针，也不修改节点值。

独立参考用普通显式遍历收集节点值，直接枚举全部无序节点对并取绝对差，不排序、不使用中序相邻差。七个合法值选取2..6个，枚举每组全部BST形状，共2513棵树对照；快照逐节点身份、值和左右引用，验证完全保持。另测10000节点左右退化链、0与100000两点最大差及原例，核对int。未向LeetCode提交。
