# 91. Decode Ways · Python

[原题](https://leetcode.com/problems/decode-ways/)。

输入为1..100位十进制数字字符串，按1..26映射字母，返回合法解码方案数；原题保证答案在32位有符号整数内。0不能单独解码，带前导0的两位块也不合法。本实现额外支持空字符串返回0，不承诺非数字输入。

令前缀解码数dp[i]表示前i个字符的方案数。最后一块只能长1或2：当前字符非0时，把它接到前一前缀的全部方案；最后两位在10..26时，把它接到前两字符之前的全部方案。两类最后块长度不同，互不重复且覆盖全部合法方案。滚动变量previous_two、previous_one在每轮更新前分别保存这两个旧前缀；统一求完ways再同时移动，防止覆盖。空前缀的内部递推基数为1，第一个字符0时为0；这与接口的空字符串扩展返回0分别定义。时间O(n)，额外空间O(1)，每次两位转换长度固定。

独立oracle枚举全部字符间切割位掩码，逐块检查长度1或2、无前导0、数值1..26，统计完整合法切割，不用前缀DP。枚举0/1/2/3上长度0..6的全部5461个字符串。固定覆盖06、10、20、26、27、100、11106和226；长度100使用重复10、全9及首位0等原题答案范围内输入，没有用超出32位答案保证的长全1字符串冒充合同边界。
