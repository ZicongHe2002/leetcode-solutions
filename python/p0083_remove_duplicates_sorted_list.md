# 83. Remove Duplicates from Sorted List · Python

[原题](https://leetcode.com/problems/remove-duplicates-from-sorted-list/)。

输入为0..300节点的已排序无环单链表，值在[-100,100]。每个不同值保留一份。本实现保留每个重复段的首个原节点，不构造新结果节点、不改写节点值；非空输入返回原头对象，空链返回None，结果尾部为None。

current是当前值的保留节点。下一节点同值时，跨过下一节点但不移动current，以便继续清掉同一段；下一节点不同值时再前移到新段的首节点。排序保证某值的所有出现都连续，因此段处理完成后不会在后面再次遇到它。每轮跳过一个节点或前移一次，总计O(L)时间，额外空间O(1)。与“重复值全部删除”不同，本题保留每段首节点。

独立oracle在原节点数组上用seen集合选出各值第一次出现的原对象，不使用相邻next重连。五值集合[-2,-1,0,1,2]上长度0..8的全部1287条非递减链均核对。边界覆盖300个相同值、三段各100个节点、201个合法互异值、空链及经典例子；确切身份序列和尾部None检查可发现只改值、复制新链或遗漏断尾的问题，并核对所有原值保持。
