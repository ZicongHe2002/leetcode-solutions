# 71. Simplify Path · Python

[原题](https://leetcode.com/problems/simplify-path/)。

原题path为长度1..3000的Unix绝对路径字符串，以/开始。重复分隔符合并，.表示当前位置，..返回父级但不能越过根；...或a..等其他名字是普通组件。返回单根斜杠起始、组件间单斜杠且无多余尾斜杠的规范字符串，根目录保持/。按字符串规约处理，不访问文件系统或符号链接。

components保存已规约前缀。空组件和.不改变位置；..弹出最近普通组件，栈空时仍停在根；其余名字原样压入。处理完每个组件，栈恰表示当前绝对位置，最后统一连接生成唯一形式。时间O(len(path))，额外空间O(len(path))。

独立oracle使用标准库posixpath.normpath，再把其POSIX特殊保留的双起始斜杠规范成原题的单斜杠。从空组件、.、..、a、...、b_c生成长度0..6的55987组组件序列核对；组件序列不等同于互异路径。边界覆盖3000字符、长父级串、普通多点名字及双斜杠，核对str，未使用Windows路径规则。
