# 429. N-ary Tree Level Order Traversal · Python

[原题](https://leetcode.com/problems/n-ary-tree-level-order-traversal/)。

按从根到叶、每层从左到右的顺序返回N叉树节点值。原题节点数0..10000，节点值0..10000，树高不超过1000，children顺序就是兄弟顺序。空根返回空列表；children为None或空列表都当作没有孩子，不修改输入节点及孩子列表。

队列初始仅有根。每层开始先固定当前队列长度，本轮恰好弹出这一批节点，按给定顺序把孩子加到队尾。因此新加入的孩子只在下一轮处理，不会与父层混入同一个结果。归纳可得队列在每轮开始时恰好按顺序保存该深度的节点，输出即为所需层序。

每个节点入队出队一次，总时间O(n)。队列中至多有相邻两层的部分节点，辅助空间O(w)，w为最大层宽；返回值另有O(n)空间。使用deque头部弹出，避免列表pop(0)的线性搬移；生产无递归，深树不依赖Python递归深度。构造器不使用共享可变默认孩子列表。

独立小参考按深度优先递归遍历，依深度向不同结果列表追加值，不使用生产队列。1..8节点全部626种有序根树形，加空根共627项核对，节点赋不同值以验证兄弟顺序；迭代快照检查节点身份、值及孩子链接保持。另测10000节点宽星形、1000节点深链与外部节点children=None，深边界参考直接给出期望而不调用递归oracle。未向LeetCode提交。
