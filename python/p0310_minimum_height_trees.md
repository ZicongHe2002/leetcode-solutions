# 310. Minimum Height Trees · Python

[原题](https://leetcode.com/problems/minimum-height-trees/)。

原题n为1..20000，无向边恰n-1条且保证为树，无重复边、自环，编号0..n-1。选择根后的高度是到最远点的边数，返回所有最小高度根的list[int]，顺序任选，输入保持。

多于两个节点时，叶子不可能最优：把根从叶子移向其唯一邻居，会把到其他节点的最远距离减少1，且回到该叶子的距离仅为1。删去全部叶子后，对保留节点来说最远距离统一减少1，所以最优根集合保留；反复剥离，最后剩一个或两个中心。队列每次只处理本轮叶子数，不把新产生叶子混入当前层。n=1单独返回0，n=2直接保留两个叶子。时间O(n)，额外空间O(n)，不做深递归。

独立参考从每个候选根分别BFS，取其最大距离，再找最小高度，不用剥叶算法。用Prüfer序列生成2..6节点全部标号树，加上单节点，共1442棵树逐一核对。另测20000节点偶长链、19999节点奇长链、中心在0或末编号的星形，按集合比较完整中心、不固定次序，核对输入保持。
