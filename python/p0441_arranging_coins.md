# 441. Arranging Coins · Python

[原题](https://leetcode.com/problems/arranging-coins/)。

原题n在1..2^31-1，第i行必须放i枚硬币，返回能填满的行数int；剩下不完整的一行不计入答案。

填满r行需要三角数r(r+1)/2，随非负r严格递增。二分0..n寻找满足需求不超过预算的最大r；满足时继续找更大，不满足时缩小上界。循环结束low=high+1，high是最后一个可行行数，下一行需求已大于预算。全部公式使用整数乘法与整除，不依赖浮点平方根；Python整数避免乘法溢出。时间O(log n)，额外空间O(1)，按原题32位整数规模计。

独立小规模参考从第1行开始实际逐行扣硬币，在1..10000上核对。另对范围内全部65535个三角数，分别验证少一枚、恰填满、多一枚时的完整行数，跳过非法预算0；同时核对32位最大预算与前一值。三角数边界直接由已知行数构造，不使用二分求参考答案，检查int。
