# 867. Transpose Matrix · Python

[原题](https://leetcode.com/problems/transpose-matrix/)。

原题矩阵行列数分别1..1000，总元素不超过100000，元素在-10^9..10^9。转置交换行列下标，m行n列变成n行m列，返回list[list[int]]，原矩阵不变。

对每个原列column，按原行row顺序收集matrix[row][column]作为结果的一行，因此结果[column][row]精确等于输入[row][column]，每个输入元素恰进入一个输出位置。各结果行用新列表构造，不共享原输入行或其他结果行。时间O(m*n)，返回矩阵空间O(m*n)，除返回值外额外空间O(1)。非方阵和单行单列使用相同下标映射。

独立参考用zip将输入行逐列打包，再将每个列元组转换为列表，不用双下标访问作为参考。覆盖1..3行列的全部682个二值矩阵、1..7行列的49种唯一坐标形状；另测100000元素的高宽矩形、最长单行/单列、10^9值域端点，核对形状、行存储独立、list行类型与输入保持。
