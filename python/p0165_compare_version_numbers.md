# 165. Compare Version Numbers · Python

[原题](https://leetcode.com/problems/compare-version-numbers/)。

原题两个合法版本串长1..500，只含数字和点，每段修订号的数值可放入32位整数。逐段按整数比较，忽略段内前导零，缺少的后续段按0处理，返回-1/0/1；版本串不能当作小数或普通字符串比较。

按点分段，遍历较长的段数，已有段转int、缺失段取0。此前所有段相等时，当前首次不同段决定整个版本的大小；所有补零后段都相同才返回0。int转换统一去掉前导零，所以1.01和1.001相等，1.0与1.0.0也相等。

两串总长度为L，分段和整数读取累计O(L)，额外空间O(L)保存段字符串。原题段数值有32位界，长前导零仍会消耗扫描时间，但不产生超范围修订值。不处理非法点号或空段。

独立参考从已知数值元组生成带不同前导零的文本，再直接补齐元组比较，不解析待测字符串得到期望。六种段文本、1..3段共258个版本，全部66564有序版本对核对。500字符单段、249个尾随零段及最大32位修订号边界检查，核对int且结果仅为-1/0/1。
