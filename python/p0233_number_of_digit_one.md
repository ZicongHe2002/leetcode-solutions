# 233. Number of Digit One · Python

[原题](https://leetcode.com/problems/number-of-digit-one/)。

给定0..10^9内的整数n，统计0..n全部整数的十进制表示中数字1出现的总次数。统计的是出现次数，一个整数可以贡献多个1；不计前导零，也不把数字0计作一次1。

固定一个权位place，将n拆成更高位higher、当前位current和低位lower。每个长度10*place的完整周期中，该位等于1的区间恰有place个整数，所以完整周期贡献higher*place。最后的不完整周期中，current=0时尚未到达1段；current=1时覆盖了低位0..lower，共lower+1个；current>1时覆盖完整的place个。

从个位逐次乘10，累加每个实际权位的贡献。同一个数有多个1时会在不同权位各计一次，正好符合出现次数的定义。n=0不进入循环并返回0。当前权位超过n后，所有0..n的该位都只能为0，因此可以停止。

每个权位使用固定数量的整数运算，按原题有界整数模型，时间O(log10(n+1))、额外空间O(1)，n=0为常数时间。Python整数可以安全计算10*place，不需浮点对数或十进制字符串转换。

独立oracle按顺序累加str(value).count('1')，逐个核对0..20000全部20001个上界，而不是复用权位分段公式。另利用0..10^k-1的全部k位补零表示：每个位出现1恰有10^(k-1)次，得到k*10^(k-1)的组合计数。检查10的幂前后及最大上界10^9，后者应为900000001。
