# 449. Serialize and Deserialize BST · Python

[原题](https://leetcode.com/problems/serialize-and-deserialize-bst/)。

本题接口为Codec.serialize/deserialize：将严格二叉搜索树编码成字符串，再从自己的编码恢复相同值与结构。原题0..10000节点，值0..10000，BST左子树严格更小、右子树严格更大，因此没有重复键。空树编码为空串；解码输入按合同来自本编码器，不负责验证任意损坏文本或非BST先序。

编码采用先序，只写节点值，用空格分隔，不写空孩子标记。显式栈先压右孩子再压左孩子，弹出顺序即根/左/右；原树不写入。省略空标记依赖严格BST约束，不能照搬到任意二叉树。

解码按先序逐值构建。ancestors保存尚可能接入右孩子的祖先链；新值比栈顶小，就作为其左孩子。否则连续弹出比新值小的祖先，最后弹出的节点正是新值所属右子树的父节点，将新节点接到其右侧，再入栈。合法BST先序保证此前左子树已经完整读完，并且新值不超过剩余较大祖先的约束，因此既恢复大小关系，也恢复先序确定的唯一结构。

编码每节点处理一次，解码每节点入栈出栈各一次，原题有界整数模型下时间均O(n)。编码保存值字符串列表，解码split保存全部文本token，各有O(n)辅助空间；祖先/遍历控制栈另为O(h)，未把token存储省略成只有O(h)。返回的新树另占O(n)。两过程均无递归，10000节点深链可直接处理。

独立验证使用包含空孩子位置的广度优先结构签名比较原树与新树，并核对新树节点身份与原树不相交、原树所有值/链接未变；不以生产先序字符串相等作为唯一正确性证据。0..8节点全部2056种BST形状分别按中序分配不同键后往返核对。另测10000节点左右深链、空串、值0与10000，以及同一Codec多次调用。未向LeetCode提交。
