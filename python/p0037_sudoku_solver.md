# 37. Sudoku Solver · Python

[原题](https://leetcode.com/problems/sudoku-solver/)。

在9×9字符矩阵上原地补全数独，每行、每列及每个3×3宫恰含1..9。空格为'.'，原题保证恰有一个解。本实现保留已有数字及行对象，返回None；不为非法、无解或多解输入增加未约定的行为。

用九位掩码分别记录每行、每列及每宫已用的数字，空格的位置另存数组。递归每次从尚未填的位置中选择候选数最少的一格，与当前位置交换；候选是全集减去三个已用集合。最低有效位逐个枚举数字，写入棋盘和三个掩码后递归。失败时撤销这一个数字，再试下一个；所有候选失败后恢复位置交换。

候选位在本行、本列和本宫原先均未使用，加入后只设置这一位，因此失败时用异或撤销不会清掉别的格子的状态。每一层只填原空格，初始线索不会改变。枚举覆盖所选空格的全部合法数字；无候选立即失败，全部空格填完即成功。最少候选只改变搜索顺序，不删除合法分支。成功返回时保留当前解，不执行撤销；原题的唯一解保证结果确定。

设初始空格数为E，分支数至多9，逐层选位置还需扫描剩余空格；宽松最坏时间界为O(E·9^E)，最少候选剪枝不保证多项式时间。掩码为固定大小，空格数组和递归栈占O(E)空间；本题E不超过81。

测试独立以集合检查全部行、列、宫和初始线索，不复用求解器的掩码逻辑。标准题及较难题均与完整解对照，并以九种循环数字置换和转置的双射变换核对36个唯一解实例；另覆盖81个单格缺失、512种每行至多一个空格的对角线缺失组合及完整棋盘。核对原地修改、行对象身份和None返回值。
