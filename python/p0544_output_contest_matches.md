# 544. Output Contest Matches · Python

[原题](https://leetcode.com/problems/output-contest-matches/)。

给定N=2^x支队伍，x在1..12，即N为2..4096的二次幂。队号1..N表示由强到弱的初始排名，每轮最强种子与最弱种子配对，返回括号和逗号组成的完整对阵字符串。数字必须保留完整十进制队号，不只支持个位数队伍。

matches最初按排名保存每支队伍的文字。每轮用首项配末项、第二项配倒数第二项，直到中间，把两项包成(左,右)。新列表仍按每组的最强种子递增排列：第i组的较强种子来自旧列表前半部第i项，较弱种子来自后半部对应项。因此相同的两端配对规则可以直接用于下一轮。

每一轮所有旧项恰好进入一个新组，没有遗漏或重复；新文字保留两项各自已经生成的子对阵，并增加一场外围比赛。N是二次幂，未到最终单项前列表长度总为偶数，无需轮空处理。经过log2(N)轮只剩一项，恰是完整比赛树的文本，返回其中字符串而非列表或额外外壳。

令C为最终输出字符数，包含全部多位队号及N-1场比赛的标点。每轮复制的文本总量至多O(C)，共log2(N)轮，时间上界O(C*log N)。任一轮全部字符串不超过最终字符量，旧新两轮同时存在也只加常数倍，空间O(C)。明确计入字符串复制，不把多位队号和反复拼接都当成常量成本。

独立参考先用种子互补关系生成最终叶序：从[1]开始，每次把旧种子s展开为s和新规模+1-s，再对最终叶序作平衡二分括号化，不按生产的比赛字符串两端归并。全部12个合法N分别对照，覆盖完整输入域。另解析4096队输出的完整语法，核对每队恰出现一次、各子树等高、每轮强弱种子互补及最终高度；核对2/4/8队原例。实际运行通过，未向LeetCode提交。
