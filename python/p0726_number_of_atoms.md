# 726. Number of Atoms · Python

[原题](https://leetcode.com/problems/number-of-atoms/)。

原题给出长度1..1000的合法化学式。元素为大写字母开头、随后零个或多个小写字母；元素和括号组后可有大于1的十进制数量，省略表示1。需要合计每种元素并按元素名排序输出，计数1不写数字。输出计数保证在32位整数范围。

先按元素名、完整数字、单个括号分词，再从右往左扫描。count保存紧接左边原子或组的数量，默认1。multipliers栈顶保存当前位置所有外层组的倍率乘积。读到数字只设置count；读到右括号就把栈顶乘count后入栈，并复位count；读到左括号离开该组、弹栈；读到元素则加入栈顶乘count的个数并复位count。

反向读到某元素时，右边所有包围它的组倍率已经入栈，而左括号尚未弹栈，栈顶恰是需要相乘的外层倍率。每个元素局部数量只使用一次；内层组结束后恢复外层栈顶，不影响相邻组或原子。元素名作为完整token处理，He不会拆成H和e。最终对合计键排序，并仅在总数大于1时附加数字。

不递归下降，也不在每个括号关闭时反复合并元素字典，所以深括号不会消耗Python调用栈或反复复制大量键。设n为输入长、K为不同元素数、L为最长元素名，分词与扫描O(n)，排序比较上界O(K*L*log(K+1))，总时间O(n+K*L*log(K+1))；token、倍率栈与计数表合计额外空间O(n)。数量按原题32位界作常数整数操作。

独立oracle先构造公式语法树，再在构造时通过字典加法与整组缩放得到期待计数，不从输入字符串解析答案。12个带合法数量的原子、144个二原子拼接和48个单原子组构成204个组件；全部组件对拼接及每组件三种外层倍率，共42228个构造案例。另核对官方样例、1000字符/499层括号、相邻元素名排序、重复元素合计和32位最大计数。未向LeetCode提交。
