# 590. N-ary Tree Postorder Traversal · Python

[原题](https://leetcode.com/problems/n-ary-tree-postorder-traversal/)。

输入N叉树有0..10000节点，值0..10000，高度不超过1000。返回后序值列表：按children的给定次序完整访问每棵孩子子树，最后才输出当前节点。平台提供Node接口；序列化中的null不是实际孩子。空根返回[]，叶子的children为None或[]均有效，输入节点和孩子列表保持。

pending每帧保存一个节点及其已推进到当前孩子位置的迭代器。若栈顶还有孩子，就压入该孩子的新帧，父帧留在栈中暂停；若孩子已全部处理，才输出本节点并弹帧。对树高归纳，叶帧立即输出，父帧在所有孩子按次序完成后输出，因此正好满足后序，而不是把整个先序随意倒序。

next(...,None)作为完成标记依赖children只含实际Node的合同，不会把数值0误当成完成，也不会按节点值去重。每个节点只保留一帧，每次只推进一个孩子，不把整层宽孩子压入栈。显式栈处理1000层链，无需更改解释器递归限制或改写节点。

节点入栈和出栈各一次，每条孩子边只推进一次，时间O(N)。辅助栈O(H)，不含必须返回的O(N)值列表。宽度10000的星形只需根与当前叶的帧，不把空间误记成必须O(最大层宽)。
