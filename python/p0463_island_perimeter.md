# 463. Island Perimeter · Python

[原题](https://leetcode.com/problems/island-perimeter/)。

0/1网格表示水与陆地，求唯一岛屿的周长。原题行列各1..100，陆地按上下左右连接，岛内没有与外部水域隔开的湖。对角相接不算共享边。输入保持，空网格额外返回0。

每个陆地格先贡献四条单位边。相邻两陆地共享的那条边已在两个格的四边中各计一次，但不属于外边界，故每对相邻陆地需要减2。扫描时只检查上方和左方，这样每条共享边恰好处理一次，不会把四个方向都减2而重复扣除。

每条格边只有两种情况：邻接水或网格外侧时计入一次，相邻两陆地时两次计入又减2。因此最终保留的恰为所有陆水/外部边界单位边，得到周长。无需修改网格、搜索岛屿或把矩形外接框周长当作岛屿周长。

时间O(R*C)，辅助空间O(1)。无需保存全部边段或访问标记；参考测试中的集合只用于独立验证，不是生产额外空间。

独立参考显式生成每个陆格的几何单位边段，规范化端点顺序，重复出现的共享边在集合中相消，最后取边段数。3*3的512个网格先按原题单岛/无湖合同筛选，全部213个合法网格对照。另测100*100实心岛、长条、单格与最大行列的梳齿状岛，检查输入保持；空网格为扩展。未向LeetCode提交。
