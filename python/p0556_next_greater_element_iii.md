# 556. Next Greater Element III · Python

[原题](https://leetcode.com/problems/next-greater-element-iii/)。

给定1..2^31-1的正整数N，找使用完全相同十进制数字、严格大于N的最小正整数；不存在或最小候选超过有符号32位上限时返回-1。重复数字的重数必须保持，结果不能产生前导0，返回int。

从右找第一个digits[pivot]<digits[pivot+1]的位置。其右侧原本非增，是该后缀可排列的最大形式，仅重排后缀无法变大；若整串都非增，已经是全体数字的最大排列，没有答案。否则必须提高某个位置，选最右可提高的pivot能保留最长前缀，比改动更左位置得到的结果更小。

非增后缀中，从右找到首个严格大于pivot数字的项，它就是可交换的最小更大数字。等值项不能使原数严格变大，所以比较使用<=并继续左移。交换后后缀仍非增，把它反转成非降，就把剩余数字安排成最小形式；前缀保留、pivot最小增加、后缀最小三个选择合起来得到唯一的下一字典序排列，也就是固定长度十进制整数的最小更大值。

原数首位非0。若pivot不在首位，首位不变；若pivot在首位，替换数字严格更大，也不可能为0。因此不需要用整数转换隐式丢掉前导0来修正结果。Python可先精确构造候选整数再检查<=2^31-1；等于2147483647允许，等于2147483648必须返回-1，不能只检查是否存在更大排列。

设十进制位数D，扫描、反转、连接及转换时间O(D)，字符列表与后缀切片空间O(D)。原题D最多10，不枚举D!种排列。没有修改输入数字对象。

独立参考对小输入枚举所有数字全排列，去掉前导0和不更大的排列，再取满足32位上限的最小整数，不使用pivot或后缀规则。数字0..3、长度1..6且首位1..3的全部4095个输入对照，覆盖重复数字。另测2147483476恰得到2147483647、下一候选2147483648必须拒绝、原数为上限、重复9溢出及含0案例，核对int。未向LeetCode提交。
