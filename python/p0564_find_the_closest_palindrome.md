# 564. Find the Closest Palindrome · Python

[原题](https://leetcode.com/problems/find-the-closest-palindrome/)。

输入n无前导零，表示1..10^18-1的正整数，长度1..18。返回除自身以外距离最近的回文整数的十进制字符串；距离相同选较小者。结果允许0，例如1返回0。只用整数运算，避免18位数被浮点数舍入。

同长度回文由前ceil(L/2)位唯一确定，奇数长度的中心位只出现一次。固定长度时，前缀越大，镜像后的回文也越大。因此n附近同长度回文只需尝试原前缀、前缀减1和加1：原前缀镜像若小于n，则更小前缀中最靠近的只可能是前缀减1；若大于n，同理只需前缀加1；若恰好等于n，则剔除自身并查看两侧邻居。

前缀跨位数时不能照原长度镜像，如1000的前缀减1变成9。直接跳过长度变化的前缀，另加入最大较短回文10^(L-1)-1和最小较长回文10^L+1；任何其他长度的数都比对应边界更远。L=1的较短边界为0。两位数中前缀0镜像得到的0也是真实回文，加入候选不会产生错误。候选集合删除自身，以(距离,数值)排序同时满足最近和相等时选小。

至多5个候选，每个镜像字符串长O(L)，额外空间O(L)。在本题最多19位中间整数的有界算术下，转换和构造处理O(L)个字符；不将这个界限声称为任意长度大整数运算的复杂度。输入字符串保持，返回不带前导零的str。

独立oracle逐个扫描0..200000，按正反字符串相等筛出全部回文，再二分找每个输入两侧的不同回文；逐一核对1..100000，不复用半前缀候选构造。另测各10次幂前后的跨长度结果、单字符、等距、输入本身为回文，以及18位上限和超过浮点精度的回文。未向LeetCode提交。
