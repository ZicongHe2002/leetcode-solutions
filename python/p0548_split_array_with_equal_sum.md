# 548. Split Array with Equal Sum · Python

[原题](https://leetcode.com/problems/split-array-with-equal-sum/)。

给定长1..2000的整数数组，值在-10^6..10^6，判断是否能选三个被排除的切点i<j<k，使四个非空段[0,i)、(i,j)、(j,k)、(k,N)的和完全相同。切点自身的三个值不计入任何段。至少要四个段元素和三个切点，长度小于7直接为False；输入保持，返回bool。

prefix[t]表示前t项之和。固定中间切点j后，左侧两段相等的条件是prefix[i]==prefix[j]-prefix[i+1]；把所有合法i得到的公共和放进集合。右侧枚举k，第三段和为prefix[k]-prefix[j+1]，第四段和为prefix[N]-prefix[k+1]。它们相等且公共和存在于左集合，就找到四段等和的完整方案。

j枚举3..N-4，i枚举1..j-2，k枚举j+2..N-2。这些界限同时保证每段至少一个元素，并排除三个切点。集合只保存公共和而非i，因为固定j时左右选择互不干扰，题目只问存在性，不要求返回切点或计数；相同左和的多个i无需重复保存。

任意合法切分会在其j被枚举时把左公共和加入集合，也会在其k被检查时命中，故不会漏解；任一次命中来自确有合法i的集合，四段和与下标条件同时成立，故不会误报。数组可能包含负数和0，不能假定前缀和单调或用普通正数双指针代替这些等式。

固定j后左右各线性枚举，配合哈希集合通常时间O(N^2)，辅助空间O(N)，包括前缀表和当前左和集合。没有在每个j下再枚举全部i/k组合，也不排序或改写nums。

独立参考直接枚举所有满足间隔约束的三切点，用实际切片求四段和，不用前缀表或左右集合。值-1/0/1、长度1..9的全部29523个数组对照，包含过短输入。另测2000项全0、全1不可分、1999项常量可分、负极值，以及三个大切点被排除后四段仍全0的构造，核对bool与输入保持。未向LeetCode提交。
