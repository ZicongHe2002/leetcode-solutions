# 217. Contains Duplicate · Python

[原题](https://leetcode.com/problems/contains-duplicate/)。

输入长度1..100000，整数在[-10^9,10^9]。空列表另支持为False。使用集合保存已经访问过的值；新值若已存在，就找到了两个不同下标上的同值，否则加入集合。每轮开始seen恰好是严格前缀出现的值；返回True有具体前缀见证，遍历结束仍未重复则任意后项都与此前项不同。输入顺序和内容保持。

平均时间O(n)，集合最多n个值，额外空间O(n)；存在早停不意味着最坏常数时间。测试用所有i<j下标对的相等比较作独立oracle，五值集合上长度0..6全部19531个数组；另查100000个不同值、末尾重复、值域端点和单元素。
