# 327. Count of Range Sum · Python

[原题](https://leetcode.com/problems/count-of-range-sum/)。

原题nums长1..100000，元素在有符号32位范围，-100000<=lower<=upper<=100000。统计非空连续子数组和位于闭区间[lower,upper]的数量int，答案保证适合32位整数，输入不变。

前缀p[j]-p[i]等于原数组[i,j)之和，合法区间对应i<j。递归按原前缀下标分成左右两半，先计半内，再在两半已按值排序的状态下计跨半配对。左半任何原下标均小于右半，故跨半的和仍属于合法原区间；对每个左值，两指针分别找右差首次>=lower与首次>upper的位置，差为high-low。左值递增时两个边界也单调前移，每层线性；随后线性归并，维持父层所需的有序性。时间O(n log n)，前缀、复用缓冲及切片临时量总额外空间O(n)，递归深度O(log n)。Python整数处理可能远超32位的中间前缀和。

独立参考枚举所有非空连续区间，直接逐项累加原数再比较上下界。长度1..7、值-1/0/1共3279数组，配15个小闭区间共49185次核对。另测100000长度合法低计数情形、65535个0的2147450880近上界答案，以及正负32位大值半段形成的巨大前缀。没有使用会使答案超出题目保证的100000个0且查询[0,0]，核对int与输入保持。
