# 103. Binary Tree Zigzag Level Order Traversal · Python

[原题](https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/)。

输入二叉树有0..2000节点，值在[-100,100]。逐层返回节点值，根层从左到右，之后每层方向交替；空树返回空列表，各层列表独立，原树值和左右链接不变。

队列始终按通常从左到右顺序处理各层，先固定本层节点数，再按左、右把孩子入队。仅在输出下标为奇数的层原地反序，不改变入队顺序；因此翻转一层不会影响下一层真正的左右关系。每节点访问一次，全部反序的元素总数不超过L，时间O(L)，除返回结果外额外空间O(w)，w为最大层宽。

独立oracle先用显式深度优先栈按深度收集从左到右的桶，再按深度奇偶选择输出顺序，不复用队列层边界。枚举长度0..6所有树形及二值赋值，共10067棵；检查各层对象独立以及原值和链接保持。边界覆盖2000层链、2000节点完全树、左右缺口、同值节点、值两端和空树。
