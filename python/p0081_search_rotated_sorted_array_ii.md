# 81. Search in Rotated Sorted Array II · Python

[原题](https://leetcode.com/problems/search-in-rotated-sorted-array-ii/)。

nums由非递减整数数组旋转得到，允许重复值，判断target是否存在。原题长度1..5000，元素及target为-10000..10000。本实现保持输入；额外支持空数组返回False。

闭区间[left, right]保留所有仍可能含有target的位置。先检查中点；若左右端与中点三者相等，由于中点已经不等于target，两个端点也不可能是答案，可以安全各缩一位。除此之外，旋转数组至少有一半可判为有序：左端不大于中点时检查左半的值域，否则检查右半的值域；按target是否落在该半开值域内保留对应区间，中点因已经排除不再保留。

能辨认有序半区时区间按二分缩小，但大量重复值可能只能去掉端点，例如全相同数组中寻找不存在的值。因此最坏时间O(n)，不能一概写成O(log n)；额外空间O(1)。

独立oracle使用线性成员判断。枚举长度1..8、值-1/0/1/3的494个非递减数组，对每个旋转位置查询7个合法target，共22176次比较；另覆盖5000元素、边界重复包住唯一目标、多个旋转位置、合法值域端点以及输入保持。空数组作为扩展单列。
