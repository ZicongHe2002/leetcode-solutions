# 623. Add One Row to Tree · Python

[原题](https://leetcode.com/problems/add-one-row-to-tree/)。

输入非空二叉树有1..10000节点，原值-100..100，根深度1，插入值val在-100000..100000，目标depth在1..原树高+1。depth=1时新建根，原树接到新根左侧；否则给原深度depth-1的每个节点新建左右孩子，旧左子树接到新左孩子的左侧，旧右子树接到新右孩子的右侧。新左孩子的右侧、新右孩子的左侧均空。使用平台TreeNode接口。

本实现按题意原地改变目标父节点的左右链接，返回原根；depth=1才返回新根。全部原节点继续复用，原值保持，被移接的旧左右子树内部结构保持，不复制或丢弃旧节点。即使某个旧孩子为空，也要创建该侧的新节点，不能只在已有孩子处插入。

depth>1时，frontier初始含根，经过depth-2次孩子展开后恰好是原深度depth-1的全部非空节点。只在这层完成后开始插入，防止新建节点又被当作原节点继续遍历。赋值前构造器先取出该父节点的旧孩子，把它接到新节点指定方向，再替换父链接；左右操作彼此独立。

对层数归纳可以定位全部且仅目标父节点，对每个父节点的局部连接规则直接满足题意。depth=原高+1时最后一层叶子也会各得到两个新叶子。显式层遍历可处理10000层链，不受Python递归深度限制。

若访问到目标层共V个旧节点，目标父节点数P，时间O(V+P)，最坏O(N)。frontier与下一层占O(W)辅助空间，W为访问层的最大宽度；另新增2P个输出节点，depth=1则只新增1个，不把输出分配成本遗漏。

独立参考先记录旧树每个L/R路径的值和节点身份，按目标深度把穿过插入层的旧边路径扩为重复方向，并加入新层路径，不按分层算法操作节点。1..7节点全部625种树形，两套原值、每个合法深度和正负100000插入值逐项核对；原节点值与非目标链接必须保持，目标两侧的新/旧链接逐一核对。另测10000深链底部插入与8191节点宽树变为16383节点，深链参考不存储长路径。未向LeetCode提交。
