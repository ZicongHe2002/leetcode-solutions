# 260. Single Number III · Python

[原题](https://leetcode.com/problems/single-number-iii/)。

原题nums长2..30000，值在有符号32位范围，恰有两个不同的值各出现1次，其余值各出现2次。返回两个单例，顺序不限，线性时间和常数额外空间；输入保持，不定义违背频次合同的情况。

全部异或时每对相同值抵消，combined等于两个单例a^b。因a!=b，combined非0，可用combined&-combined取出最低的不同位。按该位是否为1分组：每对重复值仍在同一组，继续异或抵消，而两个单例被分在两组。只需异或其中一组得到first，另一单例就是combined^first，不必保存第二组或排序。Python负数位运算同样遵循符号扩展语义，最低不同位提取适用于负combined；临时取反符号没有C++有符号溢出问题。

两遍扫描，按原题固定32位值域时间O(n)，除固定两项返回列表外额外空间O(1)。独立参考用Counter选频次1的两个值，按集合比较但同时检查列表恰有两项且每项为int。枚举值-1/0/1/2、长度2/4/6的全部合法数组，共1236个。另测30000最大长度、32位两端、0、负数双单例及符号位分组，核对输入保持。
