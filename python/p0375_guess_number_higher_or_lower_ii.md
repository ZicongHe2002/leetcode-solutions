# 375. Guess Number Higher or Lower II · Python

[原题](https://leetcode.com/problems/guess-number-higher-or-lower-ii/)。

原题1<=n<=200，秘密数在1..n。猜错x要支付x并得知目标更高或更低，猜对不用付费；求无论目标为何都保证获胜的最少资金，属于最小化最坏费用，不能只优化猜测次数。

cost[left][right]为目标仍在闭区间时的最小保证费用。若只剩一个数，直接猜对，费用0。区间至少两数时先猜guess，最坏会落入左或右子区间；错误支付guess，再承担两侧较大的最优费用。因此枚举guess，取guess+max(左费用,右费用)的最小值。猜对分支费用0不会超过错误分支，不需再收一次guess费用。

空区间也用0，二维表两侧补一圈处理边界。按候选数递增计算，左右区间更短且已完成。时间O(n³)，额外空间O(n²)。n=1返回0，而非1。

独立oracle枚举所有由1..n有序键组成的比较决策树，对每棵树直接计算猜错分支的最大沿路费用，正确命中该节点的分支为0，再从全部策略中取最小。n=1..8共2055棵策略树核对，不复用数值区间DP。另检查n=1/2/3/10及最大n=200固定结果952，核对int与同一实例多次查询。
