# 68. Text Justification · Python

[原题](https://leetcode.com/problems/text-justification/)。

原题1..300个非空单词，每词长1..20且不含空格，maxWidth在1..100，保证每词放得下一行。按原顺序尽量装满每行，所有行恰为maxWidth字符；普通多词行的空隙尽量均分，多出的空格优先给左边。最后一行和单词独占行左对齐，词间一格，剩余空格补右端。输入words保持。

从start向后试装，letters是已选单词字符总数，加入words[end]需要额外end-start个最少分隔空格。条件允许就继续，首次放不下确定本行最大词数。普通多词行把maxWidth-letters个空格分到slots个缝，商为每缝基础空格数，余数决定前几个缝各多一个。

末行或无缝行不能做除零分配，直接单空格连接再补右端。单词本身保证可放下，因此每轮至少消耗一个词，不会卡住。设输入总字符S、输出总字符T，时间O(S+T)，除输出外临时空间O(maxWidth)。

独立验证直接核对布局合同：每行精确宽度、去空格后的词序完全等于输入、任何非末行再加下一词都放不下；普通行的空隙为正、从左到右不增且最大最小差至多1，末行/单词行按单空格左对齐。三种含标点单词、长度1..6的1092个输入，各测宽3..8，共6552组；最大300词、宽100、词长20及样例也检查，验证输入保持。
