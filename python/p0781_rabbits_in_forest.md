# 781. Rabbits in Forest · Python

[原题](https://leetcode.com/problems/rabbits-in-forest/)。

原题1..1000只受访兔子，每个回答0..999表示另有多少只兔子与自己同色，未受访兔子也可能存在。求与全部回答一致的森林兔子总数最小值，输入保持。

回答v意味着完整同色组恰有v+1只，不同回答不能归到同一种颜色。把相同回答的受访者数记为c，每种颜色最多容纳v+1名受访者，因此至少需要ceil(c/(v+1))种颜色。把前面的组填满、最后一组用未受访兔子补足即可达到此下界，贡献ceil(c/(v+1))*(v+1)。各回答类别互不共享颜色，分别取最小后相加就是全局最小。

正整数向上整除写成(c+v)//(v+1)，不经浮点。回答0时每只兔子独占一种颜色，贡献c；同一个非零回答出现超过组容量时必须开新颜色，不是只看不同回答数量，也不是只返回受访者数。

Counter期望时间O(n)，后续访问每种回答一次，额外空间O(U)，U是不同回答数且不超过1000。结果为int，原数组不排序、不修改。

独立oracle按受访者逐个枚举实际集合分区：一个颜色块只接收同回答的兔子且人数不超过其完整颜色容量，每个完整候选按所有块容量之和计入未受访兔子，取最小值。不用Counter或ceil公式。回答0/1/2、长度1..7全部3279数组核对。另核对官方例、1000受访者、999最大回答、容量恰好填满/超一只、全部互异回答和输入保持。未向LeetCode提交。
