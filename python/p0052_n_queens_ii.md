# 52. N-Queens II · Python

[原题](https://leetcode.com/problems/n-queens-ii/)。

原题1<=n<=9，只返回n皇后合法放法数量，皇后不可同列或同对角线。实现直接累计计数，不构造棋盘结果。

columns表示已经占用的列，falling和rising表示当前行被两类对角线威胁的列。available先合并三类禁用位再取反，并与full相交，限制到n个棋盘列；每次取最低可用位，下一行把对角威胁分别左移和右移。左移后也与full相交。每层恰放一枚且列不重复，所以columns==full时恰好完成n行并贡献1；无可用位自然贡献0。最坏搜索O(n!)，n位掩码在原题范围内为常数大小整数，递归辅助空间O(n)。

独立oracle枚举列排列，用所有行对的列差绝对值直接检查对角线，不复用位掩码或递归。n=1..9共409113个列排列全部比较计数，另核对1/2/3/4的边界与同一实例重复调用8、1、8，返回int。没有用另一题的棋盘实现作为期望来源。
