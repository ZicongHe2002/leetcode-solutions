# 373. Find K Pairs with Smallest Sums · Python

[原题](https://leetcode.com/problems/find-k-pairs-with-smallest-sums/)。

原题两个非递减数组长度各1..100000，元素-10**9..10**9，1<=k<=10000且k不超过两个长度乘积。每个下标组合贡献一对值，重复值仍有各自的出现次数；返回和最小的k对，答案顺序不限，两个输入保持。

固定nums1的一个下标为一行，按nums2下标增加时该行的和非递减。堆为每个候选行保存最前面尚未输出的一项，弹出最小项后只推进其所在行，等价于多路有序归并。只需前min(k,len(nums1))行：若行下标至少k，它的首项之前已有前k行的k个首项不更大，因此无需依赖这一行也能选出k个最小项；相等时选择任意一组并列项均合法。

每行在堆内至多一项，令h=min(k,len(nums1))，建堆O(h)，输出O(k log(h+1))，辅助空间O(h)，另需O(k)输出。原题k不超过总配对数，候选行也提供至少k项，所以循环不会提前取空堆。

独立oracle枚举完整笛卡尔积并排序所有和，核对输出的前k小和以及每个值对的多重性，不限制并列和的具体选择或输出顺序。3种值构成长度1..4的34种有序数组，两两组合1156种；逐个查询k=1..min(10,配对数)，共9075次。边界覆盖各100000长度、k=10000、仅一行或一列、重复值和极端值，核对两个输入保持。
