# 446. Arithmetic Slices II - Subsequence · Python

[原题](https://leetcode.com/problems/arithmetic-slices-ii-subsequence/)。

原题nums长1..1000，元素在-2^31..2^31-1，统计长度至少3的等差子序列。下标顺序必须保持，但可以跳过元素；重复值的不同下标选择分别计数，零差也合法。题目保证答案在32位整数范围，返回int，输入不变。

ending[i][d]保存末下标为i、公差d、长度至少2的子序列数。对每个left<right，已有ending[left][d]条序列可接nums[right]，变成长度至少3并计入答案；同时新下标对(left,right)提供一条长度2状态，故更新量为extended+1。每条长度至少3序列由最后两下标唯一确定其本次扩展，不重计；长度2只作未来扩展的种子，不直接加到答案。枚举全部下标对，平均字典操作下时间O(n^2)，额外空间O(n^2)。Python整数差能表达跨有符号32位端点的4294967295，不截断差值。

独立参考枚举所有下标保留子集，长度至少3时直接检查选出元素的相邻差，不使用按公差计数的DP。长度1..7、值-1/0/1的3279个数组全覆盖。另测1000个互异连续值及倒序，按首下标和固定下标步长枚举合法长度求参考；31个相同值的答案2147483151仍满足32位保证，不使用会超出该保证的1000个同值数组。还覆盖32位端点差，核对int与输入保持。
