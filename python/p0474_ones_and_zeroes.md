# 474. Ones and Zeroes · Python

[原题](https://leetcode.com/problems/ones-and-zeroes/)。

从二进制字符串列表选择最多条目，使使用的0至多m个、1至多n个。每个下标至多选择一次，内容相同的多个条目仍可分别选择。原题1..600个字符串，每串长1..100，只含0/1，m和n均1..100。输入保持；空列表或预算0为额外支持，预算仍须非负。

best[z][o]表示处理过的条目中，在两个预算上限z/o内最多能选择几项，初始化0代表全不选。当前字符串成本为zeros和ones；不选保留旧值，选一次则从扣除两种成本后的状态加1。这个状态表示至多而非恰好耗尽预算，最后读取best[m][n]。

两个预算都倒序遍历，保证转移来源仍属于加入本条目之前。纯0或纯1字符串某一种成本为0，但另一种成本必为正；对应的下降维度仍能防止本条目在同一轮被再次使用。不能只把一种预算改成升序，否则可能变成可重复选择的完全背包。双层列表逐行创建，避免共享同一个行对象。

对K个条目计数字符需O(sum L_i)，DP最坏O(K*m*n)，预算可为0时更统一的上界为O(sum L_i+K*(m+1)*(n+1))。辅助空间O((m+1)*(n+1))，无需保存K层状态，不排序或改写输入。

独立参考枚举全部下标子集，直接累计选中条目的0/1用量，再求满足两预算的最大条目数，不使用预算DP。5种短串、条目数0..4的781个列表，各查m/n=0..3的16种预算，共12496次对照；空列表/0预算为扩展。另测600条、100字符条目、两预算100、纯单字母和重复条目，检查输入保持。未向LeetCode提交。
