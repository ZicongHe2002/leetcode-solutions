# 457. Circular Array Loop · Python

[原题](https://leetcode.com/problems/circular-array-loop/)。

每个数组位置按其非零数值向前或向后跳，取模回到环内，判断是否存在长度大于1、全部跳步同正负方向的环。原题长度1..5000，元素-1000..1000且不为0。本实现为满足O(n)时间/O(1)辅助空间，会把已经排除的位置改写为0，不保证输入保持；空数组额外返回False。

对每个尚未排除的起点固定方向，使用快慢指针。advance拒绝已标记0、方向不符与一步回到自身的单节点环，其余跳转用Python正模数得到合法下标。两指针在同一方向的有效链上相遇，才说明存在至少两节点的环；遇到无效跳转则本起点不能得到合法环。

失败后沿同方向链把访问位置标0，只在写0之前保存下一下标；到不同方向、旧标记或自己刚写的0就停止。被标位置的确定性后继链已经证实不能进入同向合法环，后续起点无需再搜索；不会跨过方向边界误删另一种方向的潜在环。

一次失败搜索的快慢步数与随后清理的未标链长同阶，每个位置最多被清理一次；成功时直接返回，所以总时间O(n)。只有固定数量下标和方向变量，辅助空间O(1)，没有每个起点新建访问集合。输入改写是算法状态的一部分，调用者需要原数据时应自行保留副本。
