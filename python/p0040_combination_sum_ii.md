# 40. Combination Sum II · Python

[原题](https://leetcode.com/problems/combination-sum-ii/)。

候选有1..100个，值在[1,50]且可重复，target在[1,30]。每个输入位置最多使用一次，返回和为target的不同组合，不能重复。本实现复制排序且保留输入，组合非递减、各行独立；额外支持空候选与0目标。

选择index后递归到index+1，保证同一个位置不会重用。同一递归层中，若index>start且值等于前一项，就跳过这一分支：选后一个相等值作为本层首选会重复选前一个值已经能产生的组合。进入下一层时index=start，不跳过相等值，因此允许从多个不同位置选出多个相同值。排序和正数让value>remaining时可以break；remaining=0保存副本并返回。每个合法值多重集都由最靠前的可用相同位置唯一代表，故跳过同层重复不损失合法组合。

设n为候选数，递归深度最多n，递增下标的路径数上界2^n；加上节点扫描及结果复制，使用保守时间上界O(n log n+n·2^n)，不计结果空间O(n)，包含排序副本、path和递归。正数剪枝常会显著减少实际搜索，但不把它当成多项式保证。

独立oracle枚举全部输入下标子集，计算和后只对期望的值元组去重；实际结果仍按完整列表比较，可发现重复输出。枚举1..4上长度1..6的全部209个非递减多重集，交替反转输入，对target=1..12共2508组查询。边界覆盖100个1取30次、100个50无解、经典混合重复例子、空候选与0目标扩展；检查输入和结果行身份。
