# 719. Find K-th Smallest Pair Distance · Python

[原题](https://leetcode.com/problems/find-k-th-smallest-pair-distance/)。

原题nums长度2..10000，每项0..10^6，k在1..n(n-1)/2。对全部原下标i<j的绝对差排序，返回第k小；重复值的不同下标对必须分别计数，不能把距离集合去重。输入保持，返回int。

先排序一份副本。给定候选距离d，用双指针统计差不超过d的下标对：对每个右端right，把left右移到ordered[right]-ordered[left]<=d，当前所有合法左下标恰为left..right-1，因此贡献right-left。相等值自然贡献零距离对，每一对只由自己的右端计一次。

计数随d不下降。答案是使计数至少k的最小整数距离，二分范围从0到最大值减最小值；若中点计数已经达到k，保留它并收缩右端，否则中点及更小值都不足，左端移到中点+1。即使计数跳过k也不能要求恰等于k，因为相同距离可出现多次。收敛时得到这个最小可行距离。

排序O(n log n)，每次双指针计数O(n)，总时间O(n log n+n log(D+1))，D为最大差，额外空间O(n)含排序副本。D=0时无二分转移直接返回0，仍有构造副本成本；不产生全部O(n²)距离。

独立oracle枚举每个原下标对，计算绝对差并完整排序，不使用距离阈值计数。值0/1/3、长度2..7共3276个数组，全部合法k共59868次排名核对，另核对200个固定种子样本。10000元素边界覆盖全部零、5000零/5000百万形成的大块重复排名、等差数列用闭式阈值计数给出最早与最后排名证书，核对int与输入保持。未向LeetCode提交。
