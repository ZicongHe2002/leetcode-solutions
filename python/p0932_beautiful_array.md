# 932. Beautiful Array · Python

[原题](https://leetcode.com/problems/beautiful-array/)。

从[1]开始，先把已有排列映射为2x-1的奇数块，再映射为2x的偶数块，只保留不超过n的值。仿射变换保持块内不存在中项两倍等于两端之和的性质；两端来自不同奇偶块时和为奇数，不可能等于某整数的两倍。两端同块时，下标在它们之间的中项也在同一连续块，归入块内性质。最终覆盖1..n各一次，构造所求排列。

每轮规模近翻倍，总构造时间O(n)，额外空间O(n)，不枚举排列。
