# 6. Zigzag Conversion · Python

[原题](https://leetcode.com/problems/zigzag-conversion/)。

原题s长1..1000，含大小写英文字母、逗号和句点，numRows在1..1000。字符沿行号从上到下、再斜回顶部反复放置，最终逐行连接，字符自身不改写。单行或行数不少于字符数时输出原串。

每个行缓冲只收集落在该行的字符，row和direction描述下一个落点。当前到顶行时方向设为+1，到底行时设为-1，其他行保持方向，写入后再移动row。边界先特殊处理，保证多行折返时不会产生越界行号。

每字符恰写入一次并在结果中恰出现一次；在非提前返回分支行数小于字符数，时间O(|s|)，额外空间O(|s|)。不需要构造含空白的二维可视化棋盘。

独立oracle用下标对周期2*numRows-2取模，再按三角波公式直接算落行，不复用方向状态。四种合法字符、长度1..6共5460串，各测行数1..7，共38220查询。最大1000字符与1/2/3/999/1000行、单字符高行数及固定样例核对，检查str与输出字符数保持。
