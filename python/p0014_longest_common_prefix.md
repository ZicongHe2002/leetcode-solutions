# 14. Longest Common Prefix · Python

[原题](https://leetcode.com/problems/longest-common-prefix/)。

原题输入1..200个字符串，每个长0..200，非空时仅含小写英文字母。返回所有字符串共有的最长前缀，没有共同首字符则返回空串，输入列表和内容保持。本实现额外支持空列表返回空串。

依次检查首字符串的每个位置。只要任意字符串已到末尾或该位置字符不同，之前的位置就是完整公共前缀，当前位置不可能再延伸。若首串全部通过，它自身就是答案。设字符串数为k，首串长度为L，时间上界O(k·(L+1))，除返回切片外额外空间O(1)；不排序、不反复拼接候选前缀。

独立oracle枚举每个小串的全部前缀集合，取交集中最长者，不复用逐列扫描。对二字母长度0..3的15个串，枚举列表长度1..3的全部3615个有序列表，并核对输入保持。边界覆盖200字符串、200字符、仅末位不同、列表中空串、单串与空列表扩展。
