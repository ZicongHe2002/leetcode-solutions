# 406. Queue Reconstruction by Height · Python

[原题](https://leetcode.com/problems/queue-reconstruction-by-height/)。

原题people长1..2000，每项[h,k]，h在0..10^6，k在0..n-1，表示前方恰有k个身高>=h的人，保证存在合法队列。返回重建的二维列表，保持输入及原行内容，新建输出行；不额外定义不可重建输入。

先按身高降序、同高按k升序处理。插入某人时，队列已有的人全不矮于他，直接放在下标k就保证前方恰有k个符合者。之后插入的较矮者不会影响已放人的计数；同高者按k递增插入，不会插到此前同高者前方而破坏其k。这个不变量逐人保持，最终每个约束都满足。排序O(n log n)，列表插入最坏O(n^2)，总时间O(n^2)，保存排序及新队列空间O(n)。

测试从原始高度队列计算每人的k，反向打乱成合法输入，独立按输出的每个位置直接数前方>=h者，不复用排序插入算法。值0/1/2、长度1..6的1092个高度队列全部覆盖；另测2000人、同高、不同高全k=0及10^6上界，核对输出行多重集合和输入保持。
