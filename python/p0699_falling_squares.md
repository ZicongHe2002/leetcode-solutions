# 699. Falling Squares · Python

[原题](https://leetcode.com/problems/falling-squares/)。

原题依次落下1..1000个正方形，每个由左坐标1..10^8与边长1..10^6给出。方块从足够高处竖直下落、不能倾斜，接触已有方块顶面或地面时停止。仅左右边相擦不形成支撑。每步返回全局最高高度，不能只返回新落方块高度。输入及每行保持。

用半开水平区间[left,left+side)记录每个已落方块，以及它的顶面高度top。新区间与旧区间只有在left<oldRight且oldLeft<right时才有正宽重叠；等号对应只碰边，必须排除。新区间底面要在所有重叠旧方块之上，因此支撑高度base为这些旧顶面的最大值，无重叠则为地面0，新顶面是base+side。

方块水平放置且冻结，下降时第一次被挡住的位置就是上述最大顶面。即使旧顶面某段后来被覆盖，覆盖它的更新方块顶面更高，也会参与相应水平重叠的最大值，所以保留历史方块不会虚构更高支撑。更新全局tallest后追加结果，输出自然不下降。

第i个方块扫描前i-1个方块，总时间O(n²)，额外空间O(n)包含历史与返回数组；原题最多1000个，算法没有声称进阶O(n log n)。不按巨大坐标范围分配数组，整数运算覆盖累计10^9高度。

独立oracle在整数坐标的单位宽柱上维护真实上表面：每次扫描新区间每个单位格的最高柱，再将覆盖柱全改为新顶面，不保存历史区间碰撞列表。左坐标1..4、边长1..3共12种方块，长度1..4的全部22620个序列核对完整逐步结果，另核对200个固定种子序列。1000方块边界覆盖同位叠高10^9、相邻只碰边、10^8坐标以及一格正宽交叠，核对行身份和值保持。未向LeetCode提交。
