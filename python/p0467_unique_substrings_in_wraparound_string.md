# 467. Unique Substrings in Wraparound String · Python

[原题](https://leetcode.com/problems/unique-substrings-in-wraparound-string/)。

无限循环字母串为...zabcdefghijklmnopqrstuvwxyzabc...，求输入s中同时出现在该无限串内的不同非空连续子串数量。原题s长1..100000且全为小写英文字母；空串额外返回0。不同出现位置的相同内容只计一次，子序列不属于这里的连续子串。

run记录以当前字符结束、相邻字母都沿循环字母表前进一位的最长后缀长度。相邻字符编号之差模26为1时续接，否则从当前字符重新计1；z到a因此能续接，a到z不能。第一个字符必须重新开始，不能把初始化的previous当成真实字母。

对于固定的末尾字母和长度，满足循环相邻关系的子串内容唯一：向前逐位倒推即可确定。若某个以字母c结束的合法后缀长度为L，它的长度1..L后缀全部存在；在所有位置只保存同一末尾字母的最大L，就覆盖了这一类全部内容且不重复。不同末尾字母属于不同内容，因此把26个最大长度相加就是答案，无需保存实际子串或按出现次数相加。

每个字符只更新一次run与一个表项，时间O(n)；longest固定26项，其余状态为整数，辅助空间O(26)=O(1)。输入不变，不构造无限串。答案可超过输入长度，Python整数精确表示。

独立参考枚举输入的全部实际切片，用显式后继字典验证每一对相邻字母，放入集合后取大小，不使用最长后缀表或模运算。a/b/z、长度0..8全部9841个字符串对照，空串为扩展。另测100000字符完整循环、同字母、za重复断点、zab与整轮字母，最大循环答案由各末字母可用长度的等差和得到2599675。未向LeetCode提交。
