# 372. Super Pow · Python

[原题](https://leetcode.com/problems/super-pow/)。

计算a的巨大十进制指数次幂模1337，指数b以从高到低的数字数组表示。原题a在1..2^31-1，b长1..2000，每项0..9且无多余前导0。本实现不将完整b转换为整数，不修改数组；对b=[0]按零指数返回1。

已经读取的指数前缀若为E，追加数字d后新指数为10E+d。由a^(10E+d)=(a^E)^10*a^d，当前结果只需十次方、乘本位小次幂再取模。模乘与模幂在整数模环中成立，不要求a与1337互质，因此a是7或191的倍数也正确；不能直接套用只在互质条件下成立的指数周期化简。

result初始为a^0模1337，即1。每轮按上述等式更新，归纳得到整个指数的正确余数。读取0仍须把前缀乘10，不能跳过该数字。先将a取模，后续所有参与运算的底数和结果都受模数限制。

设m为数字个数，pow的指数最多10、模数固定1337，每个数字的工作有固定上界，时间O(m)，额外空间O(1)。没有递归拆分b、pop修改数组或复制整段指数。

独立小参考直接将a重复模乘e次，a取1/2/7/191/1337/2^31-1，e为0..500共3006项查询。另对2000位指数在测试端构造大整数并调用完整指数pow(a,e,1337)核对，生产代码不整串转整数；包括非互质底数、内部0、最大a与输入保持。未向LeetCode提交。
