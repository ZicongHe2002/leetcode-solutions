# 547. Number of Provinces · Python

[原题](https://leetcode.com/problems/number-of-provinces/)。

输入是1..200阶的0/1对称邻接矩阵，对角线为1，城市间可以通过多条直接连接间接相连。返回无向连通分量数，不能只数矩阵里的1或仅看直接邻居。原矩阵内容及各行对象保持；额外支持空矩阵返回0。

每次遇到未访问城市，开始一个新省份并用显式栈完整访问该连通分量。邻居发现时立刻标记，避免多个父城市重复入栈；直接相连或通过已有路径可达的城市都会被标记。遍历完该分量后，后续未访问城市必属于另一个分量。每个城市只出栈一次并扫描整行，时间O(n²)，额外空间O(n)，不用递归、不修改矩阵。

独立oracle对矩阵执行布尔传递闭包，再计算不同可达行的数量；无向图同一分量的闭包行相同，不复用栈访问。枚举1..5城市全部1099个对称矩阵，逐次核对返回int及矩阵行身份/内容保持。边界覆盖200城市全孤立、全部直连、仅链式间接连接、四个50城市分组和空矩阵扩展。
