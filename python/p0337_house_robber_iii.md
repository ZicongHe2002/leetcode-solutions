# 337. House Robber III · Python

[原题](https://leetcode.com/problems/house-robber-iii/)。

房屋按二叉树连接，不能同时选择直接父子两个房屋，求可选房值总和的最大值。原题至多10000节点，房值0..10000；可以有相同房值。本实现不修改树的值或链接，额外支持空树返回0。

每个节点保存(skip,take)两种最优值。take包含当前房屋，因此两个孩子都必须使用skip；skip不包含当前房屋，每个孩子都可以独立选择自己的两种状态中较大者。两个孩子子树之间没有直接父子边，所以在满足与根的约束后可以相加。每个合法方案要么选当前节点、要么不选，两个状态覆盖全部可能，并由叶到根归纳得到全局最优。

用显式后序栈保存(node,ready)：首次遇到先安排自身回访，再处理孩子；回访时两个孩子状态已存在。状态字典以节点身份id为键，不按房值合并，重复房值不会覆盖不同节点。空孩子的两种收益均为0，缺失非空孩子状态则不会被默认0掩盖。

每个节点进出栈固定次数，总时间O(n)。状态字典O(n)，控制栈O(d)，d为树高，因此总额外空间O(n)，没有把字典藏在O(d)结论内。生产不递归，也不将DP结果写回node.val，所以10000节点深链仍保持原树数据。

独立oracle枚举小树的全部房屋子集，直接排除含父子边两端的子集并统计权重，不复用生产take/skip递推。0..5节点全部树形与0/1/2值标号共11497棵核对，并检查树对象、值和链接保持。另测固定祖孙选择、10000节点左右深链及最大房值，重复调用不会共享旧状态。
