# 228. Summary Ranges · Python

[原题](https://leetcode.com/problems/summary-ranges/)。

输入严格递增且无重复的整数列表，返回覆盖相同整数的最少有序区间字符串。单值写成a，多值连续区间写成a->b，不修改输入。空列表是原题合法输入，返回空列表；不对未排序或重复输入另行归一化。

从每个尚未消费的位置开始，只有下一值恰好等于当前值加1才继续扩展。第一次出现缺口或到达末尾时输出当前整段，再从下一位置开始。这样的段包含了每个可连续合并的相邻值，因此不能再与前后段合并；任何精确覆盖输入的区间划分也不能跨越缺失整数，故段数最少。

虽然使用嵌套while，index在整次调用中只递增，累计访问每个元素一次。设输出文本总字符数为T，时间O(n+T)，返回结果占O(T)空间；不计返回结果时只用常数个局部变量。原题值在32位有符号整数内，Python计算当前值加1不会因最大端点溢出，也不会在输出中加入输入未包含的额外端点。

测试不复用连续扫描作为oracle，而检查规范输出合同：解析结果后按顺序展开必须精确等于输入；单值不得写成重复端点区间；两个相邻输出区间之间必须至少缺一个整数。这些条件共同唯一确定最少区间表示。穷举-5..5全部2048个子集，另测空列表、负区间、32位端点和20项连续序列，并核对输入保持。
