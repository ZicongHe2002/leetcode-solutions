# 132. Palindrome Partitioning II · Python

[原题](https://leetcode.com/problems/palindrome-partitioning-ii/)。

原题s为1..2000个小写字母，切成若干连续回文子串，求最少切刀数；整个串已是回文时返回0。实现额外定义空串的切刀数为0。

cuts[end]表示前end个字符的最少切刀数，初始按每字符单独一段赋值end-1，空前缀设为-1。按中心右侧下标center递增，每轮从(center,center)和(center-1,center)扩展奇数与偶数回文；每找到s[left:right+1]回文，就用cuts[left]+1更新cuts[right+1]。空前缀为-1让整段回文直接得到0刀，不需要单独修改首段递推。

在处理某个中心时，left不大于该中心，cuts[left]依赖的所有回文都结束在left之前，其中心也更靠左，已经全部处理，所以来源状态已最终确定。每个回文都有唯一奇/偶中心并会被扩展一次；枚举所有可能的最后回文段即可得到每个前缀的最优值。时间O(n*n)，辅助空间O(n)，不用保存二维回文表。

独立oracle枚举所有切点子集，把得到的每段直接反转比较，选择最少切刀，不做中心扩展或前缀动态规划。3种字母、长度1..7的3279个串核对。边界覆盖2000长度、全相同、交替串、完全无长度2/3回文的abc循环、长偶数回文；空串为扩展。核对int返回。
