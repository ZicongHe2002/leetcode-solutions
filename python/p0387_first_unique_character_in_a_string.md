# 387. First Unique Character in a String · Python

[原题](https://leetcode.com/problems/first-unique-character-in-a-string/)。

原题s长1..100000，只含小写英文字母，返回最早出现且全文仅出现一次的字符下标，无此字符返回-1。返回int，下标从0开始，不重排或改写字符串。

先完整计数，避免把尚未遇到第二次的字符误当唯一；再按原下标顺序扫描，第一个计数1的字符既是唯一也是最早。所有字符计数都不是1时返回-1。两遍线性扫描，时间O(n)，26字母固定范围下额外空间O(1)。

独立参考在每个候选下标直接调用s.count检查全文频次，选择首个通过者，不复用缓存频次表。字母a/b/c、长度1..8共9840个字符串全部核对；另测100000长度，唯一字符在头/尾、完全无唯一和较短混合样本，核对int。
