# 482. License Key Formatting · Python

[原题](https://leetcode.com/problems/license-key-formatting/)。

原题s长1..100000，仅英文字母、数字和短横线，k在1..10000。去掉原有短横线并转大写，从右端按k个字符分组；只有第一组可短于k，组间用一个短横线连接。合同未排除全短横线输入，此时返回空字符串。

设cleaned长度为m，第一组长度取m%k，余数0时取k。其后所有组长度恰为k，且拼接组内容还原cleaned，因而同时满足字符次序和从右对齐的要求。全短横线先返回，不产生空的首组或尾组。

清理、切片分组和连接各处理O(n)个字符，时间O(n)，额外空间O(n)，返回字符串也为O(n)。只支持合同内ASCII英文字母和数字，不用Unicode大小写扩展推断额外行为。

独立oracle从右向左逐字符累积，达到k时插入分隔符，最后反转，而非复用首组余数分法。a/B/1/-长度1..6的5460个串，各测k1..5共27300次。另测100000长度、k=1/10000、全短横线、固定示例及不整除首组，检查str、组大小、无多余短横线和字符还原。
