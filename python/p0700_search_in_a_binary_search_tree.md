# 700. Search in a Binary Search Tree · Python

[原题](https://leetcode.com/problems/search-in-a-binary-search-tree/)。

原题root为1..5000节点的合法二叉搜索树，节点值与查询val均在1..10^7。返回值等于val的节点所根植的原子树，不存在时返回None。TreeNode由平台提供，不创建等值副本、不只返回布尔值，也不修改任何原节点。

若当前值等于目标，当前节点本身就是所需子树根，直接返回它。若目标更小，BST有序性保证当前节点及整个右子树均不可能匹配，只沿左孩子继续；目标更大时对称地沿右孩子。每步保留所有仍可能包含目标的位置，走到空指针说明整条候选路径已穷尽，返回None。

循环只重新绑定局部root变量，没有改写节点字段，因此找到节点的所有孩子和后代都保持原结构和身份。时间O(h)，h为树高，平衡树O(log n)、退化树最坏O(n)；额外空间O(1)，不假设输入平衡，也不依赖Python递归深度。

独立oracle遍历全树收集节点，再按值完整扫描，不利用BST方向。五个候选值1/2/4/8/16的所有非空BST共187棵，对合法查询1..18共3366次核对返回对象身份；每次同时保存并检查所有值和左右孩子身份。另核对5000节点左/右链的首中尾命中、缺失值与10^7边界。未向LeetCode提交。
