# 44. Wildcard Matching · Python

[原题](https://leetcode.com/problems/wildcard-matching/)。

原题s/p长度0..2000，s只含小写字母，p可含小写字母、问号和星号。问号匹配一个字符，星号可独立匹配任意长度的串，包括空串；必须全匹配。连续星号合法，不按正则表达式的前字符重复规则解释。

previous[j]记录已处理字符串前缀是否由模式前j位匹配。问号或相同字母从previous[j-1]转移。星号可以不消耗字符，读取当前行current[j-1]，也可以再消耗当前字符并继续使用同一个星号，读取previous[j]。两者取或就包含星号所有长度选择。

空s只与全由星号组成的模式前缀匹配，所以初始化从左向右连续传播；空p仅能匹配空s。每轮仅存前一行和当前行，时间O((m+1)*(n+1))，辅助空间O(n+1)。

独立oracle调用fnmatch.fnmatchcase；测试模式只用a/b/问号/星号，与本题字符集和语义一致，不包含方括号等其他glob语法。0..5长的1365个模式与63个字符串配对，共85995次原题合法查询。边界覆盖2000长度、全星号、重复星号加字母、空串和错误末字符，核对bool。
