# 616. Add Bold Tag in String · Python

[原题](https://leetcode.com/problems/add-bold-tag-in-string/)。

s长1..1000，words有0..100个互异非空词，每词最多1000字符，均只含英文字母和数字。把s中匹配任一词的全部子串用`<b>`和`</b>`包围；重叠或直接相邻的覆盖区域必须合并成一对标签。大小写区分，不是只处理第一次出现的词。输入字符串和词列表保持，源字符不变，只插入标签。

先将词放入前缀树，字符边指向下一字典，None键只标记某个完整词结束；None不会与合法的单字符边冲突。从s的每个start沿字符边前进，记录遇到的最远词结束位置longest。同一起点的全部匹配互相嵌套，最远者覆盖所有较短者，所以只需记录[start,longest)一个区间，不会丢失任何应加粗字符。

对每个区间在delta[start]加1、delta[longest]减1，随后前缀和active表示当前字符被多少匹配覆盖。只在覆盖状态由假变真时输出开始标签，由真变假时输出结束标签，最后若仍在粗体中就补结束标签。相邻区间在同一边界结束和开始，该位置的净覆盖不会形成空白字符，因此保持同一对标签；重叠区间也只看active是否正，不会嵌套重复加标签。

每个匹配都从某个start被完整词结束标记识别；各start的最远区间并集与全部匹配并集相同，差分正确还原这个并集，输出状态转换正好产生最大连续覆盖段。因此得到所有且仅应加粗的位置，并满足合并重叠和相邻的要求。

设词字符总量为W，s长N，最长词长L。前缀树构建O(W)，逐起点最多走min(N,L)条字符边，渲染O(N)，平均哈希模型下总O(W+N*min(N,L)+N)。前缀树、差分及输出片段额外空间O(W+N)。无需用每个匹配长度逐字符重涂，也不分配N×词数矩阵。

独立oracle枚举s的全部子串检查词表，保存所有匹配区间，排序并直接合并重叠/相邻区间后拼接，不使用前缀树或差分。二字母、s长1..7的254个串与6个长度1/2词的64种词子集，共16256组。另测1000字符、100词、1000长词、全覆盖、多次重叠、相邻、空词表、大小写及数字和样例，核对词列表保持。原题明确与758同题，本贡献只发布616，不另以758重复交付。未向LeetCode提交。
