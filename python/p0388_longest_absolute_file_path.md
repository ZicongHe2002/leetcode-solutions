# 388. Longest Absolute File Path · Python

[原题](https://leetcode.com/problems/longest-absolute-file-path/)。

输入用换行分隔文件系统条目，行首制表符个数表示深度，名字含点的条目为文件，求最长文件绝对路径长度，路径分隔符/也计数。原题输入长1..10000，保证表示合法文件系统，文件不能作为父目录；目录名不含点。名字中的空格是字符，不按空格判断缩进。没有文件时返回0，空串额外返回0。

prefixes[d]保存当前深度d条目之前的父路径长度，已包含连接当前名字所需的/，根层前缀为0。读完目录名后，给下一层写入prefixes[d]+目录名长度+1；读完文件名只计算完整长度并更新best。回到同级或更浅目录后，覆盖对应下一层前缀，防止沿用前一个兄弟目录的路径。

合法深度保证使用某层前缀前，其父目录已经出现；先前保存的更深数据可以暂留，但在重新进入该层前会被新父目录覆盖。文件不写入父前缀，因此没有把文件当目录继续拼接。最长目录本身不作为结果，必须真正见到文件才更新。

直接用下标扫描制表符、名字和换行，不调用split、不构造名字切片或完整路径。每个字符访问固定次数，时间O(n)，前缀数组最多保存最大深度d+1个长度，额外空间O(d)。名字很长也只保存长度，不占用同样长的临时路径字符串。

独立参考从结构化目录树生成文本，同时递归拼出每个文件的真实路径求最大长度，不使用生产文本解析或长度前缀。五个孩子分别选择空目录/文件/带文件子目录，全部243种布局对照，名字含空格且长度不同。另测根文件、多根条目、同级前缀覆盖、没有文件、恰好10000字符的深层输入与单个长文件名；空串为扩展。未向LeetCode提交。
