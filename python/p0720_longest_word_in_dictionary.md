# 720. Longest Word in Dictionary · Python

[原题](https://leetcode.com/problems/longest-word-in-dictionary/)。

原题words含1..1000个小写词，词长1..30。要求从左到右每次在末尾追加一个字母构造候选，所有非空中间前缀都必须在词典中。返回最长可构造词，并列取字典序最小者，无答案返回空串。只有后缀存在或缺少某个中间前缀都不够。输入词表顺序保持，返回str。

按字典序排序一份词表，buildable初始只含空前缀。一个词的直接前缀word[:-1]若可构造，该词才可加入集合；它本身也来自词典，所以新增一步有效。单字符词直接接在空前缀之后。如果直接前缀不可构造，即使它出现在词典中，也不能跳过其更短的缺失前缀。

严格前缀在字典序中总先于原词，因此处理某词时，它的直接前缀若确实可构造就已经处理并加入集合。归纳可知集合既不包含非法词，也不漏掉任何合法词。词按字典序递增扫描，只在长度严格增大时更新best，等长不覆盖已有更早词，从而满足全局并列要求。输入含重复词时重复检查不影响集合或答案。

设N为词数、L为最长词长，排序比较与前缀切片/散列的时间上界O(N*L*log(N+1))；额外空间O(N+L)个词引用及临时前缀字符，若连同所引用原词文本计入则O(NL)上界。没有原地排序调用方列表。

独立oracle对每个候选逐个检查它的全部非空前缀是否直接属于原词表，再按长度优先、字典序次优选择，不增量维护可构造集合。a/b长度1..3的14个词组成的全部16383个非空词典核对，反序输入；另覆盖1000词/30字符完整链与无效长词、缺起点/缺中间前缀、等长apple/apply并列和重复输入。未向LeetCode提交。
