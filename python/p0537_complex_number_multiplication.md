# 537. Complex Number Multiplication · Python

[原题](https://leetcode.com/problems/complex-number-multiplication/)。

输入是题目保证合法的a+bi形式字符串，实部与虚部系数都是-100..100的整数。加号是固定分隔符，因此负虚部写成1+-1i，而不是把这个加号省掉。返回乘积的同一文本形式，包含零实部和零虚部，不输出浮点小数。

去掉末尾i，按固定加号分开两项后转整数。int可以直接解析负系数，所以负实部与+-形式的虚部都保留符号。根据分配律和i^2=-1，(a+bi)(c+di)的实部为ac-bd，虚部为ad+bc；所有生产计算都用整数，避免用浮点计算后再格式化成整数。

最后始终用一个加号连接实部和带符号的虚部系数，再接i。虚部负时自然生成+-，例如(1+-1i)^2得到0+-2i；不为看起来像通常数学式而擅自改成0-2i。零系数也保留，不删除整项。

设输入总文本长度为S，切片、分割和解析时间O(S)，临时字符串空间O(S)。原题系数范围固定，整数乘法与输出文本长度有固定上界；若只按本题合法输入计，整体也可视为固定规模。没有eval，也不扩展处理不符合题目格式的表达式。
