# 735. Asteroid Collision · Python

[原题](https://leetcode.com/problems/asteroid-collision/)。

原题asteroids长2..10000，每项为-1000..1000内的非零整数，符号给方向、绝对值给大小，所有速度相同。相向碰撞时较小者消失，等大同时消失；求最终从左到右的存活序列。输入保持，额外支持0或1个元素并返回其副本。

只有已存活的右行正数与新到的左行负数会相撞。新项较大则弹出旧项继续向左检查；旧项不小于新项时，新项消失，等大还要弹出旧项，然后break。while的else只在没有break时执行，此时新项仍存活，可压入；同向或背向直接保留。每个元素最多入出一次，时间O(n)，额外空间O(n)。

独立oracle反复寻找相邻的正/负对，按大小直接替换或删除这两个元素，每次从左重扫直到没有相向邻居，不复用栈。值-2/-1/1/2、长度0..7共21845个数组核对，0或1元素单列扩展。边界覆盖10000项、1000大小、等大成对、一个负数吞掉长正串及背向离开，核对列表和输入保持。
