# 129. Sum Root to Leaf Numbers · Python

[原题](https://leetcode.com/problems/sum-root-to-leaf-numbers/)。

原题非空树1..1000节点，val为0..9，深度最多10，答案保证落在32位有符号整数范围。每条根到叶路径按十进制数字组成数，求所有这些数之和。0可作为根或中间位；不把空树或超深输入当作原题范围。返回int并保持树，TreeNode供本地导入。

栈项(node,prefix)的prefix表示根到当前节点父亲的十进制值；读取本位后number=prefix*10+node.val。只有左右都不存在的叶子才加入total，内部节点把新number交给存在的孩子，不能把缺失的一侧误当成一个根叶终点。每个节点由唯一根路径到达一次，因此所有根叶数各计一次，前导0自然保留数值语义。

时间O(n)，显式深度优先栈额外空间O(h)，h是树高；原题h<=10，算法仍不使用递归。独立参考把根叶路径拼成数字字符串，再int转换求和，测试期望不复用乘10递推。枚举1..5节点全部树形、值0/2，共1618棵；另测1000节点深度10的树、十位合法数1000000000、前导0和单叶9。所有测试参考答案先核对符合32位保证，再检查int和原结构保持。
