# 401. Binary Watch · Python

[原题](https://leetcode.com/problems/binary-watch/)。

二进制手表用4个LED表示小时、6个表示分钟，返回恰有turnedOn盏亮灯的所有有效时间。原题turnedOn在0..10，小时0..11，分钟0..59；小时不补前导0，分钟固定两位，可以任意顺序返回。

直接枚举12*60种合法时间，只检查小时与分钟二进制中1的个数之和。每个有效时间与唯一一组LED状态对应，所以既不遗漏合法结果，也不会重复。先枚举合法时间还自然排除12..15小时和60..63分钟，不能只把10个LED任意组合后全部格式化。

小时使用普通十进制格式，分钟使用两位补0格式。turnedOn=0时只有0:00；虽然有10个LED，但合法小时最多亮3盏、合法分钟最多亮5盏，因此9或10盏无结果。

枚举固定720项，时间O(12*60)，在题目固定表盘下为O(1)；除返回的R个时间字符串外只需常数辅助状态，输出存储O(R)。不生成无效时间再按字符串去重。

独立oracle按LED下标组合，使用小时权重1/2/4/8和分钟权重1/2/4/8/16/32累加后再过滤无效时刻，不复用生产逐时间枚举。turnedOn=0..10全部原题域核对集合、无重复和格式；另固定检查0盏、1盏、8盏及无解边界。未向LeetCode提交。
