# 472. Concatenated Words · Python

[原题](https://leetcode.com/problems/concatenated-words/)。

从词表中找出能由至少两个词表内非空单词连接而成的词，组成词可以重复使用。原题1..10000个互异小写英文词，每词长1..30，总字符数不超过100000；返回顺序不限，本实现沿输入顺序返回，输入保持。空词表额外返回空列表，词条仍要求非空。

先用集合提供词段查询。针对一个词，parts[end]保存前end个字符能切分成的最多词段数，-1表示不可达，空前缀为0。枚举最后一段起点start；只有前缀可达且word[start:end]在词表内，才用parts[start]+1更新。每段长度为正，start<end，因此状态按前缀长度增加是无环的，允许同一个词在不同位置重复使用。

词本身在集合里，必然给完整前缀提供一段方案，但只有最终至少2段才接受。无需临时删除当前词、改变集合或依赖词表顺序；较短的真拆分由其他start完整覆盖，最多段数会保留它。非空假设同时保证当前完整词不可能成为一个严格更短前缀的组成段，不会出现自我循环。

长度L的词枚举O(L^2)个切片；Python构造及首次哈希一个长度至多L的切片需O(L)，故最坏总时间O(sum(L_i^3))，不能把字符串查询整体视为常数而写成平方。集合初始化另需O(sum(L_i))哈希时间，被前述上界覆盖。集合保存N个现有字符串引用，单词DP及临时切片O(max L_i)，辅助空间O(N+max L_i)，返回列表另占O(N)。

独立参考枚举每个词内部边界的全部非空切分掩码，直接检查得到的每一段是否在词表，不使用最优前缀状态。a/b长1..3的14词全集，其全部16384个子词表逐项对照，空词表为扩展。另测10000个互异10字母词的词数/总字符上界、30字母重复分词、重复使用单词及输入逆序；所有预期基于切分语义，未向LeetCode提交。
