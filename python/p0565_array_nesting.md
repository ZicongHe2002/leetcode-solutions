# 565. Array Nesting · Python

[原题](https://leetcode.com/problems/array-nesting/)。

nums是0..n-1的一个置换，1<=n<=100000。由某下标不断跳到nums[下标]，在第一次重复前得到互异元素集合，求所有起点的最大集合大小。保持输入，实现额外定义空数组返回0；不将本算法推广到存在重复值的任意函数图。

置换中每点恰有一条出边和一条入边，因此整个图由互不相交的环组成，没有进入环的树枝。一个环上的所有起点得到的集合相同，大小等于环长。遍历下标，已访问点跳过，未访问点则沿nums逐个标记直到遇到访问点，记下新访问点数。因为不同环不相交，这次第一次遇到的访问点只能是当前环已经访问的点，不会中途汇入另一条已处理路径，因此length恰为完整环长。

题目从nums[start]开始集合，实现从start开始计数；在环上只是旋转起点，互异点数不变。每点只在某一个while中标记一次，外层也只扫描n项，时间O(n)。visited保存n个标记，额外空间O(n)，不以破坏输入换空间。单个自环长度1，不会因提前标记漏计。

独立oracle针对每个起点新建集合，直接从nums[start]追踪到重复，不共享全局访问状态。穷举1..8的全部46233个置换，另测空数组扩展。边界覆盖100000元素单大环、全自环、两两交换和多个不同长度环，核对整数返回及输入保持。未向LeetCode提交。
