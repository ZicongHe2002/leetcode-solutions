# 282. Expression Add Operators · Python

[原题](https://leetcode.com/problems/expression-add-operators/)。

给定长度1..10的十进制数字串，在相邻字符之间插入+、-、*或不插入，返回计算结果等于target的全部表达式，数字顺序不能改变，操作数不得有前导零。只有单独的0合法；不允许括号、除法或首个数前的一元运算符。输入非空，结果顺序不限。

从当前位置枚举下一个完整数字片段。片段以0开始时只允许取一个字符，不能生成00或05。第一个片段直接作为初始表达式，其后分别尝试三种运算符，每种切分位置与运算符序列唯一确定一个输出，因此不需要对结果去重。

total是已有表达式的实际值，last是其中最后一段带符号乘法链。加减新数时直接增加或减少total，并将last设为新数或其负值。追加乘法时不能直接让整个total乘新数，而是先减掉旧last，再加上last*value，从而保留乘法优先级。例如1-2*3中，乘法前total=-1、last=-2，修正后为-1-(-2)+(-6)=-5。

搜索枚举全部合法数字切分和运算符，不因当前值大于target提前剪枝，因为后续减法和乘0可能改变比较关系。按原题短字符串的有界整数操作计，保守时间上界O(n*4^n)，包括表达式构造；设输出总字符数为R，空间上界O(n²+R)。递归深度O(n)，但各层保留不同长度的前缀字符串，不能把这些字符串存储省略后直接称总额外空间O(n)。

独立oracle对每个字符间隙枚举四种插入选择，过滤前导零，再用标准库AST的运算树计算+/-/*结果，不复用生产total/last修正。三数字域长度1..5共363个字符串，各核对-6..6的13个target，共4719次查询。另测105、232的多答案与前导零，10个0的19683种合法结果，以及10字符大整数整段保留；检查没有重复表达式。
