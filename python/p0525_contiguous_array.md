# 525. Contiguous Array · Python

[原题](https://leetcode.com/problems/contiguous-array/)。

原题nums为长度1..100000的二进制数组，求0和1数量相同的最长连续子数组长度，找不到时返回0。输入不变，额外定义空数组返回0；不承诺其他值。

把1记为+1、0记为-1，区间内0和1相等就等价于两端前缀balance相等。earliest保存每种balance最早下标，balance=0初始在-1。再次遇到同一balance时，当前下标减最早下标就是以此为右端的最长平衡区间；保留更晚下标只会缩短未来候选，故只在首次出现时登记。平均哈希操作下时间O(n)，额外空间O(n)。

独立oracle枚举全部非空切片，分别count(0)和count(1)，不复用正负映射或前缀表。长度0..12的8191个二进制数组全部核对，空输入为扩展。边界覆盖100000个0、全1、交替、两长段数量相差2，以及从首项开始的平衡段；核对int及输入保持。
