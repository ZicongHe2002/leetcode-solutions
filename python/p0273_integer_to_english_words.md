# 273. Integer to English Words · Python

[原题](https://leetcode.com/problems/integer-to-english-words/)。

把0..2^31-1内整数写成原题约定的英文基数词。单词首字母大写，使用Hundred/Thousand/Million/Billion，不加入and、连字符或多余空格。0单独写Zero，其余数的零分组不读成Zero。

按十亿、百万、千、个位四个尺度逐次divmod，每个非零分组都在1..999内。三位组先输出百位与Hundred，再处理余下两位：20及以上输出整十词，最后输出非零个位；1..19直接取词表。只有非零分组才附加量级词，所以1000001写One Million One，中间两个零分组完全跳过。

从高量级到低量级收集词片段，最后以单个空格join。各组代表互不重叠的三位十进制位置，余数继续交给较低尺度，覆盖原数全部数位且没有重复计入。最高组按原题界最多为2，不会把1000以上值交给三位组助手。

设输出总字符数为L，构造片段与连接需要O(L)时间和O(L)空间；在原题固定32位范围内，四组和输出长度都有常数上界。本方法没有承诺处理超出Billion表范围的任意大整数，也不把输出空间藏在O(1)结论内。

独立验证将输出按英文语法解析回整数：三位组允许一位数+Hundred及可选两位尾数，量级词必须严格下降且组非零，十位尾数只能为1..9，单值Zero只允许单独出现。规范语法和数值回读共同唯一确定本题格式，不调用生产分组助手。穷举0..9999、每种合法三位组放在各量级，以及1728组稀疏/非稀疏量级组合，并检查最大32位正整数的完整固定文本。
