# 1004. Max Consecutive Ones III · Python

[原题](https://leetcode.com/problems/max-consecutive-ones-iii/)。

原题nums为长度1..100000的二进制数组，0<=k<=len(nums)，最多把k个0翻成1，求连续1的最大可达长度。函数只计算长度、不修改数组；额外定义空数组且k=0返回0。

窗口中的0必须全部翻转，才能让窗口全为1，因此合法性恰好是zeros<=k。加入右端后持续移出左端，直到预算内；当前左端以前的任何起点都包含过多的0，不能产生更长合法窗口。每个元素最多加入与移出各一次，时间O(n)，额外空间O(1)，无需实际翻转。

独立oracle枚举全部连续切片并用count(0)检查预算，不复用滑动状态。枚举长度0..9的1023个二进制数组及每个合法k，共9217次查询；空输入为扩展。边界覆盖100000长度的全0/全1/交替数组，预算0、17、25000与50000，核对int及输入保持。
