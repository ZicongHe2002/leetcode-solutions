# 1249. Minimum Remove to Make Valid Parentheses · Python

[原题](https://leetcode.com/problems/minimum-remove-to-make-valid-parentheses/)。

原题s长1..100000，只含左右括号和小写字母，删除最少数量括号后返回任一合法字符串；字母不能删除，原有顺序保持，空结果允许。返回str。

opened保存未匹配左括号下标，右括号优先匹配最近可用左括号；无可用左括号时标记这个右括号，扫描结束后标记剩余左括号。跳过标记位置重建结果，只会删括号。括号配对的贪心保持最多可保留的匹配对：某前缀右括号多出的数量不可由后续左括号修复，而结尾剩余左括号也没有后继可匹配。标记删除恰好消除这些无法配对的数量，因此结果合法且删除数最小，保留字母不影响配对。

平均集合操作下时间O(n)，下标栈、删除集合与结果总空间O(n)。独立参考枚举小括号骨架的全部保留子集，找最长合法子序列；测试不要求某个固定最优文本，同时检查结果合法、所有字母完整有序、为原文本子序列且删除数达到最小。字符a/左/右、长度1..8共9840个输入；另测100000字符全字母、全开、全平衡和左右分离，核对str与最优删除数。
