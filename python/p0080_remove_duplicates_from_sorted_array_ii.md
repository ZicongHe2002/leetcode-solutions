# 80. Remove Duplicates from Sorted Array II · Python

[原题](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/)。

原题nums非递减，长度1..30000，值-10000..10000；原地保留每种值最多两次且保持相对顺序，返回有效长度k，只检查nums[:k]，其后的内容不作规定。实现不分配另一个数组。

write之前始终是已经扫描部分的合法压缩结果。前两个元素直接接受；之后若当前值等于结果倒数第二项，非递减顺序保证结果最后两项都已是该值，继续接收会超过两次，因此跳过。若不同，该值在结果中还不足两次，可以写到write处并前进。write不超过当前读取位置，覆盖的都是已经读过的槽，不会改变未来尚未处理的输入。

扫描一次，时间O(n)，仅write和value两个状态，额外空间O(1)。不截断数组，不把无关尾部当作有效答案，也不对未排序输入承诺同样语义。

独立oracle用Counter统计各值后按大小展开min(计数,2)次，不复用写指针规则。五种值的非递减数组、长度1..8共1286个全部核对返回int和有效前缀。长度30000覆盖全等、每值已恰两次、极端值各15000次，另含原题重复分组样例；测试遵循原题不要求尾部内容。
