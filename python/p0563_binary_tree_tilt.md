# 563. Binary Tree Tilt · Python

[原题](https://leetcode.com/problems/binary-tree-tilt/)。

原题有0..10000个二叉树节点，值在-1000..1000。每个节点的倾斜度是左子树所有值之和与右子树所有值之和的差的绝对值，缺失子树和为0；返回所有节点倾斜度之和。根的值不参与根自身的差，但须进入向父节点返回的子树和。使用平台提供的TreeNode接口，不修改节点或左右引用。

pending显式模拟后序遍历。首次遇到非空节点，依次压入完成事件、右孩子、左孩子；栈后进先出，所以左子树先计算，右子树其次，最后才处理父节点。空节点向sums压入0。完成事件到来时，sums顶部依次是右、左子树和，弹出它们，累加绝对差，再把两者与node.val之和压回，作为完整子树的返回值。对子树大小归纳即可保证每个返回值和每个倾斜度准确。

负值保留符号，必须先计算两边的代数和再取差的绝对值，不能把各节点值先取绝对值。显式栈不受Python递归深度限制。每节点只有进入和完成事件，时间O(N)；pending和sums只保留当前路径及其待处理兄弟/已算左子树结果，额外空间O(H)，最坏链形H=N。Python整数保留可能超过32位的总倾斜度。空树返回0。

独立oracle对每个小树节点重新遍历左右子树求和，不复用一次后序计算。穷举0..5节点全部二叉树形状，并为每节点分配-1/0/2，共11497棵树；检查值和原左右引用保持。另测10000节点全1000与全-1000单链，预期1000*N*(N-1)/2，覆盖深度和超32位结果；样例与正负相消树也分别检查。未向LeetCode提交。
