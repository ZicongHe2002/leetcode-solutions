# 455. Assign Cookies · Python

[原题](https://leetcode.com/problems/assign-cookies/)。

原题孩子数1..30000，饼干数0..30000，每个需求和尺寸在1..2^31-1，每人至多一块、每块至多给一人，尺寸>=需求才满足。求最多满足数，返回int，两个输入数组保持。

需求和饼干各自升序。当前饼干小于最小未满足需求时，它也不能满足任何后续孩子，跳过没有损失；足够时用它满足最小需求，保留更大饼干给更大需求。若某个最优分配使用不同的够大饼干满足这个最小需求，可交换成当前最小够用饼干，不减少满足人数，因此逐个匹配可达到最优。只推进满足计数，全部孩子满足后不再索引越界。

时间O(n log n+m log m)，排序副本额外空间O(n+m)，不声称原地常数空间。独立参考枚举每个孩子不分配或使用某块未使用饼干，用位集表示已用饼干，不排序。需求长度1..4、饼干长度0..4、值1/2/3，共14520组查询；另测两边各30000项、空饼干及32位正值上界，核对int及两个输入保持。
