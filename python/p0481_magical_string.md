# 481. Magical String · Python

[原题](https://leetcode.com/problems/magical-string/)。

魔法串由1和2组成，以122开头；把各段相同数字的连续长度依次写出，得到的仍是魔法串本身。求其前n位中1的数量。原题1<=n<=100000；n=0额外返回0，负数不在合同内。

先放入已确定的122。前两段是一个1和两个2，其游程长度已由下标0/1给出；因此head=2指向下一段的长度，下一段要写的value=1。读取sequence[head]后追加这一段，head前进一位，value在1和2之间切换。追加的是整段，不能在中间裁掉后还把它当完整游程。

每步新增1或2个数字而head只增1，种子留出的未读数字足够保证下一次读取已存在；追加的数字由先前确定的游程长度唯一决定。所有已生成段满足自描述关系，且段数字交替；从122开始归纳即可确定完整前缀。最后可能多生成1位，所以只对sequence[:n]计数；n=1/2/3也直接由种子前缀给出，n=0为空切片。

每个生成数字只写入一次，最后切片计数再线性扫描，时间O(n)，保存序列及最终切片的辅助空间O(n)，不宣称常数空间。没有浮点、随机数或对未知未来位置的读取。

独立短参考枚举固定122种子后的全部1/2候选，对每个候选直接做游程分组：完整段长度必须等于候选对应前缀，末段允许尚未结束但长度不能超过指定值。长度1..18逐个验证只有一个合法前缀，再核对1的计数，不使用生产的head生成循环。大参考反复整体展开当前游程长度串，取收敛的嵌套前缀；另核对1..1000每个n和100000上界。实际为本地确定性验证，未向LeetCode提交。
