# 732. My Calendar III · Python

[原题](https://leetcode.com/problems/my-calendar-iii/)。

原题最多400次book，0<=startTime<endTime<=10^9。每个请求都加入，不再拒绝双重或三重重叠；返回全部已加入半开区间在任意时间的最大同时覆盖数，返回int而不是bool。

changes在每个起点加1、终点减1。同一时间的起止变动先合并到一个键，再按时间排序累计。处理某键之后，active恰为从该时间开始到下一个不同端点之前的覆盖数；相接预约的一次结束和一次开始抵消，不产生假的额外重叠。每个非空覆盖区间的状态都出现在某对相邻端点之间，所以扫描时的最大active就是全局最大预约深度。

每次book保留所有历史端点增量，再重新扫描完整端点集合，能覆盖新旧预约任意相交及全局峰值不在新区间的情况。零增量键可以保留，不改变扫描；一个请求最多引入两个新键，空间仍线性。

设目前已有q个请求，至多2q个端点，本次排序和扫描O(q log(q+1))，Q次总时间O(Q² log(Q+1))，存储O(Q)。这个实现在400调用的合同内使用标准库内建类型，不展开10^9的时间轴；没有声称每次book为对数时间。

独立oracle保存原始区间，对每个历史起点逐一数有多少区间包含该时间，取最大值；不维护端点增量。端点0..4的10个区间、长度1..4共11110个请求程序/43210次book，另核对官方峰值历史、400次重复满域/相接无交/同心嵌套及0和10^9边界。未向LeetCode提交。
