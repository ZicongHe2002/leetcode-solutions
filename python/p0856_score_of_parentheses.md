# 856. Score of Parentheses · Python

[原题](https://leetcode.com/problems/score-of-parentheses/)。

原题s为长度2..50的合法平衡括号串，仅含左右括号；空心对得1分，拼接分数相加，包裹非空合法内容使分数翻倍。返回int，非法或空输入不在原题范围。

最内层的每个相邻括号对贡献基础1分，其每层祖先包裹使贡献乘2，所以它对总分贡献2^祖先层数。扫描遇右括号先减depth，若前一字符为左括号，就找到一个最内层对，此时depth恰为祖先层数，加入1<<depth。非最内层闭合只表示包裹，其倍增已包含在各叶对的深度权重里，不能重复加分。合法输入保证右括号不在下标0且depth非负。时间O(n)，额外空间O(1)。

独立参考递归按首个完整分量拆分，直接应用空心对1、包裹乘2、拼接相加的原评分语法。枚举1..8对的2055个合法串；另测50字符全嵌套、全拼接与多个内叶被整体包裹，核对int和值域内精确整数，无在线Accepted记录。
