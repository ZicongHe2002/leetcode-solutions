# 513. Find Bottom Left Tree Value · Python

[原题](https://leetcode.com/problems/find-bottom-left-tree-value/)。

原题树非空，1..10000节点，值在32位有符号范围，返回最深一层最左节点的值。TreeNode本地定义对接val/left/right，不要求节点值唯一，也不能用数值大小决定最左位置。

队列在每轮开始时恰好保存当前层，按从左到右排列。先取队首值作为这一层答案，再固定本轮节点数，依次出队并按左、右顺序追加下一层。父节点从左到右处理且每个父亲的左孩子先加入，归纳保持下一层顺序。队列为空时已处理最后一层，最后一次记录的队首就是最深最左值。

每个节点入队出队各一次，时间O(n)，额外空间O(w)，w为真实节点最大层宽；不使用递归，不修改输入，10000节点深链也适用。

独立oracle用深度优先遍历按左优先访问，只在首次到达更深深度时更新值，与层序队列方式不同。1..7节点全部625种树形逐一核对，值使用不同负数以区分位置。最大10000节点右链及10000节点完全树覆盖深度和宽度，两种32位端点及单节点也检查，逐节点核对输入身份和值保持。
