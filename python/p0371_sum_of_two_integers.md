# 371. Sum of Two Integers · Python

[原题](https://leetcode.com/problems/sum-of-two-integers/)。

原题a、b各在-1000..1000，求和但实现中不用+和-运算符，返回有符号整数int。真实和在-2000..2000，必能由32位有符号数表示；不把任意溢出输入视为原题合同。

将a、b映射为32位无符号补码。a^b给出不考虑进位的逐位和，(a&b)<<1给出进位，二者之和模2^32与旧a+b相同。并行赋值确保两表达式都使用旧a、b。每轮都掩码截去第32位及以上进位，避免Python无界负数的符号扩展让进位永不消失；进位只能向高位移动，因此最多32轮后b为0。

若最后符号位未置位，a本身就是答案；否则a^mask翻转32个低位，再取反，得到a-2^32的负整数，表达式不使用减号。按固定32位合同时间与空间均O(1)。独立参考直接a+b，枚举-32..32的4225组输入；另测原题上下界、正负抵消和连续进位。AST检查实现不存在Add/Sub运算符；没有在线Accepted记录。
