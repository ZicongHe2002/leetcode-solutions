# 994. Rotting Oranges · Python

[原题](https://leetcode.com/problems/rotting-oranges/)。

输入为1..10行、1..10列的矩形网格：0为空、1为新鲜、2为腐烂橘子。腐烂每分钟沿四方向传播一步，返回全部新鲜橘子腐烂的最早分钟，无新鲜为0，不可全部到达为-1。本实现会原地将可到达的新鲜橘子改为2，保留行对象；额外支持空网格为0。

所有初始腐烂点同时入队，fresh记录剩余新鲜数量。一次外层循环只处理进入该轮时队列的固定长度；本分钟新发现的点虽立即改为2并入队，也要下一轮才处理，防止一分钟穿过多条边。入队前改色保证每个新鲜点只计一次。按分钟归纳，队列分层对应到任一初始腐烂点的最短橘子路径距离，首次腐烂已经最早。fresh清零时分钟即最大首次腐烂距离；队列耗尽而fresh非零说明隔离。时间O(mn)，队列空间O(mn)。

独立oracle每分钟复制完整旧网格，扫描全部新鲜点，仅依据旧状态四邻是否腐烂再同时提交新状态，直到无变化或全部腐烂。穷举1x1、1x3、2x2、2x3、3x2的全部1569个三值网格，比较返回值及最终网格。固定覆盖经典可达/不可达、无源、无新鲜、空图及10x10一角腐烂全新鲜图（18分钟）。
