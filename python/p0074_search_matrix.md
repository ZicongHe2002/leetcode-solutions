# 74. Search a 2D Matrix · Python

[原题](https://leetcode.com/problems/search-a-2d-matrix/)。

矩形矩阵行列数均1..100，各行非递减，后一行首值严格大于前一行末值，值与target在[-10000,10000]。判断目标存在性。空矩阵和零列矩形另扩展为False；不承诺处理ragged矩阵，也不把仅行列各自有序当作本题跨行合同。

矩阵按行连接后整体非递减。虚拟下标i唯一映射到(i//列数,i%列数)，不构造扁平副本。在[0,行数*列数)二分，中点较小就排除到中点的全部前缀，较大就排除从中点开始的后缀，命中即True。候选区间保持至少一个可能命中位置，严格减半至空则缺失。合法中点的商余数均不越界，非方阵也必须用列数作除数。时间O(log(mn))，额外空间O(1)，保留所有原行的值与引用。

独立oracle逐行逐元素扫描。对1..3行和1..3列，枚举五值非递减序列并只保留跨行严格递增的矩阵，共277个，各查七个target共1939次。固定例子包含非方阵、单行、单列、重复行内值与两种空扩展；100x100边界覆盖所有值不同及每行全相同但行间递增两种构造。
