# 415. Add Strings · Python

[原题](https://leetcode.com/problems/add-strings/)。

将两个非负十进制整数字符串相加，返回规范十进制字符串；不能把完整输入转换为整数或依赖大整数库。原题每个输入长1..10000，只含0..9，不含多余前导0，0用单字符表示。空串、符号和非数字不属于合同。

从两字符串末尾对齐最低位。每轮将尚未处理的两个数位与carry相加，缺失的一侧视作0，用divmod(total,10)得到新的进位与本位结果。total至多19，所以carry始终是0或1；已保存的低位正好等于相同低位输入相加的结果，剩余影响完全由carry传给更高位。

两侧都用完后若仍有进位，还需输出一位，例如99+1得到100。结果位先按低到高保存，最后反转并join。两个输入都为0时仍会处理一次并返回0，不会产生空串。仅用ord读取单个数位，未使用完整int转换或字符串拼接累积。

设L为两输入长度较大者，至多处理L+1位，时间O(L)。数位列表与结果字符串均为O(L)存储，额外空间O(L)；没有声称除了输出就只占常数空间。
