# 41. First Missing Positive · Python

[原题](https://leetcode.com/problems/first-missing-positive/)。

给定整数列表，找出没有出现的最小正整数。要求O(n)时间和O(1)额外空间；允许修改输入。本实现只通过交换改变排列，不删除或复制元素，额外支持空列表返回1。

长度为n时，答案一定在1..n+1内：若1..n都出现，答案是n+1；否则答案就是其中某个缺失值。将范围内的值v放到下标v-1。不在1..n内的值不能充当下标；目标位置已经等于v时停止，避免重复值相互交换形成死循环。

一次成功交换会使一个值首次到达自己的最终位置，后续不会将这个正确值移走：另一个相同值尝试占用该位置会触发相等检查。成功交换总数最多n，外层循环也只有n次，所以总时间O(n)，并非按两层语法循环乘成O(n²)。扫描完成后，第一个nums[i]不等于i+1的位置说明i+1不存在，否则该值早已归位；都匹配就返回n+1。额外存储只有几个整数，空间O(1)。

测试以保留原数组建立的正整数集合为独立oracle，依次查找第一个缺值，不复用归位算法。穷举六值域长度0..6的55987个数组，并核对交换后元素多重集保持。另测100000项逆序排列、全重复值、全部越界值、32位端点及重复调用。
