# 150. Evaluate Reverse Polish Notation · Python

[原题](https://leetcode.com/problems/evaluate-reverse-polish-notation/)。

输入为合法逆波兰表达式，最多10000个token；操作数[-200,200]，运算符为四则运算，保证不除零且所有中间值与结果均在32位有符号范围。除法向零截断。不承诺诊断空输入、非法token或不合法栈结构。只有完整token恰好为四种运算符时才执行运算，负数字符串正常解析。

数字入栈，运算符先弹右操作数再弹左操作数，计算left op right后压回。栈按顺序保存已读前缀中尚未被上层表达式消费的完整子表达式值；合法运算符正好消费最后两个子表达式，保持该不变量，最终剩一项即完整结果。减法与除法不能交换两个操作数。

负数除法先用非负绝对值整除求商的大小，再按两数符号决定结果符号，因此-7/3得-2；直接用Python的负数//会错误向负无穷取整。没有通过浮点除法再取整。时间O(n)，额外值栈O(n)，输入token列表保持。

独立测试生成1..3叶、叶值[-2,2]的全部合法小表达式树，树上计算期望并产生后序token，除法用精确Fraction再int向零取整；未用另一套RPN栈作oracle。固定例子覆盖弹出顺序、各符号除法、单负数及1600000200。两种9999-token边界分别覆盖5000值大栈与逐次减法长链，保持官方中间值合同。
