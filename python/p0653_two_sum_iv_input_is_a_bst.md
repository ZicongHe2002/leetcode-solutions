# 653. Two Sum IV - Input is a BST · Python

[原题](https://leetcode.com/problems/two-sum-iv-input-is-a-bst/)。

原题输入1..10000节点的合法BST，节点值-10000..10000，目标k在-100000..100000，判断是否有两个不同节点的值之和为k。节点接口由平台提供val/left/right。实现不改值、不重连树，额外支持空树返回False。

显式栈遍历节点，seen保存已经访问过的节点值。遇到当前值v，先查k-v是否已在seen，再加入v；若存在，配对值来自更早的另一个节点，因而不会把当前节点自己用两次。即使目标等于2*v，一个值为v的孤立节点也不能成功。若最终没找到，任意两个节点中后访问者都已检查过先访问者，因此不存在漏掉的节点对。

算法只用树作为遍历入口，不依赖BST排序来判断补数。期望时间O(n)、额外空间O(n)，显式栈避免10000层合法链依赖递归上限；seen、遍历栈都计入空间。提前返回也不修改节点，后续调用仍能读取完整原树。

独立oracle枚举全部不同节点下标对并求和，不维护seen。五个候选值-4/-1/0/2/5的全部非空子集与各自所有合法BST形状，共187棵树；每树测试-10..11共22个目标，即4114次查询。另查10000节点正右链与负左链、目标范围两端、唯一大值不能自配对及空树扩展，逐次回读全部值与左右引用保持。没有LeetCode提交记录。
