# 554. Brick Wall · Python

[原题](https://leetcode.com/problems/brick-wall/)。

给定1..10000行等总宽的砖墙，每行1..10000块，所有行合计最多20000块，每块宽1..2^31-1。画一条贯穿墙高的竖线，碰到砖缝不算穿砖，求最少穿过的砖数；不允许沿墙最左或最右外边缘画线。输入各行和值保持。整行总宽可以超过32位，不能误把单块宽上限当成总墙宽上限。

一行在某个内部位置要么处于砖缝而穿0块，要么处于一块砖内部而穿1块。因此固定位置x的穿砖数恰为总行数减去在x处有内部砖缝的行数。只需把所有行内部砖缝的横坐标计数，找到最大对齐次数，不需要按整面墙的宽度枚举每个坐标。

每行从0累加砖宽，但只累加到倒数第二块：最后一块结束是整墙最右外边缘，必须排除，最左位置0也不加入。砖宽为正，同行累计位置严格递增，所以一行不会在同一位置被计多次；字典频数确实表示行数而非重复边界数。若没有任何内部砖缝，字典为空，最大次数取0，答案就是全部行数。

取最大对齐砖缝可以达到最少穿砖数；任何非砖缝位置的对齐次数为0，不会优于已有最大值，所以只枚举实际砖缝不会漏掉更优线。Python整数保存累计坐标，不创建与可能很大总宽等长的数组。

设B为总砖数，通常哈希时间O(B)，辅助空间O(B)，包含不同内部砖缝字典以及单行切片临时引用；不把row[:-1]的临时列表遗漏后误报更小空间。不改wall或任一行对象，返回整数。

独立参考枚举小墙所有内部半整数截线，用双倍整数坐标直接检查线是否严格落在每块砖的开区间中，不建立跨行砖缝直方图。总宽1..6的全部正整数组成、1..3行，共38877面墙逐个对照，兼顾整数砖缝与非砖缝位置。另测10000行/20000砖、10000块单行、单块行无内部缝，以及总宽2*(2^31-1)的8000行/20000砖混合对齐构造，核对int、原行值和对象保持。未向LeetCode提交。
