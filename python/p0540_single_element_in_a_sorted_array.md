# 540. Single Element in a Sorted Array · Python

[原题](https://leetcode.com/problems/single-element-in-a-sorted-array/)。

给定有序数组，恰有一种值出现一次，其余每种值恰好出现两次，返回单独值。原题长度1..100000、值0..100000，并要求时间O(log N)、额外空间O(1)。合同隐含长度必须为奇数，所以最大合法长度为99999；不拿偶数长度或三次重复当原题输入。数组保持。

单独值之前，每对相同值从偶下标开始；单独值自身也在偶下标，因为其前面全是完整双元素对。越过单独值以后，每对相同值的起点变成奇下标。把middle向下对齐为偶数，再检查middle与middle+1是否相等：相等说明这是一对位于单独值之前的完整配对，单独值必在middle+2及其右侧；不相等则单独值在middle或其左侧。

left、right始终为偶下标，且单独值的下标保留在闭区间[left,right]。循环内left<right，二者至少差2；向下对齐后的middle不小于left，且middle+1不超过right，因此比较不会越界。两个分支都严格缩小区间，最后left==right，该位置就是唯一未配对元素。长度1直接返回，不读取第二个元素。

每步把区间缩小约一半，只保留三个下标，时间O(log N)，辅助空间O(1)。没有先扫描计数、求异或或复制数组；频数表只用于独立测试参考，不属于生产算法。

独立参考直接统计全部值的频率，取唯一频率为1的值。0..7的所有非空值子集，每次选其中一个值作为单独项，共1024个合法数组对照。另测99999项时单独值在开头、中间和末尾，以及0、100000端点、长度1与原例，核对int和输入保持。未向LeetCode提交。
