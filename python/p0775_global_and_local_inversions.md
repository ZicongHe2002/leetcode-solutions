# 775. Global and Local Inversions · Python

[原题](https://leetcode.com/problems/global-and-local-inversions/)。

原题nums是0..n-1的排列，1<=n<=100000。全局逆序统计全部i<j且nums[i]>nums[j]的下标对，局部逆序只统计相邻下标对。判断两种数量是否相等，输入保持。

每个局部逆序已经是全局逆序的一部分，所以两者相等当且仅当不存在间距至少2的逆序。访问右端index时，只需知道nums[0..index-2]的最大值；若它大于nums[index]，就存在一个非相邻逆序，立即返回False。否则以index为右端的全局逆序至多来自index-1，都是局部的。

largest初始-1，位于原题所有值以下，每次先加入nums[index-2]再比较；因此比较时恰覆盖全部间距至少2的左端，不误含相邻项，也不漏掉距离恰为2的项。所有右端检查通过就没有额外的全局逆序，返回True。n为1或2时没有非相邻下标对，循环为空，结果自然True。

每个元素最多加入前缀最大值一次，时间O(n)，额外空间O(1)。不计算可能达到数十亿的完整逆序数量，也不需要排序、树状数组或改写输入。

独立oracle双循环直接数全部全局逆序，再单独数相邻逆序并比较，不复用前缀极值条件。n=1..8的全部46233排列逐个核对。边界包括官方例、100000递增、100000相邻成对交换仍只有局部逆序、逆序排列与三循环产生非局部逆序，检查bool和输入保持。未向LeetCode提交。
