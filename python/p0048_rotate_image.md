# 48. Rotate Image · Python

[原题](https://leetcode.com/problems/rotate-image/)。

输入是边长1..20的方阵，值在[-1000,1000]，必须原地顺时针旋转90度，接口不返回矩阵。本实现返回None，保留外层与原有各行对象，只改写单元格；额外支持空矩阵为空操作。

先交换主对角线上方每对元素，使原坐标(r,c)移动到(c,r)；每对只交换一次，对角线不动。再原地反转每一行，使转置后的列r变为n-1-r。因此完整坐标变换为(r,c)→(c,n-1-r)，正好是顺时针90度。两阶段均不新建矩阵，也不替换原行对象。时间O(n²)，额外空间O(1)，包括固定大小交换临时引用。

独立oracle把原坐标直接写到新矩阵的(c,n-1-r)，不使用转置/反转过程。枚举边长1..3全部530个二值方阵；另用位置编号覆盖1..20全部20种合法尺寸。固定覆盖数值端点与空扩展，并验证四次旋转恢复原值。每次检查调用返回None、修改确实发生在传入矩阵、各行身份保持。
