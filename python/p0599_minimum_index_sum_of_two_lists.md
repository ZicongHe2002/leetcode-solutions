# 599. Minimum Index Sum of Two Lists · Python

[原题](https://leetcode.com/problems/minimum-index-sum-of-two-lists/)。

list1和list2各有1..1000个互不重复的字符串，每个长1..30，只含英文字母和空格，保证两列表至少一个共同字符串。对共同字符串的两个下标求和，返回达到最小和的全部字符串，顺序任意。比较区分大小写，不去掉名字中的空格，不改写两输入列表。

先记录第一列表每个名字的下标，再按第二列表顺序查找共同名字。第一次共同项必更新best，因为初值为两个长度之和，严格大于任何可能的下标和。后续若和更小，就替换best并清掉旧答案；若相等，就追加；若更大则忽略。处理到第二列表任意前缀后，result恰好包含当前全部最优共同项，对前缀长度归纳即可得到最终结果。

positions.get返回None表示名字缺失。下标0也是有效结果，不能直接用真假判断下标而跳过它。各列表内唯一保证同一名字只有一个下标，输出也不会重复；全部并列最优项均保留，不提前返回第一个共同名字。

设总字符数为T，两列表长度为A/B，答案数为R。平均哈希查找下时间O(T+A+B)，哈希及比较字符串需要计入字符成本；字符串长度上限30时常写为O(A+B)。字典保存A个原字符串引用及下标，结果R个引用，额外空间O(A+R)，不复制整份名字内容。

独立oracle枚举两个列表的全部下标对，对相等字符串直接计算和后选最小，不使用索引字典。四个含大小写及空格的名字，枚举全部非空不重复部分排列，两两选取有共同项的3964组。另测1000名字全部并列、列表轮转后并列、唯一共同项在末端、0下标及大小写/空格语义，检查无重复、输入保持和列表返回。未向LeetCode提交。
