# 69. Sqrt(x) · Python

[原题](https://leetcode.com/problems/sqrtx/)。

原题0<=x<=2**31-1，返回平方根向下取整的非负整数，不使用浮点开方或幂函数。

对候选根在0..x内二分。middle的平方不大于x时，它及更小候选都满足，继续尝试更大的根；否则它及更大候选都不满足，缩小右边界。循环始终把尚未确定的候选放在闭区间[left,right]，其左侧已知满足、右侧已知不满足。退出时left=right+1，right正是最后一个平方不大于x的整数；x=0也按相同路径得到0。

Python整数乘法不会发生32位平方溢出，比较完全使用整数。时间O(log(x+2))，辅助空间O(1)。

独立oracle使用标准库math.isqrt，并额外核对r*r<=x<(r+1)*(r+1)。对0..10000全部10001个值核对；边界测试若干完全平方数及其两侧，最大32位输入、最大合法平方根46340和紧邻非平方数。返回类型必须是int。
