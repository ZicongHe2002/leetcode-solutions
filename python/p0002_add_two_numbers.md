# 2. Add Two Numbers · Python

[原题](https://leetcode.com/problems/add-two-numbers/)。

原题两个非空、无环的链表分别表示非负整数，低位在前，每表1..100个节点，每个val是0..9；最高位非0，数0例外为单个0。返回和的同形式链表。本实现新建结果节点，保持两条输入链及值不变；本文件的ListNode供本地独立导入，与评测器的val/next接口一致。

每轮读取尚未处理的最低一位，缺失侧按0处理，加上carry。divmod(total,10)分别给出下一位进位和当前位；两位及旧进位最多和为19，所以carry始终为0或1。结果前缀恰好表示已处理低位的和，carry是流向下一位的值。循环条件包含carry，因此即使两表都读完，仍会补出最高进位；0+0也会由两个非空输入产生一个0节点。

每个输入节点读一次，时间O(max(m,n))；除返回的新链表外额外空间O(1)，返回空间O(max(m,n))。实现不把整条链转换为大整数。测试侧独立把输入整数转成逆序数字链，并以Python整数相加的十进制文本作参考。枚举0..99的10000组整数对，另测两条100位链、连续进位、不同长度和0；逐节点核对输出、输入原next和值保持、结果不复用输入节点以及正确链尾，无在线Accepted记录。
