# 557. Reverse Words in a String III · Python

[原题](https://leetcode.com/problems/reverse-words-in-a-string-iii/)。

给定长1..50000的可打印ASCII字符串，无首尾空格，单词间恰用一个空格分隔。反转每个词内字符，保持词序和空格位置，返回新字符串。大小写、数字、标点也属于词内字符，不只处理小写字母；输入字符串保持。

按字面空格分开，所得词序就是原词序；对每个词作反向切片，再用一个空格按原顺序连接。各词长度不变，且输入每两个词之间恰有一个空格，所以重新连接后每个分隔符仍在原下标。词内第j个输出字符来自同词倒数第j个原字符，其他词和分隔符都不会混入。

如果整个输入只有一个词，就反转全部字符；单字符词反转后保持。题目只含可打印ASCII且分隔符是空格，不需要把制表符、换行或任意Unicode空白当作额外分词规则，也不需要把整句词序倒置。

构造分词、反转各词和拼接的总字符数均为O(N)，时间O(N)，辅助及输出空间上界O(N)。Python切片会产生新字符串，split保存词列表，因此不声称原地O(1)额外空间。

独立参考分别从左右扫描记录每个位置所属词的两侧空格边界，再按左右边界计算原下标，不调用split或反转切片。a/B/!组成、长1..3的39种词，词列表长1..3，共60879句合法输入逐句对照。另测50000字符单词、含25000词的最大长度句子、大小写标点与原例，核对str和输出长度。未向LeetCode提交。
