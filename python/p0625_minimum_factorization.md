# 625. Minimum Factorization · Python

[原题](https://leetcode.com/problems/minimum-factorization/)。

输入正整数num在1..2^31-1，求各十进制位乘积恰为num的最小正整数；不存在或最小值不满足有符号32位范围时返回0。num=1的答案为1，单个数字2..9的答案就是自身。输入不含0，不以0作为合法正数答案。

num>1时，最优数不会含0（乘积会变0）或1（删除它得到更小数）。同一组2..9的数字必须升序排列才最小；更少位数又一定比更多位数小。依次尽量除去9到2，每取到一个较大的因子，就把它放在当前结果左侧的place位，后续较小因子会排到更左，最终形成升序数字，不需要保存再排序。

这个特定数字集合的贪心可以用可改进模式证明。数字5、7只能各自贡献质因子5、7，数量固定。对含2、3质因子的数字，2×2→4、2×3→6、2×4→8、3×3→9都减少位数；同位数替换6×6→4×9、3×6→2×9、4×4→2×8、4×6→3×8、3×4→2×6让升序后的数更小。最优解不能含这些模式，所以除9外至多剩一个3质因子，除8外至多剩两个2质因子；剩余2和3能合成6时优先合成，余下再用4/3/2。这正是从9到2尽量取因子的规范分解，不能仅凭“大数字通常更好”泛化到任意因子集合。

除完2..9后若num仍大于1，就有这些数字无法提供的质因子，返回0。构造中每次给结果左侧增加一个正数字，数值只增不减；一旦超过2^31-1，未来也不能恢复到范围内，立即返回0安全。所有运算是整数，避免浮点幂或对数判断边界。

每次成功除法至少把剩余num减半，成功次数O(log num)，外层固定8个数字，因此时间O(log num)。保存常数个整数，且输出构造有即时32位检查，在本题有界整数运算下额外空间O(1)。

独立oracle正向穷举2..9的所有非降序数字组合，长度1..9共24309个候选数，直接乘其数字，按乘积记录最小候选，另设1→1，不使用除法贪心。10位非降序且每位至少2的数最小为2222222222，已超过32位上限；含1的候选可以先删1变小，所以这张表覆盖全部可能的最小合法答案。核对1..100000、整张乘积表和1000个固定种子的大范围正整数，并单列9/10位边界、无法分解质因子、1与样例。未向LeetCode提交。
