# 587. Erect the Fence · Python

[原题](https://leetcode.com/problems/erect-the-fence/)。

给定1..3000个互不相同的二维整数点，坐标0..100。用最短绳索包围全部点，返回恰在绳索上的所有原点，顺序任意；需要包含凸包边上的共线中间点，不只返回拐角。全体共线时所有点都在绳索上。输入顺序和值保持，返回新的坐标列表。

按(x,y)排序后分别从左到右建立下链、从右到左建立上链。三点叉积为负表示顺时针转向，该中间点让当前链朝内部凹进，应从链尾弹出；重复弹出直到不再右转，再加入新点。扫描到某个点时，链按排序顺序覆盖已处理点的对应外边界，新点只可能影响链尾，因此每个点至多入栈一次、出栈一次。

判定必须使用严格小于0。叉积为0的中间点仍在同一条边上，需要保留；若用小于等于0，就会漏掉题目要求返回的共线树。上下链合并后用集合消除共有端点，以及全共线时两次出现的点；不做全局删除共线点。最后字典序输出仅为确定性，不承诺沿围栏环绕顺序，符合题目顺序任意。

排序O(N log N)，两次单调链扫描O(N)，合并去重后再次排序仍为O(N log N)。列表、元组和集合共O(N)额外空间。叉积使用整数，避免浮点方向判定误差；原坐标最大100，Python整数准确。单点和双点无需另设分支，最终去重即可得到全部点。

独立oracle枚举经过某点和另一点的全部直线，检查是否其余所有点均位于这条直线同侧或线上；存在支撑线则该点属于凸包边界，不使用单调链或排序弹栈。穷举3×3整数格点的511个非空子集，并核对150组固定种子小点集。另测3000点矩形格阵的216个边界点、101点全共线、0/100坐标和样例，检查无重复、输入保持及输出坐标类型。未向LeetCode提交。
