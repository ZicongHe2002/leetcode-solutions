# 1361. Validate Binary Tree Nodes · Python

[原题](https://leetcode.com/problems/validate-binary-tree-nodes/)。

原题1<=n<=10000，节点编号0..n-1，leftChild/rightChild长度均为n，元素-1表示没有孩子，否则是合法节点编号。只有所有节点恰组成一棵有效二叉树才返回True；节点没有额外值。两个孩子数组保持。

先统计每个节点的入度。任何入度超过1都意味着某节点被重复当作孩子，包括同一父亲左右都指向它，立即拒绝。合法树恰有一个入度0的根，其余各有一个父亲；根数不为1也拒绝。

这些条件仍不够：一个孤立根加一个断开的有向环也可能满足唯一根和每节点至多一个父亲。因此从唯一根迭代遍历，重复访问拒绝，最后必须恰好访问n个节点。通过时有唯一根、每节点唯一父亲、全图可达且无环，正是一棵二叉树。总边数至多2n，时间O(n)，额外空间O(n)，不用递归处理深链。

独立oracle逐个尝试每个编号为根，直接沿两个孩子槽展开，重复访问立即判该根失败，只有恰访问所有节点一次的根才接受；不使用入度或先找根的实现步骤。n=1..4的全部394806对合法值域孩子数组逐一核对，包含自环、共享孩子、无根、多根和断连环。最大10000节点链和完全树、整环、唯一根加断开环及重复孩子检查，核对bool与输入保持。
