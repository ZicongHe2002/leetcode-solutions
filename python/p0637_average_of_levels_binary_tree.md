# 637. Average of Levels in Binary Tree · Python

[原题](https://leetcode.com/problems/average-of-levels-in-binary-tree/)。

原题二叉树有1..10000节点，节点值是32位有符号整数，返回各层算术均值的浮点列表。本实现额外支持空树返回空列表，原树值和左右链接保持。

队列中一轮开始时的节点数count就是当前层大小。固定处理count个节点，以Python整数累加total，再做一次total/count；孩子按左、右入队，只参与下一层。整数累加避免逐次加浮点均值带来的额外舍入，也不会发生固定宽度整数溢出。每个节点入队出队一次，时间O(L)，除返回结果外额外空间O(w)，w为最大层宽。

独立oracle用深度优先栈按深度分桶，以Fraction构造精确有理均值后转为float比较，不复用队列定长分层。枚举长度0..6全部树形与两端整数赋值，共10067棵，空树为扩展；核对浮点结果、长度及输入结构保持。边界覆盖10000层链、10000节点完全树、极大正负值抵消、单节点和空树，不把均值错误地当作整除。
