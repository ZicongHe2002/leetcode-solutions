# 224. Basic Calculator · Python

[原题](https://leetcode.com/problems/basic-calculator/)。

计算只含十进制非负整数、二元加减、括号与空格的合法表达式。减号可以作为一元负号，例如-(2+3)或1-(-2)；不支持乘除和缺失括号等非法语法。原题中各数值与计算结果在32位有符号整数范围内，不使用生产eval、exec或AST。

当前括号层中，total保存已经结算的带符号项，number累积正在读取的整数，sign是它的正负号。遇加减号先将旧项计入total，再设置下一项符号。进入括号时保存外层的(total,sign)，以0和正号开始新层；右括号先结算内层末项，再用保存的外层符号将完整内层结果接回外层。

一元负号前没有待结算的数字，number为0，减号只改变下一项或括号整体的符号。右括号后将number清零、sign恢复正号，避免已经合并的内层结果被重复加一次。空格不改变状态，最终仅再结算仍未结束的数字项。

每个字符只访问一次，时间O(n)；上下文栈随最大括号深度d增长，额外空间O(d)。实现没有递归求值，因此很深但合法的括号不依赖Python递归深度。这里依赖输入合法，不把本题扩展成通用语法验证器。

独立oracle由标准库AST构建语法树，再按加减与一元负号的数学定义递归计算，不复用生产上下文栈。1..4个操作数、值0..2、两种运算符与全部二叉括号树共有3477个基础表达式，各测原式和整体取负，共6954次。另测5001层嵌套负号、32位边界、空格与200001字符长加法链；深层和长链使用已知精确结果而不让oracle触发递归上限。
