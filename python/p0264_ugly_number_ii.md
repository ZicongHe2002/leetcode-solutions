# 264. Ugly Number II · Python

[原题](https://leetcode.com/problems/ugly-number-ii/)。

原题n在1..1690，返回从1开始递增排列、质因子只含2/3/5的第n个正整数，返回int；1排在第一位，不重复统计同一个值。

values从1开始，三个下标分别指向乘2、乘3、乘5后尚未输出的最小候选。任意大于1的ugly数都能去掉一个允许质因子，剩余仍是更小ugly数，所以全部后续数都在这三条有序乘积序列的并集中。每次选三者最小值，就是尚未输出的全局最小值；所有等于candidate的序列都同时前进，避免6=2*3=3*2这样的重复。每步追加一个数且最多推进三个下标，时间O(n)，保存前n项，额外空间O(n)。

独立参考用最小堆维护已发现候选和集合去重，从1反复取最小并扩展乘2/3/5，不使用三个数组下标。原题全部1690个合法n逐一对照；另核对前10项、同时来自多路的6/30和最大n的2123366400，检查int。
