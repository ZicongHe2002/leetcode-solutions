# 134. Gas Station · Python

[原题](https://leetcode.com/problems/gas-station/)。

原题gas与cost等长，n为1..100000，元素0..10000。从某站空箱出发，在当前站加油后支付去下一站的费用，求能完成一圈的起点，无解返回-1；原题保证若可行则答案唯一。实现保持两个输入，也能对多个可行起点的扩展输入返回其中一个。

把每站净变化记为gas[i]-cost[i]。total累计整圈净变化，若为负则任何起点都不可能成功。tank累计当前候选起点到当前位置的净变化；一旦为负，将候选设为下一站并清零tank。此前该段每个前缀都非负，故从段内任何更晚位置出发，到本次失败位置的剩余和都不大于已经为负的整段和，这些位置全部可排除。

每次重置都到达一个比此前候选前缀和更低的新位置，最终候选位于全局最小前缀和之后。从那里向末尾的累计和非负；绕回前缀的累计和等于total加该前缀和与最小前缀和之差，total>=0时也非负，因此该候选可完成一圈。若候选落在数组末尾之后，意味着整圈由负和段组成，total必为负，返回-1。时间O(n)，辅助空间O(1)。

独立oracle逐个起点真实模拟一整圈，每步检查油量。元素取0..2、长度1..4的全部7380对gas/cost核对；oracle有多个可行起点的情况明确作为扩展，只要求返回可行成员。边界覆盖100000站、只有末站可行、总油不足、单站零油与最大费用，核对int与两个输入保持。
