# 85. Maximal Rectangle · Python

[原题](https://leetcode.com/problems/maximal-rectangle/)。

原题matrix为1..200行、1..200列的矩形，元素是字符'0'或'1'，求全部为1的轴对齐矩形最大面积。各行内容保持，实现额外定义空矩阵或0列矩阵面积0；不承诺不规则行或整数单元格。

heights记录以当前行为底的各列连续1高度，遇0清零；尾部额外一项0始终作为哨兵。对每一行重新建立非降高度下标栈，较低柱到来时弹出，并用弹出后的栈顶和当前位置确定宽度。任何全1矩形都有某一底行，其高度不会超过这些列的连续1高度，因此逐底行求最大直方图面积覆盖所有候选。实现自包含，不依赖其他题解分支。时间O(行数*列数)，额外空间O(列数)。

独立oracle枚举所有上/下/左/右边界，逐个单元格检查是否全1，不复用高度或栈。行列各1..3的全部682个二进制矩阵核对。边界覆盖200*200全1/全0、按行或按列交替和棋盘格、标准非矩形1区域；空维度单列扩展，核对int及逐行输入保持。
