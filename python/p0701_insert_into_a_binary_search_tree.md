# 701. Insert into a Binary Search Tree · Python

[原题](https://leetcode.com/problems/insert-into-a-binary-search-tree/)。

原题输入为0..10000节点的合法BST，节点值唯一，节点值和待插入val在-10^8..10^8，并保证val尚不存在。返回插入后的BST根。本实现新增一个叶节点，保留全部原节点和值；非空时根对象保持，空树时创建新根。不要求插入后平衡，TreeNode供本地导入。

从根比较val，小于当前值就向左，大于就向右；当前子树边界始终包含所有可能的合法插入位置。对应孩子为空时把新节点接在这里，因沿途每个祖先的大小约束都被保留，结果仍是合法BST。题目保证不存在重复值，所以不额外定义重复插入语义。只走一条根到空孩子路径，时间O(h)，除返回中新增节点外额外空间O(1)，不递归。

独立测试完整扫描结果并检查中序严格有序值等于原集合加val，原节点全部保留且val不变，恰多一个新节点。枚举0..7节点全部BST形状，在已有偶数key之间及两侧插入每个奇数间隙，共4707次；另测10000节点左右深链、空树和合法值域两端。输入规模上限指插入前节点数，最大样本输出有10001个节点。
