# 576. Out of Boundary Paths · Python

[原题](https://leetcode.com/problems/out-of-boundary-paths/)。

网格m×n，1<=m,n<=50，起点在网格内，0<=maxMove<=50。每步选择四个方向之一，统计至多maxMove步内首次移出网格的路径数，模1000000007。球一旦越界路径就终止，不能继续移动后把同一次逃出重复算成更长路径；maxMove=0无解返回0。

current[r][c]表示恰走过当前步数、始终留在格内且终点为该格的路径数，初始只有起点为1。下一步枚举格子和四方向：仍在网格内则累加到新的一层following，移出则加入escaped并不再传播。不同方向是不同路径，即使单行网格的上、下都会越界，也应分别计数。

按步数归纳，每条尚未越界的路径都有唯一的上一格和最后方向，因此状态恰好覆盖所有存活前缀。每条有效答案也有唯一的首次越界步，正好在那一轮加入escaped一次。累加各轮即得到至多步数的总数，而非仅恰好maxMove步的答案。新旧层分离防止一轮内多次移动，逐次取模利用加法同余保持最终模值正确。

时间O(maxMove*m*n)，额外空间O(m*n)，保留两层网格即可。所有状态与返回值都是整数，落在模数范围内；输入仅有整数参数，保持无全局状态。

独立小规模oracle递归枚举四方向路径，越界立即返回1、步数用尽则返回0，不保存滚动格计数。对1..3行、1..3列所有起点和0..6预算共252组逐项比较。边界以相同递归定义的缓存精确整数计数先不取模，核对50×50网格50步的中心/角落及单行50列，另测1×1、0预算和样例。精确整数超过模数时再取模与实现比较，覆盖模运算。未向LeetCode提交。
