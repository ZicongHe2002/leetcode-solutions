# 589. N-ary Tree Preorder Traversal · Python

[原题](https://leetcode.com/problems/n-ary-tree-preorder-traversal/)。

给定0..10000个节点的N叉树，节点值0..10000，高度不超过1000。使用平台Node(val,children)接口，返回先序值列表：先访问当前节点，再按children的原顺序完整访问每棵子树。题面序列化中的null只是孩子分组标记，不是要访问的节点值。空根返回空列表，叶子的children为None或空列表均按无孩子处理。

先把根值写入结果，pending中保存从根到当前节点的孩子迭代器。栈顶每取到一个child，就先输出它的值，再压入它的孩子迭代器，暂停父迭代器。因此该孩子的全部后代完成前不会取父节点的下一个孩子；迭代器用尽才弹出并返回父层，恰好复现先序定义。

next的默认值None表示迭代结束，合法children只包含实际Node，所以不会与孩子混淆。每次只保存一个迭代器而不是把宽节点的全部孩子压栈，10000节点星形也无需O(N)待处理引用；深度1000使用显式栈，不受Python函数递归限制。迭代器不会反转或改写原children列表。

每节点输出一次，每条孩子边推进一次，时间O(N)。除返回列表外，迭代器栈额外空间O(H)，H为树高；返回结果占O(N)。相同值的不同节点仍分别输出，不做按值去重。
