# 551. Student Attendance Record I · Python

[原题](https://leetcode.com/problems/student-attendance-record-i/)。

给定长度1..1000、仅含A/L/P的考勤字符串。获奖资格要求总缺勤A严格少于2次，且从未出现至少3天连续迟到L；两个条件必须同时成立。迟到总次数不受限制，只限制连续段；字符串保持，返回bool。

用count统计全记录A的数量，判断是否小于2。连续L段长度至少3，当且仅当字符串中包含固定子串LLL，因此第二条件直接检查LLL不存在。A或P都会打断连续L，但只有A计入全局缺勤数，不能把连续缺勤误当总缺勤条件，也不能把所有L的数量限制为2。

两个布尔条件用and连接，缺勤已经失败时可以短路，不必再查迟到；短路只减少工作，不改变必须同时满足的含义。固定三字符模式的子串查找与计数总时间O(N)，辅助空间O(1)，不构造按天状态表、切片或替换后的字符串。

独立参考逐日维护全局缺勤数和当前连续迟到长度，遇到非L重置迟到段，任一阈值越界即失败，不调用count或子串搜索。A/L/P、长度1..9的全部29523条记录逐个对照。另测1000字符、缺勤0/1/2次、连续迟到段恰2或3、被A/P打断的迟到及原例，核对bool。未向LeetCode提交。
