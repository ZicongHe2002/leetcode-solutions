# 542. 01 Matrix · Python

[原题](https://leetcode.com/problems/01-matrix/)。

二值矩形矩阵至少有一个0，m、n均为1..10000且mn<=10000。返回每个位置到最近0的四方向步数；保留输入，返回独立矩阵及互不共享的结果行。本实现额外支持[]和空行，不承诺合同外无0矩阵的距离。

把全部0设为距离0同时入队，其余距离-1表示未发现。按FIFO取点时，只给尚未发现的四邻居赋当前距离加1并入队。初始队列距离全为0，后续队列距离始终非递减；首次发现一个点时，任何更短路径的前驱早已被处理，因此首次距离就是到任一0的最短步数。至少一个0且矩形内没有障碍，所有位置最终都能到达。每点至多入队一次并检查四邻，时间O(mn)，额外空间O(mn)，包含结果矩阵和队列。

独立oracle枚举全部0坐标，逐点取曼哈顿距离的最小值；没有障碍的矩形中曼哈顿路径可实现。枚举六种小形状的全部非全1二值矩阵共660个，另穷举4x4中65535个含0矩阵，共66195个。固定测试覆盖多个等距0、全0、空扩展、1x10000/10000x1的9999距离端点、100x100单角0；验证输入保持及结果不共享行或输入。
