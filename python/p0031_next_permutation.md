# 31. Next Permutation · Python

[原题](https://leetcode.com/problems/next-permutation/)。

原题nums长1..100，值0..100，原地改为字典序的下一排列；已经最大时改为升序最小排列，不返回新数组，只用O(1)额外空间。

从右找第一个严格上升对，其左端pivot前面的前缀可以不动，pivot右侧是最长非递增后缀，已没有仅修改该后缀就能得到的更大排列。要得到最接近的更大排列，须把pivot换成后缀中最小的严格较大值；从右找首个大于pivot的元素即可，因为后缀非递增。交换后后缀仍非递增，反转为非递减即可得到这个新前缀下最小的后缀。

若没有pivot，整个数组已非递增，反转全数组回到最小排列。严格/非严格比较分别让重复值不会被当作有效增大。扫描、找后继和双指针反转各O(n)，总时间O(n)，额外空间O(1)，没有切片复制或排序后缀，方法返回None。

独立oracle对0/1/2的所有长度1..7多重集合枚举去重排列并按字典序排序，然后逐项核对环形后继；共3279个不同输入数组，不复用pivot算法。长度100覆盖升序末项交换、全降序回卷、全相等，另有重复后继与单元素，核对输入完整结果及None返回。
