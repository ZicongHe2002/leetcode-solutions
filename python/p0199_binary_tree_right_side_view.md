# 199. Binary Tree Right Side View · Python

[原题](https://leetcode.com/problems/binary-tree-right-side-view/)。

输入二叉树有0..100节点，值在[-100,100]，返回从右侧看到的逐层节点值。右视图按每层最右的实际节点定义，缺少右分支时可能来自左子树；空树返回空列表。实现不改变任何原节点或链接。

栈记录节点与深度，先压左再压右，使右子树先被弹出。深度优先遍历在同一深度总是从右向左第一次到达，所以只有depth等于当前结果长度时才记录，后到的同深度节点被忽略；该条件也保证结果顺序按深度递增。左右不对称和右子树较浅时仍会访问左侧更深层。时间O(L)，额外空间O(h)，返回结果另计，显式栈不使用递归。

独立oracle用广度优先遍历取每层最后一个值，不复用右优先深度遍历。枚举长度0..6全部树形与二值赋值，共10067棵，逐次验证原值和左右链接不变。边界覆盖100层左右交替链、100节点完全树、右浅左深的缺口反例、重复值、值两端和空树。
