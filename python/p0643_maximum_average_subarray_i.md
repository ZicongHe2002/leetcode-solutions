# 643. Maximum Average Subarray I · Python

[原题](https://leetcode.com/problems/maximum-average-subarray-i/)。

原题1<=k<=n<=100000，整数元素在-10000..10000，求长度恰为k的连续子数组最大平均值，允许绝对误差小于10^-5。实现保留输入，负数与全负数组均合法；长度不足k不属于输入合同。

所有候选长度相同，所以比较平均值等价于比较整数和。先对前k项求和，使用生成器避免复制k项切片；每右移一次，加入新项、减去刚离开的项，total继续准确表示当前窗口和，best覆盖已出现窗口。初始best必须是第一个真实窗口的和，不能从0开始，否则全负数组会错误返回0。最后只做一次best/k，把整数最优和转成浮点平均值。

首窗口与后续更新共O(n)时间，额外空间O(1)。本题窗口和绝对值最多10^9，Python整数更新精确，最终除法在所需误差内。独立oracle逐个切片求和并以Fraction精确比较，不复用滑动更新。-3/0/4组成的长度1..8共9840个数组、每个合法k共73812次查询全部核对；100000长度另检查全负、两段极值、k=1与k=n及输入保持。未向LeetCode提交。
