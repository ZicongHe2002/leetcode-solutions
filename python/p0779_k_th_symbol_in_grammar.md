# 779. K-th Symbol in Grammar · Python

[原题](https://leetcode.com/problems/k-th-symbol-in-grammar/)。

原题第1行为0，之后每个0替换为01、每个1替换为10。1<=n<=30，1<=k<=2^(n-1)，返回第n行从1开始的第k个符号。不要直接展开最多2^29长度的字符串。

把替换过程看作二叉树：每个符号的左孩子与父值相同，右孩子与父值相反。第n行第k个叶子的路径由k-1的二进制表示给出，补前导零到n-1位；0表示走左、1表示走右。根值为0，每个右分支翻转一次，因此最终值就是k-1中1的个数的奇偶，bit_count后取最低位即可。

n只保证位置合法并决定要补多少前导零；前导零不触发翻转，所以在原题合法k范围内公式不必显式使用n。这里没有定义越界k或非法n的行为，不把忽略合法性参数当作通用无界接口。

置位计数处理至多n-1位，按位工作上界O(n)；原题最多29位，为有界整数的常数工作与额外空间。不存整行、递归栈或路径列表，返回int 0或1。

独立oracle从文本0开始逐行把字符替换为01/10，实际构造前12行并检查全部4095个位置，不使用二进制置位公式。大行再对1000个固定种子合法位置用父节点递归与奇偶子位置翻转核对；边界包括n=1、n=30首末、2的幂前后以及官方例。未向LeetCode提交。
