# 61. Rotate List · Python

[原题](https://leetcode.com/problems/rotate-list/)。

输入无环单链表有0..500个节点，值在[-100,100]，k在[0,2×10^9]。向右旋转k次并返回新头。本实现保留全部原节点身份和值，返回链中每个节点恰好一次且尾部为None；空链、单节点或整圈旋转保留原头。

先定位尾节点并得到长度L，把k减成steps=k mod L。非零旋转时暂时把尾接到原头形成环，再从原头走L-steps-1条边，来到新尾；保存其next为新头，再把新尾next断成None。节点在环中的相对顺序未改变，只切换了起止位置，因此正好把末steps个节点搬到前面。空链和单节点在取模前处理，整圈在接环前返回，最后的断环使输出保持无环。时间O(L)，额外空间O(1)，循环次数与L有关而不是与原k成正比。

独立oracle按目标位置i对应原节点(i-steps)%L构造期望身份序列，不使用接环/断环。枚举-1/0/1上长度0..6的1093条链，对k=0..2L+2共15309次。边界覆盖500节点、k=2×10^9及其前一值、499节点配最大k、单节点、空链与经典例子；身份序列检查最后必须为None，能捕获忘记断环或丢节点，并检查全部节点值保持。
