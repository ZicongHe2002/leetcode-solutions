# 728. Self Dividing Numbers · Python

[原题](https://leetcode.com/problems/self-dividing-numbers/)。

原题1<=left<=right<=10000。自除数的每个十进制位都必须非零，且该位必须整除原来的完整数值。返回闭区间内全部自除数，按枚举顺序递增；不能拿逐步缩短的remaining去检查整除。

对每个候选value，反复用divmod(remaining,10)取个位并缩短remaining。若位为0，短路条件立即退出，避免除零；若value不能被该位整除，也立即淘汰。只有所有位都通过并自然退出while时，else才把value加入结果，break不会执行else。

循环不变量是已经取出的各位都非零且整除原值；自然结束恰好覆盖所有位，所以接受条件与定义等价。range右端用right+1保证闭区间。原题所有候选为正，不存在零没有位而被空循环接受的问题。

设W=right-left+1，D为right的十进制位数，时间O(WD)，除返回结果外工作空间O(1)，结果空间O(W)上界；没有构造每个候选的字符副本。参数值保持。

独立oracle用十进制字符串取各位，先拒绝0，再求这些位的最小公倍数；原数能被这个公倍数整除当且仅当能被所有位整除，不使用逐步取余的淘汰循环。核对1..10000全部单点和1..100内全部5050个闭区间，另覆盖官方区间、包含零位的端点、完整1..10000范围与顺序/唯一性。未向LeetCode提交。
