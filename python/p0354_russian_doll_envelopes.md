# 354. Russian Doll Envelopes · Python

[原题](https://leetcode.com/problems/russian-doll-envelopes/)。

每个信封的宽与高都严格小于另一个信封时才能放入其中，信封不可旋转。原题1..100000个信封，宽高各在1..100000，可能重复。本实现保留输入顺序与各子列表，额外支持空列表返回0。

先按宽升序，同宽按高降序排列。严格嵌套链必然按宽升序出现；同宽块中的高度降序，使任何严格递增高度子序列至多选择该块一个信封。于是严格递增高度子序列与合法嵌套链具有相同最大长度。同宽若也升序，会错误地把[2,2]与[2,3]计作两层。

tails[k]记录已扫描前缀中长度为k+1的严格递增高度子序列可达到的最小末尾。用bisect_left找到第一个不小于当前高度的位置并替换；相等高度只替换，不延长，保持严格性。较小末尾给未来高度留下至少同样大的扩展范围，替换不改变已知长度的可行性。tails本身不必对应同一条实际链，最终长度才是答案。

排序和二分合计时间O(n log n)，排序副本与tails共O(n)额外空间，没有把Python排序存储省略。原列表及信封子列表均不写入。

独立oracle枚举信封下标子集，再直接检查按宽排序后每一对相邻信封的宽高严格增加，不使用LIS或二分。宽高各1/2/3、长度0..4全部7381个有序输入对照，含重复与同宽反例；另测100000层合法链、100000个同宽或同高信封，以及经典交叉宽高例子。空输入属于额外扩展。
