# 4. Median of Two Sorted Arrays · Python

[原题](https://leetcode.com/problems/median-of-two-sorted-arrays/)。

原题两数组分别非递减，长度各0..1000、总长度1..2000，值在-10^6..10^6，求合并序列中位数，要求对数时间。只支持这些前提，两个数组不能同时为空；不修改输入，返回float。

先交换局部引用，让第一个数组较短。取左半总数half=(m+n+1)//2，在短数组选左半长度i，另一个左半长度就是j=half-i。由于m<=n，i在0..m时j始终在0..n。每段内部已排序，因此只需检验两个交叉边界left1<=right2、left2<=right1。前者失败表示第一个数组左半取多了，缩小i；后者失败则增大i。合法划分下左侧最大值不超过右侧最小值；奇数长度返回左侧最大值，偶数返回两侧边界均值。空半段用正负无穷作哨兵，合法非空总输入保证参与最终中位数的边界有限。

二分的候选长度为min(m,n)+1，时间O(log(min(m,n)+1))，当短数组为空时为常数；额外空间O(1)，没有实际合并或切片。独立参考将两数组拼接、排序后调用statistics.median。长度0..4、值-1/0/2的35种非递减数组，两两组合排除双空，共1224次查询。另测两数组各1000项、空侧、奇偶、重复值及值域两端，并核对float和输入保持。
