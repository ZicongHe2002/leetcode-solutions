# 546. Remove Boxes · Python

[原题](https://leetcode.com/problems/remove-boxes/)。

给定1..100个盒子，颜色编号1..100。每次删掉一段连续同色的K个盒子并得K^2分，求删空的最大总分。可以选择延后删除某些盒子，等中间颜色消失后合并。输入数组保持；返回精确整数，不取模。

只有区间左右端点不足以描述状态，因为区间最右颜色可能还会与右侧保留的同色盒子一起删除，附带数量会改变平方收益。best(left,right,carried)表示处理原区间[left,right]，且其右侧已有carried个与boxes[right]同色的附带盒子时的最优分数；这些附带盒子由祖先转移交给当前右端一起处理。顶层附带量为0。

连续相同颜色没有必要拆成几次删除：只删其中一部分不会让两侧其他颜色跨越仍存在的同色块，延后到同一次删除可用(a+b)^2>=a^2+b^2取得不少的分。因此把右端已有的连续同色项压入carried，不改变最优答案，只缩短显式区间。

第一类方案直接删除右端与附带盒子，得(carried+1)^2，剩余左区间独立求best(left,right-1,0)。第二类方案保留右端，选择更早的同色位置middle，先删空中间区间(middle,right)，再把当前右端连同附带盒子交给middle：best(left,middle,carried+1)+best(middle+1,right-1,0)。中间被middle和右端隔开，必须在二者合并前清空，故可独立求最优。

任何最优删除顺序中，右端要么不与更早同色位置合并，要么最终与某个middle合并，上面枚举覆盖两类选择；每个转移的删除顺序也确实可执行。各递归区间严格缩短，缓存相同端点和附带量，避免反复求解。只在一次方法调用内缓存，另一组输入不会继承这些分数。

设N为盒数，左右端点及附带量各有O(N)种取值，状态数上界O(N^3)；每状态尾段归并和同色位置枚举最多O(N)，时间上界O(N^4)，缓存空间O(N^3)，递归深度O(N)。即使归并后的等价状态可能来自不同原始缓存键，这些上界仍成立。不把带内层枚举的实现误写成O(N^3)时间。

独立参考以当前完整颜色序列为状态，枚举每一个合法连续同色子段，包括不是最大同色段的选择，实际删除后递归枚举全部后续顺序，不使用区间端点或carried。颜色1/2/3、长1..7的全部3279个数组逐个对照。另测100个同色、100个不同色、两块同色被中间颜色隔开的100项等场景，参考上界“每色总数量的平方和”且构造可达到该上界；核对原例、int与输入保持。未向LeetCode提交。
