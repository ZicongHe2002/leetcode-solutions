# 695. Max Area of Island · Python

[原题](https://leetcode.com/problems/max-area-of-island/)。

输入是1..50行、1..50列的二值矩形网格，岛屿按四方向相连，返回最大岛屿的单元格数，全水返回0。本实现额外支持空网格返回0，并保留输入数值和各行对象。

按行列扫描尚未访问的陆地，每次使用显式栈完整发现一个连通分量。坐标在入栈时加入visited，避免环路造成重复入栈和重复计数。栈弹出一次就计数一次；终止时，分量中的全部点都因四邻接路径而发现，且不会混入另一岛屿。外层扫描不会重新启动旧分量，largest在每次分量完成后更新。每个单元格外层检查一次，每个陆地最多检查四条边，时间O(mn)，额外空间O(mn)，输入保持；使用栈避免细长岛屿的递归溢出。

独立oracle用并查集合并相邻陆地，再统计各根的成员数，不复用栈遍历。枚举六种形状的全部666个二值网格，另外穷举全部65536个4x4网格，共66202个。固定测试覆盖空图、单点、对角分离、50x50全水/全陆地和棋盘格。每次验证输入数值和行对象身份保持。
