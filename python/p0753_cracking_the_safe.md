# 753. Cracking the Safe · Python

[原题](https://leetcode.com/problems/cracking-the-safe/)。

原题1<=n<=4、1<=k<=10且k^n<=4096，所有长度n、字符0..k-1的密码都必须作为某个连续窗口出现。可以返回任意最短字符串，不要求特定字典序。

把每个长度n-1的后缀看作一个顶点，补入一位digit就是一条对应长度n密码的有向边。顶点用k进制整数表示，下一顶点为(node*k+digit)模k^(n-1)。每个顶点有k条入边与k条出边，且通过补入目标后缀数字能互相到达，因此存在遍历每条边一次的欧拉回路。

从全零后缀开始，用next_digit[node]记录该顶点尚未使用的下一条出边。显式nodes栈保存当前行走路径，incoming保存进入各非初始栈位置的边标签。仍有边就消费一次并入栈，耗尽出边就退栈，把对应进入边的数字加入逆序结果。最终反转退栈结果，得到欧拉行走的边标签，再在前面补初始n-1个零。

每条边唯一对应一个密码，拼接后的每个n窗口正好对应这条边，所以全部k^n密码覆盖且各出现一次。长度为k^n+n-1。任意长度L字符串至多提供L-n+1个长度n窗口，要覆盖k^n种密码必有L>=k^n+n-1，因此本构造达到全局最短。n=1时只有一个空后缀顶点，k=1时也自然得到n个零。

每条边只消费一次、每个栈位置只进出一次，时间O(k^n+n)，空间O(k^n+n)含输出；全程迭代，不会因4096条边的路径深度耗尽Python递归栈。

原题合法(n,k)组合总共只有38种，测试全部枚举。独立检查实际输出的每个n窗口，与直接笛卡尔积生成的全部密码集合比较，并核对字母域、窗口数量和最短长度下界，不实现欧拉算法作为oracle，也不限定某个有效排列。包含4096窗口、十字符字母表、n=1与k=1边界。未向LeetCode提交。
