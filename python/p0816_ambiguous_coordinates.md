# 816. Ambiguous Coordinates · Python

[原题](https://leetcode.com/problems/ambiguous-coordinates/)。

移除外括号，枚举左右坐标的每个非空分界。一个数字串可保持整数，条件是单个0或不以0开头；也可插入一个小数点，条件是整数部分没有多余前导0且小数部分不以0结尾。小数点两侧都要有数字。分别得到两边合法格式后做笛卡尔积，按逗号加空格拼接坐标。不转成浮点数，因此原字符位置和格式约束完整保留。

设内部数字数为m、输出坐标数为K。候选数字格式构造总时间O(m^3)，输出拼接O(Km)；临时候选额外空间O(m^2)，结果空间O(Km)。输入不修改。
