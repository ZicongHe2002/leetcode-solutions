# 115. Distinct Subsequences · Python

[原题](https://leetcode.com/problems/distinct-subsequences/)。

原题s、t长1..1000，含英文字母，统计从s按位置删除字符后恰好得到t的不同选择数，原题保证最终答案落在32位有符号整数范围。相同字符但选取位置不同仍分别计数。实现额外定义空t有一种选择、空s对非空t为0；字符串保持。

counts[j]保存已扫描源前缀形成目标前j字符的选择数，counts[0]=1对应不取字符。读到匹配t[j-1]的源字符，可在旧的j-1长度选择后追加它，也可不使用它并保留旧j长度计数。j必须倒序，确保counts[j-1]仍来自读取此字符之前，避免一个源位置被重复使用。操作次数O(len(s)*len(t))，保存O(len(t)+1)个整数状态；中间前缀计数仍可能超过32位，Python整数精确累加，空间按状态数描述。

独立oracle枚举s的全部位置掩码，把得到的字符串放入Counter，保留重复字符串对应的不同选择数，不复用DP。二字母s长0..7、t长0..4共7905对核对，空串单列为扩展。边界覆盖1000字符、重复字符、目标更长、最终答案为1或1000但中间计数很大的情况，核对int。
