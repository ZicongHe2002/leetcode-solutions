# 772. Basic Calculator III · Python

[原题](https://leetcode.com/problems/basic-calculator-iii/)。

原题有效算术表达式长1..10000，含非负整数字面量、二元+/-/*/、空格和括号；所有中间结果在32位有符号整数范围内，除数非0。乘除先于加减，同级从左结合，除法向0截断。实现也额外支持一元正负号及连续符号，相关测试单列扩展，不把它当作原题必须的输入形式。

用values保存已经求出的操作数，用operators保存待执行运算。数字逐位消费并压入值栈；左括号隔开当前上下文；右括号执行到配对左括号并弹出括号。遇二元运算时，先执行栈顶优先级大于或等于新运算的所有操作，再压入新操作；相等也先执行保证8/3*3等从左结合。末尾清空运算栈。

apply严格先弹右操作数，再弹左操作数，避免减除方向反转。除法先算abs(left)//abs(right)，按符号是否不同决定取负，完全使用整数，避免Python对负数整除向下取整，也不把大整数先转float再截断。负中间结果是原题内行为，即使字面量都非负也必须正确处理。

括号外运算不跨过左括号执行，因此括号内先完成；优先级规则确保每个运算执行时所需左右子表达式均已求好。用expecting_operand区分一元扩展，将一元运算以更高优先级暂存，在数字或完整括号值产生后从栈顶执行，支持括号前负号而不插入改变乘除结合的伪0。

每个字符只消费一次、每个运算符最多入出栈一次，时间O(L)，两栈额外空间O(L)，全程迭代，10000字符范围内的深括号不会耗尽Python递归栈。不调用eval或依赖浮点除法。

独立oracle直接求值预先构造的AST，除法用标准库Fraction的精确有理数再int向0截断，不用两栈或优先级解析。枚举四值0..3、两次运算的全部非零除数合法组合，文本有意不加括号以检查优先级与左结合；另核对200个固定种子合法嵌套AST。边界包含官方例、负中间除法、32位端点、9999字符深括号/长加法；一元正负号仅作额外扩展检查。未向LeetCode提交。
