# 617. Merge Two Binary Trees · Python

[原题](https://leetcode.com/problems/merge-two-binary-trees/)。

两棵输入二叉树各有0..2000个节点，值-10000..10000。从两个根开始按相同左右路径叠合：两边都有节点则值相加，只有一边有则保留该值和该分支。返回合并树，两边都空返回None。使用平台提供的TreeNode(val,left,right)；本实现为输出的每个位置创建新节点，保持两输入，并不与输入共享子树，合并后可独立修改结果。只存在一边的分支也复制。

先创建根的新值，pending保存(第一来源节点,第二来源节点,新目标节点)。弹出一帧，分别看left和right：若两个来源位置都空，不创建孩子；否则新建一个孩子，值为两个来源值之和，缺失来源作0，连接到目标对应侧，再压入这个新位置的帧。数值0与空节点不同，必须通过is None判断存在性。

对路径长度归纳，根值正确，每个已有目标的左右孩子恰在至少一个来源同路径存在时创建，值也遵循相加规则。因此输出形状正好是两棵树路径集合的并集，每个位置恰处理一次。所有赋值只写新建目标，不改来源值或左右指针，也不把来源孩子直接接到输出，保证独立所有权。

显式栈不受2000层输入的Python递归限制。时间O(N1+N2)，其中每个来源节点按自身路径贡献一次。辅助待处理栈O(H)，H为并集树高度；此外输出U个新节点占O(U)，U<=N1+N2，不把新树空间隐藏为常数。重叠节点和可能到-20000..20000，Python整数精确保存。

独立参考把每棵输入转换成从根出发L/R路径到值的映射，对路径并集直接求和，再与输出的路径值映射比较，不递归合并节点。0..3节点、值-1/0/2的157棵树两两组合24649组，允许两输入同为同一对象，仍须保持输入和输出独立。另测两棵2000层链、正负边界相消、2000节点输入分叉形成3999节点并集和样例；核对输入原值/左右引用、输出无环无共享、输出节点与输入身份完全分离。未向LeetCode提交。
