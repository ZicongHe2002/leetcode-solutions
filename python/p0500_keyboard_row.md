# 500. Keyboard Row · Python

[原题](https://leetcode.com/problems/keyboard-row/)。

筛选只用美式键盘同一行字母即可输入的单词，大小写不影响所属行。原题1..20个单词，每词长1..100且仅含英文字母；返回保留原单词的大小写和输入顺序，重复条目按原出现次数保留。输入保持；空词表额外返回空列表，词条仍要求非空。

预建三行小写字母集合。逐字符转为小写后，只需保留该词实际用到的不同字母；若字母集合是某一行集合的子集，全部字符就都在那一行，否则不能接受。不能只看首尾字符，也不能要求与整行集合相等；一个单字母或同字母重复词同样合法。

只在匹配时把原word加入结果，大小写转换的集合用于判断，不替换输出文本。字符逐个lower，不为每个词额外分配完整小写字符串；ASCII字母合同保证转换仍为单个键盘字母。

设总字符数为S，遍历与建集合O(S)，固定3行的子集检查至多26字母，原题词非空使总成本仍为O(S)。键盘与当前字母集合大小受26字母表限制，除结果外O(26)=O(1)辅助空间，结果列表另占O(N)。

独立参考对三行分别使用大小写不敏感、仅ASCII的完整正则匹配，不调用集合子集判断。q/Q/a/A/z/Z、词长1..5共9330个候选，按最多20词分为467个列表对照，覆盖混合大小写与跨行。另测20个100字符词、同词重复、原大小写、空词表扩展和输入保持，未向LeetCode提交。
