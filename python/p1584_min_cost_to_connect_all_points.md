# 1584. Min Cost to Connect All Points · Python

[原题](https://leetcode.com/problems/min-cost-to-connect-all-points/)。

原题1..1000个互异二维点，坐标在-1000000..1000000，任意两点连接成本为曼哈顿距离。求使所有点连通且无环的最小总成本int，输入点和次序不变，单点成本0。

隐式完全图上运行Prim。selected标记已接入树的点，best[target]保存从当前树到它的最小边成本，每轮扫描全部未选点取最小best，再按新点距离更新所有候选。最小跨割边可加入某棵最小生成树，逐轮保持能扩展到最优的性质，选完n点即得到最小成本。单边最多4000000，初始化4000001为严格更大哨兵；除起点0外所有best在首轮就能更新为有限合法距离。时间O(n^2)，额外空间O(n)，未物化O(n^2)条完全图边，Python整数保留精确总和。

独立参考对小点集显式列出全部两点边，排序后用并查集Kruskal，不用Prim候选表。3乘3坐标网格中取1..6个互异点的全部465个子集逐一核对；另测1000共线点、1000对角点、坐标极值对与四角、原题样例，大点集成本由几何跨度的下界及相邻连接构造给出，核对int与输入保持。
