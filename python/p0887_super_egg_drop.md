# 887. Super Egg Drop · Python

[原题](https://leetcode.com/problems/super-egg-drop/)。

原题1<=k<=100个相同鸡蛋、1<=n<=10000层，存在未知临界层f在0..n；超过f会碎，不超过则不碎，求保证确定f所需最少最坏投掷次数。破碎的鸡蛋不能继续使用。

covered[eggs]表示使用当前moves次投掷和eggs枚鸡蛋最多覆盖的连续楼层数。再允许一次投掷时，选择中间测试层，破碎分支能处理旧covered[eggs-1]层，未碎分支处理旧covered[eggs]层，加测试层本身1，所以新覆盖是两旧状态加1。没有鸡蛋或没有次数都覆盖0层。

每轮eggs从大到小更新，使covered[eggs-1]仍是上一次投掷数的旧值；若从小到大会把本轮结果混入，错误超额覆盖。首次covered[k]>=n时此前次数不足、当前次数可覆盖全部n层，正是最小答案。M为返回次数，时间O(k*M)，额外空间O(k)；k=1时M=n，最大10000次。

独立小范围oracle按具体投掷楼层逐一枚举，直接计算1+max(碎后的最少次数,未碎后的最少次数)，以最坏次数最小为准，不复用按次数计算覆盖量。k=1..6、n=1..30共180种状态核对。最大10000层的1/2/3/100鸡蛋边界再用二项式覆盖闭式验证该次数足够而少一次不足，固定答案分别10000/141/40/14；另覆盖已知单层与100蛋两层，核对int及多次调用。
