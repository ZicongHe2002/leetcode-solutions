# 743. Network Delay Time · Python

[原题](https://leetcode.com/problems/network-delay-time/)。

原题有1..n编号的至多100个节点，k为起点，1..6000条唯一有向边，权重0..100。信号沿最短路传播，求全部节点收到信号所需时间，即各点最短距离最大值；有点不可达返回-1。输入边列表保持，实现额外支持空边集，按同一可达性语义处理。

使用Dijkstra最小堆，distance保存当前最好距离；弹出条目若已不同于当前distance则过期，直接跳过。非负边保证最小未处理距离不能被之后更远节点改善，松弛只在严格更小时入堆，零权环不会反复产生相同距离条目。最后忽略未使用的0号槽，取1..n距离最大值。时间O(n+E log(E+1))，辅助空间O(n+E)，包括邻接表、距离数组及堆。

独立oracle用Floyd计算小有向图全部点对距离，不复用堆或Dijkstra。3节点无自环的729个小图（每边缺失、0或2权重）共2187次起点查询核对，其中1个空边图的3次查询属于扩展。边界覆盖100节点、6000边、99边长链、全零权、不可达与过期堆条目，另测试空边集扩展，核对int及边列表保持。
