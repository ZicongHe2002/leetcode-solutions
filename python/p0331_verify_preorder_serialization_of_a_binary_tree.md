# 331. Verify Preorder Serialization of a Binary Tree · Python

[原题](https://leetcode.com/problems/verify-preorder-serialization-of-a-binary-tree/)。

验证逗号分隔的二叉树先序序列是否能构成一棵完整树，整数token表示节点，#表示空孩子。原题保证每个token格式本身是整数或#，输入至多10000字符；需要验证的是树形，不是任意损坏文本的词法。额外将空串定义为False，单个#是合法空树。

开始只有根的一个待填空位。每个token都占用一个空位：空孩子不产生新位置，净减1；非空节点再产生左右两个孩子位置，净增1。若还有token但空位已经为0，则这棵树早已结束，剩余token无处可放；全部token处理后必须恰好剩0个空位，不能遗留未填孩子。

必要性来自每个节点或空孩子对待填位置的真实消耗。充分性则可按先序顺序把每个token填入下一个开放孩子位置，空位始终可用并最终全部关闭，因此存在完整树。不需要在内存中实际构造这些节点或保存父节点栈。

按字符查找逗号与末尾边界，只在token开始位置区分#与整数，不创建split列表或token切片。依赖原题合法token格式；对于非空整数，无需知道具体数值。时间O(n)、额外空间O(1)，既没有递归，也没有把Python split产生的线性存储省略。

独立oracle把小token流按“一个节点后必须递归解析两个子树”的语法消费，最后核对没有多余token，不复用生产空位计数。9/#两种token、长度1..10全部2046种序列核对。另测多位整数、过早结束、缺少孩子、空串扩展及恰好10000字符的2499层合法链，其深层验证不调用递归oracle。
