# 347. Top K Frequent Elements · Python

[原题](https://leetcode.com/problems/top-k-frequent-elements/)。

输入长度1..100000，值[-10000,10000]，1<=k<=不同值数，题目保证top-k答案集合唯一，返回顺序不作承诺。Counter计算频数，再把不同值放入下标等于频数的桶。从n到1扫描频数桶，收集满k个值立即返回。每个不同值只入一个桶，因此没有重复输出。

扫描某频数桶前，更高频的所有值都已输出，更低频的值还未输出。按此顺序收集的k个值频数不低于任意未选值；唯一答案保证选择边界不会截断两个同频且可互换的候选。k合法确保必定返回。平均时间O(n)，桶、计数及输出合计O(n)额外空间，不用排序或堆，也不改原列表。

独立oracle用逐候选的list.count扫描和频数排序生成期望，生产实现使用Counter/桶。穷举三值集合长度1..7全部数组，检查所有满足唯一答案条件的k；不把不唯一答案当成接口承诺。另测100000项的三种明确频数、全相同上界和10000个不同值全部返回。输出只排序比较，保留长度与重复次数，不用set掩盖重复错误。
