# 301. Remove Invalid Parentheses · Python

[原题](https://leetcode.com/problems/remove-invalid-parentheses/)。

从只含括号与小写字母的字符串中删除最少数量的括号，返回全部不同的合法结果，字母不能删除、重排或改写。原题长度至多25且括号至多20；结果顺序不限。额外支持空串，结果为包含空字符串的单元素列表，而不是无结果的空列表。

BFS的一层恰好对应同一个删除数量，level中的集合同时对字符串去重。先检查本层全部候选是否合法；若有合法结果，立即返回本层所有合法字符串，不再生成更多删除的下一层。这样保证结果既包含全部最少删除答案，也不会混入删除更多括号的答案。

合法性按从左到右未匹配左括号数判断：右括号出现时余额不能为0，扫描完余额必须为0。生成下一层时只删除括号。连续相同括号中删除任意一个会得到同一个字符串，因此仅尝试连续段的第一个位置；集合继续合并不同删除次序得到的相同状态。

全部括号都删除后只剩字母，必然合法，因此在本题输入内搜索总能结束。设n为总长度、p为括号数，删除子集最多2^p个；每个状态可能生成O(n)个长度O(n)的候选，保守时间上界O(n²*2^p)，空间O(n*2^p)，包含当前/下一层及结果。没有把最坏指数搜索描述为多项式算法。

独立oracle枚举括号位置的全部删除子集，用前缀和的最小值和终值验证平衡，再选择删除位数最少的一组，不复用生产BFS层或邻接生成。穷举三字符域长度0..7的3280个字符串，核对完整答案集合及去重。另测带字母的多答案、全部字母、25字符/20括号边界、重复段与空串扩展。
