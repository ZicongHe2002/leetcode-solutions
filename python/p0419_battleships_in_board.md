# 419. Battleships in a Board · Python

[原题](https://leetcode.com/problems/battleships-in-a-board/)。

原题棋盘1..200行列，仅X和.。战舰形状必须为连续水平1xk或垂直kx1，不同战舰不能在上下左右直接相邻；按此前提统计舰数，输入保持。实现不承担对弯折、分叉等非法布局的验证。

只统计上方没有X且左方也没有X的当前X格。水平舰只有最左格满足左侧条件，垂直舰只有最上格满足上方条件；合法舰与其他舰分隔，舰首不会被别舰的上/左格排除。因此每艘恰有一个被计数格，其他格至少有一个同舰上/左邻居而被跳过。

单遍扫描，时间O(mn)，额外空间O(1)，无访问标记、递归或棋盘改写，满足原题follow-up。

独立oracle先按四邻连通分量遍历X，再确认每个分量的所有格同一行或同一列。666个小二元棋盘中286个符合直舰合同，逐一核对分量数；380个弯折/分叉布局明确跳过，不当作原题有效测试。最大200x200棋盘覆盖20000艘分隔单格舰、100条长横舰和全空，另有200格纵舰，核对int与输入保持。
