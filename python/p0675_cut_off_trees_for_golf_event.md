# 675. Cut Off Trees for Golf Event · Python

[原题](https://leetcode.com/problems/cut-off-trees-for-golf-event/)。

原题forest为1..50行、1..50列矩阵，0不可通行，1为空地，大于1为可通行的树且高度互异、最大10^9；至少有一棵树。由(0,0)出发，必须按高度递增砍完所有树，返回最少步数，不可达则-1。允许经过尚未轮到砍的高树，站在起点的树可零步砍。本实现只计算步数，保持原矩阵，不实际把高度写成1。

先按高度排序全部树，固定访问目标顺序。砍树前后该格都可通行，整个过程通行图不变，因此可以在原矩阵上反复找路，无需修改高度。若起点是0立即失败。对每对连续目标（首段从起点开始）在四邻接、单位边权图上BFS，入队即标记，首次出队目标时的层数即最短距离。某段搜尽仍找不到就返回-1。

每棵树的砍伐位置固定，任何完整行走在连续砍伐事件之间都至少付出这一段最短路。图不变，各段最短路可直接接起来，哪怕路上经过未来目标也可以暂不砍，所以逐段最短距离之和既是下界又能实现。不能把树高度当行走代价，也不能禁止穿过高树。

设R行C列、T棵树，排序O(T log T)，每段BFS最坏O(RC)，总时间O(RC+T log T+TRC)，额外空间O(RC+T)=O(RC)。矩阵各行及所有元素保持；不存在LeetCode提交记录。

独立oracle为所有可通行格构造完整邻接矩阵，用Floyd-Warshall求所有点对距离，再按高度取出连续砍伐距离，不调用BFS。枚举1x1/1x2/2x2/2x3格的障碍、空地和树分布，对两种相反高度顺序共1472次合法查询；另核对200个固定种子、最多4x4矩阵。50x50边界检查2500树正反顺序、远角单树与断路，另覆盖阻塞起点、零步首树、经过未来高树，并核对全部输入行身份和值保持。
