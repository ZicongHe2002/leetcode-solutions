# 330. Patching Array · Python

[原题](https://leetcode.com/problems/patching-array/)。

向升序正整数数组中添加尽量少的数，使1..n每个整数都能表示为数组某个下标子集的和，每个元素最多用一次。原题数组长1..1000，元素1..10000，允许重复，n在1..2^31-1。升序和正数是必要假设；本实现保留输入，额外支持空数组。

missing是目前尚不能表示的最小正整数，已处理元素恰好保证覆盖[1,missing)。初始只有空子集和0，故missing=1。若下一个原有元素x不超过missing，不选x能覆盖0..missing-1，选x能覆盖x..x+missing-1，两段相接或重叠，因此新覆盖一直延伸到missing+x-1，更新missing+=x即可，不增加补数。

若下一个原数大于missing或原数耗尽，后续原数都无法填当前缺口，必须补入某个不超过missing的数。补入missing使新连续覆盖达到2*missing-1；任何更小的补数一次只能延伸到missing+x-1，不会覆盖得更多。用missing替换一个较小的选择不会缩小连续已覆盖范围，因此逐步选择最大合法补数具有最优性。missing超过n即已覆盖所有目标，无需继续处理更大的输入。

每个原数至多消耗一次，每个补数使missing翻倍，补数至多O(log n)个，时间O(m+log n)，额外空间O(1)。Python整数可安全表示大于32位目标的覆盖右端。

独立oracle用位集合表示真实可达子集和，再通过BFS枚举补入1..n任意数的所有不同可达状态，求最小补数，不使用最小缺口或覆盖连续区间贪心。1..6的非降数组、长度0..4共210个输入，对n=1..10全部2100项查询核对。另测原数重复、值过大、数组1000项、32位最大n与空数组扩展。未向LeetCode提交。
