# 456. 132 Pattern · Python

[原题](https://leetcode.com/problems/132-pattern/)。

判断是否存在i<j<k且nums[i]<nums[k]<nums[j]，也就是按下标先1、再3、最后2的严格大小模式。原题长度1..200000，元素-10^9..10^9。输入保持，空数组额外返回False；相等值不能替代任一严格不等号。

从右向左扫描。descending按值非递增保存尚待配对的右侧元素；当前值比栈顶大时，将较小栈顶弹出，这就构成当前下标j与右侧下标k的合法3/2组合。middle保存已经确认的所有这种组合中最大的2值，None表示尚无组合。每个middle都带有真实的右侧3/2见证，而非凭空猜测。

扫描到更左的值时，若它小于middle，就与对应的右侧见证组成完整132。反过来，任一潜在模式的2值要么仍留在栈中并在它的3被扫描时弹出，要么更早已被另一个更左且更大的3配对；两种情形都会让middle至少达到该2值。所以当它的1被扫描时必能识别。保留最大middle不会失去可行1，while与最终比较都用严格不等号以排除重复值误判。

每项入栈一次、至多出栈一次，总时间O(n)，栈最坏O(n)辅助空间。reversed只提供逆向迭代，不复制或翻转输入；没有对全部三元组作生产搜索。

独立参考枚举全部i<j<k，直接检查三个原值的不等式，不使用栈或middle。-1/0/2、长度0..8全部9841个数组对照，空数组为扩展。另测200000项单调升/降序、两端数值界构造的真模式、重复相等值和经典例子，检查输入保持。未向LeetCode提交。
