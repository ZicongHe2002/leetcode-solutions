# 946. Validate Stack Sequences · Python

[原题](https://leetcode.com/problems/validate-stack-sequences/)。

原题pushed长1..1000，元素为0..1000且互不相同，popped是其等长排列；判断空栈按pushed顺序压入、适时弹出能否产生popped，返回bool。不修改两个输入列表。

逐项压栈后，只要栈顶等于popped中下一待弹出值就立即弹出。互异值条件下，如果栈顶正是目标，先压别的元素只会把目标挡住；可行序列最终必须先移走上方元素才能弹出目标，但下一输出已经指定为该目标，因此此时立即弹出是必需且安全的。栈顶不等于目标时只能继续压入；所有输入处理完后，若目标尚未全部弹出就不可能实现。每个值压入弹出至多一次，时间O(n)，额外空间O(n)。当next_pop达到n时已弹出全部n个输入，栈必为空，while短路避免越界。

独立参考在固定压入次序下枚举所有合法push/pop交错，收集其完整输出排列，再对长度1..7的全部5913个排列核对集合成员关系，不按目标排列贪心模拟。另测1000个互异值、顺序/逆序/受阻排列、0及1000边界和非排序压入次序，同时核对bool与两个输入保持。
