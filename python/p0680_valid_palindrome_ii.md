# 680. Valid Palindrome II · Python

[原题](https://leetcode.com/problems/valid-palindrome-ii/)。

原题s长1..100000，仅小写英文字母，允许至多删除一个字符；已经回文可以不删。返回bool，不修改字符串。

左右相等时保留这一对并内缩，不消耗删除机会。第一次不等时，有效方案必能选择删除当前左端或右端之一；否则这一对仍不相等。此前已匹配的对可以保留，将一次删除留给首个冲突。两个候选区间分别用不再允许删除的双指针检查，任一回文即成功，不递归展开更多删除。

外层与最多两个后续区间扫描合计O(n)，固定数量索引且无切片，额外空间O(1)。helper只读取原s，函数栈深度固定，不产生长度相关递归。

独立oracle逐个枚举删除位置并用切片反转判回文，同时单列不删除情况，不复用首冲突分支。abc长度1..8共9840串逐一核对；100000长度含已回文、首尾可删、内部可删和仍需多次删除的情况，检查bool。测试oracle为小输入允许额外分配。
