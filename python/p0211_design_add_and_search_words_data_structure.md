# 211. Design Add and Search Words Data Structure · Python

[原题](https://leetcode.com/problems/design-add-and-search-words-data-structure/)。

原题接口WordDictionary()、addWord(word)、search(word)，单词/模式长度1..25，插入内容仅为小写字母，搜索还可含点号且至多2个点号，总调用至多10000次。点号匹配恰好一个字符；addWord返回None、search返回bool。

插入按字母路径建立字典树，用None键标记完整词尾。搜索维护已经匹配模式前缀的候选节点集合：普通字母只沿同名字母边，点号则沿所有字母边展开，明确排除None结束标记。没有候选就失败，模式全部消耗后还必须至少有一个候选带词尾标记，防止把某个较长词的前缀误当成匹配。

插入长度L的词需要O(L)。设搜索点号数为d，候选分支最多26**d，搜索最坏O(L*26**d)，临时候选空间O(26**d)；原题d<=2，字典树存储随不同前缀总量增长。过程迭代执行，重复插入幂等。

独立oracle只保存字符串集合，逐词比较长度和各字符是否相等或为点号，不使用字典树。a/b长度1..2的6种词构成全部64个字典，配对长度1..3且至多2点的38种模式，共2432查询。另有恰10000调用的实例，覆盖25字符、重复插入、两点通配、前缀不等于完整词及不存在的长词；全部查询遵守点号数量限制。
