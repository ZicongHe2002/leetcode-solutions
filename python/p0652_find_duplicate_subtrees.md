# 652. Find Duplicate Subtrees · Python

[原题](https://leetcode.com/problems/find-duplicate-subtrees/)。

原题输入1..5000个节点的二叉树，节点值-200..200。重复子树必须同时满足结构、左右方向和节点值相同；每种重复类型只返回任意一个原子树根，不按重复出现次数反复输出。节点接口由LeetCode提供val/left/right。实现保留所有节点值、引用与边；额外支持空树返回[]。

用0编号表示空子树，非空子树由(节点值,左子树编号,右子树编号)三元组唯一表示。后序处理保证两个孩子的编号已确定；相同三元组共用一个递增编号。归纳上，空子树匹配正确，两个非空子树三元组相同当且仅当根值相同且有相同左右子树，故编号恰好表示完整的带值有向结构，不会把左独子和右独子混为一谈。

显式栈先压节点的展开标记，再压右、左孩子，避免5000层树依赖Python递归上限。node_ids按id(node)记编号，不要求外部TreeNode实现可哈希或值相等语义；整棵树的节点仍被根引用持有，处理时身份不会复用。计数到2时才把当前原节点加入输出，之后3、4次均不再加，既保留原节点身份又去掉重复类型。

三元组固定长且仅包含有界值/整数编号，字典操作期望O(1)，总时间期望O(n)，额外空间O(n)，不构造深链上总长O(n²)的完整子树字符串。显式栈、身份表、类型表和计数均计入空间。

独立小输入oracle对每个原节点直接递归展开嵌套元组，按整个结构计数，不使用编号驻留。全部0..6节点树形与-1/1标签共10067种输入（含1个空树扩展）逐一比较重复类型集合，核对返回对象来自输入、每类只出现一次及全部原边/值保持。大边界另查5000层同值单链无重复、4095节点完全同值树的11类重复，以及4999节点双2499层同值链的2499类重复，后者通过逐根检查链长验证，不对深链递归。未向LeetCode提交。
