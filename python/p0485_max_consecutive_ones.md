# 485. Max Consecutive Ones · Python

[原题](https://leetcode.com/problems/max-consecutive-ones/)。

原题非空数组长1..100000，每个值为0或1，返回最长连续1段的长度，不能删除或翻转0。输入数组内容与顺序保持。本实现额外定义空数组返回0，不承诺其他值。

run表示以当前位置结束的连续1段长度。遇到1就从上一段加1，遇到0则段立即断开为0；best保存此前全部结束位置的最大run，最后自然包含末尾未遇0的段。每个元素处理一次，时间O(n)，额外空间O(1)，不需要索引回退或创建分段列表。

独立oracle把二进制数组转为文本，按0分割后取最长段，不复用运行长度状态。枚举长度0..12的全部8191个二进制数组，空数组为扩展，逐次检查输入保持与int类型。边界覆盖100000个1、100000个0、100000交替值，以及末尾最长段。
