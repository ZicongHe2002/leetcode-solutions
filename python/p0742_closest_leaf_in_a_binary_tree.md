# 742. Closest Leaf in a Binary Tree · Python

[原题](https://leetcode.com/problems/closest-leaf-in-a-binary-tree/)。

原题有1..1000个节点、值1..1000且互不相同，k保证存在。叶子必须在原树中没有左右孩子；返回到k边数最少的叶子值，并列可返回任意一个。最近叶子可能需要先向父节点走，而非只在k的子树内寻找。

先迭代遍历原树，把每条父子边加入双向邻接表，同时按原始左右孩子都为空记录叶子集合。值唯一，因此可直接用值标识节点，不依赖TreeNode对象是否可哈希。根只有一个孩子时在无向图中度为1，但不是叶子，不能用图度数代替原树叶子定义。

从k开始标准BFS，首次入队就标记seen，按层扩展所有父子邻居。BFS出队顺序的距离不下降，所以首次出队的原树叶子具有全局最小边数。只返回这个叶子值，不额外要求字典序或数值最小。有限连通树必有叶子，且k存在，因此一定能在循环中返回。

建图、BFS各O(n)，总时间O(n)，邻接表、栈、队列与seen合计空间O(n)。两阶段都迭代，1000节点链不会耗尽递归栈；输入节点、值和连接保持。TreeNode由LeetCode环境提供。

独立oracle记录从根到每个节点的路径，对k路径与每条叶路径求最长公共前缀，由两段剩余长度计算树距离，不做从k的BFS。枚举1..7节点所有625个有序二叉树/4081个k查询，期待值是全部最近叶子集合，允许任何并列答案。另核对官方向祖先绕行样例、根度为1不能当叶子、单节点、1000节点左右链及原节点身份/边保持。未向LeetCode提交。
