# 527. Word Abbreviation · Python

[原题](https://leetcode.com/problems/word-abbreviation/)。

给定1..400个互不相同的小写单词，每词长2..400，按原下标返回最短无冲突缩写。初始保留首尾，中间写省略数量；冲突的词不断增加保留前缀，最终不比原词短就保留原词。输入单词列表保持，不把相同内容的重复条目当作本题合法输入。

缩写中的前缀和尾字符只有字母，中间数量只有数字，因此相同缩写必须有相同的前缀长度、省略数量与尾字符，也就必有相同原长度、首字符和尾字符。先按这三个属性分组，组间不会冲突。原词没有数字，也不会与含数字的缩写冲突。

在同组中，某词与另一词共享k个开头字符时，两者至少要保留k+1个字符才能分开；在此之前它们一直属于同一冲突组。每个词所需的最短前缀，就是它与同组其他词的最大公共前缀长度加1，至少为1。

把同组词按字典序排列后，最大公共前缀一定出现在相邻前驱或后继之一：与某词共享指定前缀的所有词形成一个连续区间，若有更远词共享，该方向的相邻词也共享。只计算每对相邻词的公共前缀，把所需长度同时更新给两端，再按原下标生成结果。互异输入保证公共前缀短于整词；同组尾字符相同，最迟保留到倒数第二个字符即可区分。

省略数量removed至少为2时，十进制数字位数严格小于被省略字符数，缩写才更短；removed为0或1时直接保留原词。这也覆盖单词很长、数量有多位数字的情况，不靠固定总缩写长度作判断。

设N为词数、L为最大词长。排序字符串比较最坏扫描L个字符，总时间上界O(N*L*log(N+1))；相邻公共前缀与结果构造再用O(N*L)。除返回字符串外，分组、排序引用和前缀表共O(N)，临时字符串最多O(L)，辅助空间O(N+L)；返回结果自身最坏O(N*L)。不改输入。

独立参考从全部前缀长度1开始，每轮直接生成所有缩写，用计数表找出冲突者并只增加它们的前缀，不排序也不计算公共前缀。a/b单词长2..5共60种，所有大小1..3的不同单词子集共36050个对照。另测400词/400字符且需保留原词、双向输入顺序、原例和多位省略数量，核对结果唯一与输入保持。未向LeetCode提交。
