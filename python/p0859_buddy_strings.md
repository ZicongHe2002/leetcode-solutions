# 859. Buddy Strings · Python

[原题](https://leetcode.com/problems/buddy-strings/)。

原题s和goal长度分别1..20000，仅小写字母。必须选两个不同下标交换恰好一次；s已经等于goal时也需要一次合法交换，不能把零次交换算成功。

长度不等不可能。记录不匹配位置，第三处立即失败，因为一次交换最多改变两个位置。恰两处时，两字符必须交叉等于goal。恰一处不可能。零处时只能交换两个相同字符才能保持串不变，故检查是否存在重复字母；单字符和全不重复串返回False。

遍历和至多一次集合构造共O(n)。mismatches至多存3个下标即返回，set最多26字母，在合同固定字母表下额外空间O(1)。不改输入，返回bool。

独立oracle枚举所有i<j、实际交换副本并比较，不复用不匹配数定理。abc长度1..5，各相同长度的有序对共66429次，含相同串、有重复、仅一处差异和三处以上差异。另测20000长度、两端交换、全同字母、重复字母等串及长度不等。
