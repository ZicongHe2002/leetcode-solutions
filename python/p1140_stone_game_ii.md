# 1140. Stone Game II · Python

[原题](https://leetcode.com/problems/stone-game-ii/)。

原题1..100堆，每堆1..10000颗石子，从前端取连续X堆，1<=X<=2M，初始M=1，之后M=max(M,X)。Alice先手，双方最优，返回Alice最多得到多少石子。不能取后端，也不能把下一轮M固定成当前X。输入保持。

suffix[index]保存剩余总石子数，best(index,limit)表示轮到的一方从该后缀和当前M能保证的最多石子。如果能一次取完，正值石子使拿走全部最优；否则枚举taken，下一方能保证best(index+taken,max(limit,taken))。所有剩余石子最终在两人间分完，当前方得分就是剩余总数减去下一方得分，因此减去这些选择中的最小值。

状态不必另存当前是Alice还是Bob，因为best始终从当前行动者视角定义，首次状态对应Alice。缓存只在本次方法调用内使用，不修改piles。保守时间上界O(n³)，缓存O(n²)，后缀表及递归深度O(n)，整体额外空间O(n²)；n<=100时递归深度在原题范围内。

独立oracle显式保存Alice/Bob轮次，每次真的累加拿取前缀的石子；Alice最大化自己的最终绝对得分，Bob最小化Alice得分，不复用当前行动者的后缀相减公式。值1/2/3、长度1..7全部3279个数组核对。最大100堆全10000和1..100不同值、单堆与样例也用明确轮次参考或固定期望检查，核对int、M扩张和输入保持。
