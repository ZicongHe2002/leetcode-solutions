# 410. Split Array Largest Sum · Python

[原题](https://leetcode.com/problems/split-array-largest-sum/)。

把非空数组按原顺序分成恰好k个非空连续段，使最大段和最小。原题长度1..1000，元素0..1000000，1<=k<=min(50,n)。非负值与k不超过长度是本实现的合同，输入保持；空数组和负数不属于合同。

答案下界是最大元素，上界是总和。对给定容量limit，按顺序把元素尽量放进当前段；下一个元素会超限时新开一段。每个元素本身都不超过limit，所以能得到有效分段。非负值保证贪心首段可延伸到任何其他合法首段的结束位置或更远；删去该前缀后归纳，贪心使用的段数最少。

若最少段数不超过k，可以把某些段进一步拆开，直到恰好k段；因为k<=n，始终有足够元素，因为非负，拆开不会增大任何段和。容量越大，所需最少段数不会增加，因此可对可行容量作二分。可行时保留当前上界，不可行时下界移到limit+1，终止时得到最小可行值。

设S为总和，M为最大元素，时间O(n log(S-M+2))，额外空间O(1)。其中包含初始最大值/总和的线性扫描；S=M时区间只有一个值，不进入二分循环。全0数组自然返回0。没有对所有切点或数组副本作生产搜索。

独立参考枚举k-1个实际切点，逐段重新求和，再在所有切分中取最小最大值，不使用贪心可行性或二分。0/1/3、长度1..7全部3279个数组，对每个合法k共21324项查询核对。另测1000项、k=1、k=50、长度50时逐元素分段、全0和单个大值。未向LeetCode提交。
