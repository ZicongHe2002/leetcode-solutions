# 437. Path Sum III · Python

[原题](https://leetcode.com/problems/path-sum-iii/)。

输入二叉树有0..1000节点，值在[-10^9,10^9]，targetSum在[-1000,1000]。统计和等于目标的向下非空路径，起点和终点可在树内任意位置，但不能跨兄弟分支或向上走。返回int，空树为0，输入节点值和链接保持。

进入一个节点前，prefixes只统计当前祖先路径上的前缀和，含空前缀0的一次。当前累计和为total时，之前每个total-targetSum前缀恰对应一个以当前节点结束的合法非空路径；先查询再加入当前前缀，避免targetSum=0时数出空路径。显式栈追加退出事件，确保两子树处理完就撤销该节点的前缀计数，兄弟子树不会共享错误历史。时间平均O(L)，除返回整数外额外空间O(h)，使用哈希表和显式栈，不受递归深度限制。

独立oracle枚举每个原节点作为起点，再遍历所有后代累计值，不使用前缀表。枚举长度0..5的全部树形与-1/0/1赋值，11497棵树分别对目标-2..2检查，共57485次；逐次核对输入保持和int类型。边界覆盖1000节点全零链的500500条路径、±10^9交替链抵消、目标两端、兄弟重复前缀、经典分叉与空树，捕获忘记退出回滚或先插入再查询的错误。
