# 827. Making A Large Island · Python

[原题](https://leetcode.com/problems/making-a-large-island/)。

在方形二值网格副本中，用迭代栈把每个四邻岛屿标为独立编号并记录面积，入栈就编号，防止重复入栈。翻转一个0后，新岛只可能由该格和相邻的原岛组成；先对四邻编号去重再累加面积，避免同一岛从两个方向接触时重复计数。保留原最大岛面积作为不翻转的候选。全1时直接保持整岛面积，全0时任意候选产生1。

每格遍历常数次，时间O(n^2)，副本、编号面积表和显式栈总额外空间O(n^2)。不修改原网格，避免对大岛使用递归DFS。
