# 50. Pow(x, n) · Python

[原题](https://leetcode.com/problems/powx-n/)。

原题-100<x<100，指数为有符号32位整数；x为0时保证n>0，最终数学结果在-10000..10000内。返回浮点幂值，使用通常的浮点近似；0的非正指数不在原题合同内。

负指数先将底数取倒数，指数转成非负。Python整数可直接表示-(-2**31)，不会发生32位取负溢出。循环不变量为result乘当前底数的剩余指数次方等于目标：当前指数奇数时先把一个底数乘入result，随后底数平方、指数整除2。循环结束剩余指数为0，result就是所求。指数为0直接返回1.0；负底数的符号由指数奇偶自然保留。

二进制每轮消去一位，时间O(log(abs(n)+2))，辅助空间O(1)。浮点乘法存在舍入误差，极小结果可以下溢到0；不声称精确有理数运算。

独立oracle使用Python内置pow，对7种底数与-8..8指数的110个合法组合以相对1e-6、绝对1e-9容差核对。边界覆盖32位最小/最大指数、底数1/-1、极小幂下溢、接近100的平方以及接近1的长指数。全部输入遵守零底数和最终结果范围约束。
