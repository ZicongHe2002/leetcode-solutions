# 263. Ugly Number · Python

[原题](https://leetcode.com/problems/ugly-number/)。

原题n在-2^31..2^31-1，ugly number必须为正，且质因子只能为2、3、5。1没有质因子，因此符合定义；返回bool，0和负数不符合。

先拒绝非正数，再依次除尽2、3、5。除去允许质因子不会改变是否含有其他质因子：若末尾剩1，原整数由这些允许因子的幂相乘构成；若还大于1，剩余整数必含允许集合以外的质因子。正数每次除法至少缩小一半，总除法次数O(log n)，额外空间O(1)。最初的正数检查同时避免0在整除循环中永远不变。

独立参考从2起做一般试除以发现实际质因子，发现非2/3/5因子即拒绝，最后检查剩余质数；参考不只按允许因子剥离。核对-1000..10000的11001个整数；另测1、纯2/3/5幂、混合允许因子、带7或11的大值及32位端点，核对bool。全部运算用整数除法。
