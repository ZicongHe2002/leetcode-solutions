# 495. Teemo Attacking · Python

[原题](https://leetcode.com/problems/teemo-attacking/)。

攻击发生在非递减时间序列timeSeries，每次使目标中毒duration秒；中毒时再攻击会刷新结束时刻，重叠秒只计一次。原题1..10000次攻击，时间和duration均0..10000000，时间允许相等。输入保持；空时间序列额外返回0。

在整数秒表示中，时刻t攻击覆盖t..t+duration-1；等价半开区间[t,t+duration)。对于最后一次攻击，它的duration全部属于总覆盖。其他一次攻击在下一次开始前独有的时间是min(duration,next-current)：下一次很远时本段完整保留，较近时只保留两攻击间距，重叠尾部由后续区间统一负责。

因此从duration开始，加上每对相邻攻击的间距与duration的较小值。所有间距非负，重复时间贡献0，不会把同一秒重复计算；duration=0时所有贡献都是0。相邻区间恰好首尾相接时gap=duration，仍完整计入，两段没有重叠。时间已有序是正确性的前提，不在函数里排序或改写输入。

一次扫描相邻下标，时间O(N)，辅助空间O(1)。没有构造每个中毒秒、区间列表或切片副本，时间坐标很大也只处理N次攻击。

独立参考把每次攻击实际覆盖的整数秒加入集合，再取并集大小，不使用相邻间距公式。时间0..5的非递减列表长度0..6共924种，各测duration=0..5，共5544次对照；空列表为扩展。另测10000次攻击、最大时间/时长、重复、首尾相接与大间隙，核对int和输入保持。未向LeetCode提交。
