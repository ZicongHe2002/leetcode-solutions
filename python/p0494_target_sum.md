# 494. Target Sum · Python

[原题](https://leetcode.com/problems/target-sum/)。

原题nums含1..20个非负整数，各值不超过1000且总和不超过1000，target在[-1000,1000]。给每个位置分别选择+或-，返回得到target的符号方案数；相同数在不同位置仍是不同选择，+0与-0也分别计数。原数组保持，不承诺负数元素。

设正号位置之和为P，全部值之和为S，则P-(S-P)=target，所以P=(S+target)/2。若|target|>S或S+target为奇数就不可能；否则统计各位置只选一次、总和为P的子集。每个value处理时从容量向下更新，避免同一位置重复选用。value=0时每个状态恰翻倍，正确计入+0/-0，不跳过零。时间O(len(nums)·(P+1))，额外空间O(P+1)，P不超过S。

独立oracle枚举每个位置的全部±1赋值，直接计算有符号总和的频次，不复用子集转换。枚举长度1..6、值0/1/2的1092个数组，对目标-6..6共14196次核对，检查int与输入保持。边界覆盖20个零的1048576方案、1000加19个零、20个相同值的组合数期望、奇偶不可达及目标正负端点。
