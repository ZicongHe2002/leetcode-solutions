# 509. Fibonacci Number · Python

[原题](https://leetcode.com/problems/fibonacci-number/)。

计算F(0)=0、F(1)=1、F(n)=F(n-1)+F(n-2)。原题n是0..30的整数；不定义负数或非整数输入。返回整数，不使用浮点Binet公式。

current/following始终表示已读取二进制前缀k对应的F(k)/F(k+1)，初始k=0。倍增恒等式给出F(2k)=F(k)*(2F(k+1)-F(k))和F(2k+1)=F(k)^2+F(k+1)^2。它们可由斐波那契加法公式推出，第二式把相同前缀相加，第一式再用F(k-1)=F(k+1)-F(k)化简。

从高位到低位读n。下一位为0时前缀变2k，保存两个倍增值；为1时前缀变2k+1，保存F(2k+1)及F(2k+2)=F(2k)+F(2k+1)。每轮同时更新一对状态，不能让后一个赋值误用已经更新的current。所有位读完，current就是F(n)。

n=0的bit_length为0，循环为空，直接返回0；n=1按单个位处理。轮数O(log(n+1))，固定数量整数状态，辅助空间O(1)，这里按整数运算次数计；原题范围很小，Python整数可精确保存全部中间结果，不靠近似取整。

独立参考把F(n)解释为长n-1区间用1格与2格块铺满的方案数：若放t个2格块，总块数n-1-t，选出其中t个位置，方案为组合数C(n-1-t,t)，对全部t求和；F(0)单独为0。不使用递推或倍增。从0到30全部31个合法输入逐项对照，并检查int接口、边界0/1/2和F(30)=832040。完整覆盖原输入合同，未向LeetCode提交。
