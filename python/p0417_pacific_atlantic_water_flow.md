# 417. Pacific Atlantic Water Flow · Python

[原题](https://leetcode.com/problems/pacific-atlantic-water-flow/)。

输入非空矩形网格，行列各1..200，高度在[0,100000]。水能向上下左右的等高或更低格子流，左/上边界接太平洋，右/下边界接大西洋。返回能到达两海的格子坐标，本实现按行优先顺序返回且不重复；原网格与行对象保持，不承诺空或非矩形输入。

从海岸反向搜索：若邻格高度不低于当前格，邻格的水就能顺坡流回当前格及该海，所以反向边应使用>=而非<=。分别从两海全部边界格出发求可达集合，交集中的格子恰能流到两海。初始集合消除重复角点，发现即标记避免重复入栈。每个搜索最多访问全部格子和常数条边，时间O(mn)，额外空间O(mn)，不递归、不改高度。

独立oracle从每个格子沿真正向低处的边搜索，检查它能否触达两种海岸，不复用反向多源搜索。六种至多6格的长宽组合枚举高度0/1/2，加3×3网格全部二值赋值，共2072个网格。边界在200×200平地上用全体坐标作期望、在严格行列递增/递减网格上用对应末行末列/首行首列闭式期望，并覆盖200单行/单列与最高合法值；大网格不运行逐格全搜索oracle。
