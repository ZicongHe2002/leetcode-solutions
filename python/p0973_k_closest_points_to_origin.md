# 973. K Closest Points to Origin · Python

[原题](https://leetcode.com/problems/k-closest-points-to-origin/)。

原题1<=k<=points长度<=10000，二维整数坐标范围-10000..10000，求到原点最近的k个点，返回顺序不限。原题保证答案集合唯一；实现也允许截断距离处有多个最优集合，此时任选合法集合，按点的出现次数保留重复点。输入保持，输出点行使用副本。

比较平方距离x*x+y*y即可，不需要开方。最小堆存负距离，相当于让已选k个点中最远者位于堆顶。堆未满时加入；满后若新点更近，就替换最远者，否则保留原选择。归纳可知每步选中的是已读点的k个最小距离，最终得到所求；相等距离不替换也符合最优集合的语义。下标用于定位原点行，不把重复值去重。

时间O(n log(k+1))，辅助空间O(k)，另外需要O(k)输出。Python整数平方精确，不使用浮点距离比较。

独立oracle对全部平方距离排序，比较输出的前k小距离及点多重性，不固定并列点的选择或排列。5种点、长度1..5共3905个小序列，枚举所有合法k，共18555次查询；边界同距造成答案不唯一的输入明确作为扩展。另测10000点、最大坐标、零点、重复点及k端点，核对整数坐标、逐行输入保持与输出副本。
