# 212. Word Search II · Python

[原题](https://leetcode.com/problems/word-search-ii/)。

原题棋盘1..12行列，仅小写字母；1..30000个互异单词，每词长1..10。只能上下左右相邻走，同一单词路径不能重复使用格子，返回能找到的词，顺序任意且每词一次。棋盘和单词列表在方法返回后保持。

先建字典树，共享所有词的前缀，终止标记$保存完整原词。棋盘每格作为起点，当前字符必须匹配字典树下一条边才继续。找到终止标记后弹出并保存该词，后续不同路径不会重复输出，但它的更长后继词仍可继续搜索。

进入匹配格时临时写#阻止同一路径重复使用，离开时恢复原字母；#和$均不属于合法小写输入。搜索完一个字典树节点后若它没有后继或终止标记，说明该前缀下所有词已找到，可以从父节点删除这条边。字典树仅属于本调用，剪枝不改words，所有棋盘临时标记在正常返回前恢复。

S为全部词总长度、L为最长词，建树O(S)，搜索保守上界O(mn*4^L)，额外空间O(S+L)，输出另计；递归只沿词前缀，L<=10。字典树剪枝通常减少搜索，但未把最坏搜索写成线性。

独立oracle逐词用访问集合搜索，不使用字典树、终止弹出或全局剪枝。二元字母的154个小棋盘，每次给出全部126个长度1..6单词，正逆字典顺序共308次查询，核对词集合、无重复及全部输入保持。最大12x12和30000互异词同时覆盖，十个a前缀词应全部找到；另测试重复格禁止与同词多条路径只输出一次。
