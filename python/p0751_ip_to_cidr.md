# 751. IP to CIDR · Python

[原题](https://leetcode.com/problems/ip-to-cidr/)。

原题给出合法IPv4起点和1..1000个连续地址，保证整个区间不越过32位IPv4末端。需要用最少CIDR块精确覆盖[ip,ip+n-1]，不能夹带范围之外的地址。返回任意最短列表；本实现使用规范网络地址并从小到大输出。

把四个十进制字节依次左移8位拼接成无符号整数start。CIDR块长度必为2的幂，且网络起点必须按这个长度对齐。start & -start给出非零起点允许的最大对齐块长；start=0时所有32位对齐都满足，必须把允许值视为2^32，不能得到0而死循环。剩余地址数n又把块长限制在不超过n的最大2幂，两者取小得到本轮块。

每轮块从当前尚未覆盖的第一个地址开始，对齐且长度不超过剩余区间，所以不会漏地址或覆盖额外地址。取最大合法块是最优的：任何精确覆盖的首块也必须从当前地址开始；对齐2幂区间只会包含或互不相交，不能部分交叉，因此最大合法块内部的更小块可以合并为它而不影响后续覆盖，块数不会增加。对剩余后缀归纳即可得到最短覆盖。

块长为2^b时前缀为32-b，等于33-size.bit_length()。用四次移位和掩码还原点分地址，随后start前进块长、n减少块长。n始终正数才进入循环，取到的size必为正；若恰到IPv4末端，剩余n为0便退出，不再格式化越界地址。

设输出B块，在32位整数模型下时间O(B)，除返回字符串列表外工作空间O(1)，输出空间O(B)。实现不调用网络服务或IP地址库。

独立oracle对小区间穷举所有能从当前地址开始的对齐2幂块，动态规划选最少块数，不使用最大块贪心。起点0..31与长度1..32全部1024查询核对，返回块用标准库IPv4Network严格解析，逐块验证规范对齐、连续、无重叠及精确终点；另用标准库地址范围汇总核对1000种子IPv4区间的最少块数。边界覆盖0、255字节进位、最大地址、1000地址及官方样例。未向LeetCode提交。
