# 409. Longest Palindrome · Python

[原题](https://leetcode.com/problems/longest-palindrome/)。

原题s长1..2000，只含大小写英文字母，区分大小写，例如Aa不能形成长度2回文。可使用部分或全部字符，返回能组成的最长回文长度int，不要求保留原字符顺序。

回文两端必须成对相等，中央至多有一个未配对字符。扫描时odd恰保存已处理前缀中出现奇数次的字符；再次遇到它就消去一次未配对状态并贡献一对长度2，否则放入odd。最终paired包含每个字符全部可用对数，至多再从odd任选一个作中央。这个构造达到任何回文必须受限的上界，因此最长长度就是paired加至多1。时间O(n)，固定52字母范围下额外空间O(1)。

独立参考枚举可能回文的半串和中央，实际拼成回文，再逐字符从输入位置列表remove分配，找最大可构造长度，不使用奇偶计数公式。字母a/A/b、长度1..7共3279个字符串，按排序文本缓存同多重集合参考结果；另测2000长度、大小写不同、全可成对和全不同字符，核对int。没有在线Accepted记录。
