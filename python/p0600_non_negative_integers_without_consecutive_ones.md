# 600. Non-negative Integers without Consecutive Ones · Python

[原题](https://leetcode.com/problems/non-negative-integers-without-consecutive-ones/)。

原题1<=n<=10^9，统计闭区间[0,n]中二进制表示不含相邻11的整数个数，必须包含0。实现额外支持n=0返回1，不处理负数。前导0不影响合法性，因此可把所有候选写成与n相同位宽。

counts[i]表示长度i的任意二进制串中无相邻1的数量，空串counts[0]=1，单个位counts[1]=2。i>=2时，合法串若以0开头，后面有counts[i-1]种；若以1开头，第二位必须0，剩下有counts[i-2]种，两类互斥完备，所以得到斐波那契递推。

从n的最高位向低位扫描，之前一直沿等于n的前缀。遇到n当前位为1时，可以把候选当前位置改为0，让其严格小于n；这个0也截断了与前一位的相邻关系，剩余bit位任取合法串，共counts[bit]种，加到answer。保持当前位1的分支继续与n前缀相同。

若前一位也是1，那么继续相等的前缀已经非法，再低位无论如何都不能补救。此时返回已经累计的更小分支总数，不能再把n加进去。若扫描结束未遇到11，则n本身合法，在所有严格更小候选之外再加1。各次累计按第一个小于n的位划分，彼此不重叠且覆盖全部小于n的合法整数。

设位宽W=max(1,n.bit_length())，预处理和扫描时间O(W)，额外空间O(W)，即O(log(n+1))，不枚举0..n。返回整数，使用整数位运算，无浮点转换或递归。

独立小规模参考直接枚举每个整数的bin字符串，以是否包含11维护累计数量，对0..100000共100001个上界逐项比较。大边界另用组合式sum(C(W-k+1,k))计算W位串中选择k个互不相邻1的位置数，不使用斐波那契或前缀扫描；核对全1上界、2次幂、以11开头的上界及n=10^9。30位最大合法数是交替10串，小于10^9，因此该上界的独立组合计数为2178309。未向LeetCode提交。
