# 1020. Number of Enclaves · Python

[原题](https://leetcode.com/problems/number-of-enclaves/)。

原题二元网格1..500行列，1是陆地，四邻移动，求无法经陆地走出网格的陆地格数量，统计格子而非岛屿个数。边界陆地可以直接离开，单行或单列所有陆地都可离开。实现保持grid。

从全部边界陆地一起入队，reachable在入队时去重，向四邻陆地泛洪。边界相接的整片陆地都可沿已发现路径走出；反过来任何能走出的格必须先到达某个边界格，因此恰好都在这次多源搜索中。全部陆地数减去reachable格数，就是封闭陆地数。

两次边界扫描可能遇到相同角格，单行/单列也会重复候选，集合保证每格只入队一次。每格至多检查4边，时间O(mn)，额外空间O(mn)，不通过抹掉陆地记录访问。

独立oracle对每个陆地格各自搜索是否能到边界，再数不能逃逸者，不复用全局多源泛洪。8858个小二元网格逐一核对。最大500x500全陆地答案0，四周水而内部满陆地答案248004，添加一个通边界桥后回到0；最大细长形也检查，核对int与输入保持。
