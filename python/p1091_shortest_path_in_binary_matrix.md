# 1091. Shortest Path in Binary Matrix · Python

[原题](https://leetcode.com/problems/shortest-path-in-binary-matrix/)。

原题grid为1..100的方形0/1矩阵，0可通行、1阻挡，允许八邻接。求左上到右下的最短路径所含格数，包含起终点；不可达返回-1。斜向相邻0可直接走，不附加两侧格也须为空的条件。输入保持，矩阵非空。

端点阻挡立即排除。以起点格数1进入BFS，每到一个未访问的相邻0格就加1并在入队时标记。所有边代价相同，队列第一次弹出目标时即为最短格数；单格0自然返回1。每格最多入队一次，八个方向为常数，时间与辅助空间均O(n^2)。

独立oracle把可通行格作为图点，以Chebyshev距离1建边，用Floyd计算所有点对最短边数，再加1转换成格数，不复用BFS。1*1、2*2、3*3全部530个格局核对。边界覆盖100*100全通、阻断横带、仅主对角可通、L形走廊的斜向拐角，核对int及输入保持。
