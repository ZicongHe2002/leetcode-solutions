# 257. Binary Tree Paths · Python

[原题](https://leetcode.com/problems/binary-tree-paths/)。

原题为1..100节点的非空二叉树，值-100..100，返回全部根到叶路径文本，用->连接节点值，顺序任意。重复值可能产生相同路径字符串，仍需按各个叶子保留重复项。只支持合法非空树，保持树，返回list[str]。

parts保存当前根路径的数字文本，显式栈区分进入与退出。进入节点时追加当前值，并安排一个退出标记；叶子把完整parts连接后加入结果，非叶依次安排右、左孩子，让左先处理。退出标记弹出一项，恢复进入该节点之前的路径，因此兄弟分支不会互相污染。只在真实叶子输出，单孩子缺失的一侧不生成路径。

设L为全部返回字符串总长度，节点值文本长度有界，每个节点进入退出各一次、每条输出只连接一次，时间O(n+L)，除输出外额外空间O(h)，没有为每个栈项复制整条前缀。测试独立递归生成根叶文本并按排序列表比较，保留重复数量。枚举1..5节点全部树形及值-1/0/2，共11496棵；另测100节点深链/宽树、负值两端、重复路径，核对原结构保持。
