# 809. Expressive Words · Python

[原题](https://leetcode.com/problems/expressive-words/)。

将目标与每个候选划分为连续同字符组。拉伸只增加原组长度，不改变组字符或组顺序，因此两边组数和对应字符必须相同。每组目标长度必须至少是候选长度；长度相等无需操作，长度不同时只有目标长度至少3才允许拉伸。逐组条件全部满足就计入该候选，重复词按数组项分别计数。输入保持。

设目标长度S、候选总长度L、词数W，时间O(S+L+WS)，其中每词组比较上界为S；额外空间O(S+最长候选长度)。
