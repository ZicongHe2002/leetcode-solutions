# 169. Majority Element · Python

[原题](https://leetcode.com/problems/majority-element/)。

输入非空整数列表，原题保证恰有一个值出现次数严格超过floor(n/2)，返回该值，不修改输入。这里依赖多数元素必存在的承诺，不对空列表或没有严格多数的输入定义返回值，也不将问题替换成寻找超过n/3的全部值。

candidate是当前未消去部分的候选，balance是其剩余份数。当前值与候选相同就增一，否则消去一份候选与当前不同值。当balance归零，下一个值可以成为新候选，相当于从剩余未处理序列重新开始。

每次消去一对不同值，严格多数最多损失一份，而其余值也恰好损失一份，因此多数相对其他值合计的数量优势不会被消去。原输入存在严格多数，所有成对消去结束后它必然仍在剩余候选中。balance不是候选的实际总频数；如果取消原题存在性承诺，就必须另行验证真实频率，不能直接沿用此接口结论。

列表只扫描一次，时间O(n)，额外空间O(1)，没有排序、构建生产频数字典或复制输入。候选使用输入的整数本身，0和负值都不充当特殊哨兵。

独立oracle用Counter统计全部值，仅选择满足原题严格多数承诺的数组。穷举三值域长度1..8的所有数组，过滤后逐项核对唯一多数与输入保持。另测50000项、前段强烈反向候选后被真实多数反超、0及极端负正值，检查返回类型。
