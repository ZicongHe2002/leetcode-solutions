# 357. Count Numbers with Unique Digits · Python

[原题](https://leetcode.com/problems/count-numbers-with-unique-digits/)。

统计0<=x<10^n中十进制各位互不相同的整数，原题n在0..8。数字按通常整数表示，不添加前导0；0本身合法。n=0只有x=0，因此答案为1。

先计入0。长度为1的正整数有9个首位选择；长度为2时，首位仍有9种，第二位可以用0但不能重复首位，剩9种；再往后每一位少一个可用数字。因此固定正长度d的数量为9乘以从9开始的d-1个递减因子。长度不同的整数集合互不相交，逐个长度相加即为所求。

ways在每次循环开始时保存当前正长度的数量，先加入total，再乘10-digits准备下一长度。首位不使用0，后续位允许0但不能重复，这与所有位置都给10种选择不同。total从1开始使零值不被漏计，也不与一位正数重复。

在一般变量n的模型下时间O(n)，只保存固定数量整数，额外空间O(1)；原题n<=8，所有结果可直接用普通整数表示。

独立数位DP将输入视为n位宽度，分别保存剩余位数、已使用数字的位掩码、是否已经遇到非零首位，枚举每个位置的0..9，不使用长度乘法公式。n=0..8全部对照；另对n=0..5逐个枚举实际整数并检查字符串数字是否重复，交叉核对DP与生产计数，覆盖零与前导零语义。上界n=8应为2345851。未向LeetCode提交。
