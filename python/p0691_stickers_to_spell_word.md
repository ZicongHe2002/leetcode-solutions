# 691. Stickers to Spell Word · Python

[原题](https://leetcode.com/problems/stickers-to-spell-word/)。

原题1..50种小写字母贴纸，每张长度1..10，每种可无限复用，target长度1..15。可以剪下字母重排，求凑齐目标所需最少贴纸数，无解返回-1。不同目标位置上的同一字母可互换，所以只需记录各字母尚缺数量；不能把每种贴纸限制只用一次，或把无关字母也当目标需求。输入贴纸列表保持，返回int。

把目标出现的字母固定排序成letters，每种贴纸只保存这些字母的供给数量。记忆化状态remaining是对应剩余数量的不可变元组。目标全满足时返回0；否则选择第一个仍缺的字母，只尝试含该字母的贴纸，将每个需求减去该贴纸供给并截断到0，再递归求剩余最优值。

这种筛选不会丢解：任何可行方案中必有一张含当前缺字的贴纸，字母数量的相减与截断不依赖贴纸使用顺序，因此可把那张先用。每个尝试至少减少所选字母1个，递归必进展，深度最多target长度。所有供给贴纸在每个状态都可再次尝试，实现无限复用。相同剩余数量的不同使用路径共享同一缓存结果。

只把可行子状态的结果加1取最小，找不到就返回-1。任意可行目标都能用至多T张贴纸完成（每个目标字母各选一张包含它的贴纸），所以T+1可作不可能哨兵，T为目标长度。

设m为贴纸种数、D为目标不同字母数、S为所有贴纸字符数。状态数至多各需求数加1的乘积，并且不超过2**T，每状态尝试m种贴纸、每次处理D项，时间O(S+m*D*2**T)，缓存及供给空间O(D*(m+2**T))。本题T<=15，算法仍是目标长度的指数算法，不声称一般多项式。

独立oracle在目标位置位掩码上BFS，对每张贴纸逐字符枚举所有合法的目标位置分配以及丢弃该字符的选择，不按某个首缺字剪枝。a/b长度1..2的6种贴纸中选1..3种，共41个集合；所有a/b长度1..5目标62个，共2542次查询。另核对200个固定种子三字母样本、50种10字符贴纸、15字符目标、无限重复、缺字无解与两个原题例。核对输入列表保持，未向LeetCode提交。
