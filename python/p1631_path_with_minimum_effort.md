# 1631. Path With Minimum Effort · Python

[原题](https://leetcode.com/problems/path-with-minimum-effort/)。

原题矩阵行列数1..100，高度1..1000000，从左上到右下可四向移动。路径代价是各相邻高度绝对差的最大值，求该最大值能达到的最小值int；不是高度总和或台阶差总和，输入不变，单格答案0。

best[r][c]保存到该格已知的最小瓶颈值，初始起点0。沿边扩展时新代价为max(旧瓶颈,本台阶差)，不会小于旧代价，因此可以按最小瓶颈优先出堆并使用Dijkstra的单调标签论证。过期标签跳过，目标以当前最优值取出即可返回；矩形网格总连通，合法输入必能取出目标。相邻差最大999999，1000000是足够大的初始哨兵。若N=rows*columns，时间O(N log N)，额外空间O(N)，不改写原高度。

独立参考枚举实际台阶差组成的候选阈值，逐个只保留差不超过阈值的边，BFS检查终点连通，不复用最小瓶颈堆。1..3行列、最多6格、值1/2/4的全部1614个矩阵逐一核对；另测100乘100常量/极值棋盘/行序梯度，长单行单列、单高格与原题零代价绕行，核对int与输入保持。
