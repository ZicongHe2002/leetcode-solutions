# 851. Loud and Rich · Python

[原题](https://leetcode.com/problems/loud-and-rich/)。

建立更富者指向较穷者的有向边，题目财富关系一致，构成无环图。每人初始答案为自己。按拓扑顺序处理时，其全部更富前驱已传完各自最安静候选，再将当前最佳传给后继。任何能沿更富关系到达当前人的人都通过某个前驱传入，自己也保留为候选，因此最终得到不比自己穷的人中最安静者。

时间O(N+E)，额外空间O(N+E)，不修改输入，不依赖递归深度。
