# 97. Interleaving String · Python

[原题](https://leetcode.com/problems/interleaving-string/)。

原题s1、s2各长0..100，s3长0..200，均为小写英文。判断s3能否由两串交错而成，同时保留各串内部顺序。空串属于原题合同；只核对字符数量相等并不足以判断交错，字符串保持。

possible[j]表示s1当前前缀与s2前j项能否形成s3对应前缀。先初始化只从s2取字符的首行；每次加入一个s1字符，可能来自上一行同列并匹配s1尾字符，或本行前一列并匹配s2尾字符。j自左向右更新，旧possible[j]仍是上一行，possible[j-1]已是本行；possible[0]单独维护只从s1取的情况。长度不等先返回False，避免越界。时间O((len(s1)+1)*(len(s2)+1))，额外空间O(len(s2)+1)。

独立oracle递归枚举从两串依次取下一个字符的全部交错结果，再按集合成员关系比较，不复用DP表。二字母两源串各长0..3，共225对，枚举每个对应长度的所有二字母候选目标，共7225次查询。边界覆盖100+100长度、相同频次但顺序错误、空串与长度不符，核对bool。
