# 143. Reorder List · Python

[原题](https://leetcode.com/problems/reorder-list/)。

原题为1..50000节点的无环单链，值1..1000，将L0,L1,…,Ln重排为L0,Ln,L1,Ln-1,…，只能改next不能改val。函数原地修改，按评测接口返回None，head对象保持为首节点；不定义空链输入。本文件ListNode供本地导入，字段与评测器一致。

快慢指针把链分成前后两半，快指针从head.next起步，保证前半长度不短于后半。先令slow.next=None断开两半，否则反转和交织时可能残留回路。再原地反转后半，使它按Ln,Ln-1,…排列；每轮分别保存两半后继，接出一个前半节点和一个后半节点。后半耗尽后，偶数长度恰好结束；奇数长度的中央节点已留在前半尾部并指向None。

找中点、反转、交织各线性扫描，时间O(n)，额外空间O(1)，没有递归、节点数组或值交换。测试按原下标交替取两端构造参考身份顺序，不复用链表拆分算法。值1/2、长度1..8共510条链，另测50000/49999长度、单节点与最短偶数链；核对返回None、确切身份、无额外尾节点和值不变。
