# 149. Max Points on a Line · Python

[原题](https://leetcode.com/problems/max-points-on-a-line/)。

给定互不相同的整数坐标点，求同一直线上的最多点数。原题最多300点，坐标绝对值不超过10000；点互异保证任意两点的方向向量不同时为0。本实现不修改输入，额外支持空列表返回0，不处理重复点的额外计数语义。

固定一个锚点，计算到后续各点的(dx,dy)。先除以两个分量的最大公约数，再统一符号：dx为正，或dx=0时dy为正。这样同线的反向向量也归入同一键；水平线规范为(1,0)，竖直线为(0,1)，不用浮点斜率或除零特例。

一个方向桶的点数再加锚点本身，就是这条线的点数。只检查后续下标不会遗漏全局最优线：取这条线上下标最早的点为锚点，该线其余点必然全部在后面。每个桶只在当前锚点内使用，不能把不同锚点的平行线混在一起。

有O(n²)个点对，每个方向使用一次gcd及哈希操作；若把坐标差界记为C，整数gcd代价计入时上界为O(n² log C)。原题坐标范围固定，通常记O(n²)时间，额外空间O(n)保存单个锚点的方向桶。

独立oracle枚举每条由两个点确定的候选直线，以整数叉积是否为0逐点判断，不用斜率归一化或方向哈希。穷举3×3网格全部512个点子集，并检查输入保持。另测水平/竖直/正负方向、几乎共线却叉积差1的点、300项共线与两条各150点的不同直线。
