# 1870. Minimum Speed to Arrive on Time · Python

[原题](https://leetcode.com/problems/minimum-speed-to-arrive-on-time/)。

原题dist长1..100000，每项1..100000，hour为至多两位小数的允许小时数；前n-1段到达后须等到下一整数小时才能出发，最后一段无需取整。求最小正整数速度，无法按时则返回-1；题目保证存在解时最小速度不超过10^7。输入距离数组保持且非空，更多小数位不属于本实现承诺的合同。

用Decimal(str(hour))把原题十进制小时读成整数百分之一小时。给定speed，前n-1段分别向上整除得到whole_hours，最后一段是dist[-1]/speed；把总时间不超过hour两侧同乘100*speed，用整数比较，避免浮点把恰好准点误判。速度增大不会增加任一段时间，故先核验上界10^7，再二分第一个可行速度。时间O(n log(10^7))；当前实现的dist[:-1]切片占O(n)额外空间，未声称常数空间。

独立oracle对小输入逐个枚举速度，用Fraction计算准确分数总时长，不复用整数交叉相乘或二分；非末段至少各占1小时，预算不超过n-1小时可直接证明无解。距离1..4、长度1..4共340个数组，各测10个合法两位小数预算，共3400次比较。边界覆盖100000段、10^7速度恰好可行、99百分之一小时尾段与无解，核对int和输入保持。
