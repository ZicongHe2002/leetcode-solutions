# 136. Single Number · Python

[原题](https://leetcode.com/problems/single-number/)。

输入非空数组长度不超过30000，值在[-30000,30000]，只有一个值出现一次，其余不同值恰出现两次。返回单次值，保留原数组，不承诺空数组或其他频次。合同决定合法长度为奇数，最大可达29999。

异或满足交换律、结合律和x^x=0，把所有元素异或后，每个成对值抵消，单次值与初始0异或仍是自身。Python负数的位运算按无限符号扩展语义计算，但同一个负数与自身异或依然为0，因而无需改写为正数或固定字长掩码。时间O(n)，额外空间O(1)，不使用频次表或排序。

独立oracle用Counter选择唯一频次1的值。取值池[-1,0,1,2]，枚举单次值、其余值的任意成对子集及全部不同排列，共2920个合法数组，覆盖负数、零和任意出现顺序。边界覆盖29999长度的合法数组、单次值正负端点与单元素；逐次核对输入保持。
