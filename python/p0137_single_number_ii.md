# 137. Single Number II · Python

[原题](https://leetcode.com/problems/single-number-ii/)。

原题nums长1..30000，值在有符号32位范围，每个数恰出现3次，只有一个数出现1次。返回这个单例int，要求线性时间、常数额外空间；不支持重复次数不满足合同的输入，保持数组。

分别对每个二进制位累计出现1的次数模3。once/twice的对应位组合表示余数0=(0,0)、余数1=(1,0)、余数2=(0,1)，不产生(1,1)。新值该位为0时保持；为1时沿0→1→2→0循环。第一式用旧twice清除不能留在once的位，第二式必须用刚更新的once来清除不能留在twice的位。三次出现的数在每一位贡献0，最终once就是唯一单例。

Python位运算对负数按符号扩展的二进制语义计算，所有高位也执行同一模3状态机；输入均为32位有符号数，扩展高位最终统一恢复正确符号，不需要把负结果强制变成无符号数。按固定32位值域每次运算大小有界，时间O(n)、额外空间O(1)。

独立参考用Counter找频次1，不复用按位状态。枚举值-1/0/1、长度1/4/7的全部合法数组，共447个，覆盖合法排列顺序。合法长度必须等于1模3，因此不超过30000的最大合法长度是29998；另测这个长度、符号两端、单元素和0，核对int及输入保持。
