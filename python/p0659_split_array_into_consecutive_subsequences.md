# 659. Split Array into Consecutive Subsequences · Python

[原题](https://leetcode.com/problems/split-array-into-consecutive-subsequences/)。

原题nums非递减、长1..10000，值-1000..1000，判断能否把每个出现位置分配到一个或多个子序列，每条严格逐项+1且长度至少3。相同值的不同出现位置可分别使用，不能把数组去重，也不能让同一出现次数进入多条序列。输入保持，不在实现中重新排序。

remaining记录尚未分配的出现次数，endings记录已形成且长度至少3的序列尾值。按升序看当前最小未用值v，先消耗它；若已有尾为v-1的序列，就把v接到其后。这个优先级不会破坏可行解：若某可行分配反而让v新开一条序列，旧序列若到v-1即结束，就把整条新序列接到它后面；若旧序列原计划接另一个v，只交换这两个相同v的出现位置，保留两条序列各自的后缀。非递减输入使所有v都先于v+1，交换后顺序与长度保持，所有出现次数仍各用一次。

若没有可接尾，v只能作为新序列的起点。它至少还需一个v+1与v+2，必须立即从remaining各预留一次，并登记尾v+2；缺任意一个就不可行。这也保证endings从不包含长度1或2的未完成序列。预留过的元素稍后在原数组中再次遇到时，若remaining已0就跳过，不二次消费。升序使这些局部选择可以逐步固定为某个可行分配的前缀，因此全部处理成功时确有合法拆分。

Counter构造与原数组扫描共期望O(n)时间，两个计数表空间O(u)，u为不同值数，保留零计数也不超过该量级；不逐条复制子序列。独立oracle允许把当前值接到任意兼容序列，或随时新开长度1的序列，直到最后才检查每条长度>=3；缓存规范化的(尾值,截到3的长度)多重集，枚举所有分配，不使用三项预留规则。

值-2..2组成的全部长度1..10非递减数组共3002个完整对照，另查200个固定种子样本。边界覆盖10000元素、重复值数量恰可分配/多一个无法分配、全同值、原题值域两端和标准可行/不可行例。未向LeetCode提交。
