# 368. Largest Divisible Subset · Python

[原题](https://leetcode.com/problems/largest-divisible-subset/)。

从互不相同的正整数中选最大子集，要求任意两项中较大的数可以被较小的数整除，返回任意一个最大子集。原题长度1..1000，数值1..2*10^9。本实现不改写输入，输出按升序组织；空列表额外返回空列表，0和负数不属于输入合同。

先排序。合法子集的升序相邻项必然整除；反过来，相邻项整除会通过传递性保证每对元素整除，所以可求最长整除链。lengths[i]为以ordered[i]结尾的最长链长度，初始单元素长度1。枚举j<i且ordered[i]能被ordered[j]整除，从j的最优链再接i；任何更长的合法链都必有这样的倒数第二项，因此候选完整。

previous[i]记录真正改善长度的前驱下标，只指向较小下标，不会循环。best指向已处理节点中最长链的末尾。沿前驱回溯得到一条实际可行链，再反转为升序。答案不唯一时保留先找到的链，不把某一固定列表当作唯一正确结果。

排序O(n log n)，双循环O(n²)，合计O(n²)时间；排序副本、长度、前驱与返回结果各O(n)，总额外空间O(n)。没有对巨大值域建立数组。

独立oracle枚举原输入的全部子集，对每个候选直接检查所有元素对的整除关系，不使用生产最长链递推。1..12的全部4096个输入子集对照最大可行大小，同时核对输出只含原值、无重复且所有元素对可整除；输入保持。另测1000元素、2*10^9值界、没有可配对项、多解与长倍增链；空输入为扩展。
