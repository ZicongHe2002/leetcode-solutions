# 188. Best Time to Buy and Sell Stock IV · Python

[原题](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iv/)。

原题1<=k<=100，prices长度1..1000，价格0..1000，同时至多持有一股，至多完成k次交易，求最大利润，保持输入。

buy[t]表示至多第t层交易且仍持股时的最佳现金，sell[t]表示至多t次交易后不持股时的最佳收益。卖出从旧buy[t]加当前价格转移，买入从旧sell[t-1]减当前价格转移；原状态均可继续等待。sell以0初始化以允许少交易，buy以负无穷表示尚未发生的买入。

交易层数从k逆序到1。更新sell[t]时buy[t]还没有改变；随后更新buy[t]时sell[t-1]仍是前一天值，因为更低层尚未处理。这让一维数组保留按天递推的含义。若k>=n//2，交易次数已足够覆盖全部上涨段，可以直接累加相邻正差；同日零收益往返不影响最优值，不需要多于n//2次有收益交易。一般分支时间O(nk)、辅助空间O(k)，不限次分支时间O(n)、辅助空间O(1)。

独立oracle枚举每天合法动作，卖出时才消耗一次完整交易额度，不复用buy/sell数组。3种价格、长度1..6共1092个数组，各查询k=1..4，共4368次。边界覆盖1000天、k=100的一般分支和200天时的不限次分支、单次额度、上涨/下降与单日，核对int及输入保持。
