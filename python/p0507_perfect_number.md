# 507. Perfect Number · Python

[原题](https://leetcode.com/problems/perfect-number/)。

判断正整数num是否等于其全部正真因子之和，真因子不包括num本身。原题1<=num<=100000000；0或负数不在合同内。1没有正真因子，和为0，因此必须返回False，不能把初始化的1误算成它自己的真因子。

对于num>1，先把真因子1计入。其他因子总能配对为factor和num/factor，其中至少一个不超过平方根；只枚举2..floor(sqrt(num))就覆盖全部。整除时加入factor和其配对因子，完全平方数在两者相等时只加入一次，不把num本身放回总和。

所有真因子均为正，总和一旦大于num就可以立即判False；但刚好等于时不能提前判True，因为还可能有未处理因子。扫描完成再比较total==num。判断循环上界用整数factor*factor，避免浮点平方根边界；商只在整除分支中计算。

至多枚举O(sqrt(num))个候选，辅助空间O(1)，没有保存因子列表，也没有把已知完全数表硬编码成实现。原上界只需约10000次候选检查。

独立参考直接枚举1..num-1的每个数，加入所有能整除的真因子，不使用平方根配对。num=1..3000全部对照。另测6/28/496/8128/33550336这些完全数、2^26、完全平方数及100000000；最大值额外以2/5素因子组合计算真因子和，核对布尔接口。未向LeetCode提交。
