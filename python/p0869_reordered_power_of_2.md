# 869. Reordered Power of 2 · Python

[原题](https://leetcode.com/problems/reordered-power-of-2/)。

可以重排成某数当且仅当两数十进制数字多重集相同。把数字串排序后比较。原题n<=10^9，只需覆盖2^0到2^30；更大幂的位数已经超过允许输入可重排的位数。候选幂本身使用规范十进制表示，所以不会接受前导0的伪表示。1=2^0也包含。

至多31个候选，每个至多10位，原题有界范围内时间与空间均为常数；不枚举数字阶乘数量的排列。
