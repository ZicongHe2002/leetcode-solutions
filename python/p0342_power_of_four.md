# 342. Power of Four · Python

[原题](https://leetcode.com/problems/power-of-four/)。

原题n在-2^31..2^31-1，判断是否为4的非负整数次幂，返回bool。1是4的0次幂；0、负数以及仅为2的奇数次幂的数都不是4的幂。

正的4^k等于2^(2k)，二进制只有一位1，而且该位的0起始下标为偶数。先用n>0和n&(n-1)==0确认正数且只有一位1，再用0x55555555检查这一位在0、2、4、…、30中。掩码覆盖原题全部合法正数位，特意绑定32位值域，不把固定掩码宣称适合任意大整数。实现没有循环或递归，固定32位合同下时间与额外空间均O(1)。

独立参考从1重复乘4生成集合。枚举-1000..1000共2001个整数，另查16个合法4次幂及邻值、全部31个2次幂以区分奇偶指数，再查有符号32位边界和bool返回。
