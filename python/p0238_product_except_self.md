# 238. Product of Array Except Self · Python

[原题](https://leetcode.com/problems/product-of-array-except-self/)。

长度2..100000，值[-30,30]，题目保证任意前后缀乘积与答案均在32位有符号范围。输出每个下标之外所有元素的积，不使用除法。左到右先写严格左积，再把当前值乘入prefix；右到左先把严格右积乘入答案，再更新suffix。两个严格区间恰好无重无漏地覆盖除当前下标之外的元素。

空前缀/后缀积为1，单零位置可得到非零积，其余位置为零；两个零使全部答案为零，无需另设分支。Python整数不会产生固定宽度溢出，但测试仍遵守原合同。时间O(n)，输出O(n)，除输出外额外空间O(1)，原输入保持。

独立oracle对每个排除下标直接乘其余所有元素，不用前后缀算法。四值[-2,0,1,2]上长度2..6共5456个数组；边界含100000个1上零个/一个/两个零，以及31个-2的完整积INT_MIN。
