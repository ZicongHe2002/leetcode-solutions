# 656. Coin Path · Python

[原题](https://leetcode.com/problems/coin-path/)。

原题coins长1..1000、每项-1..100，首项保证不是-1；-1位置禁止访问。步长1..maxJump且maxJump在1..100，从1号位置到n号位置，支付每个所到位置的coins值，返回最低总费用的1基下标路径，无解返回[]。费用相同时按完整下标序列字典序选最小，不按跳数最少选。输入保留，空数组不在合同内。

从右向左令best[i]为从i出发到终点的最低费用，包含当前位置；不可达为无穷。终点可用时best[n-1]=coins[n-1]，其他可用位置尝试范围内每个后继j，以coins[i]+best[j]更新，并记录following[i]。每个后继更靠右，计算时已知完整最优后缀，故转移覆盖所有路径。

后继按下标递增枚举，只在费用严格更低时更新，等价于相同最低费用下保留最小j；后缀本身已按同样规则最小。两条到同一终点的严格递增路径不可能一条是另一条的真前缀，因此首次不同的后继下标即可决定字典序。特别是全部费用0时，最小路径是1,2,...,n，不能为了更少跳数选1,n。

following的-1只用于终点或不可达状态；best[0]有限后重建路径，会严格向右并在终点停止。最坏时间O(n*min(n,maxJump))，空间O(n)，包括费用、后继与返回路径；有限费用均为整数，浮点无穷仅作哨兵，不参与精度近似。

独立oracle直接枚举全部合法的1..maxJump前跳路径，把(实际逐点总费用,完整下标列表)整体取最小，不使用best或following。首项0/2、其他项-1/0/2的长度1..7共2186个合法数组、全部1..n步长共14216次查询。最大1000项另查全0长字典序路径、全1大跳步、100费用且只能走一步、恰跨100与不可达，以及末位禁止访问。没有LeetCode提交记录。
