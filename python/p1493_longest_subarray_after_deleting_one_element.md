# 1493. Longest Subarray of 1's After Deleting One Element · Python

[原题](https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/)。

原题nums为长度1..100000的二进制数组，必须删除恰好一个元素，再求最长连续1段；无法得到非空1段时返回0。输入不变，实现额外定义空数组返回0，非原题删除合同。

把候选窗口视为包含本次删除的位置：窗口有一个0就删0，没有0就删一个1，均得到窗口长度减1。因此维护含至多一个0的最长窗口，加入右端造成两个0时持续缩左端，对每个右端记录right-left。若某个最优1段的删除发生在段外，可把原段与紧邻的一个元素组成窗口，再在该窗口中删一次，仍保留至少同样长的1段；所以把删除放进候选窗口不会漏掉最优解。全1数组自然得到n-1。左右各最多前进n次，时间O(n)，额外空间O(1)。

独立oracle逐个尝试真实删除每个下标，再把剩余二进制文本按0分段取最长1段，不复用至多一个0的窗口。长度0..12共8191个数组全部核对，空数组单列扩展。边界覆盖100000个1、全0、交替数组、一个0连接两长段以及两个相邻0，核对int和输入保持。
