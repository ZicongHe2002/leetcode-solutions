# 79. Word Search · Python

[原题](https://leetcode.com/problems/word-search/)。

矩形board的行列长度均为1..6，word长度1..15，字符为大小写英文字母。判断是否有一条四方向相邻、同一个单元格至多使用一次的路径拼成word。本实现保持网格数值和行对象；额外支持空word为true，空网格匹配非空word为false。

先检查格子总数与各字符总频次，任一不足即可判不可能。递归状态(row,column,index)表示当前格子拟匹配word[index]，visited只记录这一条路径之前已使用的格子。字符不符立即失败，匹配末字符立即成功；否则加入当前格子，枚举合法且未访问的四邻。成功和失败两条返回路径都撤销当前格子的visited标记，其他起点不会继承旧路径状态。每条可行路径都会逐步枚举，visited阻止单元格重用而不阻止另一条独立路径尝试同一格。

设L为word长度，预检O(mn+L)，保守搜索上界O(mn·4^L)。递归深度及visited最多L，字母表合同固定，频次表为常数个键；不计输入的额外空间O(L)。没有原地覆盖网格或保留失败搜索的标记。

独立oracle不按目标前缀剪枝：先用显式状态列表枚举网格上全部不重复格子的短路径，记录其生成的所有词，再以集合成员关系判断每个查询。枚举1x1、1x3、2x2、2x3的全部90个二字母网格，查询长度1..min(5,格子数+1)的全部二字母词，共5212次，包括格子重用诱饵。边界另有经典ABCCED/SEE/ABCB、6x6与15长度、字母频次不足、大小写及空扩展，逐次检查输入保持。
