# 629. K Inverse Pairs Array · Python

[原题](https://leetcode.com/problems/k-inverse-pairs-array/)。

原题1<=n<=1000、0<=k<=1000，统计1..n全部不同整数的排列中恰有k个逆序对的数量，返回模1000000007的整数。逆序对是下标i<j且值a[i]>a[j]的有序下标对。k超过n(n-1)/2时不存在这样的排列，直接返回0。

向1..size-1的一个排列插入最大元素size，它右边有t个元素时恰新增t个逆序对，t可取0..size-1；插入位置与t一一对应。因而本行j的计数是上一行j、j-1、…、j-size+1的和，负下标视为0。上一行只需保存0..k：逆序对不会在以后插入时减少，更大的状态不会回到所求范围。

window由左向右累加previous[j]，j>=size时减去刚离开窗口的previous[j-size]，每步取模得到本行状态。新行使用独立数组，避免把本行刚写的结果当作上一行。j最多算到min(k,size(size-1)/2)，剩余位置保留0；初始size=1仅有0逆序的一种排列。最终previous[k]即答案。包括逐行清零在内，时间O(n(k+1))，额外空间O(k+1)；k=0时仍有n行，不能把时间误写为零。

独立小输入oracle枚举n=1..8的全部46233个排列，逐一比较所有下标对建立直方图，核对108次合法k查询（含超过可达逆序上限的k）。另一oracle用未取模的逐项卷积构造至n=60的精确多项式，并抽查多个行与k；不复用滑动窗口。n=1000、k至1000时另用生成函数与Euler五边形数定理：在k<=n时，所求系数等于乘积prod(1-x^i)与(1-x)^(-n)在x^k处的系数，前者在次数k以内使用无限乘积的五边形稀疏系数，后者系数为组合数。该检查使用math.comb精确整数后取模，不使用生产DP。没有LeetCode提交记录。
